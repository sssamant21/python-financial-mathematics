## Editorial Workflow

Every section progresses through:

**Draft → Technical + Source Review → Production + Copyright Review → Revised Final / Canonical Edition**

## Source and Copyright Policy

This project is written as original educational material. Technical and mathematical claims that depend on external sources should be supported by appropriate references. Sources are used for verification and attribution rather than copied as manuscript text. Direct quotations should be exceptional, clearly identified, and appropriately cited. Mathematical notation, algorithms, examples, and Python implementations should be independently expressed unless an external source is explicitly quoted or adapted under compatible terms.

Each canonical section should retain its verified references so source provenance is preserved throughout the editorial workflow.

## Repository Layout

- `books/` — manuscript source organized by book and chapter
- `references/` — bibliography, source policy, and reference tracking
- `examples/` — reusable Python examples
- `notebooks/` — Jupyter notebooks and computational demonstrations
- `tests/` — validation tests for reusable code
- `docs/` — project and editorial documentation
