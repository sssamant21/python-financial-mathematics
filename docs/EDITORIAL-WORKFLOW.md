# Editorial Workflow

Every manuscript section follows the same controlled workflow.

## 1. Draft

Develop the mathematical theory, financial interpretation, Python implementation, examples, assumptions, terminology, and references together. References are not postponed until publication.

## 2. Technical + Source Review

Validate mathematical correctness, financial terminology, Python behavior, assumptions, notation, numerical reasoning, and the authority/relevance of cited sources. Identify unsupported claims and source gaps.

## 3. Production + Copyright Review

Review organization, readability, consistency, code presentation, equations, tables, cross-references, bibliography integrity, attribution, quotation use, external code/data/figure licensing, and possible close paraphrasing.

## 4. Revised Final / Canonical Edition

Incorporate all accepted corrections. Retain verified references. The canonical file becomes the authoritative manuscript version used by subsequent chapters and publication artifacts.

## Status Vocabulary

- Planned
- Draft
- Technical + Source Review
- Production + Copyright Review
- Revised Final / Canonical Edition

## Canonical Rule

Once a section reaches canonical status, future changes should be deliberate revisions rather than silently replacing established terminology, notation, assumptions, or references.
