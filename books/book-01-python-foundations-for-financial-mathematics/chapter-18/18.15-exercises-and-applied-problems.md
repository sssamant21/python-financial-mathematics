## Learning objectives

Apply simulation concepts to returns, paths, portfolios and risk; compute analytical benchmarks; interpret uncertainty and convergence; distinguish model assumptions from sampling error; and design reproducible validation evidence.

## How to use this section

Attempt each problem before reading its worked answer. Unless otherwise stated, values are in the same currency, rates are decimals, and samples are independent. Round only for presentation. Simulation estimates describe the specified model, not guaranteed future outcomes. A confidence interval for a model expectation is not a range of future payoffs.

## Part A — Simulation foundations

### 1. Outcome and expectation

**Problem:** A value is 90 or 110 with equal probability. Find its expected value.

**Solution:** .5(90)+.5(110)=**100**.

### 2. Unequal probabilities

**Problem:** The probability of 110 is .6. Find the expected value.

**Solution:** .6(110)+.4(90)=**102**.

### 3. Sample mean

**Problem:** A sample is [90,110,110,110]. Calculate its mean.

**Solution:** 420/4=**105**. Sampling variation explains why this sample need not equal the model mean 100.

### 4. Loss frequency

**Problem:** Initial value 100; use the sample in Exercise 3. Define loss as terminal value <100.

**Solution:** One of four observations is below 100, so observed loss frequency is **.25**.

### 5. Scenario versus probability

**Problem:** A stress assumes a 20% asset decline. Is its probability known?

**Solution:** No. A deterministic stress is a conditional calculation; a probability requires an explicit justified model.

### 6. Pseudorandom state

**Problem:** What happens when a generator consumes an additional draw?

**Solution:** Its state advances, so later draws typically change. A seed alone is insufficient if operation order changes.

### 7. Reproducibility

**Problem:** What must be recorded beyond a seed?

**Solution:** Model inputs, generator and implementation, versions, code, path count, draw order, stream assignment and relevant platform settings.

### 8. Parallel streams

**Problem:** Four workers each start with the same seed. What risk arises?

**Solution:** They may produce duplicate sequences, overstating the effective sample size. Use documented stream spawning and record assignments.

### 9. Uniform mapping

**Problem:** U is uniform on [0,1); use U<.25 for down, .25≤U<.75 for flat, and U≥.75 for up. What state is U=.75?

**Solution:** **Up**, because the final interval includes .75.

### 10. Model versus data

**Problem:** Does a large simulation sample make a poorly specified model correct?

**Solution:** No. More paths can reduce sampling variability but do not repair wrong assumptions or inputs.

## Part B — Outcomes and returns

### 11. Simple return

**Problem:** Price increases from 100 to 110. Calculate simple return.

**Solution:** (110−100)/100=**.10**, or 10%.

### 12. Log return

**Problem:** Calculate log return for 100→110.

**Solution:** ln(1.1)≈**.0953102**.

### 13. Compounding

**Problem:** Starting at 100, return +10% then −10%.

**Solution:** 100×1.1×.9=**99**, a cumulative simple return of −1%.

### 14. Simple-return boundary

**Problem:** What simple return corresponds to a price falling from 100 to zero?

**Solution:** **−1**, or −100%. A finite log return is not defined at zero terminal price.

### 15. Normal simple-return model

**Problem:** Why can an unbounded normal simple-return model be unsuitable for a limited-liability asset?

**Solution:** It assigns positive probability to returns below −1, implying negative values. Clipping or discarding those draws changes the distribution.

### 16. Normal log-return expectation

**Problem:** V₀=100, one-year log return L~N(.04,.20²). Find expected terminal value.

**Solution:** E[V₁]=100exp(.04+.20²/2)=100exp(.06)≈**106.18365**.

### 17. Median terminal value

**Problem:** Find the median under Exercise 16.

**Solution:** 100exp(.04)≈**104.08108**. It differs from the mean because the terminal distribution is right-skewed.

### 18. Discounting

**Problem:** A one-year expected payoff is 100 and the annual effective rate is .05. Find its discounted expectation.

**Solution:** 100/1.05≈**95.2381** under the stated assumptions. This is not automatically a risk-neutral price.

### 19. Costs

**Problem:** A fixed fee of 2 is paid at the end of the year from an expected terminal value of 100.

**Solution:** Expected net terminal value is **98**. State fee timing and avoid double counting.

### 20. Model probability

**Problem:** Values 80, 100, 120 have probabilities .25, .5, .25. Find P(V₁<100).

**Solution:** Only the 80 state qualifies, so **.25**.

## Part C — Estimation and convergence

### 21. Model variance

**Problem:** Calculate variance of the distribution in Exercise 20.

**Solution:** .25(80−100)²+.5(0)²+.25(120−100)²=**200**.

### 22. Standard error

**Problem:** For 10,000 independent draws from that model, calculate theoretical SE of the mean.

**Solution:** √200/√10000≈**.14142**. Outcome SD is √200≈14.1421.

### 23. Fourfold sample size

**Problem:** What is the approximate effect of quadrupling independent paths?

**Solution:** Mean SE is halved, assuming the same finite-variance model and appropriate independent observations.

### 24. One realization

**Problem:** Must a particular estimate improve when path count increases?

**Solution:** No. Sampling error is random, so observed absolute error need not decrease monotonically.

### 25. Sample variance

**Problem:** For [80,100,120], find the sample variance using N−1.

**Solution:** [(−20)²+0²+20²]/2=**400**; sample SD is 20.

### 26. Nominal normal interval

**Problem:** An estimated mean is 100.1 with SE=.2. Calculate the nominal 95% normal interval.

**Solution:** 100.1±1.96(.2)=**[99.708,100.492]**. This interval is an approximation under suitable assumptions.

### 27. Confidence interpretation

**Problem:** What does nominal 95% coverage mean in frequentist repeated sampling?

**Solution:** Under the method's assumptions, approximately 95% of such intervals across repeated samples cover the fixed model mean. The realized interval either covers it or does not.

### 28. Rare events

**Problem:** An event has model probability .001 and N=1,000 independent paths. What is the expected event count?

**Solution:** Np=**1**. Observing zero events does not prove the probability is zero.

### 29. Optional stopping

**Problem:** Can a fixed-N interval be checked repeatedly and stopped when narrow while retaining its stated coverage automatically?

**Solution:** No. Prespecify N or use a method designed for sequential stopping.

### 30. Model error

**Problem:** A Monte Carlo interval is narrow but the underlying parameters are wrong. What does the interval establish?

**Solution:** At most sampling precision for the specified model under its assumptions; it does not quantify the model error automatically.

## Part D — Paths, portfolios and risk

### 31. Time grid

**Problem:** Simulate one year using 12 equal steps. What is Δt?

**Solution:** **1/12 year**. The number of steps is distinct from the number of paths.

### 32. GBM log drift

**Problem:** For GBM with μ=.05 and σ=.20, find μ−σ²/2.

**Solution:** .05−.04/2=**.03** per year.

### 33. GBM benchmark

**Problem:** Under constant-parameter GBM, S₀=100, μ=.05, T=1. Find E[Sₜ].

**Solution:** 100e^.05≈**105.12711**, under the specified probability measure.

### 34. Barrier monitoring

**Problem:** Can a path observed only at month-end miss a barrier crossing between observations?

**Solution:** Yes. Exact GBM updates at grid times do not provide continuous monitoring.

### 35. Portfolio return

**Problem:** Weights .6 and .4, returns +10% and −5%.

**Solution:** .6(.10)+.4(−.05)=**.04**, or 4%.

### 36. Portfolio variance

**Problem:** Weights .6/.4, standard deviations .2/.1 and correlation .25.

**Solution:** Covariance=.25(.2)(.1)=.005; variance=.6²(.2²)+.4²(.1²)+2(.6)(.4)(.005)=**.0184**.

### 37. Rebalancing

**Problem:** Do weights remain fixed automatically in a buy-and-hold portfolio?

**Solution:** No. They drift as asset values change. Resetting weights requires an explicit rebalancing rule and cost assumptions.

### 38. Loss sign

**Problem:** Initial value 100, terminal value 80. Define loss as initial minus terminal.

**Solution:** Loss is **20**. Terminal value 110 would produce loss −10, a gain.

### 39. Empirical VaR

**Problem:** Sorted equally weighted losses [−10,0,20,40], α=.75. Use nearest rank ceil(αN).

**Solution:** Rank=ceil(3)=3; **VaR=20**.

### 40. Empirical Expected Shortfall

**Problem:** Using the same sample and α=.75, average the upper 25% of empirical quantile mass.

**Solution:** One observation-equivalent lies in the tail, so **ES=40**.

### 41. Fractional tail

**Problem:** Same losses, α=.625. Calculate empirical ES with fractional boundary weight.

**Solution:** Upper tail contains 1.5 observation-equivalents: (40+.5×20)/1.5=**100/3≈33.3333**.

### 42. Discrete VaR boundary

**Problem:** Same four-point distribution at α=.80. Find VaR and P(L>VaR).

**Solution:** VaR=40 and P(L>40)=0. Discrete mass means the strict exceedance probability need not equal 1−α.

## Part E — Performance and applied cases

### 43. Memory estimate

**Problem:** Store 100,000 paths with 253 binary64 values each. Calculate element storage.

**Solution:** 100,000×253×8=202,400,000 bytes, about **193.0 MiB**, excluding overhead and temporary arrays.

### 44. Batching

**Problem:** Process 100,001 paths in batches of 10,000.

**Solution:** Ten full batches and one final batch of one path. Batch size and draw order can affect reproducibility.

### 45. Streaming statistics

**Problem:** Does a running mean and variance retain enough information to calculate exact empirical VaR?

**Solution:** No. The distribution's ordering is not determined by its first two moments.

### 46. Paired comparisons

**Problem:** Two scenarios share random draws intentionally. How should uncertainty of their difference be calculated?

**Solution:** Use independent paired differences and their variability, subject to the sampling design. Pairing does not guarantee variance reduction.

### 47. Deterministic stress

**Problem:** A 60/40 portfolio experiences asset returns −20% and −10%. Find portfolio return.

**Solution:** .6(−.2)+.4(−.1)=**−.16**. For initial value 100, loss is 16 before costs.

### 48. Currency scenario

**Problem:** EUR 100 at 1.10 USD/EUR moves to 1.05 USD/EUR with no change in EUR value.

**Solution:** USD value moves from 110 to 105, a **−5 USD P&L**. Quote direction is essential.

### 49. Rare-event plug-in error

**Problem:** No losses occur in 100 paths. Does a plug-in SE of zero imply no uncertainty?

**Solution:** No. A suitable binomial interval recognizes uncertainty at the boundary; model and sampling assumptions remain important.

### 50. Review decision

**Problem:** A result is reproducible and its sampling interval is narrow, but input volatility and dependence have not been reviewed. Is the model validated?

**Solution:** No. Reproducibility and sampling precision do not establish appropriate inputs, dependence or model suitability.

## Reference snippet — three-state simulation

~~~python
import random
import statistics
import math

rng = random.Random(42)
values = []
for _ in range(10_000):
    u = rng.random()
    values.append(80 if u < .25 else (100 if u < .75 else 120))
mean = statistics.mean(values)
se = statistics.stdev(values)/math.sqrt(len(values))
print("mean:", mean, "estimated SE:", se)
~~~

The snippet assumes independent draws and a finite-variance model. Its inclusion is not evidence that it was executed or independently validated.
