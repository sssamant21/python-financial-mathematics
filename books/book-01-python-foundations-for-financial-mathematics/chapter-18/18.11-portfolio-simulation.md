## Learning objectives

Simulate a portfolio from joint asset returns; calculate weighted return, terminal value and loss frequency; explain covariance and correlation; compare simulation with analytical moments; distinguish rebalanced and buy-and-hold positions; and document modeling and sampling limitations.

## 1. Define the portfolio

A portfolio simulation begins with positions, weights, horizon, currency and a joint model for asset returns. For a one-period fully invested portfolio with weights wᵢ summing to one and simple returns Rᵢ:

**Rₚ=ΣwᵢRᵢ**, and **V₁=V₀(1+Rₚ)**.

This relationship applies to beginning-of-period weights with no intermediate cash flows, rebalancing, fees or taxes. Record any departures explicitly.

For weights .6 and .4, and asset returns +10% and −5%, portfolio return is .6(.10)+.4(−.05)=**.04**, or 4%. With initial value 100, terminal value is 104 and profit is 4.

## 2. Expected return and covariance

For weights w and mean vector μ, E[Rₚ]=wᵀμ. Portfolio variance is **wᵀΣw**, where Σ is the covariance matrix. Correlation determines covariance through Cov(R₁,R₂)=ρσ₁σ₂.

For two assets with weights .6 and .4, means .08 and .04, standard deviations .20 and .10, and correlation .25:

- Mean: .6(.08)+.4(.04)=**.064**.
- Covariance: .25(.20)(.10)=**.005**.
- Variance: .6²(.20²)+.4²(.10²)+2(.6)(.4)(.005)=**.0184**.
- Volatility: √.0184≈**.13565**.

These are one-period parameters in consistent units. They are model inputs, not estimates of future market behavior.

## 3. Joint draws

To construct two correlated standard normal variables from independent Z₁,Z₂~N(0,1), set:

**Y₁=Z₁**, **Y₂=ρZ₁+√(1−ρ²)Z₂**, for −1≤ρ≤1.

Then R₁=μ₁+σ₁Y₁ and R₂=μ₂+σ₂Y₂ have the stated normal marginal means, standard deviations and model correlation. Finite-sample statistics fluctuate. At ρ=±1 the covariance matrix is singular; the formula still works with the second coefficient zero.

For more assets, use a valid positive-semidefinite covariance matrix and a suitable factorization. Ordinary Cholesky decomposition requires positive definiteness; singular positive-semidefinite matrices require an appropriate alternative.

## 4. Important limitation: normal simple returns

A normal simple-return model is unbounded below and can produce R<−1. That can imply a negative asset value for a fully funded limited-liability asset. This section's implementation **retains such draws and counts them**, so the resulting negative values are a mathematical consequence of the illustrative model, not economically valid limited-liability prices.

Do not silently clip or reject such draws: either changes the distribution. Choose and validate a suitable model, such as a carefully specified joint log-return model, when price positivity is needed. The mean and variance benchmarks below are for the unmodified normal simple-return model.

## 5. One-period P&L and risk

Given initial value V₀, profit and loss is V₀Rₚ under the stated assumptions. A strictly negative portfolio return is a loss before costs. Define whether zero is included when estimating a loss probability.

Under the normal portfolio model with mean .064 and SD √.0184, P(Rₚ<0)=Φ(−.064/√.0184)≈**.3185**. A simulation estimates this probability under the model; it is not a prediction or a confidence interval for actual market losses.

## 6. Analytical checks

For V₀=100, the analytical expected terminal value is **106.4**, and terminal standard deviation is **100√.0184≈13.565**. For 10,000 independent simulated portfolios, the theoretical SE of the estimated mean terminal value is approximately **.13565**.

Compare the sample mean and sample volatility with these benchmarks, allowing sampling variation. A finite sample's observed correlation need not equal .25 exactly. Matching moments does not prove that tail behavior or the financial model is appropriate.

## 7. Diversification and correlation

For fixed positive weights and volatilities, lowering correlation reduces the covariance contribution to portfolio variance. It does not guarantee a gain, eliminate systematic risk or ensure that correlations remain stable during stress.

With the example's parameters and ρ=0, variance is .0144+.0016=**.016**. With ρ=.25, it is .0184. Changing correlation changes the joint model and potentially tail outcomes.

## 8. Multi-period choices

A buy-and-hold portfolio lets asset weights drift as prices change. A periodically rebalanced portfolio resets weights according to an explicit schedule and incurs any modeled costs. Applying fixed weights independently each period corresponds to rebalancing at those periods under the specified assumptions, not buy-and-hold.

State cash flows, rebalancing times, fees, leverage, short positions, funding and currency conventions. This section's code is strictly one-period and long-only.

## 9. Sampling and reproducibility

Use a local generator, record seed, generator, software versions, sample count, model parameters and units. For independent simulated portfolios, estimate the standard error of a sample mean as s/√N. The loss frequency is an event-probability estimate; its uncertainty requires an appropriate binomial method, particularly for rare events.

Independent paths do not remove uncertainty in μ, σ or ρ, and a fixed seed does not validate the model. Parallel streams require documented spawning and assignment to avoid duplicated paths.

## 10. Scenario and stress checks

Complement random simulations with deterministic joint shocks. For example, asset returns −20% and −10% give portfolio return .6(−.2)+.4(−.1)=**−.16**, or −16. A stress is conditional and need not have an assigned probability.

Sensitivity to correlations, volatility, costs and extreme joint moves can reveal model dependence. A normal distribution may understate or misrepresent tails, jumps and changing correlations.

## 11. Reference implementation

Save as `portfolio_simulation.py`. It simulates independent one-period pairs using the normal simple-return model and reports how many paths contain an asset return below −100%. It does not clip or discard those paths.

~~~python
import math
import random
import statistics
import unittest

def finite(x):
    return type(x) in (int,float) and math.isfinite(x)

def simulate(count, seed, mu1, mu2, sd1, sd2, rho, w1, w2):
    params=(mu1,mu2,sd1,sd2,rho,w1,w2)
    if not all(finite(x) for x in params):
        raise ValueError("finite model parameters required")
    if type(count) is not int or count < 2 or type(seed) is not int:
        raise ValueError("count >= 2 and integer seed required")
    if sd1 < 0 or sd2 < 0 or not -1 <= rho <= 1:
        raise ValueError("nonnegative SDs and correlation in [-1,1] required")
    if w1 < 0 or w2 < 0 or not math.isclose(w1+w2,1,rel_tol=0,abs_tol=1e-12):
        raise ValueError("nonnegative weights summing to one required")
    rng=random.Random(seed)
    residual_scale=math.sqrt(max(0.0,1-rho*rho))
    rows=[]
    for _ in range(count):
        z1,z2=rng.normalvariate(0,1),rng.normalvariate(0,1)
        r1=mu1+sd1*z1
        r2=mu2+sd2*(rho*z1+residual_scale*z2)
        rp=w1*r1+w2*r2
        if not all(math.isfinite(x) for x in (r1,r2,rp)):
            raise ValueError("nonfinite simulated return")
        rows.append((r1,r2,rp))
    return rows

def summarize(rows, initial):
    rows=list(rows)
    if not finite(initial) or initial <= 0 or len(rows)<2:
        raise ValueError("positive finite initial value and at least two rows required")
    if any(len(row)!=3 or not all(finite(x) for x in row) for row in rows):
        raise ValueError("finite triples required")
    returns=[row[2] for row in rows]
    values=[initial*(1+r) for r in returns]
    if not all(math.isfinite(x) for x in values):
        raise ValueError("nonfinite terminal value")
    return {
        "count":len(rows),
        "mean_return":statistics.mean(returns),
        "return_sd":statistics.stdev(returns),
        "mean_terminal":statistics.mean(values),
        "standard_error_terminal":statistics.stdev(values)/math.sqrt(len(values)),
        "loss_frequency":sum(r<0 for r in returns)/len(rows),
        "paths_with_asset_return_below_minus_one":sum(r1 < -1 or r2 < -1
                                                       for r1,r2,_ in rows),
    }

def analytical(mu1,mu2,sd1,sd2,rho,w1,w2):
    params=(mu1,mu2,sd1,sd2,rho,w1,w2)
    if not all(finite(x) for x in params) or sd1<0 or sd2<0 or not -1<=rho<=1:
        raise ValueError("invalid parameters")
    if w1<0 or w2<0 or not math.isclose(w1+w2,1,rel_tol=0,abs_tol=1e-12):
        raise ValueError("invalid weights")
    mean=w1*mu1+w2*mu2
    variance=(w1*sd1)**2+(w2*sd2)**2+2*w1*w2*rho*sd1*sd2
    return mean,variance

class PortfolioTests(unittest.TestCase):
    def test_analytical_mean(self):
        self.assertAlmostEqual(analytical(.08,.04,.2,.1,.25,.6,.4)[0],.064)
    def test_analytical_variance(self):
        self.assertAlmostEqual(analytical(.08,.04,.2,.1,.25,.6,.4)[1],.0184)
    def test_replay(self):
        args=(10,42,.08,.04,.2,.1,.25,.6,.4)
        self.assertEqual(simulate(*args),simulate(*args))
    def test_zero_volatility(self):
        rows=simulate(10,42,.08,.04,0,0,.25,.6,.4)
        self.assertTrue(all(math.isclose(rp,.064) for _,_,rp in rows))
    def test_summary(self):
        result=summarize([(.1,-.05,.04),(0,0,0)],100)
        self.assertAlmostEqual(result["mean_terminal"],102)
        self.assertEqual(result["loss_frequency"],0)
    def test_invalid_return_count(self):
        result=summarize([(-1.1,0,-.66),(0,0,0)],100)
        self.assertEqual(result["paths_with_asset_return_below_minus_one"],1)
    def test_invalid_correlation(self):
        with self.assertRaises(ValueError): simulate(10,1,0,0,.2,.1,1.1,.6,.4)
    def test_invalid_weights(self):
        with self.assertRaises(ValueError): simulate(10,1,0,0,.2,.1,0,.6,.5)
    def test_invalid_sd(self):
        with self.assertRaises(ValueError): analytical(0,0,-.2,.1,0,.6,.4)
    def test_invalid_initial(self):
        with self.assertRaises(ValueError): summarize([(0,0,0),(0,0,0)],0)
    def test_singular_correlation(self):
        rows=simulate(3,1,0,0,1,1,1,.6,.4)
        self.assertTrue(all(math.isclose(a,b) for a,b,_ in rows))
    def test_count(self):
        with self.assertRaises(ValueError): simulate(1,1,0,0,.2,.1,0,.6,.4)

if __name__ == "__main__":
    args=(.08,.04,.2,.1,.25,.6,.4)
    rows=simulate(10000,42,*args)
    print("simulation:",summarize(rows,100))
    print("analytical mean and variance:",analytical(*args))
    unittest.main(verbosity=2)
~~~

The reported standard error assumes independent portfolio observations and finite variance. The count of returns below −1 diagnoses a model limitation; a zero count in a finite run does not prove the normal model cannot generate them.

## 14. Troubleshooting

| Symptom | Possible cause | Next step |
|---|---|---|
| Simulated moments differ from formulas | Sampling variation or incorrect covariance | Check SE, parameters and joint construction |
| Negative asset value | Normal simple return below −1 | Review and change the model if positivity is required |
| Weights drift across periods | Buy-and-hold behavior | Define rebalancing and costs |
| Low risk despite large stresses | Incorrect dependence or missing exposures | Review joint scenarios and positions |
| Repeated identical paths across workers | Duplicate generator state | Inspect stream spawning |
| Stable estimate but unrealistic losses | Model or parameter error | Review tails, calibration and independent stresses |
