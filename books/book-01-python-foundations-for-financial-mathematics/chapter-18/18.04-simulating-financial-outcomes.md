## Learning objectives

Translate a financial question into a simulation; distinguish outcomes, returns, payoffs and profits; construct a discrete probability model; estimate an expected value and loss probability; calculate sampling uncertainty; and validate results against an analytical benchmark.

## 1. Start with the question

A simulation models possible outcomes under explicit assumptions. Begin by specifying the position, initial cost, time horizon, units, possible future states and target quantity. Possible targets include terminal value, profit, loss probability and discounted payoff.

A simulated distribution is conditional on the model. It is not a guaranteed prediction, and a large sample cannot correct an inappropriate distribution or missing costs.

## 2. A three-state investment model

An investment costs 100 today. After one year, the model assigns these terminal values:

| State | Probability | Terminal value | Profit |
|---|---:|---:|---:|
| Down | 0.25 | 80 | −20 |
| Flat | 0.50 | 100 | 0 |
| Up | 0.25 | 120 | 20 |

The probabilities sum to one. The exact expected value is **.25×80 + .50×100 + .25×120 = 100**. Expected profit is **0**, before costs, taxes and discounting.

The probability of a strictly negative profit is **.25**. If the question instead asks for profit less than or equal to zero, its probability is **.75**. Define the threshold and inequality before reporting a probability.

## 3. Outcomes and returns

A simple return is R=(V₁−V₀)/V₀ when V₀>0. The three outcomes correspond to −20%, 0% and +20%. For this model, expected simple return is zero. Profit equals V₁−V₀; terminal value includes the original investment.

If V₀=0, the simple-return formula is undefined. Costs may change both profit and loss probability. A model's state values need not represent every possible real-world outcome.

## 4. Sampling the states

Generate U uniformly on [0,1). Map U<.25 to down, .25≤U<.75 to flat, and U≥.75 to up. These intervals have lengths .25, .50 and .25.

If five paths produce [80,100,120,100,80], their mean is 96 and observed loss frequency is 2/5=.4. These sample results differ from the exact model expectation and loss probability because the sample is small.

## 5. Expected value and sampling error

For independent draws X₁,…,Xₙ, estimate expected terminal value with **X̄=ΣXᵢ/N**. The three-state model's variance is:

**.25(80−100)²+.50(100−100)²+.25(120−100)² = 200.**

Its standard deviation is √200≈14.1421. For 10,000 independent draws, the theoretical standard error of the sample mean is **√200/√10000≈0.14142**.

A sample standard deviation divided by √N estimates standard error under the independent finite-variance assumptions. Four times as many independent draws approximately halves standard error. Estimates need not improve monotonically with each larger sample.

## 6. Estimating loss probability

Use an indicator Iᵢ=1 if Vᵢ<100 and 0 otherwise. Its sample mean estimates the probability of a loss. Under independent Bernoulli draws with probability p, the model standard error is **√[p(1−p)/N]**. For p=.25 and N=10,000 this is approximately **.00433** (0.433 percentage points).

A plug-in estimate replaces p with the observed frequency, but can misleadingly give zero at observed frequencies 0 or 1. For rare events, use a suitable interval method and enough observations rather than relying only on a normal approximation.

## 7. Discounted outcomes

At an annual effective discount rate r>−1, a one-year payoff V has present value V/(1+r). For the three-state example at 5%, the expected discounted payoff is 100/1.05≈**95.2381**, under the stated probabilities and constant discount rate.

This is an arithmetic result under those inputs; it is not automatically a market-consistent valuation. Real-world probabilities, risk-neutral probabilities, discounting, and risk premia must be selected consistently for the intended purpose.

## 8. Fees and thresholds

A fixed fee of 2 paid at the end of the year reduces terminal net value by 2 in every state: [78,98,118]. Expected net terminal value becomes 98. Relative to the original 100 cost, the down and flat states now produce a loss, so loss probability is .75.

If a fee is charged at time zero or depends on the outcome, adjust timing and formulas accordingly. Avoid subtracting the same fee twice.

## 9. Scenario analysis and simulation

A scenario such as “terminal value 80” is a specified outcome. Monte Carlo simulation samples scenarios according to a model. Scenario stress can be useful without assigning a probability; simulated frequencies require justified probability assumptions.

Sensitivity analysis changes inputs such as probabilities, fees or loss thresholds and compares outputs. Use common random numbers for paired comparisons only intentionally, and calculate uncertainty from paired differences.

## 10. Reproducibility and validation

Record the model, probabilities, costs, horizon, seed, generator, sample count, software versions and units. Use a local generator to avoid hidden shared state. Compare simulated means and frequencies with the exact benchmarks above, allowing for sampling variation.

A seed supports replay in a compatible environment; it does not validate assumptions or guarantee equality across all implementations. Check input domains, missing values and finite outputs. Never interpret one seed as proof that an estimator is accurate.

## 11. Reference implementation

Save as `financial_outcomes.py`. This standard-library implementation draws independent states from the stated three-state model. It is educational, holds probabilities fixed, and is not a production valuation or risk engine.

~~~python
import math
import random
import statistics
import unittest

def simulate(count, seed, fee=0.0):
    if type(count) is not int or count < 2 or type(seed) is not int:
        raise ValueError("count >= 2 and integer seed required")
    if type(fee) not in (int,float) or not math.isfinite(fee) or fee < 0:
        raise ValueError("finite nonnegative fee required")
    rng = random.Random(seed)
    outcomes = []
    for _ in range(count):
        u = rng.random()
        value = 80.0 if u < .25 else (100.0 if u < .75 else 120.0)
        net = value - fee
        if not math.isfinite(net):
            raise ValueError("nonfinite net outcome")
        outcomes.append(net)
    return outcomes

def summarize(values, initial):
    values = list(values)
    if len(values) < 2:
        raise ValueError("at least two values required")
    if type(initial) not in (int,float) or not math.isfinite(initial):
        raise ValueError("finite initial value required")
    if any(type(v) not in (int,float) or not math.isfinite(v) for v in values):
        raise ValueError("finite numeric values required")
    mean = statistics.mean(values)
    losses = sum(value < initial for value in values)
    return {
        "count": len(values),
        "mean_terminal": mean,
        "mean_profit": mean - initial,
        "standard_error_mean": statistics.stdev(values)/math.sqrt(len(values)),
        "loss_count": losses,
        "loss_frequency": losses/len(values),
    }

def discount(value, rate):
    if any(type(x) not in (int,float) or not math.isfinite(x)
           for x in (value,rate)) or rate <= -1:
        raise ValueError("finite value and rate greater than -1 required")
    result = value/(1+rate)
    if not math.isfinite(result):
        raise ValueError("nonfinite discounted value")
    return result

class OutcomeTests(unittest.TestCase):
    def test_replay(self):
        self.assertEqual(simulate(20,42),simulate(20,42))
    def test_values_in_model(self):
        self.assertTrue(all(x in (80,100,120) for x in simulate(100,1)))
    def test_fee(self):
        base = simulate(20,7)
        net = simulate(20,7,2)
        self.assertEqual(net,[x-2 for x in base])
    def test_known_summary(self):
        result = summarize([80,100,120,100,80],100)
        self.assertEqual(result["mean_terminal"],96)
        self.assertEqual(result["mean_profit"],-4)
        self.assertEqual(result["loss_frequency"],.4)
    def test_strict_threshold(self):
        self.assertEqual(summarize([100,100],100)["loss_frequency"],0)
    def test_constant_sample(self):
        self.assertEqual(summarize([100,100],100)["standard_error_mean"],0)
    def test_discount(self):
        self.assertAlmostEqual(discount(100,.05),100/1.05)
    def test_bad_rate(self):
        with self.assertRaises(ValueError): discount(100,-1)
    def test_bad_count(self):
        with self.assertRaises(ValueError): simulate(1,42)
    def test_bad_fee(self):
        with self.assertRaises(ValueError): simulate(10,42,-1)

if __name__ == "__main__":
    result = summarize(simulate(10000,42),100)
    print(result)
    unittest.main(verbosity=2)
~~~

## 14. Troubleshooting

| Symptom | Possible cause | Next step |
|---|---|---|
| Probabilities do not sum to one | Input or model error | Correct and document the state model |
| Simulated mean differs from 100 | Sampling variation or mapping defect | Compare uncertainty and inspect interval mapping |
| Loss frequency differs from expectation | Threshold or fee differs | Verify strict inequality and timing |
| Identical repeated runs unexpectedly | Reused seed or duplicated worker streams | Inspect generator initialization |
| Small sampling error but implausible outcome | Incorrect assumptions | Review model and independent benchmarks |
| Discounted value treated as market price | Measure or risk premium not specified | Clarify valuation purpose and assumptions |
