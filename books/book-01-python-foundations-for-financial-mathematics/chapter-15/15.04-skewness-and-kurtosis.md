## 1. Why distribution shape matters

Two investments may have identical arithmetic means and standard deviations but different exposure to rare losses. **Skewness** describes standardized asymmetry. **Kurtosis** measures the standardized fourth central moment and is sensitive to extreme observations. Neither statistic alone determines a full probability distribution, a future loss probability, or a reliable tail-risk forecast.

Real financial returns may exhibit negative skewness, heavy-tailed behavior, volatility clustering, nonstationarity, and regime shifts. A short sample is especially unreliable for estimating higher moments.

## 2. Central moments

For n observed returns xᵢ with arithmetic mean x̄, define the empirical k-th central moment:

**mₖ = (1/n)Σ(xᵢ−x̄)ᵏ.**

The second central moment m₂ is the population-denominator empirical variance. The third central moment m₃ is signed and measures cubic asymmetry. The fourth central moment m₄ weights large deviations heavily.

For nonconstant observations, standardized moments divide by powers of m₂ so the results are dimensionless.

## 3. Skewness

The unadjusted empirical standardized skewness is:

**g₁ = m₃ / m₂^(3/2).**

- **g₁ > 0:** right-side deviations dominate the third central moment.
- **g₁ < 0:** left-side deviations dominate.
- **g₁ = 0:** zero third standardized moment, which does not by itself prove full distributional symmetry.

For the simple sample **[−1,0,1]**, mean=0, m₂=2/3, m₃=0, so g₁=0.

For **[0,0,0,4]**, mean=1; deviations are [−1,−1,−1,3]. Then m₂=3 and m₃=6, so

**g₁ = 6 / 3^(3/2) ≈ 1.15470**.

The reflected sample **[−4,0,0,0]** has skewness approximately −1.15470.

### Adjusted sample skewness

One widely used finite-sample correction, defined for n≥3, is:

**G₁ = [√(n(n−1))/(n−2)] g₁.**

This correction depends on sampling assumptions and should not be interpreted as a guarantee of unbiased risk estimation under arbitrary financial dependence.

## 4. Kurtosis and excess kurtosis

The unadjusted empirical kurtosis is:

**b₂ = m₄ / m₂²**.

The corresponding excess kurtosis is:

**g₂ = b₂ − 3**.

The theoretical normal distribution has kurtosis 3 and excess kurtosis 0. This does **not** imply every small sample from a normal distribution has excess kurtosis exactly zero.

For **[−1,0,1]**:

**m₂ = 2/3**, **m₄ = 2/3**.

**b₂ = (2/3)/(4/9)=1.5**.

**g₂ = 1.5−3=−1.5**.

Kurtosis is often associated with tail heaviness, but a single fourth-moment statistic also reflects the distribution's central mass and shoulders. It does not uniquely determine tail probabilities.

### Adjusted sample excess kurtosis

For n≥4, a common corrected estimator is:

**G₂ = [(n−1)/((n−2)(n−3))] × [(n+1)g₂+6]**.

The exact estimator and bias convention must be stated when comparing statistical packages.

## 5. Financial interpretation

| Shape characteristic | Potential financial implication | Limitation |
|---|---|---|
| Negative skewness | Larger or more influential left-side deviations | Does not quantify a specific loss probability |
| Positive skewness | Larger or more influential right-side deviations | Does not eliminate downside risk |
| High excess kurtosis | Fourth moment strongly affected by extreme observations | Not a substitute for expected shortfall |
| Near-zero skewness | Weak empirical third-moment asymmetry | Distribution can still be asymmetric |
| Near-zero excess kurtosis | Fourth moment near normal benchmark | Distribution need not be normal |

When evaluating risk, supplement higher moments with quantiles, drawdowns, scenario analysis, and transparent data-quality checks.

## 6. Transformation properties

For transformed observations yᵢ=axᵢ+b, with a≠0:

- **Skewness(y) = sign(a) × skewness(x).**
- **Kurtosis(y) = kurtosis(x).**

Thus a positive rescaling or change of units leaves both standardized statistics unchanged, while multiplying returns by −1 reverses skewness and preserves kurtosis.

## 7. Sample-size and data-quality cautions

Higher moments amplify outliers because they involve third and fourth powers. A single erroneous split-adjustment return can dominate the result.

Always record the return horizon, number of observations, sample window, missing-data policy, outlier policy, and estimator convention. For constant observations, m₂=0 and standardized skewness/kurtosis are undefined. For very short samples, corrected estimators may be undefined or unstable.

Serial dependence, changing volatility, and structural breaks also limit classical iid-based interpretations.

## 8. Python reference implementation

Save the following as `skewness_kurtosis.py`. The implementation uses only Python's standard library and includes **12 reference unit tests**.

```python
import math
import unittest

def _sample(values):
    if not isinstance(values, (list, tuple)) or not values:
        raise ValueError("nonempty sequence required")
    if any(type(v) not in (int, float) or not math.isfinite(v) for v in values):
        raise ValueError("finite numeric observations required")
    return [float(v) for v in values]

def standardized_moments(values):
    xs = _sample(values)
    n = len(xs)
    mu = math.fsum(xs) / n
    d = [x - mu for x in xs]
    m2 = math.fsum(v*v for v in d) / n
    if m2 == 0:
        raise ValueError("standardized moments undefined for constant observations")
    m3 = math.fsum(v**3 for v in d) / n
    m4 = math.fsum(v**4 for v in d) / n
    return {"n": n, "mean": mu, "m2": m2,
            "skewness": m3 / m2**1.5,
            "kurtosis": m4 / (m2*m2),
            "excess_kurtosis": m4 / (m2*m2) - 3.0}

def adjusted_sample_skewness(values):
    xs = _sample(values)
    n = len(xs)
    if n < 3:
        raise ValueError("adjusted sample skewness requires n >= 3")
    g1 = standardized_moments(xs)["skewness"]
    return math.sqrt(n*(n-1)) / (n-2) * g1

def adjusted_sample_excess_kurtosis(values):
    xs = _sample(values)
    n = len(xs)
    if n < 4:
        raise ValueError("adjusted excess kurtosis requires n >= 4")
    g2 = standardized_moments(xs)["excess_kurtosis"]
    return ((n-1) / ((n-2)*(n-3))) * ((n+1)*g2 + 6)

def downside_frequency(values, threshold=0):
    xs = _sample(values)
    if type(threshold) not in (int, float) or not math.isfinite(threshold):
        raise ValueError("finite threshold required")
    return sum(x < threshold for x in xs)/len(xs)

class ShapeTests(unittest.TestCase):
    def test_01_symmetric_skew(self):
        self.assertAlmostEqual(standardized_moments([-1,0,1])["skewness"],0)
    def test_02_symmetric_kurtosis(self):
        self.assertAlmostEqual(standardized_moments([-1,0,1])["kurtosis"],1.5)
    def test_03_symmetric_excess(self):
        self.assertAlmostEqual(standardized_moments([-1,0,1])["excess_kurtosis"],-1.5)
    def test_04_positive_skew(self):
        self.assertGreater(standardized_moments([0,0,0,4])["skewness"],0)
    def test_05_negative_skew(self):
        self.assertLess(standardized_moments([-4,0,0,0])["skewness"],0)
    def test_06_translation(self):
        self.assertAlmostEqual(standardized_moments([1,2,5])["skewness"],
                               standardized_moments([11,12,15])["skewness"])
    def test_07_positive_scaling(self):
        self.assertAlmostEqual(standardized_moments([1,2,5])["kurtosis"],
                               standardized_moments([2,4,10])["kurtosis"])
    def test_08_negative_scaling(self):
        self.assertAlmostEqual(standardized_moments([1,2,5])["skewness"],
                               -standardized_moments([-1,-2,-5])["skewness"])
    def test_09_adjusted_skew(self):
        self.assertAlmostEqual(adjusted_sample_skewness([-1,0,1]),0)
    def test_10_adjusted_kurtosis(self):
        self.assertAlmostEqual(adjusted_sample_excess_kurtosis([-2,-1,1,2]),-1.2)
    def test_11_downside_frequency(self):
        self.assertAlmostEqual(downside_frequency([-.03,-.01,.01,.02]),.5)
    def test_12_validation(self):
        for f in (lambda:standardized_moments([]),
                  lambda:standardized_moments([1,1,1]),
                  lambda:standardized_moments([float("nan"),2]),
                  lambda:adjusted_sample_skewness([1,2]),
                  lambda:adjusted_sample_excess_kurtosis([1,2,3])):
            with self.assertRaises(ValueError): f()

if __name__ == "__main__":
    data = [-.04,-.01,0,.02,.08]
    print("Return distribution shape:", standardized_moments(data))
    unittest.main(verbosity=2)
```

## 10. Twenty-four worked exercises

1. **Symmetric skew:** Observations −1,0,1. **Worked solution:** Third central moment is zero; skewness=0.

2. **Symmetric kurtosis:** Observations −1,0,1. **Worked solution:** m2=2/3, m4=2/3; kurtosis=1.5.

3. **Excess kurtosis:** Same observations. **Worked solution:** 1.5−3=−1.5.

4. **Right skew:** 0,0,0,4. **Worked solution:** Positive third central moment, so positive skewness.

5. **Left skew:** −4,0,0,0. **Worked solution:** Negative third central moment, so negative skewness.

6. **Mean:** −1,0,1. **Worked solution:** 0.

7. **Second central moment:** −1,0,1. **Worked solution:** 2/3.

8. **Third central moment:** −1,0,1. **Worked solution:** 0.

9. **Fourth central moment:** −1,0,1. **Worked solution:** 2/3.

10. **Translation:** Add 10 to each observation. **Worked solution:** Skewness and kurtosis unchanged.

11. **Positive scaling:** Multiply observations by 2. **Worked solution:** Skewness and kurtosis unchanged.

12. **Negative scaling:** Multiply observations by −1. **Worked solution:** Skewness changes sign; kurtosis unchanged.

13. **Normal benchmark:** Normal-distribution population. **Worked solution:** Theoretical skewness=0, kurtosis=3, excess=0.

14. **Tail interpretation:** Positive excess kurtosis. **Worked solution:** Indicates high standardized fourth moment, not necessarily only more extreme tails at every threshold.

15. **Variance requirement:** Constant sample 2,2,2. **Worked solution:** Standardized moments undefined because m2=0.

16. **Small sample skew:** n=2. **Worked solution:** Adjusted sample skewness formula undefined.

17. **Small sample kurtosis:** n=3. **Worked solution:** Adjusted sample excess kurtosis formula undefined.

18. **Downside frequency:** −3%,−1%,1%,2%. **Worked solution:** Two of four negative: 50%.

19. **Outlier sensitivity:** One extreme negative return. **Worked solution:** Third and fourth powers can dominate the shape estimates.

20. **Skewness versus loss:** Positive sample skewness. **Worked solution:** Does not guarantee absence of large losses.

21. **Kurtosis versus VaR:** Large sample kurtosis. **Worked solution:** Does not determine a unique VaR without a full distributional model.

22. **Window comparison:** Two return windows. **Worked solution:** Compare only after aligning frequency, adjustment policy, and estimation method.

23. **Bias adjustment:** n=4. **Worked solution:** Adjusted sample excess kurtosis is defined but may be highly unstable.

24. **Operational gate:** n=5 historical returns. **Worked solution:** Describe shape as exploratory; do not certify tail risk from five observations.

## 11. Troubleshooting and operational checks

| Symptom | Likely cause | Action |
|---|---|---|
| Kurtosis differs by exactly 3 | Excess versus ordinary kurtosis | Check convention |
| Two libraries disagree on skewness | Adjusted versus unadjusted estimator | Record correction formula |
| Infinite or undefined output | Zero variance or nonfinite data | Validate input |
| Extreme shape after price adjustment | Corporate-action data issue | Reconcile raw and adjusted prices |
| Results change dramatically after one return | Higher-moment sensitivity | Report sensitivity analysis |
| Normality claimed from zero skewness | Misinterpretation | Check full distribution and tests |
| Tail-risk model built from tiny sample | Sampling uncertainty | Collect adequate history and stress scenarios |
