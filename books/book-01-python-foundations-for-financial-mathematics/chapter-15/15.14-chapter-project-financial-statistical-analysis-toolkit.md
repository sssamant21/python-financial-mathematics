## Project overview

Build a reproducible **Financial Statistical Analysis Toolkit** for a fictional asset and market benchmark. The project integrates the chapter's descriptive statistics, covariance and correlation, sampling uncertainty, linear regression, financial return measurement, rolling analytics, and data-quality safeguards.

The objective is **auditable analysis**, not automated trading or investment advice. A mathematically correct calculation is not sufficient if timestamps, corporate actions, or the sampling universe are invalid.

## Learning outcomes

After completing the project, a learner should be able to:

1. Ingest and validate chronological asset and benchmark price series.
2. Calculate simple returns, arithmetic means, sample volatility, and compounded performance.
3. Estimate sample covariance, Pearson correlation, and a simple market-model regression.
4. Construct a normal-approximation confidence interval while documenting when it is unreliable.
5. Calculate rolling means and empirical tail-loss metrics with explicit conventions.
6. Design checks for missingness, data leakage, survivorship, and overlapping observations.
7. Produce a reproducible report and a structured acceptance-evidence package.
8. Distinguish **reference tests included** from **runtime validation actually performed**.

## 1. Problem statement

An investment research team receives two aligned, hypothetical end-of-day price series: one for an asset and one for a benchmark. It needs a compact, transparent statistical summary before approving a larger research study.

The toolkit must answer:

- What is the asset's observed mean simple return and sample volatility?
- What was its realized compounded return?
- How closely did its returns move with the benchmark?
- What intercept and slope result from a simple OLS market regression?
- How did the trailing mean change over the observation window?
- What are the selected empirical VaR and expected-shortfall estimates?
- What are the major statistical and data-engineering limitations?

## 4. Input contract

The CSV schema is:

```csv

2026-01-05,100,100
2026-01-06,101,102
2026-01-07,103,104
2026-01-08,102,103
2026-01-09,105,106
```

Input rules:

- `date` must be a unique, ascending ISO-formatted date string.
- `asset_price` and `benchmark_price` must be finite, strictly positive numeric values.
- Prices must represent aligned observation times and a consistent adjustment convention.
- At least four price observations are required to estimate regression on at least three returns.
- The source universe, currency, calendar, and corporate-action policy must be documented.

**Scope:** The loader validates exact schema/row shape and parses canonical YYYY-MM-DD calendar dates, rejecting impossible, duplicate or descending dates. A common CSV row declares positional date alignment; it does not verify actual venue time zones, session cutoffs, source availability or corporate actions. Those require external provenance and as-of alignment.

## 5. Statistical design

### Returns

For prices Pₜ>0, compute:

**Rₜ=Pₜ/Pₜ₋₁−1**.

### Sample statistics

**Mean:** R̄=(1/n)ΣRᵢ.

**Sample SD:** s=√[(1/(n−1))Σ(Rᵢ−R̄)²].

**Sample covariance:** cov(x,y)=Σ(xᵢ−x̄)(yᵢ−ȳ)/(n−1).

**Pearson correlation:** r=cov(x,y)/(sₓsᵧ), provided both standard deviations are nonzero.

### OLS market model

**R_asset,t=α+βR_benchmark,t+εₜ**.

**β̂=cov(x,y)/var(x)**, and **α̂=ȳ−β̂x̄**.

This is a descriptive market model. The intercept is not proof of alpha generation or causal performance.

### Approximate confidence interval

**R̄ ± z₀.₉₇₅ s/√n** for a nominal 95% normal approximation.

The reference toolkit labels this result `normal_ci_approx`. It is **not** an exact small-sample t interval, and financial dependence or heavy tails may invalidate its coverage.

### Tail-loss conventions

For sorted returns r₍₁₎≤⋯≤r₍ₙ₎, use k=max(1,ceil(αn)):

**Historical VaR=−r₍ₖ₎**.

**Discrete historical ES=−(1/k)Σᵢ₌₁ᵏ r₍ᵢ₎**.

This nearest-rank convention is explicit but not unique. For short series, tail estimates are extremely unstable. The signed VaR threshold can be negative if all returns are positive.

## 6. Reference Python implementation

Save the following as `financial_statistics_toolkit.py`. It includes reusable calculations, a CSV loader, a report function, and **12 reference unit tests**.

```python
import csv
import math
import unittest
from dataclasses import dataclass
from pathlib import Path
from datetime import date
from decimal import Decimal, InvalidOperation, localcontext
from fractions import Fraction

def finite_number(x):
    if type(x) not in (int,float):
        return False
    try:
        return math.isfinite(x)
    except OverflowError:
        return False

def exact(x):
    return Fraction(x) if type(x) is int else Fraction(str(x))

def as_float(x):
    try:
        value=float(x)
    except (OverflowError,ValueError) as exc:
        raise ValueError("result outside float range") from exc
    if not math.isfinite(value) or (x and value==0):
        raise ValueError("result outside float range")
    return value

def decimal(x):
    return Decimal(x.numerator)/Decimal(x.denominator)

def root(x):
    with localcontext() as ctx:
        ctx.prec=80
        return as_float(decimal(x).sqrt())

def validate(xs, minimum=1):
    if type(minimum) is not int or minimum<1:
        raise ValueError("positive integer minimum required")
    if not isinstance(xs,(list,tuple)) or len(xs)<minimum:
        raise ValueError("insufficient observations")
    if any(not finite_number(v) for v in xs):
        raise ValueError("all values must be finite numbers")
    return list(xs)

def mean(xs):
    a=list(map(exact,validate(xs)))
    return as_float(sum(a)/len(a))

def exact_variance(xs):
    a=list(map(exact,validate(xs,2)));m=sum(a)/len(a)
    return sum((v-m)**2 for v in a)/(len(a)-1)

def sample_sd(xs):
    return root(exact_variance(xs))

def paired_moments(xs,ys):
    a,b=validate(xs,2),validate(ys,2)
    if len(a)!=len(b):
        raise ValueError("equal-length positional series required")
    a=list(map(exact,a));b=list(map(exact,b));n=len(a)
    ma=sum(a)/n;mb=sum(b)/n
    dx=[v-ma for v in a];dy=[v-mb for v in b]
    return (sum(v*v for v in dx)/(n-1),sum(x*y for x,y in zip(dx,dy))/(n-1),sum(v*v for v in dy)/(n-1))

def sample_covariance(xs,ys):
    return as_float(paired_moments(xs,ys)[1])

def pearson(xs,ys):
    vx,cov,vy=paired_moments(xs,ys)
    if vx==0 or vy==0:
        raise ValueError("correlation undefined for constant series")
    return root(cov*cov/(vx*vy))*(1 if cov>=0 else -1)

def simple_returns(prices):
    p=validate(prices,2)
    if any(v<=0 for v in p):
        raise ValueError("prices must be positive")
    out=[]
    for i in range(1,len(p)):
        value=as_float(exact(p[i])/exact(p[i-1])-1)
        if value==-1:
            raise ValueError("positive price would falsely round to total loss")
        out.append(value)
    return out

def compounded(returns):
    r=validate(returns)
    if any(v < -1 for v in r):
        raise ValueError("invalid simple return")
    if -1 in r:
        return -1.0
    gross=math.prod((1+exact(v) for v in r),start=Fraction(1))
    result=as_float(gross-1)
    if result==-1:
        raise ValueError("positive wealth would falsely round to total loss")
    return result

def rolling_mean(xs,window):
    a=validate(xs)
    if type(window) is not int or not 1<=window<=len(a):
        raise ValueError("invalid window")
    return [mean(a[i-window:i]) for i in range(window,len(a)+1)]

def normal_mean_ci(xs,confidence=.95):
    a=validate(xs,2)
    if not finite_number(confidence) or not 0<confidence<1:
        raise ValueError("invalid confidence")
    from statistics import NormalDist
    tail=(1-exact(confidence))/2
    # Lower tail avoids rounding (1+confidence)/2 to exactly one.
    z=-NormalDist().inv_cdf(as_float(tail))
    if z<=0:
        raise ValueError("critical value outside reportable resolution")
    values=list(map(exact,a));m=sum(values)/len(values);var=exact_variance(a)
    with localcontext() as ctx:
        ctx.prec=80
        half=Decimal(str(z))*decimal(var/len(a)).sqrt()
        lo,hi=as_float(decimal(m)-half),as_float(decimal(m)+half)
    if var and not lo<hi:
        raise ValueError("positive CI width lost in float reporting")
    return lo,hi

def ols(xs,ys):
    a,b=validate(xs,3),validate(ys,3)
    if len(a)!=len(b):
        raise ValueError("equal-length positional series required")
    vx,cov,_=paired_moments(a,b)
    if vx==0:
        raise ValueError("constant predictor")
    a=list(map(exact,a));b=list(map(exact,b));n=len(a)
    beta=cov/vx;my=sum(b)/n;alpha=my-beta*sum(a)/n
    fitted=[alpha+beta*x for x in a]
    sse=sum((y-f)**2 for y,f in zip(b,fitted));sst=sum((y-my)**2 for y in b)
    r2=1-sse/sst if sst else Fraction(1)
    return {"alpha":as_float(alpha),"beta":as_float(beta),"r2":as_float(r2),"sse":as_float(sse)}

def historical_tail(returns,tail=.05):
    r=sorted(validate(returns))
    if not finite_number(tail) or not 0<tail<1:
        raise ValueError("invalid tail")
    k=max(1,math.ceil(exact(tail)*len(r)))
    return {"var":as_float(-exact(r[k-1])),"es":as_float(-sum(map(exact,r[:k]))/k),"tail_count":k}

def parse_price(text):
    try:
        value=Decimal(text)
    except (InvalidOperation,TypeError,ValueError) as exc:
        raise ValueError("invalid numeric price") from exc
    if not value.is_finite() or value<=0:
        raise ValueError("finite positive price required")
    # Preserve integral CSV prices, avoiding irreversible float coercion.
    result=int(value) if value==value.to_integral_value() else as_float(value)
    if not finite_number(result):
        raise ValueError("price outside supported numeric range")
    return result

def load_prices_csv(path):
    """Exact columns date,asset_price,benchmark_price; canonical ISO dates."""
    try:
        with Path(path).open(newline="",encoding="utf-8") as handle:
            reader=csv.DictReader(handle,strict=True)
            required={"date","asset_price","benchmark_price"}
            if reader.fieldnames is None or len(reader.fieldnames)!=3 or set(reader.fieldnames)!=required:
                raise ValueError("exactly date, asset_price, benchmark_price columns required")
            rows=list(reader)
    except csv.Error as exc:
        raise ValueError("malformed CSV") from exc
    if len(rows)<4:
        raise ValueError("at least four price dates required")
    if any(set(row)!=required or any(row[k] is None or row[k]=="" for k in required) for row in rows):
        raise ValueError("each CSV row requires exactly three nonempty fields")
    dates=[row["date"] for row in rows]
    try:
        parsed=[date.fromisoformat(v) for v in dates]
    except ValueError as exc:
        raise ValueError("valid ISO calendar dates required") from exc
    if any(v.isoformat()!=raw for v,raw in zip(parsed,dates)) or len(set(parsed))!=len(parsed) or parsed!=sorted(parsed):
        raise ValueError("dates must be canonical, unique and increasing YYYY-MM-DD")
    asset=[parse_price(row["asset_price"]) for row in rows]
    bench=[parse_price(row["benchmark_price"]) for row in rows]
    return dates,asset,bench

def report(asset_prices,benchmark_prices,window=2):
    asset=simple_returns(asset_prices)
    bench=simple_returns(benchmark_prices)
    if len(asset)!=len(bench):
        raise ValueError("aligned prices required")
    return {"observations":len(asset),
            "mean_return":mean(asset),
            "volatility":sample_sd(asset),
            "cumulative_return":compounded(asset),
            "correlation":pearson(asset,bench),
            "regression":ols(bench,asset),
            "normal_ci_approx":normal_mean_ci(asset),
            "historical_tail":historical_tail(asset),
            "rolling_mean":rolling_mean(asset,window)}

class ToolkitTests(unittest.TestCase):
    def test_01_mean(self): self.assertAlmostEqual(mean([1,2,3]),2)
    def test_02_sd(self): self.assertAlmostEqual(sample_sd([1,2,3]),1)
    def test_03_covariance(self): self.assertAlmostEqual(sample_covariance([1,2,3],[2,4,6]),2)
    def test_04_correlation(self): self.assertAlmostEqual(pearson([1,2,3],[2,4,6]),1)
    def test_05_returns(self): self.assertAlmostEqual(simple_returns([100,110])[0],.1)
    def test_06_compounding(self): self.assertAlmostEqual(compounded([.1,-.1]),-.01)
    def test_07_rolling(self): self.assertEqual(rolling_mean([1,2,3,4],2),[1.5,2.5,3.5])
    def test_08_ci_center(self):
        lo,hi=normal_mean_ci([1,2,3])
        self.assertAlmostEqual((lo+hi)/2,2)
    def test_09_ols(self):
        m=ols([1,2,3,4],[3,5,7,9])
        self.assertAlmostEqual(m["beta"],2)
        self.assertAlmostEqual(m["alpha"],1)
    def test_10_tail(self):
        self.assertAlmostEqual(historical_tail([-.1,-.05,.01,.02],.5)["es"],.075)
    def test_11_report(self):
        r=report([100,101,103,102,105],[100,102,104,103,106],2)
        self.assertEqual(r["observations"],4)
        self.assertEqual(len(r["rolling_mean"]),3)
    def test_12_invalid(self):
        for f in (lambda:sample_sd([1]),lambda:pearson([1,1,1],[1,2,3]),
                  lambda:ols([1,1,1],[2,3,4]),lambda:simple_returns([100,0]),
                  lambda:historical_tail([.1],0),lambda:rolling_mean([1,2],3),
                  lambda:report([100,101,102,103],[100,101],2)):
            with self.assertRaises(ValueError):f()

if __name__=="__main__":
    asset=[100,101,103,102,105]
    benchmark=[100,102,104,103,106]
    print(report(asset,benchmark))
    unittest.main(verbosity=2)
```

Numerical policy: preserve integer inputs; use rational intermediates with displayed-decimal float values, and 80-digit Decimal roots/endpoint arithmetic before reporting floats. Nonzero unreportable outputs, false −100% loss rounding and collapsed positive-width CIs raise `ValueError`. Constant-response OLS reports R²=1 by explicit perfect-fit convention even though the usual variance fraction is undefined. CSV integral prices retain integers; nonintegral prices become floats and must be representable. Numeric arrays validate positional pairing only. The combined report fails explicitly if required correlation/regression is undefined; it is not a partial-report API. These educational conventions do not imply performance or binary-float compatibility.

To use the CSV loader from another Python script:

```python

dates, asset, benchmark = load_prices_csv("prices.csv")
summary = report(asset, benchmark, window=2)
print(dates[0], dates[-1], summary)
```

## 10. Failure scenarios and remediation

| Failure | Likely cause | Remediation |
|---|---|---|
| Division by zero in returns | Zero price | Reject invalid input |
| Undefined correlation | Constant series | Raise explicit validation error |
| Undefined OLS slope | Zero predictor variance | Require variable benchmark |
| Unexpected high returns | Unadjusted split | Reconcile corporate actions |
| Regression sample mismatch | Different dates | Align observation timestamps |
| CI unrealistically narrow | iid approximation invalid | Dependence-aware inference |
| VaR/ES unstable | Very small tail sample | Expand history and stress test |
| Rolling values used too early | Look-ahead | Enforce signal availability and lag |
| Backtest deteriorates live | Overfit strategy or regime change | Holdout and prospective monitoring |
| CSV parsing failure | Missing fields or malformed numbers | Validate schema and fail explicitly |
