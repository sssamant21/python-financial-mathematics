## Learning objectives

This section introduces the descriptive-statistics workflow for financial data. Learners will distinguish populations from samples, choose meaningful summaries, calculate measures of location and dispersion, interpret return units, handle missing observations, and build a reproducible standard-library Python summary tool.

## 1. What descriptive statistics does

Descriptive statistics organizes and summarizes observed data without asserting that a particular model generated it. For financial returns, useful summaries include the number of valid observations, mean, median, extremes, range, variance, standard deviation, and the fraction of observations below zero.

A summary of historical returns is **not** a forecast. Descriptive statistics cannot establish causality, stationarity, or future loss probabilities.

## 2. Observation design and data quality

Before computing anything, define the unit of observation. A time series of daily returns for one stock is not equivalent to a cross-section of stock returns on one date.

| Field | Example | Review requirement |
|---|---|---|
| Instrument | Fictional ETF A | Stable identifier |
| Observation date | Trading date | Chronological, nonduplicate |
| Return | 0.02 | Decimal simple-return convention |
| Frequency | Daily | Consistent calendar |
| Currency | USD | Consistent denomination |
| Corporate actions | Adjusted prices | Consistent adjustment policy |
| Missing values | Missing, not zero | Explicit handling |

A return of 0.02 means **2%**, not 0.02%. A missing observation must not silently be treated as a zero return. Handle duplicate timestamps, stale prices, nontrading days, and survivorship bias before interpreting results.

## 3. Measures of location

For n observed values x₁,…,xₙ, the arithmetic mean is:

**x̄=(1/n)Σxᵢ.**

The median is the middle sorted observation for odd n or the average of the two central observations for even n. It is less sensitive to extreme observations than the mean.

For decimal returns **[.02, −.01, .03, 0]**:

- Sorted observations: **[−.01, 0, .02, .03]**.
- Arithmetic mean: **(.02−.01+.03+0)/4=.01=1%**.
- Median: **(0+.02)/2=.01=1%**.
- Minimum: **−1%**; maximum: **3%**.

## 4. Measures of dispersion

The range is **max(x)−min(x)**. For this sample it is **.04**, or four percentage points.

Population variance:

**σ²=(1/n)Σ(xᵢ−μ)²**.

Sample variance:

**s²=[1/(n−1)]Σ(xᵢ−x̄)²**, defined for n≥2.

The deviations from the mean are [.01, −.02, .02, −.01]. Their squared sum is **.001** in decimal-return-squared units.

Therefore:

**Population variance=.001/4=.00025.**

**Sample variance=.001/3≈.0003333333.**

**Population SD=√.00025≈.0158114**, or **1.58114 percentage points**.

**Sample SD=√(.001/3)≈.0182574**, or **1.82574 percentage points**.

The denominator n−1 is used in the conventional unbiased sample-variance estimator under iid sampling. Sample SD itself is not generally an unbiased estimator of population SD.

## 5. Frequencies and distribution shape

For the four returns, one is negative, two are positive, and one is zero.

**Negative-return fraction=1/4=.25.**

The fraction of historical negative returns is an empirical frequency, not a calibrated probability of future loss.

Mean and SD can conceal asymmetry, outliers, clustered volatility, or heavy tails. Subsequent sections develop quantiles, skewness, kurtosis, and more robust financial statistics.

## 6. Arithmetic versus compounded performance

For sequential simple returns r₁,…,rₙ, cumulative compounded return is:

**R=Π(1+rᵢ)−1.**

The per-period geometric mean return is:

**g=[Π(1+rᵢ)]^(1/n)−1**, provided all gross-return factors are nonnegative and the interpretation is appropriate.

For +10% then −10%:

**R=1.1×.9−1=−1%.**

**g=√(.99)−1≈−0.501256% per period.**

Arithmetic mean is zero, illustrating why arithmetic averaging cannot substitute for compounded performance.

A simple return below −100% is invalid for an unlevered long position; leveraged or synthetic exposures may require a different model and explicit interpretation.

## 7. Outliers and robust interpretation

For returns [1%,2%,3%,20%], mean is 6.5% and median is 2.5%. The difference highlights the influence of an extreme observation.

Do not delete outliers solely because they are inconvenient. Investigate source errors, corporate actions, flash events, and regime shifts. If winsorization or trimming is applied, disclose the rule and report unadjusted results alongside it.

## 8. Reproducible Python lab

Create `descriptive_statistics.py` using the following self-contained standard-library implementation. It deliberately rejects missing/nonfinite values rather than silently imputing them.

```python
from fractions import Fraction
from decimal import Decimal, localcontext
import math
import statistics
import unittest

def clean_returns(values):
    if not isinstance(values, (list, tuple)) or not values:
        raise ValueError("nonempty sequence required")
    if any(type(x) not in (int, float) or (isinstance(x,float) and not math.isfinite(x)) for x in values):
        raise ValueError("finite numeric returns required")
    return list(values)

def _exact(values):
    return [Fraction(str(x)) if isinstance(x,float) else Fraction(x) for x in clean_returns(values)]

def _report(x):
    try:
        result = float(x)
    except OverflowError as exc:
        raise ValueError("result outside float range") from exc
    if not math.isfinite(result) or (result == 0 and x != 0):
        raise ValueError("result outside reportable float range")
    return result

def _root(x):
    with localcontext() as ctx:
        ctx.prec=60
        return _report((Decimal(x.numerator)/Decimal(x.denominator)).sqrt())

def describe(values):
    xs = _exact(values)
    n = len(xs)
    mu = sum(xs)/n
    ordered = sorted(xs)
    median = ordered[n//2] if n%2 else (ordered[n//2-1]+ordered[n//2])/2
    squares = sum((x-mu)**2 for x in xs)
    population = squares/n
    sample = squares/(n-1) if n>1 else None
    return {
        "count": n, "mean": _report(mu), "median": _report(median),
        "minimum": _report(ordered[0]), "maximum": _report(ordered[-1]),
        "range": _report(ordered[-1]-ordered[0]),
        "population_variance": _report(population), "population_sd": _root(population),
        "sample_variance": None if sample is None else _report(sample),
        "sample_sd": None if sample is None else _root(sample),
        "negative_fraction": float(Fraction(sum(x<0 for x in xs),n)),
    }

def _gross(returns):
    xs = _exact(returns)
    if any(x < -1 for x in xs):
        raise ValueError("simple return below -100%")
    return math.prod(1+x for x in xs), len(xs)

def _reported_return(x):
    r = _report(x)
    if r == -1 and x != -1:
        raise ValueError("positive gross factor rounds to complete loss")
    return r

def compounded_return(returns):
    return _reported_return(_gross(returns)[0]-1)

def geometric_mean_return(returns):
    gross, n = _gross(returns)
    if gross == 0:
        return -1.0
    with localcontext() as ctx:
        ctx.prec=750
        result=(Decimal(gross.numerator)/Decimal(gross.denominator))**(Decimal(1)/n)-1
    if (result == 0 and gross != 1) or result == -1:
        raise ValueError("geometric return outside reportable range")
    return _reported_return(result)

class DescriptiveStatisticsTests(unittest.TestCase):
    def setUp(self):
        self.r = [.02, -.01, .03, 0.0]
    def test_01_count(self): self.assertEqual(describe(self.r)["count"],4)
    def test_02_mean(self): self.assertAlmostEqual(describe(self.r)["mean"],.01)
    def test_03_median(self): self.assertAlmostEqual(describe(self.r)["median"],.01)
    def test_04_min(self): self.assertAlmostEqual(describe(self.r)["minimum"],-.01)
    def test_05_max(self): self.assertAlmostEqual(describe(self.r)["maximum"],.03)
    def test_06_range(self): self.assertAlmostEqual(describe(self.r)["range"],.04)
    def test_07_population_variance(self): self.assertAlmostEqual(describe(self.r)["population_variance"],.00025)
    def test_08_sample_variance(self): self.assertAlmostEqual(describe(self.r)["sample_variance"],.001/3)
    def test_09_negative_fraction(self): self.assertAlmostEqual(describe(self.r)["negative_fraction"],.25)
    def test_10_compound(self): self.assertAlmostEqual(compounded_return([.1,-.1]),-.01)
    def test_11_geometric(self): self.assertAlmostEqual(geometric_mean_return([.1,-.1]),math.sqrt(.99)-1)
    def test_12_invalid(self):
        for fn in (lambda: describe([]), lambda: describe([float("nan")]),
                   lambda: compounded_return([-1.01]), lambda: geometric_mean_return([-1.01])):
            with self.assertRaises(ValueError): fn()

if __name__ == "__main__":
    print("Example return summary:", describe([.02,-.01,.03,0]))
    unittest.main(verbosity=2)
```

Suggested commands:

```bash
python descriptive_statistics.py
python -m compileall -q descriptive_statistics.py
```

Use Python 3.8 or later. The first command prints the example and runs **12 reference unit tests**; the second compiles without executing. Supply nonempty lists or tuples of finite numeric observations. Exact fractional intermediates (floats interpreted via decimal text) preserve moment calculations; unreportable float outputs raise an error. The geometric calculation uses a high-precision decimal root. This is an educational implementation, not a benchmark for high-volume data.

## 10. Twenty-four worked exercises

1. **Arithmetic mean:** Returns 2%, −1%, 3%, 0%. **Solution:** (2−1+3+0)/4=1%.

2. **Median:** Sorted values −1,0,2,3. **Solution:** (0+2)/2=1%.

3. **Minimum:** Same values. **Solution:** −1%.

4. **Maximum:** Same values. **Solution:** 3%.

5. **Range:** Same values. **Solution:** 3−(−1)=4 percentage points.

6. **Count:** Four observed returns. **Solution:** n=4.

7. **Sum:** Returns .02,−.01,.03,0. **Solution:** .04.

8. **Population variance:** Returns 2,−1,3,0 in percentage-point units. **Solution:** [(1)²+(−2)²+(2)²+(−1)²]/4=2.5 squared percentage points.

9. **Sample variance:** Same observations. **Solution:** 10/3≈3.3333 squared percentage points.

10. **Population SD:** Same observations. **Solution:** √2.5≈1.5811 percentage points.

11. **Sample SD:** Same observations. **Solution:** √(10/3)≈1.8257 percentage points.

12. **Frequency:** One negative return in four observations. **Solution:** 25% negative.

13. **Positive frequency:** Two positive returns in four. **Solution:** 50% positive.

14. **Zero frequency:** One zero return in four. **Solution:** 25% zero.

15. **Geometric return:** Two returns +10% and −10%. **Solution:** √(1.1×.9)−1≈−0.50126% per period.

16. **Total compounded return:** Two returns +10% and −10%. **Solution:** 1.1×.9−1=−1%.

17. **Outlier influence:** Returns 1%,2%,3%,20%. **Solution:** Mean=6.5%, median=2.5%.

18. **Trimmed mean:** Sorted 1,2,3,20; remove one each end. **Solution:** (2+3)/2=2.5%.

19. **Missing data:** Five dates, one missing return. **Solution:** Valid return count=4; do not silently substitute zero.

20. **Sample size:** n=1. **Solution:** Sample SD undefined; population SD of one value is zero.

21. **Scale invariance:** Convert .02 decimal return to percent. **Solution:** 2%; numerical SD scales by 100.

22. **Linear shift:** Add 1 percentage point to every return. **Solution:** Mean increases by 1 pp; SD unchanged.

23. **Cross-sectional vs time-series:** Four stocks on one date versus one stock over four dates. **Solution:** Different observational units; report explicitly.

24. **Annualization caveat:** Daily arithmetic mean .1%. **Solution:** 252×.1%=25.2% is a linear annualized mean approximation, not a compounded annual return.

## 11. Troubleshooting and operational considerations

| Symptom | Possible cause | Action |
|---|---|---|
| Mean appears 100× too large | Percent/decimal mismatch | Standardize units |
| SD differs between tools | Sample vs population denominator | Confirm ddof and sample definition |
| Zero returns unexpectedly frequent | Missing values imputed as zero | Audit ingestion and calendars |
| Apparent outlier | Split/dividend adjustment error | Inspect corporate-action data |
| Geometric mean differs from arithmetic | Compounding | Validate gross-return products |
| Single-observation sample SD fails | n<2 | Return undefined, not zero |
| Statistics shift after backfill | Data corrections | Version inputs and rerun reports |
