## 1. Why correlation matters in finance

Correlation is a dimensionless measure of statistical association. In financial mathematics, it supports portfolio diversification analysis, factor exposure studies, hedging, and multi-asset risk monitoring.

A historical correlation is not a causal relationship or a promise about future co-movement. Correlations can change during market stress and can be distorted by data errors, nonstationarity, overlapping observations, or unaligned timestamps.

## 2. Pearson correlation

For aligned observations xᵢ and yᵢ, Pearson's sample correlation is:

**r = Σ(xᵢ−x̄)(yᵢ−ȳ) / √[Σ(xᵢ−x̄)² Σ(yᵢ−ȳ)²].**

Equivalently, using a consistent sample covariance and sample standard deviations:

**r = sₓᵧ / (sₓ sᵧ).**

The denominator convention cancels when used consistently. Pearson correlation is defined only when both series have nonzero variance and there are at least two aligned observations.

The value lies in **[−1,1]**:

- **+1:** perfect positive linear association.
- **−1:** perfect negative linear association.
- **0:** zero linear correlation, which does not imply independence.

## 3. Worked example

Suppose two hypothetical assets have returns on three aligned dates:

| Date | Asset A | Asset B |
|---|---:|---:|
| 1 | 1% | 2% |
| 2 | 2% | 4% |
| 3 | 3% | 6% |

Means are **2%** and **4%**. In decimal units, the centered cross-product sum is **.0004**. The centered square sums are **.0002** and **.0008**.

Thus:

**r=.0004/√(.0002×.0008)=1**.

This perfect sample correlation arises because B is exactly twice A in the constructed observations. It does not predict that the relationship will continue.

## 4. Covariance versus correlation

Covariance is measured in the product of the input units. Correlation standardizes covariance by both standard deviations, making it dimensionless.

For constants a,c ≠0 and arbitrary shifts b,d:

**Corr(aX+b,cY+d)=sign(ac)Corr(X,Y)**.

Positive changes of units leave correlation unchanged; multiplying one variable by −1 reverses its sign. Correlation is symmetric: **Corr(X,Y)=Corr(Y,X)**.

## 5. Pearson versus Spearman

**Pearson correlation** measures linear association in the original numeric values.

**Spearman rank correlation** measures linear association between the ranked values and therefore detects monotonic relationships, including some nonlinear ones.

Spearman's rho is computed as Pearson correlation of ranks. When observations tie, the implementation below assigns **average ranks**. The familiar shortcut **1−6Σdᵢ²/[n(n²−1)]** applies only without ties; it is not used here.

For X=[1,2,3,4] and Y=[1,4,9,16], Spearman rho is **1**, because Y strictly increases with X. Pearson r is positive but less than 1, because the relationship is nonlinear.

## 6. Zero correlation does not imply independence

Consider **X=[−2,−1,0,1,2]** and **Y=[4,1,0,1,4]**. The centered cross-product sum is zero, so Pearson correlation is zero.

Yet Y=X² is completely determined by X. This example demonstrates why linear correlation alone cannot characterize nonlinear dependence.

Independence implies zero covariance when the required moments exist, but zero covariance does not generally imply independence. Special assumptions, such as a jointly normal distribution, can change this relationship.

## 7. Financial portfolio interpretation

For two assets with weights w_A and w_B, standard deviations σ_A and σ_B, and correlation ρ:

**Var(Rₚ)=w_A²σ_A²+w_B²σ_B²+2w_Aw_Bρσ_Aσ_B.**

For fixed nonnegative weights and volatilities, reducing correlation reduces portfolio variance. However, diversification is not guaranteed in every regime, and correlations may rise during crises.

For hedging, negative correlation may be useful, but the hedge's practical value also depends on basis risk, liquidity, financing, and changing exposure.

## 8. Correlation matrices

For n assets, the correlation matrix R has entries Rᵢⱼ=Corr(Rᵢ,Rⱼ). A valid correlation matrix is symmetric, has diagonal entries equal to 1 for nonconstant variables, and is positive semidefinite.

A pairwise-estimated matrix assembled using different missing-data subsets can violate positive semidefiniteness. For production portfolio modeling, use a consistent observation matrix and inspect numerical stability.

## 9. Rolling correlation

A rolling correlation computes the association over successive fixed-length windows:

**rₜ = Corr(Xₜ₋w₊₁,…,Xₜ; Yₜ₋w₊₁,…,Yₜ)**.

For n observations and a window of length w, the number of complete windows is **n−w+1**.

Rolling correlations can reveal changing co-movement, but short windows are noisy. A window containing a constant series has undefined Pearson correlation; the reference implementation reports an error rather than silently inventing a value.

## 10. Financial data and operational pitfalls

- **Timestamp misalignment:** join on shared trading dates before computing returns or correlations.
- **Price-level spurious correlation:** trending price levels can correlate even without meaningful return association.
- **Missing-value policy:** avoid silently converting missing returns to zero.
- **Outliers:** a few extreme observations can dominate Pearson correlation.
- **Regime changes:** correlations estimated in calm markets may not persist during stress.
- **Small samples:** a high observed correlation is not strong evidence of a stable relationship.
- **Causality:** correlation alone does not identify causal effects.

## 11. Python reference implementation

Save as `correlation.py`. The standard-library implementation computes Pearson and Spearman correlations, handles tied ranks, generates rolling estimates, and builds correlation matrices. It includes **12 reference unit tests**.

```python
import math
import unittest

def paired(x, y):
    if not isinstance(x, (list, tuple)) or not isinstance(y, (list, tuple)):
        raise ValueError("sequences required")
    if not x or len(x) != len(y):
        raise ValueError("aligned nonempty equal-length observations required")
    if any(type(v) not in (int, float) or not math.isfinite(v) for v in list(x)+list(y)):
        raise ValueError("finite numeric values required")
    return [float(v) for v in x], [float(v) for v in y]

def pearson(x, y):
    a,b=paired(x,y)
    if len(a)<2:
        raise ValueError("at least two pairs required")
    mx=math.fsum(a)/len(a)
    my=math.fsum(b)/len(b)
    dx=[v-mx for v in a]
    dy=[v-my for v in b]
    xx=math.fsum(v*v for v in dx)
    yy=math.fsum(v*v for v in dy)
    if xx==0 or yy==0:
        raise ValueError("correlation undefined for constant series")
    r=math.fsum(u*v for u,v in zip(dx,dy))/math.sqrt(xx*yy)
    return max(-1.0,min(1.0,r))

def average_tie_ranks(values):
    if not values:
        raise ValueError("nonempty values required")
    if any(type(v) not in (int,float) or not math.isfinite(v) for v in values):
        raise ValueError("finite values required")
    result=[0.0]*len(values)
    order=sorted(range(len(values)),key=lambda i:values[i])
    i=0
    while i<len(order):
        j=i+1
        while j<len(order) and values[order[j]]==values[order[i]]:
            j+=1
        avg=(i+1+j)/2.0
        for k in range(i,j):
            result[order[k]]=avg
        i=j
    return result

def spearman(x,y):
    a,b=paired(x,y)
    return pearson(average_tie_ranks(a),average_tie_ranks(b))

def rolling_pearson(x,y,window):
    a,b=paired(x,y)
    if type(window) is not int or window<2 or window>len(a):
        raise ValueError("invalid rolling window")
    return [pearson(a[i-window:i],b[i-window:i])
            for i in range(window,len(a)+1)]

def correlation_matrix(series):
    if not isinstance(series,(list,tuple)) or not series:
        raise ValueError("nonempty collection required")
    arrays=[paired(s,s)[0] for s in series]
    if len({len(s) for s in arrays})!=1:
        raise ValueError("series lengths must match")
    return [[pearson(a,b) for b in arrays] for a in arrays]

class CorrelationTests(unittest.TestCase):
    def setUp(self):
        self.x=[1,2,3,4]
        self.y=[2,4,6,8]
    def test_01_perfect_positive(self): self.assertAlmostEqual(pearson(self.x,self.y),1)
    def test_02_perfect_negative(self): self.assertAlmostEqual(pearson(self.x,[-v for v in self.y]),-1)
    def test_03_symmetry(self): self.assertAlmostEqual(pearson(self.x,self.y),pearson(self.y,self.x))
    def test_04_shift(self): self.assertAlmostEqual(pearson(self.x,self.y),pearson([v+100 for v in self.x],self.y))
    def test_05_scale(self): self.assertAlmostEqual(pearson(self.x,self.y),pearson(self.x,[v*3 for v in self.y]))
    def test_06_rank_positive(self): self.assertAlmostEqual(spearman(self.x,[1,4,9,16]),1)
    def test_07_rank_negative(self): self.assertAlmostEqual(spearman(self.x,[16,9,4,1]),-1)
    def test_08_tie_ranks(self): self.assertEqual(average_tie_ranks([5,2,5,1]),[3.5,2,3.5,1])
    def test_09_rolling(self): self.assertEqual(len(rolling_pearson(self.x,self.y,3)),2)
    def test_10_matrix(self):
        m=correlation_matrix([self.x,self.y])
        self.assertAlmostEqual(m[0][1],m[1][0])
        self.assertAlmostEqual(m[0][0],1)
    def test_11_nonlinear(self): self.assertAlmostEqual(pearson([-2,-1,0,1,2],[4,1,0,1,4]),0)
    def test_12_invalid(self):
        for fn in (lambda:pearson([],[]),lambda:pearson([1],[2]),
                   lambda:pearson([1,2],[1]),lambda:pearson([1,1,1],[1,2,3]),
                   lambda:spearman([1,1,1],[1,2,3]),lambda:rolling_pearson(self.x,self.y,1),
                   lambda:pearson([1,float("nan")],[1,2])):
            with self.assertRaises(ValueError):fn()

if __name__=="__main__":
    print("Pearson:",pearson([1,2,3,4],[2,4,6,8]))
    print("Spearman:",spearman([1,2,3,4],[1,4,9,16]))
    unittest.main(verbosity=2)
```

## 13. Twenty-four worked exercises

1. **Positive correlation:** X=[1,2,3], Y=[2,4,6]. **Worked solution:** Pearson r=1.

2. **Negative correlation:** X=[1,2,3], Y=[−2,−4,−6]. **Worked solution:** Pearson r=−1.

3. **Zero correlation:** X=[−1,0,1], Y=[1,0,1]. **Worked solution:** Pearson r=0; dependence remains.

4. **Correlation units:** Decimal versus percentage returns. **Worked solution:** Pearson correlation unchanged by positive scaling.

5. **Mean X:** X=[1,2,3,4]. **Worked solution:** 2.5.

6. **Mean Y:** Y=[2,4,6,8]. **Worked solution:** 5.

7. **Covariance numerator:** X=[1,2,3], Y=[2,4,6]. **Worked solution:** Sum of centered cross products=4.

8. **Variance numerators:** Same three points. **Worked solution:** X=2; Y=8.

9. **Correlation ratio:** Cross products=4, sums=2 and 8. **Worked solution:** 4/√16=1.

10. **Translation:** Add 10 to X. **Worked solution:** Pearson r unchanged.

11. **Sign reversal:** Multiply Y by −1. **Worked solution:** Pearson r changes sign.

12. **Symmetry:** Exchange X and Y. **Worked solution:** r(X,Y)=r(Y,X).

13. **Bound:** Any nonconstant finite pair. **Worked solution:** −1≤r≤1.

14. **Constant series:** X=[1,1,1]. **Worked solution:** Pearson r undefined.

15. **Spearman monotonic:** X=[1,2,3,4], Y=[1,4,9,16]. **Worked solution:** Spearman ρ=1; Pearson generally less than 1.

16. **Spearman inverse:** X=[1,2,3,4], Y=[16,9,4,1]. **Worked solution:** Spearman ρ=−1.

17. **Tie ranks:** Values [5,2,5,1]. **Worked solution:** Ranks [3.5,2,3.5,1].

18. **Rank correlation:** Spearman calculation. **Worked solution:** Compute Pearson correlation of average-tie ranks.

19. **Window count:** Six observations, rolling window 3. **Worked solution:** Six−three+one=four rolling values.

20. **Portfolio diversification:** Two positive-weight assets. **Worked solution:** Lower correlation reduces variance holding weights and volatilities fixed.

21. **Correlation matrix:** Two assets. **Worked solution:** Diagonal 1 and symmetric off-diagonal entries if both variances nonzero.

22. **Nonlinear dependence:** X=[−2,−1,0,1,2], Y=X². **Worked solution:** Pearson r=0 although Y is determined by X.

23. **Spurious correlation:** Two trending price levels. **Worked solution:** Use appropriately defined returns and inspect time trends before inference.

24. **Small sample:** Four paired returns. **Worked solution:** Correlation is descriptive and unstable; no causal or forecast claim.

## 14. Troubleshooting and checks

| Symptom | Likely cause | Recommended action |
|---|---|---|
| Correlation undefined | Constant input or too few pairs | Check sample size and variance |
| Pearson and Spearman disagree | Nonlinear monotonic relation or outliers | Inspect scatterplot and ranks |
| Correlation outside [−1,1] | Inconsistent moments or numeric error | Recompute from aligned pairs |
| Rolling window fails intermittently | Zero variance in one window | Report undefined window explicitly |
| Matrix is not symmetric | Inconsistent samples or computation | Align and recompute |
| Strong correlation in prices | Shared trend or nonstationarity | Analyze appropriate returns |
| Correlation changes abruptly | Market regime or data issue | Audit data and compare windows |
| High correlation interpreted as causality | Incorrect inference | State observational limitations |
