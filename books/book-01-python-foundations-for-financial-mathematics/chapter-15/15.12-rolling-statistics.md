## 1. Why rolling statistics matter

A full-sample mean or standard deviation summarizes an entire historical interval, but market behavior can change. Rolling statistics update a descriptive measure as new observations arrive. They are widely used for volatility monitoring, factor exposure diagnostics, moving-average signals, correlation risk, and regime detection.

A rolling statistic describes a **chosen trailing window**. It is not automatically a forecast or evidence of a structural break.

## 2. Trailing-window definition

Let x₁,…,xₙ be observations in chronological order. For a window length w, the trailing window ending at time t contains:

**Wₜ={xₜ₋w₊₁,…,xₜ}**, for t≥w.

There are **n−w+1 complete windows** when n≥w.

The rolling mean is:

**mₜ=(1/w)Σⱼ₌ₜ₋w₊₁ᵗ xⱼ**.

For [1,2,3,4] and w=2, the full-window rolling means are **[1.5,2.5,3.5]**.

### Alignment matters

A trailing window ending at t may be calculated only once observation xₜ is available. If xₜ is a closing return, a decision executed before that close cannot legitimately use it.

## 3. Rolling sample variance and volatility

For a trailing window of w≥2 observations, calculate:

**s²ₜ=[1/(w−1)]Σⱼ₌ₜ₋w₊₁ᵗ(xⱼ−mₜ)²**.

**sₜ=√s²ₜ**.

For [1,2,3] and w=3, the sample SD is **1**.

When observations are daily returns, a common annualized rolling volatility approximation is:

**σₜ,annual≈sₜ√252**.

The square-root-of-time convention relies on assumptions about return dependence, frequency, and variance stability. Volatility clustering and overlapping returns complicate interpretation.

## 4. Rolling correlation

For aligned series x and y, compute Pearson correlation separately inside each trailing window:

**rₜ = Σ(xⱼ−x̄ₜ)(yⱼ−ȳₜ) / √[Σ(xⱼ−x̄ₜ)² Σ(yⱼ−ȳₜ)²]**.

For x=[1,2,3] and y=[2,4,6], r=+1.

For y=[6,4,2], r=−1.

If either series has zero variance within a window, correlation is **undefined**, not zero. The reference implementation returns `None` for this case.

Rolling correlation can change quickly with window size and extreme observations. Short-window correlations are particularly noisy.

## 5. Rolling compounded returns

For simple returns Rⱼ greater than or equal to −1, the w-period compounded simple return is:

**Rₜ,w=∏ⱼ₌ₜ₋w₊₁ᵗ(1+Rⱼ)−1**.

For returns [+10%,−10%], the two-period compounded return is **−1%**, not zero.

When all window returns exceed −100%, the stable log form is:

**Rₜ,w=expm1[Σ log1p(Rⱼ)]**.

A window containing −100% return yields −100% compounded return under the simple wealth model. Returns below −100% are invalid for an unlevered positive-price simple-return model; leveraged instruments and P&L conventions require separate handling.

## 6. Warm-up periods and missing data

A full trailing window cannot be calculated until w observations are available. With w=5, the first four positions are a **warm-up period**.

Possible policies:

- Return only full-window results, as in this chapter's Python reference.
- Preserve original timestamps and fill warm-up positions with explicit missing markers.
- Allow a minimum number of observations, but document changed estimators and degrees of freedom.

Missing market dates are not always missing data: weekends and exchange holidays are usually excluded from trading-day series. Actual missing quotes require a separate data-quality policy.

Do not silently forward-fill missing returns or prices without analyzing the effect on volatility and correlation.

## 7. Overlapping-window dependence

Adjacent rolling windows share w−1 observations. Their statistics are therefore generally serially dependent, even when the underlying observations are independent.

Consequences include:

- Adjacent rolling estimates are not independent samples.
- Naive standard errors for trends in rolling estimates can be misleading.
- Repeated threshold testing on overlapping windows can generate false alarms.
- A smooth rolling chart may conceal abrupt underlying shocks.

For formal inference, account for overlap and time-series dependence.

## 8. Rolling versus expanding windows

A **rolling window** holds the observation count fixed, dropping older data as new data arrive.

An **expanding window** starts at a fixed historical point and grows as observations arrive.

Rolling windows adapt more quickly to regime changes but have greater sampling variability. Expanding windows are often more stable but can be slow to reflect structural breaks.

Window selection should reflect the operational question and be evaluated out of sample rather than optimized solely for a visually attractive backtest.

## 9. Exponentially weighted alternatives

An exponentially weighted variance model can emphasize recent shocks:

**vₜ=λvₜ₋₁+(1−λ)rₜ₋₁²**, for 0<λ<1, under a zero-mean innovation convention.

The timing index matters: vₜ uses information available before period t. The decay parameter controls the weight of older observations.

This is not the same estimator as a fixed-length rolling sample variance. Initialization, mean treatment, data frequency, and stability assumptions must be documented.

## 10. Preventing look-ahead bias

A common error is to calculate a rolling signal using the close at t and assume a strategy could execute at the same close without any execution delay.

A defensible backtest should define:

1. When each source observation becomes available.
2. When the rolling statistic is calculated.
3. When a decision is issued.
4. When an order can actually execute.
5. What costs, spreads, slippage, and market constraints apply.

The reference `lagged_signal` helper shifts a full-window output by one **output position**, illustrating the concept. A real implementation must map signals to original timestamps and enforce actual data-availability and execution timing.

## 11. Python reference implementation

Save as `rolling_statistics.py`. This standard-library reference calculates full-window trailing means, sample SDs, Pearson correlations, compounded simple returns, and a one-position lag. It includes **12 reference unit tests**.

```python
import math
import unittest

def validate(xs):
    if not isinstance(xs,(list,tuple)) or not xs:
        raise ValueError("nonempty sequence required")
    if any(type(x) not in (int,float) or not math.isfinite(x) for x in xs):
        raise ValueError("finite numeric values required")
    return [float(x) for x in xs]

def check_window(window,n):
    if type(window) is not int or not 1<=window<=n:
        raise ValueError("integer window in [1,n] required")

def rolling_mean(values,window):
    xs=validate(values)
    check_window(window,len(xs))
    return [math.fsum(xs[i-window+1:i+1])/window for i in range(window-1,len(xs))]

def rolling_sample_std(values,window):
    xs=validate(values)
    check_window(window,len(xs))
    if window<2:
        raise ValueError("sample standard deviation requires window >= 2")
    result=[]
    for i in range(window-1,len(xs)):
        w=xs[i-window+1:i+1]
        m=math.fsum(w)/window
        result.append(math.sqrt(math.fsum((x-m)**2 for x in w)/(window-1)))
    return result

def rolling_correlation(x,y,window):
    a,b=validate(x),validate(y)
    if len(a)!=len(b):
        raise ValueError("aligned equal-length sequences required")
    check_window(window,len(a))
    if window<2:
        raise ValueError("correlation requires window >= 2")
    out=[]
    for i in range(window-1,len(a)):
        xx=a[i-window+1:i+1]
        yy=b[i-window+1:i+1]
        mx=math.fsum(xx)/window
        my=math.fsum(yy)/window
        dx=[v-mx for v in xx]
        dy=[v-my for v in yy]
        sxx=math.fsum(v*v for v in dx)
        syy=math.fsum(v*v for v in dy)
        if sxx==0 or syy==0:
            out.append(None)
        else:
            out.append(math.fsum(u*v for u,v in zip(dx,dy))/math.sqrt(sxx*syy))
    return out

def rolling_compounded_return(returns,window):
    r=validate(returns)
    check_window(window,len(r))
    if any(x < -1 for x in r):
        raise ValueError("simple returns below -100% invalid")
    out=[]
    for i in range(window-1,len(r)):
        w=r[i-window+1:i+1]
        out.append(-1.0 if -1 in w else math.expm1(math.fsum(math.log1p(x) for x in w)))
    return out

def lagged_signal(rolling_values):
    if not isinstance(rolling_values,(list,tuple)):
        raise ValueError("sequence required")
    return [None]+list(rolling_values[:-1])

class RollingStatisticsTests(unittest.TestCase):
    def test_01_means(self): self.assertEqual(rolling_mean([1,2,3,4],2),[1.5,2.5,3.5])
    def test_02_window_full(self): self.assertEqual(rolling_mean([1,2,3],3),[2])
    def test_03_window_one(self): self.assertEqual(rolling_mean([1,2,3],1),[1,2,3])
    def test_04_std(self):
        self.assertAlmostEqual(rolling_sample_std([1,2,3],3)[0],1)
    def test_05_std_constant(self):
        self.assertEqual(rolling_sample_std([2,2,2],2),[0,0])
    def test_06_correlation_positive(self):
        self.assertAlmostEqual(rolling_correlation([1,2,3],[2,4,6],3)[0],1)
    def test_07_correlation_negative(self):
        self.assertAlmostEqual(rolling_correlation([1,2,3],[6,4,2],3)[0],-1)
    def test_08_correlation_undefined(self):
        self.assertIsNone(rolling_correlation([1,1,1],[1,2,3],3)[0])
    def test_09_compound(self):
        self.assertAlmostEqual(rolling_compounded_return([.1,-.1],2)[0],-.01)
    def test_10_total_loss(self):
        self.assertEqual(rolling_compounded_return([.1,-1],2)[0],-1)
    def test_11_lag(self):
        self.assertEqual(lagged_signal([2,3,4]),[None,2,3])
    def test_12_invalid(self):
        for f in (lambda:rolling_mean([1,2],0),
                  lambda:rolling_mean([1,2],3),
                  lambda:rolling_sample_std([1,2],1),
                  lambda:rolling_correlation([1,2,3],[1,2],2),
                  lambda:rolling_compounded_return([-1.01,0],2),
                  lambda:rolling_mean([1,float("nan")],2)):
            with self.assertRaises(ValueError):f()

if __name__=="__main__":
    returns=[.01,-.02,.03,.00,.02]
    print("Rolling mean:",rolling_mean(returns,3))
    print("Rolling volatility:",rolling_sample_std(returns,3))
    print("Rolling compounded return:",rolling_compounded_return(returns,3))
    unittest.main(verbosity=2)
```

13. **Window length:** 20 observations, w=5. **Worked solution:** 16 full-window outputs.

## 14. Troubleshooting and operational checks

| Symptom | Likely cause | Recommended action |
|---|---|---|
| Too few outputs | Full-window warm-up | Expect n−w+1 results |
| Undefined rolling correlation | Zero variance in a window | Return explicit missing marker |
| Volatility unexpectedly zero | Constant or stale returns | Audit market data |
| Backtest appears unrealistically strong | Look-ahead or execution timing | Shift and timestamp signals |
| Different window results across libraries | ddof or min-period settings | Document estimator conventions |
| Rolling mean lags regime shift | Window too long | Evaluate window tradeoff |
| Spurious confidence from smooth charts | Overlapping observations | Account for serial dependence |
| Memory or runtime pressure | Repeated slicing of large datasets | Consider stable streaming algorithms |
