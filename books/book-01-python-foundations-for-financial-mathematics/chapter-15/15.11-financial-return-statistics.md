## 1. Return measurement is the foundation

Financial statistics must begin with a precise definition of return. The answer depends on whether data are raw prices, split-adjusted prices, total-return indices, cash-flow-adjusted portfolio values, or futures prices. A statistically correct formula applied to the wrong price series produces misleading results.

For an asset price Pₜ>0, the one-period **simple price return** is:

**Rₜ=Pₜ/Pₜ₋₁−1.**

The **log return** is:

**rₜ=ln(Pₜ/Pₜ₋₁)=ln(1+Rₜ).**

For a cash dividend Dₜ paid during the period, a simplified holding-period total return is **(Pₜ+Dₜ)/Pₜ₋₁−1**, subject to the exact corporate-action and reinvestment conventions.

## 2. Simple versus logarithmic returns

Suppose prices move **100→110→99**.

| Period | Simple return | Log return |
|---|---:|---:|
| 100→110 | +10% | ln(1.1)≈+.0953102 |
| 110→99 | −10% | ln(.9)≈−.1053605 |
| Entire horizon | −1% | ln(.99)≈−.0100503 |

Simple returns **compound multiplicatively**:

**1+R_total=∏(1+Rₜ).**

Log returns **add across consecutive periods**:

**r_total=Σrₜ=ln(P_T/P₀).**

Simple returns are intuitive for wealth changes and portfolio weights. Log returns are convenient for time aggregation and some modeling assumptions. They are not interchangeable, especially for large returns.

## 3. Arithmetic mean return

For n observed simple returns:

**R̄=(1/n)ΣRᵢ.**

For returns [+10%,−10%], the arithmetic mean is **0%**.

The arithmetic mean summarizes the average observed one-period return; it is not the realized compounded growth rate across those periods.

## 4. Geometric mean and compounding

For simple returns greater than −100%, the geometric mean per period is:

**G=[∏(1+Rᵢ)]^(1/n)−1.**

Equivalently, for numerical stability:

**G=exp[(1/n)Σln(1+Rᵢ)]−1.**

For [+10%,−10%]:

**G=√(1.1×.9)−1=√.99−1≈−.00501256**, or approximately **−0.5013%** per period.

The cumulative return is **−1%**. This illustrates **volatility drag**: alternating gains and losses can produce negative compound growth even when the arithmetic average is zero.

The geometric mean is undefined for a sample containing a −100% return under the positive-wealth geometric-growth formula. The cumulative simple return remains −100% after a total loss.

## 5. Sample variance and volatility

Sample return variance:

**s²=[1/(n−1)]Σ(Rᵢ−R̄)²**, for n≥2.

Sample volatility:

**s=√s²**.

For returns [.01,.02,.03], R̄=.02, sample variance=.0001, and sample SD=.01, or **1 percentage point per observation**.

Volatility measures dispersion, not necessarily downside loss, and its estimate can be sensitive to outliers, sampling frequency, stale prices, and regime shifts.

## 6. Annualization and its assumptions

If observations are daily and there are approximately **252 trading sessions per year**, the common square-root-of-time approximation is:

**σ_annual≈σ_daily√252**.

For σ_daily=.01, this gives approximately **15.87%**.

This scaling is justified under conditions such as stationary uncorrelated increments with finite variance. Serial correlation, volatility clustering, overlapping returns, and changing regimes can invalidate the approximation.

For the arithmetic mean, **252×daily mean** is a linear annualized mean convention, not a realized compounded annual return. Compounded annual growth requires an explicit reinvestment model and horizon.

## 7. Excess returns and risk-adjusted statistics

A common simple-return excess-return approximation is:

**R_excess,t=R_asset,t−R_riskfree,t**, using consistent periods and conventions.

A per-period sample Sharpe ratio is:

**Sharpe=mean(R_excess)/SD(R_excess)**, when the denominator is positive.

Annualizing a Sharpe ratio by √252 requires assumptions about dependence and scaling. A Sharpe ratio is not a complete risk measure; downside tails, leverage, liquidity, and nonlinear exposures may remain hidden.

## 8. Historical value at risk

Define **loss L=−R** for a one-period return R. Historical VaR at confidence level 1−α is a chosen empirical upper-tail quantile of loss.

The reference implementation uses a simple **nearest-rank left-tail return convention**: sort n returns ascending, take the observation at one-based rank **max(1,ceil(αn))**, and negate it.

For returns **[−.10,−.05,.01,.02]** and α=.25, the selected return is −.10, giving **VaR=.10 (10% loss)**.

Empirical quantile conventions vary; interpolation and tail definitions can yield different results. The implementation returns a **signed loss threshold**, so VaR can be negative if every observed return is positive. Some reporting systems floor VaR at zero; that is a separate convention and must be stated.

VaR does not describe how large losses become beyond the selected quantile.

## 9. Historical expected shortfall

Expected shortfall (ES), also called conditional VaR under certain conventions, measures tail loss severity. A simplified finite-sample historical estimator averages the worst **max(1,ceil(αn))** observations.

For returns [−.10,−.05,.01,.02] and α=.5, the worst two are −.10 and −.05, so:

**ES=−[(−.10−.05)/2]=.075 (7.5% loss)**.

This discrete estimator differs from fractional-tail and interpolated ES definitions. With very small samples, tail estimates are extremely unstable. Neither historical VaR nor ES guarantees future tail coverage.

## 10. Data engineering controls for return series

| Risk | Potential distortion | Control |
|---|---|---|
| Stock splits | Artificial price jumps | Corporate-action adjustments |
| Dividends | Understated total returns | Total-return conventions |
| Stale quotes | Suppressed volatility | Price-quality checks |
| Different market calendars | Invalid cross-asset comparisons | Timestamp alignment |
| Delistings omitted | Survivorship bias | Point-in-time universe |
| Intraday versus close data | Frequency mismatch | Document bar definition |
| Futures roll | Artificial discontinuities | Consistent roll methodology |
| FX conversion | Currency exposure mixed with local returns | Define base currency |
| Negative or zero prices | Log return invalid | Enforce instrument-specific domain |
| Data revisions | Unreproducible backtests | Immutable source snapshots |

## 11. Python reference implementation

Save as `financial_return_statistics.py`. This standard-library implementation calculates simple/log returns, arithmetic/geometric means, cumulative returns, volatility, and discrete historical VaR/ES. It includes **12 reference unit tests**.

```python
import math
import unittest

def clean(values):
    if not isinstance(values,(list,tuple)) or not values:
        raise ValueError("nonempty list or tuple required")
    if any(type(v) not in (int,float) or not math.isfinite(v) for v in values):
        raise ValueError("finite numeric values required")
    return [float(v) for v in values]

def simple_returns(prices):
    p=clean(prices)
    if len(p)<2 or any(x<=0 for x in p):
        raise ValueError("at least two strictly positive prices required")
    return [p[i]/p[i-1]-1 for i in range(1,len(p))]

def log_returns(prices):
    p=clean(prices)
    if len(p)<2 or any(x<=0 for x in p):
        raise ValueError("at least two strictly positive prices required")
    return [math.log(p[i]/p[i-1]) for i in range(1,len(p))]

def arithmetic_mean(returns):
    r=clean(returns)
    return math.fsum(r)/len(r)

def geometric_mean(returns):
    r=clean(returns)
    if any(x<=-1 for x in r):
        raise ValueError("geometric mean requires returns greater than -100%")
    return math.expm1(math.fsum(math.log1p(x) for x in r)/len(r))

def cumulative_return(returns):
    r=clean(returns)
    if any(x < -1 for x in r):
        raise ValueError("simple return cannot be below -100%")
    if any(x==-1 for x in r):
        return -1.0
    return math.expm1(math.fsum(math.log1p(x) for x in r))

def sample_volatility(returns):
    r=clean(returns)
    if len(r)<2:
        raise ValueError("at least two observations required")
    m=arithmetic_mean(r)
    return math.sqrt(math.fsum((x-m)**2 for x in r)/(len(r)-1))

def annualized_volatility(returns,periods_per_year=252):
    if type(periods_per_year) not in (int,float) or not math.isfinite(periods_per_year) or periods_per_year<=0:
        raise ValueError("positive periods_per_year required")
    return sample_volatility(returns)*math.sqrt(periods_per_year)

def historical_var(returns,alpha=.05):
    r=sorted(clean(returns))
    if type(alpha) not in (int,float) or not math.isfinite(alpha) or not 0<alpha<1:
        raise ValueError("alpha in (0,1) required")
    index=max(0,math.ceil(alpha*len(r))-1)
    return -r[index]

def historical_expected_shortfall(returns,alpha=.05):
    r=sorted(clean(returns))
    if type(alpha) not in (int,float) or not math.isfinite(alpha) or not 0<alpha<1:
        raise ValueError("alpha in (0,1) required")
    count=max(1,math.ceil(alpha*len(r)))
    return -math.fsum(r[:count])/count

class ReturnStatisticsTests(unittest.TestCase):
    def test_01_simple(self): self.assertAlmostEqual(simple_returns([100,110])[0],.1)
    def test_02_log(self): self.assertAlmostEqual(log_returns([100,110])[0],math.log(1.1))
    def test_03_mean(self): self.assertAlmostEqual(arithmetic_mean([.1,-.1]),0)
    def test_04_geometric(self): self.assertAlmostEqual(geometric_mean([.1,-.1]),math.sqrt(.99)-1)
    def test_05_cumulative(self): self.assertAlmostEqual(cumulative_return([.1,-.1]),-.01)
    def test_06_bankruptcy(self): self.assertEqual(cumulative_return([-.5,-1]),-1)
    def test_07_volatility(self): self.assertAlmostEqual(sample_volatility([.01,.02,.03]),.01)
    def test_08_annual_vol(self): self.assertAlmostEqual(annualized_volatility([.01,.02,.03],4),.02)
    def test_09_var(self): self.assertAlmostEqual(historical_var([-.1,-.05,.01,.02],.25),.1)
    def test_10_es(self): self.assertAlmostEqual(historical_expected_shortfall([-.1,-.05,.01,.02],.5),.075)
    def test_11_log_additivity(self):
        p=[100,110,99]
        self.assertAlmostEqual(math.fsum(log_returns(p)),math.log(p[-1]/p[0]))
    def test_12_invalid(self):
        for f in (lambda:simple_returns([100,0]),lambda:geometric_mean([-.999,-1]),
                  lambda:cumulative_return([-1.01]),lambda:sample_volatility([.1]),
                  lambda:historical_var([.1],0),lambda:annualized_volatility([.1,.2],0),
                  lambda:arithmetic_mean([float("nan")])):
            with self.assertRaises(ValueError):f()

if __name__=="__main__":
    r=[.1,-.1]
    print("Arithmetic:",arithmetic_mean(r))
    print("Geometric:",geometric_mean(r))
    print("Cumulative:",cumulative_return(r))
    unittest.main(verbosity=2)
```

## 13. Twenty-four worked exercises

1. **Simple return:** Price 100→110. **Worked solution:** 110/100−1=.10.

2. **Log return:** Price 100→110. **Worked solution:** ln(1.1)≈.0953102.

3. **Negative simple return:** Price 110→99. **Worked solution:** 99/110−1=−.10.

4. **Log additivity:** Prices 100→110→99. **Worked solution:** ln(1.1)+ln(.9)=ln(.99).

5. **Arithmetic mean:** Returns +10%,−10%. **Worked solution:** 0%.

6. **Geometric mean:** Returns +10%,−10%. **Worked solution:** √(.99)−1≈−0.50126%.

7. **Cumulative return:** Returns +10%,−10%. **Worked solution:** 1.1×.9−1=−1%.

8. **Volatility drag:** Arithmetic 0%, geometric negative. **Worked solution:** Compounding reduces growth when returns fluctuate.

9. **Sample variance:** Returns 1%,2%,3%. **Worked solution:** s²=.0001.

10. **Sample volatility:** Same returns. **Worked solution:** s=.01=1% per observation.

11. **Annualized volatility:** Daily s=.01, 252 sessions. **Worked solution:** s_ann=.01√252≈.158745 under scaling assumptions.

12. **Annualized arithmetic mean:** Daily mean .001, 252 sessions. **Worked solution:** 252×.001=.252 as linear annualized arithmetic mean; not compounded return.

13. **Annualized geometric growth:** Daily geometric mean .001. **Worked solution:** (1.001)^252−1, assuming stable compounding.

14. **Simple return floor:** Asset price cannot be negative. **Worked solution:** Simple long-only unlevered price return ≥−100%.

15. **Log return domain:** Price 0. **Worked solution:** Undefined; do not compute ln(0).

16. **Total-return adjustment:** Dividend on ex-date. **Worked solution:** Use adjusted or total-return data where appropriate.

17. **Historical VaR:** Returns [−.10,−.05,.01,.02], α=.25. **Worked solution:** Nearest-rank left-tail loss VaR=.10.

18. **Historical ES:** Same returns, α=.5. **Worked solution:** Average worst two returns −.075; ES loss=.075.

19. **Negative VaR:** All historical returns positive. **Worked solution:** Unfloored signed VaR can be negative; define loss convention.

20. **ES sample count:** n=10, α=.05. **Worked solution:** Nearest-rank empirical tail uses at least one observation; extremely unstable.

21. **Excess return:** Asset .012, risk-free .002 same period. **Worked solution:** Excess simple return≈.010 using arithmetic difference convention.

22. **Sharpe convention:** Mean excess .01, SD .02. **Worked solution:** Per-period Sharpe=.5 under chosen convention.

23. **Stale prices:** Repeated unchanged closes. **Worked solution:** Can artificially suppress estimated volatility.

24. **Return alignment:** Two assets with different calendars. **Worked solution:** Join same observation timestamps before covariance/correlation.

## 14. Troubleshooting and operational checks

| Symptom | Likely cause | Recommended action |
|---|---|---|
| Return jumps hundreds of percent | Unadjusted split | Reconcile corporate actions |
| Log return domain error | Nonpositive price | Validate instrument and price definition |
| Arithmetic and geometric means differ | Compounding | Use correct measure for question |
| VaR negative | Signed quantile convention | Document flooring policy if any |
| Tail estimates change drastically | Small sample | Add history, sensitivity, stress scenarios |
| Volatility unexpectedly low | Stale or repeated prices | Audit quote freshness |
| Annualized volatility misleading | Serial dependence | Examine autocovariance and regimes |
| Cross-asset covariance nonsensical | Misaligned calendars | Join on identical dates |
