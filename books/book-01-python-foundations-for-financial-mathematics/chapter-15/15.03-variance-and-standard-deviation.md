## Learning objectives

Calculate population and sample variance and standard deviation; explain their denominators, units, and sensitivity to outliers; interpret financial volatility and downside deviation; understand conditional annualization; and implement defensive Python calculations with 12 reference tests.

## 1. Why dispersion matters in finance

Two investments can have the same arithmetic mean return but radically different outcomes. Variance and standard deviation quantify dispersion around the mean, not whether the outcomes are desirable. Standard deviation is commonly used as a measure of historical return volatility, but it does not independently characterize skewness, heavy tails, drawdowns, or liquidity risk.

Use a clearly defined observation frequency, adjustment policy, return convention, and sample window. Financial time series can be autocorrelated, heteroskedastic, and nonstationary.

## 2. Population versus sample

For observations x₁,…,xₙ, let **μ=(1/n)Σxᵢ** for a fully observed finite population, or **x̄** for the sample mean.

Population variance:

**σ²=(1/n)Σ(xᵢ−μ)².**

Sample variance:

**s²=[1/(n−1)]Σ(xᵢ−x̄)²**, for n≥2.

Standard deviations are **σ=√σ²** and **s=√s²**.

The n−1 denominator corrects the bias of the usual sample variance estimator when observations are independent and identically distributed with finite variance. It does not make sample SD itself unbiased, and it does not automatically correct time-series dependence.

## 3. Fully worked return example

Consider four hypothetical decimal simple returns: **[.02,−.01,.03,0]**.

| Observation | Return | Deviation from 1% mean | Squared deviation (decimal units²) |
|---|---:|---:|---:|
| 1 | 2% | +1 percentage point | .0001 |
| 2 | −1% | −2 percentage points | .0004 |
| 3 | 3% | +2 percentage points | .0004 |
| 4 | 0% | −1 percentage point | .0001 |
| **Total** | **4%** | **0** | **.0010** |

The mean is **.01**, and the sum of squared deviations is **.001**.

Population variance: **.001/4=.00025**.

Population SD: **√.00025≈.01581139**, or **1.58114 percentage points**.

Sample variance: **.001/3≈.0003333333**.

Sample SD: **√(.001/3)≈.01825742**, or **1.82574 percentage points**.

**Unit rule:** Variance of decimal returns is in decimal-return-squared units; SD is in decimal returns. Multiply decimal SD by 100 to express it in percentage points. Do not multiply variance by 100 when converting to squared percentage points; the conversion factor is 100².

## 4. Why the denominator matters

With a sample mean estimated from the same observations, only n−1 deviations are free once their sum is constrained to zero. This motivates Bessel's correction under the standard iid assumptions.

For a single observation, population variance is zero for that one-value empirical population; sample variance is **undefined**, not zero.

For constant observations, sample variance is zero in exact arithmetic provided n≥2. The reference routine preserves exact zero for constant inputs by using rational intermediate arithmetic. Its original test retains a tolerance, with strict-zero checks recorded separately in QA evidence.

## 5. Transformation rules

For constant a and b:

**Var(aX+b)=a²Var(X)**.

**SD(aX+b)=|a|SD(X)**.

Adding 3 percentage points to every return shifts the mean by 3 percentage points but leaves variance and SD unchanged. Multiplying every return by 2 multiplies variance by 4 and SD by 2.

These rules help catch implementation errors and unit inconsistencies.

## 6. Downside deviation versus total volatility

A downside-deviation measure with threshold τ and all-n denominator is:

**DD(τ)=√{(1/n)Σ[min(0,xᵢ−τ)]²}**.

For returns [.02,−.01,.03,0] and threshold τ=0, the only shortfall is −.01, giving

**DD(0)=√(.0001/4)=.005=0.5%**.

Other downside-deviation conventions use a different denominator. Always disclose the threshold and denominator. Downside deviation is not interchangeable with ordinary SD.

## 7. Annualizing volatility

Under a simplified model of uncorrelated equal-variance daily returns, variance over T trading days is approximately **Tσ_daily²** and volatility is **σ_daily√T**.

For daily SD=1% and 252 trading days:

**Annualized SD≈1%×√252≈15.8745%**.

This is a modeling approximation, not a universal identity. With serial correlation, multi-period variance contains covariance terms:

**Var(ΣₜRₜ)=ΣₜVar(Rₜ)+2Σₛ<ₜCov(Rₛ,Rₜ)**.

Return compounding and changing volatility can also invalidate a naive scaling interpretation. Never use annualized historical SD as a guaranteed forecast.

## 8. Portfolio connection

For two assets with weights w₁,w₂:

**Var(Rₚ)=w₁²σ₁²+w₂²σ₂²+2w₁w₂Cov(R₁,R₂)**.

For w₁=w₂=.5, σ₁²=.04, σ₂²=.09, and covariance zero:

**Var(Rₚ)=.25(.04)+.25(.09)=.0325**.

**SD(Rₚ)=√.0325≈.180278**, or about 18.03%.

Covariance must be compatible with the asset variances: **|Cov(R₁,R₂)|≤σ₁σ₂**. Correlation, covariance estimation, and portfolio matrices are developed in later sections and Chapter 16.

## 9. Outliers and volatility clustering

For [1%,1%,1%,9%], the mean is 3% and population variance is 12 squared percentage points, showing how a single extreme observation increases squared dispersion.

Do not automatically remove large financial moves. Investigate data errors, splits, market closures, and legitimate stress events. Also distinguish a stable variance model from volatility clustering, where quiet and turbulent periods appear in groups.

## 10. Python reference lab

Save as `variance_standard_deviation.py`. The standard-library implementation validates finite numeric observations, exposes the degrees-of-freedom convention, calculates downside deviation, checks annualization inputs, and includes **12 reference unit tests**.

```python
import math
from fractions import Fraction
from decimal import Decimal, localcontext
import unittest

def finite_number(x):
    if type(x) not in (int,float):
        return False
    try:
        return math.isfinite(x)
    except OverflowError:
        return False

def exact(x):
    return Fraction(x) if type(x) is int else Fraction(str(x))

def report(x):
    try:
        value=float(x)
    except (OverflowError, ValueError) as exc:
        raise ValueError("result outside float range") from exc
    if not math.isfinite(value) or (x and value==0):
        raise ValueError("result outside float range")
    return value

def root(x):
    # Take the root before float conversion, preserving small/large squares.
    with localcontext() as ctx:
        ctx.prec=80
        return report((Decimal(x.numerator)/Decimal(x.denominator)).sqrt())

def observations(values):
    if not isinstance(values, (list, tuple)) or not values:
        raise ValueError("nonempty list or tuple required")
    if any(not finite_number(x) for x in values):
        raise ValueError("finite numeric observations required")
    return list(values)

def moments(values, ddof=1):
    xs = list(map(exact,observations(values)))
    if type(ddof) is not int or ddof not in (0, 1):
        raise ValueError("ddof must be 0 or 1")
    n = len(xs)
    if n <= ddof:
        raise ValueError("insufficient observations")
    mu = sum(xs) / n
    ss = sum((x - mu)**2 for x in xs)
    var = ss / (n - ddof)
    return {"count": n, "mean": report(mu), "sum_squared_deviations": report(ss),
            "variance": report(var), "standard_deviation": root(var),
            "ddof": ddof}

def downside_deviation(values, threshold=0.0):
    xs = list(map(exact,observations(values)))
    if not finite_number(threshold):
        raise ValueError("finite threshold required")
    tau=exact(threshold)
    return root(sum(min(Fraction(0),x-tau)**2 for x in xs)/len(xs))

def scaled_volatility(period_sd, periods_per_year):
    if not finite_number(period_sd) or period_sd < 0:
        raise ValueError("nonnegative finite SD required")
    if not finite_number(periods_per_year) or periods_per_year <= 0:
        raise ValueError("positive annualization factor required")
    return root(exact(period_sd)**2*exact(periods_per_year))

def portfolio_variance(weight_a, var_a, weight_b, var_b, covariance):
    vals = [weight_a, var_a, weight_b, var_b, covariance]
    if any(not finite_number(v) for v in vals):
        raise ValueError("finite numeric inputs required")
    wa,va,wb,vb,cov=map(exact,vals)
    if va < 0 or vb < 0 or cov**2 > va*vb:
        raise ValueError("invalid variance/covariance parameters")
    return report(wa**2*va + wb**2*vb + 2*wa*wb*cov)

class VarianceSDTests(unittest.TestCase):
    def setUp(self): self.r = [.02,-.01,.03,0]
    def test_01_count(self): self.assertEqual(moments(self.r)["count"],4)
    def test_02_mean(self): self.assertAlmostEqual(moments(self.r)["mean"],.01)
    def test_03_ss(self): self.assertAlmostEqual(moments(self.r)["sum_squared_deviations"],.001)
    def test_04_sample_variance(self): self.assertAlmostEqual(moments(self.r)["variance"],.001/3)
    def test_05_population_variance(self): self.assertAlmostEqual(moments(self.r,0)["variance"],.00025)
    def test_06_sample_sd(self): self.assertAlmostEqual(moments(self.r)["standard_deviation"],math.sqrt(.001/3))
    def test_07_constant(self):
        self.assertTrue(math.isclose(moments([.05,.05,.05])["variance"], 0.0,
                                     rel_tol=0.0, abs_tol=1e-30))
    def test_08_single_population(self): self.assertEqual(moments([.05],0)["variance"],0)
    def test_09_downside(self): self.assertAlmostEqual(downside_deviation(self.r),.005)
    def test_10_annualization(self): self.assertAlmostEqual(scaled_volatility(.01,252),.01*math.sqrt(252))
    def test_11_portfolio(self): self.assertAlmostEqual(portfolio_variance(.5,.04,.5,.09,0),.0325)
    def test_12_invalid(self):
        for fn in (lambda:moments([]),lambda:moments([.1]),lambda:moments([float("nan")]),
                   lambda:moments([1,2],2),lambda:scaled_volatility(-1,252),
                   lambda:portfolio_variance(.5,.01,.5,.01,.02)):
            with self.assertRaises(ValueError): fn()

if __name__ == "__main__":
    print("Sample:", moments([.02,-.01,.03,0]))
    print("Population:", moments([.02,-.01,.03,0],ddof=0))
    unittest.main(verbosity=2)
```

Intermediate arithmetic preserves integers and interprets floats by their displayed decimal values. Square roots use an 80-digit decimal context before float reporting. Nonzero results that cannot be represented as finite nonzero floats raise `ValueError`; this includes every field in the moments report. Covariance feasibility is checked exactly under this input policy, with no absolute tolerance that could permit negative portfolio variance at small scales. This educational policy is not a binary-float compatibility or high-throughput performance claim.

## 12. Twenty-four worked exercises

1. **Mean:** Returns 2%,−1%,3%,0%. **Worked solution:** Sum=4 percentage points; mean=1%.

2. **Deviations:** Same sample. **Worked solution:** 1,−2,2,−1 percentage points.

3. **Squared deviations:** Same sample. **Worked solution:** 1,4,4,1 squared percentage points.

4. **Squared-deviation sum:** Same sample. **Worked solution:** 10 squared percentage points = .001 in decimal-return-squared units.

5. **Population variance:** Same sample. **Worked solution:** 10/4=2.5 squared percentage points = .00025 decimal units².

6. **Sample variance:** Same sample. **Worked solution:** 10/3≈3.333333 squared percentage points = .001/3 decimal units².

7. **Population SD:** Same sample. **Worked solution:** √2.5≈1.581139 percentage points.

8. **Sample SD:** Same sample. **Worked solution:** √(10/3)≈1.825742 percentage points.

9. **Zero variance:** Returns 5%,5%,5%. **Worked solution:** All deviations zero; variance and SD zero.

10. **Single observation:** One observed return 5%. **Worked solution:** Population SD=0; sample SD undefined because n−1=0.

11. **Two-point sample:** Returns 0%,2%. **Worked solution:** Mean=1%; sample variance=(1+1)/(2−1)=2 squared percentage points.

12. **Shift invariance:** Add 3 percentage points to each return. **Worked solution:** Variance and SD remain unchanged.

13. **Scaling variance:** Multiply returns by 2. **Worked solution:** Variance multiplies by 4; SD multiplies by 2.

14. **Percent conversion:** Sample SD=.0182574 in decimal units. **Worked solution:** 1.82574 percentage points.

15. **Downside deviation:** Returns 2%,−1%,3%,0%, threshold 0. **Worked solution:** √[(0²+.01²+0²+0²)/4]=.005=0.5%.

16. **Variance versus downside:** Same returns. **Worked solution:** Variance counts positive and negative deviations; downside deviation counts only shortfalls.

17. **Annualized SD:** Daily SD=1%, 252 trading days. **Worked solution:** 1%×√252≈15.8745%, conditional on iid/zero serial covariance assumptions.

18. **Annualization counterexample:** Strong serial correlation. **Worked solution:** √252 rule is not generally valid; incorporate autocovariances.

19. **Portfolio variance:** Weights .5,.5; variances .04,.09; covariance 0. **Worked solution:** .25(.04)+.25(.09)=.0325.

20. **Portfolio SD:** Portfolio variance .0325. **Worked solution:** √.0325≈.180278.

21. **Perfect positive correlation:** Equal 50% weights; SD 20%,30%. **Worked solution:** Portfolio SD=.5(.2)+.5(.3)=25%.

22. **Perfect negative correlation:** Equal 50% weights; SD 20%,30%. **Worked solution:** Portfolio SD=|.5(.2)−.5(.3)|=5%.

23. **Extreme outlier:** Returns 1%,1%,1%,9%. **Worked solution:** Mean=3%; population variance=[3×(−2)²+6²]/4=12 squared percentage points.

24. **Uncertainty:** Four historical returns. **Worked solution:** Sample SD describes dispersion, not a confidence interval or reliable forward-looking risk forecast.

## 13. Common mistakes and troubleshooting

| Symptom | Likely cause | Remedy |
|---|---|---|
| Two tools report different variances | ddof=0 versus ddof=1 | State population/sample convention |
| SD appears 100× different | Percent versus decimal | Normalize return units |
| Variance appears 10,000× different | Squared-unit conversion | Convert with 100² |
| One-observation sample SD equals zero | Incorrect fallback | Report undefined |
| Annualized SD understates risk | Autocorrelation or regime change | Inspect time dependence and stress scenarios |
| Variance is negative | Numerical or formula error | Investigate; variance must be nonnegative |
| Extreme losses disappear | Improper outlier filtering | Preserve raw series and audit exclusions |
| Covariance exceeds feasible bounds | Invalid covariance assumptions | Check Cauchy–Schwarz bound |
