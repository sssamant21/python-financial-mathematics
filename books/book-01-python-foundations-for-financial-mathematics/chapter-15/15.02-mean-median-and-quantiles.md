## Learning objectives

By the end of this section, you should be able to calculate and interpret arithmetic and weighted means, medians, empirical quantiles, and interquartile ranges; distinguish quantile conventions; identify outlier sensitivity; and implement validated, reproducible Python routines for financial returns.

## 1. Financial observations and units

A financial data sample may be a time series of returns for one instrument or a cross-section of returns for many instruments. The two should not be combined without a clear research design.

All worked examples below use **decimal simple returns** internally: `0.02` means 2%. A result stated in percentage points is the decimal result multiplied by 100. Missing data, duplicate timestamps, corporate-action adjustments, and sampling frequency must be addressed before statistical interpretation.

Our primary sample is:

| Sorted observation | Decimal return | Percent |
|---|---:|---:|
| 1 | −0.04 | −4% |
| 2 | −0.01 | −1% |
| 3 | 0.00 | 0% |
| 4 | 0.02 | 2% |
| 5 | 0.08 | 8% |

## 2. Arithmetic mean

For observations x₁,…,xₙ, the arithmetic mean is

**x̄ = (Σxᵢ)/n.**

In the sample, the sum is **−.04−.01+0+.02+.08=.05**. Therefore

**x̄=.05/5=.01=1%.**

The arithmetic mean is appropriate for describing the average observed single-period return. It is not the same as the compounded return across the five periods. See Chapter 13 for geometric and time-weighted performance.

### Weighted mean

For nonnegative weights wᵢ with positive total weight,

**x̄_w = (Σwᵢxᵢ)/(Σwᵢ).**

For a hypothetical portfolio holding 75% of asset A with 2% return and 25% of asset B with 8% return, the one-period weighted return is **.75(.02)+.25(.08)=.035=3.5%**. This assumes compatible return horizons and weights representing the relevant beginning-of-period exposures.

## 3. Median

Sort the n values. If n is odd, the median is the central observation. If n is even, it is the arithmetic mean of the two central observations.

Our five-return sample has median **0%**. For **[−4%,−1%,2%,8%]**, the median is **(−1%+2%)/2=.5%**.

The median is less sensitive than the mean to extreme values. However, a median alone does not measure dispersion or tail severity.

## 4. Quantiles and convention selection

An empirical quantile estimates a location within the ordered sample. **Quantile definitions differ across software packages**, particularly for small samples.

This section adopts the linear-interpolation convention commonly called **type 7**. For sorted x₀,…,xₙ₋₁ and probability p in [0,1], calculate:

**h=(n−1)p**, **j=floor(h)**, **k=ceil(h)**, then

**Q₇(p)=xⱼ+(h−j)(xₖ−xⱼ).**

For the five returns:

- Q₇(0)=−4%.
- Q₇(.25)=−1%.
- Q₇(.5)=0%.
- Q₇(.75)=2%.
- Q₇(1)=8%.

The **interquartile range (IQR)** is **Q(.75)−Q(.25)=3 percentage points**.

### Interpolation example

For sorted values **[0,10,20,30]** and p=.25:

**h=(4−1)×.25=.75**.

**Q₇(.25)=0+.75(10−0)=7.5**.

### Nearest-rank alternative

The nearest-rank quantile for p in (0,1] selects sorted observation at **one-based rank ceil(np)**. For the same four values and p=.25, the nearest-rank answer is **0**, not 7.5.

Both calculations can be legitimate under their declared conventions. Do not compare reported quantiles from two systems without checking the interpolation definition.

## 5. Tail quantiles and risk interpretation

For the five returns, the type-7 5th percentile has **h=4×.05=.2**, so

**Q₇(.05)=−4%+.2(−1%+4%)=−3.4%**.

Similarly, **Q₇(.95)=2%+.8(8%−2%)=6.8%**.

If exposure V=$100,000 and one-period loss is defined as **L=−VR**, a return 5th percentile of −3.4% corresponds to a *sample-derived* 95th loss quantile of approximately **$3,400** under this sign convention.

**Caution:** Five observations cannot support a reliable tail-risk forecast. The example is arithmetic practice, not an approved VaR model. Quantile estimation requires adequate sample size, consistent horizons, and evaluation of nonstationarity, serial dependence, and model uncertainty.

## 6. Mean, median, and outliers

Consider returns **[1%,2%,3%,20%]**.

Arithmetic mean: **(1+2+3+20)/4=6.5%**.

Median: **(2+3)/2=2.5%**.

If the maximum changes from 20% to 40%, the mean rises by 5 percentage points while the median remains unchanged.

A trimmed mean removes a specified number of extreme observations from each end of the sorted sample. Removing one observation from each end of [1%,2%,3%,20%] leaves [2%,3%], with trimmed mean **2.5%**.

Trimming should not be used to hide genuine losses. Retain both the original and adjusted statistics, document the rule, and examine whether extreme observations are data errors or real financial events.

## 7. Python reference implementation

Save as `mean_median_quantiles.py`. The reference implementation uses only Python's standard library, checks for nonfinite inputs, documents the quantile method, and includes **12 reference unit tests**.

```python
import math
import statistics
import unittest

def clean(values):
    if not isinstance(values, (list,tuple)) or not values:
        raise ValueError("nonempty list or tuple required")
    if any(type(x) not in (int,float) or not math.isfinite(x) for x in values):
        raise ValueError("finite numeric observations required")
    return sorted(float(x) for x in values)

def arithmetic_mean(values):
    xs=clean(values)
    return math.fsum(xs)/len(xs)

def median(values):
    return statistics.median(clean(values))

def quantile_type7(values, p):
    xs=clean(values)
    if type(p) not in (int,float) or not math.isfinite(p) or not 0 <= p <= 1:
        raise ValueError("quantile probability must be in [0,1]")
    h=(len(xs)-1)*p
    lo=math.floor(h)
    hi=math.ceil(h)
    return xs[lo]+(h-lo)*(xs[hi]-xs[lo])

def nearest_rank_quantile(values,p):
    xs=clean(values)
    if type(p) not in (int,float) or not math.isfinite(p) or not 0 < p <= 1:
        raise ValueError("nearest-rank p must be in (0,1]")
    return xs[math.ceil(p*len(xs))-1]

def trimmed_mean(values, trim_each_side):
    xs=clean(values)
    if type(trim_each_side) is not int or trim_each_side < 0 or 2*trim_each_side >= len(xs):
        raise ValueError("invalid trimming")
    mid=xs[trim_each_side:len(xs)-trim_each_side] if trim_each_side else xs
    return math.fsum(mid)/len(mid)

def weighted_mean(values,weights):
    xs=clean_pairs(values,weights)
    total=math.fsum(w for _,w in xs)
    if total<=0:
        raise ValueError("positive total weight required")
    return math.fsum(x*w for x,w in xs)/total

def clean_pairs(values,weights):
    if not isinstance(values,(list,tuple)) or not isinstance(weights,(list,tuple)):
        raise ValueError("sequences required")
    if not values or len(values)!=len(weights):
        raise ValueError("length mismatch")
    pairs=list(zip(values,weights))
    if any(type(x) not in (int,float) or not math.isfinite(x) or
           type(w) not in (int,float) or not math.isfinite(w) or w<0 for x,w in pairs):
        raise ValueError("invalid values or weights")
    return pairs

def downside_fraction(values,threshold=0):
    xs=clean(values)
    if type(threshold) not in (int,float) or not math.isfinite(threshold):
        raise ValueError("invalid threshold")
    return sum(x<threshold for x in xs)/len(xs)

class MeanMedianQuantileTests(unittest.TestCase):
    def setUp(self): self.x=[-.04,-.01,0,.02,.08]
    def test_01_mean(self): self.assertAlmostEqual(arithmetic_mean(self.x),.01)
    def test_02_median(self): self.assertEqual(median(self.x),0)
    def test_03_q0(self): self.assertEqual(quantile_type7(self.x,0),-.04)
    def test_04_q25(self): self.assertEqual(quantile_type7(self.x,.25),-.01)
    def test_05_q50(self): self.assertEqual(quantile_type7(self.x,.5),0)
    def test_06_q75(self): self.assertEqual(quantile_type7(self.x,.75),.02)
    def test_07_q100(self): self.assertEqual(quantile_type7(self.x,1),.08)
    def test_08_interpolation(self): self.assertAlmostEqual(quantile_type7([0,10,20,30],.25),7.5)
    def test_09_nearest_rank(self): self.assertEqual(nearest_rank_quantile([0,10,20,30],.25),0)
    def test_10_trimmed(self): self.assertAlmostEqual(trimmed_mean([1,2,3,20],1),2.5)
    def test_11_weighted(self): self.assertAlmostEqual(weighted_mean([.02,.08],[.75,.25]),.035)
    def test_12_validation(self):
        for f in (lambda:arithmetic_mean([]),lambda:median([float("nan")]),
                  lambda:quantile_type7([1,2],1.1),lambda:nearest_rank_quantile([1,2],0),
                  lambda:trimmed_mean([1,2],1),lambda:weighted_mean([1],[0]),
                  lambda:weighted_mean([1,2],[1])):
            with self.assertRaises(ValueError):f()

if __name__=="__main__":
    example=[-.04,-.01,0,.02,.08]
    print("mean",arithmetic_mean(example))
    print("median",median(example))
    print("Q05",quantile_type7(example,.05))
    print("Q95",quantile_type7(example,.95))
    unittest.main(verbosity=2)
```

## 9. Twenty-four worked exercises

1. **Arithmetic mean** — −4%,−1%,0%,2%,8%. **Worked solution:** Sum=5 percentage points; divide by 5 to obtain 1%.

2. **Median of odd n** — −4%,−1%,0%,2%,8%. **Worked solution:** The third sorted value is 0%.

3. **Median of even n** — −4%,−1%,2%,8%. **Worked solution:** Average the middle two: (−1+2)/2=0.5%.

4. **Minimum quantile** — Same five returns, type-7 p=0. **Worked solution:** −4%.

5. **Maximum quantile** — Same five returns, type-7 p=1. **Worked solution:** 8%.

6. **First quartile** — Five sorted returns, type-7 p=.25. **Worked solution:** Index h=(5−1)×.25=1 (zero-based), so −1%.

7. **Third quartile** — Five sorted returns, type-7 p=.75. **Worked solution:** h=3, so 2%.

8. **Interquartile range** — Q3=2%, Q1=−1%. **Worked solution:** IQR=3 percentage points.

9. **Type-7 interpolation** — Values 0,10,20,30; p=.25. **Worked solution:** h=.75; interpolate 0+.75(10)=7.5.

10. **Nearest rank** — Values 0,10,20,30; p=.25. **Worked solution:** ceil(4×.25)=1; first observation 0.

11. **Median equivalence** — Five observations, p=.5. **Worked solution:** Type-7 quantile equals median, 0%.

12. **Lower-tail fraction** — Two negative values among five. **Worked solution:** 2/5=40% observed negative-return frequency.

13. **Outlier effect** — 1%,2%,3%,20%. **Worked solution:** Mean 6.5%, median 2.5%.

14. **Trimmed mean** — 1%,2%,3%,20%, remove one at each end. **Worked solution:** Mean of 2%,3%=2.5%.

15. **Weighted mean** — 2% with weight .75 and 8% with weight .25. **Worked solution:** 0.75×2+0.25×8=3.5%.

16. **Unequal weights** — 1%,3%,5% with weights 1,2,1. **Worked solution:** (1+6+5)/4=3%.

17. **Shift property** — Add 2 percentage points to each return. **Worked solution:** Mean, median and all translation-equivariant quantiles increase by 2 pp.

18. **Positive scale** — Multiply all decimal returns by 100. **Worked solution:** Mean, median and quantiles multiply by 100; now expressed in percent.

19. **Mean sensitivity** — Replace 8% with 28% in five observations. **Worked solution:** Sum rises 20 pp; mean rises 4 pp from 1% to 5%.

20. **Median robustness** — Replace 8% with 28% in same observations. **Worked solution:** Median stays 0%.

21. **Missing observation** — Five dates, one return missing. **Worked solution:** Compute from four valid returns only and report n=4; never silently insert zero.

22. **Tiny sample tails** — Five returns, type-7 p=.05. **Worked solution:** h=.2; −4%+.2(−1%+4%)=−3.4%.

23. **Upper tail** — Five returns, type-7 p=.95. **Worked solution:** h=3.8; 2%+.8(8%−2%)=6.8%.

24. **Quantile as VaR input** — 5th return quantile −3.4%, exposure $100,000. **Worked solution:** Stylized 95% loss quantile $3,400 if loss=−V×return; not a forecast.

## 10. Operational and statistical pitfalls

| Problem | Why it matters | Recommended control |
|---|---|---|
| Percent versus decimal confusion | 100× scale errors | Declare return units |
| Mixed return frequencies | Noncomparable horizons | Normalize frequency before comparison |
| Different quantile conventions | Different percentile values | Record method and interpolation |
| Missing values converted to zero | Biased distribution | Preserve null/missing semantics |
| Data errors treated as real outliers | Distorted mean and tails | Reconcile corporate actions and feeds |
| Genuine losses removed as outliers | Understated downside risk | Report unadjusted series |
| Very small sample | Unstable tail quantiles | State sample-size limitations |
| Nonstationary data | Historical summaries can mislead | Segment regimes and perform sensitivity analysis |
| Weighted returns with mismatched horizons | Invalid aggregation | Align exposures and measurement periods |
