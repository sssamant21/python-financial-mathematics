## 1. Why regression matters in finance

Linear regression summarizes how one observed variable changes with another. Common financial applications include estimating market beta, studying factor exposures, analyzing execution costs, and developing baseline forecasting models.

Regression estimates associations conditional on the chosen model and sample. It does **not** prove a causal effect, establish investment skill, or guarantee out-of-sample predictive accuracy.

## 2. Simple linear regression model

For aligned observations (xᵢ,yᵢ), the model is:

**yᵢ = α + βxᵢ + εᵢ**.

- **α** is the intercept.
- **β** is the slope.
- **εᵢ** is the unobserved disturbance.

The fitted value is **ŷᵢ=α̂+β̂xᵢ**, and the residual is **eᵢ=yᵢ−ŷᵢ**.

OLS chooses coefficients to minimize **SSE=Σeᵢ²**.

## 3. Deriving the OLS estimates

Define:

**Sxx=Σ(xᵢ−x̄)²**, and **Sxy=Σ(xᵢ−x̄)(yᵢ−ȳ)**.

If Sxx>0:

**β̂=Sxy/Sxx**.

**α̂=ȳ−β̂x̄**.

This follows by setting the first derivatives of the sum of squared residuals with respect to α and β equal to zero. For simple OLS with an intercept, the residuals sum to zero (up to floating-point error).

## 4. Worked numerical example

Use the hypothetical observations:

| Observation | x | y |
|---|---:|---:|
| 1 | 1 | 3 |
| 2 | 2 | 5 |
| 3 | 3 | 7 |
| 4 | 4 | 9 |

Here x̄=2.5, ȳ=6, Sxx=5, and Sxy=10.

Therefore:

**β̂=10/5=2**, and **α̂=6−2(2.5)=1**.

The fitted line is **ŷ=1+2x**.

Every observation lies exactly on the line, so all residuals are zero and SSE=0. At x=5, the fitted prediction is 11. This is an intentionally simple arithmetic demonstration, not a realistic noisy financial model.

## 5. Residuals, fit, and error measures

The total sum of squares is **SST=Σ(yᵢ−ȳ)²**.

For OLS with an intercept and SST>0:

**R²=1−SSE/SST**.

R² measures the fraction of in-sample response variation explained by the fitted linear model under this definition. A high R² does not prove causation, correct specification, or forecasting value.

Root mean squared error is:

**RMSE=√[(1/n)Σ(yᵢ−ŷᵢ)²]**.

RMSE uses the response's units. In contrast, the conventional unbiased residual variance estimator under homoskedastic iid errors is:

**s²=SSE/(n−2)**, for n≥3.

The n−2 denominator reflects estimation of two coefficients.

## 6. Standard error of the slope

Under the classical homoskedastic, independent-error assumptions with fixed regressors or appropriate conditional assumptions:

**SE(β̂)=√(s²/Sxx)**.

A conventional t statistic for testing H₀: β=β₀ is:

**t=(β̂−β₀)/SE(β̂)**.

Its exact small-sample Student-t reference requires further distributional assumptions, commonly conditionally normal errors. A zero residual variance produces a zero estimated standard error, so conventional inference may be undefined despite a perfect fitted line.

For financial time series, serial correlation and heteroskedasticity often require robust or HAC standard errors. The simple reference lab does **not** implement those adjustments.

## 7. Finance example: market beta and alpha

For asset returns Rᵢ,t and market returns Rₘ,t, a simple market-model regression is:

**Rᵢ,t = α + βRₘ,t + εₜ**.

Here β estimates the sample sensitivity of asset returns to market returns under the fitted model. The intercept α is a conditional return intercept in the units and frequency of the data.

Do not automatically equate α with risk-adjusted investment skill. Factor omissions, data selection, costs, regime changes, and inference errors can produce misleading estimates.

For CAPM-style interpretation, the specification often uses **excess returns** over a risk-free benchmark. Clearly distinguish that model from a regression of raw returns.

## 8. Core regression assumptions and diagnostics

| Concern | Why it matters | Practical diagnostic |
|---|---|---|
| Linearity | Misspecified functional form | Residual versus fitted plot |
| Exogeneity | Endogeneity biases slope interpretation | Review omitted variables and timing |
| Constant error variance | Classical SE may be wrong | Residual scale by fitted value |
| Error independence | Serial dependence affects inference | Residual autocorrelation checks |
| Outliers | Squared loss amplifies extremes | Influence and leverage diagnostics |
| Predictor variation | Sxx=0 makes slope undefined | Check data range |
| Data leakage | Future information creates false predictability | Point-in-time feature audit |
| Structural breaks | Relationships may change over time | Rolling and regime analysis |

Normal residuals are **not** required for computing OLS coefficients; stronger distributional assumptions are relevant to exact finite-sample inference.

## 9. Prediction versus explanation

A regression fitted on historical observations can be useful descriptively but perform poorly out of sample.

Use chronological train/validation/test splits for financial forecasting, avoid random shuffling that leaks future information, and compare against simple baselines. Any standardization, feature selection, or hyperparameter tuning must be fitted on training data only.

An in-sample R² is not an out-of-sample performance guarantee. Extrapolation far beyond the observed x range is especially fragile.

## 10. Python reference implementation

Save as `linear_regression.py`. This standard-library example fits simple OLS with an intercept, reports residuals, SSE, SST, R², residual variance, slope standard error, and prediction. It includes **12 reference unit tests**.

```python
import math
import unittest
from fractions import Fraction
from decimal import Decimal, localcontext

def finite_number(x):
    if type(x) not in (int,float):
        return False
    try:
        return math.isfinite(x)
    except OverflowError:
        return False

def exact(x):
    return Fraction(x) if type(x) is int else Fraction(str(x))

def report(x):
    try:
        value=float(x)
    except (OverflowError,ValueError) as exc:
        raise ValueError("result outside float range") from exc
    if not math.isfinite(value) or (x and value==0):
        raise ValueError("result outside float range")
    return value

def root(x):
    with localcontext() as ctx:
        ctx.prec=80
        return report((Decimal(x.numerator)/Decimal(x.denominator)).sqrt())

def paired(x,y):
    if not isinstance(x,(list,tuple)) or not isinstance(y,(list,tuple)) or not x or len(x)!=len(y):
        raise ValueError("nonempty equal-length positional sequences required")
    if any(not finite_number(v) for v in list(x)+list(y)):
        raise ValueError("finite numeric observations required")
    # Timestamp alignment is an upstream responsibility.
    return list(x),list(y)

def ols_simple(x,y):
    a,b=paired(x,y);n=len(a)
    if n<3:
        raise ValueError("at least three observations required for residual variance")
    a=list(map(exact,a));b=list(map(exact,b))
    mx=sum(a)/n;my=sum(b)/n
    dx=[v-mx for v in a];dy=[v-my for v in b]
    sxx=sum(v*v for v in dx)
    if sxx==0:
        raise ValueError("predictor has zero variance")
    sxy=sum(u*v for u,v in zip(dx,dy))
    beta=sxy/sxx;alpha=my-beta*mx
    fitted=[alpha+beta*v for v in a]
    residuals=[actual-pred for actual,pred in zip(b,fitted)]
    sse=sum(e*e for e in residuals);sst=sum(v*v for v in dy)
    # Reporting convention for an exactly fitted constant response.
    r2=1-sse/sst if sst else Fraction(1)
    sigma2=sse/(n-2)
    return {"n":n,"intercept":report(alpha),"slope":report(beta),
            "coefficient_ratios":{"intercept":str(alpha),"slope":str(beta)},
            "fitted":[report(v) for v in fitted],"residuals":[report(v) for v in residuals],
            "sse":report(sse),"sst":report(sst),"r_squared":report(r2),
            "residual_variance":report(sigma2),"slope_standard_error":root(sigma2/sxx)}

def predict(model,x):
    if not finite_number(x):
        raise ValueError("finite predictor required")
    if not isinstance(model,dict) or any(not finite_number(model.get(k)) for k in ("intercept","slope")):
        raise ValueError("finite model coefficients required")
    if "coefficient_ratios" in model:
        try:
            alpha=Fraction(model["coefficient_ratios"]["intercept"])
            beta=Fraction(model["coefficient_ratios"]["slope"])
        except (KeyError,TypeError,ValueError,ZeroDivisionError) as exc:
            raise ValueError("invalid coefficient ratios") from exc
        if report(alpha)!=model["intercept"] or report(beta)!=model["slope"]:
            raise ValueError("model coefficients were modified without updating ratios")
    else:
        alpha=exact(model["intercept"]);beta=exact(model["slope"])
    return report(alpha+beta*exact(x))

def rmse(y_true,y_pred):
    a,b=paired(y_true,y_pred)
    return root(sum((exact(u)-exact(v))**2 for u,v in zip(a,b))/len(a))

class RegressionTests(unittest.TestCase):
    def setUp(self):
        self.x=[1,2,3,4]
        self.y=[3,5,7,9]
        self.m=ols_simple(self.x,self.y)
    def test_01_slope(self): self.assertAlmostEqual(self.m["slope"],2)
    def test_02_intercept(self): self.assertAlmostEqual(self.m["intercept"],1)
    def test_03_r_squared(self): self.assertAlmostEqual(self.m["r_squared"],1)
    def test_04_sse(self): self.assertAlmostEqual(self.m["sse"],0)
    def test_05_predict(self): self.assertAlmostEqual(predict(self.m,5),11)
    def test_06_rmse(self): self.assertAlmostEqual(rmse(self.y,self.m["fitted"]),0)
    def test_07_residual_sum(self): self.assertAlmostEqual(sum(self.m["residuals"]),0)
    def test_08_noisy_data(self):
        m=ols_simple([1,2,3,4],[2,4,5,9])
        self.assertGreater(m["sse"],0)
        self.assertLess(m["r_squared"],1)
    def test_09_constant_response(self):
        m=ols_simple([1,2,3],[5,5,5])
        self.assertAlmostEqual(m["slope"],0)
        self.assertAlmostEqual(m["r_squared"],1)
    def test_10_shift_response(self):
        m=ols_simple(self.x,[v+10 for v in self.y])
        self.assertAlmostEqual(m["slope"],self.m["slope"])
        self.assertAlmostEqual(m["intercept"],11)
    def test_11_scale_predictor(self):
        m=ols_simple([2*v for v in self.x],self.y)
        self.assertAlmostEqual(m["slope"],1)
    def test_12_invalid(self):
        for fn in (lambda:ols_simple([1,2],[3,5]),
                  lambda:ols_simple([1,1,1],[2,3,4]),
                  lambda:ols_simple([1,2,3],[1,2]),
                  lambda:ols_simple([1,2,float("nan")],[1,2,3]),
                  lambda:predict(self.m,float("inf"))):
            with self.assertRaises(ValueError):fn()

if __name__=="__main__":
    model=ols_simple([1,2,3,4],[3,5,7,9])
    print({k:v for k,v in model.items() if k not in ("fitted","residuals")})
    print("Prediction for x=5:",predict(model,5))
    unittest.main(verbosity=2)
```

Integer inputs retain their precision, and intermediate arithmetic uses exact fractions of integers or displayed decimal float values. Square roots use an 80-digit Decimal context before float reporting. Every reported numeric field must be finite and nonzero values may not silently underflow to zero; otherwise `ValueError` is raised. The model also retains canonical rational coefficient strings in `coefficient_ratios`; `predict` uses them to avoid losing a small intercept when large rounded coefficients cancel. Editing only the display coefficients is rejected. Manually supplied models without ratios use their declared numeric coefficients. Fitted values/residuals and fit diagnostics are computed before final rounding.

For constant responses SST=0, the usual R² fraction is undefined; this implementation reports 1 by explicit perfect-fit convention. That convention is not explained response variance or evidence of predictive quality. These educational numerical conventions are not a binary-float compatibility or performance guarantee.

## 12. Twenty-four worked exercises

1. **Model:** Predict y from x. **Worked solution:** yᵢ=α+βxᵢ+εᵢ.

2. **Mean x:** x=[1,2,3,4]. **Worked solution:** x̄=2.5.

3. **Mean y:** y=[3,5,7,9]. **Worked solution:** ȳ=6.

4. **Sxx:** x=[1,2,3,4]. **Worked solution:** Σ(x−2.5)²=5.

5. **Sxy:** x=[1,2,3,4], y=[3,5,7,9]. **Worked solution:** Σ(x−2.5)(y−6)=10.

6. **Slope:** Sxy=10, Sxx=5. **Worked solution:** β̂=2.

7. **Intercept:** ȳ=6, x̄=2.5, β̂=2. **Worked solution:** α̂=1.

8. **Prediction:** x=5, fitted y=1+2x. **Worked solution:** ŷ=11.

9. **Residual:** Observed y=9, fitted y=9. **Worked solution:** Residual=0.

10. **SSE:** Perfect fitted example. **Worked solution:** 0.

11. **SST:** y=[3,5,7,9]. **Worked solution:** Σ(y−6)²=20.

12. **R²:** SSE=0, SST=20. **Worked solution:** R²=1.

13. **Residual df:** n=4, two fitted coefficients. **Worked solution:** n−2=2.

14. **Residual variance:** SSE=2, n=4. **Worked solution:** s²=2/(4−2)=1.

15. **Slope SE:** Residual variance=1, Sxx=5. **Worked solution:** SE(β̂)=√(1/5).

16. **RMSE:** Residuals [1,−1,1,−1]. **Worked solution:** √[(1+1+1+1)/4]=1.

17. **Zero predictor variance:** x=[1,1,1]. **Worked solution:** Slope undefined; reject.

18. **Shift response:** Add 10 to y. **Worked solution:** Slope unchanged; intercept increases by 10.

19. **Scale predictor:** Multiply x by 2. **Worked solution:** Slope halves if response unchanged.

20. **Beta in finance:** Market return as x, asset return as y. **Worked solution:** Slope estimates sample market sensitivity under the model.

21. **Alpha in finance:** Intercept=.001 for daily simple returns. **Worked solution:** Estimated conditional intercept=.1 percentage points per day; not guaranteed skill.

22. **Residual autocorrelation:** Daily time-series errors dependent. **Worked solution:** Conventional iid standard errors may be invalid.

23. **Look-ahead leakage:** Future price in feature x. **Worked solution:** Invalid backtest; enforce point-in-time inputs.

24. **Extrapolation:** Fit x in [1,4], predict x=100. **Worked solution:** Prediction is outside observed range and potentially unreliable.

## 13. Troubleshooting and operational checks

| Symptom | Likely cause | Recommended action |
|---|---|---|
| Slope undefined | Constant predictor | Reject or redesign feature |
| R² is perfect in backtest | Leakage, duplicates, or synthetic relation | Audit features and timestamps |
| Standard errors implausibly small | Serial dependence or heteroskedasticity | Use justified robust inference |
| High in-sample fit, poor forecast | Overfitting or regime change | Chronological holdout |
| Alpha interpreted as skill | Omitted factors or costs | Validate model and economic context |
| Regression output changes by unit | Predictor or response rescaled | Document coefficients' units |
| Residual variance undefined | Fewer than three observations | Require n≥3 |
| Extreme coefficients | Outlier or leverage observation | Inspect influence and data quality |
