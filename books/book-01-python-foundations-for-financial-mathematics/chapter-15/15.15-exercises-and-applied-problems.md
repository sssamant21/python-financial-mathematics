## Part B — Applied case study: Descriptive risk

**Dataset:** Five hypothetical daily simple returns [.01,−.02,.03,0,.02].

1. Calculate count, arithmetic mean, median, minimum, maximum, and sample SD.
2. Compute the compounded return with ∏(1+Rᵢ)−1.
3. Calculate full-window rolling means for window=3.
4. Explain how a −20% return would affect the estimates.
5. Describe why a five-observation sample cannot reliably estimate rare-event risk.

**Reference solution:** n=5; sum=.04; mean=.008; sorted observations [−.02,0,.01,.02,.03]; median=.01; min=−.02; max=.03. Rolling means are [.0066666667,.0033333333,.0166666667]. The compounded return is (1.01)(.98)(1.03)(1)(1.02)−1. All results are descriptive; short samples have unstable tail estimates.

## Part C — Applied case study: Linear regression

**Dataset:** Aligned x=[1,2,3,4], y=[3,5,7,9].

1. Compute x̄ and ȳ.
2. Derive Sxx=Σ(x−x̄)² and Sxy=Σ(x−x̄)(y−ȳ).
3. Estimate slope β̂=Sxy/Sxx and intercept α̂=ȳ−β̂x̄.
4. Compute fitted values, residuals, SSE, and R².
5. Predict y when x=5 and discuss extrapolation.

**Reference solution:** x̄=2.5, ȳ=6, Sxx=5, Sxy=10, slope=2, intercept=1, SSE=0, R²=1, prediction=11. Perfect fit in a synthetic dataset does not prove a stable market relationship.

## Part D — Applied case study: Inference and research selection

**Scenario:** An analyst has n=100 observations, sample mean=.02, sample SD=.10, and 20 candidate strategies.

1. Define H0: μ=0 and a two-sided alternative.
2. Compute the estimated SE and nominal 95% normal-approximation interval.
3. State why a normal interval is not automatically exact.
4. Explain p-values, Type I/II errors, and power.
5. Calculate the Bonferroni threshold for familywise α=.05.
6. Describe the need for a chronological holdout and full experiment registry.

**Reference solution:** SE=.10/√100=.01; approximate 95% CI=.02±1.959964(.01), or [.00040036,.03959964]. Bonferroni threshold=.0025. Dependence, heavy tails, selection, and nonstationarity can invalidate nominal inference.

## Part G — Python reference implementation and twelve unit tests

Save as `chapter15_applied_problems.py`. The standard-library code covers core calculations and supplies twelve tests for future execution.

```python
import math
import unittest

def mean(x):
    if not isinstance(x,(list,tuple)) or not x or any(type(v) not in (int,float) or not math.isfinite(v) for v in x):
        raise ValueError("finite nonempty sample required")
    return math.fsum(x)/len(x)

def sd(x):
    m=mean(x)
    if len(x)<2: raise ValueError("n >= 2 required")
    return math.sqrt(math.fsum((v-m)**2 for v in x)/(len(x)-1))

def cumulative(r):
    mean(r)
    if any(x < -1 for x in r): raise ValueError("invalid return")
    if -1 in r: return -1.0
    return math.expm1(math.fsum(math.log1p(x) for x in r))

def rolling(x,w):
    mean(x)
    if type(w) is not int or not 1<=w<=len(x): raise ValueError("invalid window")
    return [mean(x[i-w:i]) for i in range(w,len(x)+1)]

def corr(x,y):
    mx,my=mean(x),mean(y)
    if len(x)!=len(y) or len(x)<2: raise ValueError("unaligned series")
    dx=[v-mx for v in x];dy=[v-my for v in y]
    xx=math.fsum(v*v for v in dx);yy=math.fsum(v*v for v in dy)
    if xx==0 or yy==0: raise ValueError("undefined correlation")
    return math.fsum(a*b for a,b in zip(dx,dy))/math.sqrt(xx*yy)

def bonferroni(alpha,n):
    if type(alpha) not in (int,float) or not math.isfinite(alpha) or not 0<alpha<1 or type(n) is not int or n<1:
        raise ValueError("invalid arguments")
    return alpha/n

class ReferenceTests(unittest.TestCase):
    def test_01(self): self.assertEqual(mean([1,2,3]),2)
    def test_02(self): self.assertAlmostEqual(sd([.01,.02,.03]),.01)
    def test_03(self): self.assertAlmostEqual(cumulative([.1,-.1]),-.01)
    def test_04(self): self.assertEqual(rolling([1,2,3,4],2),[1.5,2.5,3.5])
    def test_05(self): self.assertAlmostEqual(corr([1,2,3],[2,4,6]),1)
    def test_06(self): self.assertAlmostEqual(corr([1,2,3],[6,4,2]),-1)
    def test_07(self): self.assertAlmostEqual(bonferroni(.05,20),.0025)
    def test_08(self): self.assertAlmostEqual(bonferroni(.05,1),.05)
    def test_09(self): self.assertEqual(cumulative([.1,-1]),-1)
    def test_10(self): self.assertEqual(rolling([1,2,3],3),[2])
    def test_11(self): self.assertAlmostEqual(sd([1,2,3]),1)
    def test_12(self):
        for fn in (lambda:mean([]),lambda:sd([1]),lambda:cumulative([-1.01]),
                   lambda:rolling([1,2],0),lambda:corr([1,1,1],[1,2,3]),
                   lambda:bonferroni(.05,0)):
            with self.assertRaises(ValueError):fn()

if __name__=="__main__":
    unittest.main(verbosity=2)
```
