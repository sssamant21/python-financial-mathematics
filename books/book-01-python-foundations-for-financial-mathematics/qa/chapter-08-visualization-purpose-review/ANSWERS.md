# Section 8.1 — Alignment of prompts and answer guidance

| Exercise | Reviewed answer | Evidence type |
|---|---|---|
| 1. Same endpoint, different experience | 120/100, 240/200 and 60/50 all equal 6/5. DIP initially falls to 160/200 = 4/5; CALM increases across supplied points; GAP is missing at day 4. The observed points do not establish any intervening path. | Exact source and rational table |
| 2. Index 80 to 92 | Using 80 as base, 92/80 = 23/20. Index = 115 and endpoint return = 3/20 = 15%. | Independent arithmetic |
| 3. Multiply DIP by seven | Raw quotes become seven times larger; the scale cancels in each base and adjacent ratio. Both transformed arrays matched within tolerance. | Exact source with controlled input |
| 4. Drop day 4 | GAP now has a day 1→5 interval: 56/49 − 1 = 1/7. It spans four days and cannot recover either missing original interval. | Exact source with controlled input and rational ratio |
| 5. Categories versus elapsed days | The actual spacings 1, 3, 1, 3 days would become four equal spacings. Event order survives, but calendar duration and apparent slope per day do not. | Artist coordinates and interpretation |
| 6. Frequency of negative returns | A count table or distribution of defined returns answers the question directly. Report negative count and eligible interval count, and stratify by interval duration or justify combining horizons. Do not count missing returns as zero. | Chart selection review |
| 7. Total return or annualized volatility | Price-only ratios omit distributions and other cash effects; four irregular intervals with gaps provide no validated annualization policy or useful volatility estimate. | Financial scope review |
| 8. Automated and visual checks | Check the first DIP marker numerically at −20%; inspect exported labels, units, shape coding and gap readability separately. An image file signature alone proves none of those presentation properties. | Exact artists and visual inspection |
