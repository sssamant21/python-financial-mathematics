## 5.12.1 Project Brief

Turn a reviewed financial transformation into an installable local package. The package must expose a reusable API, provide two command-line launch mechanisms, declare its build requirements, and pass tests against a regular installed wheel outside the source directory.

This project packages the bounded synthetic USD inflow calculation from Section 5.11. It integrates the chapter's modules, packages, dependency boundaries, environment isolation, layout, explicit configuration, and reproducibility evidence. It does not upload a distribution or connect to a financial service.

## 5.12.3 Public and Financial Contracts

The public function is analyze(data_raw: bytes, config_raw: bytes) -> dict. It consumes UTF-8 JSON and returns currency, count, formatted total, method, and rounding. Its implementation performs no filesystem or network I/O and does not mutate caller inputs or the caller's Decimal context.

The input is a list of 1–1,000 records with exactly id, currency, and amount. IDs are unique nonempty unpadded strings. Currency is USD. Amounts are nonnegative ordinary decimal strings with up to four fractional digits and seven integer digits, each no greater than 1,000,000. Numeric JSON amounts, exponent text, negative values, nonfinite values, extra fields, and duplicate JSON members fail.

Configuration must equal the supplied object: currency USD, rounding ROUND_HALF_EVEN, scale 0.01, all represented as text. There are no implicit environment overrides. The result sums full input precision before rounding once. The synthetic 10.005 and 20.005 inputs therefore produce USD 30.01. Rounding each input first would implement a different contract.

This is a same-currency inflow aggregation without time information. It is not present value, FX conversion, net cash flow with outflows, or a profitability measure. The supported bounds fit comfortably within the fresh precision-28 Decimal context used by the implementation.

## 5.12.11 File — src/financial_inflows/core.py

```python
"""Bounded same-currency inflow aggregation; no I/O or global context mutation."""
from decimal import Context, Decimal, ROUND_HALF_EVEN, localcontext
import json
import re

def unique_object(pairs):
    result = {}
    for key, value in pairs:
        if key in result:
            raise ValueError('duplicate JSON member')
        result[key] = value
    return result


def decode(raw: bytes):
    return json.loads(raw.decode('utf-8'), object_pairs_hook=unique_object)


def analyze(data_raw: bytes, config_raw: bytes) -> dict:
    config = decode(config_raw)
    if config != {'currency': 'USD', 'rounding': 'ROUND_HALF_EVEN', 'scale': '0.01'}:
        raise ValueError('unsupported configuration')
    rows = decode(data_raw)
    if type(rows) is not list or not 1 <= len(rows) <= 1000:
        raise ValueError('expected 1 to 1000 inflows')
    seen = set()
    amounts = []
    for row in rows:
        if type(row) is not dict or set(row) != {'id', 'currency', 'amount'}:
            raise ValueError('incorrect inflow schema')
        sid = row['id']
        if type(sid) is not str or not sid or sid.strip() != sid or sid in seen:
            raise ValueError('invalid or duplicate id')
        if row['currency'] != 'USD':
            raise ValueError('mixed or unsupported currency')
        text = row['amount']
        if type(text) is not str or re.fullmatch(r'(0|[1-9][0-9]{0,6})(\.[0-9]{1,4})?', text) is None:
            raise ValueError('invalid amount text')
        value = Decimal(text)
        if value > Decimal('1000000'):
            raise ValueError('inflow exceeds lab bound')
        seen.add(sid)
        amounts.append(value)
    # A fresh context prevents caller precision, rounding, or flags from leaking in.
    with localcontext(Context(prec=28, rounding=ROUND_HALF_EVEN)):
        total = sum(amounts, Decimal('0'))
        rounded = total.quantize(Decimal('0.01'))
    return {'currency': 'USD', 'count': len(rows), 'total': format(rounded, '.2f'),
            'method': 'sum_then_round', 'rounding': 'ROUND_HALF_EVEN'}


```

## 5.12.12 File — src/financial_inflows/cli.py

```python
"""Read explicit files and emit a validated summary."""
import argparse
import json
from pathlib import Path
from .core import analyze


def main(argv=None) -> int:
    parser = argparse.ArgumentParser(description=__doc__, allow_abbrev=False)
    parser.add_argument('--input', type=Path, required=True)
    parser.add_argument('--config', type=Path, required=True)
    args = parser.parse_args(argv)
    result = analyze(args.input.read_bytes(), args.config.read_bytes())
    print(json.dumps(result, sort_keys=True, allow_nan=False))
    return 0
```

## 5.12.16 File — tests/test_inflows.py

```python
from decimal import Inexact, ROUND_DOWN, localcontext
from importlib.metadata import version
import json
import unittest
from financial_inflows import analyze

CONFIG = b'{"currency":"USD","rounding":"ROUND_HALF_EVEN","scale":"0.01"}'
DATA = b'[{"id":"A","currency":"USD","amount":"10.005"},{"id":"B","currency":"USD","amount":"20.005"}]'

class InflowTests(unittest.TestCase):
    def test_known_answer(self):
        self.assertEqual(analyze(DATA, CONFIG), {'currency':'USD','count':2,'total':'30.01',
                         'method':'sum_then_round','rounding':'ROUND_HALF_EVEN'})

    def test_metadata(self):
        self.assertEqual(version('book1-financial-inflows'), '0.1.0')

    def test_context_isolation(self):
        with localcontext() as context:
            context.prec = 2
            context.rounding = ROUND_DOWN
            context.traps[Inexact] = True
            self.assertEqual(analyze(DATA, CONFIG)['total'], '30.01')
            self.assertEqual(context.prec, 2)

    def test_amount_contract(self):
        for amount in ('NaN', '-1', '1e2', ' 1', '1000001', '1.00001', 1, None):
            with self.subTest(amount=amount), self.assertRaises(ValueError):
                analyze(json.dumps([{'id':'A','currency':'USD','amount':amount}]).encode(), CONFIG)

    def test_identity_and_currency(self):
        rows = json.loads(DATA)
        for invalid in (rows*2, [dict(rows[0], currency='EUR')], [dict(rows[0], id=' A')], [{}]):
            with self.assertRaises(ValueError):
                analyze(json.dumps(invalid).encode(), CONFIG)

    def test_schema_and_configuration(self):
        for invalid in (b'[]', b'null', b'[{"id":"A","id":"B"}]'):
            with self.assertRaises(ValueError):
                analyze(invalid, CONFIG)
        with self.assertRaises(ValueError):
            analyze(DATA, CONFIG.replace(b'0.01',b'0.1'))

    def test_bounds(self):
        rows = [{'id':str(i),'currency':'USD','amount':'1000000'} for i in range(1000)]
        self.assertEqual(analyze(json.dumps(rows).encode(), CONFIG)['total'], '1000000000.00')
        rows.append({'id':'extra','currency':'USD','amount':'0'})
        with self.assertRaises(ValueError):
            analyze(json.dumps(rows).encode(), CONFIG)

    def test_input_bytes_unchanged(self):
        before = (DATA, CONFIG)
        analyze(DATA, CONFIG)
        self.assertEqual((DATA, CONFIG), before)

if __name__ == '__main__':
    unittest.main(verbosity=2)
```

## 5.12.17 File — verify_package.py

```python
"""Build and test a regular wheel using temporary local environments."""
import hashlib
from importlib.metadata import version
import json
import os
from pathlib import Path
import shutil
import subprocess
import sys
from tempfile import TemporaryDirectory
import venv

ROOT = Path(__file__).resolve().parent


def run(command, cwd, env):
    result = subprocess.run([str(item) for item in command], cwd=cwd, env=env,
                            capture_output=True, text=True, timeout=120)
    if result.returncode:
        raise RuntimeError(result.stdout + result.stderr)
    return result


def main():
    if version('setuptools') != '84.0.0':
        raise RuntimeError('Prepare builder with setuptools==84.0.0')
    env = os.environ.copy()
    env.pop('PYTHONPATH', None)
    env.pop('PYTHONHOME', None)
    with TemporaryDirectory(prefix='book1-package-') as directory:
        work = Path(directory)
        wheels = work / 'wheels'
        run([sys.executable, '-m', 'pip', '--isolated', 'wheel', ROOT,
             '--no-index', '--no-deps', '--no-build-isolation', '--wheel-dir', wheels], work, env)
        candidates = list(wheels.glob('*.whl'))
        if len(candidates) != 1:
            raise RuntimeError('expected exactly one wheel')
        wheel = candidates[0]
        target = work / 'runtime'
        venv.EnvBuilder(with_pip=True).create(target)
        scripts = target / ('Scripts' if os.name == 'nt' else 'bin')
        python = scripts / ('python.exe' if os.name == 'nt' else 'python')
        run([python, '-m', 'pip', '--isolated', 'install', '--no-index', '--no-deps', wheel], work, env)
        run([python, '-m', 'pip', 'check'], work, env)
        outside = work / 'outside'
        outside.mkdir()
        shutil.copyfile(ROOT/'tests/test_inflows.py', outside/'test_inflows.py')
        origin_code = (
            'from pathlib import Path; import sysconfig, financial_inflows; '
            'origin=Path(financial_inflows.__file__).resolve(); '
            'purelib=Path(sysconfig.get_path("purelib")).resolve(); '
            'assert purelib in origin.parents, (origin, purelib); print(origin)'
        )
        origin = run([python, '-I', '-c', origin_code], outside, env).stdout.strip()
        tests = run([python, '-I', '-m', 'unittest', 'discover', '-s', str(outside), '-v'], outside, env)
        print(tests.stdout + tests.stderr, end='')
        arguments = ['--input', ROOT/'fixtures/inflows.json', '--config', ROOT/'fixtures/settings.json']
        module = run([python, '-I', '-m', 'financial_inflows', *arguments], outside, env)
        console = scripts / ('financial-inflows.exe' if os.name == 'nt' else 'financial-inflows')
        entry = run([console, *arguments], outside, env)
        expected = {'currency':'USD','count':2,'total':'30.01','method':'sum_then_round',
                    'rounding':'ROUND_HALF_EVEN'}
        if json.loads(module.stdout) != expected or module.stdout != entry.stdout:
            raise RuntimeError('CLI mismatch')
        bad = subprocess.run([str(python), '-I', '-m', 'financial_inflows'],
                             cwd=outside, env=env, capture_output=True, text=True, timeout=10)
        if bad.returncode == 0 or bad.stdout:
            raise RuntimeError('missing arguments must fail without report')
        print('Installed origin:', origin)
        print('Wheel SHA-256:', hashlib.sha256(wheel.read_bytes()).hexdigest())
        print('PASS: 8 installed tests; module and console CLI; argument failure; pip check')
    print('Temporary wheel and runtime removed')


if __name__ == '__main__':
    main()
```

## 5.12.18 Prepare the Builder

## 5.12.19 Read the Acceptance Evidence

A successful run prints eight discovered installed tests, a package origin beneath the temporary runtime's site-packages directory, a wheel SHA-256 digest, and:


Temporary paths and the wheel digest vary. Wheel archive timestamps and build metadata can change even when runtime behavior agrees; this project does not compare separate wheel builds byte for byte.

The copied tests import the installed package. The test process uses isolated Python mode, an external discovery directory, and no source path edits. A separate origin check verifies that the package resolves under the runtime's purelib directory. Together these checks address the working-tree import gap discussed in Section 5.9.

The console entry point is generated during installation from project.scripts. Both it and python -m financial_inflows invoke the same CLI function and produce the expected total. The CLI prints only after complete validation. The missing-argument check verifies a nonzero failure without a successful stdout report.

The driver removes PYTHONPATH and PYTHONHOME from its child-process environment. The module/test invocations also use -I. It is designed for a controlled local lab; it is not a sandbox against hostile process configuration or an untrusted build backend. Build and test only source you intend to execute.

## 5.12.20 What Each Test Adds

| Check | Defect it can expose |
|---|---|
| Known answer | Wrong total, output schema, or rounding stage |
| Distribution metadata | Missing or incorrect installed distribution version |
| Context isolation | Hidden caller precision or traps influence calculation |
| Amount contract | Unsupported text or JSON types accepted |
| Identity and currency | Duplicate IDs or mixed units aggregated |
| Schema/configuration | Unrecognized policy or malformed records accepted |
| Bounds | Maximum dataset fails or oversized dataset slips through |
| Input stability | Public call changes caller-provided input values |
| External installed import | Local source masks incomplete package installation |
| CLI parity and failure | Broken entry point or misleading successful invocation |

Tests are evidence for specific contracts. They do not replace code review or validate every possible malformed byte sequence. Keep error types, output schema, and public import paths deliberate when extending the library.

## 5.12.21 Retain an Artifact for Reuse

The acceptance driver intentionally deletes its temporary wheel and runtime. To retain a wheel for another environment, build into a dedicated dist directory with the same prepared builder:

```bash
python -m pip --isolated wheel . --no-index --no-deps --no-build-isolation --wheel-dir dist
```

Here python means the prepared builder interpreter; use its explicit path on your platform. Record its pip/backend versions and hash the retained wheel. Build into an empty output directory so an older artifact is not mistaken for the current one.

Install that exact wheel into the intended clean runtime with `python -m pip --isolated install --no-index --no-deps /absolute/path/to/file.whl`, replacing the placeholder with the real retained wheel path and using that runtime's interpreter. Validate the installed artifact before sharing it. No package-index upload is part of this project.

The driver builds directly from the project directory. It does not test a source-distribution rebuild, dependency updates, signed release provenance, public metadata completeness, or a platform/version matrix. Those are separate release workflow decisions.
