## 1. What makes an annuity level?

A **level annuity** is a sequence of equal cash-flow amounts at regularly spaced dates. For a payment amount \\(C\\) and \\(n\\) periods, a typical ordinary-annuity timeline is:

```text
Period       0       1       2       3       ...       n
             |-------|-------|-------|----------------|
Payment              C       C       C                C
```

The defining feature is the **constant payment amount**. The schedule must also specify the payment interval and whether payments occur at the beginning or end of each interval. A level annuity is not necessarily an ordinary annuity; later sections distinguish ordinary annuities, annuities due, and deferred annuities.

A periodic interest rate \\(i\\) must match the payment interval. A monthly payment schedule requires a monthly rate; an effective annual rate must be converted before use with monthly periods.

## 2. Present value of a finite level ordinary annuity

For \\(n\\) equal end-of-period payments \\(C\\), with constant periodic rate \\(i>-1\\):

\\[PV=\\sum_{k=1}^{n}\\frac{C}{(1+i)^k}.\\]

For \\(i\\ne0\\), use the geometric-series identity:

\\[\\boxed{PV=C\\frac{1-(1+i)^{-n}}{i}}.\\]

At \\(i=0\\), the limit is \\(PV=nC\\). If \\(n=0\\), the value is zero.

### Worked example

Three annual end-of-year receipts of 100 USD discounted at 10% effective annually:

\\[PV=\\frac{100}{1.10}+\\frac{100}{1.10^2}+\\frac{100}{1.10^3}\\approx248.6852\\text{ USD}.\\]

The timeline calculation and the geometric formula must agree.

## 3. Future value of a level ordinary annuity

Accumulate every payment to the end of period \\(n\\):

\\[FV=\\sum_{k=1}^{n}C(1+i)^{n-k}.\\]

For nonzero \\(i\\):

\\[\\boxed{FV=C\\frac{(1+i)^n-1}{i}}.\\]

At zero interest, \\(FV=nC\\). The consistency relationship is

\\[FV=PV(1+i)^n.\\]

For three end-of-year payments of 100 USD at 10% per year, \\(FV=100(1+1.1+1.1^2)=331\\) USD.

## 4. Financial interpretation and edge cases

- **Payment sign:** A depositor's contribution is an outflow from the depositor's perspective, but an inflow into the savings account. Choose and document the viewpoint.
- **Zero rate:** The present and future values equal the undiscounted sum of the payments.
- **Negative periodic rate:** The formula still works for \\(-1<i<0\\), though the economics and use case should be explained.
- **Fractional periods:** This section models an integer number of equal payments. A partial final payment requires an explicit additional cash flow rather than silently treating \\(n\\) as fractional.
- **Rounding:** Avoid rounding individual discounted payments before summation. Financial accounting may require a separate fixed-point rounding policy.
- **Not a perpetuity:** A level annuity has finitely many payments. Perpetuities are treated later.

## 5. Stable numerical implementation

Directly calculating \\((1+i)^n-1\\) can lose precision when \\(i\\) is very small. The reference implementation uses `math.log1p(i)` and `math.expm1(x)` for more stable results. It validates payment amounts, rates, and integer payment counts and checks the finite results.

```python
"""Chapter 10.3: level annuity foundations and reference tests."""
import math
import unittest

def validate(payment, rate, periods):
    if isinstance(periods, bool) or not isinstance(periods, int):
        raise TypeError("periods must be an integer")
    if periods < 0:
        raise ValueError("periods must be nonnegative")
    for label, value in (("payment",payment),("periodic rate",rate)):
        if isinstance(value,bool) or not isinstance(value,(int,float)):
            raise TypeError(f"{label} must be numeric")
        if not math.isfinite(value):
            raise ValueError(f"{label} must be finite")
    if rate <= -1:
        raise ValueError("periodic growth factor must be positive")

def level_cash_flows(payment, periods, first_period=1):
    if isinstance(periods,bool) or not isinstance(periods,int) or periods < 0:
        raise ValueError("periods must be a nonnegative integer")
    if isinstance(first_period,bool) or not isinstance(first_period,int) or first_period < 0:
        raise ValueError("first_period must be a nonnegative integer")
    if isinstance(payment,bool) or not isinstance(payment,(int,float)) or not math.isfinite(payment):
        raise ValueError("payment must be finite")
    return [(first_period+k,payment) for k in range(periods)]

def pv_from_timeline(payment, rate, periods, first_period=1):
    validate(payment,rate,periods)
    flows=level_cash_flows(payment,periods,first_period)
    total=math.fsum(amount*math.exp(-t*math.log1p(rate)) for t,amount in flows)
    if not math.isfinite(total):
        raise ValueError("PV outside supported range")
    return total

def pv_level_ordinary(payment, rate, periods):
    validate(payment,rate,periods)
    if periods == 0:
        return 0.0
    if rate == 0:
        return payment*periods
    # Numerically stable when rate is small.
    result=payment*(-math.expm1(-periods*math.log1p(rate)))/rate
    if not math.isfinite(result):
        raise ValueError("PV outside supported range")
    return result

def fv_level_ordinary(payment, rate, periods):
    validate(payment,rate,periods)
    if periods == 0:
        return 0.0
    if rate == 0:
        return payment*periods
    result=payment*math.expm1(periods*math.log1p(rate))/rate
    if not math.isfinite(result):
        raise ValueError("FV outside supported range")
    return result

class AnnuityTests(unittest.TestCase):
    def test_01_equal_payments(self):
        self.assertEqual(level_cash_flows(100,3),[(1,100),(2,100),(3,100)])
    def test_02_ordinary_pv(self):
        self.assertAlmostEqual(pv_level_ordinary(100,.1,3),
                               100/1.1+100/1.1**2+100/1.1**3)
    def test_03_ordinary_fv(self):
        self.assertAlmostEqual(fv_level_ordinary(100,.1,3),331)
    def test_04_zero_rate(self):
        self.assertEqual(pv_level_ordinary(100,0,3),300)
        self.assertEqual(fv_level_ordinary(100,0,3),300)
    def test_05_empty(self):
        self.assertEqual(pv_level_ordinary(100,.1,0),0)
    def test_06_negative_rate(self):
        self.assertAlmostEqual(pv_level_ordinary(100,-.1,2),
                               100/.9+100/.9**2)
    def test_07_timeline_crosscheck(self):
        self.assertAlmostEqual(pv_from_timeline(100,.08,12),
                               pv_level_ordinary(100,.08,12))
    def test_08_shifted_timeline(self):
        self.assertAlmostEqual(pv_from_timeline(100,.1,3,2),
                               pv_level_ordinary(100,.1,3)/1.1)
    def test_09_pv_fv_identity(self):
        self.assertAlmostEqual(fv_level_ordinary(200,.05,6),
                               pv_level_ordinary(200,.05,6)*1.05**6)
    def test_10_invalid_inputs(self):
        with self.assertRaises(ValueError): pv_level_ordinary(100,-1,2)
        with self.assertRaises(TypeError): pv_level_ordinary(100,.05,2.5)
        with self.assertRaises(ValueError): level_cash_flows(100,2,-1)
        with self.assertRaises(TypeError): fv_level_ordinary(True,.05,2)

if __name__=="__main__":
    print(f"PV: {pv_level_ordinary(100,.08,5):.2f}")
    print(f"FV: {fv_level_ordinary(100,.08,5):.2f}")
    unittest.main(verbosity=2)
```

## 7. Exercises with answers

1. **Definition:** What is a level annuity? **Answer:** Equal payment amounts made at regularly spaced intervals over a defined finite term.
2. **Schedule:** List three end-of-period payments of 100 USD. **Answer:** `[(1,100),(2,100),(3,100)]`.
3. **PV:** Find the present value of three 100 USD annual end-of-year payments at 10%. **Answer:** Approximately 248.6852 USD.
4. **FV:** Find the future value of those payments at year three. **Answer:** 331 USD.
5. **Zero rate:** Find the PV of five payments of 200 USD at 0%. **Answer:** 1,000 USD.
6. **Rate convention:** A 6% nominal annual rate convertible monthly implies what monthly periodic rate? **Answer:** \\(0.06/12=0.005\\), or 0.5% per month.
7. **Negative rate:** Two annual payments of 100 USD at -10% periodic rate. **Answer:** \\(100/0.9+100/0.9^2\\approx234.5679\\) USD.
8. **Shifted payments:** Move three 100 USD payments from years 1–3 to years 2–4 at 10%. **Answer:** Discount the original ordinary-annuity PV by one more period: \\(248.6852/1.1\\approx226.0775\\) USD.
9. **PV/FV check:** How do you reconcile PV and FV? **Answer:** Multiply the ordinary-annuity PV by \\((1+i)^n\\).
10. **Error handling:** Why reject a payment count of 2.5? **Answer:** The model assumes a discrete integer count of payments; any stub payment needs its own schedule.
