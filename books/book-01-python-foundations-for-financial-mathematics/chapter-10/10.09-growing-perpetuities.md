## 1. Definition and timing

A growing perpetuity models a stream of payments that changes by a constant rate **g** each period and continues indefinitely. This section first assumes an **ordinary growing perpetuity**: its first payment, **C1**, occurs at the end of period 1.

```text
Time           0       1          2              3          ...
               |-------|----------|--------------|----------->
Payment                C1      C1(1+g)       C1(1+g)^2       ...
```

The amount **C1** is the payment at time 1. If the latest payment **C0** was made at time 0, the next payment is C1 = C0(1+g). Substituting C0 directly into a formula that expects C1 understates or overstates the value.

## 2. Infinite-series derivation

With a constant periodic effective discount rate **i** and periodic growth rate **g**, the present value at time 0 is

PV = C1/(1+i) + C1(1+g)/(1+i)^2 + C1(1+g)^2/(1+i)^3 + ...

Factor C1/(1+i). The common ratio is q = (1+g)/(1+i).

For economically standard growth factors, assume **g > -1** and **i > g**. Then 0 < q < 1 and the geometric series converges. Its sum simplifies to

**PV = C1/(i-g)**.

This is sometimes called the constant-growth or Gordon-growth perpetuity model. Its mathematical convergence condition is essential: **i must be strictly greater than g**. The formula is not valid as a finite infinite-stream valuation when i = g or i < g.

## 3. Worked example

Suppose the first annual payment will be **$100 at the end of year 1**, annual payment growth is 3%, and the effective annual discount rate is 8%.

PV = 100/(0.08 - 0.03) = **$2,000**.

If the **last** payment was $100 at time 0 instead, the next payment is $103 and the value becomes 103/(0.08 - 0.03) = **$2,060**. Identifying which payment the quoted amount represents is therefore a required valuation control.

## 4. Finite growing annuity as a convergence check

For n payments, the finite growing-annuity formula is

PV(n) = C1 × [1 - ((1+g)/(1+i))^n] / (i-g).

Under i > g and g > -1, the ratio term tends to zero as n increases, yielding

**lim PV(n) = C1/(i-g)**.

For positive C1, every finite truncation has lower present value than the corresponding infinite stream. The Python lab checks this convergence numerically.

## 5. Beginning-of-period growing perpetuity

A **growing perpetuity due** begins with payment **C0 at time 0**, followed by C0(1+g) at time 1, C0(1+g)^2 at time 2, and so forth.

The time-zero payment is not discounted. The remaining payments form an ordinary growing perpetuity whose first payment is C0(1+g):

**PV_due = C0 + C0(1+g)/(i-g) = C0(1+i)/(i-g).**

For C0 = $100, i = 8%, and g = 3%, PV_due = 100 + 103/0.05 = **$2,160**.

This differs from the ordinary perpetuity with C1 = $100, which is worth $2,000.

## 6. Deferred growing perpetuity

Let d be the number of complete periods before the ordinary growing perpetuity begins. The first payment **C1** occurs at period d+1; subsequent payments grow by g.

The value at time d is C1/(i-g). Discount d periods back to time zero:

**PV_deferred = [C1/(i-g)] × (1+i)^(-d).**

For C1 = $100, i = 8%, g = 3%, and d = 2, PV = 2000/1.08², approximately **$1,714.68**. Payment dates start at periods 3, 4, 5, ...

## 7. Sensitivity, assumptions, and risk

The denominator i-g is the **discount-growth spread**. As this positive spread becomes small, model value becomes highly sensitive to small changes in assumptions. This sensitivity is not a prediction of future prices or guaranteed cash flows.

The constant-growth perpetuity assumes indefinite growth, stable rates, deterministic payment amounts, and a consistent time interval. Real dividends, rental income, pensions, and endowments may change, stop, or face credit and operational risks. High growth rates cannot generally continue indefinitely in an unconstrained economy; use finite high-growth stages followed by a defensible terminal-growth assumption when appropriate.

The standard-library reference lab includes **12 unit tests** for ordinary and due valuation, declining payments, finite convergence, deferral, inverse payment, signs, zero periods, and invalid growth/discount relationships.

```python
import math
import unittest

def pv(first, discount, growth):
    for x in (first, discount, growth):
        if isinstance(x, bool) or not isinstance(x, (int, float)) or not math.isfinite(x):
            raise ValueError("finite numeric inputs required")
    if growth <= -1 or discount <= growth:
        raise ValueError("require growth > -1 and discount > growth")
    value = first / (discount - growth)
    if not math.isfinite(value):
        raise ValueError("value overflow")
    return value

def finite_pv(first, discount, growth, periods):
    pv(first, discount, growth)
    if isinstance(periods, bool) or not isinstance(periods, int) or periods < 0:
        raise ValueError("periods must be nonnegative integer")
    if periods == 0:
        return 0.0
    x = periods * (math.log1p(growth) - math.log1p(discount))
    result = first * (-math.expm1(x)) / (discount-growth)
    if not math.isfinite(result):
        raise ValueError("finite PV overflow")
    return result

def due_pv(first_now, discount, growth):
    return first_now + pv(first_now*(1+growth), discount, growth)

def deferred_pv(first, discount, growth, delay):
    if isinstance(delay, bool) or not isinstance(delay, int) or delay < 0:
        raise ValueError("delay must be nonnegative integer")
    result = pv(first, discount, growth) * math.exp(-delay*math.log1p(discount))
    if not math.isfinite(result):
        raise ValueError("deferred PV overflow")
    return result

class Tests(unittest.TestCase):
    def test_01_basic(self):
        self.assertAlmostEqual(pv(100,.08,.03),2000)
    def test_02_zero_growth(self):
        self.assertAlmostEqual(pv(100,.05,0),2000)
    def test_03_declining(self):
        self.assertAlmostEqual(pv(100,.05,-.02),100/.07)
    def test_04_finite_limit(self):
        self.assertAlmostEqual(finite_pv(100,.08,.03,1000),pv(100,.08,.03),places=5)
    def test_05_finite_less(self):
        self.assertLess(finite_pv(100,.08,.03,20),pv(100,.08,.03))
    def test_06_due(self):
        self.assertAlmostEqual(due_pv(100,.08,.03),100+103/.05)
    def test_07_deferred(self):
        self.assertAlmostEqual(deferred_pv(100,.08,.03,2),2000/1.08**2)
    def test_08_inverse(self):
        self.assertAlmostEqual(pv(2000*(.08-.03),.08,.03),2000)
    def test_09_signed(self):
        self.assertAlmostEqual(pv(-100,.08,.03),-2000)
    def test_10_zero_periods(self):
        self.assertEqual(finite_pv(100,.08,.03,0),0)
    def test_11_invalid_rates(self):
        with self.assertRaises(ValueError): pv(100,.03,.03)
        with self.assertRaises(ValueError): pv(100,.02,.03)
        with self.assertRaises(ValueError): pv(100,.05,-1)
    def test_12_invalid_delay(self):
        with self.assertRaises(ValueError): deferred_pv(100,.08,.03,-1)

if __name__ == "__main__":
    unittest.main(verbosity=2)
```

## 9. Exercises with worked answers

1. **First payment:** What does C1 represent? **Answer:** The payment at the end of period 1.
2. **PV:** Find PV with C1 = $100, i = 8%, g = 3%. **Answer:** $2,000.
3. **Latest versus next payment:** If C0 = $100 and g = 3%, what is C1? **Answer:** $103.
4. **Updated valuation:** Value that stream with i = 8%. **Answer:** $2,060.
5. **Convergence:** What condition is required for a finite growing-perpetuity value? **Answer:** i > g, assuming g > -1.
6. **Equal rates:** Can C1/(i-g) be used when i = g? **Answer:** No; the infinite series does not converge.
7. **Declining stream:** Find PV when C1 = $100, i = 5%, g = -2%. **Answer:** 100/0.07, approximately $1,428.57.
8. **Due timing:** Find PV when the first $100 payment is immediate, i = 8%, and g = 3%. **Answer:** $2,160.
9. **Deferral:** Value C1 = $100 starting at year 3, i = 8%, g = 3%. **Answer:** 2000/1.08², approximately $1,714.68.
10. **Inverse payment:** What C1 corresponds to PV $2,000 at i = 8%, g = 3%? **Answer:** $100.
11. **Sensitivity:** What happens as i-g approaches zero from above? **Answer:** The model value increases sharply.
12. **Audit:** How can the formula be checked? **Answer:** Compute finite growing-annuity PV for increasing n and compare its limit to C1/(i-g).
