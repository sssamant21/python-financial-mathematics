## Learning objectives

Define a level perpetuity, derive its present-value formula as a convergent geometric series, distinguish ordinary and due timing, model a deferred perpetuity, and validate the limiting relationship between finite annuities and perpetuities using Python.

## 1. What is a perpetuity?

A **level perpetuity** is a modeled stream of equal payments continuing indefinitely at regular intervals. An ordinary perpetuity pays at the end of periods 1, 2, 3, and so on. Unlike a finite annuity, it has no last payment date.

```text
Time         0       1       2       3       4       ...
             |-------|-------|-------|-------|------->
Payment              C       C       C       C       ...
```

Perpetuity valuation is a mathematical model. Real-world payments may stop, change, default, or be renegotiated. A model assuming infinitely many payments should not be interpreted as a guarantee of perpetual receipts.

## 2. Derive present value using an infinite series

Let C be the constant payment at the end of each period and i the constant **periodic effective discount rate**.

The present value is:

PV = C/(1+i) + C/(1+i)^2 + C/(1+i)^3 + ...

This is a geometric series with first term C/(1+i) and common ratio 1/(1+i). For a positive rate i, the ratio is between zero and one, so the series converges:

**PV = C / i**, provided **i > 0**.

For i = 0 and nonzero C, the series does not converge to a finite value. For -1 < i < 0 and nonzero C, discounted payment magnitudes grow and the series also fails to converge. The formula must not be used for those cases. A zero payment stream is trivially zero, but this lab intentionally requires a positive discount rate for its perpetuity valuation API.

## 3. Worked example: constant annual payment

Suppose a modeled end-of-year cash flow pays $100 annually forever and the effective annual discount rate is 5%.

PV = 100/0.05 = **$2,000**.

The inverse relationships are:

- Payment required for target PV: **C = PV × i**.
- Implied rate under this simplified model: **i = C/PV**, provided PV is nonzero and the sign conventions are consistent.

The model excludes credit risk, changing rates, taxes, and payment uncertainty.

## 4. Finite annuities approach the perpetuity limit

The present value of n ordinary-annuity payments is:

PV(n) = C × [1 - (1+i)^(-n)] / i.

As n approaches infinity and i > 0, the term (1+i)^(-n) approaches zero. Therefore:

**lim PV(n) = C/i**.

At C = $100 and i = 5%, increasing the number of payments makes finite-annuity PV approach $2,000 from below. This is an important numerical consistency test.

## 5. Perpetuity due

A perpetuity due begins **immediately**, with payments at periods 0, 1, 2, and so on. Relative to the ordinary perpetuity, every payment is shifted one period earlier.

**PV_due = PV_ordinary × (1+i) = C(1+i)/i = C + C/i.**

For C = $100 and i = 5%, PV_due = $2,100. The difference is the additional $100 payment at time zero.

## 6. Deferred perpetuity

Let d be the number of complete periods of deferral before an ordinary perpetuity begins. Its first payment occurs at period d+1.

**PV_deferred = (C/i) × (1+i)^(-d).**

For C = $100, i = 5%, and d = 2, the first payment is at period 3 and PV = 2000/1.05², approximately **$1,814.06**.

Always state the first payment date explicitly because deferral terminology can vary between contracts.

## 7. Rate conventions and limitations

The rate must match the payment interval. Monthly perpetuity payments require a monthly effective rate, not an unconverted annual rate. For a nominal annual rate convertible monthly, the monthly rate is the nominal rate divided by 12; for an effective annual rate, convert with (1+i_annual)^(1/12)-1.

A perpetuity has no finite future value at a last payment date, because no such last date exists. For large or small rates, floating-point overflow or precision limits must be checked. Real financial valuation often requires a term structure of discount rates and credit-adjusted expected cash flows rather than one constant rate.

```python
"""Level perpetuities: present value, convergence, and tests."""
import math
import unittest

def check(payment, rate):
    for name, value in (("payment", payment), ("rate", rate)):
        if isinstance(value, bool) or not isinstance(value, (int, float)):
            raise TypeError(f"{name} must be numeric")
        if not math.isfinite(value):
            raise ValueError(f"{name} must be finite")
    if rate <= 0:
        raise ValueError("positive periodic discount rate required")

def perpetuity_pv(payment, rate):
    check(payment, rate)
    result = payment / rate
    if not math.isfinite(result):
        raise ValueError("value outside supported range")
    return result

def finite_annuity_pv(payment, rate, periods):
    check(payment, rate)
    if isinstance(periods, bool) or not isinstance(periods, int):
        raise TypeError("periods must be integer")
    if periods < 0:
        raise ValueError("periods must be nonnegative")
    if periods == 0:
        return 0.0
    result = payment * (-math.expm1(-periods*math.log1p(rate))) / rate
    if not math.isfinite(result):
        raise ValueError("value outside supported range")
    return result

def perpetuity_due_pv(payment, rate):
    check(payment, rate)
    result = perpetuity_pv(payment, rate) * (1 + rate)
    if not math.isfinite(result):
        raise ValueError("value outside supported range")
    return result

def deferred_perpetuity_pv(payment, rate, delay):
    check(payment, rate)
    if isinstance(delay, bool) or not isinstance(delay, int):
        raise TypeError("delay must be integer")
    if delay < 0:
        raise ValueError("delay must be nonnegative")
    factor = math.exp(-delay * math.log1p(rate))
    result = perpetuity_pv(payment, rate) * factor
    if not math.isfinite(result):
        raise ValueError("value outside supported range")
    return result

class PerpetuityTests(unittest.TestCase):
    def test_01_basic(self):
        self.assertAlmostEqual(perpetuity_pv(100,.05),2000)
    def test_02_payment_inverse(self):
        self.assertAlmostEqual(perpetuity_pv(2000*.05,.05),2000)
    def test_03_rate_inverse(self):
        self.assertAlmostEqual(100/perpetuity_pv(100,.05),.05)
    def test_04_finite_approach(self):
        self.assertAlmostEqual(finite_annuity_pv(100,.05,1000),
                               perpetuity_pv(100,.05),places=6)
    def test_05_finite_below_infinite(self):
        self.assertLess(finite_annuity_pv(100,.05,20),
                        perpetuity_pv(100,.05))
    def test_06_due(self):
        self.assertAlmostEqual(perpetuity_due_pv(100,.05),2100)
    def test_07_deferred(self):
        self.assertAlmostEqual(deferred_perpetuity_pv(100,.05,2),
                               2000/1.05**2)
    def test_08_zero_payments(self):
        self.assertEqual(perpetuity_pv(0,.05),0)
    def test_09_signed(self):
        self.assertEqual(perpetuity_pv(-100,.05),-2000)
    def test_10_zero_periods(self):
        self.assertEqual(finite_annuity_pv(100,.05,0),0)
    def test_11_invalid_rates(self):
        with self.assertRaises(ValueError): perpetuity_pv(100,0)
        with self.assertRaises(ValueError): perpetuity_pv(100,-.01)
    def test_12_invalid_types(self):
        with self.assertRaises(TypeError): perpetuity_pv(True,.05)
        with self.assertRaises(TypeError): finite_annuity_pv(100,.05,2.5)
        with self.assertRaises(ValueError): deferred_perpetuity_pv(100,.05,-1)

if __name__ == "__main__":
    print(f"PV: {perpetuity_pv(100,.05):.2f}")
    unittest.main(verbosity=2)
```

## 9. Exercises and worked answers

1. **Definition:** What is an ordinary level perpetuity? **Answer:** Equal payments at the ends of periods 1, 2, 3, and indefinitely thereafter.
2. **PV:** Find the PV of $100 paid annually forever at 5%. **Answer:** $2,000.
3. **Inverse payment:** What annual payment corresponds to PV $4,000 at 5%? **Answer:** $200.
4. **Inverse rate:** A modeled perpetuity pays $120 annually and has PV $2,400. Find the rate. **Answer:** 120/2400 = 5%.
5. **Convergence:** Why does the formula require i > 0 for nonzero constant payments? **Answer:** The discount ratio must have absolute value below one.
6. **Zero rate:** Is PV finite for $100 annually forever at 0%? **Answer:** No; the infinite sum diverges.
7. **Perpetuity due:** Find PV of $100 at periods 0, 1, 2, ... at 5%. **Answer:** $2,100.
8. **Deferred stream:** Find PV of $100 starting at period 3 and continuing indefinitely at 5%. **Answer:** 2000/1.05², approximately $1,814.06.
9. **Finite comparison:** Is the PV of 20 positive annual payments smaller than the matching perpetuity at positive rates? **Answer:** Yes.
10. **Negative rate:** May the C/i perpetuity formula be applied at -2%? **Answer:** No; the infinite discounted series does not converge.
11. **Sign:** How is a perpetual payment obligation represented from the payer's perspective? **Answer:** As a negative cash-flow stream.
12. **Audit:** How can the infinite-series formula be checked numerically? **Answer:** Calculate finite-annuity PV for increasingly large n and compare its limit with C/i.
