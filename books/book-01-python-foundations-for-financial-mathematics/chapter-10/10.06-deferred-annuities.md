## 1. Definition and timing

A **deferred annuity** is a payment stream whose first payment occurs after an initial waiting period. This section models a deferred **ordinary annuity** with equal end-of-period payments.

Let **d** be the number of complete payment periods before the ordinary annuity begins. For n payments, the first payment is at period **d+1** and the final payment is at **d+n**.

```text
Period       0       1       2       3       4       5
             |-------|-------|-------|-------|-------|
Example      -       -       -       C       C       C
                     deferral        first payment
d = 2, n = 3; payment dates = 3, 4, 5.
```

The term "two-period deferral" must be defined carefully. Some contracts describe deferral using the number of periods until the first payment instead. Always store the **actual first payment date** or state the convention explicitly.

## 2. Present-value derivation

For payment C, periodic rate i greater than -1, n payments, and d complete periods of deferral:

PV = sum over k = 1 through n of C / (1+i)^(d+k).

Factor out the additional d-period discount:

**PV_deferred = PV_ordinary × (1+i)^(-d).**

For nonzero i:

**PV_deferred = C × [1 - (1+i)^(-n)] / i × (1+i)^(-d).**

For i = 0, PV_deferred = n × C. For n = 0, the value is zero. If d = 0, this reduces to an ordinary annuity.

## 3. Worked example

Suppose an investment pays **$100 at the end of years 3, 4, and 5**, discounted at a 10% effective annual rate. This is a three-payment ordinary annuity deferred by two periods.

PV = 100/1.1³ + 100/1.1⁴ + 100/1.1⁵.

Equivalently, first value the ordinary annuity at the end of year 2:

PV_at_year_2 = 100 × [1 - 1.1^(-3)] / 0.10.

Then discount that result two more periods:

PV_at_year_0 = PV_at_year_2 / 1.1².

These two methods should agree to numerical tolerance.

## 4. Changing the deferral period

At a positive discount rate, extending the waiting period reduces present value, all else equal. For an unchanged stream of n payments:

PV(d+1) = PV(d)/(1+i).

At a zero rate, deferral has no effect on present value in this simplified model. At a negative periodic rate greater than -1, later payments can have a higher present value.

This comparison assumes the payment amount, number of payments, periodic rate, and valuation date are unchanged.

## 5. Solving for payment amount

Given a present-value target P and positive n, divide P by the deferred-annuity factor:

C = P / { [1 - (1+i)^(-n)] / i × (1+i)^(-d) } for nonzero i.

For i = 0, C = P/n. When n = 0, no unique periodic payment can be inferred.

For example, a deferred stream designed to have a present value of $1,000 at 5% per period with ten payments starting in period 4 has d = 3. Compute the deferred-annuity factor and divide $1,000 by it; then verify by discounting payments at periods 4 through 13.

## 6. Model assumptions and operational safeguards

The reference model uses integer payment periods, an integer deferral count, constant equal payments, and a periodic rate matching the payment interval. A monthly annuity requires a monthly periodic rate. Calendar-based payment schedules, leap years, business-day adjustments, taxes, fees, inflation-linked growth, and contractual rounding are not modeled here.

For stable numerical evaluation, the code uses Python's `math.log1p`, `math.expm1`, and `math.fsum`. It validates finite inputs, integer counts, and rates greater than -1. The mathematical formulas do not predict whether payments will actually be received.

```python
"""Deferred annuities: standard-library reference implementation."""
import math
import unittest

def validate(payment, rate, periods, delay):
    for name, number in (("periods", periods), ("delay", delay)):
        if isinstance(number, bool) or not isinstance(number, int):
            raise TypeError(f"{name} must be an integer")
        if number < 0:
            raise ValueError(f"{name} cannot be negative")
    for name, number in (("payment", payment), ("rate", rate)):
        if isinstance(number, bool) or not isinstance(number, (int, float)):
            raise TypeError(f"{name} must be numeric")
        if not math.isfinite(number):
            raise ValueError(f"{name} must be finite")
    if rate <= -1:
        raise ValueError("rate must exceed -1")

def ordinary_pv(payment, rate, periods):
    validate(payment, rate, periods, 0)
    if periods == 0:
        return 0.0
    if rate == 0:
        return float(payment * periods)
    result = payment * (-math.expm1(-periods * math.log1p(rate))) / rate
    if not math.isfinite(result):
        raise ValueError("present value outside supported range")
    return result

def deferred_pv(payment, rate, periods, delay):
    validate(payment, rate, periods, delay)
    if periods == 0:
        return 0.0
    base = ordinary_pv(payment, rate, periods)
    try:
        factor = math.exp(-delay * math.log1p(rate))
    except OverflowError as exc:
        raise ValueError("discount factor overflow") from exc
    result = base * factor
    if not math.isfinite(result):
        raise ValueError("present value outside supported range")
    return result

def timeline_pv(payment, rate, periods, delay):
    validate(payment, rate, periods, delay)
    result = math.fsum(payment * math.exp(-(delay+k)*math.log1p(rate))
                       for k in range(1, periods+1))
    if not math.isfinite(result):
        raise ValueError("present value outside supported range")
    return result

def deferred_payment(target_pv, rate, periods, delay):
    validate(target_pv, rate, periods, delay)
    if periods == 0:
        raise ValueError("payment cannot be inferred with no payments")
    factor = deferred_pv(1, rate, periods, delay)
    if factor == 0 or not math.isfinite(factor):
        raise ValueError("annuity factor outside supported range")
    result = target_pv / factor
    if not math.isfinite(result):
        raise ValueError("payment outside supported range")
    return result

class DeferredAnnuityTests(unittest.TestCase):
    def test_01_dates(self):
        self.assertEqual([2+k for k in range(1,4)], [3,4,5])
    def test_02_ordinary_at_zero_delay(self):
        self.assertAlmostEqual(deferred_pv(100,.1,3,0),
                               ordinary_pv(100,.1,3))
    def test_03_two_period_delay(self):
        self.assertAlmostEqual(deferred_pv(100,.1,3,2),
                               sum(100/1.1**k for k in (3,4,5)))
    def test_04_discount_identity(self):
        self.assertAlmostEqual(deferred_pv(100,.1,3,2),
                               ordinary_pv(100,.1,3)/1.1**2)
    def test_05_zero_rate(self):
        self.assertEqual(deferred_pv(200,0,5,4),1000)
    def test_06_zero_payments(self):
        self.assertEqual(deferred_pv(100,.05,0,10),0)
    def test_07_negative_rate(self):
        self.assertAlmostEqual(deferred_pv(100,-.1,2,1),
                               100/.9**2+100/.9**3)
    def test_08_timeline_reconciliation(self):
        self.assertAlmostEqual(deferred_pv(125,.04,24,7),
                               timeline_pv(125,.04,24,7),places=8)
    def test_09_inverse_payment(self):
        p=deferred_payment(1000,.05,10,3)
        self.assertAlmostEqual(deferred_pv(p,.05,10,3),1000)
    def test_10_signed_flows(self):
        self.assertAlmostEqual(deferred_pv(-100,.1,3,2),
                               -deferred_pv(100,.1,3,2))
    def test_11_delay_effect(self):
        self.assertLess(deferred_pv(100,.1,3,3),
                        deferred_pv(100,.1,3,2))
    def test_12_invalid(self):
        with self.assertRaises(ValueError): deferred_pv(100,-1,3,2)
        with self.assertRaises(ValueError): deferred_pv(100,.05,3,-1)
        with self.assertRaises(TypeError): deferred_pv(100,.05,2.5,1)
        with self.assertRaises(ValueError): deferred_payment(100,.05,0,2)

if __name__ == "__main__":
    print(f"PV deferred: {deferred_pv(100,.10,3,2):.2f}")
    unittest.main(verbosity=2)
```

## 8. Applied exercises with answers

1. **Payment dates:** If d = 2 and n = 3, list the payment periods. **Answer:** 3, 4, and 5.
2. **Ordinary comparison:** What happens when d = 0? **Answer:** The deferred-annuity formula becomes the ordinary-annuity formula.
3. **Present value:** Find the PV of $100 at years 3, 4, and 5 at 10%. **Answer:** 100/1.1³ + 100/1.1⁴ + 100/1.1⁵, approximately $205.52.
4. **Factor identity:** How is deferred PV related to ordinary PV? **Answer:** Multiply ordinary PV by (1+i)^(-d).
5. **Zero interest:** Five payments of $200 after any finite delay at 0%. **Answer:** $1,000.
6. **Zero payments:** What is PV when n = 0? **Answer:** Zero.
7. **Negative interest:** Payments of $100 at periods 2 and 3 with i = -10%. **Answer:** 100/0.9² + 100/0.9³, approximately $260.63.
8. **Additional delay:** How does one extra period change PV at 10%? **Answer:** Divide the previous PV by 1.1.
9. **Monthly rate:** What periodic rate corresponds to 6% nominal annual convertible monthly? **Answer:** 0.005.
10. **Inverse:** How is payment C obtained from target PV? **Answer:** Divide the target by the deferred-annuity factor.
11. **Perspective:** What sign represents outgoing deferred payments? **Answer:** Negative, from the payer's perspective.
12. **Audit:** How can a closed-form result be independently verified? **Answer:** Generate payment dates d+1 through d+n, discount each signed payment, and sum.
