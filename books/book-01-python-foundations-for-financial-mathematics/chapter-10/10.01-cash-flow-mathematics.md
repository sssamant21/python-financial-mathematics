## 1. What is a cash flow?

A cash flow is an amount associated with a specific date or modeled time. A cash-flow stream is a collection of such events:

\[
\mathcal C=\{(t_0,C_0),(t_1,C_1),\ldots,(t_n,C_n)\}.
\]

Here \(t_i\) is measured in years from an explicit reference date, and \(C_i\) is a **signed** amount: receipts are positive; payments and investments are negative. Two amounts of equal size on different dates are not financially equivalent when the discount rate is nonzero.

Example:

| Time (years) | Amount (USD) | Interpretation |
|---:|---:|---|
| 0 | -1,000 | Initial investment |
| 1 | +600 | First receipt |
| 2 | +600 | Second receipt |

A time-zero cost is already part of the stream and must not be subtracted a second time.

## 2. Valuation date and effective annual rate

Let \(r>-1\) be a constant effective annual rate. A single cash flow \(C_t\) at year \(t\) has value at time zero

\[
PV(C_t)=\frac{C_t}{(1+r)^t}=C_t(1+r)^{-t}.
\]

The time-\(t\) discount factor is \(d(t)=(1+r)^{-t}\). At \(r=0\), \(d(t)=1\). When \(r>0\), future receipts have smaller present values; for \(-1<r<0\), discount factors for future times exceed one.

**Example:** A receipt of 121 USD after two years at 10% effective annually is worth \(121/1.1^2=100\) USD today.

## 3. Value an entire cash-flow stream

Linearity allows the valuation of each event separately and addition at a **common valuation date**:

\[
\boxed{V_0=\sum_{i=0}^{n} C_i(1+r)^{-t_i}}.
\]

For the investment example,

\[
V_0=-1000+\frac{600}{1.10}+\frac{600}{1.10^2}
\approx41.32\text{ USD}.
\]

This is a positive modeled net present value at a 10% effective annual discount rate. The conclusion depends on the stated rate and the assumption that all receipts occur as scheduled.

## 4. Moving the valuation date

For any valuation time \(s\) in years, the same stream has modeled value

\[
\boxed{V_s=\sum_i C_i(1+r)^{s-t_i}}.
\]

Thus \(V_s=V_0(1+r)^s\), assuming the same constant effective annual rate and mathematical fractional-year compounding. Cash flows before \(s\) are accumulated; cash flows after \(s\) are discounted. This identity is a powerful reconciliation check.

## 5. Time, signs, and numerical assumptions

A modeled year fraction does not specify a day-count convention, settlement calendar, or contractual compounding date. Future chapters will distinguish payment timing, ordinary annuities, annuities due, and deferred cash flows. For this foundational model:

- Use nonnegative times measured from the reference date.
- Enter annual effective rates as decimals (10% = `0.10`).
- Include the initial investment as a negative time-zero event.
- Keep full numerical precision until presentation rounding.
- Treat deterministic modeled values as valuations, not guarantees of future receipts.

For numerical stability, use `math.log1p(r)` to compute \(\ln(1+r)\), `math.exp` for accumulation and discount factors, and `math.fsum` to reduce summation error. Binary floating point is suitable for these instructional examples, not a substitute for an approved currency rounding policy.

```python
"""Chapter 10.1: cash-flow mathematics and eight reference tests."""
from dataclasses import dataclass
import math
import unittest

@dataclass(frozen=True)
class CashFlow:
    year: float
    amount: float

    def __post_init__(self):
        for name in ("year", "amount"):
            value = getattr(self, name)
            if isinstance(value, bool) or not isinstance(value, (int, float)):
                raise TypeError(f"{name} must be numeric")
            if not math.isfinite(value):
                raise ValueError(f"{name} must be finite")
        if self.year < 0:
            raise ValueError("year cannot be negative")

def validate_rate(rate):
    if isinstance(rate, bool) or not isinstance(rate, (int, float)):
        raise TypeError("rate must be numeric")
    if not math.isfinite(rate) or rate <= -1:
        raise ValueError("effective annual rate must be finite and > -1")
    return rate

def discount_factor(rate, year):
    validate_rate(rate)
    CashFlow(year, 0)
    exponent = -year * math.log1p(rate)
    try:
        factor = math.exp(exponent)
    except OverflowError as exc:
        raise ValueError("discount factor overflow") from exc
    if not math.isfinite(factor) or factor == 0:
        raise ValueError("discount factor outside supported range")
    return factor

def present_value(flow, rate):
    factor = discount_factor(rate, flow.year)
    value = flow.amount * factor
    if not math.isfinite(value) or (flow.amount != 0 and value == 0):
        raise ValueError("discounted value outside supported range")
    return value

def value_at(flows, rate, valuation_year=0):
    validate_rate(rate)
    CashFlow(valuation_year, 0)
    base = math.log1p(rate)
    values = []
    for flow in flows:
        if not isinstance(flow, CashFlow):
            raise TypeError("flows must contain CashFlow objects")
        exponent = (valuation_year - flow.year) * base
        try:
            factor = math.exp(exponent)
        except OverflowError as exc:
            raise ValueError("valuation factor overflow") from exc
        amount = flow.amount * factor
        if not math.isfinite(amount) or (flow.amount != 0 and amount == 0):
            raise ValueError("valued amount outside supported range")
        values.append(amount)
    total = math.fsum(values)
    if not math.isfinite(total):
        raise ValueError("total outside supported range")
    return total

class CashFlowTests(unittest.TestCase):
    def test_01_timeline(self):
        self.assertEqual([x.year for x in [CashFlow(0,-100),CashFlow(2,120)]],[0,2])
    def test_02_discount_factor(self):
        self.assertAlmostEqual(discount_factor(.1,2),1/1.1**2)
    def test_03_single_present_value(self):
        self.assertAlmostEqual(present_value(CashFlow(2,121),.1),100)
    def test_04_multiple_flows(self):
        flows=[CashFlow(0,-1000),CashFlow(1,600),CashFlow(2,600)]
        self.assertAlmostEqual(value_at(flows,.1),
                               -1000+600/1.1+600/1.1**2)
    def test_05_change_valuation_date(self):
        flows=[CashFlow(0,-100),CashFlow(1,110)]
        self.assertAlmostEqual(value_at(flows,.1,1),
                               1.1*value_at(flows,.1,0))
    def test_06_zero_rate(self):
        self.assertAlmostEqual(value_at([CashFlow(1,50),CashFlow(3,-20)],0),30)
    def test_07_negative_rate(self):
        self.assertAlmostEqual(present_value(CashFlow(2,81),-.1),100)
    def test_08_invalid_inputs(self):
        with self.assertRaises(ValueError):
            discount_factor(-1,2)
        with self.assertRaises(ValueError):
            CashFlow(-1,100)
        with self.assertRaises(TypeError):
            CashFlow(True,100)
        with self.assertRaises(TypeError):
            value_at([(1,100)],.05)

if __name__ == "__main__":
    example=[CashFlow(0,-1000),CashFlow(1,600),CashFlow(2,600)]
    print(f"Example NPV: {value_at(example,.10):.2f}")
    unittest.main(verbosity=2)
```

## 7. Exercises and answers

1. **Signs and dates.** Record a 500 USD investment today and 550 USD receipt in one year. **Answer:** `[(0,-500),(1,550)]`.
2. **Discounting.** Find the present value of 1,210 USD in two years at 10% effective annually. **Answer:** \(1210/1.1^2=1000\) USD.
3. **Multiple flows.** Value 100 USD in one year and 200 USD in two years at 10% effective annually. **Answer:** \(100/1.1+200/1.1^2\approx256.20\) USD.
4. **Net present value.** An investment costs 1,000 USD now and pays 600 USD at the end of each of the next two years. Discount at 10% effective annually. **Answer:** Approximately 41.32 USD.
5. **Valuation-date shift.** A stream has \(V_0=100\) USD at 5% effective annually. What is \(V_2\)? **Answer:** \(100(1.05)^2=110.25\) USD.
6. **Zero rate.** Value a receipt of 80 USD in year 2 and a payment of 30 USD in year 4 at a zero rate. **Answer:** 50 USD.
7. **Negative rate.** Find the present value of 81 USD in two years at -10% effective annually. **Answer:** \(81/0.9^2=100\) USD.
8. **Audit question.** Why should an initial investment be represented as a time-zero negative cash flow? **Answer:** It preserves timing and sign conventions and avoids subtracting the initial cost twice.
