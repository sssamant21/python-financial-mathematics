## Learning objectives

Define the internal rate of return (IRR), derive its root-finding equation, implement bracketed bisection in Python, explain multiple or missing roots, and compare IRR with NPV for capital-budgeting decisions.

## 1. Definition and timing

For periodic signed cash flows C0, C1, ..., Cn, IRR is any rate r > -1 satisfying:

**0 = NPV(r) = C0 + C1/(1+r) + ... + Cn/(1+r)^n.**

The first amount occurs at time zero. Future amounts occur at equal intervals. IRR is a periodic rate, not automatically an annual rate. If periods are months, the annual effective equivalent is (1+r_month)^12 - 1.

```text
Period       0            1           2
             |------------|-----------|
Cash flow   -100         +60         +60
```

Unlike NPV, which reports value at a selected required return, IRR solves for the discount rate at which the modeled value equals zero.

## 2. Derivation from NPV

Starting with the NPV equation, set its value equal to zero. For a single-period project with -100 now and +110 after one period:

0 = -100 + 110/(1+r).

Rearranging gives 1+r = 110/100, so **r = 10%**.

For two or more periods, the equation can be nonlinear and may have several roots. Numerical methods are often more convenient than algebraic solutions.

## 3. Worked example

An investment costs $100 today and pays $60 at the ends of periods 1 and 2:

0 = -100 + 60/(1+r) + 60/(1+r)^2.

Solving numerically gives IRR approximately **13.07%**. At a 10% required return, the project has positive NPV, consistent with IRR exceeding the required return for this conventional stream.

A root is not itself a decision. The cash-flow signs, financing structure, scale, reinvestment assumptions, and comparison alternatives still matter.

## 4. Bisection method

Bisection is a robust method for finding a root of a continuous function **when a bracket [a,b] contains a sign change**.

1. Choose a > -1 and b > a.
2. Compute NPV(a) and NPV(b).
3. Reject the bracket if both endpoint values have the same sign, unless one is exactly zero.
4. Evaluate the midpoint m = (a+b)/2.
5. Keep the half-interval whose endpoints have opposite signs.
6. Repeat until the residual or interval width meets a chosen tolerance.

Bisection is slower than some Newton-based methods but avoids derivative calculations and stays inside the chosen bracket. A missing sign change does not prove that no root exists: there may be an even-multiplicity root or roots outside the interval.

## 5. Multiple IRRs and nonconventional cash flows

For the cash flows **[-100, +230, -132]**, the NPV equation has two valid IRRs: **10% and 20%**. This is a direct warning against treating a single solver result as the only economically meaningful answer.

The signs change twice, so multiple IRRs are possible. A conventional stream with an initial outflow followed only by positive receipts generally has one economically relevant IRR if a root exists in the domain.

For nonconventional cash flows, examine NPV across relevant discount rates and report multiple roots or lack of a sign-changing bracket. Do not silently select whichever root the solver finds first.

## 6. IRR versus NPV

For independent conventional projects, IRR can be compared with the hurdle rate. However, **NPV is usually the stronger primary measure of total value creation** for mutually exclusive projects, especially when project scale and timing differ.

IRR can be misleading for projects with interim negative flows, multiple roots, or different reinvestment patterns. Modified IRR and incremental NPV analysis may be more appropriate in some settings.

## 7. Numerical and production safeguards

Use finite numeric cash flows and an explicit rate domain greater than -100%. Verify the residual NPV at any returned rate, and record the bracket, tolerance, and iteration cap. For extreme rates or long horizons, numerical overflow or underflow may occur; a production solver should use additional range checks and diagnostic reporting.

A dated irregular stream needs an XIRR-style equation using a declared day-count convention rather than treating unequal calendar intervals as identical periods.

```python
"""IRR by bracketed bisection; periodic cash flows."""
import math
import unittest

def npv(rate, flows):
    if not math.isfinite(rate) or rate <= -1:
        raise ValueError("rate must be finite and > -1")
    return math.fsum(c / (1 + rate)**t for t, c in enumerate(flows))

def irr_bisect(flows, low=0.0, high=1.0, tol=1e-12, max_iter=300):
    flows = list(flows)
    if len(flows) < 2 or any(not math.isfinite(x) for x in flows):
        raise ValueError("at least two finite cash flows required")
    if not any(x > 0 for x in flows) or not any(x < 0 for x in flows):
        raise ValueError("both cash-flow signs required")
    if not (-1 < low < high) or tol <= 0 or max_iter <= 0:
        raise ValueError("invalid bracket or solver settings")
    a, b = low, high
    fa, fb = npv(a, flows), npv(b, flows)
    if fa == 0: return a
    if fb == 0: return b
    if fa * fb > 0:
        raise ValueError("bracket does not contain a sign change")
    for _ in range(max_iter):
        m = (a+b)/2
        fm = npv(m, flows)
        if abs(fm) < tol or (b-a)/2 < tol:
            return m
        if fa * fm < 0:
            b, fb = m, fm
        else:
            a, fa = m, fm
    raise RuntimeError("bisection did not converge")

class Tests(unittest.TestCase):
    def test_01_one_period(self):
        self.assertAlmostEqual(irr_bisect([-100,110]),.1,places=9)
    def test_02_two_period(self):
        r=irr_bisect([-100,60,60])
        self.assertAlmostEqual(npv(r,[-100,60,60]),0,places=8)
    def test_03_zero(self):
        self.assertEqual(irr_bisect([-100,100]),0)
    def test_04_negative(self):
        self.assertAlmostEqual(irr_bisect([-100,90],-.5,0),-.1,places=9)
    def test_05_root_at_high(self):
        self.assertEqual(irr_bisect([-100,200],0,1),1)
    def test_06_nonstandard_first(self):
        self.assertAlmostEqual(irr_bisect([100,-110]),.1,places=9)
    def test_07_multiple_root_a(self):
        self.assertAlmostEqual(irr_bisect([-100,230,-132],.05,.15),.1,places=8)
    def test_08_multiple_root_b(self):
        self.assertAlmostEqual(irr_bisect([-100,230,-132],.15,.3),.2,places=8)
    def test_09_no_sign_change(self):
        with self.assertRaises(ValueError): irr_bisect([-100,40,40],.1,.5)
    def test_10_same_sign(self):
        with self.assertRaises(ValueError): irr_bisect([100,200])
    def test_11_invalid_rate(self):
        with self.assertRaises(ValueError): npv(-1,[-100,110])
    def test_12_bad_bracket(self):
        with self.assertRaises(ValueError): irr_bisect([-100,110],.5,.1)

if __name__ == "__main__":
    print("IRR:", irr_bisect([-100,60,60]))
    unittest.main(verbosity=2)
```

## 9. Exercises with worked answers

1. **Definition:** What equation defines IRR? **Answer:** NPV(r) = 0.
2. **Single-period root:** Find IRR for [-100, 110]. **Answer:** 10%.
3. **Negative IRR:** Find IRR for [-100, 90]. **Answer:** -10%.
4. **Zero IRR:** Find IRR for [-100, 100]. **Answer:** 0%.
5. **Two-period project:** What is IRR for [-100, 60, 60]? **Answer:** Approximately 13.07%.
6. **Bisection requirement:** What must a valid sign-changing bracket contain? **Answer:** Opposite-sign endpoint NPVs or an endpoint root.
7. **Missing bracket:** Does a failed bracket prove no IRR exists? **Answer:** No; the root may lie elsewhere or not change sign.
8. **Multiple roots:** Give both IRRs for [-100, 230, -132]. **Answer:** 10% and 20%.
9. **Discount rate:** What does IRR measure compared with NPV? **Answer:** IRR is a break-even rate; NPV is value at a specified rate.
10. **Monthly IRR:** How do you annualize a monthly effective IRR? **Answer:** (1+r_month)^12 - 1.
11. **Mutually exclusive projects:** Why can NPV be preferable? **Answer:** It measures absolute value rather than a percentage return.
12. **Validation:** What should be checked after root finding? **Answer:** The residual NPV, domain, bracket, and possible alternative roots.
