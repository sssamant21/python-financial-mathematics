## Learning objectives

Calculate accrued coupon interest at settlement, distinguish quoted clean price from settlement dirty price, understand day-count conventions and quotation units, and verify an implementation using Python.

## 1. Coupon accrual and settlement

A fixed-coupon bond pays interest at contractual dates. If it changes hands between coupon dates, the buyer generally compensates the seller for coupon interest accrued since the previous coupon date. This accrued interest is a settlement adjustment rather than a separate issuer payment.

**Dirty price = Clean price + Accrued interest.**

**Clean price = Dirty price − Accrued interest.**

Clean price is the quoted value excluding accrued coupon interest. Dirty (full) price includes accrued interest. Actual settlement cash may also include fees and other adjustments.

## 2. Coupon amount

For face amount F, annual coupon rate c, and payment frequency m:

**C = F × c / m.**

A $1,000 bond with a 6% annual coupon and two payments per year pays **$30** per regular coupon period.

## 3. A simplified Actual/Actual coupon-period calculation

Let d0 be the previous coupon date, d1 the next coupon date, and ds the settlement date. Assume d0 ≤ ds < d1. Let A be actual calendar days from d0 to ds, and B actual days from d0 to d1.

**Accrual fraction α = A/B.**

**Accrued interest AI = C × A/B.**

This is an educational regular-coupon-period Actual/Actual-style convention, **not a universal implementation** of Actual/Actual ICMA, Actual/Actual ISDA, or every bond's contractual basis.

## 4. Worked settlement example

| Input | Value |
|---|---|
| Face value | $1,000 |
| Annual coupon rate | 6% |
| Frequency | Semiannual |
| Previous coupon | January 1, 2026 |
| Settlement | April 1, 2026 |
| Next coupon | July 1, 2026 |
| Clean price | $1,020 |

The coupon is **$30**. January 1 to July 1 is **181 days**; January 1 to April 1 is **90 days**.

**α = 90/181 ≈ 0.49723757.**

**AI = 30 × 90/181 ≈ $14.917127.**

**Dirty price = 1020 + 14.917127 ≈ $1,034.917127**, or **$1,034.92** when displayed to cents.

Retain precision through the computation, rounding only as required by settlement rules.

## 5. Price quotation units

Bonds may be quoted per **$100 of face amount**, not as the full currency amount of a holding.

For a clean quote of **101.25 per $100 face** on **$250,000 face**:

**Clean cash value = 101.25/100 × 250000 = $253,125.**

If accrued interest on the position is $3,750:

**Dirty cash value = 253125 + 3750 = $256,875.**

Do not add accrued interest denominated in dollars to a quote per $100 without converting units.

## 6. Day-count convention comparison

| Convention | General description | Key caution |
|---|---|---|
| Actual/Actual | Actual days with a convention-specific denominator | ICMA and ISDA differ |
| Actual/360 | Actual days divided by 360 | Not interchangeable with Actual/Actual |
| Actual/365 Fixed | Actual days divided by 365 | Fixed denominator even in leap years |
| 30/360 | Prescribed 30-day month rules | US and European variants differ |

The bond's contractual and market convention governs the correct result. The simplified lab is designed for a regular coupon period with actual calendar-day fraction.

## 7. Clean versus dirty in bond valuation

A settlement-date present-value calculation using remaining payments typically produces a **dirty/full theoretical price**. Compare that result to the observed full settlement price. To compare with a clean market quote, subtract accrued interest using the appropriate convention.

This distinction matters for yield-to-maturity calculations: solving a yield from a clean quote without accounting for accrued interest can produce an incorrect yield.

## 8. Coupon-date boundaries and special cases

Accrued interest is zero at the beginning of the modeled regular coupon period and increases toward the next coupon date. On the coupon date, the new period begins and the accrual balance normally resets.

Real-world cases can differ for ex-coupon dates, irregular first or final coupons, floating-rate bonds, defaulted obligations, and holiday or settlement-calendar adjustments. The lab explicitly excludes the next coupon date from the current interval.

## 9. Common operational mistakes

- Confusing clean quote with dirty settlement value.
- Applying the wrong day-count basis or coupon schedule.
- Mixing price per $100 par with the cash value of the full holding.
- Using trade date instead of the applicable settlement date.
- Double-counting the upcoming coupon.
- Rounding intermediate accrued-interest values.
- Applying regular-period formulas to irregular coupon periods.

## 10. Python hands-on lab

Save the code as **accrued_interest.py** and run **python accrued_interest.py** followed by **python -m compileall -q accrued_interest.py**.

The program computes coupon payments, a simplified day fraction, accrued interest, clean and dirty prices, and includes **12 unit tests**. Independent runtime and editorial validation remain pending.

```python
from datetime import date
import math, unittest
def coupon(face,rate,frequency=2):
    if not all(isinstance(v,(int,float)) and not isinstance(v,bool) and math.isfinite(v) for v in (face,rate)) or face<=0 or rate<0 or not isinstance(frequency,int) or isinstance(frequency,bool) or frequency<1: raise ValueError('invalid coupon terms')
    return face*rate/frequency
def fraction(previous,next_date,settlement):
    if not all(isinstance(v,date) for v in (previous,next_date,settlement)): raise TypeError('date required')
    if not previous<=settlement<next_date: raise ValueError('settlement outside coupon period')
    return (settlement-previous).days/(next_date-previous).days
def accrued(face,rate,frequency,previous,next_date,settlement):
    return coupon(face,rate,frequency)*fraction(previous,next_date,settlement)
def dirty(clean,interest):
    if not all(isinstance(v,(int,float)) and not isinstance(v,bool) and math.isfinite(v) and v>=0 for v in (clean,interest)): raise ValueError('invalid price')
    return clean+interest
def clean(full,interest):
    if not all(isinstance(v,(int,float)) and not isinstance(v,bool) and math.isfinite(v) for v in (full,interest)) or interest<0 or full<interest: raise ValueError('invalid price')
    return full-interest
class Tests(unittest.TestCase):
    def setUp(self): self.p=date(2026,1,1);self.n=date(2026,7,1);self.s=date(2026,4,1)
    def test_01_coupon(self):self.assertEqual(coupon(1000,.06),30)
    def test_02_start(self):self.assertEqual(fraction(self.p,self.n,self.p),0)
    def test_03_days(self):self.assertEqual((self.n-self.p).days,181)
    def test_04_elapsed(self):self.assertEqual((self.s-self.p).days,90)
    def test_05_fraction(self):self.assertAlmostEqual(fraction(self.p,self.n,self.s),90/181)
    def test_06_interest(self):self.assertAlmostEqual(accrued(1000,.06,2,self.p,self.n,self.s),30*90/181)
    def test_07_dirty(self):self.assertEqual(dirty(1020,15),1035)
    def test_08_clean(self):self.assertEqual(clean(1035,15),1020)
    def test_09_roundtrip(self):
        a=accrued(1000,.06,2,self.p,self.n,self.s)
        self.assertAlmostEqual(clean(dirty(1020,a),a),1020)
    def test_10_quarterly(self):self.assertEqual(coupon(2000,.08,4),40)
    def test_11_leap(self):self.assertAlmostEqual(fraction(date(2024,1,1),date(2024,7,1),date(2024,4,1)),91/182)
    def test_12_invalid(self):
        for fn in (lambda:coupon(0,.06),lambda:coupon(1000,-.01),lambda:fraction(self.p,self.n,self.n),lambda:clean(10,20)):
            with self.assertRaises(ValueError):fn()
if __name__=='__main__':
    p=date(2026,1,1);n=date(2026,7,1);s=date(2026,4,1)
    ai=accrued(1000,.06,2,p,n,s)
    print(f'Accrued interest: {ai:.6f}; dirty price: {dirty(1020,ai):.6f}')
    unittest.main(verbosity=2)
```

1. **Clean price:** What does it exclude? **Answer:** Accrued coupon interest.
2. **Dirty price:** What does it include? **Answer:** Clean price plus accrued interest.
