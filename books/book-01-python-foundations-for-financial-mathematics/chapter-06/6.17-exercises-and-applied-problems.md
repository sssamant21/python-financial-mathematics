## Purpose and Working Rules

These twenty chapter-wide problems cover Sections 6.1–6.16. Attempt them before reading the [companion solutions](6.17-solutions-and-reference-implementations.md). Use Python 3.12 with NumPy 2.3.5, the environment exercised for this chapter. Retain labels, units, shapes, and assumptions beside each answer.

All fixtures are synthetic. Unless a problem explicitly introduces signed quantities, portfolios are long-only. Prices, quantities, and currency values are distinct units. Returns are decimal fractions. No prices are investment recommendations or externally retrieved observations.

For each programming answer, supply the expression or function, a known-answer check, and an explanation of the result. Use explicit tolerances suitable for the fixture; do not round intermediate results to make an assertion pass. Expected failures are part of the answer, not errors to suppress.

## Problems

### Problem 01 — Array contract

Create a float64 array from [100, 102, 99]. Report its shape, dimension, and dtype. Explain why the values alone do not specify financial units.

### Problem 02 — Integer truncation

Assign 1.75 into the first element of an integer array [1,2]. Explain the result and supply a floating alternative.

### Problem 03 — Slice ownership

Slice elements 1 onward from [100.,101.,102.], change the slice first element to zero, then repeat using copy. Identify the source changes.

### Problem 04 — Fixed-quantity P&L

For quantities [10,-5,0], opening prices [100,80,50], and closing prices [105,76,52], calculate price-only P&L. State the assumptions.

### Problem 05 — Broadcasting direction

For closing prices [[110,95],[80,105]] and opening prices [100,100], calculate asset returns. State the input and output shapes.

### Problem 06 — Aggregation axes

For return matrix [[.10,-.05],[-.20,.05]], find row means and column means. Explain why neither is automatically an expected portfolio return.

### Problem 07 — Cash-flow vector

Discount cash flows [100,100,1100] at times [1,2,3] using annual effective rate .05. Compare a vector expression with scalar arithmetic.

### Problem 08 — Successive returns

Prices [100,110,99] are consecutive observations of one asset without distributions. Calculate simple interval returns and cumulative return.

### Problem 09 — Opening weights

Given common-currency opening values [600,300,100], derive weights and combine asset returns [.10,-.05,0]. Explain the weighting date.

### Problem 10 — Multiple portfolios

Use R=[[.10,-.05,0],[-.20,.05,0]] and W=[[.6,.3,.1],[0,1,0]]. Calculate R @ W.T and label its axes.

### Problem 11 — Linear system

Solve 2x+y=5 and x+3y=5 with np.linalg.solve. Verify the residual rather than forming an inverse.

### Problem 12 — Singular model

Attempt to solve [[1,2],[2,4]] x = [3,6]. Explain why a unique answer is unavailable.

### Problem 13 — Random protocol

Create two fresh Generator(PCG64(42)) instances and draw five standard normals from each. Then draw another five from the first. State what the seed does and does not establish.

### Problem 14 — Tiny linked changes

Link three returns of 1e-17 using both prod(1+r)-1 and expm1(sum(log1p(r))). Compare with 3e-17 and explain the loss.

### Problem 15 — Tolerance and shape

Show that allclose may accept shapes (2,1) and (2,) through broadcasting. Explain a safer result-comparison contract.

### Problem 16 — Finite input gate

Build a finite-value check for [1,nan,inf]. Explain why replacing invalid observations with zero changes the financial model.

### Problem 17 — Payload budget

Calculate float64 payload bytes for a (1000,20) matrix. Does this establish peak process memory?

### Problem 18 — Benchmark boundary

Write equivalent list-to-list Python and NumPy P&L functions for the fixed-quantity fixture in Problem 4. Verify agreement before timing. Explain a fair measurement protocol.

### Problem 19 — Project reconciliation

Independently value holdings [6,3,1] opened at [100,100,100] under closing rows [[110,95,100],[80,105,100],[100,100,100]]. Reconcile direct P&L with opening-weight returns.

### Problem 20 — Identity and permutation

For returns [.10,-.05,0] and weights [.6,.3,.1], show that permuting both together preserves return, while permuting only weights gives a different result. State how production code prevents this mistake.
