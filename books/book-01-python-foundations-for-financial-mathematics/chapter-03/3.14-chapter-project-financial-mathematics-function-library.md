## 3.14.1 Project Objective

Build a small reusable library that combines the chapter's financial interfaces, validation, docstrings, annotations, composition, numerical isolation, and tests.

The deliverable is three local files: financial_functions.py, test_function_library.py, and demo_function_library.py. Every file is supplied in full below.

This is an importable module project, not an installable package. Chapter 5 develops packaging, environments, and dependency management. No third-party dependency is needed to execute this project.

## 3.14.2 Business Questions

The library answers these questions under explicitly stated constant-rate assumptions:

1. What does a period-0 amount become after n periods?
2. What is one future amount worth at period 0?
3. What are the accumulation and discount factors?
4. What periodic rate corresponds to a nominal annual quotation?
5. What effective annual rate follows from equal periodic compounding?
6. How can a nominal quotation feed a present-value calculation?

These are educational model questions. Selecting an appropriate market or risk-adjusted rate remains outside the implementation.

## 3.14.3 Acceptance Contract

| Area | Requirement |
|---|---|
| Numeric representation | Decimal amounts and rates; controlled inputs constructed from strings |
| Amount domain | Finite and nonnegative; no sign reversal |
| Effective rate domain | Finite and greater than -1 |
| Horizon | Integer 0..1000, excluding bool |
| Frequency | Integer 1..366, excluding bool |
| Timing | Principal at period 0; future amount at end of matching periods |
| Rate convention | Effective periodic unless explicitly named nominal annual |
| Cash flows | Single amount; no intervening contributions or withdrawals |
| Currency | Input and output share currency; no conversion |
| Numerical policy | Fresh fixed 40-digit half-even context per public calculation |
| Validation | All relevant inputs checked, including at zero horizon |
| Effects | No printing, external reads, input mutation, or caller-context changes in calculations |
| Verification | Independent known values, boundaries, failures, composition, and isolation |

No taxes, fees, inflation adjustment, irregular dates, term structures, continuous compounding, or regulatory APR interpretation are included.

## 3.14.4 Numerical Policy and Compatibility

The project adopts Section 3.12's fixed policy for all public operations. Earlier Sections 3.9–3.11 used the ambient context; this integrated module intentionally introduces a documented fixed policy rather than silently changing those canonical examples.

Each policy context has precision 40, ROUND_HALF_EVEN, Emin -999999, Emax 999999, capitals 1, clamp 0, clear flags, and traps for InvalidOperation, DivisionByZero, and Overflow.

No explicit cent quantization occurs. Arithmetic can still round, lose small increments, or underflow. Positive factor and finite-result guards reject selected unusable outcomes, but finite results are not a guarantee of adequate accuracy.

The nominal wrapper converts its rate and calls present_value as separate fixed-policy stages. Conversion rounds to that policy before valuation. Changing the staging or precision is a numerical-policy revision.

## 3.14.5 File 1 — financial_functions.py

Create a new working directory for the project and save this complete module there.

```python
"""Single-amount financial helpers with a fixed Decimal policy.

Amounts are finite nonnegative Decimal values in one currency.
Effective periodic rates are finite Decimal values greater than -1.
Horizons are integer 0..1000; frequencies integer 1..366; bool is excluded.
No rate/currency conversion occurs except in explicitly named helpers.
No intermediate cash flows, taxes, fees, or inflation are modeled.

Every public calculation uses a fresh precision-40, half-even context
with exponent limits +/-999999, clamp 0, capitals 1, clear flags, and
traps for InvalidOperation, DivisionByZero, and Overflow. No explicit
currency quantization is applied. Inputs and caller context are preserved.

TypeError denotes unsupported representations; ValueError denotes
unsupported input values. Decimal exceptions may propagate; explicit
ArithmeticError guards reject unusable computed factors/rates/results.
Finite rounding, cancellation, and underflow remain possible.
"""

from decimal import (
    Context, Decimal, DivisionByZero, InvalidOperation, Overflow,
    ROUND_HALF_EVEN, localcontext,
)


def _policy() -> Context:
    """Create the module's complete arithmetic policy without shared state."""
    return Context(
        prec=40, rounding=ROUND_HALF_EVEN,
        Emin=-999999, Emax=999999, capitals=1, clamp=0,
        flags=[], traps=[InvalidOperation, DivisionByZero, Overflow],
    )


def _finite_decimal(value: Decimal, name: str) -> None:
    """Reject an unsupported representation or a non-finite value."""
    if not isinstance(value, Decimal):
        raise TypeError(f"{name} must be Decimal")
    if not value.is_finite():
        raise ValueError(f"{name} must be finite")


def _amount(value: Decimal) -> None:
    """Require a finite nonnegative Decimal amount."""
    _finite_decimal(value, "amount")
    if value < 0:
        raise ValueError("amount must be nonnegative")


def _count(value: int, name: str, lower: int, upper: int) -> None:
    """Require an integer in the specified inclusive range, excluding bool."""
    if not isinstance(value, int) or isinstance(value, bool):
        raise TypeError(f"{name} must be an integer excluding bool")
    if not lower <= value <= upper:
        raise ValueError(f"{name} must be between {lower} and {upper}")


def _positive(value: Decimal, name: str) -> Decimal:
    """Reject a computed factor that is non-finite or nonpositive."""
    if not value.is_finite() or value <= 0:
        raise ArithmeticError(f"{name} must be finite and positive")
    return value


def _growth(periodic_rate: Decimal, periods: int) -> Decimal:
    """Validate and calculate growth within an already active policy."""
    _finite_decimal(periodic_rate, "periodic_rate")
    if periodic_rate <= Decimal("-1"):
        raise ValueError("periodic_rate must be greater than -1")
    _count(periods, "periods", 0, 1000)
    return _positive(
        (Decimal("1") + periodic_rate) ** periods,
        "growth factor",
    )


def accumulation_factor(periodic_rate: Decimal, *, periods: int) -> Decimal:
    """Return (1+r)**n from period 0 to n under the module policy.

    r is an effective rate per matching period. Validate even at n=0.
    Return a dimensionless positive factor; inherit module failure rules.
    """
    with localcontext(_policy()):
        return _growth(periodic_rate, periods)


def discount_factor(periodic_rate: Decimal, *, periods: int) -> Decimal:
    """Return 1/(1+r)**n from period n to 0 under the module policy.

    Rate and horizon domains match accumulation_factor. Return a positive
    dimensionless factor; inherit module failure rules.
    """
    with localcontext(_policy()):
        return _positive(
            Decimal("1") / _growth(periodic_rate, periods),
            "discount factor",
        )


def future_value(
    principal: Decimal, *, periodic_rate: Decimal, periods: int,
) -> Decimal:
    """Return a period-0 principal's amount at period n.

    Require the module's amount, effective-rate, and horizon domains.
    Return the same currency without sign reversal or quantization.
    Validate all inputs, including for zero amount or horizon.
    Inherit module assumptions, numerical policy, and failure rules.
    """
    _amount(principal)
    with localcontext(_policy()):
        result = principal * _growth(periodic_rate, periods)
        if not result.is_finite():
            raise ArithmeticError("future value must be finite")
        return result


def present_value(
    future_amount: Decimal, *, periodic_rate: Decimal, periods: int,
) -> Decimal:
    """Return a period-n amount's discounted equivalent at period 0.

    Require the module's amount, effective-rate, and horizon domains.
    Divide directly by the growth factor. Return the original currency
    without sign reversal or quantization. Validate even at zero horizon.
    Inherit module assumptions, numerical policy, and failure rules.
    """
    _amount(future_amount)
    with localcontext(_policy()):
        result = future_amount / _growth(periodic_rate, periods)
        if not result.is_finite():
            raise ArithmeticError("present value must be finite")
        return result


def periodic_rate_from_nominal(
    nominal_annual_rate: Decimal, *, periods_per_year: int,
) -> Decimal:
    """Return j/m for a nominal annual rate convertible m times yearly.

    Require finite Decimal j and integer frequency 1..366 excluding bool.
    The implied effective periodic rate must exceed -1. This does not
    convert effective annual rates, include fees, or interpret APR rules.
    Apply the module policy and reject unusable computed periodic rates.
    """
    _finite_decimal(nominal_annual_rate, "nominal_annual_rate")
    _count(periods_per_year, "periods_per_year", 1, 366)
    with localcontext(_policy()):
        if nominal_annual_rate <= -Decimal(periods_per_year):
            raise ValueError("implied periodic rate must be greater than -1")
        rate = nominal_annual_rate / Decimal(periods_per_year)
        if not rate.is_finite() or rate <= Decimal("-1"):
            raise ArithmeticError("computed periodic rate is unusable")
        return rate


def effective_annual_rate(
    periodic_rate: Decimal, *, periods_per_year: int,
) -> Decimal:
    """Return (1+r)**m - 1 for equal periodic compounding.

    Require the module's effective-rate domain and frequency 1..366.
    Return a fractional Decimal annual rate, not percentage display text.
    Apply the module policy; reject non-finite output or output <= -1.
    """
    _count(periods_per_year, "periods_per_year", 1, 366)
    with localcontext(_policy()):
        rate = _growth(periodic_rate, periods_per_year) - Decimal("1")
        if not rate.is_finite() or rate <= Decimal("-1"):
            raise ArithmeticError("effective annual rate is unusable")
        return rate


def present_value_from_nominal(
    future_amount: Decimal, *,
    nominal_annual_rate: Decimal,
    periods_per_year: int,
    periods: int,
) -> Decimal:
    """Convert a nominal annual quotation and discount one future amount.

    periods counts the quotation's matching compounding periods, not
    necessarily years. Validate the amount before rate conversion.
    Convert j/m under the fixed policy, then pass that returned rate
    into present_value under the same policy. Preserve the input currency.
    Inherit the component domains, exclusions, and failure behavior.
    """
    _amount(future_amount)
    rate = periodic_rate_from_nominal(
        nominal_annual_rate, periods_per_year=periods_per_year
    )
    return present_value(
        future_amount, periodic_rate=rate, periods=periods
    )
```

Internal helpers centralize contracts. Public functions remain callable independently, with their own supported input checks.

The module exposes seven public calculations. A leading underscore marks internal helpers by convention; it does not enforce access restrictions.

## 3.14.6 File 2 — test_function_library.py

Save beside the implementation:

```python
"""Acceptance tests for the Chapter 3 function-library project."""

from decimal import Decimal, Inexact, Overflow, ROUND_DOWN, localcontext
import unittest

import financial_functions as finance


class TestFunctionLibrary(unittest.TestCase):
    """Verify public financial contracts and numerical isolation."""

    def test_known_valuations(self) -> None:
        self.assertEqual(
            finance.future_value(
                Decimal("1000"), periodic_rate=Decimal("0.05"), periods=2
            ), Decimal("1102.50"),
        )
        self.assertEqual(
            finance.present_value(
                Decimal("121"), periodic_rate=Decimal("0.10"), periods=2
            ), Decimal("100"),
        )

    def test_factors(self) -> None:
        self.assertEqual(
            finance.accumulation_factor(Decimal("0.05"), periods=2),
            Decimal("1.1025"),
        )
        self.assertEqual(
            finance.discount_factor(Decimal("0.25"), periods=1),
            Decimal("0.8"),
        )

    def test_rate_conversions(self) -> None:
        monthly = finance.periodic_rate_from_nominal(
            Decimal("0.12"), periods_per_year=12
        )
        self.assertEqual(monthly, Decimal("0.01"))
        self.assertEqual(
            finance.effective_annual_rate(monthly, periods_per_year=12),
            Decimal("0.126825030131969720661201"),
        )

    def test_composed_nominal_valuation(self) -> None:
        result = finance.present_value_from_nominal(
            Decimal("101"), nominal_annual_rate=Decimal("0.12"),
            periods_per_year=12, periods=1,
        )
        self.assertEqual(result, Decimal("100"))

    def test_zero_boundaries(self) -> None:
        for valuation in (finance.present_value, finance.future_value):
            with self.subTest(function=valuation.__name__):
                self.assertEqual(
                    valuation(
                        Decimal("100"), periodic_rate=Decimal("0.05"), periods=0
                    ), Decimal("100"),
                )
                self.assertEqual(
                    valuation(
                        Decimal("0"), periodic_rate=Decimal("0.05"), periods=2
                    ), Decimal("0"),
                )
                self.assertEqual(
                    valuation(
                        Decimal("100"), periodic_rate=Decimal("0"), periods=1000
                    ), Decimal("100"),
                )

    def test_negative_rate(self) -> None:
        self.assertEqual(
            finance.future_value(
                Decimal("1000"), periodic_rate=Decimal("-0.10"), periods=1
            ), Decimal("900"),
        )
        self.assertEqual(
            finance.present_value(
                Decimal("900"), periodic_rate=Decimal("-0.10"), periods=1
            ), Decimal("1000"),
        )
        self.assertGreater(
            finance.discount_factor(Decimal("-0.10"), periods=1), Decimal("1")
        )

    def test_invalid_monetary_domain(self) -> None:
        for amount in ("-1", "NaN", "Infinity"):
            with self.subTest(amount=amount):
                for valuation in (finance.present_value, finance.future_value):
                    with self.assertRaises(ValueError):
                        valuation(
                            Decimal(amount),
                            periodic_rate=Decimal("0.05"), periods=2,
                        )

    def test_invalid_rate_and_counts(self) -> None:
        for factor in (finance.accumulation_factor, finance.discount_factor):
            with self.subTest(function=factor.__name__):
                with self.assertRaises(ValueError):
                    factor(Decimal("-1"), periods=0)
                with self.assertRaises(ValueError):
                    factor(Decimal("NaN"), periods=0)
                with self.assertRaises(TypeError):
                    factor(Decimal("0.05"), periods=True)
                with self.assertRaises(ValueError):
                    factor(Decimal("0.05"), periods=1001)
        with self.assertRaises(ValueError):
            finance.periodic_rate_from_nominal(
                Decimal("0.12"), periods_per_year=0
            )
        with self.assertRaises(ValueError):
            finance.effective_annual_rate(
                Decimal("0.01"), periods_per_year=367
            )
        with self.assertRaises(ValueError):
            finance.periodic_rate_from_nominal(
                Decimal("-12"), periods_per_year=12
            )

    def test_wrong_representations(self) -> None:
        with self.assertRaises(TypeError):
            finance.present_value(
                "100", periodic_rate=Decimal("0.05"), periods=2  # type: ignore[arg-type]
            )
        with self.assertRaises(TypeError):
            finance.periodic_rate_from_nominal(
                0.12, periods_per_year=12  # type: ignore[arg-type]
            )
        with self.assertRaises(TypeError):
            finance.discount_factor(
                Decimal("0.05"), periods=2.5  # type: ignore[arg-type]
            )

    def test_direction_and_round_trip(self) -> None:
        low = finance.present_value(
            Decimal("1000"), periodic_rate=Decimal("0.03"), periods=2
        )
        high = finance.present_value(
            Decimal("1000"), periodic_rate=Decimal("0.07"), periods=2
        )
        self.assertLess(high, low)
        future = finance.future_value(
            Decimal("1234.56"), periodic_rate=Decimal("0.037"), periods=17
        )
        recovered = finance.present_value(
            future, periodic_rate=Decimal("0.037"), periods=17
        )
        with localcontext() as context:
            context.prec = 60
            context.traps[Inexact] = False
            self.assertLessEqual(
                abs(recovered - Decimal("1234.56")), Decimal("1e-30")
            )

    def test_caller_context_preservation(self) -> None:
        with localcontext() as outer:
            outer.prec = 6
            outer.rounding = ROUND_DOWN
            outer.Emin = -9
            outer.Emax = 9
            outer.traps[Inexact] = True
            outer.flags[Inexact] = True
            flags_before = dict(outer.flags)
            traps_before = dict(outer.traps)
            settings_before = (
                outer.prec, outer.rounding, outer.Emin, outer.Emax,
                outer.capitals, outer.clamp,
            )
            finance.accumulation_factor(Decimal("0.037"), periods=17)
            finance.discount_factor(Decimal("0.037"), periods=17)
            finance.future_value(
                Decimal("100"), periodic_rate=Decimal("0.037"), periods=17
            )
            finance.present_value(
                Decimal("100"), periodic_rate=Decimal("0.037"), periods=17
            )
            finance.periodic_rate_from_nominal(
                Decimal("0.10"), periods_per_year=12
            )
            finance.effective_annual_rate(
                Decimal("0.01"), periods_per_year=12
            )
            finance.present_value_from_nominal(
                Decimal("100"), nominal_annual_rate=Decimal("0.10"),
                periods_per_year=12, periods=17,
            )
            self.assertEqual(dict(outer.flags), flags_before)
            self.assertEqual(dict(outer.traps), traps_before)
            self.assertEqual(
                (
                    outer.prec, outer.rounding, outer.Emin, outer.Emax,
                    outer.capitals, outer.clamp,
                ), settings_before,
            )

    def test_context_after_overflow(self) -> None:
        with localcontext() as outer:
            flags_before = dict(outer.flags)
            with self.assertRaises(Overflow):
                finance.accumulation_factor(Decimal("1e999999"), periods=2)
            self.assertEqual(dict(outer.flags), flags_before)


if __name__ == "__main__":
    unittest.main()
```

The three narrow type-checking ignores label deliberately invalid runtime inputs. They do not suppress implementation diagnostics.

The tolerance used in the round-trip case is specific to its input scale and 40-digit policy. The independent known-value tests remain necessary because inverse functions can share a defect.

## 3.14.7 File 3 — demo_function_library.py

```python
"""Display one educational scenario without adding I/O to the library."""

from decimal import Decimal
from financial_functions import (
    effective_annual_rate,
    future_value,
    periodic_rate_from_nominal,
    present_value_from_nominal,
)


def main() -> None:
    """Convert a quotation, value one amount, and report the results."""
    nominal = Decimal("0.12")
    monthly = periodic_rate_from_nominal(nominal, periods_per_year=12)
    annual = effective_annual_rate(monthly, periods_per_year=12)
    future = future_value(
        Decimal("1000"), periodic_rate=monthly, periods=12
    )
    present = present_value_from_nominal(
        future, nominal_annual_rate=nominal,
        periods_per_year=12, periods=12,
    )
    print(f"Monthly effective rate: {monthly:.2%}")
    print(f"Effective annual rate: {annual:.6%}")
    print(f"Future value: {future:.2f}")
    print(f"Recovered present value: {present:.2f}")


if __name__ == "__main__":
    main()
```

This scenario uses a nominal 12% annual quotation compounded monthly for 12 months. It is an assumption, not a market forecast. Formatting is the reporting boundary and does not quantize the returned amounts.

## 3.14.9 Review the Integration

The project keeps the financial calculations separate from reporting. Inputs are required by keyword where their meanings could be confused, and internal validation helpers keep shared policies aligned.

All public calculations isolate arithmetic context. This includes nominal conversion: even unary negation and rate-domain checks that can involve context-sensitive Decimal operations execute inside the fixed policy where needed.

The demo composes conversion, accumulation, and discounting. Its recovered amount is a consistency check, while independent test cases establish simple known values.

## 3.14.11 Common Problems and Recovery

| Problem | Likely explanation | Action |
|---|---|---|
| Cannot import financial_functions | Wrong working directory or filename | Place files together and run from that directory |
| Calling with positional rate fails | Keyword-only interface | Name periodic_rate and periods |
| Monthly valuation is too large | Annual quotation used as monthly rate | Use the nominal converter |
| Results differ from earlier examples in last digits | Fixed policy replaces ambient policy in this project | Compare the documented numerical contracts |
| Caller trap unexpectedly fires | Arithmetic escaped the isolated context | Review every arithmetic stage |
| All round trips pass but known value fails | Shared formula defect | Fix the model and preserve independent cases |
| Formatting looks correct but arithmetic is wrong | Display hides a discrepancy | Check numeric results before formatting |
