## 4.10.1 Purpose

A security description and a portfolio position answer different questions. A description identifies an instrument; a position records how many units a portfolio holds. Keeping those records separate prevents repeated descriptions from drifting apart and makes unknown references visible.

This section defines a deliberately small catalog and portfolio snapshot. The lab joins validated holdings to catalog metadata, rejects unresolved references, and returns independent report records. It does not calculate market values or model the legal terms of an instrument.

## 4.10.2 Learning Objectives

You should be able to:

1. Separate catalog metadata from portfolio-specific holdings.
2. Define security, portfolio, and position identity scopes.
3. Use a dictionary lookup to resolve a holding's reference.
4. Reject duplicate identities and unknown security references.
5. Explain the limits of currency and quantity fields.
6. Preserve zero holdings, metadata, and source ownership.
7. Test a small join with explicit output and failure contracts.

## 4.10.3 Three Different Records

| Record | Question answered | Teaching fields |
|---|---|---|
| Security | Which instrument is described? | security_id, name, quote_currency |
| Portfolio | Which collection and snapshot? | portfolio_id, snapshot_id, holdings |
| Holding | How many units of an instrument? | security_id, quantity |

These fields are local teaching conventions. The identifiers are synthetic internal IDs, not validated exchange symbols, ISINs, or other standardized identifiers. A display name is not an identity key.

The lab permits one holding per security in a portfolio snapshot. A tax-lot model would require lot identity and acquisition information. A multi-account model would require account identity. Do not silently combine those records merely because they reference the same security.

## 4.10.4 A Catalog and a Holding

Run the introductory Python blocks in order in one session.

```python
from decimal import Decimal

catalog_rows = [
    {"security_id": "SEC-A", "name": "Example Equity", "quote_currency": "USD"},
    {"security_id": "SEC-B", "name": "Example Fund", "quote_currency": "EUR"},
]
# Safe for this known-unique teaching fixture; validate duplicates in the lab.
catalog = {row["security_id"]: row for row in catalog_rows}
holding = {"security_id": "SEC-A", "quantity": Decimal("12.5")}
security = catalog[holding["security_id"]]
assert security["name"] == "Example Equity"
assert holding["quantity"] == Decimal("12.5")
```

A catalog dictionary supports direct lookup. Building it from unvalidated rows can replace an earlier duplicate key. The lab checks each identifier before insertion.

The quantity is instrument units. It is not an amount of money. Quote currency describes how a later price observation would be labeled under this simplified schema; it does not provide a price or establish the portfolio's reporting currency.

## 4.10.5 Resolve References Explicitly

An unresolved security ID is a data-quality error in this lab. Returning a made-up name or zero price would hide a missing reference.

```python
unknown_id = "SEC-MISSING"
assert unknown_id not in catalog

report_row = {
    "portfolio_id": "PORT-01",
    "snapshot_id": "SNAP-01",
    "security_id": holding["security_id"],
    "name": security["name"],
    "quote_currency": security["quote_currency"],
    "quantity": holding["quantity"],
}
assert report_row["portfolio_id"] == "PORT-01"
assert report_row["quote_currency"] == "USD"
```

The flat row carries parent identity so it remains interpretable outside its original list. In this representation, metadata is copied into a derived report while the source catalog remains separate.

The catalog is a supplied snapshot too. This function trusts the caller to pair it with the correct portfolio snapshot. Historical effective dates, corporate actions, identifier changes, and price provenance require additional fields and rules.

## 4.10.6 Identity and Quantity Policies

The same security may appear once in each of several portfolios. That is different from a duplicate holding inside one portfolio. Identity must always be interpreted within its scope.

```python
portfolio_keys = [("PORT-01", "SEC-A"), ("PORT-02", "SEC-A")]
assert len(set(portfolio_keys)) == 2
```

This lab accepts fractional and zero quantities but rejects negative quantities. That is a long-only teaching policy, not a universal rule for portfolio systems. Short positions, derivatives, bond nominal amounts, and contract multipliers require explicit unit definitions and instrument-specific conventions.

Do not total quantities across unrelated instruments and describe the result as exposure. Valuation would need applicable prices, observation times, price units, and conversion rules. Those inputs are intentionally absent here.

## 4.10.7 Lab Contract — Enriched Holdings Snapshot

Save the complete block below as `securities_portfolios_lab.py`. Use Python 3.10 or later; only the standard library is required.

| Input/output | Contract |
|---|---|
| Catalog | List of records with exactly security_id, name, quote_currency |
| Portfolio | Dictionary with exactly portfolio_id, snapshot_id, holdings |
| Holding | Dictionary with exactly security_id, quantity |
| IDs and names | Nonempty strings without surrounding whitespace; case preserved |
| quote_currency | USD or EUR |
| quantity | Finite nonnegative Decimal instrument units |
| Catalog identity | Unique security_id throughout supplied catalog |
| Holding identity | Unique security_id within this portfolio |
| Reference integrity | Every holding ID must exist in catalog, including zero holdings |
| Output | Portfolio wrapper with enriched holdings in source holding order |
| Empty holdings | Accepted; portfolio and snapshot IDs retained |
| Unused catalog records | Allowed, but still validated |
| Ownership | Fresh wrapper, list, and record dictionaries; immutable scalar values may be shared |
| Failure | TypeError for wrong types; ValueError for schema, domain, duplicate, or reference violations |

The function validates the entire catalog and portfolio before returning. No partial report is returned on an error. It never fetches market data or computes prices, values, weights, or performance.

## 4.10.8 Complete Runnable Lab

```python
"""Resolve a single portfolio snapshot against a validated security catalog."""

from decimal import Decimal
import unittest


def checked_text(value: object, label: str) -> str:
    if not isinstance(value, str):
        raise TypeError(f"{label} must be a string")
    if not value or value.strip() != value:
        raise ValueError(f"{label} must be nonempty and unpadded")
    return value


def enrich_portfolio(catalog_value: object, portfolio_value: object) -> dict[str, object]:
    """Return independent holdings enriched from a unique security catalog.

    Preserve source holding order and valid zero quantities. Reject unknown
    references and duplicate holdings. No valuation or aggregation is performed.
    """
    if not isinstance(catalog_value, list):
        raise TypeError("catalog must be a list")
    catalog: dict[str, tuple[str, str]] = {}
    for index, row in enumerate(catalog_value):
        if not isinstance(row, dict):
            raise TypeError(f"catalog row {index} must be a dictionary")
        if set(row) != {"security_id", "name", "quote_currency"}:
            raise ValueError(f"catalog row {index} has incorrect fields")
        security_id = checked_text(row["security_id"], "security_id")
        name = checked_text(row["name"], "name")
        currency = checked_text(row["quote_currency"], "quote_currency")
        if currency not in {"USD", "EUR"}:
            raise ValueError("quote_currency must be USD or EUR")
        if security_id in catalog:
            raise ValueError(f"duplicate catalog security_id: {security_id}")
        catalog[security_id] = (name, currency)

    if not isinstance(portfolio_value, dict):
        raise TypeError("portfolio must be a dictionary")
    if set(portfolio_value) != {"portfolio_id", "snapshot_id", "holdings"}:
        raise ValueError("portfolio has incorrect fields")
    portfolio_id = checked_text(portfolio_value["portfolio_id"], "portfolio_id")
    snapshot_id = checked_text(portfolio_value["snapshot_id"], "snapshot_id")
    holdings = portfolio_value["holdings"]
    if not isinstance(holdings, list):
        raise TypeError("holdings must be a list")
    seen: set[str] = set()
    output_rows: list[dict[str, object]] = []
    for index, row in enumerate(holdings):
        if not isinstance(row, dict):
            raise TypeError(f"holding {index} must be a dictionary")
        if set(row) != {"security_id", "quantity"}:
            raise ValueError(f"holding {index} has incorrect fields")
        security_id = checked_text(row["security_id"], "holding security_id")
        quantity = row["quantity"]
        if not isinstance(quantity, Decimal):
            raise TypeError(f"holding {index} quantity must be Decimal")
        if not quantity.is_finite() or quantity < 0:
            raise ValueError(f"holding {index} quantity must be finite and nonnegative")
        if security_id in seen:
            raise ValueError(f"duplicate holding security_id: {security_id}")
        if security_id not in catalog:
            raise ValueError(f"unknown security_id: {security_id}")
        seen.add(security_id)
        name, currency = catalog[security_id]
        output_rows.append({
            "portfolio_id": portfolio_id,
            "snapshot_id": snapshot_id,
            "security_id": security_id,
            "name": name,
            "quote_currency": currency,
            "quantity": quantity,
        })
    return {"portfolio_id": portfolio_id, "snapshot_id": snapshot_id, "holdings": output_rows}


def sample_catalog() -> list[dict[str, object]]:
    return [
        {"security_id": "SEC-A", "name": "Example Equity", "quote_currency": "USD"},
        {"security_id": "SEC-B", "name": "Example Fund", "quote_currency": "EUR"},
    ]


def sample_portfolio() -> dict[str, object]:
    return {
        "portfolio_id": "PORT-01", "snapshot_id": "SNAP-01",
        "holdings": [
            {"security_id": "SEC-B", "quantity": Decimal("0")},
            {"security_id": "SEC-A", "quantity": Decimal("12.5")},
        ],
    }


def portfolio_with_holdings(holdings: object) -> dict[str, object]:
    portfolio = sample_portfolio()
    portfolio["holdings"] = holdings
    return portfolio


class PortfolioTests(unittest.TestCase):
    def test_exact_join_order_and_zero(self) -> None:
        self.assertEqual(enrich_portfolio(sample_catalog(), sample_portfolio()), {
            "portfolio_id": "PORT-01", "snapshot_id": "SNAP-01", "holdings": [
                {"portfolio_id": "PORT-01", "snapshot_id": "SNAP-01", "security_id": "SEC-B",
                 "name": "Example Fund", "quote_currency": "EUR", "quantity": Decimal("0")},
                {"portfolio_id": "PORT-01", "snapshot_id": "SNAP-01", "security_id": "SEC-A",
                 "name": "Example Equity", "quote_currency": "USD", "quantity": Decimal("12.5")},
            ],
        })

    def test_empty_and_unused_catalog(self) -> None:
        expected = {"portfolio_id": "PORT-01", "snapshot_id": "SNAP-01", "holdings": []}
        self.assertEqual(enrich_portfolio([], portfolio_with_holdings([])), expected)
        self.assertEqual(enrich_portfolio(sample_catalog(), portfolio_with_holdings([])), expected)
        invalid_catalog = sample_catalog()
        invalid_catalog.append({"security_id": "UNUSED", "name": "Bad", "quote_currency": "GBP"})
        with self.assertRaises(ValueError):
            enrich_portfolio(invalid_catalog, portfolio_with_holdings([]))

    def test_duplicates_and_unknown_zero_reference(self) -> None:
        catalog = sample_catalog()
        catalog.append(dict(catalog[0]))
        with self.assertRaises(ValueError):
            enrich_portfolio(catalog, sample_portfolio())
        with self.assertRaises(ValueError):
            enrich_portfolio(sample_catalog(), portfolio_with_holdings([
                {"security_id": "SEC-A", "quantity": Decimal("1")},
                {"security_id": "SEC-A", "quantity": Decimal("0")},
            ]))
        with self.assertRaises(ValueError):
            enrich_portfolio(sample_catalog(), portfolio_with_holdings([
                {"security_id": "MISSING", "quantity": Decimal("0")}
            ]))

    def test_quantity_types_and_domains(self) -> None:
        for quantity in (None, True, 1, 1.5, "2"):
            with self.subTest(quantity=quantity):
                with self.assertRaises(TypeError):
                    enrich_portfolio(sample_catalog(), portfolio_with_holdings([
                        {"security_id": "SEC-A", "quantity": quantity}
                    ]))
        for text in ("NaN", "sNaN", "Infinity", "-Infinity", "-1"):
            with self.subTest(text=text):
                with self.assertRaises(ValueError):
                    enrich_portfolio(sample_catalog(), portfolio_with_holdings([
                        {"security_id": "SEC-A", "quantity": Decimal(text)}
                    ]))

    def test_schema_and_text(self) -> None:
        with self.assertRaises(TypeError):
            enrich_portfolio({}, sample_portfolio())
        with self.assertRaises(TypeError):
            enrich_portfolio([None], sample_portfolio())
        with self.assertRaises(ValueError):
            enrich_portfolio([{}], sample_portfolio())
        with self.assertRaises(TypeError):
            enrich_portfolio(sample_catalog(), [])
        with self.assertRaises(ValueError):
            enrich_portfolio(sample_catalog(), {})
        with self.assertRaises(TypeError):
            enrich_portfolio(sample_catalog(), portfolio_with_holdings(None))
        with self.assertRaises(TypeError):
            enrich_portfolio(sample_catalog(), portfolio_with_holdings([None]))
        with self.assertRaises(ValueError):
            enrich_portfolio(sample_catalog(), portfolio_with_holdings([{}]))
        for field in ("security_id", "name", "quote_currency"):
            for bad in (None, "", " padded "):
                catalog = sample_catalog()
                catalog[0][field] = bad
                error = TypeError if bad is None else ValueError
                with self.subTest(field=field, bad=bad):
                    with self.assertRaises(error):
                        enrich_portfolio(catalog, sample_portfolio())
        for field in ("portfolio_id", "snapshot_id"):
            portfolio = sample_portfolio()
            portfolio[field] = " "
            with self.assertRaises(ValueError):
                enrich_portfolio(sample_catalog(), portfolio)

    def test_ownership_and_repeatability(self) -> None:
        catalog = sample_catalog()
        portfolio = sample_portfolio()
        report = enrich_portfolio(catalog, portfolio)
        self.assertEqual(catalog, sample_catalog())
        self.assertEqual(portfolio, sample_portfolio())
        rows = report["holdings"]
        if not isinstance(rows, list):
            self.fail("holdings must be a list")
        rows[0]["name"] = "Changed"
        rows[1]["quantity"] = Decimal("99")
        rows.append({})
        report["portfolio_id"] = "Changed"
        self.assertEqual(catalog, sample_catalog())
        self.assertEqual(portfolio, sample_portfolio())
        self.assertEqual(enrich_portfolio(catalog, portfolio),
                         enrich_portfolio(sample_catalog(), sample_portfolio()))

    def test_invalid_later_holding_preserves_source(self) -> None:
        portfolio = portfolio_with_holdings([
            {"security_id": "SEC-A", "quantity": Decimal("1")},
            {"security_id": "UNKNOWN", "quantity": Decimal("2")},
        ])
        before = portfolio["holdings"]
        with self.assertRaises(ValueError):
            enrich_portfolio(sample_catalog(), portfolio)
        self.assertIs(portfolio["holdings"], before)
        self.assertEqual(portfolio["holdings"], [
            {"security_id": "SEC-A", "quantity": Decimal("1")},
            {"security_id": "UNKNOWN", "quantity": Decimal("2")},
        ])


if __name__ == "__main__":
    unittest.main(verbosity=2)
```

## 4.10.10 Boundaries of the Model

A production security master generally needs richer identity and time semantics. This educational catalog is only a supplied metadata collection. A snapshot label does not verify that records were observed simultaneously or that all holdings are present.

Before extending the model, answer concrete questions: Are quantities shares, contracts, or nominal units? Can a position be negative? Are holdings aggregated or lot-level? Which catalog version applies? What timestamp and source identify a price? How is currency conversion defined?

Use additional fields only when their behavior is specified. Adding an asset_type label alone does not implement instrument-specific valuation. Likewise, attaching a price field without quote units and observation basis can produce a plausible but misleading multiplication.

## 4.10.11 Troubleshooting

| Symptom | Cause to inspect | Correction |
|---|---|---|
| One catalog record disappears | Duplicate ID overwritten | Reject duplicates before insertion |
| Holding has a blank description | Unresolved reference hidden | Reject or explicitly quarantine missing references |
| Same security cannot exist in two portfolios | Identity scope too broad | Include portfolio identity in cross-portfolio keys |
| Zero holding disappears | Truth testing used as selection | Preserve it under the declared contract |
| Report edits alter master data | Shared record dictionaries | Reconstruct output records |
| Monetary total has no clear meaning | Quantity/currency semantics missing | Specify valuation inputs before arithmetic |
| Tax lots collapse | Security ID used as lot identity | Define a separate lot key |

## 4.10.13 Key Takeaways

Represent security descriptions separately from portfolio holdings. Define identity scopes, validate references, and preserve quantity units before adding financial calculations.

A successful join establishes consistency within the supplied dataset. Financial completeness, historical correctness, and valuation remain separate responsibilities.
