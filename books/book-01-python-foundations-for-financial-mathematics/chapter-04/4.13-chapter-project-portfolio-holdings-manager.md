## 4.13.1 Project Goal

Build an in-memory manager for one portfolio snapshot. It loads validated holdings, resolves security descriptions, supports explicit add/replace/remove operations, and produces a deterministic report. Each operation returns a new portfolio dictionary so a failed command cannot partially change the baseline.

The project integrates lists, tuples, dictionaries, sets, comprehensions, sorting, and ownership contracts. It manages supplied instrument quantities. It does not execute trades or compute market values, weights, returns, or currency conversions.

## 4.13.2 Learning Objectives

On completion, you should be able to:

1. Validate a catalog and portfolio before constructing a report.
2. Enforce unique identity and reference integrity.
3. Distinguish add, replace, and remove behavior.
4. Preserve baseline records through successful and failed operations.
5. Carry a caller-supplied revision label into a new snapshot.
6. Report all or active holdings in a stable, explicit ID order.
7. Verify end-to-end command sequences and rejection cases.

## 4.13.3 Requirements and Boundaries

This is a long-only aggregate-holdings model: one holding per security in one portfolio. Quantity is finite nonnegative Decimal instrument units; zero holdings remain stored until explicitly removed. Fractional units are accepted under this teaching contract.

The catalog contains synthetic internal security IDs, display names, and quote currencies. Only USD and EUR labels are supported. Quote currency is metadata for a potential price observation, not a conversion rate or reporting-currency declaration.

The manager uses no database, network service, global mutable state, or background cache. A revision label distinguishes the immediate result from its parent; the program does not enforce global label uniqueness or persist an audit history. The caller retains prior snapshots and associates them with source/version metadata.

## 4.13.4 Schemas and Identity

| Record | Exact fields | Identity scope |
|---|---|---|
| Catalog row | security_id, name, quote_currency | security_id unique in supplied catalog |
| Portfolio | portfolio_id, snapshot_id, holdings | One caller-supplied portfolio snapshot |
| Holding | security_id, quantity | security_id unique in this portfolio |
| Report row | security_id, name, quote_currency, quantity | One row per selected holding |

IDs and names must be exact nonempty unpadded strings. Quantities must be exact Decimal values. Exact scalar types keep the ownership contract narrow and exclude subclasses with extra behavior.

Portfolio identity is preserved by commands. A new snapshot_id must differ from the immediate input label, including for a replacement with the same quantity. It is a caller-chosen revision identifier, not a computed valuation timestamp.

## 4.13.5 Structure Choices

The input catalog is a list so duplicate IDs can be detected before creating its dictionary index. The index supports reference lookup. A set detects repeated holding IDs. Holdings remain a list to preserve source order, and each validated pair is temporarily represented by a tuple.

Report rows are reconstructed and sorted by security_id using Python's case-sensitive string ordering. The report wrapper retains portfolio and snapshot identity even when its row list is empty. Reports are disposable views and do not update a portfolio when edited.

## 4.13.6 Command Contracts

| Command | Preconditions | Result |
|---|---|---|
| add | Security exists in catalog and is absent from holdings | Append one holding |
| replace | Holding already exists | Replace its quantity at the same position |
| remove | Holding already exists; quantity argument is None | Remove that holding |
| report | Complete valid catalog and portfolio | Fresh ID-sorted enriched view |

Unknown operations, unknown securities, duplicate additions, missing replacement/removal targets, reused immediate snapshot labels, and invalid quantities are errors. Removing a holding is a deliberate data operation, not a trade or liquidation.

The whole input catalog and portfolio are validated before command application or report filtering. Even an unused catalog record or excluded zero holding must satisfy its schema. Type errors raise TypeError; schema, domain, identity, and reference errors raise ValueError.

## 4.13.7 Implementation Plan

Implement the project in three pieces, supplied below in full:

1. Validate input and return fresh canonical records plus a catalog lookup.
2. Construct a new command result without modifying the canonical baseline.
3. Build reports from validated inputs and test all public workflows.

Validation helpers are shared so command and report functions apply the same rules. They do not use dictionary defaults to turn missing quantities into zero. There is no partial output on validation failure.

## 4.13.8 Complete Runnable Project

Save this entire block as `portfolio_holdings_manager.py`. Use Python 3.10 or later with the standard library.

```python
"""In-memory aggregate holdings commands with explicit validation and ownership."""

from decimal import Decimal
import unittest

Catalog = dict[str, tuple[str, str]]
Holding = tuple[str, Decimal]


def text(value: object, label: str) -> str:
    if type(value) is not str:
        raise TypeError(f"{label} must be an exact str")
    if not value or value.strip() != value:
        raise ValueError(f"{label} must be nonempty and unpadded")
    return value


def quantity_value(value: object) -> Decimal:
    if type(value) is not Decimal:
        raise TypeError("quantity must be an exact Decimal")
    if not value.is_finite() or value < 0:
        raise ValueError("quantity must be finite and nonnegative")
    return value


def validated_inputs(
    catalog_value: object, portfolio_value: object,
) -> tuple[Catalog, str, str, list[Holding]]:
    if not isinstance(catalog_value, list):
        raise TypeError("catalog must be a list")
    catalog: Catalog = {}
    for row in catalog_value:
        if not isinstance(row, dict):
            raise TypeError("catalog row must be a dictionary")
        if set(row) != {"security_id", "name", "quote_currency"}:
            raise ValueError("catalog row has incorrect fields")
        sid = text(row["security_id"], "security_id")
        name = text(row["name"], "name")
        currency = text(row["quote_currency"], "quote_currency")
        if currency not in {"USD", "EUR"}:
            raise ValueError("quote_currency must be USD or EUR")
        if sid in catalog:
            raise ValueError(f"duplicate catalog ID: {sid}")
        catalog[sid] = (name, currency)
    if not isinstance(portfolio_value, dict):
        raise TypeError("portfolio must be a dictionary")
    if set(portfolio_value) != {"portfolio_id", "snapshot_id", "holdings"}:
        raise ValueError("portfolio has incorrect fields")
    pid = text(portfolio_value["portfolio_id"], "portfolio_id")
    revision = text(portfolio_value["snapshot_id"], "snapshot_id")
    rows = portfolio_value["holdings"]
    if not isinstance(rows, list):
        raise TypeError("holdings must be a list")
    holdings: list[Holding] = []
    seen: set[str] = set()
    for row in rows:
        if not isinstance(row, dict):
            raise TypeError("holding must be a dictionary")
        if set(row) != {"security_id", "quantity"}:
            raise ValueError("holding has incorrect fields")
        sid = text(row["security_id"], "holding security_id")
        amount = quantity_value(row["quantity"])
        if sid in seen:
            raise ValueError(f"duplicate holding ID: {sid}")
        if sid not in catalog:
            raise ValueError(f"unknown holding security: {sid}")
        seen.add(sid)
        holdings.append((sid, amount))
    return catalog, pid, revision, holdings


def portfolio_record(pid: str, revision: str, holdings: list[Holding]) -> dict[str, object]:
    return {
        "portfolio_id": pid, "snapshot_id": revision,
        "holdings": [{"security_id": sid, "quantity": q} for sid, q in holdings],
    }


def apply_command(
    catalog_value: object, portfolio_value: object, *, operation: object,
    security_id: object, quantity: object = None, next_snapshot_id: object,
) -> dict[str, object]:
    """Return a new snapshot after add/replace/remove; never mutate the input.

    Quantity is an absolute replacement, not a trade delta. Remove requires
    quantity=None. Revision labels differ from the immediate parent only.
    """
    catalog, pid, revision, holdings = validated_inputs(catalog_value, portfolio_value)
    action = text(operation, "operation")
    if action not in {"add", "replace", "remove"}:
        raise ValueError("operation must be add, replace, or remove")
    target = text(security_id, "security_id")
    new_revision = text(next_snapshot_id, "next_snapshot_id")
    if new_revision == revision:
        raise ValueError("next_snapshot_id must differ from the parent")
    if target not in catalog:
        raise ValueError(f"unknown security: {target}")
    present = target in {sid for sid, q in holdings}
    if action == "add" and present:
        raise ValueError("add target already exists")
    if action in {"replace", "remove"} and not present:
        raise ValueError("target holding does not exist")
    if action == "remove":
        if quantity is not None:
            raise ValueError("remove requires quantity=None")
        changed = [(sid, q) for sid, q in holdings if sid != target]
    else:
        amount = quantity_value(quantity)
        if action == "add":
            changed = holdings + [(target, amount)]
        else:
            changed = [(sid, amount if sid == target else q) for sid, q in holdings]
    return portfolio_record(pid, new_revision, changed)


def holding_key(row: Holding) -> str:
    return row[0]


def holdings_report(
    catalog_value: object, portfolio_value: object, *, active_only: object = False,
) -> dict[str, object]:
    """Return fresh ID-sorted rows; active means strictly positive quantity."""
    catalog, pid, revision, holdings = validated_inputs(catalog_value, portfolio_value)
    if type(active_only) is not bool:
        raise TypeError("active_only must be bool")
    selected = [(sid, q) for sid, q in holdings if not active_only or q > 0]
    rows: list[dict[str, object]] = []
    for sid, amount in sorted(selected, key=holding_key):
        name, currency = catalog[sid]
        rows.append({"security_id": sid, "name": name,
                     "quote_currency": currency, "quantity": amount})
    return {"portfolio_id": pid, "snapshot_id": revision, "rows": rows}


def sample_catalog() -> list[dict[str, object]]:
    return [
        {"security_id": "SEC-A", "name": "Example Equity", "quote_currency": "USD"},
        {"security_id": "SEC-B", "name": "Example Fund", "quote_currency": "EUR"},
        {"security_id": "SEC-C", "name": "Example Holding", "quote_currency": "USD"},
    ]


def sample_portfolio() -> dict[str, object]:
    return portfolio_record("PORT-01", "S0", [
        ("SEC-B", Decimal("0")), ("SEC-A", Decimal("12.5")),
    ])


class ManagerTests(unittest.TestCase):
    def test_exact_report_and_active_selection(self) -> None:
        catalog, source = sample_catalog(), sample_portfolio()
        expected = [
            {"security_id": "SEC-A", "name": "Example Equity", "quote_currency": "USD", "quantity": Decimal("12.5")},
            {"security_id": "SEC-B", "name": "Example Fund", "quote_currency": "EUR", "quantity": Decimal("0")},
        ]
        self.assertEqual(holdings_report(catalog, source), {
            "portfolio_id": "PORT-01", "snapshot_id": "S0", "rows": expected
        })
        self.assertEqual(holdings_report(catalog, source, active_only=True)["rows"], expected[:1])

    def test_command_sequence(self) -> None:
        catalog, baseline = sample_catalog(), sample_portfolio()
        added = apply_command(catalog, baseline, operation="add", security_id="SEC-C",
                              quantity=Decimal("3"), next_snapshot_id="S1")
        replaced = apply_command(catalog, added, operation="replace", security_id="SEC-A",
                                 quantity=Decimal("20"), next_snapshot_id="S2")
        removed = apply_command(catalog, replaced, operation="remove", security_id="SEC-B",
                                next_snapshot_id="S3")
        self.assertEqual(removed, portfolio_record("PORT-01", "S3", [
            ("SEC-A", Decimal("20")), ("SEC-C", Decimal("3"))
        ]))
        self.assertEqual(baseline, sample_portfolio())
        self.assertEqual(added, portfolio_record("PORT-01", "S1", [
            ("SEC-B", Decimal("0")), ("SEC-A", Decimal("12.5")), ("SEC-C", Decimal("3"))
        ]))

    def test_empty_and_remove_last(self) -> None:
        empty = portfolio_record("P", "S0", [])
        self.assertEqual(holdings_report([], empty), {"portfolio_id": "P", "snapshot_id": "S0", "rows": []})
        one = apply_command(sample_catalog(), empty, operation="add", security_id="SEC-A",
                            quantity=Decimal("0"), next_snapshot_id="S1")
        self.assertEqual(apply_command(sample_catalog(), one, operation="remove", security_id="SEC-A",
                                       next_snapshot_id="S2"), portfolio_record("P", "S2", []))

    def test_failed_commands_preserve_baseline(self) -> None:
        source = sample_portfolio()
        for action, sid, quantity in (
            ("add", "SEC-A", Decimal("1")), ("replace", "SEC-C", Decimal("1")),
            ("remove", "SEC-C", None), ("add", "UNKNOWN", Decimal("1")),
            ("trade", "SEC-A", Decimal("1")), ("remove", "SEC-A", Decimal("0")),
        ):
            with self.subTest(action=action, sid=sid):
                with self.assertRaises(ValueError):
                    apply_command(sample_catalog(), source, operation=action, security_id=sid,
                                  quantity=quantity, next_snapshot_id="S1")
                self.assertEqual(source, sample_portfolio())

    def test_revision_and_command_types(self) -> None:
        for revision in ("S0", "", " S1"):
            with self.assertRaises(ValueError):
                apply_command(sample_catalog(), sample_portfolio(), operation="replace", security_id="SEC-A",
                              quantity=Decimal("1"), next_snapshot_id=revision)
        with self.assertRaises(TypeError):
            apply_command(sample_catalog(), sample_portfolio(), operation=None, security_id="SEC-A",
                          quantity=Decimal("1"), next_snapshot_id="S1")
        with self.assertRaises(TypeError):
            holdings_report(sample_catalog(), sample_portfolio(), active_only=1)

    def test_quantity_rejection(self) -> None:
        for quantity in (True, 1, 1.5, "1", None):
            with self.subTest(quantity=quantity):
                with self.assertRaises(TypeError):
                    apply_command(sample_catalog(), sample_portfolio(), operation="replace", security_id="SEC-A",
                                  quantity=quantity, next_snapshot_id="S1")
        for value in ("NaN", "sNaN", "Infinity", "-Infinity", "-1"):
            with self.assertRaises(ValueError):
                apply_command(sample_catalog(), sample_portfolio(), operation="add", security_id="SEC-C",
                              quantity=Decimal(value), next_snapshot_id="S1")

    def test_duplicate_and_unknown_inputs(self) -> None:
        catalog = sample_catalog()
        catalog.append(dict(catalog[0]))
        with self.assertRaises(ValueError):
            holdings_report(catalog, sample_portfolio())
        for rows in ([ ("SEC-A", Decimal("1")), ("SEC-A", Decimal("2")) ],
                     [ ("UNKNOWN", Decimal("0")) ]):
            with self.assertRaises(ValueError):
                holdings_report(sample_catalog(), portfolio_record("P", "S", rows), active_only=True)

    def test_schema_and_unused_catalog(self) -> None:
        with self.assertRaises(TypeError):
            holdings_report({}, sample_portfolio())
        with self.assertRaises(ValueError):
            holdings_report(sample_catalog(), {})
        with self.assertRaises(TypeError):
            holdings_report([None], sample_portfolio())
        with self.assertRaises(ValueError):
            holdings_report([{}], sample_portfolio())
        bad = sample_catalog()
        bad[2]["quote_currency"] = "GBP"
        with self.assertRaises(ValueError):
            holdings_report(bad, sample_portfolio())
        source = sample_portfolio()
        source["holdings"] = [{"security_id": "SEC-A", "quantity": Decimal("1"), "extra": 1}]
        with self.assertRaises(ValueError):
            holdings_report(sample_catalog(), source)

    def test_output_ownership(self) -> None:
        catalog, source = sample_catalog(), sample_portfolio()
        changed = apply_command(catalog, source, operation="replace", security_id="SEC-A",
                                quantity=Decimal("99"), next_snapshot_id="S1")
        rows = changed["holdings"]
        if not isinstance(rows, list):
            self.fail("holdings must be a list")
        rows[0]["quantity"] = Decimal("88")
        report = holdings_report(catalog, source)
        report_rows = report["rows"]
        if not isinstance(report_rows, list):
            self.fail("rows must be a list")
        report_rows[0]["name"] = "Changed"
        self.assertEqual(source, sample_portfolio())
        self.assertEqual(catalog, sample_catalog())
        fresh_rows = holdings_report(catalog, source)["rows"]
        if not isinstance(fresh_rows, list):
            self.fail("rows must be a list")
        self.assertEqual(fresh_rows[0]["name"], "Example Equity")

    def test_invalid_later_input_prevents_command(self) -> None:
        source = sample_portfolio()
        source["holdings"] = [
            {"security_id": "SEC-A", "quantity": Decimal("1")},
            {"security_id": "SEC-B", "quantity": "invalid"},
        ]
        before = source["holdings"]
        with self.assertRaises(TypeError):
            apply_command(sample_catalog(), source, operation="replace", security_id="SEC-A",
                          quantity=Decimal("2"), next_snapshot_id="S1")
        self.assertIs(source["holdings"], before)
        self.assertEqual(source["holdings"], [
            {"security_id": "SEC-A", "quantity": Decimal("1")},
            {"security_id": "SEC-B", "quantity": "invalid"},
        ])


if __name__ == "__main__":
    unittest.main(verbosity=2)
```

## 4.13.11 Review the Failure Boundary

A command builds its result locally and returns only after successful validation. This provides input preservation in this single-process function design. It does not provide database transactions, concurrent update protection, or durable rollback.

If two callers start with S0 independently, both can create competing successors. A persisted application would need version checks and a commit policy. Reusing a historical label other than the immediate parent's is also possible here; global revision management belongs outside this teaching function.

Reports retain IDs, names, currencies, and quantities but omit cash flows, prices, lots, and settlement states. No monetary comparison is implied by sorting security IDs or counting rows.

## 4.13.13 Troubleshooting

| Problem | Inspect | Correction |
|---|---|---|
| Duplicate add rejected | Target already held | Use replace for an absolute new quantity |
| Missing target on replace | Target absent from holdings | Use add if insertion is intended |
| Zero holding still listed | Storage policy retains zero | Use active report or explicit remove |
| Revision rejected | Same immediate parent label | Supply a new revision ID |
| Unknown security rejected | Catalog reference unresolved | Supply correct validated catalog metadata |
| Report edit does not update holdings | Report is a disposable view | Apply a command to the portfolio |
| Invalid unused catalog row blocks operation | Full catalog validation | Correct the supplied catalog |
| Mixed currencies lack total | No valuation inputs | Specify a separate valuation model |
