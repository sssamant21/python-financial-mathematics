## 4.6.1 Purpose

Financial information often has several levels: a portfolio contains accounts, an account contains positions, and each position contains instrument and quantity fields.

Lists and dictionaries can express those relationships, but additional nesting introduces validation, identity, and ownership questions. A valid outer dictionary does not establish that every inner position is valid.

This section introduces traversal, nested schemas, shared references, and flattening. The lab converts a small portfolio into independent flat position records while retaining its portfolio identity and currency.

## 4.6.2 Learning Objectives

You should be able to:

1. Describe a nested structure before accessing it.
2. Traverse dictionaries containing lists of records.
3. Validate every relevant layer.
4. Preserve parent metadata during flattening.
5. Distinguish shallow copying, deep copying, and schema-aware reconstruction.
6. Test that returned records do not share mutable containers with their source.

## 4.6.3 Describe the Shape First

The teaching portfolio has three fields:

| Level | Field | Meaning |
|---|---|---|
| Portfolio | portfolio_id | Identifier within the supplied dataset |
| Portfolio | currency | Common reporting currency label |
| Portfolio | positions | List of position records |
| Position | instrument_id | Identifier within this portfolio |
| Position | quantity | Finite nonnegative Decimal units |

Quantity is a count of instrument units, not a monetary amount. Currency here is reporting metadata, not evidence of an instrument's trading currency or a completed currency conversion.

The lab does not calculate market value. That would require price, price units, instrument conventions, timing, and possibly conversion rules.

## 4.6.4 A Small Nested Portfolio

```python
from decimal import Decimal

portfolio = {
    "portfolio_id": "PORT-01",
    "currency": "USD",
    "positions": [
        {"instrument_id": "FUND-A", "quantity": Decimal("10")},
        {"instrument_id": "FUND-B", "quantity": Decimal("25.5")},
    ],
}

first_position = portfolio["positions"][0]
assert first_position["instrument_id"] == "FUND-A"
assert first_position["quantity"] == Decimal("10")
```

The access path selects the positions field, the first list item, and then a field in that position. Every step assumes the previous object has the expected shape.

A missing dictionary field raises KeyError. An empty positions list makes index 0 invalid. Wrong intermediate types can fail before reaching the desired value.

Validate at a boundary before relying on such paths.

## 4.6.5 Traverse Without Assuming a First Item Exists

```python
instrument_ids = []
for position in portfolio["positions"]:
    instrument_ids.append(position["instrument_id"])

assert instrument_ids == ["FUND-A", "FUND-B"]
```

Iteration naturally handles an empty collection. It does not establish that every entry is a position dictionary or that its fields are valid.

Avoid long chains of get calls with empty defaults for mandatory layers. A missing positions field should not silently become a legitimately empty portfolio unless the schema explicitly says so.

## 4.6.6 Parent and Child Identity

The lab requires unique instrument_id values within one portfolio. Two separate portfolios can contain the same instrument.

A richer model with multiple tax lots would need a lot identifier or a different uniqueness rule. Do not aggregate equal instrument IDs automatically if they represent distinct economic records.

When flattening, retain portfolio_id with each position so the parent relationship remains available. Dropping it can make records from different portfolios appear interchangeable.

## 4.6.7 Shallow Copies Retain Nested References

```python
shallow = portfolio.copy()
assert shallow is not portfolio
assert shallow["positions"] is portfolio["positions"]
```

Changing a position through the shallow copy can change the source position. A new outer dictionary alone does not isolate its nested list and dictionaries.

The repeated-reference pattern [position] * 3 likewise creates three references to one position object. Independent mutable records need separate construction.

Section 4.11 develops mutable and immutable ownership more broadly.

## 4.6.8 Deep Copy Versus Reconstruction

deepcopy can recursively copy supported compound objects. It also preserves shared-reference relationships within the copied graph rather than necessarily producing an independent object for every occurrence.

Copying does not validate schemas, normalize data, establish identity, or verify financial correctness. Generic copying may duplicate state that was intended to remain shared.

For this small, known schema, the lab rebuilds each output record from validated scalar values. New dictionaries and a new outer list provide the required container isolation. Strings and Decimal quantities can be reused because they are immutable.

This is a schema-specific ownership guarantee, not a generic deep-copy replacement.

## 4.6.9 Flattening Is a Contract Change

The nested source stores currency once at the portfolio level. Each flat output row repeats portfolio_id and currency alongside instrument_id and quantity.

Flattening helps tabular processing but loses the explicit outer portfolio object. An empty portfolio yields no rows, so its identity cannot be recovered from that flat output alone.

If empty parent entities must remain represented, preserve a separate portfolio table or return parent metadata separately. A flattening function should state that limitation.

## 4.6.10 Hands-On Lab — Validate and Flatten a Portfolio

Save as nested_structures_lab.py. It requires Python 3.10 or later and only the standard library.

The schema is strict: unknown or missing fields are rejected at both levels. Currency is USD or EUR as a teaching allowlist. IDs are nonblank, case-sensitive strings and are not normalized.

Quantities allow zero and fractional units, exclude negative positions, and require finite Decimal values. This deliberately omits short positions and instrument-specific lot-size constraints.

```python
"""Validate nested portfolio records and reconstruct flat position rows."""

from decimal import Decimal
import unittest


def flatten_portfolio(value: object) -> list[dict[str, object]]:
    """Return fresh flat rows from the documented nested teaching schema.

    Require portfolio_id, currency, positions at the outer level.
    positions is a list of exact instrument_id/quantity dictionaries.
    IDs are nonblank text, currency USD/EUR, quantities finite nonnegative
    Decimal units, and instrument IDs unique within the portfolio.
    Preserve position order and parent ID/currency. Do not mutate inputs.
    Return fresh outer/inner containers with immutable scalar values.
    Empty positions produces no rows and does not retain a parent row.
    Raise TypeError for representations and ValueError for schema/domain.
    No pricing, aggregation, currency conversion, or valuation is performed.
    """
    if not isinstance(value, dict):
        raise TypeError("portfolio must be a dictionary")
    if set(value) != {"portfolio_id", "currency", "positions"}:
        raise ValueError("portfolio fields do not match schema")
    portfolio_id = value["portfolio_id"]
    currency = value["currency"]
    positions = value["positions"]

    if not isinstance(portfolio_id, str):
        raise TypeError("portfolio_id must be text")
    if not portfolio_id.strip():
        raise ValueError("portfolio_id must be nonblank")
    if not isinstance(currency, str):
        raise TypeError("currency must be text")
    if currency not in ("USD", "EUR"):
        raise ValueError("unsupported reporting currency")
    if not isinstance(positions, list):
        raise TypeError("positions must be a list")

    rows: list[dict[str, object]] = []
    seen: set[str] = set()
    for position in positions:
        if not isinstance(position, dict):
            raise TypeError("each position must be a dictionary")
        if set(position) != {"instrument_id", "quantity"}:
            raise ValueError("position fields do not match schema")
        instrument_id = position["instrument_id"]
        quantity = position["quantity"]
        if not isinstance(instrument_id, str):
            raise TypeError("instrument_id must be text")
        if not instrument_id.strip():
            raise ValueError("instrument_id must be nonblank")
        if not isinstance(quantity, Decimal):
            raise TypeError("quantity must be Decimal")
        if not quantity.is_finite() or quantity < 0:
            raise ValueError("quantity must be finite and nonnegative")
        if instrument_id in seen:
            raise ValueError("duplicate instrument_id")
        seen.add(instrument_id)
        rows.append({
            "portfolio_id": portfolio_id,
            "currency": currency,
            "instrument_id": instrument_id,
            "quantity": quantity,
        })
    return rows


def sample_positions() -> list[dict[str, object]]:
    """Return fresh invented positions with zero and fractional units."""
    return [
        {"instrument_id": "FUND-A", "quantity": Decimal("0")},
        {"instrument_id": "FUND-B", "quantity": Decimal("25.5")},
    ]


def sample_portfolio(
    positions: list[dict[str, object]],
) -> dict[str, object]:
    """Construct a test portfolio referencing the supplied positions."""
    return {
        "portfolio_id": "PORT-01",
        "currency": "USD",
        "positions": positions,
    }


class TestNestedPortfolio(unittest.TestCase):
    """Check traversal contracts, parent metadata, and ownership."""

    def test_flattened_values_and_order(self) -> None:
        rows = flatten_portfolio(sample_portfolio(sample_positions()))
        self.assertEqual(len(rows), 2)
        self.assertEqual(rows[0]["portfolio_id"], "PORT-01")
        self.assertEqual(rows[0]["currency"], "USD")
        self.assertEqual(rows[0]["instrument_id"], "FUND-A")
        self.assertEqual(rows[0]["quantity"], Decimal("0"))
        self.assertEqual(rows[1]["quantity"], Decimal("25.5"))

    def test_empty_positions(self) -> None:
        self.assertEqual(flatten_portfolio(sample_portfolio([])), [])

    def test_independent_containers(self) -> None:
        positions = sample_positions()
        portfolio = sample_portfolio(positions)
        rows = flatten_portfolio(portfolio)
        self.assertIsNot(rows, positions)
        self.assertIsNot(rows[0], positions[0])
        rows[0]["quantity"] = Decimal("100")
        rows[0]["currency"] = "EUR"
        self.assertEqual(positions[0]["quantity"], Decimal("0"))
        self.assertEqual(portfolio["currency"], "USD")
        self.assertEqual(rows[1]["currency"], "USD")

    def test_outer_schema(self) -> None:
        with self.assertRaises(TypeError):
            flatten_portfolio([])
        with self.assertRaises(ValueError):
            flatten_portfolio({"portfolio_id": "PORT-01"})
        invalid = sample_portfolio([])
        invalid["positions"] = None
        with self.assertRaises(TypeError):
            flatten_portfolio(invalid)
        invalid = sample_portfolio([])
        invalid["currency"] = "usd"
        with self.assertRaises(ValueError):
            flatten_portfolio(invalid)

    def test_invalid_later_position(self) -> None:
        for quantity in ("-1", "NaN", "Infinity"):
            with self.subTest(quantity=quantity):
                positions = sample_positions()
                positions[1]["quantity"] = Decimal(quantity)
                with self.assertRaises(ValueError):
                    flatten_portfolio(sample_portfolio(positions))
        positions = sample_positions()
        positions[1]["quantity"] = "25.5"
        with self.assertRaises(TypeError):
            flatten_portfolio(sample_portfolio(positions))
        positions = sample_positions()
        positions[1]["extra"] = "unexpected"
        with self.assertRaises(ValueError):
            flatten_portfolio(sample_portfolio(positions))

    def test_duplicate_identity(self) -> None:
        positions = sample_positions()
        positions[1]["instrument_id"] = "FUND-A"
        with self.assertRaisesRegex(ValueError, "duplicate"):
            flatten_portfolio(sample_portfolio(positions))


if __name__ == "__main__":
    unittest.main()
```

Run on Windows:

```powershell
py -m unittest -v nested_structures_lab
```

Run on macOS or Linux:

```bash
python3 -m unittest -v nested_structures_lab
```

Expected summary: **6 tests, OK**. Subtests cover additional invalid quantities.

An invalid later position causes the call to raise without returning a partial result. The input is never modified. This is local function behavior, not transactional storage or concurrency control.

The helper performs no quantity arithmetic, pricing, or aggregation. No new numerical-context policy is introduced.

## 4.6.11 Reviewing Ownership After a Change

If a later schema adds a list of tags, nested instrument metadata, or a price history, the current reconstruction policy must be reviewed.

Returning the original tags list would expose shared mutation. Copying that list might still share deeper dictionaries. Choose which components should be shared, copied, or immutable according to the contract.

Do not add deepcopy as an unexplained universal fix. Review its behavior for the concrete object graph and any user-defined types.

## 4.6.12 Complexity and Scope Boundaries

Nested containers are useful when parent-child relationships are naturally expressed together. Excessive depth can make traversal and validation hard to review.

Separate repeated reference data when duplicated metadata risks inconsistency. Preserve identifiers that allow those relationships to be reconstructed.

Serialization is another boundary: a valid in-memory Decimal or date object is not automatically represented correctly in a JSON payload. Parsing and serialization policy are developed later; this lab remains entirely in memory.

## 4.6.14 Troubleshooting Guide

| Symptom | Likely cause | Correction |
|---|---|---|
| Outer schema passes but traversal fails | Inner layers not validated | Validate each required level |
| Portfolio edits affect its copy | Shared nested objects | Reconstruct or copy under an explicit ownership policy |
| Positions from different portfolios collide | Parent identity dropped | Preserve parent identifiers |
| Empty portfolios disappear from a report | Flat output has no parent rows | Preserve parent metadata separately |
| Equal instrument IDs silently combine | Identity rule unresolved | Distinguish lots or reject duplicates explicitly |
| Quantity treated as monetary value | Price and unit conventions omitted | Define the valuation inputs |
| Added nested field introduces sharing | Copy guarantee no longer matches schema | Review all mutable descendants |

## 4.6.15 Key Takeaways

Nested structures represent relationships, but each layer needs a schema, identity rule, and ownership contract.

Validate the full path, preserve parent metadata during transformation, and distinguish copying from financial correctness.
