## Answers 1–6 — Structures and Identity

### 1 — Select a Representation

Use a list of event records for the working schedule, a dictionary keyed by unique security ID for catalog lookup, a frozenset of strings for the immutable currency allowlist, and a tuple of validated (ID, Decimal quantity) pairs for the baseline. The list retains event multiplicity; the lookup supports identity access; the allowlist captures membership; the scalar tuple preserves holdings order without mutable descendants. None proves that financial inputs are complete or correctly valued.

### 2 — Mutation and Rebinding

After assignment, original and other reference the same list. Changing other[0]["quantity"] changes the shared dictionary to quantity 2. Rebinding other to an empty list leaves original as the one-record list containing quantity 2. Original still references the earlier list; assignment did not copy or clear it.

### 3 — Tuple Descendants

The tuple keeps a reference to a dictionary whose entry can change. A pair such as ("A", Decimal("1")) has immutable supported scalar descendants. A tuple of those pairs can represent a holdings component. Runtime validation must enforce that shape; annotations alone do not prevent mutation of an annotated list.

### 4 — Duplicate-Key Loss

The dictionary is {"A": Decimal("2"), "B": Decimal("0")}; the ID set is {"A", "B"}. The dictionary loses the first A quantity. The set loses all quantities, multiplicity, and source sequence. Neither adds compatible lot quantities or retains lot identity.

### 5 — Missing, Zero, and Empty

Zero is a known valid quantity and remains stored. Missing quantity violates the required schema. Empty holdings is valid but makes no completeness claim. A portfolio wrapper retains portfolio and snapshot IDs even with an empty holdings list.

### 6 — Identity Scope

Use (portfolio_id, security_id) for an aggregate holding across portfolios. A lot model may use (portfolio_id, account_id, lot_id), with security_id retained as a reference; define lot-ID uniqueness explicitly. Two distinct payment events can share a date, so retain an event_id scoped to the schedule.

## Answers 14–16 — Time, Missing Data, and Views

### 14 — Calendar and Model Time

A period index needs a declared period unit and origin. A date records a calendar day without intraday settlement time. Thirty-day increments do not encode month lengths, end-of-month conventions, or business-day adjustment. Before discounting, specify valuation date, currency and sign perspective, actual payment basis, year-fraction convention, rate/curve inputs, compounding conventions, and relevant source versions.

### 15 — Unknown Data and Event Loss

Replacing missing amounts with zero changes unknown observations into definite payments. Mapping one amount per date can overwrite distinct events. Keep an identified schedule wrapper and a list of event records, or a date-to-event-list view. Reject missing required amounts or quarantine them with their identities and explicit reasons. Keep original records for inspection when deriving a net view.

### 16 — Independent Views

The views function below returns capture, lookup, and frozenset membership. Source edits cannot change retained scalar pairs. Lookup edits cannot update the tuple or frozenset. A corrected input requires building all three new views and associating them with the new snapshot identity. Do not mix views from different versions.

## Answers 17–20 — Project Integration

### 17 — Lookup Extension

find_holding validates the whole catalog and portfolio before finding the target. It returns a fresh dictionary, accepts stored zero, and rejects an unheld ID even if that ID exists in the catalog. The returned record is a view, not an editable handle into the portfolio.

### 18 — Scenario Sequence

Use add SEC-C/3, replace SEC-A/20, and remove SEC-B with immediate revision labels S1, S2, and S3. Final holdings are SEC-A/20, SEC-C/3; the ID report uses the same order in this fixture. S0 remains SEC-B/0 then SEC-A/12.5. Replace assigns the supplied absolute quantity and performs no arithmetic; executing trades would need a separate domain model.

### 19 — Rejection Matrix

The tests below cover all six requested rejection cases. A duplicate add or missing replacement target fails without changing S0. Reusing S0, passing bool as quantity, supplying an unsupported unused catalog currency, and hiding an unknown zero holding behind active filtering also fail. Input-preservation assertions accompany these checks.

### 20 — Design Review

Define account/lot identity before supporting repeated securities. Specify quantity and price units, contract multipliers where relevant, quote currency, conversion policy, timestamps, and catalog version before valuation. Reject unresolved references or preserve them in an explicit rejection workflow. Reconstruct output views and retain versioned source snapshots.

Immediate label comparison does not guarantee global revision uniqueness. Concurrent updates require a persisted version check and a commit policy. Durable history, backup/recovery, and access controls need implementation and operational evidence. Reproducibility also requires source data, code/model version, parameters, and numeric context for arithmetic. Local tests verify selected contracts for synthetic inputs; they do not establish financial completeness, live integration reliability, or production transaction behavior.

```python
"""Chapter 4 reference answers; requires the complete Section 4.13 module."""

from datetime import date, datetime
from decimal import Decimal
import unittest

from portfolio_holdings_manager import (
    apply_command, holdings_report, quantity_value, sample_catalog,
    sample_portfolio, text, validated_inputs,
)

Holding = tuple[str, Decimal]
Snapshot = tuple[Holding, ...]


def capture(value: object) -> Snapshot:
    if not isinstance(value, list):
        raise TypeError("holdings must be a list")
    rows: list[Holding] = []
    seen: set[str] = set()
    for row in value:
        if not isinstance(row, dict):
            raise TypeError("holding must be a dictionary")
        if set(row) != {"security_id", "quantity"}:
            raise ValueError("holding has incorrect fields")
        sid = text(row["security_id"], "security_id")
        quantity = quantity_value(row["quantity"])
        if sid in seen:
            raise ValueError(f"duplicate security_id: {sid}")
        seen.add(sid)
        rows.append((sid, quantity))
    return tuple(rows)


def record(row: Holding) -> dict[str, object]:
    return {"security_id": row[0], "quantity": row[1]}


def active_rows(value: object) -> list[dict[str, object]]:
    return [record(row) for row in capture(value) if row[1] > 0]


def quantity_lookup(value: object) -> dict[str, Decimal]:
    return dict(capture(value))


def holding_key(row: Holding) -> str:
    return row[0]


def id_report(value: object) -> list[dict[str, object]]:
    return [record(row) for row in sorted(capture(value), key=holding_key)]


def id_members(value: object) -> set[str]:
    if not isinstance(value, list):
        raise TypeError("IDs must be a list")
    return {text(item, "ID") for item in value}


def compare_ids(expected: object, actual: object) -> dict[str, list[str]]:
    expected_ids, actual_ids = id_members(expected), id_members(actual)
    return {"missing": sorted(expected_ids - actual_ids),
            "unexpected": sorted(actual_ids - expected_ids)}


def at_least(value: object, minimum: object) -> list[dict[str, object]]:
    threshold = quantity_value(minimum)
    snapshot = capture(value)
    return [record(row) for row in snapshot if row[1] >= threshold]


def group_events(value: object) -> dict[date, list[dict[str, object]]]:
    if not isinstance(value, list):
        raise TypeError("events must be a list")
    validated: list[tuple[date, str, Decimal]] = []
    seen: set[str] = set()
    for row in value:
        if not isinstance(row, dict):
            raise TypeError("event must be a dictionary")
        if set(row) != {"event_id", "payment_date", "amount"}:
            raise ValueError("event has incorrect fields")
        event_id = text(row["event_id"], "event_id")
        payment_date = row["payment_date"]
        if type(payment_date) is not date:
            raise TypeError("payment_date must be an exact date")
        amount = row["amount"]
        if type(amount) is not Decimal:
            raise TypeError("amount must be an exact Decimal")
        if not amount.is_finite():
            raise ValueError("amount must be finite")
        if event_id in seen:
            raise ValueError(f"duplicate event_id: {event_id}")
        seen.add(event_id)
        validated.append((payment_date, event_id, amount))
    # Unique event IDs ensure the amount never needs to break a date/ID tie.
    ordered = sorted(validated)
    grouped: dict[date, list[dict[str, object]]] = {}
    for payment_date, event_id, amount in ordered:
        grouped.setdefault(payment_date, []).append({
            "event_id": event_id, "payment_date": payment_date, "amount": amount
        })
    return grouped


def views(value: object) -> tuple[Snapshot, dict[str, Decimal], frozenset[str]]:
    snapshot = capture(value)
    lookup = dict(snapshot)
    return snapshot, lookup, frozenset(lookup)


def find_holding(catalog: object, portfolio: object, security_id: object) -> dict[str, object]:
    _, _, _, holdings = validated_inputs(catalog, portfolio)
    target = text(security_id, "security_id")
    for sid, quantity in holdings:
        if sid == target:
            return {"security_id": sid, "quantity": quantity}
    raise ValueError(f"holding not found: {target}")


def fixture() -> list[dict[str, object]]:
    return [
        {"security_id": "SEC-B", "quantity": Decimal("0")},
        {"security_id": "SEC-A", "quantity": Decimal("12.5")},
        {"security_id": "SEC-C", "quantity": Decimal("3")},
    ]


def event_fixture() -> list[dict[str, object]]:
    return [
        {"event_id": "E2", "payment_date": date(2028, 1, 1), "amount": Decimal("100")},
        {"event_id": "E0", "payment_date": date(2027, 1, 1), "amount": Decimal("-100")},
        {"event_id": "E1", "payment_date": date(2028, 1, 1), "amount": Decimal("0")},
    ]


class ChapterFourTests(unittest.TestCase):
    def test_07_capture(self) -> None:
        source = fixture()
        snapshot = capture(source)
        self.assertEqual(snapshot, (("SEC-B", Decimal("0")),
                                   ("SEC-A", Decimal("12.5")), ("SEC-C", Decimal("3"))))
        source[0]["quantity"] = Decimal("99")
        self.assertEqual(snapshot[0], ("SEC-B", Decimal("0")))
        self.assertEqual(capture([]), ())

    def test_08_active(self) -> None:
        source = fixture()
        result = active_rows(source)
        self.assertEqual(result, [
            {"security_id": "SEC-A", "quantity": Decimal("12.5")},
            {"security_id": "SEC-C", "quantity": Decimal("3")},
        ])
        result[0]["quantity"] = Decimal("99")
        self.assertEqual(source, fixture())
        self.assertEqual(active_rows([]), [])

    def test_09_lookup(self) -> None:
        source = fixture()
        lookup = quantity_lookup(source)
        self.assertEqual(lookup, {"SEC-B": Decimal("0"), "SEC-A": Decimal("12.5"), "SEC-C": Decimal("3")})
        lookup["SEC-B"] = Decimal("99")
        self.assertEqual(source, fixture())
        self.assertEqual(quantity_lookup([]), {})

    def test_10_report_and_reversed_input(self) -> None:
        expected = [
            {"security_id": "SEC-A", "quantity": Decimal("12.5")},
            {"security_id": "SEC-B", "quantity": Decimal("0")},
            {"security_id": "SEC-C", "quantity": Decimal("3")},
        ]
        self.assertEqual(id_report(fixture()), expected)
        self.assertEqual(id_report(list(reversed(fixture()))), expected)
        self.assertNotEqual(capture(fixture()), capture(list(reversed(fixture()))))
        self.assertEqual(id_report([]), [])

    def test_11_membership(self) -> None:
        self.assertEqual(compare_ids(["A", "B", "B"], ["B", "C"]),
                         {"missing": ["A"], "unexpected": ["C"]})
        self.assertEqual(compare_ids([], []), {"missing": [], "unexpected": []})
        with self.assertRaises(TypeError):
            compare_ids("A", [])
        with self.assertRaises(ValueError):
            compare_ids([" A"], [])

    def test_12_threshold(self) -> None:
        self.assertEqual(at_least(fixture(), Decimal("3")), fixture()[1:])
        self.assertEqual(at_least(fixture(), Decimal("0")), fixture())
        self.assertEqual(at_least(fixture(), Decimal("13")), [])
        with self.assertRaises(TypeError):
            at_least(fixture(), 0)
        with self.assertRaises(ValueError):
            at_least(fixture(), Decimal("NaN"))

    def test_holdings_rejections_for_all_views(self) -> None:
        for function in (capture, active_rows, quantity_lookup, id_report, views):
            with self.subTest(function=function.__name__):
                with self.assertRaises(ValueError):
                    function([
                        {"security_id": "A", "quantity": Decimal("0")},
                        {"security_id": "A", "quantity": Decimal("1")},
                    ])
                invalid = fixture() + [{"security_id": "BAD", "quantity": True}]
                with self.assertRaises(TypeError):
                    function(invalid)
                self.assertIs(invalid[-1]["quantity"], True)
        with self.assertRaises(TypeError):
            at_least(fixture() + [{"security_id": "BAD", "quantity": None}], Decimal("99"))
        for bad in ("NaN", "sNaN", "Infinity", "-Infinity", "-1"):
            with self.assertRaises(ValueError):
                capture([{"security_id": "A", "quantity": Decimal(bad)}])
        with self.assertRaises(ValueError):
            capture([{}])
        with self.assertRaises(TypeError):
            capture(())

    def test_13_group_values_and_ownership(self) -> None:
        source = event_fixture()
        grouped = group_events(source)
        self.assertEqual(list(grouped), [date(2027, 1, 1), date(2028, 1, 1)])
        self.assertEqual(grouped[date(2028, 1, 1)], [
            {"event_id": "E1", "payment_date": date(2028, 1, 1), "amount": Decimal("0")},
            {"event_id": "E2", "payment_date": date(2028, 1, 1), "amount": Decimal("100")},
        ])
        self.assertEqual(grouped[date(2027, 1, 1)][0]["amount"], Decimal("-100"))
        grouped[date(2028, 1, 1)][0]["amount"] = Decimal("99")
        self.assertEqual(source, event_fixture())
        self.assertEqual(group_events([]), {})

    def test_13_event_rejections(self) -> None:
        source = event_fixture()
        duplicate = dict(source[0])
        duplicate["payment_date"] = date(2030, 1, 1)
        with self.assertRaises(ValueError):
            group_events(source + [duplicate])
        for field, value, error in (
            ("payment_date", datetime(2027, 1, 1), TypeError),
            ("amount", "1", TypeError), ("amount", Decimal("sNaN"), ValueError),
            ("event_id", " ", ValueError),
        ):
            bad = {"event_id": "BAD", "payment_date": date(2030, 1, 1), "amount": Decimal("1")}
            bad[field] = value
            with self.assertRaises(error):
                group_events(source + [bad])
            self.assertEqual(source, event_fixture())

    def test_16_views(self) -> None:
        source = fixture()
        snapshot, lookup, members = views(source)
        source[0]["quantity"] = Decimal("88")
        lookup["SEC-A"] = Decimal("99")
        lookup["NEW"] = Decimal("1")
        self.assertEqual(snapshot[0], ("SEC-B", Decimal("0")))
        self.assertEqual(snapshot[1], ("SEC-A", Decimal("12.5")))
        self.assertEqual(members, frozenset({"SEC-A", "SEC-B", "SEC-C"}))
        rebuilt, rebuilt_lookup, _ = views(source)
        self.assertEqual(rebuilt[0][1], Decimal("88"))
        self.assertEqual(rebuilt_lookup["SEC-B"], Decimal("88"))

    def test_17_lookup(self) -> None:
        source = sample_portfolio()
        row = find_holding(sample_catalog(), source, "SEC-B")
        self.assertEqual(row, {"security_id": "SEC-B", "quantity": Decimal("0")})
        row["quantity"] = Decimal("99")
        self.assertEqual(source, sample_portfolio())
        for sid in ("SEC-C", "UNKNOWN"):
            with self.assertRaises(ValueError):
                find_holding(sample_catalog(), source, sid)

    def test_18_scenario(self) -> None:
        catalog, baseline = sample_catalog(), sample_portfolio()
        one = apply_command(catalog, baseline, operation="add", security_id="SEC-C",
                            quantity=Decimal("3"), next_snapshot_id="S1")
        two = apply_command(catalog, one, operation="replace", security_id="SEC-A",
                            quantity=Decimal("20"), next_snapshot_id="S2")
        three = apply_command(catalog, two, operation="remove", security_id="SEC-B", next_snapshot_id="S3")
        self.assertEqual(three, {"portfolio_id": "PORT-01", "snapshot_id": "S3", "holdings": [
            {"security_id": "SEC-A", "quantity": Decimal("20")},
            {"security_id": "SEC-C", "quantity": Decimal("3")},
        ]})
        self.assertEqual(holdings_report(catalog, three), {"portfolio_id": "PORT-01", "snapshot_id": "S3", "rows": [
            {"security_id": "SEC-A", "name": "Example Equity", "quote_currency": "USD", "quantity": Decimal("20")},
            {"security_id": "SEC-C", "name": "Example Holding", "quote_currency": "USD", "quantity": Decimal("3")},
        ]})
        self.assertEqual(baseline, sample_portfolio())

    def test_19_rejection_matrix(self) -> None:
        baseline = sample_portfolio()
        for action, sid, quantity, revision, error in (
            ("add", "SEC-A", Decimal("1"), "S1", ValueError),
            ("replace", "SEC-C", Decimal("1"), "S1", ValueError),
            ("replace", "SEC-A", Decimal("1"), "S0", ValueError),
            ("replace", "SEC-A", True, "S1", TypeError),
        ):
            with self.assertRaises(error):
                apply_command(sample_catalog(), baseline, operation=action, security_id=sid,
                              quantity=quantity, next_snapshot_id=revision)
            self.assertEqual(baseline, sample_portfolio())
        catalog = sample_catalog()
        catalog[-1]["quote_currency"] = "GBP"
        with self.assertRaises(ValueError):
            apply_command(catalog, baseline, operation="replace", security_id="SEC-A",
                          quantity=Decimal("1"), next_snapshot_id="S1")
        self.assertEqual(baseline, sample_portfolio())
        bad_portfolio = {"portfolio_id": "P", "snapshot_id": "S", "holdings": [
            {"security_id": "UNKNOWN", "quantity": Decimal("0")}
        ]}
        with self.assertRaises(ValueError):
            holdings_report(sample_catalog(), bad_portfolio, active_only=True)
        self.assertEqual(bad_portfolio["holdings"], [{"security_id": "UNKNOWN", "quantity": Decimal("0")}])


if __name__ == "__main__":
    unittest.main(verbosity=2)
```
