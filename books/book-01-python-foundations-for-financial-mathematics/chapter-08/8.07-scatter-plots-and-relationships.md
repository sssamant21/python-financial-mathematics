## 1. Purpose

A scatter plot places one observation's x-value and y-value at the same point. In finance, those coordinates might be a benchmark return and an asset return for a common interval. The plot helps inspect their joint behavior, including direction, dispersion, clusters, unusual observations, and departures from a simple linear pattern.

The observation pairing is more important than the marker style. Two arrays of equal length can still contain returns from different intervals. This section therefore aligns labeled observations before drawing, discloses excluded pairs, and keeps descriptive association separate from causal or predictive claims.

The complete lab uses synthetic already-derived simple price returns. It includes a Pearson sample correlation as a descriptive check and an equal-return reference line. It does not fit a regression model.

## 3. One Point Must Have One Shared Observation Identity

For a point $(x_i,y_i)$, both values must describe the same defined observation. In this lab, the identity is a timezone-aware interval-ending instant; each return covers the preceding 24 hours.

The benchmark is on the horizontal axis and the asset on the vertical axis. Their definition, horizon, currency/adjustment conventions, and interval boundaries must be compatible. Matching calendar-date strings alone does not establish simultaneous observation windows across markets.

A point in the upper-right quadrant has positive returns for both series. A lower-left point has negative returns for both. Opposite-sign quadrants indicate different signs over that matched interval. Those sign descriptions do not establish causality or an economic explanation.

Connecting successive points with lines would introduce order as another visual claim. The scatter plot here has no connecting path between observations. A point's x-position is benchmark return, not elapsed time.

## 4. Worked Fixture and Intended Pairings

The expected grid contains eight UTC midnight endpoints, January 2–9, 2026. Returns are synthetic decimal fractions. The benchmark omits January 9 entirely; the asset supplies January 4 with a missing value. The asset's source rows are deliberately shuffled.

| UTC interval end | Benchmark return | Asset return | Plot pair? |
|---|---:|---:|---|

| Jan 3 | -2% | -1% | Yes |
| Jan 4 | -1% | Missing value in supplied row | No |

The fixture uses synthetic simple price returns, not total investment returns. It has no distributions, fees, taxes, corporate-action adjustments, or FX calculations. The expected calendar-day grid is a teaching schedule, not an exchange calendar.

## 5. Align First, Then Apply a Joint Mask

The program converts aware indexes to UTC, rejects duplicate or off-grid instants, and reindexes each source onto the same expected grid [3]. It allows source rows in any order because alignment is explicitly label-based. It requires the expected grid itself to be sorted.

Then it creates one pairwise completeness rule:

```python
complete = aligned[["benchmark", "asset"]].notna().all(axis=1)
pairs = aligned.loc[complete, ["benchmark", "asset"]]
```

This is an explanatory snippet; the full implementation also retains source-row-presence columns. Extracting arrays only after alignment preserves their shared observation identity.

Do not independently drop missing values from each source and zip the resulting arrays. That operation can shift later pairings or pair values from different dates. Independent sorting by return magnitude is also invalid: it can manufacture a visual relationship by matching small values with small values and large with large.

The rule excludes a pair if either coordinate is unknown. It does not fill missing returns with zero. Pairwise exclusion changes the sample being described, so disclose the expected size and excluded count. If missingness depends on conditions of interest, the complete-pair sample can differ systematically from the full intended population.

## 6. Scatter Properties and Coordinate Meaning

Matplotlib's `Axes.scatter` draws x/y positions and returns a collection of markers [1]. The lab uses constant size, a black outline, and one blue fill:

```python
ax.scatter(x, y, s=60, color="#0072B2", edgecolors="black",
           linewidths=0.5, alpha=0.8)
```

Here `s` represents marker area in typographic points squared, not a financial amount [1]. Constant size avoids introducing an additional data encoding. If marker area encodes market value, volume, or another quantity, supply a documented scale and legend.

Transparency can help reveal overlapping points, but coincident observations can still look like one marker. The plotted point count need not equal the number of visibly distinct circles. Preserve counts and source records alongside the figure. Artificial jitter changes displayed coordinates; use it only with an explicit explanation when exact positions are not being represented.

Color can encode a category or another measurement, but it needs its own legend or colorbar. The present lab uses one color so that visual grouping is not confused with another analytical variable.

## 7. Zero Axes and the Equal-Return Reference

The horizontal and vertical zero lines divide sign quadrants. The dashed diagonal is:

$$y=x.$$

It represents equal numerical simple returns for the two series. A point above it has an asset return greater than the benchmark return for that matched interval. For example, Jan 6 is `(1%, 1.5%)`, so its vertical excess is 0.5 percentage points. At Jan 7, `(2%, 1%)` lies below the diagonal by one percentage point.

This line is not estimated from the data and is not a regression fit. It has no fitted intercept, slope uncertainty, or forecast interpretation. A point's vertical distance from it is an arithmetic return difference for that interval, not automatically an annualized alpha, a risk-adjusted measure, or a relative wealth ratio.

Because the axes use the same return units, the lab sets matching limits and equal aspect. Equal numerical changes occupy equal physical distances, and the equality line appears at 45 degrees. Stretching a plot would change that visual angle without changing any observations.

Both axes store decimal fractions and use percentage formatters. A coordinate of `0.015` therefore appears as 1.5%, rather than 0.015%.

## 8. A Descriptive Pearson Correlation

For the selected complete pairs, define centered coordinates $\widetilde x_i=x_i-\overline x$ and $\widetilde y_i=y_i-\overline y$. The descriptive Pearson sample correlation is:

$$r=\frac{\sum_i\widetilde x_i\widetilde y_i}
{\sqrt{\left(\sum_i\widetilde x_i^2\right)
\left(\sum_i\widetilde y_i^2\right)}}.$$

NumPy's `corrcoef` computes Pearson correlation coefficients [2]. For the six fixture pairs, the result is approximately **0.9388**. The tests compare it with the independently expressed centered-coordinate formula.

The coefficient describes linear association in the selected paired sample. It does not measure a fitted slope: a perfectly affine series can have correlation +1 while having a slope other than one. Nor does it establish causality, investment suitability, forecasting skill, or future stability.

The helper withholds correlation when fewer than three complete pairs remain or either coordinate has a range no larger than `1e-12`. The three-pair threshold and variation tolerance are teaching/reporting policies, not a statistical reliability guarantee. A constant coordinate has no defined Pearson correlation under the formula because its denominator is zero. The scatter can still display the available points.

A single complete pair is sufficient to draw a point but not to release the correlation under this policy. With no complete pair, the helper raises an error instead of creating an empty relationship chart.

## 9. Interpretation Beyond One Number

Inspect the cloud as well as its correlation. A curved pattern can have weak linear correlation despite a strong nonlinear relationship. Different subgroups can exhibit different behavior, and pooling them can hide those distinctions. An unusual point can materially change a small sample's coefficient.

Do not delete unusual observations simply to strengthen a relationship. Check their timestamps, units, return calculations, corporate actions, and provenance. If exclusion is justified, record the rule and compare the resulting sample with the original.

A contemporaneous scatter pairs the same intervals. A lagged scatter pairs explicitly different intervals and asks another question. Relabeling or shifting one source silently changes the estimand and can introduce look-ahead errors. A forecast study must establish what information was available at the prediction time and validate against appropriately held-out observations.

The plot also loses temporal sequence. A simultaneous permutation of complete paired rows leaves the coordinates and correlation unchanged; independently permuting only one coordinate generally changes the relationship. Keep an accompanying time-series view when regime changes or clustering in time matter.

This six-point synthetic cloud supports no inference about real financial dependence. No regression line, confidence band, hypothesis test, or model-selection step is performed.

### `scatter_relationships.py`

```python
"""Align labeled return intervals before plotting complete pairs."""
from pathlib import Path
import matplotlib
matplotlib.use('Agg')
import matplotlib.pyplot as plt
from matplotlib.ticker import PercentFormatter
import numpy as np
import pandas as pd


def fixture():
    grid = pd.date_range('2026-01-02T00:00:00Z', periods=8, freq='D')
    benchmark = pd.Series([-.03, -.02, -.01, 0., .01, .02, .03],
                           index=grid[:-1], name='benchmark')
    asset = pd.Series([-.02, -.01, np.nan, 0., .015, .01, .04, .02],
                       index=grid, name='asset')
    # Source order differs deliberately; labels determine the pairings.
    return benchmark, asset.iloc[[6, 0, 7, 2, 5, 1, 4, 3]], grid


def normalize_index(index, name):
    if (not isinstance(index, pd.DatetimeIndex) or index.tz is None
            or index.hasnans or not index.is_unique):
        raise ValueError(f'{name} needs unique aware instants without NaT')
    utc = index.tz_convert('UTC').copy()
    if len(utc) and (utc.year.min() < 2000 or utc.year.max() > 2100):
        raise ValueError('supported UTC years are 2000..2100')
    return utc


def prepare(benchmark, asset, expected):
    grid = normalize_index(expected, 'expected')
    if (not 3 <= len(grid) <= 366 or not grid.is_monotonic_increasing
            or not (grid[1:] - grid[:-1] == pd.Timedelta(days=1)).all()):
        raise ValueError('expected needs 3..366 consecutive 24-hour endpoints')
    aligned = pd.DataFrame(index=grid)
    for label, series in [('benchmark', benchmark), ('asset', asset)]:
        if (not isinstance(series, pd.Series) or series.dtype != np.dtype('float64')
                or not 1 <= len(series) <= len(grid)):
            raise ValueError('each input must be a nonempty float64 Series')
        index = normalize_index(series.index, label)
        if not index.isin(grid).all():
            raise ValueError('source endpoints must belong to the expected grid')
        values = series.to_numpy(copy=True)
        observed = values[np.isfinite(values)]
        if np.isinf(values).any() or (observed < -1).any() or (observed > 10).any():
            raise ValueError('observed simple returns must be in [-1,10]')
        source = pd.Series(values, index=index)
        aligned[label] = source.reindex(grid)
        aligned[label + '_present'] = grid.isin(index)
    aligned['complete'] = aligned[['benchmark', 'asset']].notna().all(axis=1)
    pairs = aligned.loc[aligned.complete, ['benchmark', 'asset']].copy()
    if pairs.empty:
        raise ValueError('at least one complete pair is required for a scatter plot')
    correlation = None
    if len(pairs) >= 3:
        x = pairs.benchmark.to_numpy(); y = pairs.asset.to_numpy()
        if np.ptp(x) > 1e-12 and np.ptp(y) > 1e-12:
            candidate = float(np.corrcoef(x, y)[0, 1])
            if np.isfinite(candidate):
                correlation = candidate
    report = {'expected': len(grid), 'complete': len(pairs),
              'excluded': int((~aligned.complete).sum()), 'correlation': correlation}
    return aligned, pairs, report


def build_figure(benchmark, asset, expected):
    aligned, pairs, report = prepare(benchmark, asset, expected)
    x = pairs.benchmark.to_numpy(); y = pairs.asset.to_numpy()
    # A common numerical scale keeps the equal-return reference interpretable.
    lower = min(float(x.min()), float(y.min()), 0.)
    upper = max(float(x.max()), float(y.max()), 0.)
    padding = max((upper-lower)*0.12, .005)
    limits = (lower-padding, upper+padding)
    fig, ax = plt.subplots(figsize=(7, 6), layout='constrained')
    ax.scatter(x, y, s=60, color='#0072B2', edgecolors='black',
                linewidths=.5, alpha=.8, label='Complete matched intervals')
    ax.plot(limits, limits, color='gray', linestyle='--', linewidth=1,
             label='Equal-return reference (not a fitted line)')
    ax.axhline(0, color='gray', linewidth=.7)
    ax.axvline(0, color='gray', linewidth=.7)
    ax.set(xlabel='Benchmark simple price return', ylabel='Asset simple price return',
            xlim=limits, ylim=limits)
    ax.set_aspect('equal', adjustable='box')
    ax.xaxis.set_major_formatter(PercentFormatter(xmax=1., decimals=1))
    ax.yaxis.set_major_formatter(PercentFormatter(xmax=1., decimals=1))
    corr = 'withheld' if report['correlation'] is None else f'{report["correlation"]:.4f}'
    ax.set_title(f'Synthetic matched returns | Pearson r = {corr}\n'
                  f'Complete {report["complete"]}/{report["expected"]}; excluded {report["excluded"]}')
    ax.legend(loc='upper left', fontsize=8)
    ax.grid(alpha=.2)
    fig.supxlabel('Same 24-hour endpoints | pairwise exclusions disclosed | association is not causation',
                  fontsize=8)
    return fig, ax


def main():
    benchmark, asset, expected = fixture()
    aligned, pairs, report = prepare(benchmark, asset, expected)
    print(f'Expected: {report["expected"]}; complete pairs: {report["complete"]}; excluded: {report["excluded"]}')
    print(f'Benchmark absent endpoints: {(~aligned.benchmark_present).sum()}')
    print(f'Asset explicit missing cells: {(aligned.asset_present & aligned.asset.isna()).sum()}')
    print(f'Paired sample Pearson r: {report["correlation"]:.4f}')
    fig, _ = build_figure(benchmark, asset, expected)
    try:
        Path('output').mkdir(exist_ok=True)
        fig.savefig('output/scatter_relationships.png', dpi=150)
    finally:
        plt.close(fig)
    print('Saved output/scatter_relationships.png')


if __name__ == '__main__':
    main()
```

The numerical helper finishes alignment and sample selection before creating a Figure. The plot uses exactly the complete pairs used by the descriptive statistic. The caller saves and closes its Figure explicitly. Agg produces a PNG without a desktop window; re-running the demonstration replaces that output.

## 11. Reference Tests

### `test_scatter_relationships.py`

```python
import tempfile
import unittest
from pathlib import Path
import numpy as np
import pandas as pd
from numpy.testing import assert_allclose, assert_array_equal
from pandas.testing import assert_frame_equal, assert_series_equal
from scatter_relationships import fixture, prepare, build_figure, plt


class ScatterTests(unittest.TestCase):
    def test_exact_label_pairing_and_coverage(self):
        b, a, grid = fixture(); aligned, pairs, report = prepare(b, a, grid)
        assert_array_equal(pairs.index, grid[[0, 1, 3, 4, 5, 6]])
        assert_allclose(pairs.to_numpy(), [[-.03, -.02], [-.02, -.01], [0, 0],
                                          [.01, .015], [.02, .01], [.03, .04]])
        self.assertEqual(report['complete'], 6); self.assertEqual(report['excluded'], 2)
        self.assertFalse(aligned.benchmark_present.iloc[-1])
        self.assertTrue(aligned.asset_present.iloc[2])
        self.assertTrue(np.isnan(aligned.asset.iloc[2]))

    def test_source_order_and_zone_invariance(self):
        b, a, grid = fixture()
        _, original, _ = prepare(b, a, grid)
        b = b.iloc[::-1].copy(); b.index = b.index.tz_convert('America/New_York')
        _, changed, _ = prepare(b, a.sort_index(), grid.tz_convert('Asia/Kolkata'))
        assert_frame_equal(original, changed)

    def test_correlation_independent_centered_formula(self):
        b, a, grid = fixture(); _, pairs, report = prepare(b, a, grid)
        x = pairs.benchmark.to_numpy(); y = pairs.asset.to_numpy()
        xc = x-x.mean(); yc = y-y.mean()
        expected = (xc @ yc) / np.sqrt((xc @ xc)*(yc @ yc))
        self.assertAlmostEqual(report['correlation'], expected)
        linear = 2*b + .01
        self.assertAlmostEqual(prepare(b, linear, grid)[2]['correlation'], 1.)

    def test_degenerate_correlation_and_no_pairs(self):
        b, a, grid = fixture()
        constant = pd.Series(np.zeros(8), index=grid)
        self.assertIsNone(prepare(constant, a, grid)[2]['correlation'])
        short = pd.Series([.01, .02], index=grid[:2])
        self.assertIsNone(prepare(short, short, grid)[2]['correlation'])
        missing = pd.Series(np.full(8, np.nan), index=grid)
        with self.assertRaises(ValueError): prepare(missing, a, grid)

    def test_invalid_indexes(self):
        b, a, grid = fixture()
        for bad in [grid.tz_localize(None), grid[::-1], grid.insert(1, grid[1]),
                    grid.delete(2)]:
            with self.assertRaises(ValueError): prepare(b, a, bad)
        bad = b.copy(); bad.index = bad.index + pd.Timedelta(hours=1)
        with self.assertRaises(ValueError): prepare(bad, a, grid)
        bad = pd.concat([b, b.iloc[:1]])
        with self.assertRaises(ValueError): prepare(bad, a, grid)

    def test_invalid_values_and_dtype(self):
        b, a, grid = fixture()
        for value in [np.inf, -1.01, 11.]:
            bad = b.copy(); bad.iloc[0] = value
            with self.assertRaises(ValueError): prepare(bad, a, grid)
        with self.assertRaises(ValueError): prepare(b.astype(str), a, grid)
        with self.assertRaises(ValueError): prepare(b.to_frame(), a, grid)

    def test_source_preservation(self):
        b, a, grid = fixture(); bc = b.copy(deep=True); ac = a.copy(deep=True)
        aligned, pairs, report = prepare(b, a, grid)
        aligned.iloc[0, 0] = 99; pairs.iloc[0, 0] = 99
        assert_series_equal(b, bc); assert_series_equal(a, ac)

    def test_offsets_reference_export_and_cleanup(self):
        b, a, grid = fixture(); _, pairs, _ = prepare(b, a, grid)
        before = set(plt.get_fignums()); fig, ax = build_figure(b, a, grid)
        try:
            assert_allclose(ax.collections[0].get_offsets(), pairs.to_numpy())
            line = ax.lines[0]
            assert_allclose(line.get_xdata(), line.get_ydata())
            self.assertIn('not a fitted', line.get_label())
            self.assertEqual(ax.get_aspect(), 1.)
            with tempfile.TemporaryDirectory() as folder:
                path = Path(folder)/'scatter.png'; fig.savefig(path)
                self.assertEqual(path.read_bytes()[:8], b'\x89PNG\r\n\x1a\n')
        finally:
            plt.close(fig)
        self.assertEqual(set(plt.get_fignums()), before)


if __name__ == '__main__':
    unittest.main()
```

## 14. Common Errors and Corrections

| Error | Consequence | Correction |
|---|---|---|
| Pairing by array position before label alignment | Different intervals can be matched | Align by defined observation identity first |
| Dropping missing values independently | Later coordinates can shift | Apply one joint completeness mask |
| Sorting each return series by magnitude | Manufactures a relationship | Preserve labels and paired records |
| Filling a missing return with zero | Adds an invented point | Exclude and disclose the unknown pair |
| Using different samples for plot and correlation | Title statistic does not describe the cloud | Compute both from the same complete-pair frame |
| Calling the equality line a regression | Implies an estimated model | Label its fixed meaning explicitly |
| Treating high correlation as slope one | Confuses scale-free association with relative magnitude | Distinguish correlation from fitted slope and equal returns |
| Returning correlation for a constant coordinate | Divides by zero or releases a misleading result | Withhold the coefficient under a stated policy |
| Inferring causality or forecast skill from the cloud | Overstates descriptive evidence | Define and validate a separate causal/predictive study |

## 15. Exercises and Answer Guidance

1. **Pair identity:** Which date produces the `(2%, 1%)` point?  
   **Guidance:** January 7, 2026, the common interval endpoint.
2. **Coverage:** Why are two pairs excluded rather than all rows with any missing provenance flag?  
   **Guidance:** Complete numerical coordinates determine inclusion; presence flags diagnose the reason. Jan 4 has an explicit asset NaN and Jan 9 lacks a benchmark row.
3. **Zero pair:** Is `(0,0)` missing?  
   **Guidance:** No; both observed simple returns are zero.
4. **Reference:** At `(1%,1.5%)`, how far is the point vertically above the equality line?  
   **Guidance:** 0.5 percentage points; this is an interval arithmetic return difference.
5. **Correlation versus slope:** Can correlation be +1 for `asset = 2 * benchmark + 0.01`?  
   **Guidance:** Yes, for a varying complete sample. That does not make the relationship equal-return or unit-slope.
6. **Constant input:** What happens if every benchmark return is zero?  
   **Guidance:** The scatter can display points on a vertical line; the coefficient is withheld under the variation rule.
7. **Ordering:** Should reversing the source row order change the result?  
   **Guidance:** No, because the helper aligns unique endpoint labels. Independently changing the endpoint labels would change the pairs.
8. **Inference:** What additional work is required before interpreting this as a forecast?  
   **Guidance:** Specify prediction timing, available information, model assumptions, and out-of-sample validation. The descriptive plot alone does not provide that evidence.
