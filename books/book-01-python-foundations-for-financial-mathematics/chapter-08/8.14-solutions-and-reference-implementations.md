## Worked answers

### 1. Same endpoint, different paths

Both finish at index 120 and return 20%. At the middle observation A is 110 while B is 80. Equal endpoint growth does not imply equal interim experience.

### 2. Figure, Axes, Axis, and Artist

The axes array has shape (2, 1). axes[0, 0] belongs to fig; its yaxis belongs to that Axes; the returned Line2D is the first element of its lines collection.

### 3. Coordinate order and elapsed spacing

The numeric gaps are 1 and 3 days. The alternative order is not strictly increasing. A line follows supplied order; it does not sort observations for the author. Equal category spacing would conceal the longer interval.

### 4. A missing point and a dropped point

Retaining NaN preserves a break. Dropping the missing point leaves coordinates [0, 1, 3], which permits a direct connection from day 1 to day 3. Neither operation supplies evidence about the missing value.

### 5. Effective position states

The held states are 10 and 12. Initial vertices are (0, 10), (1, 10), (1, 12). At day 3 the state becomes 8; the fixture supplies no later end date. Straight interpolation would invent gradual position changes.

### 6. Repeated local clock hours

The labels are 01:30 EDT -0400 and 01:30 EST -0500, one elapsed hour apart. UTC coordinates distinguish the instants; local clock text alone does not.

### 7. Expected rows and expected cells

Source-row presence is [True, False, True]. Observed counts by date are [2, 0, 1], or 3 of 6 expected cells. The January 3 row exists even though one of its cells is missing.

### 8. Simple, log, and compounded returns

Simple returns are +10% and −10%; their sum is zero. Compounding gives 1.1 × 0.9 − 1 = −1%. Summed log returns recover the same −1% through expm1. An arithmetic sum of simple returns is not the compounded result.

### 9. Strict linkage and an observed zero

Adjacent returns are undefined at the first point, then +10%, −10%, unknown, unknown, and 0%. Strict linkage becomes unknown at the gap and stays unknown. The separately calculated endpoint ratio is +8%; it does not reconstruct the missing intervals.

### 10. Histogram edges and exact zeros

Counts are [2, 2, 3, 4]. Binning the edges gives [1, 1, 1, 2]. Bins include their left edge and exclude their right edge except the last, which includes both. Exact zero belongs to the bin starting at zero.

### 11. Density area and unit changes

Shares are counts/11 and sum to one. Density is share/width; its area sums to one although heights need not sum to one and may exceed one. Multiplying widths by 100 requires dividing density heights by 100, preserving every bin area.

### 12. Scatter alignment by interval label

Retained dates are January 1, 3, and 4: (.01, .015), (0, 0), and (−.01, −.02). Coverage is 3/4 expected pairs. Independent dropna calls followed by positional pairing would not establish label alignment.

### 13. Correlation, slope, and equality

Correlation is +1, but the line has slope 2 and intercept .01 rather than the equality reference slope 1 and intercept 0. A constant coordinate has zero centered sum of squares, so the correlation denominator is zero; report the statistic as unavailable.

### 14. Signed weights and absolute composition

Net value is 1,000 and total absolute value 1,400. Signed weights are [.6, .4, −.2, .2]; absolute shares are [3/7, 2/7, 1/7, 1/7]. Both sums equal one for different reasons. Risky gross exposure is 1,200/1,000 = 120%, excluding cash. These are exposure measures, not risk contributions.

### 15. Payoff, profit, and contract scaling

Call profits are [−600, −600, −600, 0, 1,400]; put profits are [9,600, 0, −400, −400, −400]. Break-even prices are 106 and 96. Call payoff minus put payoff equals 100(S − 100). This terminal identity is not a claim about current option prices.

### 16. Equal numeric rates and equivalent rates

Using the same numeric nominal 5% with monthly compounding produces a larger balance than annual 5%. Equivalent nominal annual rate is 12[(1.05)^(1/12) − 1]; equivalent continuous rate is log(1.05). Applying these equivalent rates reproduces 1,000(1.05)^20 within floating-point tolerance.

### 17. Scenario orientation and a reference case

The grid shape is (5, 4); cell [2, 1] equals 1,000(1.05)^10. The joint case exceeds the reference by approximately 623.30 currency units. Both inputs change, so this difference is not a one-factor sensitivity. Scenario cells do not supply probabilities.

### 18. Zero, omission, units, and sign cues

The order is D, A, C, B; E is explicitly omitted, leaving coverage 4/5. C remains an observed zero-width bar, not missing data. PercentFormatter(xmax=1) displays .025 as 2.5%; a hatch on B supplements its sign and position. Object checks do not certify legibility or accessibility.

### 19. Export and resource checks

The line retains the three specified balances. PNG signature and SVG XML checks establish limited format evidence. Closing the Figure restores the prior open-figure set. These checks do not demonstrate that labels are readable; the temporary files are removed automatically.

### 20. Dashboard coverage and evidence

There are 5/6 price cells and 1/2 jointly complete adjacent-return pairs. A’s final strict return is unknown and serializes as null. Strict JSON rejects NaN; replacing LF with CRLF changes the input hash. A hash records byte identity, not economic truth. The small reference check covers these semantics only; it does not replace the sixteen acceptance tests or visual review in Section 8.13.

"""Twenty fixed-fixture reference checks for Chapter 8 exercises."""
import csv
import hashlib
import io
import json
from pathlib import Path
import tempfile
import unittest
from xml.etree import ElementTree
from zoneinfo import ZoneInfo
import matplotlib
matplotlib.use('Agg')
import matplotlib.pyplot as plt
import matplotlib.dates as mdates
from matplotlib.ticker import PercentFormatter
import numpy as np
import pandas as pd
from numpy.testing import assert_allclose, assert_array_equal


class Chapter08Solutions(unittest.TestCase):
    def test_01_same_endpoint_different_paths(self):
        paths = np.array([[100., 200.], [110., 160.], [120., 240.]])
        indexed = 100*paths/paths[0]
        assert_allclose(indexed[-1], [120, 120])
        assert_allclose(paths[-1]/paths[0]-1, [.2, .2])
        self.assertEqual(indexed[1, 1], 80)
        self.assertEqual(indexed[1, 0], 110)

    def test_02_figure_axes_axis_artist(self):
        fig, axes = plt.subplots(2, 1, squeeze=False)
        try:
            line, = axes[0,0].plot([0,1], [100,105])
            self.assertEqual(axes.shape, (2,1))
            self.assertIs(axes[0,0].figure, fig)
            self.assertIs(axes[0,0].yaxis.axes, axes[0,0])
            self.assertIs(axes[0,0].lines[0], line)
        finally: plt.close(fig)

    def test_03_coordinate_order_and_spacing(self):
        days = np.array([0,1,4]); values = np.array([100,101,103])
        fig, ax = plt.subplots()
        try:
            line, = ax.plot(days, values, marker='o')
            assert_array_equal(np.diff(line.get_xdata()), [1,3])
            bad_order = np.array([0,4,1])
            self.assertFalse(np.all(np.diff(bad_order)>0))
        finally: plt.close(fig)

    def test_04_nan_gap_versus_dropped_point(self):
        x = np.array([0.,1.,2.,3.]); y = np.array([100.,101.,np.nan,104.])
        fig, ax = plt.subplots()
        try:
            retained, = ax.plot(x,y)
            known = np.isfinite(y); dropped, = ax.plot(x[known],y[known])
            self.assertTrue(np.isnan(retained.get_ydata()[2]))
            assert_array_equal(dropped.get_xdata(), [0,1,3])
            self.assertTrue(np.isfinite(dropped.get_ydata()).all())
        finally: plt.close(fig)

    def test_05_post_step_effective_state(self):
        fig, ax = plt.subplots()
        try:
            line, = ax.step([0,1,3], [10,12,8], where='post')
            self.assertEqual(line.get_drawstyle(), 'steps-post')
            assert_allclose(line.get_path().vertices[:3], [[0,10],[1,10],[1,12]])
        finally: plt.close(fig)

    def test_06_repeated_clock_hour(self):
        stamps = pd.to_datetime(['2026-11-01T05:30:00Z','2026-11-01T06:30:00Z'], utc=True)
        coordinates = mdates.date2num(stamps.to_pydatetime())
        self.assertAlmostEqual((coordinates[1]-coordinates[0])*24, 1)
        formatter = mdates.DateFormatter('%H:%M %Z %z',tz=ZoneInfo('America/New_York'))
        self.assertEqual(formatter(coordinates[0]), '01:30 EDT -0400')
        self.assertEqual(formatter(coordinates[1]), '01:30 EST -0500')

    def test_07_expected_grid_row_and_cell_missingness(self):
        grid = pd.date_range('2026-01-01',periods=3,tz='UTC')
        source = pd.DataFrame({'A':[100.,102.], 'B':[200.,np.nan]},index=grid[[0,2]])
        aligned = source.reindex(grid)
        present = grid.isin(source.index)
        assert_array_equal(present,[True,False,True])
        assert_array_equal(aligned.notna().sum(axis=1),[2,0,1])
        self.assertEqual(aligned.notna().sum().sum(),3)

    def test_08_simple_log_and_compounded_returns(self):
        p = np.array([100.,110.,99.]); gross = p[1:]/p[:-1]
        r = gross-1; logs = np.diff(np.log(p))
        assert_allclose(r,[.1,-.1])
        self.assertAlmostEqual(r.sum(),0)
        self.assertAlmostEqual(np.prod(gross)-1,-.01)
        self.assertAlmostEqual(np.expm1(logs.sum()),-.01)

    def test_09_strict_linked_unknown_and_later_zero(self):
        p = np.array([100.,110.,99.,np.nan,108.,108.])
        gross = p[1:]/p[:-1]; returns = np.r_[np.nan,gross-1]
        linked = np.r_[0.,np.cumprod(gross)-1]
        assert_array_equal(np.isfinite(returns),[False,True,True,False,False,True])
        self.assertEqual(returns[-1],0)
        self.assertTrue(np.isnan(linked[3:]).all())
        self.assertAlmostEqual(p[-1]/p[0]-1,.08)

    def test_10_histogram_boundary_and_zero(self):
        edges = np.array([-.1,-.02,0.,.02,.1])
        sample = np.array([-.08,-.04,-.02,-.01,0.,0.,.01,.02,.03,.04,.1])
        counts,_ = np.histogram(sample,bins=edges)
        assert_array_equal(counts,[2,2,3,4])
        assert_array_equal(np.histogram(edges,bins=edges)[0],[1,1,1,2])
        self.assertEqual(counts.sum(),len(sample))

    def test_11_density_area_and_units(self):
        counts = np.array([2,2,3,4]); widths = np.array([.08,.02,.02,.08])
        mass = counts/11; density = mass/widths
        self.assertAlmostEqual(mass.sum(),1)
        self.assertAlmostEqual(np.sum(density*widths),1)
        self.assertGreater(density.max(),1)
        # Converting x to percentage-point units scales widths up and density down.
        assert_allclose((density/100)*(widths*100),mass)
        self.assertNotAlmostEqual(density.sum(),1)

    def test_12_scatter_label_alignment_and_joint_mask(self):
        dates = pd.date_range('2026-01-01',periods=4,tz='UTC')
        x = pd.Series([.01,.02,0.,-.01],index=dates,name='x')
        y = pd.Series([-.02,.015,np.nan,0.],index=dates[[3,0,1,2]],name='y')
        aligned = pd.concat([x,y],axis=1).reindex(dates)
        pairs = aligned.dropna(how='any')
        assert_array_equal(pairs.index,dates[[0,2,3]])
        assert_allclose(pairs.to_numpy(),[[.01,.015],[0.,0.],[-.01,-.02]])

    def test_13_correlation_is_not_slope(self):
        x = np.array([-.02,0.,.01,.03]); y = 2*x+.01
        self.assertAlmostEqual(np.corrcoef(x,y)[0,1],1)
        self.assertFalse(np.allclose(x,y))
        self.assertEqual(np.ptp(np.zeros(4)),0)
        # A constant coordinate makes the centered correlation denominator zero.
        centered = np.zeros(4)-np.zeros(4).mean()
        self.assertEqual(centered@centered,0)

    def test_14_signed_weights_and_absolute_shares(self):
        values = np.array([600.,400.,-200.,200.])
        net = values.sum(); absolute = np.abs(values).sum()
        weights = values/net; shares = np.abs(values)/absolute
        self.assertEqual(net,1000); self.assertEqual(absolute,1400)
        assert_allclose(weights,[.6,.4,-.2,.2])
        self.assertAlmostEqual(shares[2],1/7)
        self.assertAlmostEqual(weights.sum(),1); self.assertAlmostEqual(shares.sum(),1)
        self.assertAlmostEqual(np.abs(values[:3]).sum()/net,1.2)

    def test_15_payoff_profit_and_multiplier(self):
        s = np.array([0.,96.,100.,106.,120.])
        call = 100*np.maximum(s-100,0); put = 100*np.maximum(100-s,0)
        cp = call-600; pp = put-400
        assert_allclose(cp,[-600,-600,-600,0,1400])
        assert_allclose(pp,[9600,0,-400,-400,-400])
        assert_allclose(call-put,100*(s-100))
        self.assertEqual(call[2],0); self.assertEqual(cp[2],-600)

    def test_16_equal_numeric_and_equivalent_rates(self):
        principal=1000.; years=20
        annual=principal*1.05**years
        monthly_same_number=principal*(1+.05/12)**(12*years)
        equivalent_nominal=12*np.expm1(np.log1p(.05)/12)
        monthly_equivalent=principal*(1+equivalent_nominal/12)**(12*years)
        continuous_equivalent=principal*np.exp(np.log1p(.05)*years)
        self.assertGreater(monthly_same_number,annual)
        self.assertAlmostEqual(monthly_equivalent,annual,places=8)
        self.assertAlmostEqual(continuous_equivalent,annual,places=8)

    def test_17_scenario_orientation_and_reference_difference(self):
        rates=np.array([.01,.03,.05,.07,.09]); years=np.array([5,10,15,20])
        rr,nn=np.meshgrid(rates,years,indexing='ij')
        grid=1000*np.exp(nn*np.log1p(rr))
        self.assertEqual(grid.shape,(5,4))
        self.assertAlmostEqual(grid[2,1],1000*1.05**10)
        joint=1000*1.07**12; reference=1000*1.05**10
        self.assertAlmostEqual(joint-reference,623.2969621832355,places=7)

    def test_18_chart_units_zero_omission_and_sign_cues(self):
        returns=pd.Series([.025,-.01,0.,.04,np.nan],index=['A','B','C','D','E'])
        known=returns.dropna().sort_values(ascending=False)
        self.assertEqual(known.index.tolist(),['D','A','C','B'])
        self.assertEqual(returns.index[returns.isna()].tolist(),['E'])
        fig,ax=plt.subplots()
        try:
            bars=ax.barh(known.index,known.to_numpy())
            bars[-1].set_hatch('//'); ax.axvline(0,color='black')
            ax.xaxis.set_major_formatter(PercentFormatter(xmax=1.,decimals=1))
            self.assertEqual(ax.xaxis.get_major_formatter()(.025),'2.5%')
            self.assertEqual(bars[-1].get_hatch(),'//')
            self.assertEqual(bars[2].get_width(),0)
        finally: plt.close(fig)

    def test_19_export_objects_and_cleanup(self):
        before=set(plt.get_fignums()); fig,ax=plt.subplots(figsize=(4,3))
        try:
            line,=ax.plot([0,1,2],[100,105,110.25],marker='o')
            ax.set(xlabel='Elapsed years',ylabel='Illustrative USD balance')
            assert_allclose(line.get_ydata(),[100,105,110.25])
            with tempfile.TemporaryDirectory() as folder:
                png=Path(folder)/'figure.png'; svg=Path(folder)/'figure.svg'
                fig.savefig(png,dpi=100); fig.savefig(svg)
                self.assertEqual(png.read_bytes()[:8],b'\x89PNG\r\n\x1a\n')
                self.assertTrue(ElementTree.parse(svg).getroot().tag.endswith('svg'))
        finally: plt.close(fig)
        self.assertEqual(set(plt.get_fignums()),before)

    def test_20_dashboard_coverage_and_evidence_semantics(self):
        # Fixed mini-fixture: checks core accounting; not the Section 8.13 acceptance suite.
        raw=(b'timestamp,asset,currency,price\n'
             b'2026-01-01T00:00:00Z,A,USD,100\n'
             b'2026-01-01T00:00:00Z,B,USD,200\n'
             b'2026-01-02T00:00:00Z,A,USD,110\n'
             b'2026-01-02T00:00:00Z,B,USD,202\n'
             b'2026-01-03T00:00:00Z,B,USD,204\n')
        rows=list(csv.DictReader(io.StringIO(raw.decode())))
        frame=pd.DataFrame(rows); frame['timestamp']=pd.to_datetime(frame.timestamp,utc=True)
        frame['price']=frame.price.astype(float)
        grid=pd.date_range('2026-01-01',periods=3,tz='UTC')
        prices=frame.pivot(index='timestamp',columns='asset',values='price').reindex(grid)
        p=prices.to_numpy(); gross=p[1:]/p[:-1]; linked=np.cumprod(gross,axis=0)-1
        report={'input_sha256':hashlib.sha256(raw).hexdigest(),'observed':int(np.isfinite(p).sum()),
                'expected':int(p.size),'complete_pairs':int(np.isfinite(gross).all(axis=1).sum()),
                'A_final_strict':None if not np.isfinite(linked[-1,0]) else float(linked[-1,0])}
        self.assertEqual((report['observed'],report['expected'],report['complete_pairs']),(5,6,1))
        self.assertIsNone(json.loads(json.dumps(report,allow_nan=False))['A_final_strict'])
        self.assertNotEqual(hashlib.sha256(raw).hexdigest(),hashlib.sha256(raw.replace(b'\n',b'\r\n')).hexdigest())
        with self.assertRaises(ValueError): json.dumps({'bad':float('nan')},allow_nan=False)


if __name__=='__main__':
    unittest.main(verbosity=2)
