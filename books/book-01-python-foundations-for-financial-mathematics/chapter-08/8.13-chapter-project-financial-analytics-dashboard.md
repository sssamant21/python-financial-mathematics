## 1. Project Purpose

Build a reproducible financial reporting dashboard from a small CSV of synthetic USD prices. The project combines Chapter 7's validation and alignment habits with Chapter 8's indexed paths, cumulative returns, histograms, scatter plots, and explicit chart-design policies.

The deliverable is a **static four-panel report**, audit tables, and a machine-readable evidence record. It is not a hosted website, a live market-data application, an interactive trading screen, or an investment recommendation. No external account, API, credential, or network connection is needed to run the lab.

The dashboard must report incomplete evidence honestly. Its primary success case intentionally contains a missing price observation. A valid report preserves that gap, distinguishes endpoint-only changes from complete linked paths, and discloses the sample used in each panel.

## 3. Requirements and Analytical Contract

The project uses two fixed fictional assets, `ALPHA` and `BETA`, on six UTC midnight instants from January 1 through January 6, 2026. Every neighboring expected instant is exactly 24 hours apart. This is a synthetic calendar-day schedule, including weekend dates; it is not an exchange calendar.

| Requirement | Policy |
|---|---|
| Source format | UTF-8 CSV with exact ordered header `timestamp,asset,currency,price` |
| Size | 1–100,000 bytes; bounded read from the input file |
| Source rows | 1 through twice the number of expected grid instants |
| Timestamp tokens | Exact ASCII `YYYY-MM-DDTHH:MM:SSZ`; valid calendar instants |
| Assets/currency | Only ALPHA/BETA and exact USD |
| Price tokens | Unsigned ASCII decimal digits with optional fractional digits; no exponent, sign, whitespace, NaN, or infinity tokens |
| Observed price bounds | `[1e-6,1e6]` USD |
| Keys | Unique `(timestamp, asset)`; every source timestamp must belong to the supplied grid |
| Missingness | Absent asset/time rows become NaN on alignment; no filling |
| Baseline | Both assets need observed prices at the first expected instant |
| Returns | Adjacent expected-grid price ratios minus one |
| Linked path | Zero baseline; stop releasing the path from the first unknown required ratio onward |
| Paired returns | Same expected interval and both values known |
| Reporting basis | Price-only USD; no distributions, fees, taxes, FX, or annualization |

An empty price field is invalid input, not a missing-value token. Omit a missing asset/time record to express structural missingness under this CSV contract. A different provider format needs a different explicitly tested parser.

The numerical analysis helper also accepts a directly supplied aligned DataFrame under its stated validation rules, but the published CLI enters through the CSV loader.

## 5. Numerical Products and Release Policies

For each asset, define the indexed price and adjacent simple return:

$$I_t=100\frac{P_t}{P_0},\qquad r_t=\frac{P_t}{P_{t-1}}-1.$$

The first adjacent return is undefined because no preceding in-sample point exists. Missing prices block both neighboring required interval returns. No prior price is carried forward.

Define the strict linked path from the initial baseline:

$$C_0=0,\qquad C_t=\prod_{i=1}^{t}\frac{P_i}{P_{i-1}}-1,$$

with the reporting rule that an unknown required factor makes that and every later linked value unknown. Ordinary NumPy cumulative multiplication preserves that propagation. A later valid interval does not repair the missing earlier history.

For ALPHA, the adjacent returns after the baseline are `[+10%, -10%, unknown, unknown, 0%]`. Its strict linked values are `[0%, +10%, -1%, unknown, unknown, unknown]`. Its independently observed final/baseline price ratio is +8%, recorded as an **endpoint-only change**, not spliced into the strict linked line.

BETA's adjacent ratios are all known. Its final strict linked return is +5%, matching `210 / 200 - 1` within numerical tolerance. It therefore has a full released linked path, while ALPHA does not.

| Coverage/product | ALPHA | BETA |
|---|---:|---:|
| Observed prices | 5/6 | 6/6 |
| Known adjacent intervals | 3/5 | 5/5 |
| Endpoint-only price change | +8% | +5% |
| Final strict linked return | Withheld (`null` in JSON) | +5% |

The complete scatter pairs occur at Jan 2, Jan 3, and Jan 6. Its x-coordinate is BETA return and y-coordinate ALPHA return. The genuine ALPHA zero on Jan 6 remains a valid paired observation.

## 6. Four Panels, Four Questions

| Panel | Question | Data/coverage policy |
|---|---|---|
| Indexed prices | How do supplied price observations compare from a common baseline? | Preserve aligned NaNs; show later observed endpoints without inventing a gap path |
| Strict linked returns | Which cumulative paths have every required ratio from the original baseline? | Propagate unknowns; never skip or restart |
| Return count histograms | How are the known same-horizon adjacent returns distributed in this tiny sample? | Shared bins; ALPHA `n=3/5`, BETA `n=5/5`; no fitted model |
| Paired-return scatter | How do contemporaneous known returns compare? | Exactly three complete pairs from five expected intervals; no fitted line or correlation release |

The two time-series panels use UTC date coordinates and consistent asset colors, markers, and line styles. The histogram panel uses common edges covering every finite observed return, with a minimum display support of -15% through +15%. Its y-axis is count, not density or probability. Differing sample sizes are disclosed in the legend.

The scatter's axes represent returns, not time. Zero reference lines aid sign interpretation. The asset with less variation can appear visually compressed when zero is included on its axis; inspect the numeric pairs rather than inferring predictive strength from the cloud's shape. There is no fitted relationship, hypothesis test, or causal interpretation.

When no complete return pair exists, the scatter panel reports “No complete pairs.” The histogram still supports empty observed interval samples with zero counts, while the title retains price coverage. The test suite exercises this degenerate but valid diagnostic case.

## 7. Architecture and Reproducibility

The program separates five responsibilities:

1. `validate_grid` checks the independently supplied time grid and normalizes it to UTC.
2. `load_prices` reads bounded input bytes, validates CSV fields and keys, hashes those same bytes, and aligns prices.
3. `analyze` creates copied numeric products, complete pairs, and coverage/release summaries.
4. `build_dashboard` renders those products without a second calculation policy for each panel.
5. `run` creates a fresh output directory, writes the report/audit files, and writes JSON evidence last.

The loader uses Python's CSV reader, which returns field strings before the application's explicit conversion checks [1]. pandas alignment creates missing values at absent expected labels [3]. Matplotlib subplots organize the report panels [4].

The SHA-256 input digest identifies the bytes consumed in that run [2]. The code digest identifies the local `dashboard.py` bytes at export time. Runtime versions provide additional reproduction context. None of these establishes that a quote is authentic, economically valid, or independently verified.

Image bytes need not match between runs: rendering libraries, fonts, SVG identifiers/metadata, and environment settings can change exported bytes without changing financial values. Each run hashes its own generated outputs. Compare policies and numerical audit tables when assessing analytical equivalence, rather than requiring identical image digests.

## 8. Output Isolation and Failure Behavior

The output path must not already exist. This prevents a new run from reusing an old successful report directory and accidentally combining stale and current files. Input parsing and financial analysis finish before the directory is created.

If a later export or write fails, a partial new directory may remain. The files are not committed as an atomic transaction. Do not treat a partial directory as a completed report. A successful run writes `evidence.json` last, and readers should verify its listed hashes against the referenced files before relying on a copied bundle.

An existing directory is rejected without replacing its files. For another demonstration run, select a new path, such as `output/run02`. Tests use temporary fresh directories and clean them automatically. No cleanup command that deletes reader data is needed to reproduce the lab.

The program records `null` for an unavailable final strict linked return. It uses JSON serialization with `allow_nan=False`, so unhandled nonstandard NaN values cannot silently become JSON numeric literals. CSV audit outputs use the explicit marker `NA`; interpret it as unknown or baseline-undefined according to the relevant column/product.

The general helpers accept an expected grid of 3–31 consecutive 24-hour aware instants in supported UTC years 2000–2100.
```python
"""Reproducible static financial dashboard with coverage and audit exports."""
import argparse
import csv
import hashlib
import io
import json
from pathlib import Path
import platform
import re
from datetime import timezone
import matplotlib
matplotlib.use('Agg')
import matplotlib.pyplot as plt
import matplotlib.dates as mdates
from matplotlib.ticker import PercentFormatter, MaxNLocator
import numpy as np
import pandas as pd

ASSETS = ('ALPHA', 'BETA')
HEADER = ['timestamp', 'asset', 'currency', 'price']


def validate_grid(grid):
    if (not isinstance(grid, pd.DatetimeIndex) or grid.tz is None or grid.hasnans
            or not grid.is_unique or not grid.is_monotonic_increasing
            or not 3 <= len(grid) <= 31):
        raise ValueError('expected grid needs 3..31 sorted unique aware instants')
    grid = grid.tz_convert('UTC').copy()
    if (grid[0].year < 2000 or grid[-1].year > 2100
            or not (grid[1:]-grid[:-1] == pd.Timedelta(days=1)).all()):
        raise ValueError('grid must contain consecutive 24-hour instants in 2000..2100')
    return grid


def load_prices(path, expected):
    grid = validate_grid(expected)
    with Path(path).open('rb') as stream:
        raw = stream.read(100001)
    if not 1 <= len(raw) <= 100000:
        raise ValueError('CSV must contain 1..100000 bytes')
    try:
        rows = list(csv.reader(io.StringIO(raw.decode('utf-8'), newline=''), strict=True))
    except (UnicodeError, csv.Error) as exc:
        raise ValueError('invalid UTF-8 CSV') from exc
    if not rows or rows[0] != HEADER or not 1 <= len(rows)-1 <= len(grid)*2:
        raise ValueError('wrong header or row count')
    records = []; seen = set()
    for row in rows[1:]:
        if len(row) != 4:
            raise ValueError('each row must have exactly four fields')
        timestamp, asset, currency, token = row
        if (not re.fullmatch(r'[0-9]{4}-[0-9]{2}-[0-9]{2}T[0-9]{2}:[0-9]{2}:[0-9]{2}Z', timestamp)
                or asset not in ASSETS or currency != 'USD'
                or not re.fullmatch(r'[0-9]+(?:\.[0-9]+)?', token)):
            raise ValueError('invalid timestamp, asset, currency, or decimal token')
        instant = pd.Timestamp(timestamp)
        price = float(token)
        key = (instant, asset)
        if key in seen or instant not in grid or not 1e-6 <= price <= 1e6:
            raise ValueError('duplicate/off-grid key or price outside [1e-6,1e6]')
        seen.add(key); records.append((instant, asset, price))
    table = pd.DataFrame(records, columns=['timestamp', 'asset', 'price'])
    prices = table.pivot(index='timestamp', columns='asset', values='price').reindex(index=grid, columns=ASSETS)
    prices.columns.name = None; prices.index.name = 'timestamp'
    return prices, {'input_sha256': hashlib.sha256(raw).hexdigest(), 'source_rows': len(records)}


def analyze(prices):
    if (not isinstance(prices, pd.DataFrame) or tuple(prices.columns) != ASSETS
            or any(dtype != np.dtype('float64') for dtype in prices.dtypes)):
        raise ValueError('prices must have ALPHA/BETA float64 columns')
    grid = validate_grid(prices.index)
    p = prices.to_numpy(copy=True)
    finite = p[np.isfinite(p)]
    if (np.isinf(p).any() or (finite < 1e-6).any() or (finite > 1e6).any()
            or not np.isfinite(p[0]).all()):
        raise ValueError('valid positive observed prices and both baselines required')
    clean = pd.DataFrame(p, index=grid, columns=ASSETS)
    clean.index.name = 'timestamp'
    gross = p[1:]/p[:-1]
    returns = pd.DataFrame(np.vstack([np.full(2, np.nan), gross-1]), index=grid, columns=ASSETS)
    linked = pd.DataFrame(np.vstack([np.zeros(2), np.cumprod(gross, axis=0)-1]), index=grid, columns=ASSETS)
    indexed = 100*clean/clean.iloc[0]
    pairs = returns.iloc[1:].dropna(how='any').copy()
    summaries = []
    for j, asset in enumerate(ASSETS):
        endpoint = p[-1,j]/p[0,j]-1 if np.isfinite(p[-1,j]) else None
        final_linked = float(linked.iloc[-1,j]) if np.isfinite(linked.iloc[-1,j]) else None
        summaries.append({'asset': asset, 'observed_prices': int(np.isfinite(p[:,j]).sum()),
                          'known_intervals': int(returns[asset].iloc[1:].notna().sum()),
                          'endpoint_only_change': endpoint, 'final_strict_linked': final_linked})
    report = {'assets': summaries, 'expected_price_cells': int(p.size),
              'observed_price_cells': int(np.isfinite(p).sum()),
              'expected_intervals_per_asset': len(grid)-1, 'complete_pair_intervals': len(pairs),
              'full_linked_paths': sum(s['final_strict_linked'] is not None for s in summaries)}
    return {'prices': clean, 'indexed': indexed, 'returns': returns, 'linked': linked,
            'pairs': pairs, 'report': report}


def build_dashboard(result):
    prices, returns = result['prices'], result['returns']; report = result['report']
    x = mdates.date2num(prices.index.to_pydatetime())
    fig, axes = plt.subplots(2, 2, figsize=(12, 8), layout='constrained')
    styles = [('ALPHA', '#0072B2', 'o', '-'), ('BETA', '#D55E00', 's', '--')]
    for asset, color, marker, style in styles:
        axes[0,0].plot(x, result['indexed'][asset], color=color, marker=marker, linestyle=style, label=asset)
        axes[0,1].plot(x, result['linked'][asset], color=color, marker=marker, linestyle=style, label=asset)
    axes[0,0].set(title='Indexed supplied prices | gaps retained', ylabel='Price index (baseline 100)')
    axes[0,1].set(title='Strict linked returns | no skip or restart', ylabel='Cumulative price return')
    axes[0,1].yaxis.set_major_formatter(PercentFormatter(xmax=1.))
    for ax in axes[0]:
        ax.legend(fontsize=8); ax.grid(alpha=.2); ax.set_xticks(x)
        ax.xaxis.set_major_formatter(mdates.DateFormatter('%b %d', tz=timezone.utc))
        ax.set_xlabel('UTC observation date')
    observed = returns.iloc[1:].to_numpy(); finite = observed[np.isfinite(observed)]
    lower = min(-.15, float(finite.min())) if len(finite) else -.15
    upper = max(.15, float(finite.max())) if len(finite) else .15
    edges = np.linspace(lower, upper, 7)
    for asset, color, marker, style in styles:
        sample = returns[asset].iloc[1:].dropna().to_numpy()
        counts, _ = np.histogram(sample, bins=edges)
        axes[1,0].stairs(counts, edges, color=color, linestyle=style, linewidth=2,
                         label=f'{asset}: n={len(sample)}/{len(prices)-1}')
    axes[1,0].set(title='Observed adjacent-return counts | shared bins',
                  xlabel='24-hour simple price return', ylabel='Observed intervals')
    axes[1,0].xaxis.set_major_formatter(PercentFormatter(xmax=1., decimals=0))
    axes[1,0].yaxis.set_major_locator(MaxNLocator(integer=True)); axes[1,0].set_ylim(bottom=0)
    axes[1,0].legend(fontsize=8); axes[1,0].grid(alpha=.2)
    pairs = result['pairs']
    if len(pairs):
        axes[1,1].scatter(pairs.BETA, pairs.ALPHA, color='#0072B2', edgecolors='black', linewidths=.5)
    else:
        axes[1,1].text(.5, .5, 'No complete pairs', transform=axes[1,1].transAxes, ha='center')
    axes[1,1].axhline(0, color='gray', linewidth=.7); axes[1,1].axvline(0, color='gray', linewidth=.7)
    axes[1,1].set(title=f'Paired adjacent returns | complete {len(pairs)}/{len(prices)-1}',
                  xlabel='BETA simple price return', ylabel='ALPHA simple price return')
    for axis in [axes[1,1].xaxis, axes[1,1].yaxis]: axis.set_major_formatter(PercentFormatter(xmax=1., decimals=2))
    axes[1,1].grid(alpha=.2)
    window = f'{prices.index[0]:%Y-%m-%d} to {prices.index[-1]:%Y-%m-%d} UTC'
    fig.suptitle(f'Synthetic financial analytics dashboard | {window}\n'
                 f'Prices {report["observed_price_cells"]}/{report["expected_price_cells"]}; '
                 f'full linked paths {report["full_linked_paths"]}/2; no filling', fontsize=12)
    fig.supxlabel('Price-only USD inputs | no portfolio aggregation, annualization, fitted distribution, or causal inference', fontsize=9)
    return fig, axes


def run(input_path, output_dir, expected):
    prices, metadata = load_prices(input_path, expected)
    result = analyze(prices)
    output = Path(output_dir)
    # Fresh directory prevents old report files from being mistaken for this run.
    output.mkdir(parents=True, exist_ok=False)
    fig, _ = build_dashboard(result)
    try:
        fig.savefig(output/'dashboard.png', dpi=150)
        fig.savefig(output/'dashboard.svg')
    finally:
        plt.close(fig)
    result['prices'].to_csv(output/'aligned_prices.csv', na_rep='NA')
    result['returns'].to_csv(output/'adjacent_returns.csv', na_rep='NA')
    result['linked'].to_csv(output/'strict_linked_returns.csv', na_rep='NA')
    result['pairs'].to_csv(output/'complete_return_pairs.csv', na_rep='NA')
    evidence = {**metadata, **result['report'], 'window_start': prices.index[0].isoformat(),
                'window_end': prices.index[-1].isoformat(), 'currency': 'USD',
                'policy': 'point prices; adjacent 24h returns; strict linked paths; no filling',
                'code_sha256': hashlib.sha256(Path(__file__).read_bytes()).hexdigest(),
                'runtime': {'python': platform.python_version(), 'numpy': np.__version__,
                            'pandas': pd.__version__, 'matplotlib': matplotlib.__version__}}
    evidence['output_sha256'] = {p.name: hashlib.sha256(p.read_bytes()).hexdigest()
                                 for p in sorted(output.iterdir()) if p.is_file()}
    # Write evidence last. It records completion of these writes, not model certification.
    (output/'evidence.json').write_text(json.dumps(evidence, indent=2, allow_nan=False)+'\n', encoding='utf-8')
    return evidence


def main():
    parser = argparse.ArgumentParser()
    parser.add_argument('--input', default='prices.csv')
    parser.add_argument('--out', default='output/run01')
    args = parser.parse_args()
    expected = pd.date_range('2026-01-01T00:00:00Z', periods=6, freq='D')
    evidence = run(args.input, args.out, expected)
    print(f'Price coverage: {evidence["observed_price_cells"]}/{evidence["expected_price_cells"]}')
    print(f'Complete return pairs: {evidence["complete_pair_intervals"]}/5')
    print(f'Full strict linked paths: {evidence["full_linked_paths"]}/2')
    print(f'Input SHA-256: {evidence["input_sha256"]}')
    print(f'Saved dashboard, audit tables, and evidence to {args.out}')


if __name__ == '__main__':
    main()
```

The byte limit bounds the read, and the row/field/key checks run before pivoting. The application rejects off-grid and duplicate records rather than relying on pivoting or reindexing to resolve them. Blank rows, altered headers, missing fields, unsupported tokens, and invalid calendar timestamps are not silently repaired.

The analysis helper copies arrays before constructing products. The common initial prices are required even if later cells are missing. It permits missing endpoints, in which case the endpoint-only summary is also withheld. It makes no portfolio aggregation claim because no holdings or portfolio-weight inputs are supplied.

## 14. Troubleshooting and Reporting Decisions

| Symptom | Likely cause or meaning | Response |
|---|---|---|
| `FileExistsError` at output creation | The selected run directory already exists | Choose a new run path; inspect the prior directory separately |
| Wrong header or field count | Source format differs from the contract | Correct the declared source/export or write a separately tested parser |
| Invalid decimal token | Exponents, blanks, signs, or missing-value strings are present | Apply an explicit ingestion policy; do not coerce silently |
| Duplicate key rejected | More than one price is supplied for an asset/instant | Resolve under an upstream documented rule |
| Off-grid timestamp rejected | The source and expected observation schedule differ | Reconcile timestamp semantics and schedule before plotting |
| Baseline missing | One common initial price is unavailable | Correct the data or define a new explicit comparison baseline |
| Linked path stops while endpoint price exists | A required intermediate ratio is unknown | Retain the strict path policy and label endpoint-only output separately |
| Histograms have different sample sizes | The assets have different interval coverage | Read the disclosed counts; do not interpret heights without denominators |
| Scatter says no complete pairs | No interval has both returns | Investigate coverage rather than inventing pairs |
| Partial output directory without evidence | Export did not finish | Diagnose the error and use a fresh directory for the next attempt |

## 15. Applied Exercises and Extensions

1. **Known arithmetic:** Reconcile ALPHA's +10%, -10%, and linked -1% through Jan 3 using the source prices.  
   **Guidance:** `110/100 - 1`, `99/110 - 1`, and `99/100 - 1` give the required values.
2. **Gap policy:** Why does ALPHA's final zero adjacent return not restore its linked path?  
   **Guidance:** The earlier unknown ratios remain required to link from the original baseline.
3. **Coverage:** Which interval endpoints form the scatter pairs?  
   **Guidance:** Jan 2, Jan 3, and Jan 6. Confirm them in `complete_return_pairs.csv`.
4. **Source order:** Reverse the data rows without changing the header. What should change?  
   **Guidance:** The byte hash changes; aligned prices and financial outputs remain the same.
5. **Rejection:** Add an identical duplicate key and run into a new output path. What should happen?  
   **Guidance:** Validation fails before creating the new report directory.
6. **Complete fixture:** In a separate test fixture, supply an ALPHA Jan 4 price of 105. What becomes releasable?  
   **Guidance:** All ALPHA adjacent intervals and its final strict linked +8% path become known; complete pair coverage rises to 5/5.
7. **Independent schedule:** Why not infer the expected grid from source timestamps?  
   **Guidance:** A completely absent time point could then disappear from the expectations and coverage count.
8. **Extension scope:** What must change before this becomes a real portfolio dashboard?  
   **Guidance:** Add complete holdings/weights, valuation and currency conventions, data lineage, portfolio-return definitions, and appropriate acceptance tests. Two asset price paths alone do not establish a portfolio result.
