## 1. Purpose

An effective financial chart makes its analytical meaning easy to recover. A reader should be able to identify the measure, units, observation window, comparison basis, missingness, and source assumptions without reverse-engineering the code.

The earlier sections developed individual chart families. This section brings their design decisions together and builds a compact release example: a cross-asset return comparison with signed bars, direct labels, an observed-zero marker, an explicit missing-asset note, and both color and monochrome exports.

The goal is clear communication of validated inputs. Good design cannot establish that a source price is correct, that a model is suitable, or that a selected reporting window is representative. Those remain separate analytical responsibilities.

## 2. Learning Objectives

After completing this section, you should be able to:

1. Translate a financial question into a chart specification before styling.
2. State the data measure, units, window, and comparison conventions in the figure.
3. Choose axes and baselines that preserve the intended visual encoding.
4. Distinguish unknown observations from observed zeros.
5. Add labels and redundant sign cues that remain useful in monochrome.
6. Separate automated data/Artist checks from visual export review.
7. Document the limits of a chart's accessibility and financial validation.

Prerequisites: Sections 8.1–8.11, pandas Series, missing-data rules, and basic unit testing.

## 3. Start with a Reviewable Chart Specification

Write one sentence describing the intended comparison. For this lab: “Compare the supplied simple price returns for five fictional assets over the same stated endpoint-to-endpoint interval, displaying the four known values and identifying the unknown one.”

Then record the decisions that give that sentence a precise meaning:

| Decision | Lab specification |
|---|---|
| Quantity plotted | Already-derived simple price return per asset |
| Stored units | Decimal fractions, displayed as percentages |
| Window | 2026-01-01 00:00 UTC to 2026-02-01 00:00 UTC |
| Interpretation of window | Return between the stated endpoints, not a stream of observations |
| Adjustment basis | Synthetic price-only values; no distributions, fees, or FX adjustment |
| Source scope | Five asset slots in the local fixture |
| Missingness | Exclude the unknown value from bars and name the omitted asset |
| Zero treatment | Keep an observed zero and add a visible marker |
| Order | Return descending; asset ascending for ties |
| Baseline | Zero, with negative returns extending left |
| Output | Color PNG, color SVG, and separately rendered monochrome PNG |

The program accepts the common window as caller metadata. It cannot infer that precomputed asset returns were actually calculated from compatible prices or endpoints. The caller must establish that lineage upstream.

## 4. Match the Chart to the Comparison

The fixture contains one return per asset, not a time sequence. Horizontal bars make category names readable and allow comparison from a common zero baseline. Direct numeric labels complement, rather than replace, the bar-length encoding.

A line chart connecting asset names would imply an ordering relationship that is not part of the financial question. A pie chart would suggest a part-to-whole quantity, whereas signed returns are not allocation shares. A histogram would describe the distribution of the supplied returns while losing asset identity. A scatter plot would require another coordinate with a defined paired-observation meaning.

Choosing a chart is therefore an analytical decision. Choose the visual encoding that answers the stated question before adding color, labels, and layout details.

## 5. Worked Data and Honest Missingness

The synthetic input is:

| Asset | Stored decimal return | Display value | Status |
|---|---:|---:|---|
| ALPHA | 0.025 | +2.5% | Observed |
| BETA | -0.01 | -1.0% | Observed |
| GAMMA | 0.0 | 0.0% | Observed zero |
| DELTA | 0.04 | +4.0% | Observed |
| EPSILON | NaN | Unknown | Omitted from bars and named in note |

The title reports observed **4/5**. The source note identifies **EPSILON** as unknown and omitted. It does not assign EPSILON a zero bar, interpolate a value, or imply that the remaining four are the full intended universe.

GAMMA is different: its return is known to be zero. Because a zero-width bar is visually inconspicuous, the chart adds an open circle at the zero origin and a direct value label. The label's plus sign is a formatting convention; it does not change a zero into a positive gain.

The arithmetic mean of the observed assets is not calculated or presented as a portfolio return. A portfolio result would need its weights, timing, cash-flow, and completeness policies. A comparison chart of asset returns does not supply them automatically.

## 6. Titles, Axes, and Notes Have Different Jobs

The title states the comparison and observed coverage. Its second line gives the complete UTC window. The horizontal axis identifies the measure as simple price return over the common reporting interval. The asset labels identify the compared entities.

The footer names the synthetic source, the omitted asset, the missingness policy, and the price-only scope. In a real report, replace “synthetic fixture” with the actual source/version or retrieval identifier, while retaining enough context to locate the data used.

Use the title for the central comparison, axes for units and dimensions, and the note for material qualifications. Avoid crowding every implementation detail into the figure. File paths, internal function names, and test commands generally belong in the accompanying report or lab instructions, not the reader's main visual flow.

A chart should remain understandable when separated from its original conversation. A caption, data table, or accessible text description should travel with an exported figure when its context is otherwise unavailable.

## 7. Baselines, Scale, and Precision

A bar's length represents magnitude from an origin. The lab therefore retains zero and shows negative and positive sides on a linear percentage axis. Truncating a positive bar chart's baseline can exaggerate relative differences in length. Signed returns particularly need a visible zero reference.

Line charts may use a focused vertical range for a clearly labeled question, while logarithmic balance plots answer ratio questions. Those choices have different semantics from a bar-length comparison. Do not use one universal axis rule without considering the encoding.

The helper derives padding from the observed range and includes a minimum margin. This gives direct labels room beyond bar ends. It does not clip the displayed data to a preferred performance story. If an adapted dataset produces overlapping labels, adjust and re-inspect the output rather than assuming layout automation solved it.

Returns remain decimals throughout. A `PercentFormatter(xmax=1.0)` displays the axis, while explicit labels use Python percentage formatting. Thus `0.025` becomes `+2.5%`; the data are not multiplied by 100 first.

One decimal place is enough for this fixture's labels. It is a presentation choice, not evidence of measurement accuracy. Two values that round to the same display label may still differ in the retained data. Choose precision to support the question and keep the unrounded source available.

## 8. Ordering and Direct Labels

The chart sorts by return descending and asset name ascending to resolve ties. Its displayed order is DELTA, ALPHA, GAMMA, BETA. Sorting is applied to a table that keeps each asset and its value together; values are never sorted independently of their labels.

A high-to-low ordering helps the reader compare this snapshot. For repeated reports, a stable asset order may be preferable so readers can track the same row across time. Choose and disclose the rule; changing sort order can make visual movement look like a change in an asset's result when only its row position changed.

Matplotlib's `bar_label` adds the explicitly formatted values to the bars [3]. A direct label reduces the need to estimate a precise return from tick spacing. The implementation reserves margin for those labels and checks both positive and negative examples.

With one data series and direct category labels, no additional color legend is needed. Avoid a legend that repeats information without helping the reader identify a distinct encoding.

## 9. Color Should Reinforce Meaning

The color version uses blue for nonnegative returns and orange for negative returns. Sign is also conveyed by direction relative to zero, an explicit signed value label, and hatching on negative bars. A reader need not distinguish colors to identify a decline.

The monochrome version changes the fill palette while retaining identical values, labels, ordering, sign direction, and negative hatching. It is separately rendered from the same prepared data; it is not a claim that every arbitrary grayscale conversion will preserve all distinctions.

Matplotlib documents hatching for patch-based plots and its backend support [2]. This lab exports PNG and SVG using supported paths and inspects the PNGs. For another format/backend, verify that patterns remain visible.

For numerical color scales, choose a map consistent with the quantity: sequential scales for ordered magnitude, diverging scales around a meaningful reference, and distinct categorical colors for categories. Matplotlib's colormap guide discusses these families and perceptual considerations [1]. A colorbar must name the encoded units, as in Section 8.11.

Do not treat a chosen palette as a guarantee of accessibility. Legibility depends on contrast, size, output medium, color perception, and surrounding context. Redundant encodings, source tables, and text alternatives improve usability but do not constitute an accessibility certification.

## 10. Export Is Part of the Design

The lab writes a color PNG, a color SVG, and a monochrome PNG. PNG is convenient for fixed-size previews; SVG preserves vector geometry for the elements used here. Matplotlib's `savefig` controls file format and raster resolution [4].

At the chosen 8 by 5 inches and 150 dpi, the ordinary uncropped PNG is 1,200 by 750 pixels. Inspect it at the size at which the reader will actually see it. A figure that looks clear when zoomed to full screen may have unreadable footnotes in a slide, document column, or chat preview.

The SVG is structurally parsed in tests, but no separate browser rendering of it is claimed. Vector format alone does not guarantee correct text flow, embedded-font behavior, assistive-technology support, or visual accessibility.

The file set is not an atomic export transaction: a later failure can leave an earlier file on disk. Re-running the demonstration replaces its three outputs. Each figure is closed in a `finally` block after its attempted saves, so repeated report generation does not leave these figures registered in pyplot.

Input is a pandas Series with ordinary NumPy `float64` dtype and 1–12 unique asset labels. Labels must be nonempty strings without leading/trailing whitespace and no longer than 16 characters. NaNs are allowed, infinity is rejected, and at least one observed return is required. Observed simple returns must lie in `[-1,10]`; these are teaching bounds, not universal financial-return limits.

The caller supplies increasing timezone-aware pandas start/end Timestamps in the supported UTC year range 2000–2100. They are converted to UTC for display. The implementation does not annualize returns or calculate them from prices. Its fixed footer assumes price-only inputs without the stated adjustments; adapt that metadata if the input definition changes.

The `monochrome` option must be Boolean. It changes presentation only. The prepared numerical table, missing labels, and reporting-window instants are separate from the figure-building code.

### `chart_design.py`

```python
"""A labeled return comparison with explicit omissions and monochrome support."""
from pathlib import Path
import matplotlib
matplotlib.use('Agg')
import matplotlib.pyplot as plt
from matplotlib.ticker import PercentFormatter
import numpy as np
import pandas as pd


def fixture():
    values = pd.Series([.025, -.01, 0., .04, np.nan],
                        index=['ALPHA', 'BETA', 'GAMMA', 'DELTA', 'EPSILON'],
                        name='simple_price_return')
    return values, pd.Timestamp('2026-01-01T00:00:00Z'), pd.Timestamp('2026-02-01T00:00:00Z')


def prepare(values, start, end):
    times = []
    for t in [start, end]:
        if not isinstance(t, pd.Timestamp) or pd.isna(t) or t.tzinfo is None:
            raise ValueError('start/end must be aware pandas Timestamps')
        times.append(t.tz_convert('UTC'))
    if not 2000 <= times[0].year <= times[1].year <= 2100 or not times[0] < times[1]:
        raise ValueError('require an increasing reporting window within 2000..2100')
    if (not isinstance(values, pd.Series) or values.dtype != np.dtype('float64')
            or not 1 <= len(values) <= 12 or not values.index.is_unique
            or any(not isinstance(label, str) or not label or label != label.strip()
                   or len(label)>16 for label in values.index)):
        raise ValueError('supply 1..12 unique nonblank labels and float64 returns')
    raw = values.to_numpy(copy=True)
    known = raw[np.isfinite(raw)]
    if np.isinf(raw).any() or (known < -1).any() or (known > 10).any() or not len(known):
        raise ValueError('need observed simple returns within [-1,10]; infinity is invalid')
    data = pd.DataFrame({'asset': values.index.to_list(), 'return': raw})
    missing = data.loc[data['return'].isna(), 'asset'].tolist()
    observed = data.loc[data['return'].notna()].copy()
    observed = observed.sort_values(['return', 'asset'], ascending=[False, True]).reset_index(drop=True)
    return observed, missing, times


def build_figure(values, start, end, monochrome=False):
    if not isinstance(monochrome, bool):
        raise ValueError('monochrome must be Boolean')
    observed, missing, times = prepare(values, start, end)
    r = observed['return'].to_numpy(); y = np.arange(len(r))
    palette = ['#777777' if monochrome else ('#D55E00' if v<0 else '#0072B2') for v in r]
    with plt.rc_context({'font.size': 10, 'axes.titlesize': 12}):
        fig, ax = plt.subplots(figsize=(8, 5), layout='constrained')
        bars = ax.barh(y, r, color=palette, edgecolor='black', linewidth=.6)
        for bar, value in zip(bars, r):
            if value < 0: bar.set_hatch('//')
        ax.bar_label(bars, labels=[f'{value:+.1%}' for value in r], padding=5, fontsize=9)
        zero = r == 0
        ax.plot(r[zero], y[zero], linestyle='none', marker='o',
                 markerfacecolor='white', markeredgecolor='black', markersize=5)
        ax.set_yticks(y, observed.asset.to_list()); ax.invert_yaxis()
        ax.axvline(0, color='black', linewidth=.9)
        lo = min(float(r.min()), 0.); hi = max(float(r.max()), 0.)
        pad = max((hi-lo)*.25, .01)
        ax.set_xlim(lo-pad, hi+pad)
        ax.xaxis.set_major_formatter(PercentFormatter(xmax=1., decimals=1))
        ax.set_xlabel('Simple price return over the common reporting interval')
        ax.set_title(f'Synthetic return comparison | observed {len(observed)}/{len(values)}\n'
                      f'{times[0]:%Y-%m-%d %H:%M} to {times[1]:%Y-%m-%d %H:%M} UTC', loc='left')
        ax.grid(axis='x', alpha=.2); ax.set_axisbelow(True)
        ax.spines[['top', 'right']].set_visible(False)
        omitted = ', '.join(missing) if missing else 'none'
        fig.supxlabel(f'Synthetic fixture | unknown and omitted: {omitted}\n'
                       'No filling; zero returns retained. Price-only; no fees, distributions, or FX adjustments.',
                       fontsize=8)
    return fig, ax


def save_example(folder='output'):
    values, start, end = fixture()
    output = Path(folder); output.mkdir(parents=True, exist_ok=True)
    paths = []
    for monochrome, stem in [(False, 'financial_chart'), (True, 'financial_chart_monochrome')]:
        fig, _ = build_figure(values, start, end, monochrome)
        try:
            png = output/(stem+'.png'); fig.savefig(png, dpi=150, facecolor='white'); paths.append(png)
            if not monochrome:
                svg = output/(stem+'.svg'); fig.savefig(svg, facecolor='white'); paths.append(svg)
        finally:
            plt.close(fig)
    return paths


def main():
    values, start, end = fixture(); observed, missing, _ = prepare(values, start, end)
    print(f'Observed: {len(observed)}/{len(values)}; unknown: {len(missing)}')
    print('Displayed order: '+', '.join(observed.asset))
    print('Unknown and omitted: '+', '.join(missing))
    for path in save_example(): print('Saved '+path.as_posix())


if __name__ == '__main__':
    main()
```

The temporary style context sets selected font defaults and then restores them. It is not complete isolation from every possible global Matplotlib setting. The publication export was checked in the stated runtime with its available rendering configuration.

The input is copied into an asset/value table before filtering and sorting. An unknown asset is omitted from bars only under the explicit disclosure policy. The function does not renormalize the remaining returns, calculate a partial portfolio total, or mutate the source Series.

### `test_chart_design.py`

```python
import tempfile
import unittest
from xml.etree import ElementTree
import numpy as np
import pandas as pd
from numpy.testing import assert_allclose
from pandas.testing import assert_series_equal, assert_frame_equal
from chart_design import fixture, prepare, build_figure, save_example, plt


class DesignTests(unittest.TestCase):
    def test_order_zero_and_omission(self):
        values, start, end = fixture(); data, missing, _ = prepare(values, start, end)
        self.assertEqual(data.asset.tolist(), ['DELTA', 'ALPHA', 'GAMMA', 'BETA'])
        assert_allclose(data['return'], [.04, .025, 0, -.01])
        self.assertEqual(missing, ['EPSILON'])

    def test_invalid_returns_and_empty_observed_sample(self):
        values, start, end = fixture()
        for value in [np.inf, -1.01, 11.]:
            bad = values.copy(); bad.iloc[0] = value
            with self.assertRaises(ValueError): prepare(bad, start, end)
        with self.assertRaises(ValueError): prepare(values*float('nan'), start, end)
        with self.assertRaises(ValueError): prepare(values.astype(str), start, end)

    def test_invalid_labels(self):
        values, start, end = fixture()
        for labels in [['A','A','B','C','D'], ['A',' ','B','C','D']]:
            bad=values.copy(); bad.index=labels
            with self.assertRaises(ValueError): prepare(bad, start, end)

    def test_reporting_window_and_zone_equivalence(self):
        values, start, end=fixture()
        for a,b in [(end,start), (start,start), (start.tz_localize(None),end), (pd.NaT,end)]:
            with self.assertRaises(ValueError): prepare(values,a,b)
        self.assertEqual(prepare(values,start.tz_convert('America/New_York'),end)[2][0],start)

    def test_inputs_preserved_and_order_invariance(self):
        values, start, end=fixture(); original=values.copy(deep=True)
        data, _, _=prepare(values,start,end)
        changed, _, _=prepare(values.iloc[::-1],start,end)
        assert_frame_equal(data,changed)
        data.iloc[0,1]=99
        assert_series_equal(values,original)

    def test_color_and_monochrome_share_data_and_hatch(self):
        values,start,end=fixture(); fig1,ax1=build_figure(values,start,end)
        fig2,ax2=build_figure(values,start,end,True)
        try:
            assert_allclose([p.get_width() for p in ax1.patches], [p.get_width() for p in ax2.patches])
            self.assertEqual(ax2.patches[-1].get_hatch(),'//')
            self.assertEqual(ax2.lines[0].get_xdata()[0],0)
        finally:
            plt.close(fig1); plt.close(fig2)

    def test_axis_baseline_labels_and_missing_note(self):
        values,start,end=fixture(); fig,ax=build_figure(values,start,end)
        try:
            lo,hi=ax.get_xlim(); self.assertLess(lo,0); self.assertGreater(hi,.04)
            labels=[t.get_text() for t in ax.texts]
            self.assertIn('+4.0%',labels); self.assertIn('-1.0%',labels)
            self.assertIn('EPSILON',fig.get_supxlabel())
            self.assertIn('5',ax.get_title(loc='left'))
        finally:
            plt.close(fig)

    def test_exports_and_cleanup(self):
        before=set(plt.get_fignums())
        with tempfile.TemporaryDirectory() as folder:
            paths=save_example(folder); self.assertEqual(len(paths),3)
            for path in paths:
                if path.suffix=='.png': self.assertEqual(path.read_bytes()[:8],b'\x89PNG\r\n\x1a\n')
                else: self.assertTrue(ElementTree.parse(path).getroot().tag.endswith('svg'))
        self.assertEqual(set(plt.get_fignums()),before)


if __name__=='__main__':
    unittest.main()
```

## 15. Common Design Failures

| Failure | Reader risk | Concrete correction |
|---|---|---|
| Title says only “Performance” | Return definition and scope remain unknown | Name the measure, window, and relevant basis |
| Percent sign added to already inconsistent data units | Magnitudes can be off by a factor of 100 | Match stored units and formatter convention |
| Unknowns shown as zeros | Missing evidence appears unchanged | Preserve/disclose missingness and mark genuine zeros separately |
| Bar origin cropped away | Relative lengths can exaggerate the comparison | Keep a meaningful common zero origin |
| Sign conveyed only by color | Meaning may disappear in another medium | Use direction, signed labels, and an additional pattern/cue |
| Legend covers a significant point | Observation is visually hidden | Reposition, simplify, or directly label |
| Too many asset labels squeezed into one chart | Text becomes unreadable | Use a table, multiple panels, or an explicitly scoped selection |
| Decorative 3D effects alter apparent length/area | Encoding becomes harder to compare | Keep the quantitative geometry direct |
| Scenario shading labeled “confidence” without a model | Adds unsupported probability meaning | Use accurate scenario language or provide a validated interval method |
| Testing only that a file exists | Wrong values or unreadable layout can pass | Combine numeric/Artist checks with visual export review |

A useful chart carries enough context to prevent an avoidable misunderstanding. More decoration, more decimals, or more panels do not automatically improve that context.

## 16. Exercises and Answer Guidance

1. **Question:** Why is a horizontal bar chart appropriate for this fixture?  
   **Guidance:** It compares one signed quantitative value per named asset from a common zero origin; it is not a time path or part-to-whole allocation.
2. **Missingness:** Why is EPSILON named outside the bars?  
   **Guidance:** Its return is unknown. An explicit omission note preserves coverage information without inventing a numeric value.
3. **Zero:** Why does GAMMA receive an open-circle marker?  
   **Guidance:** A zero-width bar alone is hard to see; the marker identifies a genuine observed zero.
4. **Ordering:** What tie rule makes the output deterministic?  
   **Guidance:** Return descending, then asset label ascending. Label/value relationships remain intact.
5. **Monochrome:** Which cues preserve the sign without color?  
   **Guidance:** Direction relative to zero, signed direct labels, and negative-bar hatching.
6. **Precision:** Does the +2.5% label establish that the original observation is accurate to one decimal percentage point?  
   **Guidance:** No. Display precision is not a measurement-quality guarantee.
7. **Export:** Why inspect the saved PNG rather than only the interactive figure?  
   **Guidance:** Export size, font rendering, margins, and format can affect the artifact the reader actually receives.
8. **Validation:** What additional work is needed before sharing a chart of real assets?  
   **Guidance:** Establish source lineage, compatible return/window conventions, data checks, and appropriate accessible context. The synthetic example does not certify those real inputs.
