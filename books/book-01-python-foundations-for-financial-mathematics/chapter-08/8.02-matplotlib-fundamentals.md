## 1. Purpose

Matplotlib turns numerical arrays into figures whose data, labels, layout, and export settings can be controlled in Python. Section 8.1 established why that control matters. This section explains the objects that make it possible, then builds a complete two-panel financial illustration.

The central habit is to keep explicit references to the figure and its plotting areas. That makes it easier to place each series correctly, test the plotted values, save the intended figure, and release it when work finishes. These habits become more valuable as a report grows beyond one chart.

## 2. Learning Objectives

After completing this section, you should be able to:

1. Distinguish Figure, Axes, Axis, and Artist objects.
2. Use `plt.subplots` and explicit Axes methods to create and configure charts.
3. Explain subplot return shapes and shared horizontal axes.
4. Add labels, legends, observation markers, reference lines, and an annotation.
5. Apply temporary style settings without leaving global defaults changed.
6. Export PNG and SVG files and close the correct figure.
7. Separate numerical validation, object-level tests, and visual inspection.

Prerequisites: Section 8.1, NumPy arrays, functions, exceptions, and basic unit testing. The financial example is a fixed-rate illustration; detailed time-value-of-money theory follows in Chapter 9.

## 3. The Objects Behind a Chart

| Object | Responsibility | Example in this section |
|---|---|---|
| `Figure` | The complete output container | `fig`, holding two panels and the overall title |
| `Axes` | A plotting area with data, labels, and its own coordinate system | `balance_ax` and `gain_ax` |
| `Axis` | Scale, ticks, and tick labels for a coordinate direction | `balance_ax.yaxis` |
| `Artist` | A drawable object | A line, annotation, legend, or text label |

An Axes is not an Axis. “Axes” is the class name for one plotting area, even when referring to a single instance. Most familiar visible objects are Artists [1].

For example, the opening-principal reference line belongs to the upper Axes. The figure-wide title belongs to the Figure. Setting a y-label on the lower Axes does not label the upper one. Keeping these relationships explicit prevents configuration from landing on an unintended panel.

## 4. pyplot and Explicit Object Methods

The conventional import is:

```python
import matplotlib.pyplot as plt
```

`pyplot` provides figure creation and an interface that can operate on the current plotting state. Explicit object methods identify the target directly:

```python
fig, ax = plt.subplots()
ax.plot([0, 1, 2], [1000, 1050, 1102.5], label="Illustrative balance")
ax.set_xlabel("Elapsed years")
ax.set_ylabel("USD")
ax.legend()
```

This snippet is introductory and is not the complete lab. Its `fig` must eventually be saved or displayed and then closed as appropriate. In the complete program, `build_figure` returns the objects and the caller handles their lifecycle.

`ax.plot` returns a list of line Artists, even when it creates only one line. Unpack the single result with a trailing comma:

```python
line, = ax.plot(x, values, marker="o")
line.set_linewidth(2)
```

Here `x` and `values` stand for already validated arrays. The unpacking also expresses the expectation that exactly one line was created. Styling can be supplied when drawing or changed through the returned Artist [1].

## 5. Subplots and Predictable Return Shapes

By default, `plt.subplots()` returns one Axes, whereas `plt.subplots(2, 1)` returns a one-dimensional array of Axes. A grid with multiple rows and columns returns a two-dimensional array. This shape reduction can surprise a helper that expects consistent indexing.

Use `squeeze=False` to retain a two-dimensional Axes array [2]:

```python
fig, axes = plt.subplots(2, 1, squeeze=False, sharex=True,
                         figsize=(8, 6), layout="constrained")
balance_ax, gain_ax = axes[:, 0]
```

The array shape is `(2, 1)`. `axes[0, 0]` is the upper panel and `axes[1, 0]` the lower panel. The array is a container of Axes references; it is not another plotting area.

`sharex=True` links the horizontal axes. That is useful because both panels use the same elapsed years. Their vertical axes stay independent: one reports the full balance and the other reports the balance less opening principal. Shared horizontal tick labels normally appear on the bottom panel, avoiding repeated text [2].

Figure size is given in inches. `layout="constrained"` requests automatic spacing for decorations. A layout engine still needs a visual check, especially after long titles, annotations, or unusually large fonts.

## 6. Financial Illustration and Numerical Contract

Assume an opening principal of USD 1,000, an illustrative constant annual rate of 5%, annual compounding, and observations at years 0 through 4. There are no subsequent deposits, withdrawals, fees, taxes, or inflation adjustments.

Define the balance and cumulative gain as:

$$B_n=P(1+r)^n,\qquad G_n=B_n-P.$$

This is the model chosen for the exercise; it is not a market forecast or a quoted product. A rate of 5% is stored as `0.05`.

| Year | Balance, USD | Cumulative gain, USD |
|---:|---:|---:|
| 0 | 1,000.00000 | 0.00000 |
| 1 | 1,050.00000 | 50.00000 |
| 2 | 1,102.50000 | 102.50000 |
| 3 | 1,157.62500 | 157.62500 |
| 4 | 1,215.50625 | 215.50625 |

The two panels show related quantities in the same currency. The lower panel does not show annual interest payments or annual percentage returns. Its final gain is USD 215.50625 accumulated over the full four years. For example, the increase from year 1 to year 2 is USD 52.50, whereas the cumulative gain at year 2 is USD 102.50.

The lab uses floating-point arrays for illustration, retains unrounded values for calculations, and formats the final annotation to cents. It does not implement a contractual cent-rounding schedule. A display of USD 1,215.51 therefore does not imply that every intermediate interest credit was rounded to cents.

The numerical helper requires:

- A real finite principal in `(0, 1e12]`, excluding Booleans.
- A real finite annual rate in `(-1, 1]`, excluding Booleans.
- A one-dimensional integer NumPy array with consecutive years starting at zero, containing 2–51 entries.

These bounds keep this teaching example small. Negative rates above -100% are supported; the title is generated from the supplied rate rather than hard-coded to 5%. Missing observations, irregular calendars, and arbitrary input coercion are outside this helper's contract. Matplotlib itself supports many inputs beyond these deliberately narrow lab requirements.

## 7. Labels, Legends, Reference Lines, and Annotations

Labels should say what the plotted numbers mean. The upper panel uses “USD” for its vertical axis and explicitly names its series “Modeled balance.” A dashed horizontal reference identifies the opening principal. The lower panel labels cumulative modeled gain and includes a zero reference.

Calling `plot(..., label="...")` assigns a label to the Artist; calling `legend()` creates the visible legend from eligible labeled Artists. Set meaningful labels before creating it.

The final-balance annotation combines two coordinate conventions:

```python
balance_ax.annotate(
    f"Final: ${balances[-1]:,.2f}",
    xy=(x[-1], balances[-1]),
    xytext=(-12, -28),
    textcoords="offset points",
    ha="right",
    arrowprops={"arrowstyle": "->", "color": "gray"},
)
```

The arrow's target is in data coordinates. The text is offset from that point in typographic points. This avoids interpreting the text offset as a change in dollars or elapsed years. Placement is chosen for the demonstration fixture; other rates and long schedules may require moving the text to avoid overlap.

Markers identify annual observations. The segments between them are visual guides. The program does not calculate intermediate monthly balances. Chapter 8.3 examines line charts in more detail.

## 8. Temporary Styling and Figure Ownership

`rcParams` holds Matplotlib configuration defaults. A global edit can affect later plots in the same Python process. `plt.rc_context({...})` temporarily applies selected settings and restores the configuration on exit, with backend handling being a documented exception [3].

The lab creates its text, lines, and legends inside the context. Those existing Artists retain their configured properties after the context ends. It does not claim complete independence from all possible user styles: unspecified defaults can still influence output.

The lab's ownership rule is simple:

1. `build_figure` creates and returns an open Figure.
2. `save_outputs` saves that specific Figure and leaves it open.
3. The caller closes it in a `finally` block, including when saving raises an error.

`plt.close(fig)` unregisters that Figure from pyplot [6]. It does not delete saved files, and Python references held elsewhere still exist. Closing the specific Figure avoids disturbing another report's open figures. Keeping unused figures registered can consume memory during repeated report generation.

## 9. Backends, Display, and Export

A backend supports rendering and, for interactive use, displaying plots [4]. This batch lab selects `Agg` before importing pyplot. It can write files without a desktop window. This is appropriate for automated execution and does not open a graphical chart.

For an interactive script, use an installed interactive backend suitable for the environment and call `plt.show()` while the figure is still open. Notebook display behavior depends on the notebook backend. Do not expect the unchanged Agg-based program to open a window. Backend choice belongs near program setup, rather than inside a reusable function that might unexpectedly change a caller's session.

`fig.savefig(...)` saves the referenced Figure. The lab writes both a raster PNG and a vector SVG [5]:

```python
fig.savefig("chart.png", dpi=150, facecolor="white")
fig.savefig("chart.svg", facecolor="white")
```

At 8 by 6 inches and 150 dpi, the ordinary uncropped PNG is 1,200 by 900 pixels. DPI controls raster resolution; the plotted lines in the SVG are vector elements. SVG output can still contain raster components when such Artists are used. No external LaTeX installation is required by this example.

The filename extension selects the format when `format` is omitted. If `format` is supplied explicitly, keep it consistent with the filename. The code creates its output directory before saving; `savefig` does not create missing parent directories. Re-running the demonstration replaces its two output files. Export is not an atomic two-file transaction: if the second save fails, the first file may already exist.

## 10. Complete Lab — `matplotlib_fundamentals.py`

Create a directory named `visualization_lab_82` and save the following file inside it. It has no dependency on the Section 8.1 lab.

```python
"""Matplotlib objects and export using an illustrative annual balance schedule."""
from pathlib import Path
from numbers import Real

import matplotlib
matplotlib.use("Agg")
import matplotlib.pyplot as plt
import numpy as np


def balance_schedule(principal, annual_rate, years):
    """Return copied year offsets, balances, and gains for a fixed-rate example."""
    for name, value in (("principal", principal), ("annual_rate", annual_rate)):
        if isinstance(value, (bool, np.bool_)) or not isinstance(value, Real):
            raise ValueError(f"{name} must be a real scalar, not a Boolean")
    if not 0 < principal <= 1e12 or not np.isfinite(principal):
        raise ValueError("principal must be finite and in (0, 1e12]")
    if not -1 < annual_rate <= 1 or not np.isfinite(annual_rate):
        raise ValueError("annual_rate must be finite and in (-1, 1]")
    if (not isinstance(years, np.ndarray) or years.ndim != 1
            or years.dtype.kind not in "iu" or not 2 <= years.size <= 51):
        raise ValueError("years must be a 1-D integer array with 2..51 entries")
    if not np.array_equal(years, np.arange(years.size)):
        raise ValueError("years must be consecutive offsets beginning at zero")
    x = years.astype(np.int64, copy=True)
    balances = float(principal) * (1.0 + float(annual_rate)) ** x
    return x, balances, balances - float(principal)


def build_figure(principal, annual_rate, years):
    x, balances, gains = balance_schedule(principal, annual_rate, years)
    style = {"font.size": 10, "axes.titlesize": 11,
             "axes.labelsize": 10, "figure.facecolor": "white"}
    with plt.rc_context(style):
        fig, axes = plt.subplots(2, 1, squeeze=False, sharex=True,
                                 figsize=(8, 6), layout="constrained")
        balance_ax, gain_ax = axes[:, 0]
        balance_line, = balance_ax.plot(x, balances, label="Modeled balance",
                                        color="#0072B2", marker="o")
        balance_line.set_linewidth(2)
        balance_ax.axhline(principal, color="gray", linestyle="--",
                           label="Opening principal")
        balance_ax.set(title="Balance at annual observation points", ylabel="USD")
        balance_ax.legend(loc="upper left")
        balance_ax.annotate(f"Final: ${balances[-1]:,.2f}",
                            xy=(x[-1], balances[-1]), xytext=(-12, -28),
                            textcoords="offset points", ha="right",
                            arrowprops={"arrowstyle": "->", "color": "gray"})
        gain_ax.plot(x, gains, label="Cumulative modeled gain",
                     color="#D55E00", marker="s", linestyle="--")
        gain_ax.axhline(0, color="gray", linewidth=0.8)
        gain_ax.set(title="Balance minus opening principal", ylabel="USD",
                    xlabel="Elapsed years (annual compounding)")
        gain_ax.legend(loc="upper left")
        # At most six ticks, even for a longer permitted schedule.
        tick_positions = np.unique(np.linspace(0, len(x) - 1,
                                               min(6, len(x)), dtype=int))
        gain_ax.set_xticks(x[tick_positions])
        for ax in axes.flat:
            ax.grid(alpha=0.2)
        fig.suptitle(f"Illustrative fixed rate: {annual_rate:.1%} per year")
        fig.supxlabel("No deposits, withdrawals, fees, taxes, or inflation adjustment",
                      fontsize=9)
    return fig, axes


def save_outputs(fig, folder):
    """Save the supplied Figure; caller retains ownership and must close it."""
    output = Path(folder)
    output.mkdir(parents=True, exist_ok=True)
    png = output / "matplotlib_fundamentals.png"
    svg = output / "matplotlib_fundamentals.svg"
    fig.savefig(png, dpi=150, facecolor="white")
    fig.savefig(svg, facecolor="white")
    return png, svg


def main():
    years = np.arange(5, dtype=np.int64)
    _, balances, gains = balance_schedule(1000.0, 0.05, years)
    print(f"Final balance: USD {balances[-1]:.2f}")
    print(f"Cumulative gain: USD {gains[-1]:.2f}")
    fig, axes = build_figure(1000.0, 0.05, years)
    try:
        paths = save_outputs(fig, "output")
        print(f"Axes array shape: {axes.shape}")
        for path in paths:
            print(f"Saved {path.as_posix()}")
    finally:
        plt.close(fig)


if __name__ == "__main__":
    main()
```

`balance_schedule` computes arrays without creating a figure. `build_figure` validates and transforms first, then draws. `save_outputs` accepts the Figure explicitly. This separation lets tests compare known financial values without relying on rendered pixels, then inspect the presentation independently.

## 11. Reference Tests — `test_matplotlib_fundamentals.py`

Save this file beside the implementation:

```python
import tempfile
import unittest
from xml.etree import ElementTree

import numpy as np
from numpy.testing import assert_allclose, assert_array_equal

from matplotlib_fundamentals import (balance_schedule, build_figure,
                                     save_outputs, plt)


class FundamentalsTests(unittest.TestCase):
    def setUp(self):
        self.years = np.arange(5, dtype=np.int64)

    def test_known_schedule_and_recurrence(self):
        x, b, g = balance_schedule(1000, 0.05, self.years)
        assert_allclose(b, [1000, 1050, 1102.5, 1157.625, 1215.50625])
        assert_allclose(b[1:], b[:-1] * 1.05)
        assert_allclose(g, b - 1000)
        assert_array_equal(x, self.years)

    def test_zero_and_negative_rates(self):
        _, b, g = balance_schedule(1000, 0, self.years)
        assert_array_equal(b, [1000]*5); assert_array_equal(g, [0]*5)
        _, b, _ = balance_schedule(1000, -0.1, self.years)
        self.assertAlmostEqual(b[-1], 656.1)

    def test_invalid_scalar_contract(self):
        for bad in [True, "1000", complex(1, 1), np.nan, np.inf, 0, -1, 1e13]:
            with self.subTest(principal=bad), self.assertRaises(ValueError):
                balance_schedule(bad, 0.05, self.years)
        for bad in [False, "0.05", np.nan, np.inf, -1, 1.01]:
            with self.subTest(rate=bad), self.assertRaises(ValueError):
                balance_schedule(1000, bad, self.years)

    def test_invalid_year_grid(self):
        for bad in [[0, 1], np.array([0]), np.array([0., 1.]),
                    np.array([0, 2]), np.array([1, 2]), np.array([0, 1, 1]),
                    np.arange(52), self.years.reshape(1, -1)]:
            with self.subTest(years=str(bad)), self.assertRaises(ValueError):
                balance_schedule(1000, 0.05, bad)

    def test_source_and_outputs_independent(self):
        original = self.years.copy()
        x, b, g = balance_schedule(1000, 0.05, self.years)
        x[0] = 99; g[0] = 99
        assert_array_equal(self.years, original)
        self.assertEqual(b[0], 1000)

    def test_figure_objects_and_data(self):
        fig, axes = build_figure(1000, 0.05, self.years)
        try:
            self.assertEqual(axes.shape, (2, 1))
            self.assertIs(axes[0, 0].figure, fig)
            self.assertTrue(axes[0, 0].get_shared_x_axes().joined(
                axes[0, 0], axes[1, 0]))
            assert_allclose(axes[0, 0].lines[0].get_ydata(),
                            [1000, 1050, 1102.5, 1157.625, 1215.50625])
            self.assertEqual(axes[1, 0].get_ylabel(), "USD")
            self.assertEqual(axes[0, 0].lines[0].get_label(), "Modeled balance")
            self.assertEqual(axes[0, 0].lines[0].get_linewidth(), 2)
        finally:
            plt.close(fig)

    def test_style_restored(self):
        before = plt.rcParams["font.size"]
        with plt.rc_context({"font.size": 17}):
            fig, axes = build_figure(1000, 0.05, self.years)
            try:
                self.assertEqual(plt.rcParams["font.size"], 17)
                self.assertEqual(axes[0, 0].get_legend().get_texts()[0].get_fontsize(), 10)
            finally:
                plt.close(fig)
        self.assertEqual(plt.rcParams["font.size"], before)

    def test_exports_and_explicit_close(self):
        initial = set(plt.get_fignums())
        fig, _ = build_figure(1000, 0.05, self.years)
        try:
            with tempfile.TemporaryDirectory() as folder:
                png, svg = save_outputs(fig, folder)
                self.assertEqual(png.read_bytes()[:8], b"\x89PNG\r\n\x1a\n")
                self.assertTrue(ElementTree.parse(svg).getroot().tag.endswith("svg"))
                self.assertIn(fig.number, plt.get_fignums())
        finally:
            plt.close(fig)
        self.assertEqual(set(plt.get_fignums()), initial)


if __name__ == "__main__":
    unittest.main()
```

The eight methods test known values and the annual recurrence, zero and negative rates, scalar rejection rules, year-grid rejection rules, independent outputs, the plotted object/data relationships, restoration of temporary style settings, and file export with explicit cleanup.

The SVG test parses XML and checks the root element. The PNG test checks its format signature. Neither is a visual-layout assessment. Object-level checks establish what values were handed to the lines; visual inspection establishes whether the exported labels, annotation, and panels remain understandable. Byte-identical image comparisons are deliberately avoided because rendering details and SVG metadata can vary between runs and environments.

## 13. Common Errors and Corrections

| Symptom | Likely cause | Correction |
|---|---|---|
| `Axes` is not subscriptable | A single Axes was treated as an array | Use `ax` directly or request `squeeze=False` |
| NumPy array has no `plot` method | An Axes array was treated as one Axes | Select a panel, such as `axes[0, 0]` |
| A line variable has no `set_linewidth` | The list from `plot` was retained | Unpack `line, = ax.plot(...)` |
| Legend is empty | Lines were unlabeled when legend was created | Assign labels, then create the legend |
| Plot opens no window | Agg is selected | Use saved files, or choose an appropriate interactive setup |
| Saved file belongs to another plot | Current-state saving targeted an unintended figure | Call `fig.savefig` on the intended reference |
| Output path fails | Parent directory does not exist or cannot be written | Create the directory and inspect the raised error |
| Memory grows across repeated reports | Figures remain registered in pyplot | Close the owned figure after saving |
| Display says 5 but data represent 500% | Rate units were confused | Store 5% as `0.05`; format explicitly |
| Different charts inherit unexpected styles | Global configuration was changed | Use a local context and explicit properties |

A valid file is not proof of correct finance. Reconcile the final numerical balance before interpreting the chart. Equally, correct arrays do not establish good layout; inspect the export at the intended reading size.

## 14. Exercises and Answer Guidance

1. **Object identification:** Which object owns the entire two-panel output, and which owns the upper y-label?  
   **Guidance:** The Figure owns the full output; the upper Axes owns its y-label.
2. **Axis versus Axes:** What does `balance_ax.yaxis` represent?  
   **Guidance:** The vertical Axis, including tick/scale machinery, within the balance Axes.
3. **Subplot indexing:** With `squeeze=False`, what shape does `plt.subplots(1, 1)` return for the Axes container?  
   **Guidance:** `(1, 1)`; select its sole Axes with `[0, 0]`.
4. **Line return value:** Why does `line = ax.plot(...)` differ from `line, = ax.plot(...)`?  
   **Guidance:** The former keeps a list; the latter extracts its one Line2D element and expects exactly one result.
5. **Financial meaning:** Is the year-2 lower-panel value USD 52.50 or USD 102.50?  
   **Guidance:** USD 102.50, because the panel shows cumulative gain from opening principal.
6. **Raster sizing:** What ordinary uncropped PNG dimensions result from a 10 by 4 inch figure at 200 dpi?  
   **Guidance:** 2,000 by 800 pixels. Cropping or other export settings can change the final dimensions.
7. **Lifecycle:** If SVG saving fails after PNG succeeds, should the caller still close the figure?  
   **Guidance:** Yes; `finally` closes it. The successful PNG may remain, so assess outputs separately.
8. **Style scope:** Change the surrounding font-size default, build the figure, and inspect the restored default. What does this establish?  
   **Guidance:** The context restored that setting. It does not prove that every possible global style or rendering dependency is isolated.
