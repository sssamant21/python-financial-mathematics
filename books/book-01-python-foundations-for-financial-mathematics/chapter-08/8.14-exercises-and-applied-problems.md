## Working assumptions and submission

All data are synthetic. Monetary figures use illustrative currency units unless USD is specified. Return inputs are fractions; .01 means 1%. Do not fill unknown observations, infer trading calendars, add financing costs, or interpret scenarios as forecasts. Use floating-point tolerances for numerical comparisons. Time-series labels identify observations or intervals explicitly; row positions alone are not identifiers.

For each problem submit the calculation or small Python implementation, the requested checks, and a short interpretation. For plotting problems include a labeled figure and inspect it at its intended display size. State missing-data coverage, denominators, rate conventions, and units wherever relevant. The companion automates selected fixed-fixture checks; your visual and written work remains part of the exercise.

## Problem 1 — Same endpoint, different paths

Use columns A = [100, 110, 120] and B = [200, 160, 240] at three successive observations. Index each to 100 at the first observation and calculate endpoint returns. Explain what an endpoint comparison hides.

## Problem 2 — Figure, Axes, Axis, and Artist

Create two vertically stacked panels with squeeze=False. Plot [100, 105] against [0, 1] in the first panel. Identify the Figure, the first Axes, its y Axis, and the returned line Artist. Verify their ownership.

## Problem 3 — Coordinate order and elapsed spacing

Plot values [100, 101, 103] at elapsed days [0, 1, 4]. Check spacing and assess the alternative order [0, 4, 1]. Explain why category positions would change the temporal meaning.

## Problem 4 — A missing point and a dropped point

Use x = [0, 1, 2, 3] and y = [100, 101, NaN, 104]. Compare retaining the unknown observation with dropping it before plotting. Inspect each line data array and explain the connecting segment.

## Problem 5 — Effective position states

A position becomes 10 units at day 0, 12 at day 1, and 8 at day 3. Use a post-step line. Identify the held state on [0, 1) and [1, 3), and inspect the initial path vertices.

## Problem 6 — Repeated local clock hours

Convert 2026-11-01T05:30:00Z and 2026-11-01T06:30:00Z to plotting coordinates. Format in America/New_York with clock time, timezone abbreviation, and UTC offset. Check actual elapsed time.

## Problem 7 — Expected rows and expected cells

Use an expected daily UTC grid for January 1–3, 2026, with assets A and B. Supply January 1 values (100, 200) and January 3 values (102, NaN); supply no January 2 row. Report row presence and observed-cell counts without filling.

## Problem 8 — Simple, log, and compounded returns

For prices [100, 110, 99], calculate adjacent simple returns, their sum, compounded return, and the return recovered from summed log returns. Explain which quantity describes endpoint growth.

## Problem 9 — Strict linkage and an observed zero

For [100, 110, 99, NaN, 108, 108], compute adjacent returns and a strict cumulative product anchored at the first price. Preserve unknown intervals. Compare the final endpoint ratio with the strict path.

## Problem 10 — Histogram edges and exact zeros

Use returns [−.08, −.04, −.02, −.01, 0, 0, .01, .02, .03, .04, .10] and edges [−.10, −.02, 0, .02, .10]. Count observations in each bin. Separately bin the five edge values themselves. State the boundary policy.

## Problem 11 — Density area and unit changes

Using Exercise 10, calculate sample shares and density heights for the unequal bin widths. Verify total area. Convert the horizontal unit from fractional return to percentage points and derive the corresponding density scale.

## Problem 12 — Scatter alignment by interval label

Let x on January 1–4 be [.01, .02, 0, −.01]. Let y values [−.02, .015, NaN, 0] carry date labels January [4, 1, 2, 3], respectively. Align by label, then apply one joint complete-pair mask. Report dates, pairs, and coverage.

## Problem 13 — Correlation, slope, and equality

Set x = [−.02, 0, .01, .03] and y = 2x + .01. Calculate correlation and explain why it does not establish y = x. Examine whether correlation is defined when a coordinate is constant.

## Problem 14 — Signed weights and absolute composition

Use signed position values [600, 400, −200, 200], with the last position cash. Compute net value, total absolute value, signed weights, absolute shares, and risky gross exposure divided by net value. Explain each denominator.

## Problem 15 — Payoff, profit, and contract scaling

At terminal prices [0, 96, 100, 106, 120], calculate long call and put payoffs for strike 100, call premium 6, put premium 4, and multiplier 100. Subtract premiums without financing or fees. Check break-even points and the payoff difference identity.

## Problem 16 — Equal numeric rates and equivalent rates

Invest 1,000 for 20 years at an effective annual rate of 5%. Compare monthly compounding using a nominal annual 5%, then derive a nominal monthly-compounded annual rate and continuous rate equivalent to the 5% effective annual rate.

## Problem 17 — Scenario orientation and a reference case

For F = 1,000(1+r)^n, use rate rows [.01, .03, .05, .07, .09] and horizon columns [5, 10, 15, 20]. Build the grid with indexing="ij" and verify an interior cell. Compare the joint case (7%, 12 years) with reference (5%, 10 years).

## Problem 18 — Zero, omission, units, and sign cues

Use returns A=.025, B=−.01, C=0, D=.04, E=NaN. Sort known values descending for horizontal bars, list omitted labels, format fractional returns as percentages, and add a zero reference plus a non-color cue for the negative value.

## Problem 19 — Export and resource checks

Plot balances [100, 105, 110.25] at years [0, 1, 2] with units. Save temporary PNG and SVG exports, inspect the line data, check PNG signature and SVG parsing, and close the Figure. Separate these checks from visual inspection.

## Problem 20 — Dashboard coverage and evidence

Create a tiny long-form CSV with A=100,110 and B=200,202,204 on January 1–3 UTC, leaving A absent on January 3. Align to the three-day, two-asset grid. Count price cells and jointly complete adjacent-return pairs; preserve A’s unknown strict final return as JSON null. Hash exact CSV bytes and test a newline change. Then rerun the complete Section 8.13 project acceptance suite as a separate integration task.
