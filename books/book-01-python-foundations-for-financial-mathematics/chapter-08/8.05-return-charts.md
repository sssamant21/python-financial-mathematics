## 1. Purpose

A price chart answers where supplied prices stand. A return chart shows changes relative to a starting value or a preceding observation. Those changes can be displayed interval by interval or linked across a reporting window, but the two views have different meanings and different completeness requirements.

This section builds a standalone chart with three aligned areas: adjacent-period return bars, a narrow diagnostic strip for unknown intervals, and a strict cumulative linked path. The example distinguishes a genuine zero return from missing evidence and distinguishes an observable endpoint price change from a complete sequence of adjacent returns.

Section 7.15 introduced price-to-return transformation. Here the emphasis is how to present those calculations without changing their meaning. Section 8.6 turns to return distributions; the present charts retain time order.

## 2. Learning Objectives

After completing this section, you should be able to:

1. Distinguish price levels, simple returns, log returns, and cumulative linked returns.
2. Label each interval return at a declared endpoint and state its duration.
3. Format decimal fractions as percentages without double scaling.
4. Use bars and a zero reference for signed interval changes.
5. Preserve unknown returns and identify observed zero returns explicitly.
6. Apply a strict no-skipping, no-restart linking policy.
7. Reconcile plotted data against known calculations and an independent complete-path check.

Prerequisites: Sections 7.15 and 8.1–8.4, array calculations, missing-value policies, and unit testing.

## 3. Define the Return Before Drawing It

For positive prices observed at neighboring grid instants, define:

$$g_i=\frac{P_i}{P_{i-1}},\qquad r_i=g_i-1,$$

where $g_i$ is the gross price ratio and $r_i$ the simple price return. Define the log price return as:

$$\ell_i=\ln(P_i)-\ln(P_{i-1})=\ln(g_i).$$

The lab stores both forms but plots simple returns. A simple return of `0.10` is displayed as 10%; its corresponding log return is approximately `0.09531018`. The values have the same sign here but are different quantities. Label a log-return plot explicitly if using that convention.

All calculations are price-only. The synthetic quotes omit distributions, fees, taxes, currency conversion, and corporate-action adjustments. A price-return chart is not automatically a total-return chart. Account balances affected by external deposits or withdrawals also cannot be treated as an investment-return series merely by taking adjacent ratios.

The helper requires strictly positive observed prices. That domain supports the ratio and logarithm definitions used here; it does not cover instruments whose quoted price conventions allow zero or negative values.

## 4. Link Returns by Multiplication

For a complete sequence from the baseline through observation $n$, cumulative simple price return is:

$$C_n=\prod_{i=1}^{n}g_i-1.$$

For complete compatible observations, cancellation gives:

$$C_n=\frac{P_n}{P_0}-1=\exp\left(\sum_{i=1}^{n}\ell_i\right)-1.$$

A cumulative sum of simple returns is generally a different quantity. For prices 100, 110, and 99, the two adjacent simple returns are +10% and -10%:

$$(1+0.10)(1-0.10)-1=-0.01=-1\%.$$

Their arithmetic sum is zero, but the final price is 1% below the starting price. A 10% decline from 110 loses 11 price units, whereas the preceding 10% gain from 100 added 10 units. Equal signed percentages applied to different bases need not cancel.

The code uses NumPy's cumulative product for the gross ratios [3]. It calculates log returns with NumPy's natural logarithm [4]. These functions implement arithmetic operations; the financial definitions and completeness policy remain the application's responsibility.

## 5. Worked Fixture and Reporting Grid

Use six synthetic USD price observations on an explicitly supplied 24-hour grid:

| UTC observation date | Price | Adjacent simple return | Strict linked return from Jan 1 |
|---|---:|---:|---:|
| 2026-01-01 | 100 | Undefined: no prior point | 0% baseline |
| 2026-01-02 | 110 | +10% | +10% |
| 2026-01-03 | 99 | -10% | -1% |
| 2026-01-04 | Missing | Unknown | Unknown |
| 2026-01-05 | 108 | Unknown | Unknown |
| 2026-01-06 | 108 | 0% | Unknown |

The grid uses UTC midnight observations and exact elapsed durations of 24 hours. It is a synthetic calendar-day schedule, not a trading-session calendar. Local-midnight grids across daylight-saving transitions can have different elapsed durations, so the helper's duration contract should not be transferred to them without review.

Each interval return is labeled at its ending instant. The Jan 3 bar therefore describes Jan 2→Jan 3. The Jan 6 marker describes Jan 5→Jan 6. The first price has no preceding interval in this dataset, so its adjacent return is undefined. By contrast, the cumulative baseline is deliberately defined as zero.

These are distinct uses of missing and zero values: the first adjacent return is unavailable by construction; an interior gap blocks calculations; an observed unchanged price pair gives a valid zero return.

## 6. Unknown Is Not Zero

The missing Jan 4 price prevents calculation of Jan 3→Jan 4 and Jan 4→Jan 5. Retain both unknown returns as NaN. The Jan 5 and Jan 6 prices are supplied and equal, so Jan 5→Jan 6 has an independently calculable zero return.

A zero-height bar can be difficult to see. The chart therefore adds an open circle on the zero line for an observed zero. Unknown intervals have no return bars; black crosses appear at their endpoint dates in a separate, unscaled diagnostic strip. Their vertical positions in that strip are layout positions, not financial magnitudes.

The strip excludes the first observation because it has no preceding in-sample interval. There are five possible adjacent intervals after the baseline, of which three are known. The first undefined value must not be counted as a failed expected interval.

Do not forward-fill the missing price, substitute zero for the missing returns, or delete the missing grid point to make the picture continuous. Removing Jan 4 would create a new Jan 3→Jan 5 interval. Its two-day price change, `108 / 99 - 1`, is about 9.09%; that cannot be presented as either of the two unknown one-day returns.

## 7. A Strict Linked Path and a Separate Endpoint Ratio

The lab adopts a conservative release policy: a linked path is displayed only while every required adjacent ratio from the original baseline is known. Once a required ratio is unknown, the linked series remains unknown for the rest of the window. It does not skip a missing factor and does not restart from a later baseline.

The output is therefore `[0, 0.10, -0.01, NaN, NaN, NaN]` within numerical tolerance. A later valid zero interval does not repair the missing earlier intervals.

The first and final prices are both observed, so the endpoint-only price change is separately calculable:

$$\frac{108}{100}-1=8\%.$$

This ratio is numerically meaningful for its two endpoints. It does not recover the missing adjacent returns or supply a complete observed path. The strict linked series is intentionally withheld beyond the gap even though endpoint ratios could be computed there. That is a reporting policy, not a claim that endpoint price changes are mathematically undefined whenever an intermediate point is absent.

The demonstration prints the +8% endpoint-only result but does not splice it into the cumulative line. If a report includes both quantities, label them as different products with different coverage requirements. A benchmark comparison likewise needs consistent baselines, interval definitions, adjustment conventions, and coverage policies for every series.

## 8. Chart Construction and Percentage Units

The upper panel uses bars centered at interval-ending dates. Their width is a presentation choice, not the interval's elapsed duration. With Matplotlib date numbers, the width `0.55` represents 0.55 days [1]. Bars start at zero and extend upward for positive returns and downward for negative returns.

Color reinforces sign, but position relative to zero remains the primary encoding. Blue represents a nonnegative known value; orange represents a negative one. The observed-zero open circle remains visible even though its bar has no height.

Store returns as decimals throughout and apply:

```python
ax.yaxis.set_major_formatter(PercentFormatter(xmax=1.0))
```

With `xmax=1.0`, the value 1 corresponds to 100% [2]. A stored `0.10` becomes a displayed 10%. Multiplying the data by 100 and applying this same formatter would display 1,000%, which is a unit error. If plotting already-scaled percentage values, use a matching formatter convention instead.

The lower panel draws the strict linked values with observation markers and NaNs. The baseline point is zero. Its line ends after Jan 3, while the horizontal date axis continues through the full reporting window. That retained window makes the missing continuation visible.

The code uses two independent percentage formatters, one per financial axis. The diagnostic strip has no percentage scale. All three areas share the same date positions.

## 9. Interpretation Limits

Neither the bars nor the cumulative path are annualized. Scaling a short sample to an annual figure requires a defined convention and assumptions. Equally spaced 24-hour intervals do not establish a trading-year frequency, and three known intervals cannot support a reliable volatility or distribution claim.

A log-return chart should distinguish interval log changes from cumulative log changes and from cumulative simple returns. Under complete data, cumulative log changes can be transformed back with the exponential identity above. Simply relabeling a cumulative log series as simple percentage return would be incorrect.

Drawdown, volatility, benchmark excess returns, and risk-adjusted performance require further definitions. They are not additional interpretations of the same y-axis. Chapter 13 develops investment-performance mathematics in more detail.

The chart performs no smoothing, winsorization, outlier deletion, or return imputation. A large bar may be a real move, a corporate-action issue, or a data error; its appearance alone does not decide which. Reconcile it with the supplied data and source conventions.

### `return_charts.py`

```python
"""Adjacent price returns and a strict linked path, with unknowns preserved."""
from datetime import timezone
from pathlib import Path
import matplotlib
matplotlib.use('Agg')
import matplotlib.pyplot as plt
import matplotlib.dates as mdates
from matplotlib.ticker import PercentFormatter
import numpy as np
import pandas as pd


def fixture():
    dates = pd.date_range('2026-01-01T00:00:00Z', periods=6, freq='D')
    return pd.Series([100., 110., 99., np.nan, 108., 108.],
                     index=dates, name='DEMO')


def calculate(prices):
    if (not isinstance(prices, pd.Series) or prices.dtype != np.dtype('float64')
            or not 2 <= len(prices) <= 31):
        raise ValueError('prices must be a float64 Series with 2..31 points')
    index = prices.index
    if (not isinstance(index, pd.DatetimeIndex) or index.tz is None
            or index.hasnans or not index.is_unique or not index.is_monotonic_increasing):
        raise ValueError('index must contain sorted, unique, aware instants')
    index = index.tz_convert('UTC')
    if (index[0].year < 2000 or index[-1].year > 2100
            or not (index[1:] - index[:-1] == pd.Timedelta(days=1)).all()):
        raise ValueError('supply consecutive 24-hour grid instants in 2000..2100')
    p = prices.to_numpy(copy=True)
    finite = p[np.isfinite(p)]
    if (np.isinf(p).any() or (finite < 1e-6).any() or (finite > 1e6).any()
            or not np.isfinite(p[0])):
        raise ValueError('observed prices must be in [1e-6, 1e6]; baseline required')
    gross = p[1:] / p[:-1]
    simple = np.r_[np.nan, gross - 1.0]
    log_returns = np.r_[np.nan, np.log(p[1:]) - np.log(p[:-1])]
    # Ordinary cumprod propagates NaN: never skip unknown intervals or restart.
    linked = np.r_[0.0, np.cumprod(gross) - 1.0]
    result = pd.DataFrame({'price': p, 'simple': simple, 'log': log_returns,
                           'linked': linked}, index=index.copy())
    endpoint = p[-1] / p[0] - 1.0 if np.isfinite(p[-1]) else np.nan
    return result, float(endpoint)


def build_figure(prices):
    data, endpoint = calculate(prices)
    x = mdates.date2num(data.index.to_pydatetime())
    r = data['simple'].to_numpy()
    known = np.isfinite(r[1:]); interval_x = x[1:]; interval_r = r[1:]
    fig, axes = plt.subplots(3, 1, figsize=(9, 8), sharex=True,
                             layout='constrained', height_ratios=[3, 0.6, 3])
    colors = np.where(interval_r[known] >= 0, '#0072B2', '#D55E00')
    axes[0].bar(interval_x[known], interval_r[known], width=0.55,
                color=colors, label='Known adjacent price return')
    zero = known & (interval_r == 0)
    axes[0].plot(interval_x[zero], interval_r[zero], linestyle='none', marker='o',
                 markerfacecolor='white', markeredgecolor='black', label='Observed zero return')
    axes[1].plot(interval_x[~known], np.full((~known).sum(), 0.5),
                 linestyle='none', marker='x', color='black', markersize=9)
    axes[1].set(ylim=(0, 1), yticks=[], ylabel='Unknown\nintervals')
    axes[1].tick_params(axis='x', labelbottom=False)
    axes[0].set(title='Adjacent 24-hour simple price returns | marked at interval end',
                ylabel='Simple price return')
    axes[0].legend(loc='upper right', fontsize=8)
    axes[2].plot(x, data['linked'].to_numpy(), marker='o', color='#0072B2',
                 label='Linked price return; stops at first unknown interval')
    axes[2].set(title='Strict linked path from the common baseline | no restart',
                ylabel='Cumulative price return', xlabel='UTC observation date (2026 in demo)')
    axes[2].legend(loc='upper right', fontsize=8)
    for ax in (axes[0], axes[2]):
        ax.axhline(0, color='gray', linewidth=0.8)
        ax.yaxis.set_major_formatter(PercentFormatter(xmax=1.0))
        ax.grid(axis='y', alpha=0.2)
    ticks = np.unique(np.linspace(0, len(x)-1, min(7, len(x)), dtype=int))
    axes[2].set_xticks(x[ticks])
    axes[2].xaxis.set_major_formatter(mdates.DateFormatter('%b %d', tz=timezone.utc))
    fig.suptitle('Synthetic USD prices | decimal returns formatted as percentages')
    fig.supxlabel('Unknown is not zero. Baseline linked value is 0; baseline interval return is undefined.',
                  fontsize=9)
    return fig, axes


def main():
    prices = fixture(); data, endpoint = calculate(prices)
    print(f'Known adjacent intervals: {data.simple.iloc[1:].notna().sum()}/5')
    print(f'Endpoint-only price change: {endpoint:.2%}')
    print(f'Last finite linked value: {data.linked.dropna().iloc[-1]:.2%}')
    print(f'Final linked value unknown: {bool(pd.isna(data.linked.iloc[-1]))}')
    fig, _ = build_figure(prices)
    try:
        Path('output').mkdir(exist_ok=True)
        fig.savefig('output/return_charts.png', dpi=150)
    finally:
        plt.close(fig)
    print('Saved output/return_charts.png')


if __name__ == '__main__':
    main()
```

The linked path uses the original gross ratios rather than rebuilding them by adding one to already-subtracted simple returns. Ordinary `cumprod` propagates a NaN through subsequent cumulative products. The calculation deliberately avoids skip-missing cumulative methods and avoids restarting a later segment.

The caller owns the returned Figure, saves it, and closes it in `finally`. The Agg backend writes a PNG without requiring a desktop window. Re-running the demonstration replaces its output file.

## 11. Reference Tests

### `test_return_charts.py`

```python
import tempfile
import unittest
from pathlib import Path
import numpy as np
import pandas as pd
from numpy.testing import assert_allclose, assert_array_equal
from pandas.testing import assert_series_equal
from return_charts import fixture, calculate, build_figure, plt


class ReturnChartTests(unittest.TestCase):
    def test_known_loss_recovery_and_compounding(self):
        p = fixture().iloc[:3]; data, endpoint = calculate(p)
        assert_allclose(data.simple.iloc[1:], [0.1, -0.1])
        assert_allclose(data.linked, [0, 0.1, -0.01], atol=1e-14)
        self.assertAlmostEqual(endpoint, -0.01)
        self.assertAlmostEqual(np.expm1(data.log.iloc[1:].sum()), endpoint)
        self.assertAlmostEqual(data.simple.iloc[1:].sum(), 0)

    def test_missing_intervals_zero_and_strict_path(self):
        data, endpoint = calculate(fixture())
        assert_array_equal(data.simple.notna(), [False, True, True, False, False, True])
        self.assertEqual(data.simple.iloc[-1], 0)
        self.assertTrue(data.linked.iloc[3:].isna().all())
        self.assertAlmostEqual(endpoint, 0.08)
        self.assertTrue(np.isnan(data.simple.iloc[0]))
        self.assertEqual(data.linked.iloc[0], 0)

    def test_complete_path_matches_direct_prices(self):
        p = fixture().copy(); p.iloc[3] = 105
        data, endpoint = calculate(p)
        assert_allclose(data.linked, p.to_numpy()/p.iloc[0]-1, atol=1e-14)
        assert_allclose(np.expm1(data.log.iloc[1:].cumsum()), data.linked.iloc[1:], atol=1e-14)
        self.assertAlmostEqual(data.linked.iloc[-1], endpoint)

    def test_invalid_prices_and_schema(self):
        p = fixture()
        for value in [0, -1, np.inf, 1e7]:
            bad = p.copy(); bad.iloc[1] = value
            with self.assertRaises(ValueError): calculate(bad)
        bad = p.copy(); bad.iloc[0] = np.nan
        with self.assertRaises(ValueError): calculate(bad)
        with self.assertRaises(ValueError): calculate(p.astype(str))
        with self.assertRaises(ValueError): calculate(p.to_frame())

    def test_invalid_grid(self):
        p = fixture()
        for index in [p.index.tz_localize(None), p.index[::-1],
                      p.index.insert(1, p.index[1]).delete(-1),
                      pd.date_range('2026-01-01', periods=6, freq='2D', tz='UTC')]:
            bad = p.copy(); bad.index = index
            with self.assertRaises(ValueError): calculate(bad)

    def test_source_preservation_and_zone_equivalence(self):
        p = fixture(); original = p.copy(deep=True)
        local = p.copy(); local.index = local.index.tz_convert('America/New_York')
        a, _ = calculate(p); b, _ = calculate(local)
        assert_allclose(a.to_numpy(), b.to_numpy(), equal_nan=True)
        a.iloc[0, 0] = 999
        assert_series_equal(p, original)

    def test_artists_percentage_and_gap_markers(self):
        p = fixture(); fig, axes = build_figure(p)
        try:
            assert_allclose([bar.get_height() for bar in axes[0].patches], [0.1, -0.1, 0])
            self.assertIn('10', axes[0].yaxis.get_major_formatter()(0.1))
            self.assertEqual(len(axes[1].lines[0].get_xdata()), 2)
            self.assertTrue(np.isnan(axes[2].lines[0].get_ydata()[3:]).all())
        finally:
            plt.close(fig)

    def test_png_and_cleanup(self):
        before = set(plt.get_fignums()); fig, _ = build_figure(fixture())
        try:
            with tempfile.TemporaryDirectory() as folder:
                path = Path(folder)/'returns.png'; fig.savefig(path)
                self.assertEqual(path.read_bytes()[:8], b'\x89PNG\r\n\x1a\n')
        finally:
            plt.close(fig)
        self.assertEqual(set(plt.get_fignums()), before)


if __name__ == '__main__':
    unittest.main()
```

The eight methods cover the known +10%/-10% example, missing intervals versus observed zero, strict linking, a complete-path cross-check against direct price ratios and cumulative log changes, rejection rules, source preservation and aware timezone equivalence, plotted bar heights/formatter/gap data, and PNG export with figure cleanup.

The complete-path test replaces the missing fixture price with a supplied synthetic value solely for that test. It does not impute the publication fixture. An independent endpoint identity and the exponential log-return identity check the linked implementation from different arithmetic routes.

PNG-signature tests establish file format, not readability. Artist checks establish what data were plotted, not whether the visual arrangement communicates clearly. The exported PNG therefore also receives a separate visual inspection.

## 14. Common Errors and Corrections

| Error | Consequence | Correction |
|---|---|---|
| Summing simple returns for a cumulative line | +10% and -10% appear to cancel | Compound compatible gross ratios |
| Plotting the first interval return as zero | Invents a prior interval | Leave it undefined; define cumulative baseline separately |
| Filling missing returns with zero | Treats unknown changes as unchanged prices | Preserve NaN under the stated policy |
| Dropping a missing price before ratios | Creates a longer interval silently | Retain the expected grid or label the new horizon explicitly |
| Skipping NaNs while linking | Releases an incomplete full-window path | Propagate unknown required factors |
| Restarting after a gap without a new label | Mixes different baselines | Withhold the strict path or identify a separate rebased product |
| Double scaling percentages | Decimal 0.10 can display as 1,000% | Match stored units to the formatter |
| Calling an endpoint ratio a complete interval history | Hides missing intermediate evidence | Label endpoint and path products separately |
| Treating price ratios as total investment returns | Omits distributions and other adjustments | Obtain and document the required return inputs |

## 15. Exercises and Answer Guidance

1. **Compounding:** What is the cumulative simple return for +20% followed by -20%?  
   **Guidance:** `1.2 * 0.8 - 1 = -0.04`, or -4%.
2. **Baseline:** Why is the first linked value zero while the first adjacent return is NaN?  
   **Guidance:** Zero measures change from the baseline to itself; no earlier observation exists for an adjacent return.
3. **Observed zero:** Why is Jan 6 a valid zero even though the final linked value is unknown?  
   **Guidance:** Both endpoints of that local interval are observed and equal; missing earlier ratios still block the full linked path.
4. **Endpoint scope:** What does the +8% endpoint-only result establish?  
   **Guidance:** The last observed price is 8% above the baseline price. It does not recover the missing interval history or establish total return.
5. **Percentage units:** What does `PercentFormatter(xmax=1.0)` display for `-0.025`?  
   **Guidance:** -2.5%, subject to the formatter's chosen precision.
6. **Missing point:** If Jan 4 is deleted before calculating returns, what new interval appears?  
   **Guidance:** Jan 3→Jan 5, spanning two days; its approximately 9.09% price change is not a one-day observation.
7. **Complete-path validation:** Replace the missing price with 105 only in a separate test fixture. Should the final linked value equal the endpoint ratio?  
   **Guidance:** Yes, within numerical tolerance. The complete product telescopes to the endpoint ratio.
8. **Chart choice:** Which later chart would describe the frequency distribution of observed returns instead of their time order?
