## 1. The level-payment contract

A **level-payment loan** requires a constant scheduled payment at each equally spaced period. The payment is level, but the composition changes: interest is calculated on the outstanding balance, while the remainder reduces principal. For a conventional fixed-rate, fully amortizing loan, interest typically falls and principal repayment rises over time.

Assume a principal L > 0, a constant effective periodic rate r ≥ 0, n positive integer periods, and end-of-period payments A. The model excludes fees, taxes, escrow, skipped payments, variable rates, and prepayment.

```text
Borrower perspective

time:       0           1           2                   n
            |-----------|-----------|--------- ... -------|
cash flow: +L          -A          -A                  -A
```

The original advance and repayment cash flows are opposite signs from the borrower's perspective.

## 2. Deriving the level payment

The loan amount equals the present value of the promised payments:

**L = A × sum from t=1 to n of (1+r)^(-t).**

For r > 0, the finite geometric series gives:

**L = A × [1 - (1+r)^(-n)] / r.**

Therefore:

**A = Lr / [1 - (1+r)^(-n)].**

At r = 0, the limiting result is **A = L/n**. The loan is fully repaid at the last scheduled payment under exact arithmetic.

## 3. Amortization mechanics

Let B(k-1) be the balance after the previous payment. During period k:

**I(k) = r × B(k-1)** — interest accrued.

**P(k) = A - I(k)** — principal reduction.

**B(k) = B(k-1) - P(k) = B(k-1)(1+r) - A** — balance after payment.

The first interest amount is Lr. For a normal fully amortizing loan, the level payment exceeds first-period interest; otherwise the principal would not begin declining.

## 4. Worked example

A borrower takes **$10,000** at an effective **0.5% monthly** rate, repayable over **24 monthly payments**.

The payment is:

**A = 10000 × 0.005 / [1 - (1.005)^(-24)] ≈ $443.21.**

The first month's interest is **$50.00**. First-month principal reduction is approximately **$393.21**, and the remaining balance after the first payment is approximately **$9,606.79**.

The displayed values are rounded for communication. The model uses the unrounded payment internally; an actual lender's cent-rounding rules may change the final installment.

## 5. Outstanding balance: two methods

The **retrospective method** accumulates the original loan and subtracts accumulated payments:

**B(k) = L(1+r)^k - A × [(1+r)^k - 1]/r.**

The **prospective method** values the remaining n-k payments:

**B(k) = A × [1 - (1+r)^(-(n-k))]/r.**

Both are mathematically equivalent for r > 0. At zero rate, **B(k) = L - kA**. The prospective method can be more numerically stable near maturity because it avoids subtracting large accumulated values.

## 6. Total scheduled interest

For an ideal fully amortizing loan with no other cash flows:

**Total interest = nA - L.**

This is the sum of all scheduled interest components, not a separate charge added to the payments. A lower payment obtained by lengthening the term can increase total interest even though it improves short-term cash flow.

## 7. Loan model validation

A reliable model should verify that all scheduled payments are equal before contractual rounding, each row satisfies **payment = interest + principal**, the ending balance is approximately zero, and the sum of principal reductions equals the initial principal.

For floating-point calculations, use numerical tolerances rather than exact equality. When preparing a production amortization schedule, specify the monetary rounding policy and treatment of the final payment.

The schedule uses prospective balances and the equivalent principal reduction A(1+r)^(-(n-k+1)) at positive rates, avoiding subtraction of nearly equal terms. The closing balance at maturity is exactly zero under the model; this is not an adjustment to a cent-rounded servicing schedule. Total interest uses a local higher-precision Decimal calculation before returning a bounded float. Nonzero results that underflow to zero and nonfinite results are rejected.

The standard-library reference implementation includes payment, schedule, balance, and total-interest functions, with **12 unit tests** covering known values, interest/principal splits, balance reconciliation, declining interest, and invalid inputs.

```python
"""Level-payment loans: prospective and retrospective balances."""
from decimal import Decimal, DecimalException, localcontext
import math
import unittest

def check(L,r,n):
    if any(isinstance(v,bool) or not isinstance(v,(int,float)) or not math.isfinite(v) for v in (L,r)):
        raise ValueError("nonfinite loan input")
    if L<=0 or r<0 or isinstance(n,bool) or not isinstance(n,int) or n<=0:
        raise ValueError("invalid principal, rate, or term")

def _positive(value, label):
    if not math.isfinite(value) or value <= 0:
        raise ValueError(f"{label} outside supported range")
    return value

def _loss(log_rate, periods):
    try:
        return _positive(-math.expm1(-periods*log_rate), "discount loss")
    except OverflowError as exc:
        raise ValueError("discount loss outside supported range") from exc

def payment(L,r,n):
    check(L,r,n)
    if r == 0:
        amount = L/n
    elif n == 1:
        amount = L*(1+r)
    else:
        amount = L*(r/_loss(math.log1p(r),n))
    return _positive(amount,"payment")

def _balance(L,log_rate,n,k,full_loss):
    if k == 0:
        return L
    if k == n:
        return 0.0
    fraction = (n-k)/n if log_rate == 0 else _loss(log_rate,n-k)/full_loss
    return _positive(L*fraction,"balance")

def schedule(L,r,n):
    A = payment(L,r,n)
    log_rate = math.log1p(r)
    full_loss = _loss(log_rate,n) if r > 0 and n > 1 else None
    outstanding = L
    rows = []
    for k in range(1,n+1):
        interest = 0.0 if r == 0 else _positive(outstanding*r,"interest")
        if k == n:
            principal = outstanding
        elif r == 0:
            principal = A
        else:
            # Equivalent to A - interest, without near-equal subtraction.
            principal = _positive(A*math.exp(-(n-k+1)*log_rate),"principal")
        outstanding = _balance(L,log_rate,n,k,full_loss)
        rows.append((k,A,interest,principal,outstanding))
    return rows

def balance(L,r,n,k):
    check(L,r,n)
    if isinstance(k,bool) or not isinstance(k,int) or not 0<=k<=n:
        raise ValueError("invalid completed payments")
    log_rate = math.log1p(r)
    full_loss = _loss(log_rate,n) if r > 0 and 0 < k < n else None
    return _balance(L,log_rate,n,k,full_loss)

def total_interest(L,r,n):
    check(L,r,n)
    if r == 0:
        return 0.0
    try:
        with localcontext() as ctx:
            ctx.prec = 750
            rate = Decimal(r)
            loss = 1 - (1 + rate)**(-n)
            result = float(Decimal(L) * (n*rate/loss - 1))
    except (DecimalException, OverflowError) as exc:
        raise ValueError("total interest outside supported range") from exc
    return _positive(result,"total interest")

class Tests(unittest.TestCase):
    def test_01_zero_rate(self): self.assertEqual(payment(1200,0,12),100)
    def test_02_one_period(self): self.assertAlmostEqual(payment(100,.1,1),110)
    def test_03_known_payment(self):
        self.assertAlmostEqual(payment(10000,.005,24),10000*.005/(1-1.005**-24))
    def test_04_count(self): self.assertEqual(len(schedule(1000,.01,12)),12)
    def test_05_first_interest(self):
        self.assertAlmostEqual(schedule(1000,.01,12)[0][2],10)
    def test_06_first_principal(self):
        row=schedule(1000,.01,12)[0]
        self.assertAlmostEqual(row[3],row[1]-row[2])
    def test_07_balance_initial(self):
        self.assertAlmostEqual(balance(1000,.01,12,0),1000)
    def test_08_balance_intermediate(self):
        self.assertAlmostEqual(balance(1000,.01,12,3),schedule(1000,.01,12)[2][4])
    def test_09_balance_final(self):
        self.assertEqual(balance(1000,.01,12,12),0)
    def test_10_total_interest(self):
        self.assertAlmostEqual(sum(x[2] for x in schedule(1000,.01,12)),total_interest(1000,.01,12))
    def test_11_declining_interest(self):
        rows=schedule(1000,.01,12)
        self.assertLess(rows[-1][2],rows[0][2])
    def test_12_invalid(self):
        with self.assertRaises(ValueError): payment(100,-.01,12)
        with self.assertRaises(ValueError): payment(0,.01,12)
        with self.assertRaises(ValueError): balance(100,.01,12,13)
        self.assertAlmostEqual(payment(.1,5e-324,1),.1)
        self.assertEqual(balance(1e308,1,1,0),1e308)
        self.assertEqual(total_interest(1e308,1,1),1e308)
        self.assertTrue(math.isclose(schedule(1,1e100,2)[0][3],1e-100))
        self.assertEqual(schedule(1,1e308,1)[0][4],0)
        self.assertTrue(math.isclose(total_interest(1000,1e-18,12),6.5e-15))
        for call in (lambda: payment(5e-324,0,2),
                     lambda: payment(1e308,1,1),
                     lambda: schedule(5e-324,.5,1),
                     lambda: total_interest(1e308,1,10)):
            with self.assertRaises(ValueError):
                call()

if __name__=="__main__":
    L,r,n=10000,.005,24
    print("Payment:",round(payment(L,r,n),2))
    print("Total interest:",round(total_interest(L,r,n),2))
    unittest.main(verbosity=2)
```

## 9. Exercises with worked answers

1. **Loan structure:** What stays constant in a level-payment loan? **Answer:** The scheduled payment amount, before rounding adjustments.
2. **Payment equation:** Give the formula for A. **Answer:** A = Lr/[1-(1+r)^(-n)] for r > 0, or A = L/n for r = 0.
3. **Zero-rate case:** Find A for $1,200 over 12 periods at 0%. **Answer:** $100.
4. **One-period case:** Find A for $100 at 10% for one period. **Answer:** $110.
5. **Interest:** Find first-period interest for $10,000 at 0.5%. **Answer:** $50.
6. **Principal:** If payment is $443.21 and interest is $50, what is the principal component? **Answer:** Approximately $393.21.
7. **New balance:** What is the approximate balance after the first payment in Exercise 6, starting from the $10,000 balance in Exercise 5? **Answer:** $9,606.79.
8. **Recurrence:** State the balance recurrence. **Answer:** B(k) = B(k-1)(1+r)-A.
9. **Prospective value:** What does the remaining balance equal? **Answer:** The PV of remaining scheduled payments at the loan's periodic rate.
10. **Total interest:** How is scheduled total interest calculated? **Answer:** nA-L.
11. **Validation:** What must the sum of principal reductions equal? **Answer:** Initial principal L, up to rounding.
12. **Rounding:** Why can the final contractual installment differ slightly? **Answer:** Periodic interest and payment rounding can create a small residual balance.
