## Project brief

This capstone integrates Sections 11.1–11.12. The implementation is educational, uses only the Python standard library, and deliberately separates contractual assumptions from numerical results.

## 1. Learning outcomes

By completing this project, you should be able to:

1. Translate loan terms into a consistent periodic-rate model.
2. Compute a fixed installment without cancellation in the modeled amounts.
3. Construct a fully reconciled amortization schedule.
4. Model recurring principal prepayments and payoff caps.
5. Compare interest and payoff time across scenarios.
6. Calculate prospective outstanding balances.
7. Compare refinancing payments and simple cash-cost break-even.
8. Validate results with automated tests and explicit acceptance criteria.

## 2. Requirements and boundaries

**Inputs:** Principal L, periodic rate r, number of periods n, optional recurring extra payment E, extra-payment start period, and refinance parameters.

**Outputs:** Contractual scheduled payment, row-by-row amortization, total interest, total cash paid, payoff period, prepayment savings, outstanding balance, and refinancing payment comparison.

**Assumptions:** Fixed periodic rate, equal end-of-period payment intervals, no delinquency, no taxes, no escrow, no lender fees inside the schedule, and no prepayment penalties. The refinancing helper models **upfront cash fees only**, not financed closing costs or full common-horizon economic valuation.

**Out of scope:** Adjustable-rate mortgages, daily accrual, regulatory APR, contractual cent rounding, escrow, credit underwriting, and lender-specific payoff quotes.

## 3. Mathematical specification

For principal L, rate r per period, and n periods, the scheduled installment is:

**A = Lr/[1-(1+r)^(-n)]** when r>0, or **A=L/n** when r=0.

In floating point, the numerically stable equivalent is:

**A = Lr/[-expm1(-n log1p(r))].**

For each period k, with opening balance B(k-1):

**I(k) = r B(k-1)**

**Scheduled(k) = min(A, B(k-1)+I(k))**

**Extra(k) = min(E, max(0, B(k-1)+I(k)-Scheduled(k)))**, when extras are enabled.

**Payment(k) = Scheduled(k)+Extra(k)**

**Principal(k) = Payment(k)-I(k)**

**B(k) = max(0, B(k-1)-Principal(k))**

Stop when the balance is zero. A final payment may be smaller than the regular installment.

For an ordinary loan without extra payments, the prospective balance after k payments is:

**B(k) = A[1-(1+r)^(-(n-k))]/r**, when r>0; otherwise **B(k)=A(n-k)**.

## 6. Complete runnable Python reference implementation

Use Python 3.9 or later and its standard library. Save the following as `loan_mortgage_analyzer.py`; no earlier script or data file is needed.

```python
"""Chapter 11 capstone: fixed-rate loan analyzer, prepayment and refinance."""
import math
import unittest
from fractions import Fraction

def _input(value, label, positive=False):
    if isinstance(value, bool) or not isinstance(value, (int, float)):
        raise ValueError(f"invalid {label}")
    try:
        finite = math.isfinite(value)
    except OverflowError:
        finite = False
    if not finite or value < 0 or (positive and value == 0):
        raise ValueError(f"invalid {label}")
    return Fraction(str(value))

_MIN_FLOAT = Fraction(math.ulp(0.0))

def _reported(value, label):
    try:
        if 0 < abs(value) < _MIN_FLOAT:
            raise OverflowError
        result = float(value)
    except OverflowError as exc:
        raise ValueError(f"{label} outside supported range") from exc
    if not math.isfinite(result):
        raise ValueError(f"{label} outside supported range")
    return result

def _terms(L,r,n):
    principal = _input(L, "principal", positive=True)
    rate = _input(r, "rate")
    if isinstance(n, bool) or not isinstance(n, int) or n < 1:
        raise ValueError("invalid term")
    amount = principal/_annuity(rate,n)
    _reported(amount, "regular installment")
    return principal, rate, amount

def payment(principal,rate,periods):
    _, _, amount = _terms(principal,rate,periods)
    return _reported(amount, "regular installment")

def schedule(principal,rate,periods,extra=0,extra_start=1):
    balance, rate, amount = _terms(principal,rate,periods)
    requested = _input(extra, "extra")
    if isinstance(extra_start, bool) or not isinstance(extra_start, int) or extra_start < 1:
        raise ValueError("invalid extra start")
    rows=[]
    for k in range(1,periods+1):
        opening = balance
        interest = opening*rate
        due = opening+interest
        _reported(due, "amount due")
        scheduled = min(amount,due)
        additional = min(requested,due-scheduled) if k>=extra_start else Fraction(0)
        paid = scheduled+additional
        balance = due-paid
        values = dict(opening=opening,interest=interest,scheduled=scheduled,
                      extra=additional,payment=paid,principal=paid-interest,closing=balance)
        rows.append(dict(period=k,**{key:_reported(value,key) for key,value in values.items()}))
        if balance == 0:
            break
    return rows

def summary(rows):
    if not rows:
        raise ValueError("empty schedule")
    try:
        interest=math.fsum(x["interest"] for x in rows)
        paid=math.fsum(x["payment"] for x in rows)
    except OverflowError as exc:
        raise ValueError("schedule totals outside supported range") from exc
    if not (math.isfinite(interest) and math.isfinite(paid)):
        raise ValueError("nonfinite schedule total")
    return dict(periods=len(rows),total_interest=interest,total_paid=paid,
                final_balance=rows[-1]["closing"])

def audit(rows,original):
    if not rows:
        return False
    def close(a,b):
        return math.isclose(a,b,rel_tol=1e-12,abs_tol=0)
    try:
        _input(original,"principal",positive=True)
        previous=original
        for k,row in enumerate(rows,1):
            opening,interest,scheduled,extra,paid,principal,closing=(
                row[x] for x in ("opening","interest","scheduled","extra",
                                  "payment","principal","closing"))
            if type(row["period"]) is not int or row["period"]!=k or previous<=0:
                return False
            if any(type(v) not in (int,float) or not math.isfinite(v) or v<0
                   for v in (opening,interest,scheduled,extra,paid,principal,closing)):
                return False
            if not (close(opening,previous) and close(paid,scheduled+extra)
                    and close(paid,interest+principal) and close(opening,closing+principal)):
                return False
            previous=closing
        return previous==0 and close(math.fsum(x["principal"] for x in rows),original)
    except (KeyError,TypeError,ValueError,OverflowError):
        return False

def _annuity(rate,n):
    return Fraction(n) if rate==0 else (1-(1+rate)**-n)/rate

def remaining_balance(principal,rate,periods,after):
    L=_input(principal,"principal",positive=True)
    r=_input(rate,"rate")
    if type(periods) is not int or periods<1:
        raise ValueError("periods must be a positive integer")
    if type(after) is not int or not 0<=after<=periods:
        raise ValueError("invalid elapsed periods")
    if after==0:
        return _reported(L,"balance")
    if after==periods:
        return 0.0
    return _reported(L*_annuity(r,periods-after)/_annuity(r,periods),"balance")

def refinance(old_balance,old_rate,old_remaining,new_rate,new_periods,fees=0):
    cost=_input(fees,"fees")
    _,_,old=_terms(old_balance,old_rate,old_remaining)
    _,_,new=_terms(old_balance,new_rate,new_periods)
    saving=old-new
    return dict(old_payment=_reported(old,"old payment"),new_payment=_reported(new,"new payment"),
                monthly_saving=_reported(saving,"payment saving"),
                simple_break_even=math.ceil(cost/saving) if cost>0 and saving>0 else (0 if cost==0 else None))

class Tests(unittest.TestCase):
    def test_01_zero_rate(self): self.assertEqual(payment(1200,0,12),100)
    def test_02_payment(self): self.assertAlmostEqual(payment(10000,.005,24),10000*.005/(1-1.005**-24))
    def test_03_rows(self): self.assertEqual(len(schedule(10000,.005,24)),24)
    def test_04_audit(self): self.assertTrue(audit(schedule(10000,.005,24),10000))
    def test_05_extra_audit(self): self.assertTrue(audit(schedule(10000,.005,24,100),10000))
    def test_06_extra_shortens(self): self.assertLess(len(schedule(10000,.005,24,100)),24)
    def test_07_extra_saves_interest(self):
        self.assertLess(summary(schedule(10000,.005,24,100))["total_interest"],
                        summary(schedule(10000,.005,24))["total_interest"])
    def test_08_balance(self):
        a=payment(10000,.005,24)
        self.assertAlmostEqual(remaining_balance(10000,.005,24,1),10000*1.005-a)
    def test_09_final_balance(self): self.assertEqual(remaining_balance(10000,.005,24,24),0)
    def test_10_refinance(self):
        x=refinance(200000,.06/12,240,.045/12,240,3000)
        self.assertGreater(x["monthly_saving"],0)
        self.assertGreater(x["simple_break_even"],0)
    def test_11_delayed_extra(self):
        self.assertGreaterEqual(summary(schedule(10000,.005,24,100,12))["total_interest"],
                                summary(schedule(10000,.005,24,100,1))["total_interest"])
    def test_12_validation(self):
        with self.assertRaises(ValueError): payment(-1,.01,12)
        with self.assertRaises(ValueError): schedule(1000,.01,12,-5)
        with self.assertRaises(ValueError): remaining_balance(1000,.01,12,13)
        with self.assertRaises(ValueError): refinance(1000,.01,12,.005,12,-1)
        self.assertEqual(len(schedule(1e-10,0,4)),4)
        rows=schedule(1000,.01,12)
        rows[0]["extra"]=1
        self.assertFalse(audit(rows,1000))

if __name__=="__main__":
    L,r,n=240000,.06/12,360
    base=schedule(L,r,n)
    accelerated=schedule(L,r,n,extra=200)
    print("Base:",summary(base))
    print("Extra $200:",summary(accelerated))
    print("Interest saved:",round(summary(base)["total_interest"]-summary(accelerated)["total_interest"],2))
    print("Audits:",audit(base,L),audit(accelerated,L))
    print(f"Balance after 60 payments: {remaining_balance(L,r,n,60):.2f}")
    print("Refinance:",refinance(200000,.06/12,240,.045/12,240,3000))
    unittest.main(verbosity=2)
```

## 7. Data contract and numerical conventions

- **Rate units:** `rate` is per payment period, not annual. Divide nominal annual monthly-compounded rates by 12.
- **Precision:** The model uses the decimal text of its inputs and exact rational arithmetic for payment and payoff decisions. Reported amounts are floats; positive magnitudes below the smallest positive float and nonfinite conversions are rejected. Exact powers are intended for teaching-sized terms.
- **Payment timing:** Payments occur at the end of each modeled period.
- **Prepayment posting:** Additional principal is applied with the scheduled installment after the period's interest accrues.
- **Payoff:** Cap payment at the remaining amount due.
- **Tolerance:** Compare reported row identities and totals using relative tolerance; require exact zero for the reported final balance. The audit checks internal consistency, not whether the inputs reflect a contract.
- **Contractual currency:** Do not use this float-only implementation as a lender's cent-rounded servicing ledger.

## 8. Acceptance tests and evidence

| Check | Expected result |
|---|---|
| Standard payment | Agrees with annuity formula |
| Zero-interest loan | Principal divided by payment count |
| Baseline amortization | Full original term, final balance zero |
| Extra payments | Earlier payoff, lower modeled total interest |
| Row payment identity | Payment = interest + principal |
| Balance continuity | Next opening equals prior closing |
| Principal reconciliation | Sum of principal equals original principal |
| Outstanding balance | Matches first-period recurrence |
| Refinance savings | Lower new rate at equal term lowers payment |
| Invalid inputs | Rejected with meaningful exceptions |

## 9. Troubleshooting

**Incorrect payment by a factor of twelve:** Verify that the nominal annual rate was converted to a monthly periodic rate.

**Schedule never reaches zero:** Check the payment formula, term, and whether the implementation accidentally rounds down every installment.

**Extra payments fail to save interest:** Confirm extras are applied directly to principal and future interest uses the reduced balance.

**Negative balance at payoff:** Cap the final installment at the remaining principal plus accrued interest.

**Reconciliation fails by a small amount:** Check floating-point tolerance and whether presentation-rounded values were used in subsequent calculations.

**Refinance looks better only because the term is longer:** Compare outstanding principal and total cash flows over a common holding horizon, not only monthly payments.

## 10. Exercises with worked answers

1. **Periodic rate:** Convert nominal annual 6% compounded monthly. **Answer:** 0.005 per month.
2. **Payment count:** How many installments are in 30 years? **Answer:** 360.
3. **Payment formula:** State the level-payment equation. **Answer:** A=Lr/[1-(1+r)^(-n)] for r>0; A=L/n when r=0.
4. **Zero-rate branch:** Find payment on $1,200 over 12 periods at zero rate. **Answer:** $100.
5. **First interest:** Find first-month interest on $240,000 at 0.5%. **Answer:** $1,200.
6. **Extra payment:** If scheduled payment is A and extra is $200, what is the uncapped total? **Answer:** A+$200.
7. **Interest saving:** Define the comparison. **Answer:** Baseline interest minus accelerated interest.
8. **Periods saved:** Define the comparison. **Answer:** Baseline payoff periods minus accelerated payoff periods.
9. **Row identity:** What must payment equal? **Answer:** Interest plus principal.
10. **Balance identity:** What must closing balance equal? **Answer:** Opening balance minus principal repaid.
11. **Final balance:** What should the fully repaid balance be? **Answer:** Exactly zero at modeled payoff. Use relative tolerance for identities involving reported float amounts.
12. **Refinance payment:** What changes when the rate falls but principal and term stay equal? **Answer:** The scheduled installment falls.
13. **Break-even:** If cash costs are $3,000 and savings $100 per month, what is simple break-even? **Answer:** 30 months.
14. **Limitation:** Why is simple break-even not a complete economic decision? **Answer:** It excludes discounting, residual balances, and other costs.
