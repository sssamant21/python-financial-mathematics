## Learning objectives

Derive a fixed loan payment from principal, rate, and term; reconcile the result with the present value of repayments; distinguish payment amounts from total borrowing cost; handle zero-interest loans; and implement validated Python payment calculations.

## 1. The payment problem

Suppose a borrower receives principal L today and agrees to repay it through n equal end-of-period payments A. With a constant effective interest rate r per payment period, the loan amount equals the present value of the repayment stream.

```text
Period        0            1           2                n
              |------------|-----------|----------------|
Borrower     +L           -A          -A               -A
```

The unknown payment A must be large enough to cover interest and fully repay principal by the final scheduled date.

## 2. Derive the formula

For r > 0:

**L = A/(1+r) + A/(1+r)^2 + ... + A/(1+r)^n.**

Using the finite geometric-series identity:

**L = A[1-(1+r)^(-n)]/r.**

Rearrange to isolate the payment:

**A = Lr/[1-(1+r)^(-n)].**

For r = 0, the limit is **A = L/n**. Always use a periodic rate that matches the payment frequency.

## 3. Worked example: monthly loan payment

Consider a $250,000 loan with a nominal annual rate of 6%, compounded monthly, and 360 end-of-month payments.

L = 250000; r = 0.06/12 = 0.005; n = 360.

**A = 250000 × 0.005/[1-(1.005)^(-360)] ≈ $1,498.88 per month.**

This is the scheduled principal-and-interest payment. It does not include property taxes, insurance, escrow, or origination fees. The displayed amount is rounded, while the exact mathematical payment is used in subsequent calculations.

## 4. Validate using present value

A reliable payment solution must satisfy:

**sum from k=1 to n of A/(1+r)^k = L.**

For numerical computations, compare the reconstructed present value with principal using an appropriate tolerance. This detects wrong timing, inconsistent rates, and formula errors.

At r = 0, the sum becomes nA = L.

## 5. Sensitivity analysis

For a fixed principal and term, increasing the interest rate raises the scheduled payment. For fixed principal and rate, extending the term lowers the payment but generally increases total scheduled interest.

The total scheduled interest in the simplified model is:

**Interest total = nA - L.**

Do not equate a smaller monthly payment with lower overall borrowing cost.

## 6. Reverse calculation: affordable principal

Given a payment limit A, rate r, and term n, the present value of that payment stream gives the supported principal:

**L = A[1-(1+r)^(-n)]/r**, when r > 0.

For zero rate, **L = nA**. This is a mathematical affordability estimate, not a lender's underwriting approval.

## 7. Extension: final balloon payment

Some loans have n equal scheduled payments A plus an additional balloon amount F due at period n. The present-value equation is:

**L = A[1-(1+r)^(-n)]/r + F/(1+r)^n.**

Thus, for r > 0:

**A = [L - F/(1+r)^n] × r/[1-(1+r)^(-n)].**

For r = 0, **A = (L-F)/n**.

The Python lab includes this optional extension. The balloon is an additional payment at maturity, not a substitute for the last regular payment. The model rejects a balloon amount that would require nonpositive scheduled payments.

## 8. Numerical stability and rounding

Direct evaluation of 1-(1+r)^(-n) can lose precision for very small rates. The lab uses `math.log1p` and `math.expm1` to improve stability. Unit factors are formed before scaling the principal. The balloon calculation discounts the final amount in a higher-precision local Decimal context before solving for the regular payment. This avoids an overflowing ordinary payment or positive exponential and reduces cancellation when a balloon nearly covers principal. Returned values are bounded floats; nonzero values rounded to zero and nonfinite results are rejected. Currency display is rounded only after calculation.

Contractual schedules often round interest and payments to cents at each period, which can produce a slightly adjusted final payment. That is a separate policy from the ideal mathematical formula.

```python
"""Loan payment solver with numerical checks."""
from decimal import Decimal, DecimalException, localcontext
import math
import unittest

def _validate(principal, rate, periods):
    if isinstance(principal,bool) or not isinstance(principal,(int,float)) or not math.isfinite(principal) or principal<=0:
        raise ValueError("principal must be positive finite")
    if isinstance(rate,bool) or not isinstance(rate,(int,float)) or not math.isfinite(rate) or rate<0:
        raise ValueError("rate must be nonnegative finite")
    if isinstance(periods,bool) or not isinstance(periods,int) or periods<=0:
        raise ValueError("periods must be positive integer")

def _positive(result, label):
    if not math.isfinite(result) or result <= 0:
        raise ValueError(f"{label} outside supported positive range")
    return result

def _payment_factor(rate, periods):
    if periods == 1:
        return 1 + rate
    try:
        loss = -math.expm1(-periods*math.log1p(rate))
    except OverflowError as exc:
        raise ValueError("payment factor outside supported range") from exc
    return _positive(rate/loss,"payment factor")

def payment(principal, rate, periods):
    _validate(principal,rate,periods)
    result = principal/periods if rate == 0 else principal*_payment_factor(rate,periods)
    return _positive(result,"payment")

def present_value_of_payments(amount,rate,periods):
    _validate(amount,rate,periods)
    try:
        result = amount*periods if rate == 0 else amount/_payment_factor(rate,periods)
    except OverflowError as exc:
        raise ValueError("principal outside supported range") from exc
    return _positive(result,"principal")

def payment_with_balloon(principal,rate,periods,balloon):
    _validate(principal,rate,periods)
    if isinstance(balloon,bool) or not isinstance(balloon,(int,float)) or not math.isfinite(balloon) or balloon<0:
        raise ValueError("balloon must be nonnegative finite")
    if balloon == 0:
        return payment(principal,rate,periods)
    try:
        with localcontext() as ctx:
            ctx.prec = 750
            L, r, F = Decimal(principal), Decimal(rate), Decimal(balloon)
            if rate == 0:
                amount = (L-F)/periods
            else:
                discount = (1+r)**(-periods)
                amount = (L-F*discount)*r/(1-discount)
            result = float(amount)
    except (DecimalException, OverflowError) as exc:
        raise ValueError("balloon payment outside supported range") from exc
    return _positive(result,"balloon payment")

def first_interest(principal,rate,periods):
    _validate(principal,rate,periods)
    return 0.0 if rate == 0 else _positive(principal*rate,"interest")

class Tests(unittest.TestCase):
    def test_01_zero_rate(self): self.assertEqual(payment(1200,0,12),100)
    def test_02_one_period(self): self.assertAlmostEqual(payment(100,.1,1),110)
    def test_03_standard(self): self.assertAlmostEqual(payment(10000,.005,24),10000*.005/(1-1.005**-24))
    def test_04_pv_reconciliation(self):
        a=payment(1000,.01,12)
        self.assertAlmostEqual(sum(a/1.01**k for k in range(1,13)),1000)
    def test_05_scaling(self): self.assertAlmostEqual(payment(2000,.01,12),2*payment(1000,.01,12))
    def test_06_rate_sensitivity(self): self.assertGreater(payment(1000,.02,12),payment(1000,.01,12))
    def test_07_term_sensitivity(self): self.assertLess(payment(1000,.01,24),payment(1000,.01,12))
    def test_08_inverse_principal(self):
        a=payment(1000,.01,12)
        self.assertAlmostEqual(present_value_of_payments(a,.01,12),1000)
    def test_09_zero_balloon(self): self.assertAlmostEqual(payment_with_balloon(1000,.01,12,0),payment(1000,.01,12))
    def test_10_balloon(self):
        a=payment_with_balloon(1000,.01,12,200)
        self.assertAlmostEqual(sum(a/1.01**k for k in range(1,13))+200/1.01**12,1000)
    def test_11_interest(self): self.assertAlmostEqual(first_interest(1000,.01,12),10)
    def test_12_invalid(self):
        for args in ((0,.01,12),(100,-.01,12),(100,.01,0),(100,float("nan"),12)):
            with self.assertRaises(ValueError): payment(*args)
        with self.assertRaises(ValueError): payment_with_balloon(100,.01,12,-1)
        self.assertAlmostEqual(payment(.1,5e-324,1),.1)
        self.assertEqual(payment_with_balloon(1e308,1,1,1e308),1e308)
        self.assertEqual(payment_with_balloon(100,1,2000,200),100)
        self.assertEqual(payment_with_balloon(100,5e-324,1,100),100*5e-324)
        for call in (lambda: payment(5e-324,0,2),
                     lambda: present_value_of_payments(5e-324,1,1),
                     lambda: present_value_of_payments(1e308,0,2),
                     lambda: first_interest(5e-324,.5,1),
                     lambda: first_interest(1e308,2,1),
                     lambda: first_interest(100,-.1,1),
                     lambda: first_interest(100,.1,0),
                     lambda: first_interest(True,.1,1)):
            with self.assertRaises(ValueError):
                call()

if __name__=="__main__":
    p=payment(250000,.06/12,360)
    print("Monthly payment:",round(p,2))
    unittest.main(verbosity=2)
```

## 10. Exercises and worked answers

1. **Formula:** State the fixed-payment equation. **Answer:** A = Lr/[1-(1+r)^(-n)] for r > 0, or A = L/n for r = 0.
2. **Zero rate:** What is the payment on $1,200 over 12 periods at 0%? **Answer:** $100.
3. **Single period:** What repays $100 after one period at 10%? **Answer:** $110.
4. **Monthly rate:** What is the periodic rate for a nominal 6% annual rate compounded monthly? **Answer:** 0.5%.
5. **Payment count:** How many monthly payments are scheduled over 30 years? **Answer:** 360.
6. **Mortgage example:** Calculate payment for $250,000 at 0.5% monthly over 360 months. **Answer:** Approximately $1,498.88.
7. **Present-value check:** What identity validates a computed payment? **Answer:** Sum of discounted scheduled payments equals L.
8. **Higher rate:** With L and n fixed, what happens to A as r rises? **Answer:** It rises.
9. **Longer term:** With L and r fixed, what happens to A as n increases? **Answer:** It falls.
10. **Interest total:** How is scheduled total interest calculated? **Answer:** nA-L.
11. **Inverse problem:** How is supported principal computed from A? **Answer:** L = A[1-(1+r)^(-n)]/r for r > 0, or L = nA for r = 0.
12. **Balloon:** How does a positive final balloon affect the regular payment when all else is fixed? **Answer:** It lowers the regular payment but leaves an additional maturity obligation.
