## Project brief

Build an auditable, reusable **Time Value of Money (TVM) Engine** for financial analysts and Python learners. The engine must support valuation under explicitly declared interest-rate conventions, reverse calculations, dated cash flows, reproducible CSV input, machine-readable JSON output, and acceptance tests.

This project integrates Sections 9.1–9.15. It is an educational reference implementation, not an approved trading, lending, regulatory, or accounting system.

## Learning outcomes and acceptance criteria

By completion, the learner should be able to:

1. Represent a nominal annual rate and compounding frequency with a validated immutable configuration.
2. Compute future and present values under discrete and continuous compounding.
3. Convert nominal annual rates into effective annual rates.
4. Recover an implied annual nominal rate or a nonnegative investment horizon from two matching-sign balances.
5. Calculate the NPV of multiple dated signed cash flows without double-counting the initial investment.
6. Import a strictly defined CSV cash-flow schedule and produce an auditable JSON report.
7. Reject invalid frequencies, unsupported growth factors, nonfinite values, and impossible inverse problems.
8. Run a twelve-test acceptance suite and inspect the evidence rather than relying on a single demonstration.

## Architecture

\`\`\`text
CSV cash-flow schedule (year,amount)
          |
          v
   Strict CSV parser
          |
          v
 Convention(rate, frequency)
          |
          +----> FV / PV / continuous valuation
          |
          +----> implied rate / time solvers
          |
          v
  Cash-flow discounting
          |
          v
  Event-level audit rows + NPV
          |
          v
   JSON report and tests
\`\`\`

All dates are nonnegative real years relative to valuation time zero. Amounts are signed: costs/outflows are negative and receipts/inflows are positive. The model assumes a flat deterministic rate, no fees, no taxes, and no interim cash flows except those supplied explicitly.

## Core formulas

For nominal annual decimal rate \(j\), positive integer compounding frequency \(m\), and years \(t\):

\[
FV=PV(1+j/m)^{mt},\qquad PV=FV(1+j/m)^{-mt}.
\]

\[
EAR=(1+j/m)^m-1,\qquad
j=m[(FV/PV)^{1/(mt)}-1].
\]

\[
t=\frac{\ln(FV/PV)}{m\ln(1+j/m)},\qquad
NPV=\sum_{k=1}^N C_k(1+j/m)^{-mt_k}.
\]

For continuous compounding with annual rate \(r_c\):

\[
FV=PV e^{r_ct},\qquad PV=FV e^{-r_ct}.
\]

Rates are entered as decimals: 8% is \`0.08\`. A monthly compounding frequency is \`12\`. Continuous compounding uses a distinct function to prevent rate-convention confusion.

\`\`\`python
"""Chapter 9 capstone: auditable Time Value of Money Engine."""
from dataclasses import dataclass
import csv
import io
import json
import math
from numbers import Real
import unittest

def real(value, name):
    if isinstance(value, bool) or not isinstance(value, Real):
        raise TypeError(f"{name} must be a real number")
    try:
        value = float(value)
    except OverflowError as exc:
        raise ValueError(f"{name} out of range") from exc
    if not math.isfinite(value):
        raise ValueError(f"{name} must be finite")
    return value

@dataclass(frozen=True)
class Convention:
    """Annual nominal decimal rate and compounding periods per year."""
    rate: float
    frequency: int = 1

    def __post_init__(self):
        r = real(self.rate, "rate")
        if isinstance(self.frequency, bool) or not isinstance(self.frequency, int):
            raise TypeError("frequency must be a positive integer")
        if self.frequency <= 0:
            raise ValueError("frequency must be positive")
        periodic = r / self.frequency
        if r != 0 and periodic == 0:
            raise ValueError("periodic rate underflow")
        if periodic <= -1:
            raise ValueError("periodic accumulation factor must be positive")
        object.__setattr__(self, "rate", r)

    def log_growth(self):
        return self.frequency * math.log1p(self.rate / self.frequency)

    def effective_annual(self):
        try:
            value = math.expm1(self.log_growth())
        except OverflowError as exc:
            raise ValueError("effective annual rate overflow") from exc
        if not math.isfinite(value) or value <= -1:
            raise ValueError("effective annual rate not representable")
        return value

def years(value):
    t = real(value, "time in years")
    if t < 0:
        raise ValueError("time must be nonnegative")
    return t

def scaled(amount, log_growth):
    amount = real(amount, "amount")
    if not math.isfinite(log_growth):
        raise ValueError("nonfinite exponent")
    if amount == 0:
        return 0.0
    # Avoid an intermediate growth-factor overflow when amount is small.
    log_magnitude = math.log(abs(amount)) + log_growth
    if log_magnitude > math.log(float.fromhex("0x1.fffffffffffffp1023")):
        raise ValueError("result overflow")
    try:
        magnitude = math.exp(log_magnitude)
    except OverflowError as exc:
        raise ValueError("result overflow") from exc
    if magnitude == 0 or not math.isfinite(magnitude):
        raise ValueError("result underflow or overflow")
    return math.copysign(magnitude, amount)

def future_value(present, convention, time):
    return scaled(present, convention.log_growth() * years(time))

def present_value(future, convention, time):
    return scaled(future, -convention.log_growth() * years(time))

def continuous_future_value(present, annual_rate, time):
    return scaled(present, real(annual_rate, "continuous rate") * years(time))

def continuous_present_value(future, annual_rate, time):
    return scaled(future, -real(annual_rate, "continuous rate") * years(time))

def log_balance_ratio(present, future):
    p, f = real(present, "present"), real(future, "future")
    if p == 0 or f == 0 or (p > 0) != (f > 0):
        raise ValueError("balances must be nonzero and have matching signs")
    return math.log(abs(f)) - math.log(abs(p))

def solve_rate(present, future, time, frequency=1):
    t = years(time)
    if t == 0:
        raise ValueError("rate not identifiable at zero horizon")
    # Reuse Convention validation for frequency and the resulting rate.
    Convention(0.0, frequency)
    nominal = frequency * math.expm1(log_balance_ratio(present, future) /
                                      (frequency * t))
    return Convention(nominal, frequency).rate

def solve_time(present, future, convention):
    growth = convention.log_growth()
    if growth == 0:
        raise ValueError("zero growth gives no unique finite time")
    result = log_balance_ratio(present, future) / growth
    if not math.isfinite(result) or result < 0:
        raise ValueError("target unreachable at nonnegative finite time")
    return result

def cashflow_audit(events, convention):
    """Return per-event audit records and total NPV; events are (years, amount)."""
    rows = []
    for number, (when, amount) in enumerate(events, 1):
        t, a = years(when), real(amount, "cash flow")
        discount = math.exp(-convention.log_growth() * t)
        if not math.isfinite(discount) or discount == 0:
            raise ValueError("discount factor outside float range")
        pv = scaled(a, -convention.log_growth() * t)
        rows.append({"event": number, "year": t, "amount": a,
                     "discount_factor": discount, "present_value": pv})
    total = math.fsum(row["present_value"] for row in rows)
    if not math.isfinite(total):
        raise ValueError("NPV outside float range")
    return rows, total

def parse_cashflow_csv(csv_text):
    """CSV columns: year,amount. No implicit initial investment."""
    reader = csv.DictReader(io.StringIO(csv_text))
    if reader.fieldnames != ["year", "amount"]:
        raise ValueError("CSV header must be exactly year,amount")
    events = []
    for line, row in enumerate(reader, 2):
        try:
            if row.get("year") is None or row.get("amount") is None:
                raise ValueError("missing field")
            events.append((years(float(row["year"])),
                           real(float(row["amount"]), "amount")))
        except (TypeError, ValueError, OverflowError) as exc:
            raise ValueError(f"invalid CSV record on line {line}") from exc
    return events

def report(events, convention):
    rows, npv = cashflow_audit(events, convention)
    return {"rate_convention": "nominal_annual",
            "nominal_annual_rate": convention.rate,
            "compounds_per_year": convention.frequency,
            "effective_annual_rate": convention.effective_annual(),
            "event_count": len(rows), "cash_flows": rows, "npv": npv}

class EngineAcceptanceTests(unittest.TestCase):
    def test_01_future_present_round_trip(self):
        c = Convention(.06, 12)
        self.assertAlmostEqual(present_value(future_value(1000, c, 2), c, 2),
                               1000, places=9)
    def test_02_effective_annual(self):
        self.assertAlmostEqual(Convention(.06, 12).effective_annual(),
                               (1 + .06/12)**12 - 1)
    def test_03_continuous_round_trip(self):
        self.assertAlmostEqual(continuous_present_value(
            continuous_future_value(2500, .04, 3), .04, 3), 2500)
    def test_04_inverse_rate(self):
        self.assertAlmostEqual(solve_rate(1000, 1210, 2), .1)
    def test_05_inverse_time(self):
        self.assertAlmostEqual(solve_time(1000, 1210, Convention(.1)), 2)
    def test_06_npv_break_even(self):
        rows, npv = cashflow_audit([(0, -1000), (1, 1100)],
                                   Convention(.1))
        self.assertEqual(len(rows), 2)
        self.assertAlmostEqual(npv, 0, places=8)
    def test_07_csv_json_audit(self):
        data = "year,amount\n0,-1000\n1,1100\n"
        result = report(parse_cashflow_csv(data), Convention(.1))
        self.assertEqual(json.loads(json.dumps(result))["event_count"], 2)
        self.assertAlmostEqual(result["npv"], 0, places=8)
    def test_08_negative_rate(self):
        self.assertAlmostEqual(future_value(100, Convention(-.1), 2), 81)
    def test_09_zero_rate(self):
        self.assertAlmostEqual(present_value(100, Convention(0), 5), 100)
        with self.assertRaises(ValueError):
            solve_time(100, 100, Convention(0))
    def test_10_invalid_inputs(self):
        with self.assertRaises(ValueError):
            Convention(-1, 1)
        with self.assertRaises(TypeError):
            Convention(.05, True)
        with self.assertRaises(ValueError):
            future_value(100, Convention(.05), -1)
        with self.assertRaises(ValueError):
            solve_rate(100, -110, 2)
        with self.assertRaises(ValueError):
            parse_cashflow_csv("year,amount\nx,100\n")
    def test_11_same_date_netting(self):
        result = report([(0, -100), (0, 40), (0, 60)], Convention(.07))
        self.assertAlmostEqual(result["npv"], 0)
    def test_12_no_hidden_initial_cost(self):
        result = report([(1, 110)], Convention(.1))
        self.assertAlmostEqual(result["npv"], 100)

if __name__ == "__main__":
    example = "year,amount\n0,-1000\n1,400\n2,500\n3,300\n"
    print(json.dumps(report(parse_cashflow_csv(example),
                            Convention(.08, 12)), indent=2))
    unittest.main(verbosity=2)

## Operational and numerical considerations

**Precision:** \`math.log1p\` is used for small rates and \`math.fsum\` for NPV summation. Binary floats remain unsuitable for accounting-ledger rounding policies; use \`decimal.Decimal\` with a documented precision and rounding regime if exact cent-level handling is required.

**Boundaries:** A nominal periodic growth factor must remain positive. A rate of \(-100\%\) per period is excluded from the logarithmic inverse model. Rate and time solvers require two nonzero same-sign balances; a zero-rate time problem cannot identify a unique horizon.

**Timing:** Fractional years use the mathematical compound-interest extension. Real day-count conventions, holidays, settlement dates, and discrete crediting schedules require additional specifications.

**Auditability:** Every event produces its original amount, valuation year, discount factor, and discounted value. The report states the rate convention and frequency. The initial cost is entered exactly once as a negative cash flow, usually at year zero.

**Security:** CSV parsing does not execute input as code. Still, production ingestion should impose file-size, row-count, schema, and resource limits.

## Applied exercises with solutions

1. **Monthly accumulation:** 1,000 USD at 6% nominal monthly for two years. **Answer:** \(1000(1+.06/12)^{24}\approx1127.16\) USD.
2. **Annual effective rate:** Convert 6% nominal monthly. **Answer:** \((1+.06/12)^{12}-1\approx6.1678\%\).
3. **NPV:** Enter \`[(0,-1000),(1,1100)]\` at 10% effective annual. **Answer:** Approximately zero.
4. **Reverse rate:** Find the annual rate from 1,000 to 1,210 in two years. **Answer:** 10%.
5. **Reverse time:** At 10% effective annually, find the time from 1,000 to 1,210. **Answer:** Two years.
6. **Failure handling:** What should happen if a user supplies a frequency of zero? **Answer:** Reject the request with a clear validation error.
7. **Audit reconciliation:** What should the report contain for three time-zero flows of -100, +40, and +60? **Answer:** Three separate audit rows and total NPV of zero.
8. **Extension:** Design a day-count-aware input model. **Answer:** Store an explicit valuation date, payment dates, selected day-count convention, and compounding schedule; convert dates to model times only after validation.
