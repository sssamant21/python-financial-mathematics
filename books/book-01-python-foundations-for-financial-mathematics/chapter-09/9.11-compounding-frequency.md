## What changes when interest is credited more often?

Compounding means earned interest remains in the account and itself earns interest in later periods. A nominal annual quote $`j`$, convertible $`m`$ times a year, defines a periodic rate $`j/m`$. With principal $`P`$, an integer number of years $`t`$, and $`mt`$ complete compounding periods,

```math
\boxed{A(P,j,m,t)=P\left(1+\frac{j}{m}\right)^{mt}}.
```

The corresponding effective annual rate is

```math
\boxed{\operatorname{EAR}(j,m)=\left(1+\frac{j}{m}\right)^m-1}.
```

These formulas assume a fixed nominal rate, equally spaced periods, full reinvestment, and no cash flows, fees, taxes, default, or contractual posting-rounding adjustments. They are not a universal rule for fractional settlement periods.

## An original frequency comparison

Suppose 10,000 illustrative USD earns **6% nominal annually** for one complete year. Keep the nominal quote and starting balance fixed while varying only the conversion frequency.

| Frequency | $`m`$ | Effective annual rate (approx.) | End-of-year balance (USD, approx.) |
|---|---:|---:|---:|
| Annual | 1 | 6.000000% | 10,600.00 |
| Semiannual | 2 | 6.090000% | 10,609.00 |
| Quarterly | 4 | 6.136355% | 10,613.64 |
| Monthly | 12 | 6.167781% | 10,616.78 |
| Daily, 365 equal periods | 365 | 6.183131% | 10,618.31 |

The daily row is a **365-equal-period mathematical model**, not an assertion about an actual bank's day-count convention. Each added conversion period has a diminishing effect. The amount is not multiplied by the number of periods: interest is repeatedly applied to the changing balance.

For positive $`j`$, holding $`j`$ fixed while increasing $`m`$ raises the effective annual accumulation factor. This statement does not apply without qualification to negative rates or to contracts with different terms.

## Do not change two assumptions at once

If instead an **effective annual rate $`e`$** is held fixed, the equivalent nominal quote for each frequency is

```math
j_m=m\left[(1+e)^{1/m}-1\right].
```

Then every frequency produces the **same one-year growth factor** $`1+e`$, apart from floating-point rounding. Thus:

- Fixed nominal quote: more frequent compounding changes the effective annual return.
- Fixed effective annual rate: the nominal quote adjusts to frequency, preserving equivalent annual value.

The difference is essential when comparing advertised offers: frequency alone cannot rank products with different rate conventions or fees.

## Multiple years and a limiting comparison

For a complete $`t`$-year horizon, the factor is $`(1+j/m)^{mt}`$. Under the positive-rate assumptions above, the limiting value as $`m`$ grows without bound is

```math
\lim_{m\to\infty}P(1+j/m)^{mt}=Pe^{jt}.
```

This is a **mathematical limit**, not a claim that daily compounding is continuous compounding. Section 9.12 develops the continuous model separately. The limiting effective annual rate is $`e^j-1`$; the exponential's exponent is the nominal annual rate times years, not an already-converted EAR.

For the 6% example, the limiting one-year rate is approximately 6.18365465%, so the 365-period value remains below that limit.

## Financial interpretation and modeling boundaries

When comparing schedules, hold constant the nominal quote, horizon, principal, and reinvestment assumptions. Actual interest products may differ in accrual day bases, posting dates, minimum balances, rate changes, taxes, fees, and disclosure definitions. The mathematical effective annual rate here is not automatically an advertised APY or a regulated APR.

If the compounding period is monthly, the exponent must count complete months, not years. If a payment occurs mid-period, the model needs a separate stated accrual or interpolation convention. Do not silently use a fractional exponent as if every contract permits it.

## Numerically careful Python lab

Save the following as `compounding_frequency.py`. Run:

```bash
python compounding_frequency.py
python -m compileall -q compounding_frequency.py
```

The code uses `math.log1p` and `math.expm1` to preserve small-rate precision and rejects invalid frequencies, nonfinite inputs, and unsupported growth-factor boundaries. The range limit of 1,000,000 periods is a teaching implementation choice, not a financial rule. The lab accepts only nonnegative integer years and positive principal to keep the accumulation comparison explicit.

```python
"""Compounding frequency with equal periods and complete years."""
import math
from numbers import Real
import unittest


def real(value, name):
    if isinstance(value, bool) or not isinstance(value, Real):
        raise TypeError(f"{name} must be a real number")
    try:
        value = float(value)
    except OverflowError as exc:
        raise ValueError(f"{name} exceeds float range") from exc
    if not math.isfinite(value):
        raise ValueError(f"{name} must be finite")
    return value


def frequency(m):
    if isinstance(m, bool) or not isinstance(m, int):
        raise TypeError("frequency must be an integer")
    if not 1 <= m <= 1_000_000:
        raise ValueError("frequency outside supported range")
    return m


def years(t):
    if isinstance(t, bool) or not isinstance(t, int):
        raise TypeError("years must be a whole number")
    if not 0 <= t <= 1_000_000:
        raise ValueError("years outside supported range")
    return t


def log_growth(j, m):
    j = real(j, "nominal annual rate")
    m = frequency(m)
    p = j / m
    if j != 0 and p == 0:
        raise ValueError("periodic rate underflow")
    if p <= -1:
        raise ValueError("periodic growth factor must be positive")
    return m * math.log1p(p)


def effective_annual(j, m):
    g = log_growth(j, m)
    try:
        result = math.expm1(g)
    except OverflowError as exc:
        raise ValueError("effective rate overflow") from exc
    if not math.isfinite(result) or result <= -1:
        raise ValueError("effective rate outside supported range")
    return result


def future_value(principal, j, m, t):
    principal = real(principal, "principal")
    if principal <= 0:
        raise ValueError("principal must be positive")
    t = years(t)
    g = log_growth(j, m)
    try:
        result = principal * math.exp(t * g)
    except OverflowError as exc:
        raise ValueError("balance overflow") from exc
    if not math.isfinite(result) or result <= 0:
        raise ValueError("balance outside supported float range")
    return result


def nominal_for_effective(e, m):
    e = real(e, "effective annual rate")
    m = frequency(m)
    if e <= -1:
        raise ValueError("effective annual growth factor must be positive")
    result = m * math.expm1(math.log1p(e) / m)
    if not math.isfinite(result):
        raise ValueError("nominal rate outside supported range")
    return result


class FrequencyTests(unittest.TestCase):
    def test_01_annual(self):
        self.assertAlmostEqual(future_value(10000, .06, 1, 1), 10600)

    def test_02_semiannual(self):
        self.assertAlmostEqual(future_value(10000, .06, 2, 1), 10609)

    def test_03_quarterly(self):
        self.assertAlmostEqual(effective_annual(.06, 4), (1 + .06 / 4)**4 - 1)

    def test_04_monthly(self):
        self.assertAlmostEqual(effective_annual(.06, 12), .06167781186449957)

    def test_05_frequency_order(self):
        vals = [future_value(10000, .06, m, 1) for m in (1, 2, 4, 12, 365)]
        self.assertEqual(vals, sorted(vals))
        self.assertEqual(len(vals), len(set(vals)))

    def test_06_fixed_effective(self):
        for m in (1, 2, 4, 12, 365):
            j = nominal_for_effective(.06, m)
            self.assertTrue(math.isclose(effective_annual(j, m), .06,
                                         rel_tol=1e-12, abs_tol=1e-14))

    def test_07_limit_and_multiyear(self):
        daily = future_value(10000, .06, 365, 3)
        limit = 10000 * math.exp(.06 * 3)
        self.assertLess(daily, limit)
        self.assertAlmostEqual(future_value(10000, .06, 12, 3),
                               10000 * (1 + .06 / 12)**36, places=7)

    def test_08_invalid_and_zero(self):
        self.assertEqual(effective_annual(0, 12), 0)
        self.assertEqual(future_value(10000, 0, 12, 2), 10000)
        for bad in (True, 0, -1, 12.0, 1_000_001):
            with self.assertRaises((TypeError, ValueError)):
                effective_annual(.06, bad)
        for bad in (float("nan"), float("inf"), "0.06"):
            with self.assertRaises((TypeError, ValueError)):
                effective_annual(bad, 12)
        with self.assertRaises(ValueError):
            effective_annual(-12, 12)
        with self.assertRaises(ValueError):
            future_value(10000, .06, 12, -1)
        with self.assertRaises(ValueError):
            future_value(0, .06, 12, 1)


if __name__ == "__main__":
    for name, m in [("Annual", 1), ("Semiannual", 2), ("Quarterly", 4),
                    ("Monthly", 12), ("Daily (365)", 365)]:
        print(f"{name:13} EAR={effective_annual(.06, m):.8%} "
              f"balance={future_value(10000, .06, m, 1):,.2f}")
    unittest.main(verbosity=2)
```

Expected behavior: eight tests pass and compilation succeeds. The demonstration prints comparable effective rates and balances; output is formatted only after computing full-precision results. The examples are educational and do not simulate payment posting, cash-flow fees, or regulatory disclosures.

## Practice with answers

1. What is the periodic rate for 8% nominal annual, compounded quarterly? **Answer:** 2% per quarter.
2. Compute its EAR. **Answer:** $`(1.02)^4-1=8.243216\%`$.
3. Why is 6% nominal with monthly compounding different from 6% effective annual? **Answer:** The former compounds 0.5% twelve times; the latter is already the full-year rate.
4. Does doubling compounding frequency double the interest? **Answer:** No. The periodic rate shrinks as frequency increases under a fixed nominal quote.
5. How many complete compounding periods occur over three years at monthly frequency? **Answer:** 36.
6. What is held fixed when comparing annual and daily compounding in the table? **Answer:** Principal, nominal quote, one-year horizon, reinvestment, and other model assumptions.
