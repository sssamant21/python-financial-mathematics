## Learning objectives

Identify financial invariants and metamorphic relationships; state their assumptions; test cash-flow, return and portfolio properties; choose numerical tolerances; and distinguish property tests from independent model validation.

## 1. What is an invariant?

An invariant is a property expected to hold under specified assumptions. A metamorphic test changes inputs in a controlled way and checks the expected relationship between outputs. These checks are useful when an exact answer for every input is unavailable.

An invariant is only as valid as its assumptions. A test that ignores fees, timing, currency or domain boundaries may incorrectly reject a valid implementation or accept a wrong model.

## 2. Cash-flow linearity

For periodic cash flows Cₜ and a fixed annual effective rate r>−1:

**NPV(C,r)=Σₜ Cₜ/(1+r)ᵗ.**

For finite scale factor k, **NPV(kC,r)=k NPV(C,r)** in exact arithmetic, provided the rate and timing are unchanged and the model has no nonlinear fees or thresholds.

Example: [−100,110] at 10% has NPV 0; [−200,220] also has NPV 0. Use other nonzero cases too: a zero-only benchmark may not detect every defect.

## 3. Timing and zero cash flows

Appending a zero after all existing flows leaves NPV unchanged. Inserting a zero in the middle of a positional schedule delays subsequent flows and can change NPV.

At 10%, NPV([−100,110])=0, but NPV([−100,0,110])=−100+110/1.1²≈−9.0909. The inserted zero changes the payment from period 1 to period 2.

## 4. Discount monotonicity

For C>0 at a strictly positive future period, PV=C/(1+r)ⁿ decreases as the valid rate r increases. For a negative cash flow, the inequality reverses. At period zero, PV equals C and does not depend on r.

For C=100 after one period, PV at 5% is approximately 95.2381; at 6% it is approximately 94.3396.

## 5. Simple return relationships

For positive starting price P₀ and nonnegative ending price P₁:

**R=P₁/P₀−1.**

Scaling both prices by the same positive factor leaves the simple return unchanged. A price of 100→101.50 gives .015; 200→203 gives the same return. This assumes the same currency conversion and no fees or cash distributions.

A sequence of simple returns compounds: +10% then −10% yields 1.1×.9−1=−1%, not zero.

## 6. Portfolio relationships

For one-period weights wᵢ and simple returns Rᵢ, portfolio return is ΣwᵢRᵢ under the stated no-fee setup. Weights summing to one can be an invariant for a fully invested, unlevered portfolio; other strategies may have leverage, cash or short positions and require different rules.

For a positive-semidefinite covariance matrix Σ, portfolio variance wᵀΣw is nonnegative in exact arithmetic. A tiny negative computed result can arise from rounding, but a negative result should be investigated against a justified scale-aware threshold; do not silently clip an invalid matrix.

## 7. Currency and units

Consistently scaling currency units should scale monetary results but leave dimensionless returns unchanged. FX conversions require a stated quote direction and appropriate timestamps. A conversion round trip using a rounded reciprocal need not be exactly identical because of finite precision and fees.

A rate of 5% is .05 decimal; one basis point is .0001. An invariant test cannot rescue a model that consistently uses the wrong unit.

## 8. Numerical comparisons

Float invariants are approximate in computation. Select absolute and relative tolerances based on the output units and expected numerical error. Near zero, an absolute threshold is important. Reject or handle NaN and infinity explicitly.

Known-value tests and property checks complement each other. A defective function that always returns zero could pass a scaling invariant, so include independent nonzero benchmarks and negative tests.

## 9. Reference implementation

Save as `financial_invariants.py`. It tests a simplified periodic NPV, simple return and two-asset portfolio return. It is not a production valuation library.

~~~python
import math
import unittest

def finite_number(value):
    return type(value) in (int,float) and math.isfinite(value)

def npv(cashflows,rate):
    flows=list(cashflows)
    if not flows or not finite_number(rate) or rate<=-1:
        raise ValueError("nonempty flows and finite rate > -1 required")
    if not all(finite_number(x) for x in flows):
        raise ValueError("finite numeric cash flows required")
    try:
        result=math.fsum(c*math.exp(-t*math.log1p(rate))
                         for t,c in enumerate(flows))
    except OverflowError as exc:
        raise ValueError("discount calculation overflow") from exc
    if not math.isfinite(result):
        raise ValueError("nonfinite NPV")
    return result

def simple_return(start,end):
    if not all(finite_number(x) for x in (start,end)) or start<=0 or end<0:
        raise ValueError("positive start and nonnegative end required")
    return end/start-1

def portfolio_return(weights,returns):
    weights,returns=list(weights),list(returns)
    if len(weights)!=2 or len(returns)!=2:
        raise ValueError("two weights and returns required")
    if not all(finite_number(x) for x in weights+returns):
        raise ValueError("finite numeric values required")
    if any(w<0 for w in weights) or not math.isclose(sum(weights),1,rel_tol=0,abs_tol=1e-12):
        raise ValueError("nonnegative weights summing to one required")
    if any(r < -1 for r in returns):
        raise ValueError("simple returns >= -1 required")
    return math.fsum(w*r for w,r in zip(weights,returns))

class InvariantTests(unittest.TestCase):
    def test_known_nonzero_npv(self):
        self.assertTrue(math.isclose(npv([-100,110],0),10,rel_tol=0,abs_tol=1e-10))
    def test_npv_scaling(self):
        self.assertTrue(math.isclose(npv([-200,220],.05),2*npv([-100,110],.05),
                                     rel_tol=1e-12,abs_tol=1e-10))
    def test_append_zero(self):
        self.assertTrue(math.isclose(npv([-100,110],.1),npv([-100,110,0],.1),
                                     rel_tol=0,abs_tol=1e-10))
    def test_insert_zero_changes_timing(self):
        self.assertLess(npv([-100,0,110],.1),npv([-100,110],.1))
    def test_positive_flow_monotonicity(self):
        self.assertGreater(npv([0,100],.05),npv([0,100],.06))
    def test_negative_flow_direction(self):
        self.assertLess(npv([0,-100],.05),npv([0,-100],.06))
    def test_time_zero_independent_of_rate(self):
        self.assertEqual(npv([100],.05),npv([100],.1))
    def test_known_return(self):
        self.assertTrue(math.isclose(simple_return(100,101.5),.015,
                                     rel_tol=0,abs_tol=1e-12))
    def test_return_scale(self):
        self.assertTrue(math.isclose(simple_return(100,101.5),simple_return(200,203),
                                     rel_tol=0,abs_tol=1e-12))
    def test_portfolio_known(self):
        self.assertTrue(math.isclose(portfolio_return([.6,.4],[.1,-.05]),.04,
                                     rel_tol=0,abs_tol=1e-12))
    def test_invalid_weights(self):
        with self.assertRaises(ValueError): portfolio_return([.6,.5],[.1,-.05])
    def test_invalid_rate(self):
        with self.assertRaises(ValueError): npv([100],-1)
    def test_zero_start(self):
        with self.assertRaises(ValueError): simple_return(0,1)
    def test_nonfinite(self):
        with self.assertRaises(ValueError): npv([float("nan")],.05)

if __name__ == "__main__":
    unittest.main(verbosity=2)
~~~

The code uses binary floats, equal-period cash flows, long-only weights and no fees. It does not implement covariance validation, dates, taxes, FX, rebalancing or every extreme magnitude. Tolerances are illustrative and must be adapted to the real specification.

## 12. Troubleshooting

| Symptom | Possible cause | Next step |
|---|---|---|
| Scaling test fails | Fee, rounding or implementation defect | Check stated assumptions and units |
| Zero insertion changes NPV | Later cash flows shifted | Review schedule timing |
| Monotonicity fails | Negative cash flow or zero period | Check domain and inequality direction |
| Property passes despite wrong result | Test is too weak | Add an independent nonzero benchmark |
| Portfolio weights fail | Strategy differs from contract | Check leverage, cash and short rules |
| Small variance is negative | Rounding or invalid covariance | Inspect matrix and scale-aware tolerance |
