## 7.2.1 Purpose

A Series associates a one-dimensional collection of values with an index. For financial work, that index can preserve the identity of each asset while calculations, selection, and inspection operate on the values.

Section 7.1 motivated labels through a portfolio alignment problem. This section develops the Series itself: construction, metadata, explicit access, filtering, arithmetic, missingness, and copies. The examples use opening holding values at one valuation instant. They do not infer returns from a sequence of dates.

## 7.2.2 Learning Objectives

1. Construct a Series with explicit labels, numeric dtype, and names.
2. Distinguish values, index, Series name, and index name.
3. Select by label with `.loc` and by position with `.iloc`.
4. Filter using a Boolean condition derived from the same Series.
5. Explain scalar arithmetic and Series-to-Series alignment.
6. Recognize missing observations introduced by reindexing.
7. Make explicit copies at ownership boundaries.
8. Validate a small financial Series constructor and reproduce its tests.

## 7.2.3 Anatomy of a Financial Series

```python
import pandas as pd
s = pd.Series(
    [600., 300., 100.],
    index=pd.Index(['ALPHA', 'BETA', 'CASH'], name='asset'),
    dtype='float64',
    name='opening_value',
)
```

| Component | Value in this fixture | Meaning |
|---|---|---|
| Values | 600, 300, 100 | Opening market values in one common currency |
| Index | ALPHA, BETA, CASH | Ordered asset identifiers |
| dtype | float64 | Approximate floating-point numeric representation |
| Series name | opening_value | Name of the measured field |
| Index name | asset | Name of the label axis |
| shape / ndim | (3,) / 1 | Three observations on one axis |

Names describe the data, but do not enforce a financial schema. Nothing in `name='opening_value'` proves that the numbers share currency, valuation time, price conventions, or provenance. Retain those facts in the application contract.

A Series has a single dtype. That dtype can be a NumPy numeric dtype, a pandas nullable dtype, or another supported representation. An object dtype can contain heterogeneous Python objects; it does not guarantee a usable numeric column. The complete constructor below intentionally accepts a narrower subset.

## 7.2.4 Construction Choices

A list plus an explicit index pairs values and labels by position. The lengths must match. Without an explicit index, a normal list-based construction receives a default integer index, which does not encode asset identity.

A dictionary instead supplies key/value relationships:

```python
from_mapping = pd.Series({'ALPHA': 600., 'BETA': 300., 'CASH': 100.},
                         name='opening_value', dtype='float64')
requested = pd.Series({'ALPHA': 600., 'BETA': 300.},
                      index=['BETA', 'DELTA'], dtype='float64')
# requested: BETA is 300; DELTA is missing.
```

An explicit index with mapping input selects by key; it does not merely relabel the dictionary's values in positional order. A Python dictionary also cannot retain two entries with the same key as two distinct observations. Validate duplicate source records before converting them to a mapping.

A scalar can be repeated across an explicit index, for example `pd.Series(0.0, index=['ALPHA','BETA'])`. This is useful only when repeating that value is an intended assumption. It is not a repair for unknown prices or returns.

## 7.2.5 Labels and Positions Are Different Questions

For the fixture, `s.loc['BETA']` returns 300 by asset identity. `s.iloc[1]` returns 300 by its second position. They coincide here because BETA occupies that position; reordering can change the positional answer.

| Expression | Meaning | Fixture result |
|---|---|---|
| `s.loc['ALPHA']` | Value under one label | 600.0 |
| `s.loc[['CASH','ALPHA']]` | Requested label order | Series with CASH then ALPHA |
| `s.iloc[0]` | First position | 600.0 |
| `s.iloc[:2]` | First two positions | ALPHA and BETA |
| `s.loc['ALPHA':'BETA']` | Label slice on this ordered unique index | ALPHA and BETA, including both endpoints |

Label slices use the index's organization; they are not a general promise to alphabetically sort labels. Complicated or duplicate indexes require additional care. Section 7.4 develops selection in more detail.

Integer labels make the distinction especially clear:

```python
integer_labels = pd.Series([10., 20.], index=[1, 0])
# integer_labels.loc[0] == 20.0  (label 0)
# integer_labels.iloc[0] == 10.0 (first position)
```

Use explicit accessors rather than relying on ambiguous integer bracket access. A missing label requested with scalar `.loc` raises KeyError; an out-of-bounds scalar `.iloc` raises IndexError. Reindexing serves a different purpose: it can create absent labels with missing values.

## 7.2.6 Filtering, Arithmetic, and Aggregation

```python
large = s.loc[s >= 300]   # ALPHA and BETA
scaled = s * 2           # same asset labels, values doubled
complete_total = s.sum(skipna=False)
```

The mask is derived from the same Series so its labels correspond directly to the data being filtered. A mask imported from another source requires an alignment contract of its own.

Scalar multiplication changes each numeric value and keeps the index. Multiplication by two is a mathematical operation, not a currency conversion unless the scalar and contract actually represent an exchange rate.

Series arithmetic aligns labels. For `r = pd.Series([1.,2.,3.], index=['CASH','BETA','ALPHA'])`, `(s+r).loc['ALPHA']` is 603. This synthetic arithmetic illustrates alignment; adding unrelated financial measures would still be dimensionally invalid. A Series does not check units for you.

The opening-value total is 1,000 in common currency units. Summing prices across different assets would generally not have the same portfolio-value meaning. Operations must be chosen using the measured quantity, not just its dtype.

## 7.2.7 Reindexing and Missing Observations

```python
subset = s.reindex(['CASH', 'DELTA'])
# CASH = 100.0; DELTA = NaN
missing = subset.isna()
```

Reindexing establishes a requested axis. It can reorder, omit, or introduce labels. It does not prove that a newly introduced label had a zero value.

For this subset, `.size` is two, while `.count()` is one because count excludes missing observations. The default sum returns 100 by skipping the missing value. `sum(skipna=False)` returns a missing result. As in Section 7.1, validate coverage before accepting a financial total.

Use `.isna()` to detect missingness rather than comparing values with NaN. A floating Series commonly represents missingness with NaN. A nullable integer example is `pd.Series([1,pd.NA], dtype='Int64')`; the capitalized dtype name is intentional. Missing-data and conversion policies receive dedicated treatment in Sections 7.6–7.8.

## 7.2.8 Mutation and Explicit Ownership

For an intentional update to a Series you own, use one explicit assignment such as `s.loc['ALPHA'] = 650.0`. Avoid chained assignment. Selection and storage-sharing behavior can depend on context, pandas version, dtype, and Copy-on-Write settings.

For a separate working copy of this numeric Series, use `s.copy(deep=True)`. For an exported independent numeric array, use `s.to_numpy(copy=True)`. Neither array export nor a copy preserves an automatic connection to external financial metadata. Keep the labels alongside any NumPy result.

A deep pandas copy is not recursive copying of arbitrary nested Python objects in object-dtype data. This section's component avoids that ambiguity by constructing owned float64 data. It also avoids any claim that all slices are independent or all slices share storage.

## 7.2.9 Financial Lab Contract and Setup

The lab constructs nonnegative opening market values indexed by asset. Values share one currency and one valuation instant. Zero is allowed, including an entirely zero-valued holdings set: this constructor does not calculate weights or require a positive investment total. Later operations may impose stronger requirements.

Labels must be a tuple of 1–10,000 unique, trimmed, nonempty strings. Values must be a one-dimensional real numeric vector of matching length, with finite nonnegative values. Numeric strings, Boolean arrays, complex arrays, and object dtype are rejected. NumPy inference can erase Boolean identity in mixed numeric sequences; callers must validate such source records before conversion.

Values are copied to float64. This is approximate analysis data, not an exact-decimal ledger. Very large integers may lose precision on conversion, and a finite per-asset check does not guarantee every future aggregate will stay finite. ## 7.2.10 Complete Lab — series_lab.py

```python
"""Labeled opening holding values in one common currency."""
import numpy as np
import pandas as pd


def holding_values(assets, values):
    """Construct owned float64 Series from explicit ordered labels and values.

    Nonnegative opening market values, common currency, one valuation instant.
    No pricing, FX conversion, or exact-decimal ledger accounting is performed.
    """
    if not isinstance(assets, tuple) or not 1 <= len(assets) <= 10_000:
        raise ValueError('assets: tuple with 1..10000 labels required')
    if any(not isinstance(x,str) or not x or x != x.strip() for x in assets):
        raise ValueError('trimmed nonempty string labels required')
    if len(set(assets)) != len(assets):
        raise ValueError('duplicate assets')
    try:
        raw = np.asarray(values)
    except (TypeError,ValueError) as exc:
        raise ValueError('rectangular numeric vector required') from exc
    if raw.shape != (len(assets),) or raw.dtype.kind not in 'iuf':
        raise ValueError('one real numeric value per asset required')
    array = np.array(raw,dtype=np.float64,copy=True)
    if not np.isfinite(array).all() or np.any(array < 0):
        raise ValueError('finite nonnegative opening values required')
    return pd.Series(array,index=pd.Index(assets,name='asset'),name='opening_value')


def demo():
    s=holding_values(('ALPHA','BETA','CASH'),[600,300,100])
    print(s.to_string(float_format=lambda x:f'{x:.2f}'))
    print(f'ALPHA by label: {s.loc["ALPHA"]:.2f}')
    print(f'First by position: {s.iloc[0]:.2f}')
    print('At least 300: '+', '.join(s.loc[s >= 300].index))
    print(f'Complete total: {s.sum(skipna=False):.2f}')
    print('Reindex adds missing: '+str(pd.isna(s.reindex(['ALPHA','DELTA']).loc['DELTA'])))

if __name__=='__main__': demo()
```

## 7.2.11 Complete Tests — test_series_lab.py

```python
import unittest
import numpy as np
import pandas as pd
from series_lab import holding_values

class SeriesTests(unittest.TestCase):
    def fixture(self):
        return holding_values(('ALPHA','BETA','CASH'),[600,300,100])

    def test_constructor_and_metadata(self):
        s=self.fixture()
        self.assertEqual(s.shape,(3,)); self.assertEqual(s.ndim,1)
        self.assertEqual(s.dtype,np.dtype('float64'))
        self.assertEqual(s.name,'opening_value'); self.assertEqual(s.index.name,'asset')
        self.assertEqual(s.index.tolist(),['ALPHA','BETA','CASH'])

    def test_loc_iloc_and_slices(self):
        s=self.fixture()
        self.assertEqual(s.loc['BETA'],300); self.assertEqual(s.iloc[1],300)
        self.assertEqual(s.loc['ALPHA':'BETA'].index.tolist(),['ALPHA','BETA'])
        self.assertEqual(s.iloc[0:1].index.tolist(),['ALPHA'])
        with self.assertRaises(KeyError): s.loc['DELTA']
        with self.assertRaises(IndexError): s.iloc[3]

    def test_integer_labels(self):
        s=pd.Series([10.,20.],index=[1,0])
        self.assertEqual(s.loc[0],20); self.assertEqual(s.iloc[0],10)

    def test_mask_and_arithmetic(self):
        s=self.fixture()
        self.assertEqual(s.loc[s>=300].index.tolist(),['ALPHA','BETA'])
        pd.testing.assert_index_equal((s*2).index,s.index)
        self.assertEqual((s*2).loc['ALPHA'],1200)
        r=pd.Series([1.,2.,3.],index=['CASH','BETA','ALPHA'])
        self.assertEqual((s+r).loc['ALPHA'],603)
        self.assertEqual(s.sum(skipna=False),1000)

    def test_reindex_and_missing(self):
        s=self.fixture().reindex(['CASH','DELTA'])
        self.assertEqual(s.loc['CASH'],100); self.assertTrue(s.isna().loc['DELTA'])
        self.assertEqual(s.size,2); self.assertEqual(s.count(),1)
        self.assertTrue(pd.isna(s.sum(skipna=False)))
        self.assertEqual(s.sum(),100)
        nullable=pd.Series([1,pd.NA],dtype='Int64')
        self.assertEqual(str(nullable.dtype),'Int64')
        self.assertTrue(nullable.isna().iloc[1])

    def test_invalid_labels(self):
        for a in [(),('A','A'),(' A','B'),('A',1),['A','B']]:
            with self.subTest(a=a),self.assertRaises(ValueError): holding_values(a,[1,2])

    def test_invalid_values(self):
        for v in [[1],[[1,2]],[1,-2],[1,np.nan],[np.inf,2],['1','2'],[True,False],[1j,2]]:
            with self.subTest(v=v),self.assertRaises(ValueError): holding_values(('A','B'),v)
        self.assertEqual(holding_values(('A',),[0]).iloc[0],0)

    def test_owned_copy_and_explicit_update(self):
        a=np.array([600.,300.,100.]); s=holding_values(('ALPHA','BETA','CASH'),a)
        a[0]=0; self.assertEqual(s.loc['ALPHA'],600)
        other=s.copy(deep=True); other.loc['ALPHA']=650
        self.assertEqual(s.loc['ALPHA'],600)
        exported=s.to_numpy(copy=True); exported[0]=99
        self.assertEqual(s.loc['ALPHA'],600)

if __name__=='__main__': unittest.main()
```

## 7.2.13 Troubleshooting

| Symptom | Explanation | Action |
|---|---|---|
| Label lookup raises KeyError | Identifier is absent | Inspect the index and source coverage |
| First item differs from label 0 | Integer label and position differ | Use `.loc` and `.iloc` explicitly |
| New NaN after reindex | Requested identifier was absent | Check expected asset coverage |
| Size differs from count | Missing observations occupy slots | Inspect `.isna()` before aggregating |
| Numeric constructor rejects strings | Parsing is outside this contract | Validate and convert at ingestion |
| Updating a copy has no effect on the original | Explicit copy owns its working data | Return the intended result rather than assuming propagation |
| Total looks plausible despite gaps | Default aggregation skipped missing values | Require completeness and choose aggregation policy explicitly |
