## 7.13.1 Purpose

Resampling groups observations into time intervals or changes the observation grid. A financial resampling rule must specify both interval membership and the meaning of each aggregated field. Summing prices, treating an empty interval as zero volume, or confusing a bin label with a price timestamp can produce plausible but misleading results.

This section constructs half-hour observed-event bars for one synthetic instrument. It specifies the UTC grid, interval closure, labels, reporting horizon and empty-bin policy. The output summarizes supplied events; it does not certify that a market-data feed was complete.

## 7.13.2 Learning Objectives

1. Distinguish downsampling, upsampling and grid selection.
2. Specify rule, origin, closed and label deliberately.
3. Aggregate prices as OHLC and event volumes as sums.
4. Preserve empty bins without inventing prices or observed volume.
5. Include leading and trailing reporting bins from an explicit horizon.
6. Reconcile input event counts and volume with output bins.
7. Distinguish bar labels from information-availability times.
8. Test exact boundaries, ordering, time zones and missing intervals.

## 7.13.3 Synthetic Event Contract

Each input row represents one supplied trade event for one instrument, with a price and event volume. Prices share one currency/per-unit convention; volumes share one unit convention. Volume is the amount associated with that event, not a cumulative exchange counter. There are no corporate-action adjustments, FX conversions or portfolio calculations.

| UTC event time | Price | Event volume |
|---|---:|---:|
| 14:00 | 100 | 10 |
| 14:29 | 102 | 20 |
| 14:30 | 101 | 5 |
| 15:45 | 103 | 7 |

All timestamps are on 2026-01-30. The reporting horizon is [14:00 UTC,16:00 UTC), divided into four half-hour intervals. Supplied events are complete numeric records, but the example does not claim every actual market event was captured.

The teaching contract requires unique instants. Real trade feeds can have multiple events at the same timestamp; those need event identifiers or a documented within-timestamp sequence to determine open and close. Do not delete legitimate trades solely to satisfy this simplified key policy.

## 7.13.4 Downsampling and Field Meaning

Downsampling aggregates more detailed observations into coarser intervals. For each nonempty interval:

- Open is the first supplied event price in chronological order.
- High and low are the maximum and minimum supplied prices.
- Close is the last supplied event price.
- Volume is the sum of supplied event volumes.
- Event count is the number of supplied records.

The first interval contains prices 100 and 102, so OHLC is [100,102,100,102] and volume is 30. A price sum of 202 has no role as a bar close. A simple mean price would be an event-weighted arithmetic mean, not automatically a time-weighted mean or volume-weighted average price.

If input volume were a cumulative counter, summing it would overcount. A different field contract would first need increments, reset handling and ordering checks. Resampling cannot discover those semantics from the column name.

## 7.13.5 Interval Membership and Labels

The lab uses:

```python
grouped = table.resample('30min', closed='left', label='right', origin='epoch')
```

| Setting | Meaning in this UTC lab |
|---|---|
| 30min | Fixed half-hour bin width |
| origin='epoch' | Grid anchored to the Unix epoch |
| closed='left' | Start included, end excluded |
| label='right' | Output index shows interval end |

An event at 14:30 belongs to [14:30,15:00), whose label is 15:00. It does not belong to the bar labeled 14:30. Changing label alone changes how a bin is named, not which endpoint is included; closed controls membership.

The reporting start and end must both lie on UTC half hours. All supplied events must be within the half-open reporting horizon. An event exactly at end is rejected instead of silently being placed outside the requested report.

Right labeling is an explicit reporting choice. A bar labeled 15:00 summarizes events before 15:00 under this contract; the label is not the actual timestamp of its close observation. It also does not prove that the completed aggregate was available at 15:00 to a live or historical strategy.

## 7.13.6 Empty Bins and Coverage

No events were supplied for [15:00,15:30). Its event_count is zero and has_observations is false. OHLC and volume remain NaN.

```python
result['volume'] = grouped['volume'].sum(min_count=1)
```

The minimum-count policy prevents an empty volume group from being reported as an observed zero. A nonempty interval whose supplied events all have zero volume remains a known zero-volume group. Those states are deliberately different.

An empty bin can mean no trades, missing feed records, a closed market or another operational condition. Without independent completeness evidence, the lab does not decide which interpretation applies. A nonempty bin is also not proof of complete coverage; one event can be present while others are missing.

Reindexing to the explicit horizon adds leading and trailing bins that might not occur in the resampler's data-driven span. Only event_count is filled with zero there, because it counts supplied records. Observed financial measures are not forward filled or zero filled.

## 7.13.7 Upsampling and asfreq

Upsampling creates a finer observation grid. It does not create new market observations. Filling or interpolation then adds assumptions, as discussed in Section 7.7.

`asfreq` selects or conforms observations to a frequency without performing OHLC aggregation. For this fixture, the exact 14:00 event price is 100, while the half-hour close is 102 from the 14:29 event. Those results answer different questions.

Calling asfreq on an irregular event stream can omit off-grid observations from the returned grid. Do not interpret that as a completed bar or evidence that intervening prices were constant. The test explicitly contrasts the two mechanisms.

## 7.13.8 UTC Grids and Trading Calendars

The component normalizes an aware DatetimeIndex to UTC before sorting and resampling. Equivalent instants displayed in New York time produce the same UTC bars. Naive timestamps, NaT and duplicate instants are rejected.

These bins are fixed elapsed UTC intervals, not exchange sessions. A local trading day can cross an offset transition, contain a holiday or have an early close. Daily/monthly calendar resampling also uses different offsets and may have different defaults. Do not carry this half-hour setup into a venue-specific session report without an explicit calendar and boundary policy.

Resampling combines time and aggregation. It does not establish that observations share the same instrument, price adjustment policy or information-availability timestamp. Those are preconditions of the single-instrument source.

## 7.13.9 Validation and Reconciliation

The source DataFrame has exactly price and volume columns with 1–10,000 events. Numeric fields must use ordinary NumPy-backed real numeric dtypes and contain finite nonnegative values. The horizon is positive, at most one day, and aligned to the fixed grid, bounding output to at most 48 bins.

All input events must fit the horizon. Values are copied to float64, records sorted together by their UTC index, and nonfinite observed aggregates rejected. Float64 remains approximate; very large integer conversion can lose precision, and numerical scale matters when comparing volume totals. The limits bound the teaching workload rather than guaranteeing peak process memory.

Count conservation requires output event_count sum to equal the input event count. With all supplied volumes observed and every event assigned once, the summed observed bin volumes agree with the input sum. The independent loop test selects each interval by explicit >= start and < end conditions and checks its count and last price.

Do not sum close prices as a conservation check: prices are observations, not additive flows. Similarly, event-count reconciliation establishes assignment of supplied records, not completeness of the upstream feed.

## 7.13.11 Complete Lab — resampling.py

```python
"""Observed-event bars, not a certification of exchange-feed completeness."""
import numpy as np
import pandas as pd


def bars(raw, *, start, end):
    """Aggregate one instrument's supplied trade events in [start,end).

    Fixed 30-minute UTC bins, left-closed/right-labeled, epoch aligned.
    Price currency/unit and volume units are consistent across events.
    """
    for stamp in (start,end):
        if not isinstance(stamp,pd.Timestamp) or pd.isna(stamp) or stamp.tz is None:
            raise ValueError('aware Timestamp boundaries required')
    start=start.tz_convert('UTC'); end=end.tz_convert('UTC')
    if start!=start.floor('30min') or end!=end.floor('30min'):
        raise ValueError('boundaries must lie on UTC half hours')
    if not pd.Timedelta(0)<end-start<=pd.Timedelta(days=1):
        raise ValueError('positive horizon of at most one day required')
    if not isinstance(raw,pd.DataFrame) or not 1<=len(raw)<=10_000:
        raise ValueError('DataFrame with 1..10000 events required')
    if not raw.columns.is_unique or raw.columns.tolist()!=['price','volume']:
        raise ValueError('exact price, volume columns required')
    if not isinstance(raw.index,pd.DatetimeIndex) or raw.index.tz is None or raw.index.hasnans:
        raise ValueError('nonmissing aware DatetimeIndex required')
    t=raw.copy(deep=True); t.index=t.index.tz_convert('UTC')
    if not t.index.is_unique: raise ValueError('unique event instants required')
    if not ((t.index>=start)&(t.index<end)).all():
        raise ValueError('every supplied event must be inside the horizon')
    for c in ('price','volume'):
        if not isinstance(t[c].dtype,np.dtype) or t[c].dtype.kind not in 'iuf':
            raise ValueError('ordinary real numeric columns required')
        t[c]=t[c].astype('float64')
        if not np.isfinite(t[c].to_numpy()).all() or (t[c]<0).any():
            raise ValueError('complete finite nonnegative observations required')
    t=t.sort_index()
    grouped=t.resample('30min',closed='left',label='right',origin='epoch')
    result=grouped['price'].ohlc()
    result['volume']=grouped['volume'].sum(min_count=1)
    result['event_count']=grouped.size()
    expected=pd.date_range(start+pd.Timedelta(minutes=30),end,freq='30min')
    result=result.reindex(expected)
    result.index.name='interval_end'
    result['event_count']=result['event_count'].fillna(0).astype('int64')
    result['has_observations']=result['event_count']>0
    observed=result['has_observations']
    if not np.isfinite(result.loc[observed,['open','high','low','close','volume']].to_numpy()).all():
        raise ValueError('nonfinite aggregate')
    return result


def fixture():
    index=pd.to_datetime(['2026-01-30T14:00:00Z','2026-01-30T14:29:00Z',
                          '2026-01-30T14:30:00Z','2026-01-30T15:45:00Z'])
    return pd.DataFrame({'price':[100.,102.,101.,103.],'volume':[10.,20.,5.,7.]},index=index)

if __name__=='__main__':
    result=bars(fixture(),start=pd.Timestamp('2026-01-30T14:00:00Z'),
                end=pd.Timestamp('2026-01-30T16:00:00Z'))
    print(result.to_string())
    print(f'Events accounted for: {result["event_count"].sum()}')
```

## 7.13.12 Complete Tests — test_resampling.py

```python
import unittest
import numpy as np
import pandas as pd
from resampling import bars,fixture

START=pd.Timestamp('2026-01-30T14:00:00Z'); END=START+pd.Timedelta(hours=2)
class BarTests(unittest.TestCase):
    def run_bars(self,raw=None,**changes):
        return bars(fixture() if raw is None else raw,start=changes.get('start',START),end=changes.get('end',END))

    def test_known_bars(self):
        r=self.run_bars()
        self.assertEqual(r.iloc[0][['open','high','low','close','volume']].tolist(),[100,102,100,102,30])
        self.assertEqual(r['event_count'].tolist(),[2,1,0,1])
        self.assertEqual(r.loc[START+pd.Timedelta(hours=1),'close'],101)

    def test_empty_bin_unknown_values(self):
        r=self.run_bars(); empty=r.iloc[2]
        self.assertFalse(empty['has_observations'])
        self.assertTrue(empty[['open','high','low','close','volume']].isna().all())

    def test_conservation_and_scalar_oracle(self):
        raw=fixture(); r=self.run_bars()
        self.assertEqual(int(r['event_count'].sum()),len(raw))
        self.assertEqual(r['volume'].sum(min_count=1),raw['volume'].sum())
        for label,row in r.iterrows():
            subset=raw.loc[(raw.index>=label-pd.Timedelta(minutes=30))&(raw.index<label)]
            self.assertEqual(row['event_count'],len(subset))
            if len(subset): self.assertEqual(row['close'],subset['price'].tolist()[-1])

    def test_horizon_boundaries_and_leading_empty(self):
        raw=fixture(); extra=raw.iloc[[0]].copy(); extra.index=pd.DatetimeIndex([END])
        with self.assertRaises(ValueError): self.run_bars(pd.concat([raw,extra]))
        r=self.run_bars(raw.iloc[2:]); self.assertEqual(r.iloc[0]['event_count'],0)
        self.assertTrue(pd.isna(r.iloc[0]['volume']))

    def test_invalid_time_contract(self):
        for changes in [dict(start=START.tz_localize(None)),dict(end=START),
                        dict(start=START+pd.Timedelta(minutes=1)),dict(end=START+pd.Timedelta(days=2))]:
            with self.assertRaises(ValueError): self.run_bars(**changes)
        raw=fixture(); raw.index=raw.index.tz_localize(None)
        with self.assertRaises(ValueError): self.run_bars(raw)
        with self.assertRaises(ValueError): self.run_bars(pd.concat([fixture(),fixture().iloc[[0]]]))

    def test_invalid_values_and_zero(self):
        for v in [np.nan,np.inf,-1]:
            raw=fixture(); raw.iloc[0,0]=v
            with self.assertRaises(ValueError): self.run_bars(raw)
        raw=fixture(); raw['volume']=0.
        self.assertEqual(self.run_bars(raw).iloc[0]['volume'],0)
        self.assertTrue(pd.isna(self.run_bars(raw).iloc[2]['volume']))

    def test_order_zone_and_source(self):
        raw=fixture(); before=raw.copy(deep=True); a=self.run_bars(raw)
        b=self.run_bars(raw.iloc[::-1].tz_convert('America/New_York'))
        pd.testing.assert_frame_equal(a,b)
        a.iloc[0,0]=0; pd.testing.assert_frame_equal(raw,before)

    def test_asfreq_is_not_aggregation(self):
        raw=fixture()
        sampled=raw['price'].asfreq('30min')
        self.assertEqual(sampled.iloc[0],100)
        self.assertEqual(self.run_bars().iloc[0]['close'],102)
        self.assertEqual(raw['volume'].resample('30min').sum().iloc[2],0)
        self.assertTrue(pd.isna(raw['volume'].resample('30min').sum(min_count=1).iloc[2]))

if __name__=='__main__': unittest.main()
```

## 7.13.14 Troubleshooting and Exercises

| Symptom | Likely cause | Action |
|---|---|---|
| Boundary event appears in unexpected bar | closed and label were confused | State interval membership separately from output naming |
| Empty volume reports zero | Default sum used min_count=0 | Preserve unknown volume with the chosen minimum-count policy |
| Leading report bins are absent | Output span inferred only from events | Reindex to an independently specified horizon |
| Close differs from exact grid price | Aggregation and asfreq answer different questions | Choose the operation required by the contract |
| High/low contradict expectations | Wrong instrument mix, order or price convention | Validate source identity and units before resampling |
| Bar appears usable before its inputs arrived | Reporting label mistaken for availability | Preserve publication/ingestion times in the wider workflow |

1. Verify the first bin's OHLC and volume by hand.
2. Explain why the 14:30 event belongs to the bin labeled 15:00.
3. Remove the first two events and inspect the newly visible leading empty bin.
4. Set all supplied volumes to zero and distinguish observed zero from the empty bin's NaN.
5. Add an event exactly at reporting end and explain the rejection.
6. Contrast asfreq with the bar close for the first interval.
7. Design a multiple-events-per-timestamp key and deterministic within-time ordering policy.
8. List calendar and feed-completeness evidence required before treating an empty interval as confirmed no trading.
