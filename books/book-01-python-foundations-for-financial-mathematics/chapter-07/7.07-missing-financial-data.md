## 7.7.1 Purpose

A missing observation is an unknown input, not an observed zero. In financial calculations, substituting zero, dropping rows, or carrying a previous quote forward can change the economic question being answered.

This section treats missingness as both a representation problem and a coverage problem. A complete-looking table can omit an entire asset, while a labeled row can exist with an unknown return. The lab reports both conditions, retains the expected asset population, and withholds a portfolio total until all required returns are observed.

## 7.7.2 Learning Objectives

1. Detect missing values with `isna` and `notna` across pandas representations.
2. Distinguish missing cells, absent records, zero observations and invalid nonfinite values.
3. Explain how default aggregation can hide incomplete coverage.
4. Separate partial contributions from complete portfolio performance.
5. Describe the assumptions introduced by dropping, zero filling and renormalization.
6. Recognize stale-price and future-information risks in temporal filling.
7. Define an explicit unknown-condition policy for nullable Booleans.
8. Reproduce an executable coverage assessment and its tests.

## 7.7.3 Representation Is Not Meaning

| Representation or state | Example | Required interpretation |
|---|---|---|
| NaN | Missing floating return | Unknown numeric observation under the field contract |
| pd.NA | Missing nullable integer or Boolean | Unknown value; type can remain nullable |
| NaT | Missing datetime observation | Missing temporal value |
| None | Missing object value in many pandas contexts | Inspect dtype and source contract |
| Absent row | No record for BETA | Requires an external expected population to detect |
| Observed zero | Return 0.0 | Known unchanged price over the specified interval |
| Infinity | Invalid return np.inf | Nonfinite numerical value; not an approved missing return |

Use `.isna()` or `.notna()` rather than equality with a sentinel. `np.nan == np.nan` is false; comparison with pd.NA can propagate an unknown result. `bool(pd.NA)` is ambiguous and raises TypeError.

An empty string or literal text NA is not inherently missing under every contract. Section 7.5 deliberately preserved NA as an asset identifier. Normalize documented source null tokens by field at ingestion; do not apply one global replacement to identifiers and numeric fields alike.

The lab accepts ordinary NumPy-backed real numeric Series. Missing numeric observations are represented by NaN after conversion to float64. It rejects pandas extension dtypes at this narrow boundary; that restriction does not mean nullable types are unsuitable in general.

## 7.7.4 Missing Cells and Missing Records

Suppose expected opening weights are ALPHA 0.6, BETA 0.3 and CASH 0.1. Returns arrive only for ALPHA and CASH. Counting missing cells in that two-row source alone finds no NaN, yet BETA is absent.

The expected population comes from the validated weight index. Reindexing returns to that index makes the absent observation visible. The report separately records:

- `absent_record`: the asset identifier was not present in the returns input.
- `missing_return`: the aligned asset return is unknown, whether its source row was absent or its value was NaN.

These flags diagnose structure, not the operational root cause. A missing quote, suspended trading, a failed feed or an unavailable observation cannot be inferred merely from NaN. Preserve source reason codes and availability timestamps when a wider workflow provides them.

Unexpected return identifiers are rejected rather than silently discarded. Duplicate keys are rejected because the one-return-per-asset contract would otherwise be ambiguous.

## 7.7.5 Financial Fixture and Alternative Answers

Use common-interval, common-currency, long-only opening weights. There are no flows, distributions, fees, FX changes or rebalancing. Returns are simple price returns. The synthetic CASH identifier has no special rules.

| Asset | Opening weight | Complete return | Incomplete input |
|---|---:|---:|---|
| ALPHA | 0.60 | 0.10 | 0.10 |
| BETA | 0.30 | −0.05 | Absent |
| CASH | 0.10 | 0.00 | 0.00 |

Complete portfolio return is 0.6×0.1 + 0.3×(−0.05) + 0.1×0 = 0.045, or 4.50%.

For the incomplete input, observed contributions sum to 0.06. That is a partial observed contribution, not complete portfolio performance. Filling BETA's return with zero also yields 6.00%, but adds an unsupported economic assumption. Dropping BETA and renormalizing the remaining opening weights gives 0.06/0.70, approximately 8.5714%, which describes a different set of exposures.

The lab publishes none of these alternatives as the portfolio total. It returns `None` and coverage evidence until every expected return is observed. Its strict policy also blocks a missing return on a zero-weight asset. A different policy may exempt zero exposures, but that exception must be specified and tested, not inferred from missing arithmetic.

## 7.7.6 Aggregation Defaults and Completeness

```python
partial = pd.Series([0.06, float('nan'), 0.0])
partial.sum()                 # 0.06: missing contribution skipped
partial.sum(skipna=False)     # nan
partial.sum(min_count=1)      # 0.06: one observation is enough
```

`min_count=1` prevents an all-missing sum from becoming zero, but does not require every expected asset. The default sum of an all-NaN floating Series is zero; this is not evidence of a zero portfolio result.

For a known nonempty aligned population, min_count equal to the expected count can enforce a numerical observation threshold. It still does not validate keys, duplicates, interval consistency or weights. Establish identity and coverage before aggregating.

The lab returns explicit counts and a complete flag. A report displaying only the observed total conceals essential context. Even a high percentage of available records can omit a large exposure. Record coverage and exposure coverage are different measures; the lab does not claim they are interchangeable.

## 7.7.7 Dropping and Filling Are Policies

`dropna()` removes observations under its selected axis and field rules. That can be useful for a defined analysis sample but changes the retained population. Deleting incomplete assets can bias portfolio or multi-asset comparisons, especially when missingness relates to difficult market conditions.

`fillna(0)` is appropriate only if the field's meaning and evidence establish zero. An unknown price, unknown return and unknown position size are not interchangeable cases. Preserve an imputation flag and original observation when applying an approved transformation.

`ffill()` carries an earlier observation into a later row in the current order. It does not check chronological sorting, trading calendars, quote age or instrument identity. A limit such as `limit=1` bounds consecutive rows filled, not elapsed time. Forward filling a quote assumes that carrying that quote is permitted; it does not establish an observed trade at the later time.

`bfill()` uses a later observation. In a historical decision simulation, that later information may not have been available at the earlier decision time. Interpolation can also use future observations. Do not use such transformations in a backtest without an explicit information-availability contract.

A price sequence [100, NaN, 110] illustrates the difference: forward fill inserts 100; backward fill inserts 110. The test demonstrates mechanics, not an approved financial filling policy. Date and time indexes and return transformations receive dedicated treatment later in the chapter.

## 7.7.8 Lab Contract and Setup

Weights are a nonempty Series of finite nonnegative ordinary numeric values, summing to one within absolute tolerance 1e-12. Returns are another ordinary numeric Series with zero or more supplied records. Each axis is a unique flat index of trimmed nonempty string identifiers, bounded to 10,000 elements.

Return identifiers must be a subset of expected weight identifiers. NaN is allowed for unknown returns. Observed returns must be finite and at least −1. Returned asset order follows the weights. Inputs are copied to float64. The code does not parse source text, validate currency/time metadata, fill gaps, drop expected assets or renormalize weights.

The summary reports expected, observed, missing and absent counts. The total is either a finite complete portfolio return or Python None. The counts refer to the expected population after alignment, rather than simply the number of source rows.

## 7.7.9 Complete Assessment — missingness.py

```python
"""Coverage-first single-interval portfolio-return assessment."""
import numpy as np
import pandas as pd


def assess(weights, returns):
    """Opening long-only weights; returns may be missing or absent by asset.

    No flows, fees, distributions, FX or rebalancing. Missing any expected
    asset return blocks the total, including a missing zero-weight return.
    """
    for value,name in [(weights,'weights'),(returns,'returns')]:
        if not isinstance(value,pd.Series) or len(value)>10_000:
            raise ValueError(f'{name}: bounded Series required')
        if isinstance(value.index,pd.MultiIndex) or not value.index.is_unique:
            raise ValueError(f'{name}: unique flat index required')
        if any(not isinstance(x,str) or not x or x!=x.strip() for x in value.index):
            raise ValueError(f'{name}: trimmed string identifiers required')
        if not isinstance(value.dtype,np.dtype) or value.dtype.kind not in 'iuf':
            raise ValueError(f'{name}: ordinary real numeric dtype required')
    if weights.empty or weights.isna().any():
        raise ValueError('nonempty complete weights required')
    w=weights.astype('float64').copy(deep=True)
    r=returns.astype('float64').copy(deep=True)
    if not np.isfinite(w.to_numpy()).all() or (w<0).any():
        raise ValueError('finite nonnegative weights required')
    if not np.isclose(w.sum(),1,rtol=0,atol=1e-12):
        raise ValueError('opening weights must sum to one')
    if not set(r.index).issubset(set(w.index)):
        raise ValueError('unexpected return identifiers')
    observed=r.dropna()
    if not np.isfinite(observed.to_numpy()).all() or (observed < -1).any():
        raise ValueError('observed returns must be finite and at least -1')
    aligned=r.reindex(w.index)
    absent=~w.index.isin(r.index)
    missing=aligned.isna()
    product=w*aligned
    report=pd.DataFrame({'weight':w,'return':aligned,'absent_record':absent,
                         'missing_return':missing,'contribution':product})
    # No partial total or renormalization is published as portfolio performance.
    total=None
    if not missing.any():
        with np.errstate(over='raise',invalid='raise'):
            total=float(product.sum(skipna=False))
        if not np.isfinite(total):
            raise ValueError('nonfinite total')
    summary={'expected':len(w),'observed':int(aligned.notna().sum()),
             'missing':int(missing.sum()),'absent':int(absent.sum()),
             'complete':not bool(missing.any())}
    return report,total,summary


if __name__=='__main__':
    w=pd.Series([.6,.3,.1],index=['ALPHA','BETA','CASH'])
    r=pd.Series([.1,0.],index=['ALPHA','CASH'])
    report,total,summary=assess(w,r)
    print('Missing assets: '+', '.join(report.index[report['missing_return']]))
    print(f'Coverage: {summary["observed"]}/{summary["expected"]}; total={total}')
    complete=pd.Series([.1,-.05,0.],index=w.index)
    print(f'Complete portfolio price return: {assess(w,complete)[1]:.2%}')
```

## 7.7.10 Complete Tests — test_missingness.py

```python
import unittest
import numpy as np
import pandas as pd
from missingness import assess

class MissingnessTests(unittest.TestCase):
    def weights(self): return pd.Series([.6,.3,.1],index=['A','B','C'])

    def test_complete_known_answer(self):
        w=self.weights(); r=pd.Series([0.,.1,-.05],index=['C','A','B'])
        report,total,s=assess(w,r)
        self.assertAlmostEqual(total,.045); self.assertTrue(s['complete'])
        self.assertEqual(s['observed'],3); self.assertEqual(report.index.tolist(),['A','B','C'])

    def test_absent_vs_explicit_missing(self):
        w=self.weights()
        for r,absent in [(pd.Series([.1,0.],index=['A','C']),1),
                         (pd.Series([.1,np.nan,0.],index=w.index),0)]:
            report,total,s=assess(w,r)
            self.assertIsNone(total); self.assertEqual(s['missing'],1)
            self.assertEqual(s['absent'],absent); self.assertTrue(report.loc['B','missing_return'])

    def test_zero_is_observed_and_zero_weight_policy(self):
        w=self.weights(); r=pd.Series([0.,0.,0.],index=w.index)
        self.assertEqual(assess(w,r)[1],0)
        w=pd.Series([1.,0.],index=['A','B']); r=pd.Series([.1],index=['A'])
        self.assertIsNone(assess(w,r)[1])

    def test_all_missing_and_empty_returns(self):
        for r in [pd.Series(np.nan,index=self.weights().index),pd.Series(dtype='float64')]:
            _,total,s=assess(self.weights(),r)
            self.assertIsNone(total); self.assertEqual(s['observed'],0)
        a=pd.Series([np.nan,np.nan])
        self.assertEqual(a.sum(),0); self.assertTrue(pd.isna(a.sum(min_count=1)))

    def test_invalid_data(self):
        w=self.weights()
        for r in [pd.Series([.1],index=['OTHER']),pd.Series([.1,.2],index=['A','A']),
                  pd.Series([np.inf],index=['A']),pd.Series([-1.1],index=['A']),
                  pd.Series(['.1'],index=['A'])]:
            with self.assertRaises(ValueError): assess(w,r)
        with self.assertRaises(ValueError): assess(w*2,pd.Series(dtype='float64'))

    def test_skip_drop_and_renormalization(self):
        w=self.weights(); r=pd.Series([.1,0.],index=['A','C']); p=w*r
        self.assertAlmostEqual(p.sum(),.06)  # partial observed contribution
        self.assertTrue(pd.isna(p.sum(skipna=False)))
        self.assertAlmostEqual(p.sum()/w.loc[r.index].sum(),.06/.7)
        self.assertIsNone(assess(w,r)[1])

    def test_fill_and_unknown_logic(self):
        prices=pd.Series([100.,np.nan,110.])
        self.assertEqual(prices.ffill(limit=1).iloc[1],100)
        self.assertEqual(prices.bfill().iloc[1],110)
        self.assertTrue(pd.isna(pd.Series([np.nan,100.]).ffill().iloc[0]))
        flags=pd.Series([True,pd.NA],dtype='boolean')
        self.assertTrue(pd.isna(flags.iloc[1]))
        with self.assertRaises(TypeError): bool(pd.NA)

    def test_input_preservation(self):
        w=self.weights(); r=pd.Series([.1,np.nan,0.],index=w.index)
        wc=w.copy(deep=True); rc=r.copy(deep=True)
        report,_,_=assess(w,r); report.loc['A','weight']=99
        pd.testing.assert_series_equal(w,wc); pd.testing.assert_series_equal(r,rc)

if __name__=='__main__': unittest.main()
```

## 7.7.12 What the Tests Establish

| Area | Evidence |
|---|---|
| Complete result | Reordered complete return input produces 4.50% |
| Structural diagnosis | Absent record and explicit NaN both block total, with different absent counts |
| Zero policy | Observed zero is complete; unknown zero-weight return still blocks total |
| Empty/all-missing input | No portfolio total; observed count zero; default all-missing sum behavior reproduced |
| Invalid input | Unexpected/duplicate keys, infinity, below −1, text and invalid weight total rejected |
| Alternative computations | Partial sum and renormalized result differ from complete portfolio performance |
| Temporal/Boolean mechanics | Forward/backward filling and unknown Boolean ambiguity demonstrated |
| Ownership | Report mutation leaves original numeric inputs unchanged |

Float64 values remain approximate, and very small weighted contributions can underflow. Extreme observed numbers or later arithmetic require additional scale checks. The row limit is a teaching workload policy, not a process-memory guarantee. A passing coverage assessment establishes neither the truth of a reported return nor its availability at a historical decision time.

## 7.7.13 Troubleshooting and Exercises

| Symptom | Explanation | Action |
|---|---|---|
| Total is None | At least one expected return is unknown | Inspect report flags and source coverage |
| No NaN in source, but coverage is incomplete | Entire expected record is absent | Compare with an independently specified population |
| Partial sum looks like a valid return | Default aggregation skipped unknown contributions | Require complete coverage before publishing performance |
| Filled quote is old | Row-based filling did not constrain elapsed age | Define chronology and maximum quote age |
| Backtest improves after backward fill | Later information may have entered earlier observations | Audit data availability and decision timestamps |
| Unknown flag cannot become bool | pd.NA is not an observed true/false value | Apply an explicit unknown-condition policy |

1. Replace BETA's absent record with an explicit NaN. Compare missing and absent counts.
2. Supply an observed zero for every asset and explain why the total is now valid.
3. Remove all returns while retaining the expected weights. Verify the total remains None.
4. Reproduce the partial 6.00%, renormalized 8.5714%, and complete 4.50% results; state what each means.
5. Add an unexpected return identifier and explain why rejection is preferable to silent dropping.
6. Compare forward and backward fill on [100, NaN, 110]; describe what information each replacement uses.
7. Design a quote-age policy that uses timestamps rather than a number of rows. List the metadata required.
8. Propose a documented zero-weight exception and tests for it, retaining the original strict implementation for comparison.
