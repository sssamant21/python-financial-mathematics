## 7.17.1 Purpose and Deliverable

Build a reproducible local analyzer that reads synthetic multi-asset price records, validates their structure and meaning, constructs an expected observation panel, calculates aligned returns, and reports coverage beside descriptive results.

The project combines the chapter's ingestion, data types, missingness, temporal indexes, reshaping and rolling calculations. It is an analysis component with a local demonstration and acceptance suite, not a market-data client, investment strategy or portfolio-performance engine.

The delivered lab has four files: panel.py, analyzer.py, test_analyzer.py and prices.csv. Every listing is provided below. The panel module is included locally so the project runs without copying code from another lab directory or modifying import paths.

## 7.17.3 Requirements and Financial Contract

The input CSV has exactly time, asset, currency and price columns in that order. Every row represents one supplied positive price observation for one instrument at one exact UTC instant. Currency must be USD. All prices share compatible per-unit and adjustment conventions for the exercise.

The caller supplies an ordered asset tuple and an ordered aware DatetimeIndex. These define the expected universe and grid independently of the file. Unexpected assets/times and duplicate asset-time keys are rejected. Supplied invalid price cells fail ingestion; absent grid cells remain missing.

No distributions, corporate-action processing, fees, trades, external flows, FX conversion, weights or portfolio aggregation are implemented. Returns are simple price changes. USD labels are checked but not converted, and neither source accuracy nor historical availability is authenticated.

The fixture grid spans three calendar-day instants, including a weekend. It is synthetic and does not represent an exchange calendar. Users must supply a suitable observation grid for any different source contract.

## 7.17.4 Pipeline and Output Contract

| Stage | Work | Evidence/result |
|---|---|---|
| Snapshot read | Read bounded local bytes, strict UTF-8 | Exact payload used for hashing and parsing |
| Structural preflight | Exact header, bounded records, field counts | Reject malformed records rather than skip them |
| Conversion | UTC syntax, numeric grammar, currency | Typed long-form records |
| Panel construction | Composite-key validation and expected-axis reindex | Labeled prices with visible gaps |
| Returns | Adjacent grid rows, fill_method=None | Aligned return matrix |
| Description | Two-return rolling mean, per-asset coverage | Explicit warm-up and missingness |
| Summary | Complete-path linked and endpoint-only changes | Separately named measures |

The returned dictionary contains prices, returns, rolling_mean_2, coverage, summary and evidence. Outputs retain asset/time labels. The component prints a concise demonstration but does not write persistent report files or modify the source CSV.

## 7.17.5 Fixture and Expected Financial Results

ALPHA has prices 100,110,99 at all three expected times. Its adjacent returns are +10% and −10%, giving linked return −1%. Its endpoint ratio is also 99/100−1 = −1%.

BETA has prices 200 and 220 only at the first and final times. Its endpoint return is +10% over the full two-day horizon. Both adjacent one-grid-step returns are unknown because the middle price is absent. Consequently complete_path is false and linked_return is NaN.

These fields answer different questions. A known endpoint return does not supply the missing intermediate path. The analyzer reports it under a separate name rather than filling the missing grid price, dropping the intermediate timestamp or publishing a fabricated sequence.

There are no intervals with all expected assets observed at both endpoints in the incomplete fixture. Adding BETA's middle price 210 creates two complete aligned intervals, which the acceptance suite checks independently.

## 7.17.6 Minimum Observations and Summary Policy

rolling_mean_2 averages two adjacent grid-return rows, requiring both to be observed. For ALPHA, only the last row has a result, approximately zero. The first two rows are warm-up gaps. For BETA, every rolling mean remains missing. This arithmetic mean is a descriptive two-return statistic, not the cumulative return over those intervals.

A complete_path requires every expected price for that asset. Only then does the analyzer publish a linked return from the product of interval gross returns. The endpoint return requires only the first and last expected prices and is reported separately even when the intermediate path is incomplete.

Neither measure is annualized. The analyzer does not compute sample volatility, correlations or portfolio returns from unequal samples. Such extensions require their own sampling, units, missing-data and exposure contracts.

## 7.17.7 Source and Validation Policies

The CSV snapshot is bounded to 1,000,000 bytes. A strict CSV preflight requires its original header and every record's field count, with 1–100,000 records. The same decoded snapshot is then read by pandas as text with automatic missing-token interpretation disabled. Literal identifiers such as NA can therefore remain text.

Timestamp text is restricted to YYYY-MM-DDTHH:MM:SSZ. Invalid dates fail parsing. Numeric price text is an unsigned ordinary decimal of at most 64 characters; signs, exponents, grouping and blank values are rejected. The panel helper further requires finite strictly positive float64 prices and exact expected key coverage boundaries.

Expected assets are bounded to 100 and expected times to 1,000, so the grid contains at most 100,000 cells. These educational limits constrain the workflow but do not guarantee peak process memory. Input objects, decoding, CSV rows and multiple output tables all consume additional memory.

Wrong structure or invalid supplied observations raise errors. Valid source records with structural gaps instead produce a partial-coverage report. Do not catch every exception and return an apparently empty successful report. File, decoding, CSV syntax, parsing and numerical exceptions may retain their native types; caller-level handling should preserve the distinction between failed ingestion and valid incomplete coverage.

## 7.17.10 Panel Component — panel.py

This local component retains the validation and no-fill alignment policy developed in Section 7.16. Its complete listing is included so this project has no cross-directory dependencies.

```python
"""Long-to-wide price panel on an independently specified observation grid."""
import numpy as np
import pandas as pd


def panel(raw,assets,times):
    """Return wide prices, adjacent-grid returns, and complete interval flags.

    Single common currency and adjustment convention, no fills or portfolio
    weights. Missing asset-time observations remain unknown.
    """
    if not isinstance(assets,tuple) or not 1<=len(assets)<=100:
        raise ValueError('tuple of 1..100 expected assets required')
    if any(not isinstance(x,str) or not 0<len(x)<=64 or x!=x.strip() for x in assets) or len(set(assets))!=len(assets):
        raise ValueError('unique trimmed asset strings required')
    if not isinstance(times,pd.DatetimeIndex) or not 2<=len(times)<=1000:
        raise ValueError('DatetimeIndex with 2..1000 expected times required')
    if times.tz is None or times.hasnans or not times.is_unique or not times.is_monotonic_increasing:
        raise ValueError('aware ordered unique expected times required')
    grid=times.tz_convert('UTC').rename('time')
    if not isinstance(raw,pd.DataFrame) or not 1<=len(raw)<=100_000:
        raise ValueError('DataFrame with 1..100000 records required')
    if not raw.columns.is_unique or raw.columns.tolist()!=['time','asset','price']:
        raise ValueError('exact ordered long schema required')
    if not isinstance(raw['time'].dtype,pd.DatetimeTZDtype) or raw['time'].isna().any():
        raise ValueError('complete aware time column required')
    if not raw['asset'].map(lambda x:isinstance(x,str) and 0<len(x)<=64 and x==x.strip()).all():
        raise ValueError('trimmed asset strings required')
    t=raw.reset_index(drop=True).copy(deep=True); t['time']=t['time'].dt.tz_convert('UTC')
    if not t['asset'].isin(assets).all() or not t['time'].isin(grid).all():
        raise ValueError('record outside expected asset/time grid')
    if t.duplicated(['time','asset']).any(): raise ValueError('duplicate asset-time key')
    if not isinstance(t['price'].dtype,np.dtype) or t['price'].dtype.kind not in 'iuf':
        raise ValueError('ordinary real numeric prices required')
    t['price']=t['price'].astype('float64')
    if not np.isfinite(t['price'].to_numpy()).all() or (t['price']<=0).any():
        raise ValueError('supplied prices must be finite and positive')
    wide=t.pivot(index='time',columns='asset',values='price').reindex(index=grid,columns=list(assets))
    returns=wide.pct_change(periods=1,fill_method=None)
    known=wide.notna() & wide.shift(1).notna()
    observed=returns.to_numpy()[known.to_numpy()]
    if not np.isfinite(observed).all() or np.any(observed<=-1):
        raise ValueError('unsupported return numerical range')
    complete=known.all(axis=1).rename('complete_interval')
    return wide,returns,complete

```

## 7.17.11 Analyzer — analyzer.py

```python
"""Bounded local CSV to labeled coverage and price-return reports."""
import csv
import hashlib
from io import StringIO
from pathlib import Path
import re
import numpy as np
import pandas as pd
from panel import panel


def analyze(path, assets, times):
    """USD, same observation convention; strict UTC text and positive prices.

    Summaries publish linked returns only for assets with a complete grid path.
    Endpoint-only returns are reported separately and never fill missing steps.
    """
    with Path(path).open('rb') as handle: payload=handle.read(1_000_001)
    if len(payload)>1_000_000: raise ValueError('CSV byte limit exceeded')
    text=payload.decode('utf-8',errors='strict')
    rows=list(csv.reader(StringIO(text,newline=''),strict=True))
    fields=['time','asset','currency','price']
    if not rows or rows[0]!=fields or not 1<=len(rows)-1<=100_000:
        raise ValueError('exact header and bounded nonempty records required')
    if any(len(row)!=4 for row in rows[1:]): raise ValueError('record field count violation')
    raw=pd.read_csv(StringIO(text),dtype=str,keep_default_na=False,na_filter=False,
                    skip_blank_lines=False,index_col=False,on_bad_lines='error')
    if len(raw)!=len(rows)-1 or raw.columns.tolist()!=fields:
        raise ValueError('parser disagreement')
    if not raw['currency'].eq('USD').all(): raise ValueError('USD only; no FX conversion')
    stamp=r'[0-9]{4}-[0-9]{2}-[0-9]{2}T[0-9]{2}:[0-9]{2}:[0-9]{2}Z'
    if not raw['time'].map(lambda x:re.fullmatch(stamp,x) is not None).all():
        raise ValueError('exact UTC timestamp text required')
    raw['time']=pd.to_datetime(raw['time'],format='%Y-%m-%dT%H:%M:%SZ',utc=True,errors='raise')
    decimal=r'(?:0|[1-9][0-9]*)(?:\.[0-9]+)?'
    if not raw['price'].map(lambda x:len(x)<=64 and re.fullmatch(decimal,x) is not None).all():
        raise ValueError('bounded unsigned decimal price text required')
    raw['price']=pd.to_numeric(raw['price'],errors='raise').astype('float64')
    prices,returns,complete=panel(raw[['time','asset','price']],assets,times)
    rolling=returns.rolling(2,min_periods=2).mean()
    expected_known=returns.notna().rolling(2,min_periods=2).sum().eq(2)
    if not np.isfinite(rolling.to_numpy()[expected_known.to_numpy()]).all():
        raise ValueError('nonfinite rolling return summary')
    records=[]
    for asset in assets:
        p=prices[asset]; r=returns[asset]; path_complete=bool(p.notna().all())
        endpoint=np.nan; linked=np.nan
        with np.errstate(over='raise',invalid='raise',divide='raise'):
            if pd.notna(p.iloc[0]) and pd.notna(p.iloc[-1]):
                endpoint=float(p.iloc[-1]/p.iloc[0]-1)
                if not np.isfinite(endpoint) or endpoint<=-1: raise ValueError('unsupported endpoint range')
            if path_complete:
                linked=float(np.prod(1+r.iloc[1:].to_numpy())-1)
                if not np.isfinite(linked) or linked<=-1: raise ValueError('unsupported linked range')
                if not np.isclose(linked,endpoint,rtol=1e-10,atol=1e-12):
                    raise ValueError('linked/endpoint reconciliation failed')
        records.append({'asset':asset,'observed_prices':int(p.notna().sum()),
            'expected_prices':len(p),'observed_intervals':int(r.iloc[1:].notna().sum()),
            'complete_path':path_complete,'endpoint_return':endpoint,'linked_return':linked})
    summary=pd.DataFrame(records).set_index('asset')
    coverage=pd.DataFrame({'observed_prices':prices.notna().sum(axis=1),
                           'expected_prices':len(assets),'complete_interval':complete})
    evidence={'sha256':hashlib.sha256(payload).hexdigest(),'bytes':len(payload),
              'records':len(raw),'currency':'USD','python':__import__('platform').python_version(),
              'pandas':pd.__version__,'numpy':np.__version__}
    return {'prices':prices,'returns':returns,'rolling_mean_2':rolling,
             'coverage':coverage,'summary':summary,'evidence':evidence}


if __name__=='__main__':
    assets=('ALPHA','BETA')
    times=pd.date_range('2026-01-30T16:00:00Z',periods=3,freq='D')
    result=analyze(Path(__file__).with_name('prices.csv'),assets,times)
    print(result['summary'].to_string(float_format=lambda x:f'{x:.4f}'))
    print(f'Complete aligned intervals: {int(result["coverage"]["complete_interval"].sum())}')
    print(f'Source records: {result["evidence"]["records"]}')
```

## 7.17.12 Acceptance Suite — test_analyzer.py

```python
import hashlib
from pathlib import Path
import tempfile
import unittest
import numpy as np
import pandas as pd
from analyzer import analyze

TEXT=Path(__file__).with_name('prices.csv').read_text()
ASSETS=('ALPHA','BETA'); TIMES=pd.date_range('2026-01-30T16:00:00Z',periods=3,freq='D')
class AnalyzerTests(unittest.TestCase):
    def run_case(self,text=TEXT,assets=ASSETS):
        with tempfile.TemporaryDirectory() as folder:
            p=Path(folder)/'prices.csv'; p.write_bytes(text.encode())
            return analyze(p,assets,TIMES)

    def test_incomplete_known_answer(self):
        r=self.run_case(); s=r['summary']
        self.assertAlmostEqual(s.loc['ALPHA','linked_return'],-.01)
        self.assertAlmostEqual(s.loc['BETA','endpoint_return'],.1)
        self.assertTrue(pd.isna(s.loc['BETA','linked_return']))
        self.assertEqual(s['observed_intervals'].tolist(),[2,0])
        self.assertEqual(int(r['coverage']['complete_interval'].sum()),0)

    def test_complete_pipeline_and_scalar(self):
        text=TEXT+'2026-01-31T16:00:00Z,BETA,USD,210\n'; r=self.run_case(text)
        self.assertEqual(int(r['coverage']['complete_interval'].sum()),2)
        expected=[210/200-1,220/210-1]
        np.testing.assert_allclose(r['returns']['BETA'].iloc[1:],expected,rtol=0,atol=1e-12)
        self.assertAlmostEqual(r['summary'].loc['BETA','linked_return'],.1)
        self.assertAlmostEqual(r['rolling_mean_2']['ALPHA'].iloc[-1],0)

    def test_hash_and_records(self):
        e=self.run_case()['evidence']
        self.assertEqual(e['sha256'],hashlib.sha256(TEXT.encode()).hexdigest())
        self.assertEqual(e['records'],5); self.assertEqual(e['bytes'],len(TEXT.encode()))

    def test_schema_and_context_rejections(self):
        for text in [TEXT.replace('time,asset','asset,time',1),TEXT.replace('USD','EUR',1),
                     TEXT.replace(',100\n',',100,extra\n',1),TEXT+'\n']:
            with self.assertRaises(ValueError): self.run_case(text)

    def test_invalid_price_and_time(self):
        for token in ['','0','-1','NaN','1e2']:
            with self.assertRaises(ValueError): self.run_case(TEXT.replace(',100\n',f',{token}\n',1))
        with self.assertRaises(ValueError): self.run_case(TEXT.replace('2026-01-30T16:00:00Z','2026-02-30T16:00:00Z',1))
        with self.assertRaises(ValueError): self.run_case(TEXT.replace('T16:00:00Z','T16:00:00',1))

    def test_duplicate_unexpected_and_missing_universe(self):
        with self.assertRaises(ValueError): self.run_case(TEXT+TEXT.splitlines()[1]+'\n')
        with self.assertRaises(ValueError): self.run_case(TEXT.replace('ALPHA','OTHER'))
        r=self.run_case(assets=ASSETS+('CASH',))
        self.assertEqual(r['summary'].loc['CASH','observed_prices'],0)
        self.assertTrue(pd.isna(r['summary'].loc['CASH','linked_return']))

    def test_row_order_and_returned_ownership(self):
        lines=TEXT.splitlines(); reordered='\n'.join([lines[0],*lines[:0:-1]])+'\n'
        a=self.run_case(); b=self.run_case(reordered)
        pd.testing.assert_frame_equal(a['prices'],b['prices'])
        pd.testing.assert_frame_equal(a['summary'],b['summary'])
        a['prices'].iloc[0,0]=1
        self.assertEqual(self.run_case()['prices'].iloc[0,0],100)

    def test_gap_not_bridged_and_warmup(self):
        r=self.run_case()
        self.assertTrue(r['returns']['BETA'].isna().all())
        self.assertTrue(r['rolling_mean_2']['BETA'].isna().all())
        self.assertTrue(r['rolling_mean_2']['ALPHA'].iloc[:2].isna().all())

if __name__=='__main__': unittest.main()
```

## 7.17.14 Reproducibility and Numerical Limits

The evidence dictionary records SHA-256, payload byte count, parsed record count, currency and Python/pandas/NumPy versions. The hash identifies the exact bytes parsed, not source authenticity. Line endings or record ordering can change the hash while preserving normalized analytical results. Retain the original file and expected-grid configuration alongside evidence when reproducing an analysis.

The supplied tests reverse file record order and verify normalized reports agree. The source hash is expected to differ; equality of analytical output is a separate assertion from byte identity.

Float64 remains approximate. The linked/endpoint comparison uses rtol=1e-10 and atol=1e-12 as a local policy for this bounded teaching workflow. They are not universal financial acceptance thresholds. Long paths or extreme ratios can accumulate rounding, overflow, underflow or round returns to −1; unsupported results are rejected. Tiny changes and integer-to-float conversion can still lose information.

The rolling mean is checked for finite output only where two numerical interval returns are expected. Warm-up and structural missing values remain explicit. Do not round stored returns to match a formatted output before running reconciliation.
