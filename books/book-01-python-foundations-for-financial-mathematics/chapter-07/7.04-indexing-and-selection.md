## 7.4.1 Purpose

Selection defines which observations enter a calculation. In financial analysis, accidentally selecting a different asset, dropping an unknown condition, or changing row order can alter an otherwise valid formula's result.

This section develops explicit access by label, integer position, and Boolean condition. It then introduces a small checked selector that preserves requested row and column order and returns an independent numeric subset. Selection validation is separate from validating the financial meaning of the source table.

## 7.4.2 Learning Objectives

1. Choose `.loc`, `.iloc`, `.at`, or `.iat` according to the intended identity or position.
2. Predict scalar, Series, and DataFrame result dimensions.
3. Distinguish label-slice endpoints from positional-slice endpoints.
4. Combine Boolean conditions with explicit parentheses.
5. Explain label alignment versus positional Boolean indexing.
6. Recognize missing keys and unknown Boolean conditions.
7. Assign through one indexing operation and refresh derived values.
8. Test selection order, rejection policies, and numeric copy isolation.

## 7.4.4 A Choice of Accessors

For a DataFrame `t` with unique asset and column labels:

| Accessor | Meaning | Example | Result |
|---|---|---|---|
| `.loc` | Row and column labels | `t.loc['ALPHA','price']` | Scalar 100 |
| `.iloc` | Integer row and column positions | `t.iloc[0,1]` | Scalar 100 in the supplied order |
| `.at` | One labeled cell | `t.at['ALPHA','quantity']` | Scalar 6 |
| `.iat` | One positional cell | `t.iat[0,0]` | Scalar 6 in the supplied order |

A label such as integer 0 is still a label to `.loc`; it is not shorthand for the first position. With `pd.Series([10.,20.], index=[1,0])`, `.loc[0]` returns 20 while `.iloc[0]` returns 10.

Use `.loc` when the question is about a named asset. Use `.iloc` when the question genuinely concerns a position in a known order. Reordering can change positional answers without changing label-based answers. Neither accessor can detect a label attached incorrectly upstream.

## 7.4.5 Preserve the Intended Dimensions

| Expression | Result under unique axes |
|---|---|
| `t.loc['ALPHA','price']` | Scalar |
| `t.loc['ALPHA']` | Row Series |
| `t.loc[['ALPHA']]` | One-row DataFrame |
| `t.loc[:, 'price']` | Column Series |
| `t.loc[:, ['price']]` | One-column DataFrame |
| `t.loc[['CASH','ALPHA'], ['price','market_value']]` | Two-row, two-column DataFrame in requested order |

Lists retain an axis even when the list contains one label. This helps callers maintain a two-dimensional interface. Duplicate labels can change expected behavior, so the helper below rejects duplicates in both table axes and requests.

Do not assume that square brackets have one universal meaning across pandas objects. Explicit two-axis selection makes the intended rows and columns easier to inspect.

## 7.4.6 Slices, Bounds, and Absent Keys

For the fixture's ordered unique index, `t.loc['ALPHA':'BETA']` includes ALPHA and BETA. Label slices include matching endpoints. This does not mean pandas first sorts the index alphabetically; slicing follows the index's structure and ordering. Nonunique or more complicated indexes need additional rules.

`t.iloc[0:1]` contains only the first row because the positional stop is excluded. Positional slices tolerate out-of-bounds endpoints, so `t.iloc[:99]` returns all three rows. Scalar positional access `t.iloc[3]` raises IndexError.

An absent label in a requested label list raises KeyError. Reindexing is different: `t.reindex(['UNKNOWN'])` creates a row of missing fields. Choose deliberately between selecting required existing keys and constructing a requested axis that may contain missing observations.

The checked helper rejects absent requested labels with ValueError before selection. That is its application policy; it does not change the underlying pandas exception behavior.

## 7.4.7 Boolean Conditions and Alignment

```python
mask = (t['market_value'] >= 300) & (t['quantity'] > 0)
large = t.loc[mask, ['quantity', 'market_value']]
```

This selects ALPHA and BETA. Use `&` for elementwise AND, `|` for elementwise OR, and `~` for Boolean negation. Parenthesize comparisons. Python's scalar `and` and `or` do not express this vector condition.

A Boolean Series passed to `.loc` aligns by its index. Reordering this complete unique mask does not change which asset each Boolean describes. Missing or incompatible mask coverage can cause indexing errors; do not assume an arbitrary external mask is valid.

An ordinary Boolean array has no labels. With `.iloc`, its entries refer to positions and its length must fit the row axis. If converting a Boolean Series with `.to_numpy()`, first establish that its order matches the target table. Dropping labels changes the contract.

Nullable Boolean conditions can contain `pd.NA`. pandas selection treats those unknown entries as false in the illustrated nullable-mask case. That may exclude an observation without establishing that its financial condition was false. If unknown conditions are unacceptable, explicitly check `mask.isna().any()` and reject them before selection. The lab demonstrates this behavior rather than endorsing silent exclusion for every financial use case.

## 7.4.8 Assignment in One Operation

```python
scenario = t.copy(deep=True)
scenario.loc['ALPHA', 'price'] = 110.0
scenario.loc[:, 'market_value'] = scenario['quantity'] * scenario['price']
```

This creates a separate synthetic price scenario and recalculates market values. ALPHA becomes 660; the scenario total becomes 1,060. The original remains unchanged. This is a repricing illustration, not a trade execution or a performance calculation.

Avoid chained assignment such as selecting rows and then assigning through another bracket operation. Copy/view behavior and Copy-on-Write settings can affect propagation. Express the target on the intended object in one indexing operation.

A derived column is stored data, not a self-updating spreadsheet formula. Updating price alone would leave market_value stale. Recalculate affected measures and rerun the relevant financial checks before accepting a changed report.

## 7.4.10 Complete Lab — selection.py

```python
"""Explicit selection of an already validated synthetic holdings snapshot."""
import pandas as pd


def fixture():
    return pd.DataFrame({'quantity':[6.,3.,1.], 'price':[100.,100.,100.],
                         'market_value':[600.,300.,100.]},
                        index=pd.Index(['ALPHA','BETA','CASH'],name='asset'))


def axis_labels(axis, name):
    if isinstance(axis,pd.MultiIndex) or not axis.is_unique:
        raise ValueError(f'{name}: unique flat labels required')
    if any(not isinstance(x,str) or not x or x!=x.strip() for x in axis):
        raise ValueError(f'{name}: trimmed nonempty strings required')


def select_assets(table, assets, columns):
    """Return an independent ordered numeric subset; never invent absent keys.

    The caller owns numeric validation, valuation time, currency and derived
    field consistency. This helper validates selection identity, not valuation.
    """
    if not isinstance(table,pd.DataFrame) or not 1<=len(table)<=10_000:
        raise ValueError('table with 1..10000 rows required')
    if not 1<=len(table.columns)<=20:
        raise ValueError('table with 1..20 columns required')
    axis_labels(table.index,'index'); axis_labels(table.columns,'columns')
    for requested,available,name in [(assets,table.index,'assets'),
                                      (columns,table.columns,'columns')]:
        if not isinstance(requested,tuple) or not requested:
            raise ValueError(f'{name}: nonempty tuple required')
        if any(not isinstance(x,str) or not x or x!=x.strip() for x in requested):
            raise ValueError(f'{name}: invalid requested label')
        if len(set(requested))!=len(requested):
            raise ValueError(f'{name}: repeated requested label')
        if any(x not in available for x in requested):
            raise ValueError(f'{name}: unknown label')
    # Limit the ownership promise to ordinary numeric columns (no nested objects).
    import numpy as np
    if any(not isinstance(table[c].dtype,np.dtype) or table[c].dtype.kind not in 'iuf'
           for c in columns):
        raise ValueError('requested columns must have ordinary real numeric dtype')
    return table.loc[list(assets),list(columns)].copy(deep=True)


if __name__=='__main__':
    t=fixture()
    subset=select_assets(t,('CASH','ALPHA'),('price','market_value'))
    print(subset.to_string(float_format=lambda x:f'{x:.2f}'))
    mask=(t['market_value']>=300)&(t['quantity']>0)
    print('Filtered assets: '+', '.join(t.loc[mask].index))
    scenario=t.copy(deep=True)
    scenario.loc['ALPHA','price']=110.
    scenario.loc[:,'market_value']=scenario['quantity']*scenario['price']
    print(f'Synthetic repriced total: {scenario["market_value"].sum(skipna=False):.2f}')
```

## 7.4.11 Complete Tests — test_selection.py

```python
import unittest
import pandas as pd
from selection import fixture,select_assets

class SelectionTests(unittest.TestCase):
    def test_order_and_dimensions(self):
        t=fixture(); s=select_assets(t,('CASH','ALPHA'),('price','market_value'))
        self.assertEqual(s.shape,(2,2)); self.assertEqual(s.index.tolist(),['CASH','ALPHA'])
        self.assertEqual(s.columns.tolist(),['price','market_value'])
        self.assertEqual(s.loc['ALPHA','market_value'],600)
        self.assertEqual(select_assets(t,('ALPHA',),('price',)).shape,(1,1))

    def test_label_position_and_scalar_access(self):
        t=fixture()
        self.assertEqual(t.loc['BETA','price'],t.iloc[1,1])
        self.assertEqual(t.at['ALPHA','quantity'],6)
        self.assertEqual(t.iat[0,0],6)
        self.assertIsInstance(t.loc['ALPHA'],pd.Series)
        self.assertIsInstance(t.loc[['ALPHA']],pd.DataFrame)
        s=pd.Series([10.,20.],index=[1,0])
        self.assertEqual(s.loc[0],20); self.assertEqual(s.iloc[0],10)

    def test_slices_and_absent_labels(self):
        t=fixture()
        self.assertEqual(len(t.loc['ALPHA':'BETA']),2)
        self.assertEqual(len(t.iloc[0:1]),1)
        self.assertEqual(len(t.iloc[:99]),3)
        with self.assertRaises(KeyError): t.loc[['UNKNOWN']]
        with self.assertRaises(IndexError): t.iloc[3]
        self.assertTrue(t.reindex(['UNKNOWN']).isna().all().all())

    def test_masks_and_alignment(self):
        t=fixture(); mask=(t['market_value']>=300)&(t['quantity']>0)
        self.assertEqual(t.loc[mask].index.tolist(),['ALPHA','BETA'])
        shuffled=mask.reindex(['CASH','BETA','ALPHA'])
        self.assertEqual(t.loc[shuffled].index.tolist(),['ALPHA','BETA'])
        # Positional Boolean arrays have no labels; preserve their intended order.
        self.assertEqual(t.iloc[mask.to_numpy()].index.tolist(),['ALPHA','BETA'])
        unknown=pd.Series([True,pd.NA,False],index=t.index,dtype='boolean')
        self.assertEqual(t.loc[unknown].index.tolist(),['ALPHA'])

    def test_requests_rejected(self):
        t=fixture()
        for a,c in [((),('price',)),(('ALPHA','ALPHA'),('price',)),
                    (('UNKNOWN',),('price',)),(('ALPHA',),('missing',)),
                    (['ALPHA'],('price',)),(('ALPHA',),('price','price'))]:
            with self.assertRaises(ValueError): select_assets(t,a,c)

    def test_axis_and_dtype_rejections(self):
        t=fixture(); t.index=['A','A','C']
        with self.assertRaises(ValueError): select_assets(t,('A',),('price',))
        t=fixture(); t.columns=['price','price','value']
        with self.assertRaises(ValueError): select_assets(t,('ALPHA',),('price',))
        t=fixture(); t['price']=['100','100','100']
        with self.assertRaises(ValueError): select_assets(t,('ALPHA',),('price',))

    def test_copy_isolation(self):
        t=fixture(); before=t.copy(deep=True)
        s=select_assets(t,('ALPHA',),('price',)); s.loc['ALPHA','price']=0
        pd.testing.assert_frame_equal(t,before)

    def test_one_step_assignment_and_recalculation(self):
        t=fixture(); original=t.copy(deep=True); scenario=t.copy(deep=True)
        scenario.loc['ALPHA','price']=110
        scenario.loc[:,'market_value']=scenario['quantity']*scenario['price']
        self.assertEqual(scenario.loc['ALPHA','market_value'],660)
        self.assertEqual(scenario['market_value'].sum(skipna=False),1060)
        pd.testing.assert_frame_equal(t,original)

if __name__=='__main__': unittest.main()
```

## 7.4.13 Troubleshooting

| Symptom | Likely cause | Action |
|---|---|---|
| Wrong asset after reordering | Positional selection used for an identity question | Select by label |
| Result unexpectedly one-dimensional | Scalar selection removed an axis | Use a list when retaining a table axis |
| KeyError for required assets | Requested identity is absent | Check source coverage instead of replacing with zero |
| Fewer rows than expected | Nullable condition contained unknown entries | Inspect and define an unknown-condition policy |
| Mask selects wrong positions | Labels discarded before positional indexing | Establish and verify target order first |
| Assignment does not propagate | Chained operation targeted an intermediate object | Use one explicit `.loc` assignment |
| Repriced total uses old values | Derived columns were not recalculated | Recompute and validate dependent fields |
