## 7.14.1 Purpose

Rolling calculations summarize a moving subset of observations. Expanding calculations summarize the observations accumulated since the start of the supplied history. Both can produce useful descriptive features, but their meaning depends on window membership, minimum observations, time ordering and alignment.

This section constructs trailing price means and sample standard deviations for one synthetic instrument. It distinguishes observation-count windows from elapsed-time windows and shows why a current-inclusive feature is different from the previous row's feature. No trading rule or performance claim is made.

## 7.14.3 Synthetic Observation Contract

The source is one instrument's ordered price observations in a common currency/per-unit convention. The fixture has irregular observation intervals. It does not claim a complete trading schedule or a regularly sampled daily series.

| UTC time on 2026-01-30 | Price |
|---|---:|
| 14:00 | 100 |
| 14:10 | 102 |
| 14:40 | 104 |
| 15:00 | 106 |
| 15:10 | 108 |

Prices are finite and nonnegative. There are no adjustments for distributions, splits, fees or FX. This is descriptive price analysis, not an investment-return calculation. Source timestamps identify observations; they do not establish publication or historical decision-time availability.

The public function requires increasing unique aware timestamps and rejects unsorted input. It does not silently reorder records and thereby conceal an upstream ordering problem. Times are converted to UTC while preserving instants.

## 7.14.4 Rolling Versus Expanding Versus Resampling

| Operation | Population at each output | Shape/interpretation |
|---|---|---|
| Rolling three observations | Current and previous two observations | One result aligned to each source row; early warm-up gaps |
| Rolling thirty minutes | Observations within a specified elapsed interval | Variable number of rows on irregular data |
| Expanding mean | All supplied observations through current row | Growing historical sample |
| Half-hour resampling | Separate nonoverlapping bins | Aggregated reporting grid, as in Section 7.13 |

Overlapping rolling windows are not independent samples. Adjacent three-observation windows share two observations. Treating their outputs as independent evidence in later statistical analysis requires additional justification.

An expanding statistic starts at the beginning of the supplied dataset, not the instrument's entire historical life. Truncating or extending the source history changes what that statistic means.

## 7.14.5 Fixed Observation Windows

```python
window = prices.rolling(window=3, min_periods=3,
                        center=False, closed='right')
mean = window.mean()
std = window.std(ddof=1)
```

The right-aligned three-observation window includes the current row and two previous rows. At 14:40 it contains [100,102,104], yielding mean 102. The next mean is 104 from [102,104,106], followed by 106 from [104,106,108].

With min_periods=3, the first two means and standard deviations are NaN. Those are defined warm-up results, not failed source observations. Filling them with zero would create unsupported statistics. A one-row input is accepted but has no mature three-observation statistic.

The component rejects missing source prices. In general pandas usage, min_periods counts nonmissing observations. A lower threshold can therefore produce a mean from only the available records. The mechanical test uses [100,NaN,104] to show that a threshold of two produces 102 while a threshold of three produces NaN. That is not a replacement for a financial completeness policy.

## 7.14.6 Time Windows and Endpoint Closure

```python
timed = prices.rolling('30min', min_periods=1, closed='right').mean()
```

At 14:40 this window is (14:10,14:40]. It excludes the observation exactly at 14:10, so the result is 104. The three-observation mean at the same timestamp is 102. Equal-looking window labels do not imply equal populations.

A time duration window has a variable number of observations on this irregular fixture. It does not guarantee a particular sample size or complete quote coverage. Set min_periods explicitly because pandas defaults differ between integer and offset windows.

Closed controls endpoint membership. Center controls where the result is aligned; a centered window can include observations later than the result's label. This section uses center=False for trailing calculations. A centered descriptive chart must not be reused as a historical decision feature without inspecting the information it contains.

## 7.14.7 Expanding Mean

```python
historical_mean = prices.expanding(min_periods=1).mean()
```

The fixture's expanding means are [100,101,102,103,104]. The value at each row averages all supplied observations through that row with equal observation weights. It is not a time-weighted mean merely because the index contains timestamps.

Dense periods contribute more observations than sparse periods in an event-sampled series. Before interpreting an expanding price average economically, state the observation sampling rule and whether equal observation weighting is appropriate.

Do not replace this with a full-sample mean broadcast across history for a past-only feature. That would use later observations at earlier rows. The future-perturbation test verifies the chosen trailing and expanding implementation leaves earlier results unchanged when only the final price changes.

## 7.14.8 Standard Deviation and Units

For [100,102,104], the mean is 102 and squared deviations sum to 8. With ddof=1, sample variance is 8/(3−1)=4 and sample standard deviation is 2. With ddof=0, the population-style value is sqrt(8/3), approximately 1.633.

The function states ddof=1 explicitly. Neither convention is selected merely to make a result larger or smaller; choose it for the intended statistical interpretation. A constant mature price window has standard deviation zero.

These standard deviations have price units. They are not the volatility of percentage investment returns and are not annualized. Applying a square-root-of-time multiplier to irregularly sampled price-level dispersion would not establish a valid risk measure. Return transformations and later statistical chapters supply the additional context for return-based volatility.

## 7.14.9 Current-Inclusive and Prior-Row Alignment

```python
prior_mean = rolling_mean.shift(1)
```

Without a freq argument, shift(1) moves values by one row while retaining the output index. At 15:00, prior_mean is 102, the feature computed at the preceding observation at 14:40. It is not necessarily a thirty-minute delay or one trading day.

Changing the final price changes the final current-inclusive mean, while leaving its prior_mean unchanged. That is a useful check of alignment, but not proof of a valid historical strategy. The earlier observation may have arrived late, been revised or been unavailable to the decision process. Source publication/ingestion times and the decision rule still matter.

The prior_mean column is a teaching alignment example, not a recommendation to trade against a moving average. It preserves three leading NaNs because a complete previous-row three-observation statistic first exists at the fourth row.

## 7.14.11 Complete Lab — windows.py

```python
"""Trailing descriptive price summaries for one instrument."""
import numpy as np
import pandas as pd


def summaries(prices):
    """Strictly ordered, unique aware timestamps; complete nonnegative prices.

    Fixed three-observation window and expanding mean include the current row.
    prior_mean is the previous row's computed mean, not an availability proof.
    """
    if not isinstance(prices,pd.Series) or not 1<=len(prices)<=10_000:
        raise ValueError('Series with 1..10000 prices required')
    idx=prices.index
    if not isinstance(idx,pd.DatetimeIndex) or idx.tz is None or idx.hasnans:
        raise ValueError('complete aware DatetimeIndex required')
    if not idx.is_unique or not idx.is_monotonic_increasing:
        raise ValueError('strictly ordered unique instants required')
    if not isinstance(prices.dtype,np.dtype) or prices.dtype.kind not in 'iuf':
        raise ValueError('ordinary real numeric prices required')
    p=prices.astype('float64').copy(deep=True); p.index=p.index.tz_convert('UTC')
    if not np.isfinite(p.to_numpy()).all() or (p<0).any():
        raise ValueError('finite nonnegative prices required')
    rolling=p.rolling(window=3,min_periods=3,center=False,closed='right')
    result=pd.DataFrame({'price':p,'rolling_mean':rolling.mean(),
                         'rolling_std':rolling.std(ddof=1),
                         'expanding_mean':p.expanding(min_periods=1).mean()})
    result['prior_mean']=result['rolling_mean'].shift(1)
    # Warm-up NaNs are intentional; required mature values must be finite.
    for c,skip in [('rolling_mean',2),('rolling_std',2),('expanding_mean',0),('prior_mean',3)]:
        if not np.isfinite(result[c].iloc[skip:].to_numpy()).all():
            raise ValueError('nonfinite mature statistic')
    return result


def fixture():
    return pd.Series([100.,102.,104.,106.,108.],
        index=pd.to_datetime(['2026-01-30T14:00:00Z','2026-01-30T14:10:00Z',
                              '2026-01-30T14:40:00Z','2026-01-30T15:00:00Z',
                              '2026-01-30T15:10:00Z']),name='price')

if __name__=='__main__':
    print(summaries(fixture()).to_string(float_format=lambda x:f'{x:.2f}'))
```

## 7.14.12 Complete Tests — test_windows.py

```python
import unittest
import numpy as np
import pandas as pd
from windows import summaries,fixture

class WindowTests(unittest.TestCase):
    def test_known_means_and_warmup(self):
        r=summaries(fixture())
        self.assertTrue(r['rolling_mean'].iloc[:2].isna().all())
        self.assertEqual(r['rolling_mean'].iloc[2:].tolist(),[102,104,106])
        self.assertEqual(r['expanding_mean'].tolist(),[100,101,102,103,104])
        self.assertTrue(r['prior_mean'].iloc[:3].isna().all())
        self.assertEqual(r['prior_mean'].iloc[3:].tolist(),[102,104])

    def test_scalar_oracle_and_std(self):
        p=fixture(); r=summaries(p)
        for i in range(2,len(p)):
            window=p.iloc[i-2:i+1].tolist(); mean=sum(window)/3
            std=(sum((x-mean)**2 for x in window)/2)**.5
            self.assertAlmostEqual(r['rolling_mean'].iloc[i],mean)
            self.assertAlmostEqual(r['rolling_std'].iloc[i],std)
        self.assertEqual(r['rolling_std'].iloc[2:].tolist(),[2,2,2])

    def test_time_window_is_different(self):
        p=fixture(); timed=p.rolling('30min',min_periods=1,closed='right').mean()
        self.assertEqual(timed.iloc[2],104)  # (14:10,14:40] excludes 14:10
        self.assertEqual(summaries(p)['rolling_mean'].iloc[2],102)

    def test_future_perturbation_and_current_effect(self):
        p=fixture(); before=summaries(p); changed=p.copy(); changed.iloc[-1]=1000
        after=summaries(changed)
        pd.testing.assert_frame_equal(before.iloc[:-1],after.iloc[:-1])
        self.assertNotEqual(before['rolling_mean'].iloc[-1],after['rolling_mean'].iloc[-1])
        self.assertEqual(before['prior_mean'].iloc[-1],after['prior_mean'].iloc[-1])

    def test_bad_values(self):
        for values in [[100,np.nan,104,106,108],[100,np.inf,104,106,108],[-1,102,104,106,108],['1']*5]:
            with self.assertRaises(ValueError): summaries(pd.Series(values,index=fixture().index))

    def test_bad_time_axis(self):
        p=fixture()
        for bad in [p.iloc[::-1],pd.concat([p,p.iloc[:1]]),p.tz_localize(None),p.reset_index(drop=True)]:
            with self.assertRaises(ValueError): summaries(bad)

    def test_short_constant_and_source(self):
        p=fixture(); before=p.copy(deep=True); r=summaries(p.iloc[:1])
        self.assertTrue(r['rolling_mean'].isna().all()); self.assertEqual(r['expanding_mean'].iloc[0],100)
        constant=p*0; self.assertEqual(summaries(constant)['rolling_std'].iloc[-1],0)
        output=summaries(p); output.iloc[0,0]=0
        pd.testing.assert_series_equal(p,before)

    def test_missing_min_periods_and_ddof(self):
        p=pd.Series([100.,np.nan,104.])
        self.assertTrue(pd.isna(p.rolling(3,min_periods=3).mean().iloc[-1]))
        self.assertEqual(p.rolling(3,min_periods=2).mean().iloc[-1],102)
        p=pd.Series([100.,102.,104.])
        self.assertAlmostEqual(p.std(ddof=0),(8/3)**.5)
        self.assertEqual(p.std(ddof=1),2)

if __name__=='__main__': unittest.main()
```

## 7.14.14 Troubleshooting and Exercises

| Symptom | Likely cause | Action |
|---|---|---|
| Early rows are NaN | Required sample has not accumulated | Preserve warm-up policy |
| Time and row windows differ | Irregular spacing or endpoint membership | Inspect the exact observations in each window |
| Signal changes before final observation | Centered/full-sample calculation may use later data | Test perturbations and inspect alignment |
| Prior feature delay is inconsistent in minutes | Shift moved values by rows | Define elapsed-time requirements separately |
| Price std interpreted as return risk | Units were confused | Transform and validate returns before risk estimation |
| Missing source silently reduces sample | min_periods permits partial observations | Define completeness and minimum-sample policy explicitly |
