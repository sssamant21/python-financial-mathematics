## 1. Project scope

Build a transparent long-only portfolio engine that combines return, covariance, risk attribution, historical estimation, weight drift, rebalancing, position caps, and stress scenarios. This is an educational implementation, not an investment recommendation or production trading system.

## 2. Architecture and data contract

Use one consistent asset order for weights, expected returns, covariance rows and columns, and position caps. Inputs are finite decimal one-period returns, nonnegative weights summing to one, and a symmetric n×n covariance matrix. Historical observations must be aligned by timestamp and currency. A symmetric matrix with nonnegative diagonal entries is not necessarily positive semidefinite.

## 3. Portfolio expected return

For fixed weights, μp=wᵀμ. With weights [.5,.3,.2] and expected returns [.08,.05,.02], μp=.059=5.9%. This is a hypothetical expectation, not a guaranteed return.

## 4. Variance and volatility

For Σ=[[.04,.006,0],[.006,.09,0],[0,0,.0004]], portfolio variance wᵀΣw=.01+.0081+.000016+.0018=.019916, and volatility=√.019916≈14.11%.

## 5. Risk contribution attribution

Compute m=Σw=[.0218,.03,.00008]. Component variance contributions wᵢmᵢ are [.0109,.009,.000016], summing to .019916. For nonzero portfolio volatility, component volatility contributions are wᵢmᵢ/σp, and their sum equals σp.

## 6. Historical covariance estimator

For T≥2 synchronized observations, sample covariance is Σₜ(Rᵢₜ−meanᵢ)(Rⱼₜ−meanⱼ)/(T−1). The estimator uses asset series as rows. Check missing data, stale prices, corporate actions, base currency, and sample-size sensitivity.

## 7. Weight drift

For simple total returns and no external cash flows, wᵢ,new=wᵢ(1+Rᵢ)/(1+Rp). Starting [.5,.5] with returns [.1,0] yields portfolio return .05 and weights [.55/1.05,.5/1.05].

## 8. Rebalancing trades

Ignoring costs, trade dollars are NAV×(target weight−current weight). From [.4,.6] to [.5,.5] at NAV $100, buy $10 of the first asset and sell $10 of the second. One-way turnover=.1 and gross traded notional=$20.

## 9. Position constraints

A cap check verifies wᵢ≤uᵢ. Weights [.5,.3,.2] pass caps [.6,.4,.3] but violate caps [.4,.4,.3]. Full production mandates also require sector, liquidity, issuer, leverage, and other constraints.

## 10. Volatility stress

A common volatility multiplier k≥0 with unchanged correlations implies stressed covariance k²Σ. Thus portfolio variance scales by k² and volatility by k. This is a coherent scale scenario, but does not model correlation breakdown or nonlinear tail risk.

```python
import math
import unittest
from fractions import Fraction
from decimal import Decimal, localcontext

def exact(x):
    if type(x) not in (int,float):
        raise ValueError("finite int/float required; booleans excluded")
    try:
        if not math.isfinite(x):
            raise ValueError("finite int/float required")
    except OverflowError as exc:
        raise ValueError("input outside finite float range") from exc
    return Fraction(x) if type(x) is int else Fraction(str(x))

def _float(x):
    try:
        value=float(x)
    except (OverflowError,ValueError) as exc:
        raise ValueError("unreportable numeric result") from exc
    if not math.isfinite(value) or (x != 0 and value == 0):
        raise ValueError("unreportable numeric result")
    return value

def root(x):
    with localcontext() as ctx:
        ctx.prec=80
        return (Decimal(x.numerator)/Decimal(x.denominator)).sqrt()

def psd(a):
    # Exact Schur complements; a zero pivot must have an all-zero row.
    a=[row[:] for row in a]
    for k in range(len(a)):
        pivot=a[k][k]
        if pivot<0:
            return False
        if pivot==0:
            if any(a[k][j]!=0 for j in range(k+1,len(a))):
                return False
            continue
        for i in range(k+1,len(a)):
            for j in range(i,len(a)):
                a[i][j]-=a[i][k]*a[k][j]/pivot
                a[j][i]=a[i][j]
    return True

def _covariance(cov,tolerance=1e-10):
    relative=exact(tolerance)
    if relative<0 or relative>Fraction(1,10**6):
        raise ValueError("relative tolerance must be in [0,1e-6]")
    n=None
    if not isinstance(cov,(list,tuple)) or not cov:
        raise ValueError("nonempty square covariance required")
    if n is None:
        n=len(cov)
    if len(cov)!=n or any(not isinstance(row,(list,tuple)) or len(row)!=n for row in cov):
        raise ValueError("square aligned covariance required")
    a=[[exact(x) for x in row] for row in cov]
    if any(a[i][i]<0 for i in range(n)):
        raise ValueError("negative asset variance")
    scale=max(a[i][i] for i in range(n))
    tolerance=scale*relative
    for i in range(n):
        for j in range(i+1,n):
            if abs(a[i][j]-a[j][i])>max(abs(a[i][j]),abs(a[j][i]))*relative+tolerance:
                raise ValueError("covariance must be symmetric within stated tolerance")
            a[i][j]=a[j][i]=(a[i][j]+a[j][i])/2
    if any(a[i][i]==0 and any(a[i][j]!=0 for j in range(n)) for i in range(n)):
        raise ValueError("zero variance requires zero covariance row")
    shifted=[[a[i][j]+(tolerance if i==j else 0) for j in range(n)] for i in range(n)]
    if not psd(shifted):
        raise ValueError("covariance is not PSD within scale-relative tolerance")
    return a,tolerance

def _numbers(values,name):
    if not isinstance(values,(list,tuple)) or not values:
        raise ValueError(name+" must be a nonempty list/tuple")
    return [exact(x) for x in values]

def _weights(values,normalize=True):
    w=_numbers(values,"weights");budget=sum(w)
    if min(w)<0 or abs(budget-1)>Fraction(1,10**10):
        raise ValueError("long-only absolute budget tolerance 1e-10 required")
    return [x/budget for x in w] if normalize else w

def _inputs(w,mu,cov):
    w=_weights(w);mu=_numbers(mu,"means");cov,_=_covariance(cov)
    if len(w)!=len(mu) or len(w)!=len(cov):
        raise ValueError("dimensions must align")
    return w,mu,cov

def check(w,mu,cov):
    _inputs(w,mu,cov)

def _reconcile(values,total):
    try:
        summed=math.fsum(values)
    except OverflowError as exc:
        raise ValueError("reported contributions cannot reconcile") from exc
    if not math.isclose(summed,total,rel_tol=1e-10,abs_tol=0):
        raise ValueError("reported contributions lose reconciliation")

def _statistics(w,mu,cov):
    weighted=[sum(cov[i][j]*w[j] for j in range(len(w))) for i in range(len(w))]
    vc=[w[i]*weighted[i] for i in range(len(w))];variance=sum(vc)
    if variance<0:
        raise ValueError("negative exact requested quadratic variance")
    reported_variance=_float(variance);sigma=_float(root(variance))
    contribution=[_float(x) for x in vc];_reconcile(contribution,reported_variance)
    rc=None
    if variance>0:
        rc=[(-1 if x<0 else 1)*_float(root(x*x/variance)) for x in vc]
        _reconcile(rc,sigma)
    return {"expected_return":_float(sum(w[i]*mu[i] for i in range(len(w)))),
            "variance":reported_variance,"volatility":sigma,
            "variance_contributions":contribution,"volatility_contributions":rc}

def report(w,mu,cov):
    return _statistics(*_inputs(w,mu,cov))

def sample_covariance(series):
    if not isinstance(series,(list,tuple)) or not series:
        raise ValueError("asset-major common series required")
    data=[_numbers(row,"observations") for row in series];t=len(data[0])
    if t<2 or any(len(row)!=t for row in data):
        raise ValueError("aligned T>=2 required")
    avg=[sum(row)/t for row in data]
    return [[_float(sum((data[i][k]-avg[i])*(data[j][k]-avg[j]) for k in range(t))/(t-1))
             for j in range(len(data))] for i in range(len(data))]

def drift(w,returns):
    w=_weights(w);returns=_numbers(returns,"returns")
    if len(w)!=len(returns) or min(returns)<-1:
        raise ValueError("aligned simple returns >= -100% required")
    values=[w[i]*(1+returns[i]) for i in range(len(w))];total=sum(values)
    if total<=0:
        raise ValueError("NAV exhausted")
    realized=_float(sum(w[i]*returns[i] for i in range(len(w))))
    if realized==-1:
        raise ValueError("positive ending NAV cannot report total loss")
    ending=[_float(x/total) for x in values];_reconcile(ending,1.0)
    return {"portfolio_return":realized,"ending_weights":ending}

def rebalance(current,target,nav):
    a=_weights(current);b=_weights(target);nav=exact(nav)
    if len(a)!=len(b) or nav<=0:
        raise ValueError("aligned weights and positive NAV required")
    delta=[b[i]-a[i] for i in range(len(a))];trades=[nav*x for x in delta]
    gross=sum(abs(x) for x in trades);display=[_float(x) for x in trades]
    if abs(sum(Fraction(str(x)) for x in display))>Fraction(1,10**12)*gross:
        raise ValueError("reported frictionless trades lose cash reconciliation")
    return {"trades":display,"gross_traded":_float(gross),
            "one_way_turnover":_float(sum(abs(x) for x in delta)/2)}

def stress(w,mu,cov,multiplier):
    w,mu,cov=_inputs(w,mu,cov);k=exact(multiplier)
    if k<0:
        raise ValueError("nonnegative common volatility multiplier required")
    return _statistics(w,mu,[[x*k*k for x in row] for row in cov])

def within_caps(w,caps):
    w=_weights(w,normalize=False);caps=_numbers(caps,"caps")
    if len(w)!=len(caps) or any(not 0<=x<=1 for x in caps):
        raise ValueError("aligned caps in [0,1] required")
    return all(x<=cap for x,cap in zip(w,caps))

class Tests(unittest.TestCase):
    w=[.5,.3,.2]; mu=[.08,.05,.02]
    cov=[[.04,.006,0],[.006,.09,0],[0,0,.0004]]
    def test_01_mean(self):self.assertAlmostEqual(report(self.w,self.mu,self.cov)["expected_return"],.059)
    def test_02_variance(self):self.assertAlmostEqual(report(self.w,self.mu,self.cov)["variance"],.019916)
    def test_03_sd(self):self.assertAlmostEqual(report(self.w,self.mu,self.cov)["volatility"],math.sqrt(.019916))
    def test_04_vc(self):
        r=report(self.w,self.mu,self.cov)
        self.assertAlmostEqual(math.fsum(r["variance_contributions"]),r["variance"])
    def test_05_rc(self):
        r=report(self.w,self.mu,self.cov)
        self.assertAlmostEqual(math.fsum(r["volatility_contributions"]),r["volatility"])
    def test_06_sample(self):self.assertAlmostEqual(sample_covariance([[1,2,3],[2,4,6]])[0][1],2)
    def test_07_drift(self):self.assertAlmostEqual(drift([.5,.5],[.1,0])["ending_weights"][0],.55/1.05)
    def test_08_turnover(self):self.assertAlmostEqual(rebalance([.4,.6],[.5,.5],100)["one_way_turnover"],.1)
    def test_09_stress(self):
        self.assertAlmostEqual(stress(self.w,self.mu,self.cov,2)["volatility"],
                               2*report(self.w,self.mu,self.cov)["volatility"])
    def test_10_caps(self):
        self.assertTrue(within_caps(self.w,[.6,.4,.3]))
        self.assertFalse(within_caps(self.w,[.4,.4,.3]))
    def test_11_single(self):self.assertAlmostEqual(report([1],[.07],[[.04]])["volatility"],.2)
    def test_12_invalid(self):
        for fn in (lambda:report([.4,.4],[.1,.2],[[.04,0],[0,.09]]),
                   lambda:sample_covariance([[1],[2]]),
                   lambda:drift([.5,.5],[-1,-1]),
                   lambda:rebalance([.5,.5],[.5,.5],0),
                   lambda:stress(self.w,self.mu,self.cov,-1)):
            with self.assertRaises(ValueError):fn()

if __name__=="__main__":
    print(report([.5,.3,.2],[.08,.05,.02],[[.04,.006,0],[.006,.09,0],[0,0,.0004]]))
    unittest.main(verbosity=2)
```

**Validation boundary:** This remains an educational long-only engine with frictionless trades, no costs/taxes/external flows, no leveraged accounting or live market ingestion. The full covariance screen uses rational Schur complements on `covariance + delta*I`, `delta=1e-10*max(diagonal)`, following Section16.7. Negative diagonals/nonzero zero-variance rows reject; accepted within-tolerance asymmetric pairs are averaged. Requested exact negative forms reject rather than clip. This numerical screen is not exact PSD, economic-model or production certification. Stress validates the original model before scaling, so a zero multiplier cannot hide invalid covariance.

Integer/displayed-decimal rational intermediates and 80-digit Decimal roots precede finite/nonzero-preserving float reporting. Required statistics fields must all be reportable. Displayed variance and volatility contributions must reconcile within relative `1e-10`, no absolute floor, or raise `ValueError`. Zero-risk volatility attribution remains `None`, not a claim that derivatives exist there. Sample covariance is asset-major and requires at least two complete aligned observations; float rounding may affect near-singular covariance rank.

Arithmetic weights accepted within an absolute `1e-10` unit budget are normalized before calculation. Cap checking instead audits the supplied validated weights without normalization and uses strict bounds, matching Section16.13's audit convention. It also validates long-only budgets before checking caps. Drift computes weighted return directly, preserves tiny nonzero returns, and rejects positive wealth that would be reported as total loss. Frictionless trade cash sums reconcile within `1e-12` times gross dollar volume; turnover is formed from weight differences before dollar conversion, avoiding large-NAV denominator overflow.

## 17. Troubleshooting

| Symptom | Likely cause | Corrective action |
|---|---|---|
| Expected return mismatch | Weight and mean ordering differ | Align identifiers |
| Negative quadratic variance | Invalid covariance or numerical error | Independently check PSD and arithmetic |
| Risk contributions do not reconcile | Incorrect matrix multiplication | Recompute Σw |
| Historical covariance differs | Missing-data or denominator policy | Standardize aligned samples and T−1 |
| Drifted weights do not sum to one | Wrong NAV normalization | Divide by ending total value |
| Trades do not net to zero | Inconsistent budgets or cash | Reconcile frictionless self-financing trades |
| Stressed risk is inconsistent | Covariance scaled by k rather than k² | Apply coherent volatility scaling |
| Position breach missed | Misaligned caps | Verify asset order |
| Reference tests pass but risk is implausible | Model assumptions incomplete | Perform independent mathematical and economic review |
