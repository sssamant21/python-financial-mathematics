## Learning objectives

Construct covariance matrices from aligned asset returns; interpret diagonal and off-diagonal elements; distinguish sample and population conventions; evaluate symmetry, positive semidefiniteness, and estimation error; transform covariance into correlation; and use the quadratic form to measure portfolio variance.

## 1. Why covariance matrices matter

A portfolio's risk depends not only on the volatility of individual holdings but also on **how their returns move together**. Covariance quantifies joint deviations from expected returns. A covariance matrix organizes every pairwise covariance for n assets into one n×n structure.

For an asset return vector **R=(R₁,…,Rₙ)ᵀ**, define:

**Σᵢⱼ=Cov(Rᵢ,Rⱼ)=E[(Rᵢ−μᵢ)(Rⱼ−μⱼ)].**

The matrix **Σ=[Σᵢⱼ]** is the population covariance matrix, assuming the relevant moments exist.

## 2. Matrix anatomy

For three assets:

```text
         A         B         C
A   Var(A)   Cov(A,B)  Cov(A,C)
B   Cov(B,A) Var(B)    Cov(B,C)
C   Cov(C,A) Cov(C,B)  Var(C)
```

Diagonal elements are variances, **Σᵢᵢ=σᵢ²**. Off-diagonal elements are covariances. Covariance is symmetric, so **Σᵢⱼ=Σⱼᵢ**.

Covariance carries squared return units. Its numerical magnitude depends on whether returns are decimals or percentages, so never mix scales.

## 3. Sample covariance estimator

For T synchronized observations of n assets, with sample mean for asset i:

**R̄ᵢ=(1/T)ΣₜRᵢ,ₜ**,

the usual sample covariance is:

**Sᵢⱼ=[Σₜ(Rᵢ,ₜ−R̄ᵢ)(Rⱼ,ₜ−R̄ⱼ)]/(T−1)**.

The **T−1** denominator is appropriate for the usual unbiased covariance estimator under iid sampling assumptions. A descriptive population covariance of the observed dataset instead divides by **T**.

The denominator choice must be explicit; do not combine inconsistent conventions in one matrix.

## 4. Worked two-asset example

Suppose three aligned observations:

| Observation | A | B |
|---|---:|---:|
| 1 | 1 | 2 |
| 2 | 2 | 4 |
| 3 | 3 | 6 |

Means are Ā=2 and B̄=4. Deviations are A=[−1,0,1] and B=[−2,0,2].

Sample variances:

**S_AA=(1+0+1)/2=1**.

**S_BB=(4+0+4)/2=4**.

Sample covariance:

**S_AB=[(−1)(−2)+0+(1)(2)]/2=2**.

Thus:

```text
S = [[1, 2],
     [2, 4]]
```

This matrix is symmetric and positive semidefinite. It is singular because B is exactly twice A in this example.

## 5. Covariance and correlation

The Pearson correlation between two nonconstant asset returns is:

**ρᵢⱼ=Σᵢⱼ/(σᵢσⱼ)**.

In matrix form, when all standard deviations are positive:

**C=D⁻¹ΣD⁻¹**, where **D=diag(σ₁,…,σₙ)**.

For the preceding example, σ_A=1, σ_B=2, and ρ_AB=2/(1×2)=1.

A zero-variance asset has undefined Pearson correlation with other assets; do not replace that undefined result with zero.

## 6. Portfolio variance as a quadratic form

For a fixed vector of starting weights **w**, portfolio return is **Rₚ=wᵀR**. Its variance is:

**Var(Rₚ)=wᵀΣw=ΣᵢΣⱼwᵢwⱼΣᵢⱼ**.

For two assets:

**σₚ²=w₁²σ₁²+w₂²σ₂²+2w₁w₂Cov(R₁,R₂)**.

This formula is central to portfolio mathematics and will be developed in more depth in Section 16.6.

## 7. Worked portfolio variance example

Consider:

```text
Σ = [[0.04, 0.01],
     [0.01, 0.09]]
w = [0.6, 0.4]
```

Then:

**σₚ²=.6²(.04)+2(.6)(.4)(.01)+.4²(.09)**

**=.0144+.0048+.0144=.0336.**

Portfolio standard deviation is **√.0336≈.1833**, or approximately 18.33% for the return horizon used by the matrix.

This is a mathematical illustration; it is not a calibrated market risk forecast.

## 8. Symmetry and positive semidefiniteness

A valid covariance matrix is symmetric and **positive semidefinite (PSD)**:

**aᵀΣa≥0 for every real vector a**.

This property follows because aᵀΣa is the variance of a linear combination of returns.

Negative portfolio variance is mathematically impossible. A material negative quadratic form indicates invalid input, an inconsistent estimator, or a numerical defect.

A matrix can be PSD yet singular. For example, perfectly collinear asset returns produce redundant risk directions.

## 9. Rank and small samples

For T complete aligned observations, the sample covariance matrix has rank at most **min(n,T−1)**. If the number of assets n exceeds T−1, the sample matrix must be singular.

This matters for portfolio optimization, where a matrix inverse may be required. An apparently precise high-dimensional covariance estimate may be numerically unstable or impossible to invert.

Do not assume more assets automatically provide more independent information.

## 10. Missing observations and calendar alignment

Covariance requires matching return horizons and timestamps. Different exchange holidays, stale prices, currency conversion, and corporate actions can distort pairwise relationships.

**Listwise deletion** uses observations complete across all assets and retains a coherent common sample, though it can reduce sample size and introduce selection bias.

**Pairwise deletion** uses different subsets for different covariance entries and can produce a matrix that is not PSD.

Document the observation universe, date intersection, missing-data policy, and whether a covariance estimator enforces PSD.

## 11. Covariance estimation error

Historical covariance estimates can be noisy, especially with short samples or many assets. Financial correlations can also change sharply during stress.

Common approaches include:

- Historical sample covariance.
- Rolling-window covariance.
- Exponentially weighted covariance.
- Shrinkage toward a structured target.
- Factor-model covariance.
- Scenario and stress covariance estimates.

Each method trades flexibility, stability, and model assumptions. Shrinkage can improve conditioning but does not guarantee future risk accuracy.

## 12. Annualization and time scale

Under sufficiently strong assumptions, including independent daily return increments with stable covariance, annual covariance is approximately:

**Σ_annual≈252Σ_daily**.

Corresponding volatility scales by **√252**. Serial dependence, time-varying volatility, and irregular calendars can invalidate naive scaling.

For a portfolio with multiple currencies, ensure the covariance matrix and weights refer to a common base-currency return convention.

## 13. Risk interpretation

A positive covariance means the assets tend to deviate in the same direction relative to their means. A negative covariance means they tend to deviate in opposite directions.

Neither covariance nor correlation establishes causality. A low historical covariance is not a guarantee of protection during a crisis.

## 14. Python reference implementation

Save as `covariance_matrices.py`. The implementation uses only the Python standard library and includes **12 reference unit tests**. It calculates sample or population covariance, correlation from a covariance matrix, and portfolio quadratic-form variance.

Numeric policy: integers and displayed-decimal float inputs use rational intermediates; required float outputs must remain finite and preserve nonzero values or raise `ValueError`. Decimal roots use 80-digit precision. Inputs must already share asset order, units, currency and horizon; labels/timestamps are not inferred. Both estimators require at least two complete rows, even with `ddof=0`.

Both matrix consumers screen the full symmetric matrix. Symmetry tolerance is `1e-10 * max(abs(pair)) + 1e-12 * max(diagonal)`; accepted pairs are averaged. Negative diagonals and nonzero covariance rows for zero-variance assets are rejected. The PSD screen requires the matrix plus `delta * I`, where `delta=1e-12 * max(diagonal)`, to be PSD using rational Schur complements. This is a scale-relative numerical screen, not proof that a tolerated matrix is exactly PSD. Portfolio negatives no smaller than `-delta * sum(weight**2)` are reported as zero; smaller values are rejected. Correlation magnitudes exceeding one by at most `1e-12` are clipped to one; larger values are rejected. No absolute variance floor hides invalid tiny-unit matrices.

`portfolio_variance` accepts general finite signed exposures, including zero weights; it does not require a unit investment budget or validate financing/margin. Float rounding of estimated matrix entries can affect near-singular results; conditioning, high-dimensional performance and economic calibration remain outside this educational implementation.

```python
import math
import unittest
from fractions import Fraction
from decimal import Decimal, localcontext

def exact(x):
    if type(x) not in (int,float):
        raise ValueError("finite int/float required; booleans excluded")
    try:
        if not math.isfinite(x):
            raise ValueError("finite int/float required")
    except OverflowError as exc:
        raise ValueError("input outside finite float range") from exc
    return Fraction(x) if type(x) is int else Fraction(str(x))

def report(x):
    try:
        value=float(x)
    except (OverflowError,ValueError) as exc:
        raise ValueError("unreportable numeric result") from exc
    if not math.isfinite(value) or (x != 0 and value == 0):
        raise ValueError("unreportable numeric result")
    return value

def root(x):
    with localcontext() as ctx:
        ctx.prec=80
        return (Decimal(x.numerator)/Decimal(x.denominator)).sqrt()

def validate_rows(rows):
    if not isinstance(rows,(list,tuple)) or len(rows)<2:
        raise ValueError("at least two observations required")
    if any(not isinstance(r,(list,tuple)) or not r for r in rows):
        raise ValueError("nonempty rows required")
    n=len(rows[0])
    if any(len(r)!=n for r in rows):
        raise ValueError("rectangular aligned data required")
    return [[exact(x) for x in row] for row in rows]

def covariance_matrix(rows,ddof=1):
    data=validate_rows(rows)
    t=len(data)
    if type(ddof) is not int or ddof not in (0,1):
        raise ValueError("ddof must be 0 or 1")
    n=len(data[0])
    means=[sum(row[j] for row in data)/t for j in range(n)]
    centered=[[row[j]-means[j] for j in range(n)] for row in data]
    return [[report(sum(row[i]*row[j] for row in centered)/(t-ddof))
             for j in range(n)] for i in range(n)]

def psd(a):
    # Exact Schur complements; a zero pivot must have an all-zero row.
    a=[row[:] for row in a]
    for k in range(len(a)):
        pivot=a[k][k]
        if pivot<0:
            return False
        if pivot==0:
            if any(a[k][j]!=0 for j in range(k+1,len(a))):
                return False
            continue
        for i in range(k+1,len(a)):
            for j in range(i,len(a)):
                a[i][j]-=a[i][k]*a[k][j]/pivot
                a[j][i]=a[i][j]
    return True

def validate_covariance(cov,n=None):
    if not isinstance(cov,(list,tuple)) or not cov:
        raise ValueError("nonempty square covariance required")
    if n is None:
        n=len(cov)
    if len(cov)!=n or any(not isinstance(row,(list,tuple)) or len(row)!=n for row in cov):
        raise ValueError("square aligned covariance required")
    a=[[exact(x) for x in row] for row in cov]
    if any(a[i][i]<0 for i in range(n)):
        raise ValueError("negative asset variance")
    scale=max(a[i][i] for i in range(n))
    tolerance=scale*Fraction(1,10**12)
    for i in range(n):
        for j in range(i+1,n):
            if abs(a[i][j]-a[j][i])>max(abs(a[i][j]),abs(a[j][i]))*Fraction(1,10**10)+tolerance:
                raise ValueError("covariance must be symmetric within stated tolerance")
            a[i][j]=a[j][i]=(a[i][j]+a[j][i])/2
    if any(a[i][i]==0 and any(a[i][j]!=0 for j in range(n)) for i in range(n)):
        raise ValueError("zero variance requires zero covariance row")
    shifted=[[a[i][j]+(tolerance if i==j else 0) for j in range(n)] for i in range(n)]
    if not psd(shifted):
        raise ValueError("covariance is not PSD within scale-relative tolerance")
    return a,tolerance

def portfolio_variance(weights,cov):
    if not isinstance(weights,(list,tuple)) or not weights:
        raise ValueError("nonempty finite weights required")
    w=[exact(x) for x in weights]
    a,tolerance=validate_covariance(cov,len(w))
    result=sum(w[i]*a[i][j]*w[j] for i in range(len(w)) for j in range(len(w)))
    if result < -tolerance*sum(x*x for x in w):
        raise ValueError("negative quadratic form beyond covariance tolerance")
    return report(max(result,Fraction(0)))

def correlation_matrix(cov):
    a,_=validate_covariance(cov)
    n=len(a)
    if any(a[i][i]==0 for i in range(n)):
        raise ValueError("correlation undefined for zero variance")
    result=[]
    for i in range(n):
        row=[]
        for j in range(n):
            magnitude=root(a[i][j]**2/(a[i][i]*a[j][j]))
            if magnitude>Decimal(1)+Decimal("1e-12"):
                raise ValueError("correlation outside [-1,1] beyond tolerance")
            value=report(min(magnitude,Decimal(1)))
            row.append(-value if a[i][j]<0 else value)
        result.append(row)
    return result

class CovarianceTests(unittest.TestCase):
    def test_01_sample(self): self.assertEqual(covariance_matrix([[1,2],[2,4],[3,6]]),[[1,2],[2,4]])
    def test_02_population(self): self.assertAlmostEqual(covariance_matrix([[1],[2],[3]],0)[0][0],2/3)
    def test_03_symmetry(self):
        c=covariance_matrix([[1,2],[2,4],[3,6]])
        self.assertEqual(c[0][1],c[1][0])
    def test_04_variance(self): self.assertAlmostEqual(portfolio_variance([.5,.5],[[1,0],[0,1]]),.5)
    def test_05_perfect(self): self.assertAlmostEqual(portfolio_variance([.5,.5],[[1,2],[2,4]]),2.25)
    def test_06_hedge(self): self.assertAlmostEqual(portfolio_variance([.5,.5],[[1,-1],[-1,1]]),0)
    def test_07_correlation(self): self.assertAlmostEqual(correlation_matrix([[1,2],[2,4]])[0][1],1)
    def test_08_negative(self): self.assertAlmostEqual(correlation_matrix([[1,-1],[-1,1]])[0][1],-1)
    def test_09_one_asset(self): self.assertEqual(covariance_matrix([[1],[3]]),[[2]])
    def test_10_zero_weights(self): self.assertEqual(portfolio_variance([0,0],[[1,0],[0,1]]),0)
    def test_11_invalid_data(self):
        for rows in ([[1,2]],[[1,2],[3]],[[1],[float("nan")]]):
            with self.assertRaises(ValueError):covariance_matrix(rows)
    def test_12_invalid_matrix(self):
        for f in (lambda:portfolio_variance([.5,.5],[[1,2],[0,1]]),
                  lambda:portfolio_variance([1],[[float("inf")]]),
                  lambda:correlation_matrix([[0,0],[0,1]])):
            with self.assertRaises(ValueError):f()

if __name__=="__main__":
    example=[[.01,.02],[-.01,0],[.02,.03],[0,-.01]]
    c=covariance_matrix(example)
    print("Sample covariance:",c)
    print("Equal-weight variance:",portfolio_variance([.5,.5],c))
    unittest.main(verbosity=2)
```

## 17. Troubleshooting

| Symptom | Possible cause | Corrective action |
|---|---|---|
| Asymmetric covariance | Implementation or data defect | Recheck estimator and ordering |
| Negative portfolio variance | Non-PSD matrix or numerical problem | Validate PSD and data |
| Singular matrix | Collinear assets or insufficient observations | Diagnose rank; use justified regularization |
| Correlation exceeds ±1 | Inconsistent scales or estimator | Recompute on aligned data |
| Zero variance | Constant return series | Mark correlation undefined |
| Correlation changes after join | Timestamp mismatch | Audit alignment |
| PSD fails with pairwise deletion | Different sample subsets | Use coherent PSD estimator |
| Volatility inflated 100× | Percent/decimal mix | Normalize units |
| Optimizer unstable | Noisy or ill-conditioned matrix | Assess conditioning and estimation method |
