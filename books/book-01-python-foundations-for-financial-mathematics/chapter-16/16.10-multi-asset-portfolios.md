## Learning objectives

Generalize two-asset portfolio mathematics to any number of assets; calculate expected return, variance, and volatility using vectors and covariance matrices; understand asset-level risk contributions; account for cash, constraints, and rebalancing drift; and construct a reproducible Python portfolio analytics workflow.

## 1. From two assets to many assets

Real portfolios may contain equities, bonds, cash, commodities, funds, and other exposures. The mathematical extension from two assets to n assets is straightforward when asset returns are represented as a vector.

Let **w=(w₁,…,wₙ)ᵀ** be the vector of beginning-of-period weights and **R=(R₁,…,Rₙ)ᵀ** the aligned asset-return vector.

For a fully invested portfolio:

**Σᵢwᵢ=1.**

Long-only portfolios also require **wᵢ≥0**. Portfolios with leverage or short sales may have signed weights and need a clearly defined NAV and financing convention.

## 2. Portfolio return and expected return

For fixed beginning weights:

**Rₚ=wᵀR=ΣᵢwᵢRᵢ.**

If **μ=E[R]** is the expected-return vector, linearity of expectation gives:

**E[Rₚ]=wᵀμ=Σᵢwᵢμᵢ.**

Correlation does not enter the expectation formula for fixed weights, but the quality of the expected-return estimates still matters.

## 3. Three-asset worked example

Consider fictional assets A, B, and C:

| Asset | Weight | Expected one-period return | Contribution |
|---|---:|---:|---:|
| A | 50% | 8% | 4.0 percentage points |
| B | 30% | 5% | 1.5 percentage points |
| C | 20% | 2% | 0.4 percentage points |
| **Total** | **100%** | | **5.9 percentage points** |

Thus:

**E[Rₚ]=.5(.08)+.3(.05)+.2(.02)=.059=5.9%.**

The 2% asset could represent a simplified cash-like position, provided the time horizon and currency are consistent.

## 4. Multi-asset covariance matrix

Let **Σ** denote the n×n covariance matrix with entries:

**Σᵢⱼ=Cov(Rᵢ,Rⱼ).**

For three assets:

```text
Σ = [[Var(A), Cov(A,B), Cov(A,C)],
     [Cov(B,A), Var(B), Cov(B,C)],
     [Cov(C,A), Cov(C,B), Var(C)]]
```

A valid covariance matrix is symmetric and positive semidefinite. The matrix must use the **same asset order** as the weight and expected-return vectors.

## 5. Portfolio variance and volatility

For fixed weights:

**Var(Rₚ)=wᵀΣw=ΣᵢΣⱼwᵢwⱼΣᵢⱼ.**

Portfolio volatility is:

**σₚ=√(wᵀΣw).**

The variance can be decomposed as:

**σₚ²=Σᵢwᵢ²σᵢ²+2Σᵢ₍ⱼ>ᵢ₎wᵢwⱼCov(Rᵢ,Rⱼ).**

This shows how each asset's standalone variance and every pairwise covariance influence total risk.

## 6. Worked three-asset covariance example

Use:

```text
w = [0.50, 0.30, 0.20]
Σ = [[0.0400, 0.0060, 0.0000],
     [0.0060, 0.0900, 0.0000],
     [0.0000, 0.0000, 0.0004]]
```

Diagonal contributions:

- A: (.5)²(.04)=**.010000**.
- B: (.3)²(.09)=**.008100**.
- C: (.2)²(.0004)=**.000016**.

Only A–B covariance is nonzero:

**2(.5)(.3)(.006)=.001800.**

Therefore:

**σₚ²=.010000+.008100+.000016+.001800=.019916.**

**σₚ=√.019916≈.141124=14.11%.**

These are hypothetical inputs, not calibrated market forecasts.

## 7. Asset-level variance contributions

Let **m=Σw**. The component variance contribution of asset i is:

**VCᵢ=wᵢmᵢ=wᵢ(Σw)ᵢ.**

The contributions reconcile to total portfolio variance:

**ΣᵢVCᵢ=wᵀΣw.**

For the example:

**Σw=[.0218,.0300,.00008].**

Hence:

- A: .5(.0218)=**.0109**.
- B: .3(.0300)=**.0090**.
- C: .2(.00008)=**.000016**.

Sum: **.019916**, matching total variance.

Component contributions are different from diagonal-only contributions because each asset's contribution includes an allocation of covariance effects.

## 8. Portfolio volatility contributions

For σₚ>0:

**RCᵢ=wᵢ(Σw)ᵢ/σₚ.**

These contributions sum to portfolio volatility. Dividing by σₚ again gives percentage volatility risk shares:

**PRCᵢ=wᵢ(Σw)ᵢ/σₚ².**

Risk contributions can be negative for hedging positions even when total variance and volatility are nonnegative.

At zero portfolio volatility, this derivative-based decomposition is generally undefined.

## 9. Cash and low-volatility assets

A cash position is represented by an additional portfolio weight and return series. It should not automatically be assigned zero variance or zero covariance without a defensible modeling assumption.

Cash-like instruments may carry reinvestment, inflation, credit, liquidity, and currency risks. A risk-free approximation is specific to a horizon, currency, and payoff definition.

## 10. Long-only, short, and leveraged portfolios

For a long-only fully invested portfolio:

**wᵢ≥0** and **Σᵢwᵢ=1**.

For a long-short portfolio, some weights are negative. A fully invested signed-weight vector may still sum to one even though gross exposure **Σᵢ|wᵢ|** exceeds one.

Example:

**w=[1.2,−.2]**, expected returns [.10,.05].

**E[Rₚ]=1.2(.10)−.2(.05)=.11** before financing, margin, borrow fees, and trading costs.

Real-world leveraged portfolios require explicit cash-flow, NAV, and collateral accounting.

## 11. Portfolio weights from position values

For long-only positions with nonnegative market values Vᵢ and positive total NAV:

**wᵢ=Vᵢ/ΣⱼVⱼ.**

For values [50,30,20], weights are [.5,.3,.2].

In a long-short portfolio, position market values can be signed, and weights should be calculated relative to portfolio NAV with a consistent cash and liability treatment—not simply by normalizing absolute position sizes.

## 12. Weight drift after realized returns

For a long-only buy-and-hold portfolio with no external flows and simple asset returns Rᵢ:

**wᵢ,new=wᵢ(1+Rᵢ)/Σⱼwⱼ(1+Rⱼ).**

For weights [.5,.5] and returns [.10,0]:

**w_A,new=.55/1.05≈.52381.**

**w_B,new=.50/1.05≈.47619.**

The portfolio realized return is 5%, and the higher-return asset becomes a larger weight.

Rebalancing to target weights requires trading and may incur costs.

## 13. Scenario-based multi-asset analysis

Suppose a set of economic scenarios indexed by s has probabilities pₛ summing to one and scenario-specific asset returns Rᵢ,ₛ.

Portfolio return under scenario s:

**Rₚ,ₛ=ΣᵢwᵢRᵢ,ₛ.**

Scenario-based expected portfolio return:

**μₚ=ΣₛpₛRₚ,ₛ.**

Scenario-based portfolio variance:

**σₚ²=Σₛpₛ(Rₚ,ₛ−μₚ)².**

Scenario analysis allows coherent modeling of joint asset outcomes, but its usefulness depends on plausible probabilities and scenarios.

## 14. Diversification versus concentration

Adding assets can reduce portfolio variance when their covariance structure provides distinct exposures. Merely increasing the number of holdings does not guarantee diversification.

Useful complementary measures include capital-weight concentration, factor exposures, volatility risk contributions, stress scenarios, and liquidity profiles.

Risk budgets can become concentrated even when capital weights look balanced.

## 15. Estimation risk and matrix conditioning

Sample covariance estimates become unstable when there are many assets relative to observations. For T aligned observations and n assets, the sample covariance rank is at most **min(n,T−1)**.

If n>T−1, the sample matrix is singular. Optimization that relies on matrix inversion may fail or produce extreme allocations.

Possible mitigations include covariance shrinkage, factor models, regularization, and constraints. Each introduces assumptions and must be evaluated out of sample.

## 16. Data and production controls

A repeatable multi-asset calculation should document:

- Asset identifiers and matrix ordering.
- Base currency, pricing conventions, and corporate-action adjustments.
- Return frequency and synchronized timestamps.
- Expected-return forecast vintage.
- Covariance estimation window and method.
- Missing-data and stale-price policies.
- Portfolio NAV, short exposure, and financing conventions.
- Rebalancing dates, transaction costs, and turnover.
- Validation thresholds and exception handling.

An accurate formula applied to misaligned or biased inputs still produces unreliable results.

## 17. Python reference implementation

Save as `multi_asset_portfolios.py`. This standard-library implementation calculates expected return, portfolio variance, volatility, variance contributions, normalized long-only allocations, weight drift, and scenario-based portfolio statistics. It includes **12 reference unit tests**.

```python
"""Multi-asset portfolio calculations, standard library only."""
import math
import unittest

def vector(values, name):
    if not isinstance(values,(list,tuple)) or not values:
        raise ValueError(name+" must be nonempty")
    if any(type(x) not in (int,float) or not math.isfinite(x) for x in values):
        raise ValueError(name+" must contain finite numbers")
    return [float(x) for x in values]

def inputs(weights,means,covariance,allow_short=False):
    w=vector(weights,"weights")
    mu=vector(means,"means")
    n=len(w)
    if len(mu)!=n:
        raise ValueError("expected returns must align")
    if not math.isclose(math.fsum(w),1,rel_tol=0,abs_tol=1e-10):
        raise ValueError("fully invested weights must sum to one")
    if not allow_short and any(x<0 for x in w):
        raise ValueError("short positions not allowed")
    if not isinstance(covariance,(list,tuple)) or len(covariance)!=n:
        raise ValueError("covariance dimensions do not align")
    c=[vector(row,"covariance row") for row in covariance]
    if any(len(row)!=n for row in c):
        raise ValueError("covariance must be square")
    if any(c[i][i]<0 for i in range(n)):
        raise ValueError("negative diagonal variance")
    if any(not math.isclose(c[i][j],c[j][i],rel_tol=1e-10,abs_tol=1e-12)
           for i in range(n) for j in range(n)):
        raise ValueError("covariance must be symmetric")
    return w,mu,c

def portfolio_statistics(weights,means,covariance,allow_short=False):
    w,mu,c=inputs(weights,means,covariance,allow_short)
    n=len(w)
    expectation=math.fsum(w[i]*mu[i] for i in range(n))
    variance=math.fsum(w[i]*c[i][j]*w[j] for i in range(n) for j in range(n))
    if variance < -1e-12:
        raise ValueError("negative quadratic variance; covariance may not be PSD")
    variance=max(0.0,variance)
    sigma=math.sqrt(variance)
    variance_contributions=[w[i]*math.fsum(c[i][j]*w[j] for j in range(n))
                            for i in range(n)]
    return {"expected_return":expectation,"variance":variance,
            "volatility":sigma,"variance_contributions":variance_contributions}

def normalize_allocations(allocations):
    a=vector(allocations,"allocations")
    if any(x<0 for x in a) or math.fsum(a)<=0:
        raise ValueError("nonnegative allocations with positive total required")
    total=math.fsum(a)
    return [x/total for x in a]

def drifted_weights(weights,realized_returns):
    w=vector(weights,"weights")
    r=vector(realized_returns,"returns")
    if len(w)!=len(r) or any(x<0 for x in w):
        raise ValueError("aligned long-only weights required")
    if not math.isclose(math.fsum(w),1,rel_tol=0,abs_tol=1e-10):
        raise ValueError("weights must sum to one")
    if any(x < -1 for x in r):
        raise ValueError("unleveraged simple return cannot be below -100%")
    ending=[w[i]*(1+r[i]) for i in range(len(w))]
    if math.fsum(ending)<=0:
        raise ValueError("portfolio NAV exhausted")
    return normalize_allocations(ending)

def scenario_statistics(weights,scenario_probabilities,scenario_asset_returns):
    w=vector(weights,"weights")
    p=vector(scenario_probabilities,"probabilities")
    if any(x<0 for x in p) or not math.isclose(math.fsum(p),1,rel_tol=0,abs_tol=1e-10):
        raise ValueError("probabilities must sum to one")
    if len(p)!=len(scenario_asset_returns):
        raise ValueError("scenario count mismatch")
    if not math.isclose(math.fsum(w),1,rel_tol=0,abs_tol=1e-10):
        raise ValueError("weights must sum to one")
    rows=[vector(row,"scenario returns") for row in scenario_asset_returns]
    if any(len(row)!=len(w) for row in rows):
        raise ValueError("asset dimensions mismatch")
    pr=[math.fsum(w[i]*row[i] for i in range(len(w))) for row in rows]
    mu=math.fsum(p[k]*pr[k] for k in range(len(p)))
    variance=math.fsum(p[k]*(pr[k]-mu)**2 for k in range(len(p)))
    return {"scenario_returns":pr,"expected_return":mu,
            "variance":variance,"volatility":math.sqrt(variance)}

class MultiAssetTests(unittest.TestCase):
    W=[.5,.3,.2]
    MU=[.08,.05,.02]
    C=[[.04,.006,0],[.006,.09,0],[0,0,.0004]]
    def test_01_expected(self): self.assertAlmostEqual(portfolio_statistics(self.W,self.MU,self.C)["expected_return"],.059)
    def test_02_variance(self): self.assertAlmostEqual(portfolio_statistics(self.W,self.MU,self.C)["variance"],.019396)
    def test_03_volatility(self): self.assertAlmostEqual(portfolio_statistics(self.W,self.MU,self.C)["volatility"],math.sqrt(.019396))
    def test_04_contributions(self):
        r=portfolio_statistics(self.W,self.MU,self.C)
        self.assertAlmostEqual(math.fsum(r["variance_contributions"]),r["variance"])
    def test_05_normalize(self): self.assertEqual(normalize_allocations([50,30,20]),self.W)
    def test_06_drift(self):
        w=drifted_weights([.5,.5],[.1,0])
        self.assertAlmostEqual(w[0],.55/1.05)
    def test_07_scenarios(self):
        r=scenario_statistics([.5,.5],[.5,.5],[[.1,0],[0,.1]])
        self.assertAlmostEqual(r["expected_return"],.05)
        self.assertAlmostEqual(r["variance"],0)
    def test_08_one_asset(self):
        self.assertAlmostEqual(portfolio_statistics([1],[.07],[[.04]])["volatility"],.2)
    def test_09_short(self):
        r=portfolio_statistics([1.2,-.2],[.1,.05],[[.04,0],[0,.09]],True)
        self.assertAlmostEqual(r["expected_return"],.11)
    def test_10_zero_return_drift(self):
        self.assertEqual(drifted_weights(self.W,[0,0,0]),self.W)
    def test_11_invalid_weights(self):
        for w in ([.5,.3,.1],[.5,-.1,.6]):
            with self.assertRaises(ValueError):portfolio_statistics(w,self.MU,self.C)
    def test_12_invalid_data(self):
        for f in (lambda:portfolio_statistics(self.W,self.MU,[[1]]),
                  lambda:portfolio_statistics(self.W,self.MU,[[.04,.1,0],[0,.09,0],[0,0,.0004]]),
                  lambda:scenario_statistics([.5,.5],[.2,.2],[[.1,0],[0,.1]]),
                  lambda:drifted_weights([.5,.5],[-1,-1])):
            with self.assertRaises(ValueError):f()

if __name__=="__main__":
    w=[.5,.3,.2]
    mu=[.08,.05,.02]
    cov=[[.04,.006,0],[.006,.09,0],[0,0,.0004]]
    print(portfolio_statistics(w,mu,cov))
    unittest.main(verbosity=2)
```

## 20. Troubleshooting

| Symptom | Likely cause | Corrective action |
|---|---|---|
| Wrong portfolio return | Misaligned weights and means | Verify asset ordering |
| Negative quadratic variance | Invalid covariance or implementation | Check PSD and calculations |
| Risk contributions do not sum | Incorrect covariance allocation | Use wᵢ(Σw)ᵢ |
| Volatility is off by 100× | Percent/decimal mix | Normalize units |
| Matrix inversion fails | Singular covariance | Diagnose rank and conditioning |
| Rebalancing weights incorrect | Missing NAV normalization | Recompute ending values |
| Scenario probabilities inconsistent | Invalid probability model | Validate probability sum |
| Short strategy performance inflated | Financing costs omitted | Include economic costs |
| Historical risk unstable | Window or regime sensitivity | Stress and out-of-sample tests |
