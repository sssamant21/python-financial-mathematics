## Learning objectives

Calculate single-period portfolio returns and return contributions; distinguish price, total, gross, and net returns; model portfolio wealth through multiple periods; contrast buy-and-hold with constant-mix rebalancing; and identify the effects of external cash flows, timing, FX, and transaction costs.

## 1. From asset returns to portfolio return

For n assets with **beginning-of-period** portfolio value weights wᵢ and aligned simple total returns Rᵢ, the portfolio's one-period simple return is:

**Rₚ=Σᵢ₌₁ⁿ wᵢRᵢ.**

This identity assumes a consistent valuation horizon, appropriate treatment of cash and financing, and no external cash flows that distort the starting capital base.

For weights [.6,.4] and returns [.10,−.05]:

**Rₚ=.6(.10)+.4(−.05)=.04=4%.**

The result is a **weighted sum**, not a simple average unless weights are equal.

## 2. Derivation from beginning and ending wealth

Suppose the portfolio starts with total value V₀>0. Asset i initially has value Vᵢ,₀=wᵢV₀.

Without external flows or trades, and using total-return-consistent asset valuations:

**V₁=ΣᵢVᵢ,₀(1+Rᵢ).**

Dividing by V₀ gives:

**V₁/V₀=Σᵢwᵢ(1+Rᵢ)=1+ΣᵢwᵢRᵢ.**

Thus **V₁/V₀−1=ΣᵢwᵢRᵢ**.

The derivation makes clear why beginning weights matter: ending weights already incorporate the asset returns.

## 3. Return contributions

The simple contribution of asset i to one-period portfolio return is:

**Cᵢ=wᵢRᵢ.**

In the example:

| Asset | Starting weight | Return | Contribution |
|---|---:|---:|---:|
| A | 60% | +10% | +6 percentage points |
| B | 40% | −5% | −2 percentage points |
| **Portfolio** | **100%** | | **+4 percentage points** |

A contribution of +6 percentage points is not the same as a 6% relative contribution to total performance. The distinction matters for reporting.

## 4. Price returns versus total returns

A price-only return is:

**R_price=(P₁−P₀)/P₀.**

When a cash dividend D is paid during the period and treated as received at the end, a simplified total return is:

**R_total=(P₁−P₀+D)/P₀.**

For P₀=$100, P₁=$105, and D=$2, price return=5% and total return=7%.

Actual total-return series must account for the timing and reinvestment of distributions, splits, spin-offs, and other corporate actions. Mixing price-only and total-return series makes portfolio performance inconsistent.

## 5. Gross and net portfolio return

**Gross return** excludes some or all costs, depending on the reporting convention. **Net return** accounts for relevant costs such as commissions, spreads, market impact, financing, management fees, and taxes where applicable.

If a hypothetical portfolio earns 5% gross and incurs costs equal to 1% of initial NAV, and costs are charged at period end, net return is 4%.

A production report must state precisely which costs are included and how they are timed. There is no universal single cost adjustment that fits every strategy.

## 6. External cash flows

Suppose NAV rises from $100 to $120 but includes a $10 external deposit. The naive ratio 120/100−1=20% **overstates investment performance**.

If the $10 deposit occurred exactly at the end and did not participate in the investment period, the return would be:

**(120−10)/100−1=10%.**

For deposits and withdrawals at arbitrary times, a simple subtraction can be wrong. Use a specified time-weighted or money-weighted return convention (Chapter 13), with accurate flow timestamps.

The reference `value_return` helper therefore rejects nonzero external flows rather than silently calculating an invalid performance figure.

## 7. Multi-period portfolio returns

Given portfolio simple returns Rₚ,₁,…,Rₚ,T, cumulative wealth growth is:

**1+R_cumulative=∏ₜ₌₁ᵀ(1+Rₚ,ₜ).**

For portfolio returns +10% and −10%:

**R_cumulative=1.1×.9−1=−1%.**

The arithmetic mean of the two returns is zero, but cumulative wealth falls by 1%.

## 8. Buy-and-hold versus constant-mix strategies

**Buy-and-hold** keeps initial asset quantities unchanged (ignoring distributions and other actions), so weights drift as assets earn different returns.

**Constant-mix** restores a target weight vector between periods. Rebalancing changes the subsequent period's beginning weights and can change compounded performance.

Consider initial weights [.5,.5] and two return periods:

- Period 1: A +20%, B 0%.
- Period 2: A 0%, B +20%.

**Buy-and-hold:** Initial values [.5,.5] become [.6,.5] after period 1, then [.6,.6] after period 2. Final wealth=1.2, so cumulative return=**20%**.

**Constant-mix:** Each period earns .5(.2)+.5(0)=10%. Rebalance to 50/50 between periods. Final wealth=1.1×1.1=1.21, so cumulative return=**21%** before costs.

This example illustrates path dependence. Constant-mix does not universally outperform buy-and-hold; trend persistence, volatility, costs, and constraints can reverse the result.

## 9. Drifted weights

For a long-only portfolio with initial weights wᵢ,₀ and period returns Rᵢ:

**wᵢ,₁=wᵢ,₀(1+Rᵢ)/(1+Rₚ).**

For 50/50 weights and returns [.10,0], the portfolio earns 5% and new weights are:

**w_A=.55/1.05=1.1/2.1≈.52381.**

**w_B=.50/1.05=1/2.1≈.47619.**

Drift is central to interpreting multi-period buy-and-hold returns.

## 10. Long-short portfolios and leverage

With signed weights, **Rₚ=ΣwᵢRᵢ** can describe a simplified portfolio exposure return when weights are normalized by a consistent NAV denominator.

For weights [1.2,−.2] and asset returns [.10,.05], the exposure return is:

**1.2(.10)−.2(.05)=.11=11%.**

This is **before** borrowing, short rebates, margin, collateral, funding, and trading costs. Derivative and leveraged portfolios may require separate exposure and P&L models.

## 11. FX and currency-consistent returns

If an asset earns local-currency return R_local and the currency conversion factor earns return R_FX under a consistent base-currency quote:

**1+R_base=(1+R_local)(1+R_FX).**

For local return +10% and currency return −5%, base-currency return is:

**1.10×.95−1=.045=4.5%.**

Use a documented FX quote direction and valuation timestamp.

## 12. Return measurement pitfalls

- **Stale weights:** End-of-period weights are not starting-period weights.
- **Misaligned periods:** Assets must share a compatible measurement horizon.
- **Corporate actions:** Unadjusted price series can produce artificial returns.
- **External flows:** Deposits and withdrawals must be separated from investment gain.
- **Rebalancing costs:** Constant-mix returns without trading costs can be optimistic.
- **Leverage:** Exposure returns omit financing and margin dynamics unless modeled.
- **Rounding:** Monetary rounding and floating-point approximations need declared conventions.
- **Survivorship:** A historical portfolio must include assets that later disappeared.

## 13. Python reference implementation

Save as `portfolio_return.py`. This standard-library implementation calculates one-period returns, return contributions, simple no-flow NAV returns, buy-and-hold paths, and constant-mix paths. It includes **12 reference unit tests**.

```python
import math
import unittest

def numeric(xs):
    if not isinstance(xs,(list,tuple)) or not xs:
        raise ValueError("nonempty list or tuple required")
    if any(type(x) not in (int,float) or not math.isfinite(x) for x in xs):
        raise ValueError("finite numbers required")
    return [float(x) for x in xs]

def weights(xs, allow_short=False):
    w=numeric(xs)
    if not allow_short and any(x<0 for x in w):
        raise ValueError("long-only weights must be nonnegative")
    if not math.isclose(math.fsum(w),1.0,rel_tol=0,abs_tol=1e-10):
        raise ValueError("weights must sum to 1")
    return w

def period_return(start_weights,asset_returns,allow_short=False):
    w=weights(start_weights,allow_short)
    r=numeric(asset_returns)
    if len(w)!=len(r):
        raise ValueError("aligned weights and returns required")
    if any(x < -1 for x in r):
        raise ValueError("simple returns below -100% invalid")
    return math.fsum(a*b for a,b in zip(w,r))

def value_return(start_value,end_value,external_flows=0):
    for v in (start_value,end_value,external_flows):
        if type(v) not in (int,float) or not math.isfinite(v):
            raise ValueError("finite numeric values required")
    if start_value<=0:
        raise ValueError("positive start value required")
    if external_flows!=0:
        raise ValueError("flow timing requires a specified performance convention")
    return end_value/start_value-1

def buy_and_hold(start_weights,return_rows):
    w=weights(start_weights)
    if not isinstance(return_rows,(list,tuple)) or not return_rows:
        raise ValueError("nonempty return rows required")
    values=list(w)
    series=[]
    for row in return_rows:
        r=numeric(row)
        if len(r)!=len(values) or any(x < -1 for x in r):
            raise ValueError("aligned simple returns >= -100% required")
        old=math.fsum(values)
        if old<=0:
            raise ValueError("portfolio depleted")
        values=[v*(1+x) for v,x in zip(values,r)]
        new=math.fsum(values)
        series.append(new/old-1)
    return {"period_returns":series,
            "cumulative_return":math.fsum(values)-1,
            "ending_weights":([v/math.fsum(values) for v in values]
                              if math.fsum(values)>0 else None)}

def constant_mix(start_weights,return_rows):
    w=weights(start_weights)
    if not isinstance(return_rows,(list,tuple)) or not return_rows:
        raise ValueError("nonempty return rows required")
    wealth=1.0
    period=[]
    for row in return_rows:
        p=period_return(w,row)
        period.append(p)
        wealth*=1+p
    return {"period_returns":period,"cumulative_return":wealth-1}

def contribution(weights_start,returns):
    w=weights(weights_start,allow_short=True)
    r=numeric(returns)
    if len(w)!=len(r):
        raise ValueError("aligned series required")
    return [a*b for a,b in zip(w,r)]

class PortfolioReturnTests(unittest.TestCase):
    def test_01_weighted(self): self.assertAlmostEqual(period_return([.6,.4],[.1,-.05]),.04)
    def test_02_equal(self): self.assertAlmostEqual(period_return([.5,.5],[.1,-.1]),0)
    def test_03_contribution(self): self.assertEqual(contribution([.6,.4],[.1,-.05]),[.06,-.020000000000000004])
    def test_04_value(self): self.assertAlmostEqual(value_return(100,104),.04)
    def test_05_buy_hold(self):
        result=buy_and_hold([.5,.5],[[.1,0],[0,.1]])
        self.assertAlmostEqual(result["cumulative_return"],.1025)
    def test_06_constant_mix(self):
        result=constant_mix([.5,.5],[[.1,0],[0,.1]])
        self.assertAlmostEqual(result["cumulative_return"],.1025)
    def test_07_drift(self):
        result=buy_and_hold([.5,.5],[[.1,0]])
        self.assertAlmostEqual(result["ending_weights"][0],1.1/2.1)
    def test_08_short(self): self.assertAlmostEqual(period_return([1.2,-.2],[.1,.05],True),.11)
    def test_09_zero(self): self.assertEqual(period_return([1,0],[0,.5]),0)
    def test_10_loss(self): self.assertAlmostEqual(period_return([.5,.5],[-1,0]),-.5)
    def test_11_rebalance_difference(self):
        rows=[[.2,0],[0,.2]]
        self.assertNotAlmostEqual(buy_and_hold([.5,.5],rows)["cumulative_return"],
                                  constant_mix([.5,.5],rows)["cumulative_return"])
    def test_12_invalid(self):
        for f in (lambda:period_return([.6,.3],[.1,.1]),
                  lambda:period_return([1,0],[.1]),
                  lambda:value_return(100,110,10),
                  lambda:buy_and_hold([.5,.5],[[0,-1.1]]),
                  lambda:constant_mix([.5,.5],[])):
            with self.assertRaises(ValueError):f()

if __name__=="__main__":
    sample=[[.2,0],[0,.2]]
    print("Buy and hold:",buy_and_hold([.5,.5],sample))
    print("Constant mix:",constant_mix([.5,.5],sample))
    unittest.main(verbosity=2)
```

## 15. Twenty-four worked exercises

1. **Weighted return:** Weights [.6,.4], returns [.1,-.05]. **Worked solution:** 4%.

2. **Contribution:** Same example. **Worked solution:** A contributes +6pp; B contributes −2pp.

3. **Equal weights:** Returns [+10%,−10%]. **Worked solution:** 0% period return.

4. **Zero allocation:** Weights [1,0], returns [0,.5]. **Worked solution:** 0%.

5. **Short exposure:** Weights [1.2,−.2], returns [.1,.05]. **Worked solution:** 11% before financing and costs.

6. **Price return:** 100→110. **Worked solution:** +10%.

7. **Dividend return:** Price 100→105, cash dividend 2. **Worked solution:** 7% total return if dividend included at period end.

8. **NAV return:** NAV 100→104, no external flows. **Worked solution:** +4%.

9. **Deposit:** NAV 100→120 including deposit 10. **Worked solution:** Simple NAV change 20% is not investment return.

10. **Gross versus net:** Gross return 5%, costs 1% of initial NAV. **Worked solution:** Net return 4% under stated additive cost convention.

11. **One-period drift:** 50/50, returns [.1,0]. **Worked solution:** New weights 1.1/2.1 and 1/2.1.

12. **Portfolio period loss:** 50/50, returns [−1,0]. **Worked solution:** −50%.

13. **Two-period compounding:** Returns [.1,−.1]. **Worked solution:** −1% cumulative.

14. **Arithmetic averaging:** Returns [.1,−.1]. **Worked solution:** 0% arithmetic mean, not cumulative.

15. **Geometric average:** Returns [.1,−.1]. **Worked solution:** √.99−1≈−0.5013% per period.

16. **Buy-and-hold:** 50/50, periods [[.2,0],[0,.2]]. **Worked solution:** Cumulative=20%; terminal asset values [.6,.6] relative to starting NAV 1.

17. **Constant mix:** Same periods, rebalance to 50/50 between periods. **Worked solution:** Cumulative=21% before costs.

18. **Rebalancing premium:** Compare preceding strategies. **Worked solution:** 1 percentage point difference for this path, not a universal benefit.

19. **Beginning weights:** Return attribution. **Worked solution:** Use start-of-period weights.

20. **Cash:** Weights [.5,.4,.1], cash return 0. **Worked solution:** Include cash contribution explicitly.

21. **FX:** Local return 10%, FX return −5%. **Worked solution:** Base-currency return 1.1×.95−1=4.5%.

22. **External flows:** Mid-period deposit. **Worked solution:** Specify time-weighted or money-weighted methodology.

23. **Transaction costs:** Two trades costing $1 total on NAV $1,000. **Worked solution:** −0.1 percentage point return impact if charged at end.

24. **Precision:** Weighted returns sum .039999999999. **Worked solution:** Report 4% using appropriate tolerance.

## 16. Troubleshooting

| Symptom | Likely cause | Recommended action |
|---|---|---|
| Weighted return differs from NAV change | Cash flows or costs | Reconcile portfolio accounting |
| Compounded return differs from mean | Arithmetic versus geometric effect | Multiply gross returns |
| Rebalancing results differ | Timing or target weights | Document rebalance convention |
| Unrealistic short returns | Funding omitted | Include financing and collateral |
| FX-adjusted return differs | Quote direction mismatch | Standardize base-currency FX |
| Dividend portfolio underperforms | Price-only data | Use total-return-consistent series |
| Returns change with end weights | Incorrect attribution timing | Use beginning weights |
| Strategy looks better before fees | Trading costs omitted | Report net results |
