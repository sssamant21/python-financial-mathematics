## Learning objectives

Derive the two-asset expected-return and variance equations; evaluate correlation and diversification; solve the minimum-variance allocation; calculate allocations for target returns; trace the risk–return opportunity set; and understand long-only constraints, leverage, degeneracy, and estimation uncertainty.

## 1. Why study two-asset portfolios?

A two-asset portfolio is the smallest useful model of diversification. It makes the relationship between weights, expected returns, variances, and covariance explicit, and it provides a foundation for multi-asset portfolio optimization.

Let asset A have weight **w** and asset B have weight **1−w**. For a fully invested long-only portfolio, **0≤w≤1**. Allowing short sales permits w outside that interval but introduces additional funding and risk considerations.

## 2. Portfolio return and expectation

The one-period portfolio return is:

**Rₚ=wR_A+(1−w)R_B.**

For fixed beginning weights, linearity of expectation gives:

**E[Rₚ]=wμ_A+(1−w)μ_B.**

If w=.6, μ_A=.08, and μ_B=.04:

**E[Rₚ]=.6(.08)+.4(.04)=.064=6.4%.**

Correlation is not needed for this expectation. It matters for risk.

## 3. Portfolio variance and volatility

The variance is:

**σₚ²=w²σ_A²+(1−w)²σ_B²+2w(1−w)σ_Aσ_Bρ.**

Portfolio volatility is:

**σₚ=√σₚ².**

The covariance is **Cov(R_A,R_B)=σ_Aσ_Bρ**.

For σ_A=.2, σ_B=.3, ρ=1/6:

**Cov=.2(.3)(1/6)=.01.**

With w=.6:

**σₚ²=.6²(.04)+.4²(.09)+2(.6)(.4)(.01)=.0336.**

Thus **σₚ≈18.33%**.

## 4. How correlation changes risk

Consider equal weights and two assets with σ_A=σ_B=.2:

| Correlation | Portfolio variance | Volatility |
|---|---:|---:|
| +1 | .04 | 20% |
| 0 | .02 | 14.14% |
| −1 | 0 | 0% |

These are idealized examples. A historical negative correlation is not guaranteed to persist. Zero correlation does not necessarily imply statistical independence.

## 5. The minimum-variance weight

To minimize two-asset variance, write:

**V(w)=w²σ_A²+(1−w)²σ_B²+2w(1−w)c**, where **c=Cov(R_A,R_B)**.

Differentiate:

**dV/dw=2wσ_A²−2(1−w)σ_B²+2(1−2w)c.**

Set the derivative to zero and solve:

**w_A,MV=(σ_B²−c)/(σ_A²+σ_B²−2c).**

The denominator is **Var(R_A−R_B)**, which is nonnegative for a valid covariance matrix.

For a nondegenerate model with positive denominator, this is the unconstrained minimum-variance weight. In the long-only case, the optimal w is this result **clamped to [0,1]**.

## 6. Minimum-variance worked example

Suppose σ_A=.2, σ_B=.3, and ρ=0. Then c=0.

**w_A,MV=.09/(.04+.09)=.09/.13≈.692308.**

**w_B,MV=.04/.13≈.307692.**

The minimum variance is:

**V_min=(.04×.09)/(.04+.09)=.0036/.13≈.0276923.**

The minimum volatility is:

**σ_min≈√.0276923≈16.64%.**

This is less than either standalone volatility of 20% or 30%.

## 7. Long-only boundary solutions

The unconstrained minimum-variance weight may be negative or greater than one. When short selling is prohibited, the minimum is then attained at the closest feasible boundary, w=0 or w=1.

Example: σ_A=.1, σ_B=.2, and ρ=+1. The minimum-variance long-only allocation is 100% A.

A boundary optimum is not a numerical failure; it reflects the constraints and covariance structure.

## 8. Degenerate identical-return risk

If:

**σ_A²+σ_B²−2c=0**,

then **Var(R_A−R_B)=0**. For a valid covariance model, the two assets have identical random return deviations almost surely.

If σ_A=σ_B and ρ=+1, all fully invested weights have the same portfolio variance. There is no unique minimum-variance allocation.

A robust implementation must detect this case rather than divide by zero or return an arbitrary optimizer weight.

## 9. Solving for a target expected return

Given target expected return μ_target and unequal asset expected returns:

**μ_target=wμ_A+(1−w)μ_B.**

Therefore:

**w=(μ_target−μ_B)/(μ_A−μ_B).**

If μ_A=.09, μ_B=.05, and μ_target=.07:

**w=(.07−.05)/(.09−.05)=.5.**

For long-only portfolios, the target must lie between the two expected asset returns. A target outside this interval requires leverage, short selling, another asset, or a revised target.

If μ_A=μ_B, every fully invested allocation has the same expected return; a different target is unattainable.

## 10. The two-asset opportunity set

As w varies, each portfolio produces a point:

**(σₚ(w), E[Rₚ(w)]).**

Plotting these points with volatility on the horizontal axis and expected return on the vertical axis traces the feasible two-asset opportunity set.

For long-only portfolios, w runs from 0 to 1. With shorting, the set extends beyond the endpoints.

The shape depends on expected returns, volatilities, and correlation. When correlation is less than +1, the opportunity set generally bends toward lower risk compared with the straight weighted-volatility combination.

## 11. Efficient versus inefficient portfolios

A portfolio is **mean–variance dominated** if another feasible portfolio has at least as high expected return and no greater variance, with at least one strict improvement.

The efficient portion of the opportunity set contains portfolios not dominated under the chosen feasible set and estimated moments.

If μ_A>μ_B and the minimum-variance weight lies strictly inside [0,1], then allocations on the branch toward greater weight in A can be efficient, while allocations on the opposite branch can be dominated by portfolios with the same or greater expected return and lower risk. Boundary cases and equal means require separate treatment.

Efficiency is always relative to the available assets, assumptions, and constraints.

## 12. Correlation sensitivity

For fixed w, σ_A, and σ_B:

**∂σₚ²/∂ρ=2w(1−w)σ_Aσ_B.**

For long-only interior weights, this derivative is nonnegative.

At w=.5, σ_A=.2, σ_B=.3:

**∂σₚ²/∂ρ=2(.5)(.5)(.2)(.3)=.03.**

An increase in correlation of .1 therefore increases portfolio variance by .003 in this example, with all other parameters held fixed.

## 13. Short selling and leverage

If w=1.2, the second weight is −.2. The portfolio has a 120% long position and a 20% short position relative to NAV.

With expected returns μ_A=.10 and μ_B=.05:

**E[Rₚ]=1.2(.10)−.2(.05)=.11.**

This simplified expected exposure return omits financing, borrowing fees, short-sale rebates, margin, and execution costs. A production model must account for these effects.

## 14. Estimation risk and practical limitations

The mathematical frontier assumes expected returns, variances, and covariance are known. In practice they are estimated from imperfect data.

Important sources of error include:

- Short or nonrepresentative historical windows.
- Correlation regime changes.
- Survivorship and look-ahead bias.
- Stale or misaligned prices.
- Currency and return-horizon mismatches.
- Trading costs and rebalancing drift.
- Shorting, borrowing, liquidity, and leverage constraints.
- Nonlinear derivatives and tail-risk exposures.

A precise frontier calculated from noisy inputs can create false confidence. Stress scenarios and sensitivity analysis are essential.

## 15. Python reference implementation

Save as `two_asset_portfolios.py`. This standard-library implementation calculates expected return, variance, volatility, minimum-variance weights, target-return weights, and a grid of two-asset portfolios. It includes **12 reference unit tests**.

```python
import math
import unittest
from fractions import Fraction
from decimal import Decimal, localcontext

def exact(x):
    if type(x) not in (int,float):
        raise ValueError("finite int/float required; booleans excluded")
    try:
        if not math.isfinite(x):
            raise ValueError("finite int/float required")
    except OverflowError as exc:
        raise ValueError("input outside finite float range") from exc
    return Fraction(x) if type(x) is int else Fraction(str(x))

def report(x):
    try:
        value=float(x)
    except (OverflowError,ValueError) as exc:
        raise ValueError("unreportable numeric result") from exc
    if not math.isfinite(value) or (x != 0 and value == 0):
        raise ValueError("unreportable numeric result")
    return value

def root(x):
    with localcontext() as ctx:
        ctx.prec=80
        return (Decimal(x.numerator)/Decimal(x.denominator)).sqrt()

def finite(x):
    try:
        exact(x)
    except ValueError:
        return False
    return True

def _parameters(mu1,mu2,sigma1,sigma2,rho):
    values=tuple(exact(x) for x in (mu1,mu2,sigma1,sigma2,rho))
    if values[2]<0 or values[3]<0 or not -1<=values[4]<=1:
        raise ValueError("nonnegative volatilities and correlation in [-1,1] required")
    return values

def validate(mu1,mu2,sigma1,sigma2,rho):
    _parameters(mu1,mu2,sigma1,sigma2,rho)

def portfolio(w,mu1,mu2,sigma1,sigma2,rho,allow_short=False):
    mu1,mu2,s1,s2,rho=_parameters(mu1,mu2,sigma1,sigma2,rho)
    if type(allow_short) is not bool:
        raise ValueError("allow_short must be boolean")
    w=exact(w);v=1-w
    if not allow_short and not 0<=w<=1:
        raise ValueError("invalid long-only weight")
    displayed=[report(w),report(v)]
    if not math.isclose(math.fsum(displayed),1,rel_tol=0,abs_tol=1e-10):
        raise ValueError("reported weights lose unit-budget reconciliation")
    expected=w*mu1+v*mu2
    variance=(w*s1)**2+(v*s2)**2+2*w*v*s1*s2*rho
    if variance<0:
        raise ValueError("negative exact variance")
    return {"w1":displayed[0],"w2":displayed[1],"expected_return":report(expected),
            "variance":report(variance),"volatility":report(root(variance))}

def minimum_variance_weight(sigma1,sigma2,rho,long_only=True):
    _,_,s1,s2,rho=_parameters(0,0,sigma1,sigma2,rho)
    if type(long_only) is not bool:
        raise ValueError("long_only must be boolean")
    denominator=s1*s1+s2*s2-2*s1*s2*rho
    if denominator==0:
        return {"w1":None,"note":"all weights have identical variance"}
    w=(s2*s2-s1*s2*rho)/denominator
    if long_only:
        w=min(Fraction(1),max(Fraction(0),w))
    return {"w1":report(w),"note":"long-only optimum" if long_only else "unconstrained optimum"}

def target_return_weight(target,mu1,mu2,long_only=True):
    target,mu1,mu2=(exact(x) for x in (target,mu1,mu2))
    if type(long_only) is not bool:
        raise ValueError("long_only must be boolean")
    if mu1==mu2:
        if target==mu1:
            return {"w1":None,"note":"any fully invested weight matches target"}
        raise ValueError("target unattainable for equal expected returns")
    w=(target-mu2)/(mu1-mu2)
    if long_only and not 0<=w<=1:
        raise ValueError("target outside long-only attainable range")
    return {"w1":report(w),"note":"target-return weight"}

def frontier(mu1,mu2,sigma1,sigma2,rho,steps=10):
    if type(steps) is not int or steps<1:
        raise ValueError("positive integer steps required")
    return [portfolio(i/steps,mu1,mu2,sigma1,sigma2,rho) for i in range(steps+1)]

class TwoAssetTests(unittest.TestCase):
    def test_01_expected(self): self.assertAlmostEqual(portfolio(.6,.08,.04,.2,.3,1/6)["expected_return"],.064)
    def test_02_variance(self): self.assertAlmostEqual(portfolio(.6,.08,.04,.2,.3,1/6)["variance"],.0336)
    def test_03_volatility(self): self.assertAlmostEqual(portfolio(.6,.08,.04,.2,.3,1/6)["volatility"],math.sqrt(.0336))
    def test_04_zero_corr(self): self.assertAlmostEqual(portfolio(.5,0,0,.2,.2,0)["variance"],.02)
    def test_05_perfect_pos(self): self.assertAlmostEqual(portfolio(.5,0,0,.2,.2,1)["volatility"],.2)
    def test_06_perfect_neg(self): self.assertAlmostEqual(portfolio(.5,0,0,.2,.2,-1)["volatility"],0)
    def test_07_min_variance(self): self.assertAlmostEqual(minimum_variance_weight(.2,.3,0)["w1"],.09/.13)
    def test_08_min_variance_boundary(self): self.assertEqual(minimum_variance_weight(.1,.2,1)["w1"],1)
    def test_09_target(self): self.assertAlmostEqual(target_return_weight(.07,.09,.05)["w1"],.5)
    def test_10_frontier(self): self.assertEqual(len(frontier(.08,.04,.2,.3,0,10)),11)
    def test_11_short(self): self.assertAlmostEqual(portfolio(1.2,.1,.05,.2,.3,0,True)["expected_return"],.11)
    def test_12_invalid(self):
        degenerate = minimum_variance_weight(.2,.2,1)
        self.assertIsNone(degenerate["w1"])
        self.assertEqual(degenerate["note"], "all weights have identical variance")
        for fn in (lambda:portfolio(-.1,0,0,.2,.3,0),
                   lambda:portfolio(.5,0,0,.2,.3,2),
                   lambda:target_return_weight(.1,.09,.05),
                   lambda:frontier(0,0,.2,.2,0,0)):
            with self.assertRaises(ValueError):fn()

if __name__=="__main__":
    print("Example:",portfolio(.6,.08,.04,.2,.3,1/6))
    print("Minimum variance:",minimum_variance_weight(.2,.3,0))
    unittest.main(verbosity=2)
```

**Numeric and model boundary:** Inputs use integer/displayed-decimal rational intermediates and 80-digit Decimal roots before float output. Every required float field must remain finite and preserve nonzero exact values, or `ValueError` is deliberate. `portfolio` returns both variance and SD, so an unreportable variance rejects that whole result even when SD alone could be reported. Reported weight pairs must reconcile to one within absolute `1e-10`; signed exposures too large to retain that budget in displayed floats reject. Short/long-only policy controls must be booleans.

For valid two-asset nonnegative volatilities and rho in [-1,1], the covariance model is PSD; no tolerance expands that correlation interval. Minimum-variance and target-return degeneracy use exact denominators/equality under the declared input policy, not fixed absolute floors that erase small distinct models. Both zero volatilities are degenerate for any allowed rho. A tiny positive optimizer denominator remains a valid mathematical problem; exact arithmetic does not remove its economic sensitivity. An allocation returned by an optimizer/target solver may require subsequent reporting/feasibility checks when passed into `portfolio`.

## 18. Troubleshooting

| Symptom | Likely cause | Corrective action |
|---|---|---|
| Variance differs from expectation | Covariance or units wrong | Recompute σ_Aσ_Bρ |
| Minimum-variance weight outside [0,1] | Unconstrained solution | Apply long-only bounds |
| Division by zero in optimizer | Degenerate covariance | Detect equal-risk case |
| Target-return solver fails | Equal expected returns or infeasible target | Check target and constraints |
| Frontier looks unexpectedly linear | Perfect correlation or incorrect formula | Verify correlation and cross term |
| Negative variance | Invalid correlation or numerical error | Validate PSD and calculations |
| Backtest frontier underperforms | Estimation error or regime shift | Stress-test inputs |
| Short portfolio returns too high | Financing and trading costs omitted | Model net returns |
| Currency mix distorts covariance | Inconsistent FX basis | Convert to common currency |
