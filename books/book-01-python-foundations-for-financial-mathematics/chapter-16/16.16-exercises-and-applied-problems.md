## 1. Working assumptions and notation

Let w be the weight vector, μ the vector of expected simple returns, and Σ the covariance matrix over the **same period**.

- Fully invested budget: **Σᵢwᵢ=1**.
- Long-only: **wᵢ≥0**.
- Expected return: **μp=wᵀμ**.
- Variance: **σp²=wᵀΣw**.
- Volatility: **σp=√(wᵀΣw)**.
- Covariance from correlation: **Cov(i,j)=ρᵢⱼσᵢσⱼ**.
- Component variance: **VCᵢ=wᵢ(Σw)ᵢ**.
- Component volatility for σp>0: **RCᵢ=VCᵢ/σp**.
- One-way turnover for a self-financing rebalance: **T=½Σᵢ|wᵢ,target−wᵢ,current|**.

## 4. Integrated applied case A — Healthcare endowment portfolio

A fictional healthcare endowment invests 50% in broad equities, 30% in bonds, and 20% in cash-like instruments. Use the base three-asset expected returns and covariance matrix.

**Tasks:** Calculate expected return, variance, volatility, component risk contributions, and determine whether a maximum 45% equity allocation is satisfied.

**Solution:** Expected return=.059. Variance=.019916. Volatility=√.019916≈14.11%. Component variances are [.0109,.009,.000016], which reconcile to .019916. The 50% equity allocation violates a 45% cap by five percentage points. A risk-optimal portfolio is not automatically mandate-compliant.

## 5. Integrated applied case B — Two-asset minimum variance

A fictional pension plan considers two assets with variances .04 and .09 and zero covariance. Expected returns are 8% and 4%.

**Tasks:** Find the unconstrained minimum-variance weights subject to the budget, calculate expected return, variance, and volatility, and test a 7% return requirement.

**Solution:** Weight A=.09/(.04+.09)=9/13≈69.23%; B=4/13≈30.77%. Expected return=.0676923≈6.77%. Variance=.0036/.13≈.0276923; volatility≈16.64%. The GMV allocation does not meet the 7% return floor; the feasible target-return portfolio requires at least 75% in A. In this particular example the minimum-variance feasible target solution is exactly 75% in A because the GMV weight lies below that threshold.

## 6. Integrated applied case C — Rebalancing after market drift

A $100 fictional account begins with 50% in A and 50% in B. During the period A earns +10% and B earns 0%. The policy target remains 50/50.

**Tasks:** Compute portfolio return, ending NAV, drifted weights, frictionless rebalance trades, one-way turnover, and whether an absolute five-percentage-point band triggers.

**Solution:** Portfolio return=5%, ending NAV=$105, and drifted weights=[55/105,50/105]≈[.5238095,.4761905]. To restore 50/50, each holding must equal $52.50. Sell $2.50 of A and buy $2.50 of B. One-way turnover=$2.50/$105≈2.381%. The largest deviation is about 2.381 percentage points, so a five-percentage-point absolute band does **not** trigger.

## 7. Integrated applied case D — Covariance stress and model risk

A risk committee suspects that asset volatilities may double while pairwise correlations remain unchanged.

**Tasks:** Transform the covariance matrix, calculate the new portfolio variance and volatility, and explain what the scenario omits.

**Solution:** Every covariance element is multiplied by four. The base portfolio variance becomes 4(.019916)=.079664. Volatility doubles from √.019916≈14.11% to approximately 28.22%. This scenario does not account for changing correlations, liquidity spirals, jumps, or model uncertainty.

## 8. Integrated applied case E — Governance and feasibility

A portfolio has weights [.5,.3,.2], individual caps [.6,.4,.3], and a combined A+B sector cap of .7. A target return floor of 6% is also required.

**Tasks:** Check budget, individual caps, sector cap, and target return.

**Solution:** Budget and individual caps pass. Sector A+B=.8 breaches the .7 cap by .1. Expected return=.059 is below .06 by .001 (0.1 percentage point). The proposed portfolio is infeasible under the stated combined mandate, even though its individual positions pass.

## 9. Reference Python solution and unit tests

Save the following as `chapter16_applied_problems.py`. This complete standard-library reference covers portfolio return and risk, variance contributions, sample covariance, buy-and-hold drift, and frictionless rebalancing. It includes **12 reference unit tests**.

```python
import math
import unittest
from fractions import Fraction
from decimal import Decimal, localcontext

def exact(x):
    if type(x) not in (int,float):
        raise ValueError("finite int/float required; booleans excluded")
    try:
        if not math.isfinite(x):
            raise ValueError("finite int/float required")
    except OverflowError as exc:
        raise ValueError("input outside finite float range") from exc
    return Fraction(x) if type(x) is int else Fraction(str(x))

def _float(x):
    try:
        value=float(x)
    except (OverflowError,ValueError) as exc:
        raise ValueError("unreportable numeric result") from exc
    if not math.isfinite(value) or (x != 0 and value == 0):
        raise ValueError("unreportable numeric result")
    return value

def root(x):
    with localcontext() as ctx:
        ctx.prec=80
        return (Decimal(x.numerator)/Decimal(x.denominator)).sqrt()

def psd(a):
    # Exact Schur complements; a zero pivot must have an all-zero row.
    a=[row[:] for row in a]
    for k in range(len(a)):
        pivot=a[k][k]
        if pivot<0:
            return False
        if pivot==0:
            if any(a[k][j]!=0 for j in range(k+1,len(a))):
                return False
            continue
        for i in range(k+1,len(a)):
            for j in range(i,len(a)):
                a[i][j]-=a[i][k]*a[k][j]/pivot
                a[j][i]=a[i][j]
    return True

def _covariance(cov,tolerance=1e-10):
    relative=exact(tolerance)
    if relative<0 or relative>Fraction(1,10**6):
        raise ValueError("relative tolerance must be in [0,1e-6]")
    n=None
    if not isinstance(cov,(list,tuple)) or not cov:
        raise ValueError("nonempty square covariance required")
    if n is None:
        n=len(cov)
    if len(cov)!=n or any(not isinstance(row,(list,tuple)) or len(row)!=n for row in cov):
        raise ValueError("square aligned covariance required")
    a=[[exact(x) for x in row] for row in cov]
    if any(a[i][i]<0 for i in range(n)):
        raise ValueError("negative asset variance")
    scale=max(a[i][i] for i in range(n))
    tolerance=scale*relative
    for i in range(n):
        for j in range(i+1,n):
            if abs(a[i][j]-a[j][i])>max(abs(a[i][j]),abs(a[j][i]))*relative+tolerance:
                raise ValueError("covariance must be symmetric within stated tolerance")
            a[i][j]=a[j][i]=(a[i][j]+a[j][i])/2
    if any(a[i][i]==0 and any(a[i][j]!=0 for j in range(n)) for i in range(n)):
        raise ValueError("zero variance requires zero covariance row")
    shifted=[[a[i][j]+(tolerance if i==j else 0) for j in range(n)] for i in range(n)]
    if not psd(shifted):
        raise ValueError("covariance is not PSD within scale-relative tolerance")
    return a,tolerance

def _numbers(values,name):
    if not isinstance(values,(list,tuple)) or not values:
        raise ValueError(name+" must be a nonempty list/tuple")
    return [exact(x) for x in values]

def _weights(values,normalize=True):
    w=_numbers(values,"weights");budget=sum(w)
    if min(w)<0 or abs(budget-1)>Fraction(1,10**10):
        raise ValueError("long-only absolute budget tolerance 1e-10 required")
    return [x/budget for x in w] if normalize else w

def _inputs(w,mu,cov):
    w=_weights(w);mu=_numbers(mu,"means");cov,_=_covariance(cov)
    if len(w)!=len(mu) or len(w)!=len(cov):
        raise ValueError("dimensions must align")
    return w,mu,cov

def check(w,mu,cov):
    _inputs(w,mu,cov)

def _reconcile(values,total):
    try:
        summed=math.fsum(values)
    except OverflowError as exc:
        raise ValueError("reported contributions cannot reconcile") from exc
    if not math.isclose(summed,total,rel_tol=1e-10,abs_tol=0):
        raise ValueError("reported contributions lose reconciliation")

def _statistics(w,mu,cov):
    weighted=[sum(cov[i][j]*w[j] for j in range(len(w))) for i in range(len(w))]
    vc=[w[i]*weighted[i] for i in range(len(w))];variance=sum(vc)
    if variance<0:
        raise ValueError("negative exact requested quadratic variance")
    reported_variance=_float(variance);sigma=_float(root(variance))
    contribution=[_float(x) for x in vc];_reconcile(contribution,reported_variance)
    rc=None
    if variance>0:
        rc=[(-1 if x<0 else 1)*_float(root(x*x/variance)) for x in vc]
        _reconcile(rc,sigma)
    return {"expected_return":_float(sum(w[i]*mu[i] for i in range(len(w)))),
            "variance":reported_variance,"volatility":sigma,
            "variance_contributions":contribution,"volatility_contributions":rc}

def portfolio_stats(weights,means,covariance):
    result=_statistics(*_inputs(weights,means,covariance))
    result["mean"]=result.pop("expected_return")
    return result

def drift(w,returns):
    w=_weights(w);returns=_numbers(returns,"returns")
    if len(w)!=len(returns) or min(returns)<-1:
        raise ValueError("aligned simple returns >= -100% required")
    values=[w[i]*(1+returns[i]) for i in range(len(w))];total=sum(values)
    if total<=0:
        raise ValueError("NAV exhausted")
    realized=_float(sum(w[i]*returns[i] for i in range(len(w))))
    if realized==-1:
        raise ValueError("positive ending NAV cannot report total loss")
    ending=[_float(x/total) for x in values];_reconcile(ending,1.0)
    return {"return":realized,"weights":ending}

def rebalance(current,target,nav):
    a=_weights(current);b=_weights(target);nav=exact(nav)
    if len(a)!=len(b) or nav<=0:
        raise ValueError("aligned weights and positive NAV required")
    delta=[b[i]-a[i] for i in range(len(a))];trades=[nav*x for x in delta]
    gross=sum(abs(x) for x in trades);display=[_float(x) for x in trades]
    if abs(sum(Fraction(str(x)) for x in display))>Fraction(1,10**12)*gross:
        raise ValueError("reported frictionless trades lose cash reconciliation")
    return {"trades":display,
            "one_way_turnover":_float(sum(abs(x) for x in delta)/2)}

def sample_covariance(a,b):
    a=_numbers(a,"sample a");b=_numbers(b,"sample b")
    if len(a)!=len(b) or len(a)<2:
        raise ValueError("aligned T>=2 required")
    ma=sum(a)/len(a);mb=sum(b)/len(b)
    return _float(sum((x-ma)*(y-mb) for x,y in zip(a,b))/(len(a)-1))

class Chapter16Tests(unittest.TestCase):
    w=[.5,.3,.2];mu=[.08,.05,.02]
    cov=[[.04,.006,0],[.006,.09,0],[0,0,.0004]]
    def test_01_return(self):self.assertAlmostEqual(portfolio_stats(self.w,self.mu,self.cov)["mean"],.059)
    def test_02_variance(self):self.assertAlmostEqual(portfolio_stats(self.w,self.mu,self.cov)["variance"],.019916)
    def test_03_volatility(self):self.assertAlmostEqual(portfolio_stats(self.w,self.mu,self.cov)["volatility"],math.sqrt(.019916))
    def test_04_variance_contributions(self):
        r=portfolio_stats(self.w,self.mu,self.cov)
        self.assertAlmostEqual(math.fsum(r["variance_contributions"]),r["variance"])
    def test_05_volatility_contributions(self):
        r=portfolio_stats(self.w,self.mu,self.cov)
        self.assertAlmostEqual(math.fsum(r["volatility_contributions"]),r["volatility"])
    def test_06_sample_covariance(self):self.assertAlmostEqual(sample_covariance([1,2,3],[2,4,6]),2)
    def test_07_drift_return(self):self.assertAlmostEqual(drift([.5,.5],[.1,0])["return"],.05)
    def test_08_drift_weights(self):self.assertAlmostEqual(drift([.5,.5],[.1,0])["weights"][0],.55/1.05)
    def test_09_trades(self):self.assertAlmostEqual(rebalance([.4,.6],[.5,.5],100)["trades"][0],10)
    def test_10_turnover(self):self.assertAlmostEqual(rebalance([.4,.6],[.5,.5],100)["one_way_turnover"],.1)
    def test_11_one_asset(self):self.assertAlmostEqual(portfolio_stats([1],[.07],[[.04]])["volatility"],.2)
    def test_12_invalid(self):
        for fn in (lambda:portfolio_stats([.4,.4],[.08,.05],[[.04,0],[0,.09]]),
                   lambda:sample_covariance([1],[2]),
                   lambda:drift([.5,.5],[-1,-1]),
                   lambda:rebalance([.5,.5],[.5,.5],0)):
            with self.assertRaises(ValueError):fn()

if __name__=="__main__":
    unittest.main(verbosity=2)
```

## 12. Troubleshooting and common misconceptions

| Issue | Explanation |
|---|---|
| Treating covariance as correlation | Correlation is dimensionless; covariance scales with volatilities |
| Summing standalone volatilities | Portfolio volatility depends on cross-asset covariance |
| Confusing variance with volatility | Variance is squared-return units; volatility is return units |
| Assuming more assets always diversify | Highly correlated positions can share substantial risk |
| Calling a dominated portfolio efficient | Check both expected return and variance |
| Confusing target with realized return | Expected return is an estimate, not a realized outcome |
| Treating a symmetric matrix as necessarily PSD | Symmetry alone is insufficient |
| Mixing daily and annual covariance | Align all horizons and scaling assumptions |
