## Learning objectives

Define expected return, derive expected portfolio return using linearity of expectation, calculate scenario-weighted expectations, distinguish forecasts from realized outcomes, and evaluate estimation uncertainty, changing weights, cash, short exposures, and the limits of historical averages.

## 1. What is an expected return?

A realized return is observed after an investment period. An **expected return** is a probability-weighted average of possible future returns under a specified model.

For a discrete return random variable R with possible outcomes rₛ and probabilities pₛ:

**E[R]=Σₛpₛrₛ**, where pₛ≥0 and Σₛpₛ=1.

For a continuous distribution with suitable integrability, the expectation is the integral of return against its probability distribution.

An expected return is not the most likely outcome, a promise, or a guaranteed rate. It depends on the model and the information available when the forecast is made.

## 2. Deriving expected portfolio return

For fixed **beginning-of-period weights** w₁,…,wₙ and aligned one-period simple asset returns R₁,…,Rₙ:

**Rₚ=ΣᵢwᵢRᵢ.**

By linearity of expectation:

**E[Rₚ]=ΣᵢwᵢE[Rᵢ].**

This identity does **not** require asset returns to be independent. Correlation matters for portfolio variance, but not for the weighted-sum expectation when weights are fixed.

If weights themselves are random and depend on returns, then in general **E[ΣwᵢRᵢ]** cannot be simplified to **ΣE[wᵢ]E[Rᵢ]** without additional assumptions.

## 3. Two-asset worked example

Suppose:

| Asset | Starting weight | Assumed expected return | Contribution to expectation |
|---|---:|---:|---:|
| A | 60% | 8% | 4.8 percentage points |
| B | 40% | 4% | 1.6 percentage points |
| **Portfolio** | **100%** | | **6.4 percentage points** |

Therefore:

**E[Rₚ]=.6(.08)+.4(.04)=.064=6.4%.**

This is a model-implied expectation for the specified period, not a prediction that the realized return will be exactly 6.4%.

## 4. Scenario-based expectations

Suppose two economic scenarios:

| Scenario | Probability | Asset A return | Asset B return |
|---|---:|---:|---:|
| Expansion | 25% | +20% | 0% |
| Slowdown | 75% | 0% | +10% |

Then:

**E[R_A]=.25(.20)+.75(0)=.05.**

**E[R_B]=.25(0)+.75(.10)=.075.**

With equal portfolio weights:

**E[Rₚ]=.5(.05)+.5(.075)=.0625=6.25%.**

Equivalently, scenario portfolio returns are 10% and 5%; their weighted mean is .25(.10)+.75(.05)=6.25%. Both routes agree because expectation is linear.

## 5. Scenario risk is separate from expectation

The same scenario model also permits variance calculation:

**Var(Rₚ)=Σₛpₛ(Rₚ,ₛ−E[Rₚ])².**

For returns +10% and −10% with probabilities [.5,.5], expected return is zero and variance is .01, giving SD=.10.

Two portfolios can have identical expected returns but very different risk. Portfolio variance and covariance matrices are developed later in Chapter 16.

## 6. Historical mean as an estimator

A common estimate of expected return is the arithmetic sample mean:

**μ̂=(1/T)ΣₜRₜ.**

This estimates a population mean under assumptions about sampling, stability, and representativeness. Historical averages can be noisy and may fail under regime shifts, survivorship bias, look-ahead bias, selection, or structural changes.

For returns [.10,.30], the sample mean is .20, but two observations provide very weak evidence about a stable future mean.

A **forecast** should be distinguished from a **historical estimate** and from a **realized outcome**.

## 7. Estimation uncertainty

Expected returns are particularly difficult to estimate accurately from financial time series. A sample mean may have a large standard error relative to its magnitude.

Under iid observations with finite variance, the estimated standard error is approximately:

**SE(μ̂)=s/√T.**

Serial correlation, heteroskedasticity, overlapping returns, and nonstationarity can invalidate the naive iid formula.

Report assumptions and uncertainty alongside any expected-return estimate. Never interpret a point estimate as a precise forecast.

## 8. Cash and risk-free assets

A cash allocation contributes to portfolio expected return just like any other asset:

**E[Rₚ]=w_cashE[R_cash]+Σ_risky wᵢE[Rᵢ].**

For weights [.5,.4,.1] and expected returns [.08,.04,.02], the portfolio expectation is:

**.5(.08)+.4(.04)+.1(.02)=.058=5.8%.**

A cash-like or risk-free return must use the same time horizon and currency as the other returns. In practice, cash, Treasury instruments, and funding accounts can carry reinvestment, credit, liquidity, or currency considerations.

## 9. Long-short expected returns

For signed weights [1.2,−.2] and expected asset returns [.10,.05]:

**E[Rₚ]=1.2(.10)−.2(.05)=.11=11%.**

This simplified exposure expectation omits borrowing fees, short rebates, margin, collateral, and other financing costs. A leveraged strategy requires an explicit economic and accounting model.

## 10. Expected versus realized portfolio return

Let the forecast at time t be **μ̂ₚ,t**, and the subsequent realized portfolio return be **Rₚ,t+1**.

A simple forecast error is:

**eₜ₊₁=Rₚ,t+1−μ̂ₚ,t.**

For a forecast of 5% and realized return of 2%, the forecast error is −3 percentage points.

Evaluation should use forecasts that were actually available at the decision time. Re-estimating a forecast using future observations introduces look-ahead bias.

## 11. Multi-period expectations and compounding

The arithmetic expected return per period and expected multi-period compounded return are not generally interchangeable.

If each period deterministically returns 1%, twelve-period compounded return is:

**(1.01)¹²−1≈12.6825%.**

Multiplying a monthly mean by twelve gives a 12% **arithmetic annualization approximation**, not the same quantity as a compound annual return.

For random returns, the expectation of the product **E[∏(1+Rₜ)]** depends on the joint distribution across periods. Independence or other assumptions may permit simplification, but those assumptions must be stated.

## 12. Changing portfolio weights

For a dynamically managed portfolio, weights vary through time. The one-period conditional expected return, given information at decision time, can be written:

**E[Rₚ,t+1 | Fₜ]=Σᵢwᵢ,t E[Rᵢ,t+1 | Fₜ]**

when wᵢ,t are determined using information available at time t.

This emphasizes the difference between a fixed-weight model and a strategy whose allocations respond to forecasts or market conditions.

## 13. Estimation methods and practical limitations

Possible sources of expected-return estimates include historical means, forward-looking economic scenarios, factor models, analyst forecasts, implied market expectations, and Bayesian/shrinkage approaches.

Each introduces assumptions and uncertainty. Forecasts should be documented with a model version, estimation window, timestamp, asset universe, return horizon, and source data.

Avoid using future prices, revised statements, or present-day survivor lists when reconstructing historical expected-return estimates.

## 14. Python reference implementation

Save as `expected_portfolio_return.py`. The standard-library implementation calculates weighted expectations, scenario-based expected returns and portfolio distributions, historical arithmetic means, and forecast errors. It includes **12 reference unit tests**.

```python
import math
import unittest

def finite_vector(values):
    if not isinstance(values,(list,tuple)) or not values:
        raise ValueError("nonempty vector required")
    if any(type(x) not in (int,float) or not math.isfinite(x) for x in values):
        raise ValueError("finite numeric values required")
    return [float(x) for x in values]

def expected_portfolio_return(weights, expected_returns, allow_short=False):
    w=finite_vector(weights)
    mu=finite_vector(expected_returns)
    if len(w)!=len(mu):
        raise ValueError("weights and expected returns must align")
    if not allow_short and any(x<0 for x in w):
        raise ValueError("long-only weights required")
    if not math.isclose(math.fsum(w),1.0,rel_tol=0,abs_tol=1e-10):
        raise ValueError("fully invested weights must sum to one")
    return math.fsum(a*b for a,b in zip(w,mu))

def scenario_expected_returns(probabilities, scenario_asset_returns):
    p=finite_vector(probabilities)
    if any(x<0 for x in p) or not math.isclose(math.fsum(p),1,rel_tol=0,abs_tol=1e-10):
        raise ValueError("valid scenario probabilities must sum to one")
    if not isinstance(scenario_asset_returns,(list,tuple)) or len(p)!=len(scenario_asset_returns):
        raise ValueError("one asset-return row per scenario required")
    rows=[finite_vector(row) for row in scenario_asset_returns]
    n=len(rows[0])
    if any(len(row)!=n for row in rows):
        raise ValueError("scenario rows must have equal asset count")
    return [math.fsum(p[s]*rows[s][i] for s in range(len(p))) for i in range(n)]

def scenario_portfolio_distribution(weights,probabilities,scenario_asset_returns):
    p=finite_vector(probabilities)
    if any(x<0 for x in p) or not math.isclose(math.fsum(p),1,rel_tol=0,abs_tol=1e-10):
        raise ValueError("probabilities must sum to one")
    if len(p)!=len(scenario_asset_returns):
        raise ValueError("scenario count mismatch")
    returns=[expected_portfolio_return(weights,row,allow_short=True) for row in scenario_asset_returns]
    mu=math.fsum(a*b for a,b in zip(p,returns))
    var=math.fsum(a*(r-mu)**2 for a,r in zip(p,returns))
    return {"scenario_returns":returns,"mean":mu,"variance":var,"sd":math.sqrt(var)}

def historical_mean_returns(return_rows):
    if not isinstance(return_rows,(list,tuple)) or not return_rows:
        raise ValueError("nonempty observations required")
    rows=[finite_vector(row) for row in return_rows]
    n=len(rows[0])
    if any(len(row)!=n for row in rows):
        raise ValueError("aligned observations required")
    return [math.fsum(row[i] for row in rows)/len(rows) for i in range(n)]

def forecast_error(forecast, realized):
    f,r=finite_vector(forecast),finite_vector(realized)
    if len(f)!=len(r):
        raise ValueError("aligned vectors required")
    return [actual-predicted for predicted,actual in zip(f,r)]

class ExpectedPortfolioReturnTests(unittest.TestCase):
    def test_01_weighted(self): self.assertAlmostEqual(expected_portfolio_return([.6,.4],[.08,.04]),.064)
    def test_02_equal(self): self.assertAlmostEqual(expected_portfolio_return([.5,.5],[.1,0]),.05)
    def test_03_cash(self): self.assertAlmostEqual(expected_portfolio_return([.5,.4,.1],[.08,.04,.02]),.058)
    def test_04_short(self): self.assertAlmostEqual(expected_portfolio_return([1.2,-.2],[.1,.05],True),.11)
    def test_05_scenario_mu(self):
        mu=scenario_expected_returns([.25,.75],[[.2,0],[0,.1]])
        self.assertAlmostEqual(mu[0],.05)
        self.assertAlmostEqual(mu[1],.075)
    def test_06_scenario_portfolio(self):
        d=scenario_portfolio_distribution([.5,.5],[.25,.75],[[.2,0],[0,.1]])
        self.assertAlmostEqual(d["mean"],.0625)
    def test_07_scenario_variance(self):
        d=scenario_portfolio_distribution([1],[.5,.5],[[.1],[-.1]])
        self.assertAlmostEqual(d["variance"],.01)
    def test_08_historical(self): self.assertEqual(historical_mean_returns([[.1,.2],[.3,.4]]),[.2,.30000000000000004])
    def test_09_forecast_error(self): self.assertAlmostEqual(forecast_error([.05],[.02])[0],-.03)
    def test_10_zero_weight(self): self.assertAlmostEqual(expected_portfolio_return([1,0],[.03,.99]),.03)
    def test_11_one_scenario(self):
        self.assertAlmostEqual(scenario_portfolio_distribution([1],[1],[[.04]])["sd"],0)
    def test_12_invalid(self):
        for fn in (lambda:expected_portfolio_return([.5,.4],[.1,.2]),
                   lambda:expected_portfolio_return([.5,.5],[.1]),
                   lambda:expected_portfolio_return([1.2,-.2],[.1,.2]),
                   lambda:scenario_expected_returns([.2,.2],[[.1],[.2]]),
                   lambda:historical_mean_returns([[.1],[.1,.2]]),
                   lambda:forecast_error([.1],[.1,.2])):
            with self.assertRaises(ValueError):fn()

if __name__=="__main__":
    print("Expected return:",expected_portfolio_return([.6,.4],[.08,.04]))
    unittest.main(verbosity=2)
```

## 17. Troubleshooting

| Symptom | Likely cause | Recommended action |
|---|---|---|
| Forecast weights sum to less than one | Missing cash or allocation | Reconcile complete portfolio |
| Scenario probabilities do not sum to one | Invalid probability model | Validate and document probabilities |
| Expected return confused with realized return | Forecast/outcome mix-up | Record forecast and observation dates |
| High forecast precision with little data | Estimation uncertainty ignored | Quantify uncertainty |
| Scenario and asset-weight methods disagree | Alignment or calculation error | Reconcile scenario inputs |
| Forecast changes after backtest | Look-ahead or revised inputs | Preserve point-in-time versions |
| Expected annual return inconsistent | Arithmetic versus compounding | Specify annualization convention |
| Short strategy forecast overstated | Financing costs omitted | Model funding and margin |
