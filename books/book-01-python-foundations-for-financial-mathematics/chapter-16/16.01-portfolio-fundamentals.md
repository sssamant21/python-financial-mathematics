## 1. What is a portfolio?

A **portfolio** is a collection of financial positions: securities, cash, derivatives, liabilities, or other exposures. A portfolio is not simply a list of tickers; quantities, valuation timestamps, currency, financing, and legal constraints all affect its economics.

For n assets, define quantity qᵢ, current unit price Pᵢ, and position value:

**Vᵢ=qᵢPᵢ**.

For a simple long-only portfolio with no liabilities:

**V=ΣᵢVᵢ**.

For two shares priced at $100 and three shares priced at $50, V=$200+$150=$350.

## 2. Portfolio weights

For positive total portfolio value V, the value weight of asset i is:

**wᵢ=Vᵢ/V**.

A fully invested portfolio satisfies **Σwᵢ=1**, provided all relevant holdings, including cash, are included.

If asset A is worth $600 and asset B $400, weights are [.6,.4]. If 10% is held in cash, the risky-asset weights might be [.6,.3] and cash .1.

Weights must be tied to a **valuation time**. Beginning-of-period and end-of-period weights are generally different.

## 3. Long-only, short, and leveraged positions

A **long-only** portfolio has wᵢ≥0. A short position can be represented by a negative market-value exposure, subject to financing and margin conventions.

**Net exposure:** Σwᵢ.

**Gross exposure:** Σ|wᵢ|.

For [1.2,−.2], net exposure=1 and gross exposure=1.4. This illustrates leveraged gross exposure even though the net weights sum to 1.

Short-sale proceeds, borrowing costs, collateral, and derivatives may require a more sophisticated capital and exposure definition. A simple signed-weight formula is not a complete margin model.

## 4. Portfolio return

For a single holding period, if wᵢ are **beginning-of-period value weights** and Rᵢ are consistently defined asset total returns, a self-financing portfolio without external flows has:

**Rₚ=ΣᵢwᵢRᵢ**.

For [.6,.4] and returns [.10,−.05]:

**Rₚ=.6(.10)+.4(−.05)=.04=4%**.

This identity depends on consistent asset valuation, return horizons, and treatment of cash flows, financing, and costs.

A 4% portfolio return does not imply both components performed well.

## 5. Expected portfolio return

By linearity of expectation, for fixed starting weights:

**E[Rₚ]=ΣᵢwᵢE[Rᵢ]**.

For weights [.6,.4] and expected returns [.08,.04], the expected return is:

**.6(.08)+.4(.04)=.064=6.4%**.

This is an expectation under an assumed return model, not a guaranteed result. Estimation error in expected returns can dominate portfolio decisions.

## 6. Diversification versus asset count

Diversification means spreading exposure across sources of uncertainty. Owning many assets does not necessarily diversify risk if their returns move together.

For two assets:

**Var(Rₚ)=w₁²σ₁²+w₂²σ₂²+2w₁w₂Cov(R₁,R₂)**.

Equivalently:

**Var(Rₚ)=w₁²σ₁²+w₂²σ₂²+2w₁w₂ρ₁₂σ₁σ₂**.

A lower correlation can reduce portfolio variance for fixed positive weights and marginal volatilities. Negative correlation can provide substantial diversification, but relationships can change under stress.

Detailed covariance-matrix mathematics follows in Sections 16.5–16.7.

## 7. Concentration and exposure

A portfolio with 90% of capital in one asset is concentrated even if it holds many other securities.

Common exposure limits include issuer, sector, region, currency, duration, factor, liquidity, and counterparty limits. Weight limits should be measured on a clearly defined denominator.

Gross exposure and net exposure answer different questions; both matter when shorting or leverage is permitted.

## 8. Weight drift

Suppose a 50/50 portfolio experiences asset returns of +10% and 0%.

After the returns, before rebalancing:

**w₁,new=.5(1.1)/[.5(1.1)+.5(1.0)]=1.1/2.1≈.52381**.

**w₂,new=1/2.1≈.47619**.

The portfolio no longer has equal weights. Weight drift occurs even without trading.

For long-only weights and asset returns greater than −100%, the general expression is:

**wᵢ,new=wᵢ(1+Rᵢ)/[Σⱼwⱼ(1+Rⱼ)]**.

The reference code deliberately excludes a complete asset bankruptcy from this helper to avoid ambiguous treatment of extinguished holdings; a production implementation would define a zero-valued position policy explicitly.

## 9. Rebalancing and costs

**Rebalancing** trades assets to restore target weights. Common schedules are periodic, threshold-based, or triggered by risk and cash-flow changes.

Rebalancing can maintain intended risk exposure but generates transaction costs, potential taxes, market impact, and operational work. It does not guarantee improved performance.

A practical workflow distinguishes **target weights**, **current weights**, **trade quantities**, **execution prices**, and **post-trade weights**.

## 10. Currency, cash flows, and corporate actions

For a foreign asset, base-currency return combines local asset performance and exchange-rate changes. A simplified gross-return identity is:

**1+R_base=(1+R_local)(1+R_FX)**,

when R_FX uses the exchange-rate direction consistent with the base currency.

Dividends, splits, spin-offs, fees, and external contributions require explicit accounting. A deposit increases portfolio value but is not automatically investment profit.

For performance measurement with external flows, consider time-weighted or money-weighted return methods from Chapter 13.

## 11. Portfolio constraints

Examples of common constraints:

- Fully invested: Σwᵢ=1.
- Long-only: wᵢ≥0.
- Maximum issuer weight: wᵢ≤cᵢ.
- Cash minimum: w_cash≥c.
- Gross exposure cap: Σ|wᵢ|≤L.
- Sector and country exposure limits.
- Turnover and liquidity limits.

Not every combination of constraints is feasible. Later chapters examine portfolio constraints and optimization concepts in greater detail.

## 12. Python reference implementation

Save as `portfolio_fundamentals.py`. The standard-library code demonstrates weights, portfolio value, return, and drift, with **12 reference unit tests**.

```python
import math
import unittest

def checked_weights(weights, tol=1e-10, long_only=True):
    if not isinstance(weights,(list,tuple)) or not weights:
        raise ValueError("nonempty weights required")
    if any(type(w) not in (int,float) or not math.isfinite(w) for w in weights):
        raise ValueError("finite numeric weights required")
    if long_only and any(w<0 for w in weights):
        raise ValueError("long-only weights cannot be negative")
    if not math.isclose(math.fsum(weights),1.0,rel_tol=0,abs_tol=tol):
        raise ValueError("fully invested weights must sum to 1")
    return [float(w) for w in weights]

def portfolio_return(weights,asset_returns,long_only=True):
    w=checked_weights(weights,long_only=long_only)
    if not isinstance(asset_returns,(list,tuple)) or len(w)!=len(asset_returns):
        raise ValueError("one return per asset required")
    if any(type(r) not in (int,float) or not math.isfinite(r) for r in asset_returns):
        raise ValueError("finite numeric returns required")
    return math.fsum(a*b for a,b in zip(w,asset_returns))

def portfolio_value(holdings,prices):
    if not isinstance(holdings,(list,tuple)) or not isinstance(prices,(list,tuple)) or not holdings or len(holdings)!=len(prices):
        raise ValueError("aligned holdings and prices required")
    if any(type(x) not in (int,float) or not math.isfinite(x) for x in holdings+prices):
        raise ValueError("finite numeric values required")
    if any(p<=0 for p in prices):
        raise ValueError("positive prices required")
    return math.fsum(q*p for q,p in zip(holdings,prices))

def weights_from_values(values):
    if not isinstance(values,(list,tuple)) or not values or any(type(v) not in (int,float) or not math.isfinite(v) or v<0 for v in values):
        raise ValueError("nonnegative finite values required")
    total=math.fsum(values)
    if total<=0:
        raise ValueError("total portfolio value must be positive")
    return [v/total for v in values]

def post_return_weights(weights,asset_returns):
    w=checked_weights(weights)
    if not isinstance(asset_returns,(list,tuple)) or len(w)!=len(asset_returns) or any(type(r) not in (int,float) or not math.isfinite(r) or r<=-1 for r in asset_returns):
        raise ValueError("aligned returns > -100% required")
    grown=[a*(1+r) for a,r in zip(w,asset_returns)]
    total=math.fsum(grown)
    return [v/total for v in grown]

class PortfolioFundamentalsTests(unittest.TestCase):
    def test_01_weights(self): self.assertEqual(checked_weights([.6,.4]),[.6,.4])
    def test_02_portfolio_return(self): self.assertAlmostEqual(portfolio_return([.6,.4],[.1,-.05]),.04)
    def test_03_equal_weight(self): self.assertAlmostEqual(portfolio_return([.5,.5],[.1,-.1]),0)
    def test_04_value(self): self.assertEqual(portfolio_value([2,3],[100,50]),350)
    def test_05_value_weights(self): self.assertEqual(weights_from_values([60,40]),[.6,.4])
    def test_06_drift(self):
        w=post_return_weights([.5,.5],[.1,0])
        self.assertAlmostEqual(w[0],1.1/2.1)
    def test_07_zero_weight(self): self.assertAlmostEqual(portfolio_return([1,0],[.1,-.5]),.1)
    def test_08_short_allowed(self): self.assertAlmostEqual(portfolio_return([1.2,-.2],[.1,.05],False),.11)
    def test_09_invalid_sum(self):
        with self.assertRaises(ValueError):checked_weights([.6,.3])
    def test_10_invalid_negative(self):
        with self.assertRaises(ValueError):checked_weights([1.2,-.2])
    def test_11_invalid_price(self):
        with self.assertRaises(ValueError):portfolio_value([1],[0])
    def test_12_invalid_bankruptcy(self):
        with self.assertRaises(ValueError):post_return_weights([.5,.5],[-1,0])

if __name__=="__main__":
    print("Portfolio return:",portfolio_return([.6,.4],[.1,-.05]))
    print("Drifted weights:",post_return_weights([.5,.5],[.1,0]))
    unittest.main(verbosity=2)
```

## 14. Twenty-four worked exercises

1. **Portfolio definition:** A portfolio holds two securities. **Worked solution:** It is a set of positions whose combined value and risk depend on holdings and market prices.

2. **Value:** 2 shares at $100 and 3 shares at $50. **Worked solution:** Total=$350.

3. **Weights:** Positions worth $600 and $400. **Worked solution:** Weights=.6 and .4.

4. **Full investment:** Weights [.6,.4]. **Worked solution:** Sum=1.

5. **Invalid weights:** Weights [.6,.3]. **Worked solution:** Sum=.9, so not fully invested without an explicit cash weight.

6. **Cash allocation:** Risky assets .6,.3 and cash .1. **Worked solution:** Total=1.

7. **Equal weights:** Two assets. **Worked solution:** [.5,.5].

8. **Portfolio return:** Weights [.6,.4], returns [.1,−.05]. **Worked solution:** .6(.1)+.4(−.05)=.04.

9. **Diversification:** Two risky assets. **Worked solution:** Risk reduction depends on covariance, not simply asset count.

10. **Concentration:** Weight .9 in one asset. **Worked solution:** High concentration despite multiple holdings.

11. **Long-only:** Weights [.7,.3]. **Worked solution:** No negative positions.

12. **Short exposure:** Weights [1.2,−.2]. **Worked solution:** Gross exposure=1.4; net=1.0.

13. **Gross exposure:** Weights [1.2,−.2]. **Worked solution:** |1.2|+|−.2|=1.4.

14. **Portfolio drift:** 50/50 weights, returns 10% and 0%. **Worked solution:** New weights 1.1/2.1 and 1/2.1.

15. **Rebalancing:** Drifted weights. **Worked solution:** Trading restores target allocations and incurs potential costs.

16. **Expected return:** Weights [.6,.4], expected returns [.08,.04]. **Worked solution:** Expected portfolio return=.064 under linearity.

17. **Risk:** Two assets with equal volatility. **Worked solution:** Portfolio volatility also depends on correlation.

18. **Return timing:** Weights measured after period closes. **Worked solution:** Cannot automatically use as starting-period weights.

19. **Corporate actions:** Stock split. **Worked solution:** Share count and price change; economic value should be preserved.

20. **FX exposure:** Foreign stock priced in EUR. **Worked solution:** USD portfolio return includes FX movements.

21. **Cash flows:** External deposit during return period. **Worked solution:** Separate contribution from investment performance.

22. **Leverage:** Borrow to increase exposure. **Worked solution:** Potential losses and funding constraints rise.

23. **Constraints:** Maximum 30% per issuer. **Worked solution:** Requires portfolio weight limits.

24. **Risk-free:** Cash-like allocation. **Worked solution:** Not necessarily riskless after inflation, currency, or credit considerations.

## 15. Troubleshooting

| Symptom | Likely cause | Corrective action |
|---|---|---|
| Weights do not sum to one | Cash or liabilities omitted | Reconcile all exposures |
| Negative weights rejected | Long-only validation active | Specify short-allowed policy |
| Portfolio return differs from account P&L | External flows or costs | Reconcile performance accounting |
| Portfolio value differs by currency | FX conversion mismatch | Define base currency and timestamp |
| Unexpected weight drift | Unequal asset returns | Recompute post-period weights |
| Apparent diversification fails | Correlations rise in stress | Examine covariance and scenarios |
| Leverage understated | Only net exposure reported | Include gross and financing exposure |
| Split changes measured wealth | Unadjusted holdings or prices | Reconcile corporate actions |
