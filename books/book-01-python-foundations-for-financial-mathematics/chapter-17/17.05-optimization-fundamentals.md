## Learning objectives

Define an optimization problem with objective, decision variables, and constraints; distinguish minimization from maximization and local from global optima; recognize convexity, gradients, Hessians, and first-order conditions; compare analytic and numerical approaches; implement a reproducible scalar search; and independently validate portfolio optimization results.

## 1. Why optimization matters in finance

Optimization chooses a decision that best satisfies a stated goal. Financial applications include portfolio risk minimization, asset allocation, hedging, transaction-cost reduction, capital budgeting, model calibration, and cash management.

A numerical optimizer returns a candidate decision. Whether that decision is acceptable depends on the **objective definition, constraints, assumptions, data quality, and independent verification**.

## 2. Standard mathematical formulation

A constrained minimization problem is

**minimize f(x)**

subject to **gᵢ(x)≤0**, **hⱼ(x)=0**, and bounds **l≤x≤u**.

Here x is a vector of decision variables; f is the objective; g and h encode inequality and equality constraints. Maximizing utility U(x) can be rewritten as minimizing −U(x).

Examples of financial decision variables include portfolio weights, hedge ratios, borrowing amounts, and calibrated volatility parameters.

## 3. Feasibility comes before optimality

A candidate solution is **feasible** if it satisfies every hard constraint.

For portfolio weights, a typical mandate includes:

- Fully invested budget: Σwᵢ=1.
- Long-only: wᵢ≥0.
- Position caps: wᵢ≤uᵢ.
- Sector exposure caps.
- Minimum or maximum portfolio risk.
- Liquidity and turnover requirements.

An infeasible solution is not acceptable merely because it has a low objective value. Check for inconsistent bounds before solving.

## 4. Analytic scalar optimization

Consider

**f(x)=(x−.3)²**.

The derivative is **f′(x)=2(x−.3)**, so the stationary point is x=.3. Since **f″(x)=2>0**, this is a strict global minimum.

If the feasible interval is [.5,1], x=.3 is not permitted. The constrained minimum occurs at **x=.5**.

This is a simple benchmark for testing numerical algorithms.

## 5. First-order and second-order conditions

For differentiable unconstrained optimization, an interior local minimum typically satisfies **∇f(x*)=0**.

A positive-definite Hessian at a stationary point is sufficient for a strict local minimum. A positive-semidefinite Hessian alone does not necessarily prove a strict minimum.

For constrained problems, a solution can lie on a boundary with a nonzero unconstrained gradient. This motivates Lagrange multipliers and Karush–Kuhn–Tucker conditions, developed in the next section.

## 6. Convexity and global optimality

A convex objective over a convex feasible set has the useful property that **every local minimum is global**.

For twice-differentiable objectives, a positive-semidefinite Hessian throughout a convex domain is a sufficient condition for convexity.

Portfolio variance **wᵀΣw** is convex when covariance Σ is positive semidefinite. Real-world constraints such as integer share counts or cardinality limits can make a problem nonconvex.

## 7. Numerical grid search

A grid search evaluates an objective at a finite set of candidate points.

For x∈[0,1] with step .1, the candidates are 0,.1,...,1. The function **(x−.3)²** reaches its grid minimum at x=.3.

Advantages: simple, deterministic, transparent, and useful as a test oracle.

Limitations: resolution is limited by grid spacing; computational cost increases quickly with dimension; and a discrete grid optimum is not necessarily the continuous optimum.

## 8. Golden-section search

For a continuous **unimodal** scalar objective on [a,b], golden-section search reduces the interval while reusing function evaluations.

The contraction factor is **(√5−1)/2≈.618034**.

Golden-section search does not require derivatives and can be more efficient than a dense grid. It is not a global optimization guarantee for arbitrary multimodal functions.

## 9. Gradient-based optimization

For a smooth scalar objective, gradient descent updates:

**xₖ₊₁=xₖ−αₖ∇f(xₖ)**,

where αₖ is a step size.

Poor step sizes can cause slow convergence or divergence. Gradient scaling, conditioning, line searches, and stopping criteria matter. Newton and quasi-Newton optimization methods use curvature information or approximations to improve convergence.

## 10. Portfolio variance minimization

Given covariance matrix Σ and weights w:

**minimize wᵀΣw**

subject to **Σᵢwᵢ=1**, **wᵢ≥0**, and applicable limits.

For two assets with variance A=σA², variance B=σB², and covariance C, let w be the weight in A and 1−w in B.

Then

**V(w)=w²A+(1−w)²B+2w(1−w)C**.

Differentiating and setting the derivative to zero yields:

**wA*=(B−C)/(A+B−2C)**,

provided the denominator is positive. For a long-only portfolio, clamp this analytic unconstrained weight to [0,1].

If the denominator is zero for a valid PSD covariance, the two-asset variance is constant across budget-feasible mixes and the minimizer is nonunique.

## 11. Worked minimum-variance example

Let A=.04, B=.09, C=0.

Then:

**wA=.09/(.04+.09)=9/13≈69.23%**.

**wB=4/13≈30.77%**.

The minimum portfolio variance is:

**(.04×.09)/(.04+.09)=.0036/.13≈.0276923**.

Volatility is **√.0276923≈16.64%**.

These analytic results provide independent reference values for a numerical optimizer.

## 12. Covariance validation

Covariance matrices must be symmetric and positive semidefinite. For a two-asset covariance matrix, this requires nonnegative diagonal variances and

**C²≤AB**.

For A=.04 and B=.09, the covariance magnitude cannot exceed .06. A covariance of .10 is mathematically invalid.

A solver may return a number even with malformed risk inputs. Validate the matrix before optimizing.

## 13. Constraints and boundary optima

Suppose a minimum-variance portfolio calls for 69.23% in A, but policy caps A at 40%. The unconstrained optimum is infeasible; a constrained optimizer must choose within the allowed region.

For a convex one-dimensional quadratic, the constrained minimum is the projection of the unconstrained minimizer onto the feasible interval.

This simple case illustrates why a production optimizer must check its returned solution against every investment policy rule.

## 14. Objective functions and units

Common portfolio objectives include:

- Minimize variance.
- Maximize expected return at a given risk limit.
- Minimize tracking error.
- Minimize transaction cost for a required rebalance.
- Maximize a risk-adjusted utility function.

Expected return is in return units, variance is in squared-return units, and transaction costs may be currency or basis points. Combining objectives without explicit scaling can produce meaningless tradeoffs.

## 15. Lagrangians and constrained optimization preview

For equality-constrained optimization **minimize f(x)** subject to **h(x)=0**, define the Lagrangian:

**L(x,λ)=f(x)+λh(x)**.

Under suitable regularity assumptions, first-order optimality requires stationarity with respect to x and satisfaction of h(x)=0.

With inequality constraints, KKT conditions additionally involve multiplier signs and complementary slackness. These concepts are treated in greater depth in Section 17.6.

## 16. SciPy optimization introduction

SciPy offers scalar and multivariable optimizers.

```python
from scipy.optimize import minimize_scalar, minimize

scalar = minimize_scalar(
    lambda x: (x - 0.3)**2,
    bounds=(0.0, 1.0),
    method="bounded",
)
if not scalar.success:
    raise RuntimeError(scalar.message)
assert abs(scalar.x - 0.3) < 1e-5

vector = minimize(
    lambda w: w[0]**2 + 2*w[1]**2,
    x0=[0.5, 0.5],
    bounds=[(0, 1), (0, 1)],
    constraints=[{"type": "eq", "fun": lambda w: w[0] + w[1] - 1}],
    method="SLSQP",
)
if not vector.success:
    raise RuntimeError(vector.message)
assert abs(sum(vector.x) - 1) < 1e-7
```

This example requires SciPy. Solver success must still be accompanied by explicit feasibility and objective checks.

## 17. Solver diagnostics and validation

Record the objective, variables, bounds, constraint tolerances, solver method, initial guess, iteration limit, objective value, and convergence status.

A robust acceptance process also:

1. Verifies all constraints independently.
2. Compares against an analytic benchmark when available.
3. Checks objective sensitivity to input perturbations.
4. Repeats with different starting points for nonconvex problems.
5. Evaluates whether estimated inputs are economically plausible.
6. Retains a reproducible record of data and code revisions.

## 18. Complete standard-library reference implementation

Save as `optimization_fundamentals.py`. The code includes scalar grid search, golden-section search, portfolio variance evaluation, a two-asset minimum-variance formula, and **12 reference unit tests**.

```python
"""17.5 Optimization fundamentals: deterministic standard-library reference."""
import math
import unittest

def finite(x):
    return type(x) in (int,float) and math.isfinite(x)

def grid_minimize(f,lo,hi,steps=1000):
    if not all(finite(x) for x in (lo,hi)) or not lo<hi or type(steps) is not int or steps<1:
        raise ValueError("invalid grid")
    dx=(hi-lo)/steps
    best=None
    for i in range(steps+1):
        x=lo+i*dx
        y=f(x)
        if not finite(y):raise ValueError("nonfinite objective")
        if best is None or y<best["value"]:
            best={"x":x,"value":y,"index":i,"spacing":dx}
    return best

def golden_minimize(f,lo,hi,tol=1e-10,max_iter=300):
    if not all(finite(x) for x in (lo,hi,tol)) or not lo<hi or tol<=0 or type(max_iter) is not int or max_iter<1:
        raise ValueError("invalid inputs")
    ratio=(math.sqrt(5)-1)/2
    a,b=lo,hi
    c=b-ratio*(b-a)
    d=a+ratio*(b-a)
    fc,fd=f(c),f(d)
    if not finite(fc) or not finite(fd):raise ValueError("nonfinite objective")
    for i in range(1,max_iter+1):
        if b-a<=tol:
            x=(a+b)/2
            y=f(x)
            if not finite(y):raise ValueError("nonfinite objective")
            return {"x":x,"value":y,"iterations":i-1,"interval":(a,b)}
        if fc<=fd:
            b,d,fd=d,c,fc
            c=b-ratio*(b-a)
            fc=f(c)
            if not finite(fc):raise ValueError("nonfinite objective")
        else:
            a,c,fc=c,d,fd
            d=a+ratio*(b-a)
            fd=f(d)
            if not finite(fd):raise ValueError("nonfinite objective")
    raise RuntimeError("iteration limit")

def portfolio_variance(w,cov):
    n=len(w)
    if not n or len(cov)!=n or any(len(row)!=n for row in cov):
        raise ValueError("matrix dimensions")
    if any(not finite(x) for x in w) or any(not finite(x) for row in cov for x in row):
        raise ValueError("nonfinite inputs")
    if any(x<0 for x in w) or not math.isclose(math.fsum(w),1,abs_tol=1e-10):
        raise ValueError("long-only budget")
    if any(not math.isclose(cov[i][j],cov[j][i],abs_tol=1e-12,rel_tol=1e-10)
           for i in range(n) for j in range(n)):
        raise ValueError("asymmetric covariance")
    value=math.fsum(w[i]*cov[i][j]*w[j] for i in range(n) for j in range(n))
    if value< -1e-12:raise ValueError("negative portfolio variance")
    return max(0,value)

def two_asset_min_variance(var_a,var_b,cov_ab):
    if not all(finite(x) for x in (var_a,var_b,cov_ab)) or min(var_a,var_b)<0:
        raise ValueError("invalid variances")
    if cov_ab*cov_ab>var_a*var_b+1e-12:
        raise ValueError("non-PSD two-asset covariance")
    den=var_a+var_b-2*cov_ab
    if den<=1e-15:
        return {"weight_a":0.5,"weight_b":0.5,"nonunique":True}
    wa=min(1,max(0,(var_b-cov_ab)/den))
    return {"weight_a":wa,"weight_b":1-wa,"nonunique":False}

class OptimizationTests(unittest.TestCase):
    def test_01_grid(self):self.assertAlmostEqual(grid_minimize(lambda x:(x-.3)**2,0,1,10)["x"],.3)
    def test_02_golden(self):self.assertAlmostEqual(golden_minimize(lambda x:(x-.3)**2,0,1)["x"],.3,places=6)
    def test_03_boundary(self):self.assertAlmostEqual(grid_minimize(lambda x:(x-.3)**2,.5,1,10)["x"],.5)
    def test_04_min_value(self):self.assertAlmostEqual(golden_minimize(lambda x:(x-2)**2,-1,5)["value"],0,places=8)
    def test_05_portfolio(self):self.assertAlmostEqual(portfolio_variance([.5,.5],[[.04,0],[0,.09]]),.0325)
    def test_06_min_var(self):self.assertAlmostEqual(two_asset_min_variance(.04,.09,0)["weight_a"],9/13)
    def test_07_cap_boundary(self):self.assertEqual(two_asset_min_variance(.04,.09,-.01)["nonunique"],False)
    def test_08_nonunique(self):self.assertTrue(two_asset_min_variance(.04,.04,.04)["nonunique"])
    def test_09_invalid_psd(self):
        with self.assertRaises(ValueError):two_asset_min_variance(.04,.09,.1)
    def test_10_budget(self):
        with self.assertRaises(ValueError):portfolio_variance([.4,.4],[[.04,0],[0,.09]])
    def test_11_nonfinite(self):
        with self.assertRaises(ValueError):grid_minimize(lambda x:float("nan"),0,1,10)
    def test_12_iteration(self):
        with self.assertRaises(RuntimeError):golden_minimize(lambda x:(x-.3)**2,0,1,1e-15,1)

if __name__=="__main__":
    print("Grid:",grid_minimize(lambda x:(x-.3)**2,0,1,100))
    print("Golden:",golden_minimize(lambda x:(x-.3)**2,0,1))
    print("Two-asset GMV:",two_asset_min_variance(.04,.09,0))
    unittest.main(verbosity=2)
```

## 21. Troubleshooting

| Symptom | Likely cause | Corrective action |
|---|---|---|
| Optimizer violates weight cap | Missing constraint or numerical tolerance | Check bounds and feasibility independently |
| Different starting points give different answers | Nonconvexity or local minima | Use multiple starts and global checks |
| Grid solution differs from analytic optimum | Coarse discretization | Refine grid |
| Golden search returns a local minimum | Objective is multimodal | Use appropriate global method |
| Negative portfolio variance | Invalid covariance or numerical issue | Validate PSD and calculations |
| Objective values have inconsistent units | Mixed return, variance, and currency | Normalize and document scaling |
| Solver reports success but poor financial result | Model or input risk | Perform economic validation |
| Algorithm stalls | Conditioning or stopping settings | Inspect gradient, tolerances, and scaling |
| No runtime evidence exists | Manuscript QA deferred | Execute and retain test results during QA |
