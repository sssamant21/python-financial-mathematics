## 1. Why numerical integration matters in finance

Financial calculations frequently aggregate a continuously varying quantity or average a payoff over a probability distribution. Applications include continuously paid cash flows, expected loss, option payoff expectations, probability calculations, and risk measures.

A definite integral is an accumulation:

**I=∫ₐᵇf(x)dx**.

When a closed-form antiderivative is unavailable or inconvenient, numerical integration approximates I using finite evaluations of f.

## 2. Integral as accumulated value

If f(t) is a cash-flow rate in dollars per year, then

**∫₀ᵀ f(t)dt**

is the undiscounted amount paid over T years.

If f(x) is a probability density, then

**∫ₐᵇ f(x)dx**

is the probability of a random variable falling in [a,b], subject to the model.

The units and interpretation of the integrand determine what the integral means economically.

## 3. Riemann sums and discretization

Partition [a,b] into n equal subintervals of width:

**h=(b−a)/n**.

A Riemann sum approximates the area by weighted rectangles. Refining n generally improves accuracy for well-behaved functions, but costs more evaluations.

Numerical integration is a balance between truncation error, floating-point error, and computational expense.

## 4. Composite midpoint rule

The midpoint approximation is:

**I_mid≈h Σᵢ₌₀ⁿ⁻¹ f(a+(i+1/2)h)**.

For f(x)=x on [0,1], the one-panel midpoint is x=.5, yielding the exact integral .5.

For sufficiently smooth functions, composite midpoint error is generally O(h²).

## 5. Composite trapezoidal rule

The trapezoidal approximation is:

**I_trap≈h[f(a)/2+Σᵢ₌₁ⁿ⁻¹ f(a+ih)+f(b)/2]**.

For f(x)=x on [0,1], one trapezoid gives (0+1)/2=.5, the exact result.

For sufficiently smooth functions, composite trapezoidal error is generally O(h²).

## 6. Composite Simpson's rule

Composite Simpson quadrature uses piecewise quadratic interpolation and requires an even number of panels:

**I_S≈(h/3)[f(x₀)+4f(x₁)+2f(x₂)+⋯+4f(xₙ₋₁)+f(xₙ)]**.

For f(x)=x² over [0,1] with n=2:

**I_S=(1/6)[0+4(.25)+1]=1/3**.

For sufficiently smooth functions, composite Simpson error is generally O(h⁴). It integrates polynomials of degree at most three exactly in exact arithmetic.

## 7. Error orders and smoothness

The usual O(h²) and O(h⁴) error statements rely on sufficient differentiability and bounded derivatives.

Discontinuities, kinks, endpoint singularities, rapidly oscillating functions, and heavy tails can degrade performance. When known discontinuities exist, splitting the integral into smooth pieces often improves reliability.

A small difference between successive refinements is useful evidence but does not prove the true error is small.

## 8. Worked integration benchmark

Consider:

**I=∫₀¹x²dx=1/3**.

Use midpoint, trapezoid, and Simpson methods with progressively refined grids. Compare each approximation against 1/3 and record absolute error:

**error=|I_approx−1/3|**.

This is an essential acceptance test for a numerical quadrature implementation.

## 9. Probability density and cumulative distribution

For a random variable X with density p(x), the cumulative distribution function is:

**F(z)=∫₋∞ᶻp(x)dx**.

For the standard normal distribution:

**φ(x)=exp(−x²/2)/√(2π)**.

Using symmetry:

**Φ(z)=.5+∫₀ᶻφ(x)dx**, interpreted as a signed integral for negative z.

Numerical integration can approximate Φ, although specialized library functions are generally more efficient and accurate.

## 10. Expected value as an integral

For a continuous random variable with density p(x):

**E[g(X)]=∫g(x)p(x)dx**.

If X is uniform on [0,1]:

**E[X]=∫₀¹x dx=.5**.

**E[X²]=∫₀¹x²dx=1/3**.

Thus:

**Var(X)=E[X²]−E[X]²=1/3−1/4=1/12**.

This connection between integration and moments underpins financial risk analytics.

## 11. Expected payoff example

Suppose X is uniform on [0,1] and a payoff is:

**H(X)=max(X−.5,0)**.

Then:

**E[H]=∫.5¹(x−.5)dx=.125**.

If the payoff is received at time T and discounted continuously at rate r under an appropriate valuation model, its present value is:

**PV=e^(−rT)×.125**.

This is an illustrative payoff expectation, not a claim that the uniform model is a realistic market model.

## 12. Continuous cash-flow present value

For continuous cash-flow intensity c(t) and continuously compounded rate r:

**PV=∫₀ᵀc(t)e^(−rt)dt**.

If c(t)=C is constant and r≠0:

**PV=C(1−e^(−rT))/r**.

At r=0, the limiting value is **PV=CT**.

For C=100, T=2, r=.05:

**PV=100(1−e^(−.1))/.05≈190.325**.

The expression **−expm1(−rT)** improves numerical stability when rT is small.

## 13. Risk-neutral expectation and pricing

Under suitable no-arbitrage assumptions and a risk-neutral measure Q, a terminal payoff H(S_T) can be valued as:

**V₀=e^(−rT)E_Q[H(S_T)]**,

for constant continuously compounded r and the corresponding market model.

If the terminal asset price has density p_Q(s):

**V₀=e^(−rT)∫H(s)p_Q(s)ds**.

In practice, the integration domain may be infinite, the density may be nontrivial, and the model may require more advanced numerical methods.

## 14. Tail truncation and infinite intervals

Normal and lognormal distributions have unbounded support. Replacing an infinite integral with a finite interval introduces truncation error.

For a normal distribution, integrating only over [−3,3] excludes nonzero tail probability. The amount excluded should be quantified if it matters to risk or pricing.

Tail-sensitive payoffs may require much wider bounds or specialized quadrature.

## 15. SciPy adaptive quadrature

SciPy's `quad` uses adaptive numerical integration and can handle many finite and infinite intervals.

```python
from math import exp
from scipy.integrate import quad

value, estimated_error = quad(lambda x: x*x, 0.0, 1.0)
assert abs(value - 1.0/3.0) < 1e-10

rate, horizon, cashflow = 0.05, 2.0, 100.0
pv, err = quad(lambda t: cashflow*exp(-rate*t), 0.0, horizon)
analytic = cashflow*(-__import__("math").expm1(-rate*horizon))/rate
assert abs(pv-analytic) < 1e-8
```

The estimated error is an algorithmic diagnostic, not a universal proof of correctness. Review SciPy warnings and validate against independent benchmarks when possible.

## 16. Quadrature versus Monte Carlo

Deterministic quadrature is often effective in one or a few dimensions for smooth functions.

For d-dimensional tensor-product integration with m grid points per dimension, evaluation count scales as **m^d**, which becomes prohibitive as d grows.

Monte Carlo methods have sampling error typically proportional to **1/√N** under standard assumptions and may be more practical in high dimensions. Monte Carlo methods are introduced in Chapter 18.

Save as `numerical_integration.py`. This implementation includes midpoint, trapezoid, Simpson, normal CDF approximation, continuous annuity valuation, and payoff expectation, with **12 reference unit tests**.

```python
"""Section 17.8: deterministic numerical integration reference."""
import math
import unittest

def check(f,a,b,n):
    if not callable(f) or not all(type(x) in (int,float) and math.isfinite(x) for x in (a,b)):
        raise ValueError("invalid function or bounds")
    if not a<b or type(n) is not int or n<1:raise ValueError("invalid interval or panels")

def evaluate(f,x):
    y=f(x)
    if type(y) not in (int,float) or not math.isfinite(y):
        raise ValueError("nonfinite integrand")
    return y

def midpoint(f,a,b,n=1000):
    check(f,a,b,n)
    h=(b-a)/n
    return h*math.fsum(evaluate(f,a+(i+.5)*h) for i in range(n))

def trapezoid(f,a,b,n=1000):
    check(f,a,b,n)
    h=(b-a)/n
    return h*(.5*evaluate(f,a)+math.fsum(evaluate(f,a+i*h) for i in range(1,n))+.5*evaluate(f,b))

def simpson(f,a,b,n=1000):
    check(f,a,b,n)
    if n%2:raise ValueError("Simpson requires even panel count")
    h=(b-a)/n
    odd=math.fsum(evaluate(f,a+i*h) for i in range(1,n,2))
    even=math.fsum(evaluate(f,a+i*h) for i in range(2,n,2))
    return h/3*(evaluate(f,a)+evaluate(f,b)+4*odd+2*even)

def normal_pdf(x):
    return math.exp(-x*x/2)/math.sqrt(2*math.pi)

def normal_cdf_integrated(z,n=2000):
    if type(z) not in (int,float) or not math.isfinite(z):
        raise ValueError("finite z required")
    if z==0:return .5
    area=simpson(normal_pdf,0,abs(z),n)
    return .5+area if z>0 else .5-area

def discounted_continuous_cashflow(rate,horizon,annual_cashflow,n=1000):
    if not all(type(x) in (int,float) and math.isfinite(x) for x in (rate,horizon,annual_cashflow)):
        raise ValueError("finite parameters required")
    if horizon<=0:raise ValueError("positive horizon required")
    return simpson(lambda t:annual_cashflow*math.exp(-rate*t),0,horizon,n)

def discounted_payoff_expectation(payoff,pdf,a,b,n=1000):
    return simpson(lambda x:payoff(x)*pdf(x),a,b,n)

class IntegrationTests(unittest.TestCase):
    def test_01_midpoint(self):self.assertAlmostEqual(midpoint(lambda x:x,0,1,10),.5)
    def test_02_trapezoid(self):self.assertAlmostEqual(trapezoid(lambda x:x,0,1,10),.5)
    def test_03_simpson_quadratic(self):self.assertAlmostEqual(simpson(lambda x:x*x,0,1,10),1/3)
    def test_04_simpson_cubic(self):self.assertAlmostEqual(simpson(lambda x:x**3,0,1,10),.25)
    def test_05_normal_half(self):self.assertEqual(normal_cdf_integrated(0),.5)
    def test_06_normal_symmetry(self):self.assertAlmostEqual(normal_cdf_integrated(-1)+normal_cdf_integrated(1),1)
    def test_07_cashflow_zero_rate(self):self.assertAlmostEqual(discounted_continuous_cashflow(0,2,100),200)
    def test_08_cashflow_positive_rate(self):
        self.assertAlmostEqual(discounted_continuous_cashflow(.05,2,100),100*(-math.expm1(-.1))/.05,places=8)
    def test_09_constant(self):self.assertAlmostEqual(simpson(lambda x:3,0,2,10),6)
    def test_10_odd_panels(self):
        with self.assertRaises(ValueError):simpson(lambda x:x,0,1,3)
    def test_11_invalid_bounds(self):
        with self.assertRaises(ValueError):midpoint(lambda x:x,1,0)
    def test_12_nonfinite(self):
        with self.assertRaises(ValueError):trapezoid(lambda x:float("nan"),0,1,2)

if __name__=="__main__":
    print("Integral x^2 on [0,1]:",simpson(lambda x:x*x,0,1))
    print("Normal CDF(1):",normal_cdf_integrated(1))
    print("Continuous annuity:",discounted_continuous_cashflow(.05,2,100))
    unittest.main(verbosity=2)
```

## 20. Troubleshooting

| Symptom | Likely cause | Corrective action |
|---|---|---|
| Simpson rejects n | Odd panel count | Use even n |
| Integrand becomes nonfinite | Singular point or invalid model | Check domain or split interval |
| Numerical PV differs from analytic | Discount convention mismatch | Align compounding and payment units |
| Normal probability does not sum to one | Truncated tails or poor resolution | Extend bounds and quantify tail mass |
| Error stops decreasing | Floating-point limitations | Use adaptive method or higher precision |
| Integration is very slow | Too many grid points | Use adaptive quadrature |
| Payoff has a kink | Nonsmooth integrand | Split at strike or kink |
| Extreme-tail CDF inaccurate | Cancellation | Use specialized survival/CDF functions |
| Test results unavailable | QA intentionally deferred | Execute and retain evidence later |
