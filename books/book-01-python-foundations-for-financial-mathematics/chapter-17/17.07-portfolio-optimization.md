## Learning objectives

By the end of this section, readers can calculate portfolio expected return, variance, volatility, Sharpe ratio, and tracking error; formulate minimum-variance and target-return optimization; derive a two-asset global minimum-variance portfolio; build and interpret an efficient frontier; impose investment constraints; use SciPy SLSQP for a numerical portfolio example; and validate risk-model assumptions.

## 1. Portfolio optimization in practice

Portfolio optimization selects asset weights to achieve a financial objective while satisfying investment rules. Common objectives include minimizing variance, meeting a target expected return with minimum risk, maximizing risk-adjusted performance, minimizing tracking error, and controlling turnover or transaction costs.

A portfolio optimizer is a **decision-support model**, not a guarantee of future returns. Its output depends on estimated expected returns, covariance, liquidity, constraints, and market regime.

## 2. Notation and model assumptions

Let:

- **w** be the n-dimensional portfolio weight vector.
- **μ** be the vector of expected asset returns.
- **Σ** be the covariance matrix of asset returns.
- **r_f** be the risk-free return over the same horizon.
- **1ᵀw=1** represent full investment.

For long-only portfolios, **wᵢ≥0**. For a valid covariance matrix, Σ is symmetric and positive semidefinite.

Assume all returns are measured on compatible horizons and use a consistent convention.

## 3. Expected portfolio return

The expected portfolio return is:

**E[Rₚ]=wᵀμ=Σᵢwᵢμᵢ**.

For two assets with expected returns 8% and 4%, equally weighted:

**E[Rₚ]=.5(.08)+.5(.04)=.06**, or 6%.

Expected return is a model estimate, not a realized or guaranteed result.

## 4. Portfolio variance and volatility

Portfolio variance is:

**σₚ²=wᵀΣw**.

Portfolio volatility is:

**σₚ=√(wᵀΣw)**.

For two assets A and B:

**σₚ²=wA²σA²+wB²σB²+2wAwB Cov(A,B)**.

For weights [.5,.5], variances [.04,.09], and zero covariance:

**σₚ²=.25(.04)+.25(.09)=.0325**.

Therefore volatility is **√.0325≈18.03%**.

## 5. Correlation and diversification

Covariance is related to correlation by:

**Cov(A,B)=ρAB σA σB**.

With σA=.2, σB=.3, and ρ=.5, covariance is .03.

Correlation changes the potential diversification benefit. Lower correlation can reduce portfolio volatility for a given allocation, but correlations are estimated and can shift during stressed markets.

## 6. Minimum-variance portfolio

The global minimum-variance (GMV) problem is:

**minimize wᵀΣw**

subject to **1ᵀw=1**, and any applicable investment constraints.

When Σ is positive definite and unrestricted short selling is allowed, the unconstrained fully invested solution is:

**w_GMV=Σ⁻¹1/(1ᵀΣ⁻¹1)**.

This expression is not directly applicable when Σ is singular or when box, sector, or other investment constraints bind. In practice, solve a linear system rather than explicitly forming a matrix inverse.

## 7. Worked two-asset GMV derivation

For A=σA², B=σB², and C=Cov(A,B), write wA=w and wB=1−w:

**V(w)=Aw²+B(1−w)²+2Cw(1−w)**.

Differentiate:

**V′(w)=2(A+B−2C)w−2(B−C)**.

If the denominator is positive, the unconstrained optimum is:

**wA*=(B−C)/(A+B−2C)**.

For A=.04, B=.09, C=0:

**wA=9/13≈69.23%**, **wB=4/13≈30.77%**.

Variance is **.0036/.13≈.0276923** and volatility is approximately **16.64%**.

## 8. Long-only and position-cap constraints

A long-only portfolio imposes **wᵢ≥0**. A position cap imposes **wᵢ≤uᵢ**.

If the GMV allocation calls for 69.23% in A but the mandate caps A at 40%, the constrained two-asset optimum is:

**wA=.4, wB=.6**.

Its variance is **.0388**, higher than the uncapped GMV variance.

The difference reflects the risk cost of the cap under the assumed covariance model.

## 9. Target-return optimization

A target-return minimum-variance problem is:

**minimize wᵀΣw**

subject to:

**1ᵀw=1**, **μᵀw≥R_target**, and portfolio bounds.

For μA=.08, μB=.04, and target return 7%:

**.08wA+.04(1−wA)≥.07**,

so **wA≥.75**.

With zero covariance and the same variances, the unconstrained GMV weight is below .75; therefore the target-return minimum-variance solution is **wA=.75, wB=.25**.

Its variance is:

**.04(.75)²+.09(.25)²=.028125**.

## 10. Efficient frontier

The efficient frontier consists of portfolios that offer the lowest attainable variance for each feasible target return, or equivalently the highest attainable return for a specified risk level, under the model and constraints.

To construct a numerical frontier:

1. Choose a grid of feasible return targets.
2. Solve minimum variance for each target.
3. Record expected return and volatility.
4. Exclude infeasible targets.
5. Plot risk versus return.
6. Check every solution's budget, bounds, and target residuals.

The frontier changes when expected returns, covariance, or constraints change.

## 11. Sharpe ratio and tangency portfolios

The Sharpe ratio is:

**S=(E[Rₚ]−r_f)/σₚ**, for σₚ>0.

For expected return 8%, risk-free rate 2%, and volatility 20%:

**S=(.08−.02)/.20=.30**.

Maximizing Sharpe is a nonlinear objective. It can be numerically difficult near zero volatility and may yield misleading results when estimated expected returns are unstable. Ensure the risk-free rate uses the same horizon as portfolio returns.

## 12. Tracking error and benchmark-relative objectives

For benchmark weights b, active weights are **a=w−b**.

Tracking-error variance is:

**TE²=aᵀΣa**,

with tracking error **TE=√(aᵀΣa)**.

The information ratio is active expected return divided by tracking error, when tracking error is positive.

These measures support benchmark-aware investment mandates. A portfolio with low absolute variance need not have low tracking error.

## 13. Transaction costs and turnover

Portfolio rebalancing creates implementation costs. A common gross turnover measure is:

**T_gross=Σᵢ|w_new,i−w_old,i|**.

For old weights [.5,.5] and new weights [.6,.4], gross turnover is .2. Some reporting conventions define one-way turnover as half this amount, .1, for a fully invested self-financing rebalance.

A realistic optimization model may penalize trading costs or constrain turnover:

**Σᵢ|w_new,i−w_old,i|≤T_max**.

Use explicit cost units, execution assumptions, and turnover conventions.

## 14. Covariance estimation and model risk

Sample covariance estimates are noisy, especially when asset counts are large relative to historical observations.

Practical controls include:

- Validate matrix symmetry and positive semidefiniteness.
- Consider shrinkage or factor-based covariance estimates.
- Test sensitivity to sample window.
- Compare normal and stressed correlations.
- Avoid look-ahead bias in backtests.
- Record the exact data window and return convention.

A numerically converged optimum can be economically fragile if the input estimates are unreliable.

## 15. SciPy numerical optimization example

The following example minimizes variance for two assets, with long-only weights, a 40% cap on asset A, and a fully invested budget.

```python
import numpy as np
from scipy.optimize import minimize

cov = np.array([[0.04, 0.0], [0.0, 0.09]])
mu = np.array([0.08, 0.04])

def variance(w):
    return float(w @ cov @ w)

result = minimize(
    variance,
    x0=np.array([0.4, 0.6]),
    method="SLSQP",
    bounds=[(0.0, 0.4), (0.0, 1.0)],
    constraints=[
        {"type": "eq", "fun": lambda w: float(np.sum(w) - 1.0)}
    ],
    options={"ftol": 1e-12, "maxiter": 500},
)

if not result.success:
    raise RuntimeError(result.message)
assert abs(sum(result.x) - 1.0) < 1e-8
assert result.x[0] <= 0.4 + 1e-8
assert abs(variance(result.x) - 0.0388) < 1e-7
print(result.x, float(mu @ result.x), variance(result.x))
```

The snippet requires NumPy and SciPy. A solver's success flag does not replace independent checks of constraints and risk calculations.

## 16. Complete standard-library reference implementation

Save as `portfolio_optimization.py`. The reference provides two-asset statistics, a capped GMV solution, target-return minimum variance, grid-based maximum Sharpe, and **12 reference unit tests**.

```python
"""Section 17.7: portfolio optimization reference (long-only, two assets)."""
import math
import unittest

def finite(x):
    return type(x) in (int,float) and math.isfinite(x)

def validate(mu, cov):
    if len(mu)!=2 or len(cov)!=2 or any(len(row)!=2 for row in cov):
        raise ValueError("two-asset inputs required")
    if any(not finite(x) for x in mu) or any(not finite(x) for row in cov for x in row):
        raise ValueError("nonfinite input")
    a,b=cov[0][0],cov[1][1]
    c=cov[0][1]
    if not math.isclose(c,cov[1][0],rel_tol=1e-10,abs_tol=1e-12):
        raise ValueError("asymmetric covariance")
    if min(a,b)<0 or c*c>a*b+1e-12:
        raise ValueError("covariance not positive semidefinite")
    return a,b,c

def portfolio_stats(weight_a,mu,cov):
    a,b,c=validate(mu,cov)
    if not finite(weight_a) or not 0<=weight_a<=1:
        raise ValueError("long-only weight required")
    w=weight_a
    mean=w*mu[0]+(1-w)*mu[1]
    var=w*w*a+(1-w)*(1-w)*b+2*w*(1-w)*c
    return {"weights":(w,1-w),"expected_return":mean,
            "variance":max(var,0.0),"volatility":math.sqrt(max(var,0.0))}

def gmv(mu,cov,cap_a=1,cap_b=1):
    a,b,c=validate(mu,cov)
    if not all(finite(x) and 0<=x<=1 for x in (cap_a,cap_b)):
        raise ValueError("invalid caps")
    lo=max(0,1-cap_b)
    hi=min(1,cap_a)
    if lo>hi:raise ValueError("infeasible caps")
    den=a+b-2*c
    if den<=1e-14:
        w=(lo+hi)/2
        nonunique=True
    else:
        w=min(hi,max(lo,(b-c)/den))
        nonunique=False
    return {**portfolio_stats(w,mu,cov),"nonunique":nonunique,
            "feasible_weight_interval":(lo,hi)}

def efficient_target(mu,cov,target,cap_a=1,cap_b=1):
    validate(mu,cov)
    if not finite(target) or not all(finite(x) and 0<=x<=1 for x in (cap_a,cap_b)):
        raise ValueError("invalid target or caps")
    lo=max(0,1-cap_b)
    hi=min(1,cap_a)
    if lo>hi:raise ValueError("infeasible caps")
    # For two assets, expected return is affine in w_A.
    d=mu[0]-mu[1]
    if d>0:lo=max(lo,(target-mu[1])/d)
    elif d<0:hi=min(hi,(target-mu[1])/d)
    elif mu[0]<target:raise ValueError("unreachable target")
    if lo>hi+1e-12:raise ValueError("unreachable target")
    lo=max(0,min(1,lo))
    hi=max(0,min(1,hi))
    a,b,c=validate(mu,cov)
    den=a+b-2*c
    w=(lo+hi)/2 if den<=1e-14 else min(hi,max(lo,(b-c)/den))
    return portfolio_stats(w,mu,cov)

def sharpe(mean,volatility,risk_free):
    if not all(finite(x) for x in (mean,volatility,risk_free)) or volatility<=0:
        raise ValueError("positive volatility required")
    return (mean-risk_free)/volatility

def grid_max_sharpe(mu,cov,risk_free,steps=10000):
    validate(mu,cov)
    if not finite(risk_free) or type(steps) is not int or steps<1:
        raise ValueError("invalid inputs")
    best=None
    for i in range(steps+1):
        w=i/steps
        s=portfolio_stats(w,mu,cov)
        if s["volatility"]<=0:continue
        score=sharpe(s["expected_return"],s["volatility"],risk_free)
        if best is None or score>best["sharpe"]:
            best={**s,"sharpe":score}
    if best is None:raise ValueError("all candidate portfolios have zero volatility")
    return best

class PortfolioTests(unittest.TestCase):
    MU=(.08,.04)
    COV=((.04,0),(0,.09))
    def test_01_equal_return(self):self.assertAlmostEqual(portfolio_stats(.5,self.MU,self.COV)["expected_return"],.06)
    def test_02_equal_variance(self):self.assertAlmostEqual(portfolio_stats(.5,self.MU,self.COV)["variance"],.0325)
    def test_03_gmv_weight(self):self.assertAlmostEqual(gmv(self.MU,self.COV)["weights"][0],9/13)
    def test_04_gmv_variance(self):self.assertAlmostEqual(gmv(self.MU,self.COV)["variance"],.0036/.13)
    def test_05_cap(self):self.assertAlmostEqual(gmv(self.MU,self.COV,cap_a=.4)["weights"][0],.4)
    def test_06_target(self):self.assertGreaterEqual(efficient_target(self.MU,self.COV,.07)["expected_return"],.07-1e-12)
    def test_07_target_infeasible(self):
        with self.assertRaises(ValueError):efficient_target(self.MU,self.COV,.1)
    def test_08_sharpe(self):self.assertAlmostEqual(sharpe(.08,.2,.02),.3)
    def test_09_grid(self):self.assertTrue(0<=grid_max_sharpe(self.MU,self.COV,.02,100)["weights"][0]<=1)
    def test_10_bad_cov(self):
        with self.assertRaises(ValueError):gmv(self.MU,((.04,.1),(.1,.09)))
    def test_11_bad_cap(self):
        with self.assertRaises(ValueError):gmv(self.MU,self.COV,cap_a=.4,cap_b=.4)
    def test_12_zero_vol(self):
        with self.assertRaises(ValueError):sharpe(.08,0,.02)

if __name__=="__main__":
    print("GMV:",gmv((.08,.04),((.04,0),(0,.09))))
    print("Target return:",efficient_target((.08,.04),((.04,0),(0,.09)),.07))
    print("Max Sharpe grid:",grid_max_sharpe((.08,.04),((.04,0),(0,.09)),.02,1000))
    unittest.main(verbosity=2)
```

## 17. Portfolio optimization acceptance checklist

Before using an optimized portfolio in a financial workflow:

1. Confirm the asset universe and order.
2. Verify return horizon and data timestamps.
3. Validate covariance symmetry and PSD.
4. Check expected-return assumptions.
5. Confirm budget, bounds, and sector limits.
6. Recompute return, variance, and volatility independently.
7. Check risk-free rate units.
8. Evaluate turnover and implementation costs.
9. Stress correlations and expected returns.
10. Review out-of-sample performance without look-ahead.
11. Retain solver status, iterations, and tolerance.
12. Record approvals, limitations, and reproducible inputs.

## 20. Troubleshooting

| Symptom | Likely cause | Corrective action |
|---|---|---|
| Optimizer returns negative weights | Long-only constraints omitted | Add and independently check bounds |
| Weights do not sum to one | Budget constraint missing or loose | Validate budget residual |
| Negative portfolio variance | Invalid covariance or numerical issue | Check symmetry and PSD |
| Extreme concentration | No position caps or unstable return estimates | Add mandates and stress inputs |
| Return target unreachable | Constraints inconsistent with target | Check feasible return range |
| Sharpe undefined | Zero volatility | Do not divide by zero |
| Solver converges but performance disappoints | Estimation error and regime changes | Conduct out-of-sample and stress analysis |
| Tracking error differs from volatility | Benchmark-relative vs absolute risk | Recompute using active weights |
| Turnover unexpectedly high | Trading costs not modeled | Add turnover constraints or costs |
| Runtime test evidence absent | QA intentionally deferred | Execute and retain tests during QA |
