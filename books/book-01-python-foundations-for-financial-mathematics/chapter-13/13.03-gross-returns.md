## 1. Gross return: two meanings

In investment mathematics, **gross return** commonly refers to the **gross return factor**:

**G = 1 + R**, where R is the simple return.

The factor expresses ending wealth as a multiple of beginning wealth. A +10% return has G=1.10; a −20% return has G=0.80; zero return has G=1.00.

In performance reporting, **gross-of-fees return** means performance before certain fees. It is not the same concept as a gross return factor. A fund can have a 6% gross-of-fees return, corresponding to a gross return **factor** of 1.06. Always label which meaning is intended.

## 2. Derivation from asset values

For positive beginning value V0 and nonnegative ending value V1, with no distributions, contributions, withdrawals, or costs:

**R=(V1−V0)/V0.**

Adding one:

**G=1+R=V1/V0.**

Therefore:

**V1=V0×G.**

A factor of 1.15 transforms $1,000 into $1,150. A factor of 0.75 transforms $1,000 into $750.

### Worked example A — From price to factor

An asset rises from $80 to $92.

**G=92/80=1.15**, corresponding to **R=15%**.

### Worked example B — From factor to return

An investment's gross factor is 0.88.

**R=0.88−1=−0.12=−12%**.

## 3. Factor domain and zero wealth

For an unlevered long-only investment with nonnegative ending wealth:

**G ≥ 0** and **R ≥ −1**.

If G=0, all beginning wealth has been lost. The simple return is −100%.

A factor below zero is not meaningful as an ending-to-beginning wealth ratio under this simplified model. Leveraged positions and obligations can generate losses greater than invested capital, but they require a more general cash-flow or equity-capital model.

**Important:** A zero factor can be multiplied and linked, but its logarithm is undefined. Geometric mean simple return is −100% if at least one gross factor is zero, while log-return methods must handle this boundary separately.

## 4. Why gross factors multiply

Consider consecutive intervals with values V0, V1, and V2:

**G1=V1/V0**, and **G2=V2/V1**.

Multiplying:

**G1×G2=(V1/V0)(V2/V1)=V2/V0**.

The intermediate value cancels. For n consecutive intervals:

**G_total=∏[t=1..n] G_t = ∏\[t=1..n\](1+R_t).**

The cumulative simple return is:

**R_total=G_total−1.**

This is the fundamental mathematical reason to **multiply** period factors rather than add period returns.

### Worked example C — Up, then down

Start with $100, gain 10%, then lose 10%.

**G_total=1.10×0.90=0.99**.

**R_total=0.99−1=−1%**.

Ending wealth is $99, not $100.

## 5. Multi-period worked example

Suppose returns are +10%, −10%, +5%, and −2%.

| Period | Simple return | Gross factor |
|---|---:|---:|
| 1 | +10% | 1.10 |
| 2 | −10% | 0.90 |
| 3 | +5% | 1.05 |
| 4 | −2% | 0.98 |

**G_total=1.10×0.90×1.05×0.98=1.01871**.

**R_total=1.871%.**

An initial $10,000 therefore becomes **$10,187.10**, assuming returns are earned on the entire evolving investment value and no external flows occur.

## 6. Geometric mean factor and growth rate

Given n strictly positive gross factors:

**G_geometric=[∏G_t]^(1/n).**

The corresponding equivalent constant-period simple return is:

**R_geometric=G_geometric−1.**

For +10% followed by −10%:

**G_geometric=sqrt(0.99)≈0.99498744**.

**R_geometric≈−0.5013% per period**.

This is different from the arithmetic average return of zero. The arithmetic-versus-geometric distinction is developed in Section 13.8.

If one or more factors equal zero, the product is zero and the geometric mean gross factor is zero, yielding −100% equivalent simple return. The log-based computational shortcut cannot directly evaluate ln(0).

## 7. Annualized growth from a gross factor

For a cumulative gross factor G over T years, where G>0 and T>0:

**R_annual=(G)^(1/T)−1.**

If wealth grows by 21% over two years:

**G=1.21**.

**R_annual=sqrt(1.21)−1=10%.**

Annualization expresses a constant-equivalent compound rate; it does not assert that the actual path earned 10% in each year.

## 8. Income, distributions, and costs

For a single period with beginning wealth V0, ending ex-distribution asset value V1, distributions D, and costs C that have **not** already been deducted:

**G_total=(V1+D−C)/V0**.

For V0=$100, V1=$105, D=$3, and C=$1:

**G_total=(105+3−1)/100=1.07**.

The total simple return is **7%**.

This assumes no external contributions or withdrawals and treats the cash flows as terminal wealth. Reinvestment timing, intra-period transactions, and external cash flows require more careful performance methods. Never deduct costs twice if they are already reflected in reported net asset value.

## 9. Foreign-exchange gross factors

When an investor owns an asset denominated in another currency:

**G_domestic=G_local_asset×G_currency**,

provided the currency factor measures the change in domestic-currency value of one unit of local currency.

Example: asset return +8%, local currency return −2%:

**G_domestic=1.08×0.98=1.0584**.

The domestic-currency simple return is **5.84%**.

The multiplicative relation also shows why simply adding +8% and −2% (6%) is only an approximation.

## 10. Portfolio factors: weighted arithmetic, not product

For a long-only portfolio with beginning-value weights w_i summing to one and asset simple returns R_i over the same period, with no interim rebalancing or external flows:

**R_portfolio=Σw_i R_i.**

Therefore:

**G_portfolio=1+Σw_i R_i=Σw_i G_i**.

The portfolio's one-period factor is a **weighted average** of its constituent factors, not their product. Multiplication applies to **sequential time periods**, not parallel assets.

Example: 60% in an asset earning +10%, 40% in one losing 5%:

**G_portfolio=0.6×1.10+0.4×0.95=1.04**, so **R_portfolio=4%**.

## 11. Numerical implementation and stability

For a modest number of periods, multiplying gross factors directly is straightforward. For very long sequences of strictly positive factors, numerical work can instead use:

**ln(G_total)=Σ ln(1+R_t)**.

Then recover **G_total=exp[Σln(1+R_t)]**.

Python's `math.log1p` is especially useful when R_t is near zero, and `math.expm1` is useful when converting small log growth back into a simple return.

Caution: a zero factor makes ln(G_total) undefined. Very large or small cumulative factors may also overflow or underflow ordinary floating-point representations; use explicit numerical policies for production systems.

## 12. Python hands-on lab

Save the following as **gross_returns.py** and run `python gross_returns.py` and `python -m compileall -q gross_returns.py`.

Use Python 3.9 or later with the standard library. The standalone lab uses rational products for decimal-text inputs and a local Decimal context for fractional powers before checked float reporting. Gross factors close to one can still round to one at the public float boundary; use the linked return helper to retain small cumulative changes. The lab calculates gross factors, inverse conversions, linked returns, geometric averages, annualization, FX returns, and a single-period total-wealth factor. It contains **12 reference unit tests**.
```python
import math
import unittest
from decimal import Context, Decimal, DecimalException, localcontext
from fractions import Fraction

def _number(value,label,positive=False,signed=False):
    if isinstance(value,bool) or not isinstance(value,(int,float)):
        raise ValueError(f"invalid {label}")
    try:
        finite=math.isfinite(value)
    except OverflowError:
        finite=False
    if not finite or (not signed and value<0) or (positive and value==0):
        raise ValueError(f"invalid {label}")
    return Fraction(str(value))

_MIN_FLOAT=Fraction(math.ulp(0.0))

def _report(value,label):
    try:
        if 0<abs(value)<_MIN_FLOAT:
            raise OverflowError
        result=float(value)
    except OverflowError as exc:
        raise ValueError(f"{label} outside supported range") from exc
    if not math.isfinite(result):
        raise ValueError(f"{label} outside supported range")
    return result

def finite_number(x,name):
    _number(x,name,signed=True)

def _return(value):
    r=_number(value,"return",signed=True)
    if r<-1:
        raise ValueError("gross return cannot be negative in this model")
    return r

def _reported_return(value):
    result=_report(value,"return")
    if value>-1 and result==-1:
        raise ValueError("positive gross return rounds to total loss")
    return result

def check(x,name):
    finite_number(x,name)

def gross_factor(simple_return):
    return _report(1+_return(simple_return),"gross factor")

def simple_from_gross(factor):
    return _reported_return(_number(factor,"gross factor")-1)

def factor_from_prices(start,end):
    return _report(_number(end,"end")/_number(start,"start",positive=True),"gross factor")

def _linked(returns):
    factors=[1+_return(r) for r in returns]
    if not factors:
        raise ValueError("returns required")
    return math.prod(factors),len(factors)

def linked_factor(returns):
    return _report(_linked(returns)[0],"linked factor")

def linked_return(returns):
    return _reported_return(_linked(returns)[0]-1)

def _equivalent(factor,years):
    try:
        with localcontext(Context(prec=750)):
            g=Decimal(factor.numerator)/Decimal(factor.denominator)
            t=Decimal(years.numerator)/Decimal(years.denominator)
            result=(g.ln()/t).exp()-1
    except DecimalException as exc:
        raise ValueError("equivalent return outside supported range") from exc
    if result==-1:
        raise ValueError("positive gross return rounds to total loss")
    return _reported_return(result)

def annualized_from_factor(factor,years):
    return _equivalent(_number(factor,"factor",positive=True),_number(years,"years",positive=True))

def geometric_mean(returns):
    factor,count=_linked(returns)
    return -1.0 if factor==0 else _equivalent(factor,Fraction(count))

def fx_factor(local_return,fx_return):
    return _report((1+_return(local_return))*(1+_return(fx_return)),"FX factor")

def factor_from_total_wealth(start,end,income=0,costs=0):
    initial=_number(start,"start",positive=True)
    terminal=_number(end,"end")+_number(income,"income")-_number(costs,"costs")
    if terminal<0:
        raise ValueError("terminal wealth cannot be negative")
    return _report(terminal/initial,"wealth factor")

class GrossReturnTests(unittest.TestCase):
    def test_01_positive(self): self.assertAlmostEqual(gross_factor(.12), 1.12)
    def test_02_negative(self): self.assertAlmostEqual(gross_factor(-.25), .75)
    def test_03_zero(self): self.assertEqual(gross_factor(0), 1)
    def test_04_full_loss(self): self.assertEqual(gross_factor(-1), 0)
    def test_05_inverse(self): self.assertAlmostEqual(simple_from_gross(1.08), .08)
    def test_06_prices(self): self.assertAlmostEqual(factor_from_prices(100, 110), 1.1)
    def test_07_link(self): self.assertAlmostEqual(linked_factor([.1, -.1]), .99)
    def test_08_return(self): self.assertAlmostEqual(linked_return([.1, -.1]), -.01)
    def test_09_annualize(self): self.assertAlmostEqual(annualized_from_factor(1.21, 2), .1)
    def test_10_geometric(self): self.assertAlmostEqual(geometric_mean([.1, -.1]), math.sqrt(.99)-1)
    def test_11_fx_total(self):
        self.assertAlmostEqual(fx_factor(.08, -.02), 1.0584)
        self.assertAlmostEqual(factor_from_total_wealth(100, 105, 3, 1), 1.07)
    def test_12_invalid(self):
        for fn in [lambda:gross_factor(-1.01),lambda:simple_from_gross(-.1),
                   lambda:factor_from_prices(0, 10),lambda:linked_factor([]),
                   lambda:annualized_from_factor(0, 2),lambda:geometric_mean([]),
                   lambda:factor_from_total_wealth(100, 0, 0, 101)]:
            with self.assertRaises(ValueError): fn()
        self.assertEqual(linked_return([1e-30]),1e-30)
        with self.assertRaises(ValueError): annualized_from_factor(.1,.001)

if __name__ == '__main__':
    series = [.10, -.10, .05, -.02]
    print('Period gross factors:', [gross_factor(r) for r in series])
    print('Linked factor:', linked_factor(series))
    print('Linked simple return:', linked_return(series))
    print('Geometric mean:', geometric_mean(series))
    unittest.main(verbosity=2)
```

## 14. Applied mini-project — Gross-return reconciliation engine

Given daily simple returns:

| Day | Return |
|---|---:|
| 1 | +3% |
| 2 | −2% |
| 3 | +4% |
| 4 | −1% |
| 5 | +2% |

Build a report with:

1. Daily simple returns and gross factors.
2. Running cumulative gross factor.
3. Running cumulative simple return.
4. Final wealth from a $25,000 starting balance.
5. Arithmetic average daily return.
6. Geometric mean daily return.
7. Annualized equivalent return under an **explicit** assumed 252 trading days per year.
8. A separate calculation showing the effect of a −100% day.

**Worked validation:** First two days yield a cumulative factor **1.03×0.98=1.0094**, or **+0.94%**. The final gross factor is **1.0600638048** and $25,000 grows to **$26,501.60**. The arithmetic and geometric daily returns are **1.20%** and approximately **1.173413%**. Repeating this five-day growth at an assumed 252 trading days per year gives approximately **1,791.18% annualized**, a constant-equivalent calculation and not a forecast. Adding a −100% day at any point makes the remaining long-only wealth zero under the multiplicative model.

**Acceptance criteria:** Period factors match 1+R; cumulative factors reconcile with simulated wealth; annualization assumptions are stated; and all 12 reference unit tests pass.

## 15. Production considerations

- Distinguish gross factors from gross-of-fees performance in names and reports.
- Keep return frequency, trading calendars, and currency conventions explicit.
- Handle missing prices and corporate actions before constructing return factors.
- Reject non-finite values rather than silently propagating them.
- Use unit tests for factor/return round trips and price-ratio reconciliation.
- Treat a −100% return as a valid boundary case, not a missing value.
- Avoid multiplying gross factors across different assets when you intend portfolio aggregation.
- Record whether distributions are reinvested and whether costs are already included.
