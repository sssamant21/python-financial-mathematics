## 1. Reference formula sheet

| Measure | Formula | Essential convention |
|---|---|---|
| Simple return | R=(P1−P0)/P0 | P0>0; dividends separately if applicable |
| Gross return | G=1+R | G≥0 for unlevered long-only total loss bound |
| Log return | ℓ=ln(1+R) | Requires 1+R>0 |
| Cumulative return | ∏(1+Rt)−1 | Link gross factors |
| Arithmetic mean | ΣRt/n | Periodic average |
| Geometric mean | [∏(1+Rt)]^(1/n)−1 | Compound average |
| Annualized return | (1+Rtotal)^(1/years)−1 | Years and horizon explicit |
| Total return | (P1−P0+D)/P0 | Single-period cash distribution D |
| Time-weighted return | ∏(1+subperiod return)−1 | Flow-adjusted valuations |
| Periodic IRR | ΣCFt/(1+r)^t=0 | Investor cash-flow signs |
| XIRR | ΣCFi/(1+r)^((di−d0)/365)=0 | Actual/365 Fixed convention |
| Sample volatility | sqrt[Σ(Rt−mean)²/(n−1)] | At least two observations |
| Annualized volatility | σperiod×sqrt(k) | Requires scaling assumptions |
| Drawdown | Wealth/running_peak−1 | Flow-adjusted wealth index |
| Sharpe | mean(excess)/std(excess) | Matched risk-free frequency |
| Sortino | (mean−target)/downside_deviation | State target and denominator |
| Calmar | annualized_return/abs(MDD) | State drawdown horizon |
| Information ratio | mean(active)/std(active) | Appropriate benchmark |
| Beta | Cov(portfolio,benchmark)/Var(benchmark) | Aligned returns |

## 2. Thirty worked exercises

1. **Simple price return:** Buy at $80; sell at $92. **Worked answer:** (92−80)/80 = 15%.

2. **Gross return:** A simple return is −12%. **Worked answer:** 1−0.12 = 0.88.

3. **Log return:** Gross return is 1.10. **Worked answer:** ln(1.10) ≈ 0.0953102.

4. **Log/simple conversion:** Log return is ln(1.2). **Worked answer:** exp(ln(1.2))−1 = 20%.

5. **Two-period cumulative return:** Returns are +10%, then −10%. **Worked answer:** 1.1×0.9−1 = −1%.

6. **Three-period growth:** Returns +5%, −2%, +3%. **Worked answer:** 1.05×0.98×1.03−1 = 5.987%.

7. **Annualize cumulative return:** An investment gains 21% over exactly two years. **Worked answer:** 1.21^(1/2)−1 = 10% annually.

8. **Dividend total return:** Beginning price $100, ending price $105, $3 cash dividend. **Worked answer:** (105−100+3)/100 = 8%, assuming no reinvestment before period end.

9. **Arithmetic mean:** Returns +20% and −10%. **Worked answer:** (20%−10%)/2 = 5%.

10. **Geometric mean:** Returns +20% and −10%. **Worked answer:** sqrt(1.2×0.9)−1 ≈ 3.9230% per period.

11. **Arithmetic/geometric inequality:** Can geometric mean exceed arithmetic mean for positive gross factors? **Worked answer:** No; by AM–GM, geometric ≤ arithmetic, with equality for identical gross factors.

12. **Time-weighted return:** Starting $100 grows to $110, then $50 deposited, then $160 falls to $144. **Worked answer:** (110/100)×(144/160)−1 = −1%.

13. **Money-weighted return:** Investor flows [−100,+110] at consecutive annual dates. **Worked answer:** IRR = 10% annually.

14. **Money-weighted with contribution:** Investor flows [−100,−50,+144] at annual intervals. **Worked answer:** Solve 100(1+r)^2+50(1+r)−144=0; r≈−2.42% annually.

15. **XIRR day count:** Cash flows dated January 1, 2025 and January 1, 2026. **Worked answer:** Elapsed time is 365 days; Actual/365 Fixed year fraction = 1.

16. **Population volatility:** Two returns +10% and −10%. **Worked answer:** Mean 0; population standard deviation = sqrt((.01+.01)/2)=10%.

17. **Sample volatility:** Two returns +10% and −10%. **Worked answer:** sqrt((.01+.01)/(2−1)) ≈ 14.1421%.

18. **Volatility annualization:** Daily volatility is 1%; use 252 trading days. **Worked answer:** 0.01×sqrt(252)≈15.8745% annualized under scaling assumptions.

19. **Downside deviation:** Returns +10%, −10%; target 0%; divide by all observations. **Worked answer:** sqrt((0+.01)/2)≈7.0711%.

20. **Maximum drawdown:** Wealth index [100,120,90,120]. **Worked answer:** 90/120−1 = −25% maximum drawdown.

21. **Recovery gain:** Portfolio suffers a 40% loss from its peak. **Worked answer:** 1/(1−0.4)−1≈66.6667% gain required.

22. **Sharpe ratio:** Mean monthly return 1%, risk-free monthly 0.2%, sample monthly volatility 2%. **Worked answer:** Monthly Sharpe = (.01−.002)/.02=0.4; annualized ≈1.3856 under sqrt(12).

23. **Sortino ratio:** Returns +10%, −10%, target 0%. **Worked answer:** Mean excess 0; downside deviation sqrt(.005); Sortino = 0.

24. **Calmar ratio:** Annualized return 12%, maximum drawdown −20%. **Worked answer:** 0.12/0.20=0.6.

25. **Information ratio:** Active returns +2%, −2%. **Worked answer:** Mean active return = 0; information ratio = 0.

26. **Beta:** Asset returns [+20%,−20%], benchmark [+10%,−10%]. **Worked answer:** Beta = covariance/benchmark variance = 2.

27. **Multiple IRRs:** Cash flows [−100,+230,−132]. **Worked answer:** IRR equation has two valid roots, 10% and 20%; a single IRR is ambiguous.

28. **Total loss edge case:** A period return equals −100%. **Worked answer:** Cumulative wealth becomes zero; finite log return is undefined; geometric gross factor is zero.

29. **Flow contamination:** A deposit raises portfolio balance from $100 to $150 without market gain. **Worked answer:** Balance growth of 50% is not investment return; flow-adjust the performance series.

30. **Undefined ratio:** All returns are identical. **Worked answer:** Sample volatility = 0; conventional Sharpe denominator zero, so report undefined.

## 3. Applied problem A — Price, dividends, and compounding

A share starts at $100. At the end of month 1 its ex-distribution price is $104 and a $2 cash dividend is paid. At the end of month 2 the share price is $101, with no additional distribution.

**Tasks:** Calculate month-1 price return, month-1 total return, month-2 price return, and the two-month total return assuming the dividend is held as cash rather than reinvested.

**Worked solution:**

- Month-1 price return = (104−100)/100 = **4%**.
- Month-1 total return = (104−100+2)/100 = **6%**.
- Month-2 price return = (101−104)/104 ≈ **−2.8846%**.
- Without reinvestment, terminal wealth is $101 stock + $2 cash = $103, so **two-month investor total return = 3%**.

**Important distinction:** Multiplying 1.06 by (101/104) implicitly reinvests the month-1 dividend into the asset at the end of month 1. That produces a different wealth path than holding the $2 distribution as cash. Record the distribution and reinvestment convention explicitly.

## 4. Applied problem B — External contributions and investment performance

A portfolio begins with $100, appreciates to $110, receives an investor contribution of $50, and finishes the next period at $144.

**Tasks:** Compute the two subperiod returns, exact cumulative TWR, and investor-perspective periodic IRR.

**Worked solution:**

- First subperiod: **+10%**.
- Second subperiod: 144/160−1 = **−10%**.
- Cumulative TWR: 1.1×0.9−1 = **−1%**.
- Investor cash flows: [−100,−50,+144].
- IRR solves −100−50/(1+r)+144/(1+r)²=0; the admissible periodic root is approximately **−2.42%**.

TWR neutralizes contribution timing, while IRR measures the investor's capital-weighted experience. If each subperiod is a year, the TWR is a two-year cumulative return while the IRR is an annual rate.

## 5. Applied problem C — Risk monitoring

A flow-adjusted wealth index is [100, 108, 104, 112, 98, 91, 100, 112, 118].

**Tasks:** Identify the final high-water mark, the peak preceding the maximum drawdown, the trough, the recovery, and the gain needed to recover from the trough.

**Worked solution:** The final high-water mark is **118** at observation 8. The peak preceding the worst drawdown is **112** at observation 3 (zero-based). The trough is **91** at observation 5. Maximum drawdown is 91/112−1 = **−18.75%**. Recovery occurs at observation 7 when wealth returns to 112. Required gain from trough to the prior peak is 112/91−1 ≈ **23.0769%**.

A monitoring system should distinguish depth, peak-to-trough duration, and the full recovery interval.

## 7. Applied problem E — Nonconventional IRR

Investor cash flows are [−100,+230,−132] at consecutive annual dates.

**Tasks:** Derive the IRR polynomial, find all admissible roots, and explain why one reported IRR is inadequate.

**Worked solution:** Multiply NPV by (1+r)² and set x=1+r:

**−100x²+230x−132=0**.

Its roots are x=1.1 and x=1.2, so **r=10% and r=20%**. A single-bracket numerical solver may miss both roots if endpoint NPVs share the same sign. The result must be flagged as ambiguous, and an NPV analysis at a specified required return may be more appropriate.

## 8. Python reference lab and 12 acceptance tests

Save as **chapter13_exercises.py**. The implementation uses the Python standard library, with explicit validation, compounding, sample volatility, drawdown, Sharpe, TWR, periodic IRR, and reconciliation checks.

Run:

```bash

```

Use Python 3.8 or later. The first command prints the Strategy A illustration and runs **12 reference unit tests**; the second compiles without executing. Use finite numeric inputs in decimal units. Exact fractions are used internally (floats use their decimal text); results that would overflow or be confused with zero or complete loss raise an error. The periodic IRR accepts an endpoint root or an opposite-sign bracket and checks rate width independently of cash-flow scale; check the residual separately and use separate brackets when testing for multiple roots.

```python
import math
import unittest
from decimal import Decimal, DecimalException, localcontext
from fractions import Fraction

def finite(x):
    if isinstance(x, bool) or not isinstance(x, (int, float)):
        raise ValueError("finite numeric input required")
    if isinstance(x, float) and not math.isfinite(x):
        raise ValueError("finite numeric input required")
    return Fraction(x) if isinstance(x, int) else Fraction(str(x))

def _report(x, *, long_only=False):
    try:
        result = float(x)
    except OverflowError as exc:
        raise ValueError("result exceeds float range") from exc
    if not math.isfinite(result) or (result == 0 and x != 0):
        raise ValueError("result outside reportable float range")
    if long_only and result == -1 and x != -1:
        raise ValueError("positive gross factor rounds to complete loss")
    return result

def _returns(returns, minimum=1):
    rs = [finite(x) for x in returns]
    if len(rs) < minimum or any(x < -1 for x in rs):
        raise ValueError("insufficient returns or a return below -100%")
    return rs

def _root(x):
    with localcontext() as ctx:
        ctx.prec = 50
        return (Decimal(x.numerator) / Decimal(x.denominator)).sqrt()

def cumulative(returns):
    return _report(math.prod(1 + r for r in _returns(returns)) - 1, long_only=True)

def _mean(rs):
    return sum(rs) / len(rs)

def arithmetic(returns):
    return _report(_mean(_returns(returns)), long_only=True)

def geometric(returns):
    rs = _returns(returns)
    gross = math.prod(1 + r for r in rs)
    if gross == 0:
        return -1.0
    try:
        with localcontext() as ctx:
            # Extra precision preserves tiny changes when subtracting one.
            ctx.prec = 750
            value = (Decimal(gross.numerator) / Decimal(gross.denominator))**(Decimal(1)/len(rs))-1
    except DecimalException as exc:
        raise ValueError("geometric return outside reportable range") from exc
    if (value == -1) or (value == 0 and gross != 1):
        raise ValueError("geometric return outside reportable range")
    return _report(value, long_only=True)

def _variance(rs):
    center = _mean(rs)
    return sum((r - center)**2 for r in rs) / (len(rs)-1)

def sample_volatility(returns):
    return _report(_root(_variance(_returns(returns, 2))))

def drawdowns(returns):
    relative = Fraction(1)
    result = [0.0]
    for r in _returns(returns):
        relative = min(Fraction(1), relative * (1+r))
        result.append(_report(relative - 1, long_only=True))
    return result

def _sharpe(excess, variance, k):
    if variance == 0:
        raise ValueError("undefined Sharpe: zero volatility")
    magnitude = _root(excess**2 * k / variance)
    return _report(magnitude.copy_negate() if excess < 0 else magnitude)

def sharpe(returns, periodic_risk_free=0.0, periods_per_year=12):
    rs = _returns(returns, 2)
    rf,k = finite(periodic_risk_free),finite(periods_per_year)
    if k <= 0:
        raise ValueError("invalid frequency")
    return _sharpe(_mean(rs)-rf, _variance(rs), k)

def twr(initial_value, events):
    opening = finite(initial_value)
    if opening <= 0 or not events:
        raise ValueError("invalid opening or events")
    factors=[]
    for i,(pre_flow,flow) in enumerate(events):
        pre_flow,flow=finite(pre_flow),finite(flow)
        final = i == len(events)-1
        if pre_flow < 0 or (final and flow != 0):
            raise ValueError("negative valuation or nonzero final flow")
        factors.append(pre_flow/opening)
        opening=pre_flow+flow
        if not final and opening <= 0:
            raise ValueError("nonpositive post-flow value")
    return _report(math.prod(factors)-1, long_only=True)

def _npv(rate, fs):
    if rate <= -1 or len(fs) < 2:
        raise ValueError("invalid IRR input")
    discount = 1 / (1 + rate)
    value = Fraction(0)
    for f in reversed(fs):
        value = f + discount * value
    return value

def npv(rate, flows):
    return _report(_npv(finite(rate), [finite(f) for f in flows]))

def irr(flows, lower=-.9, upper=1.0):
    fs=[finite(f) for f in flows]
    if not any(f<0 for f in fs) or not any(f>0 for f in fs):
        raise ValueError("IRR requires positive and negative cash flows")
    lo,hi=finite(lower),finite(upper)
    if lo<=-1 or hi<=lo:
        raise ValueError("invalid bracket")
    a,b=_npv(lo,fs),_npv(hi,fs)
    if a==0:
        return _report(lo, long_only=True)
    if b==0:
        return _report(hi, long_only=True)
    if (a<0)==(b<0):
        raise ValueError("no bracketed root; check multiple roots")
    for _ in range(300):
        mid=(lo+hi)/2
        fm=_npv(mid,fs)
        if fm==0 or hi-lo<=Fraction(1,10**12):
            return _report(mid, long_only=True)
        if (a<0)==(fm<0):
            lo,a=mid,fm
        else:
            hi=mid
    raise RuntimeError("IRR failed to converge")

class Chapter13AcceptanceTests(unittest.TestCase):
    def test_01_simple_cumulative(self):
        self.assertAlmostEqual(cumulative([.1,-.1]),-.01)
    def test_02_arithmetic(self):
        self.assertAlmostEqual(arithmetic([.1,-.1]),0)
    def test_03_geometric(self):
        self.assertAlmostEqual(geometric([.1,-.1]),math.sqrt(.99)-1)
    def test_04_reconciliation(self):
        r=[.03,-.02,.04]
        self.assertAlmostEqual((1+geometric(r))**len(r),1+cumulative(r))
    def test_05_total_loss(self):
        self.assertEqual(geometric([.2,-1]),-1)
    def test_06_volatility(self):
        self.assertAlmostEqual(sample_volatility([.1,-.1]),math.sqrt(.02))
    def test_07_drawdown(self):
        self.assertAlmostEqual(min(drawdowns([.2,-.25])),-.25)
    def test_08_sharpe(self):
        self.assertAlmostEqual(sharpe([.1,-.1],0,12),0)
    def test_09_twr(self):
        self.assertAlmostEqual(twr(100,[(110,50),(144,0)]),-.01)
    def test_10_irr(self):
        self.assertAlmostEqual(irr([-100,110]),.1)
    def test_11_npv_residual(self):
        f=[-100,-50,144]
        self.assertAlmostEqual(npv(irr(f),f),0,places=7)
    def test_12_invalid(self):
        for fn in (lambda:cumulative([float("nan")]),
                   lambda:sample_volatility([.1]),
                   lambda:sharpe([.1,.1]),
                   lambda:irr([-100,-50]),
                   lambda:twr(100,[(110,50),(144,10)])):
            with self.assertRaises(ValueError): fn()

if __name__ == "__main__":
    returns=[.03,-.02,.04,-.01,.02,.01]
    print("Cumulative:",f"{cumulative(returns):.6%}")
    print("Geometric monthly:",f"{geometric(returns):.6%}")
    print("Sample monthly volatility:",f"{sample_volatility(returns):.6%}")
    print("Maximum drawdown:",f"{min(drawdowns(returns)):.6%}")
    print("Annualized Sharpe:",f"{sharpe(returns,.002,12):.6f}")
    unittest.main(verbosity=2)
```

## 10. Troubleshooting and review scenarios

| Failure | Diagnostic question | Resolution |
|---|---|---|
| Returns appear 100× too large | Were percentages entered as 3 rather than 0.03? | Normalize to decimal fractions |
| Drawdown spikes after withdrawal | Is the series raw account balance? | Use a flow-adjusted wealth index |
| Sharpe becomes infinite | Is volatility zero or near zero? | Mark undefined and inspect data |
| IRR differs from TWR | Are external flows substantial? | Explain the distinct return concepts |
| Annualization appears wrong | Is k matched to sampling frequency? | Document and correct scaling |
| Dividend return is overstated | Was distribution counted twice? | Reconcile price and cash ledgers |
| No IRR found | Does the bracket contain a sign change? | Inspect all roots and cash-flow signs |
| Beta unstable | Is benchmark variance near zero? | Flag insufficient variation |
| Recomputed report changes | Were historical prices revised? | Reconcile source snapshots and versions |

## 11. Final chapter knowledge check

A learner should be able to explain, without referring to the code, why:

- A +50% gain does not undo a −50% loss.
- Arithmetic and geometric returns answer different questions.
- Time-weighted return and money-weighted return can disagree.
- Volatility and drawdown measure different dimensions of risk.
- Sharpe, Sortino, Calmar, and information ratios are not interchangeable.
- IRR may be nonunique for cash flows with multiple sign changes.
- A published manuscript is not the same as independently validated software.
