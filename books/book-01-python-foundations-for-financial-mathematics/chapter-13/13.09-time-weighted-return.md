## Learning objectives

Distinguish investment performance from investor contributions and withdrawals; calculate exact time-weighted returns (TWR) using valuations at external cash flows; link subperiod returns; explain Modified Dietz approximations, valuation timing, and operational controls; and implement reproducible Python reference tests.

## 1. Why cash flows distort naive returns

Portfolio balances change because of both investment gains/losses and **external cash flows**. An external contribution increases the account balance without generating investment profit; a withdrawal decreases the balance without necessarily implying a loss.

A naive ending-versus-beginning account-value calculation confuses these effects. Time-weighted return aims to measure the **performance of invested assets independently of the size and timing of external capital flows**.

This makes TWR useful for evaluating an investment manager's performance where the manager does not control investor deposits and withdrawals. It does not measure the investor's own dollar-weighted experience; Section 13.10 covers money-weighted return.

## 2. Exact TWR: subperiod segmentation

An **exact TWR** divides the measurement horizon at external cash-flow times and values the portfolio immediately before each flow. Under the convention used here:

1. Start with opening portfolio value B.
2. Measure ending value E immediately **before** an external flow.
3. Compute subperiod return **r=E/B−1**.
4. Apply the external flow F (positive contribution, negative withdrawal) **after** the valuation.
5. The next subperiod begins at **B_next=E+F**.
6. Multiply subperiod gross factors.

For subperiod returns r1,…,rn:

**TWR = ∏(1+r_i)−1.**

The flow itself is never treated as investment income.

**Valuation timing is critical:** if a deposit occurs at the beginning of a day, its impact must be included in the opening capital for that day's performance, not the prior day's ending pre-flow valuation.

## 3. Worked example — Contribution between two periods

A portfolio begins at $100 and grows to $110. The investor then deposits $50. The new capital base is $160. The portfolio subsequently falls to $144.

| Event | Value | External flow | Calculation |
|---|---:|---:|---|
| Initial valuation | $100 | — | Opening value |
| Before contribution | $110 | +$50 afterward | First subperiod +10% |
| After contribution | $160 | — | New opening value |
| Final valuation | $144 | $0 | Second subperiod −10% |

First subperiod: **110/100−1=+10%**.

Second subperiod: **144/160−1=−10%**.

Exact TWR: **1.10×0.90−1=−1%**.

Naive account-value change: **144/100−1=+44%**. This is not the portfolio's investment return because $50 was added.

## 4. Worked example — Withdrawal

A portfolio begins at $100 and grows to $110. The investor withdraws $20, leaving $90 invested. That amount grows to $99.

First subperiod return: **110/100−1=10%**.

Second subperiod return: **99/90−1=10%**.

Exact TWR: **1.10²−1=21%**.

The account ends at $99, below its original $100 balance, yet the investment performance is +21% because the investor also withdrew $20. TWR and account-balance growth answer different questions.

## 5. Deriving the flow-adjusted recursion

Let V_(i−1) be the post-flow opening value of subperiod i, and let V_i^− be its ending **pre-flow** valuation.

**G_i=V_i^−/V_(i−1)**.

After an external flow F_i:

**V_i^+=V_i^−+F_i**.

The next period begins with V_i^+.

The linked factor is:

**G_TWR=∏G_i**.

This product measures successive investment performance factors. The flow F_i changes the next period's capital base but does not enter the prior period's numerator as earned return.

The final measurement date has no additional external flow in this convention; if one occurs, the portfolio must be valued and the measurement cutoff specified.

## 6. Dividends, fees, and internal transfers

A dividend paid by a portfolio holding is generally **investment income**, not an external investor contribution. If retained as portfolio cash or reinvested, it belongs in portfolio value. Similarly, selling one holding and buying another inside the account is an **internal transaction**, not an external flow.

Fees require a documented reporting basis:

- **Gross-of-fees TWR** may exclude specified management fees.
- **Net-of-fees TWR** reflects the defined fees.
- Transaction costs and taxes require consistent accounting.

A fee withdrawal must not be incorrectly classified as an ordinary investor withdrawal if doing so would remove a performance cost that the stated net-return methodology intends to include.

## 7. Why exact valuations matter

Exact TWR requires reliable portfolio valuations at cash-flow boundaries. Challenges include:

- Intraday deposits and withdrawals.
- Illiquid holdings without observable transaction prices.
- Stale or missing market data.
- Corporate actions and accrued income.
- Time zones and valuation cutoffs.
- Currency translation for foreign assets.

Daily valuation can reduce approximation error but does not automatically solve timing ambiguities for material intraday flows. Performance standards may prescribe particular valuation frequency and large-cash-flow policies; the method used must be disclosed.

## 8. Modified Dietz approximation

When exact valuations at each cash flow are unavailable, the **Modified Dietz** method approximates a period return using beginning value B, ending value E, external flows F_j, and weights w_j representing the fraction of the period remaining after each flow:

**R_MD = (E−B−ΣF_j)/(B+Σw_jF_j).**

A positive F is a contribution; a negative F is a withdrawal. The weight lies between 0 and 1 and depends on the defined time convention.

Modified Dietz is an **approximation**, not exact TWR. Its accuracy depends on valuation frequency, flow size, flow timing, and the return path. A large flow during a volatile period can create a material difference from an exact subperiod calculation.

### Worked example — Midpoint contribution

Opening value B=$100; ending value E=$165; a $50 contribution occurs halfway through the period.

Numerator: **165−100−50=15**.

Weighted capital: **100+0.5×50=125**.

**Modified Dietz return = 15/125 = 12%**.

Without interim valuations, 12% is an approximation based on the midpoint-weighting assumption.

## 9. Time-weighted versus money-weighted return

| Dimension | Time-weighted return | Money-weighted return |
|---|---|---|
| Main purpose | Evaluate investment performance largely independent of investor flow timing | Evaluate investor experience including flow timing |
| Cash-flow treatment | Segment and geometrically link subperiod returns | Solve a cash-flow discounting equation |
| Sensitivity to contribution timing | Reduced by exact segmentation | Intentionally sensitive |
| Typical implementation | Portfolio valuations and return linking | IRR/XIRR-style root finding |

Neither measure is inherently misleading when properly defined. They answer different economic questions.

## 10. Linking across reporting periods

Exact subperiod returns can be linked into monthly, quarterly, or annual TWR if the periods are contiguous and the valuation and flow conventions are consistent.

For monthly TWR of +3%, −2%, and +4%:

**Quarterly TWR = 1.03×0.98×1.04−1 = 4.9776%.**

Do not sum the three monthly returns (5%) and report that as exact compounded performance.

A −100% subperiod return produces a zero cumulative factor. A subsequent recovery from zero requires fresh capital or a different economic model; it is not generated by ordinary multiplicative compounding of a fully depleted long-only investment.

## 11. Reconciliation and controls

An auditable performance ledger should retain:

- Opening and ending valuations.
- Each external flow amount and timestamp.
- Pre-flow valuation and post-flow capital base.
- Each subperiod return and gross factor.
- The linked TWR.
- Currency and FX conventions.
- Fee basis, income accounting, and valuation policies.

A core acceptance invariant is that **flows change the post-flow capital base, but do not directly appear as investment return**. Compare independently constructed ledgers and review large unexplained discrepancies.

The reference implementation models exact pre-flow valuation events, external cash flows, linked returns, and Modified Dietz approximations. It includes **12 reference unit tests**. Independent runtime verification remains pending.

```python
import math
import unittest

def amount(x, label, *, positive=False):
    if isinstance(x, bool) or not isinstance(x, (int, float)) or not math.isfinite(x):
        raise ValueError(f"{label}: finite numeric value required")
    if x <= 0 if positive else x < 0:
        raise ValueError(f"{label}: invalid sign")
    return float(x)

def subperiod_return(beginning, ending_before_flow):
    b = amount(beginning, "beginning", positive=True)
    e = amount(ending_before_flow, "ending_before_flow")
    return e / b - 1.0

def link_returns(returns):
    if not returns:
        raise ValueError("at least one return required")
    factor = 1.0
    for r in returns:
        if isinstance(r, bool) or not isinstance(r, (int, float)) or not math.isfinite(r) or r < -1:
            raise ValueError("invalid long-only subperiod return")
        factor *= 1.0 + r
    return factor - 1.0

def exact_twr(initial_value, events):
    """Events: (pre_flow_value, external_flow), including final (value, 0).
    Positive external_flow = contribution; negative = withdrawal.
    Flows occur after the pre-flow valuation; last event must have zero flow.
    """
    opening = amount(initial_value, "initial_value", positive=True)
    if not events:
        raise ValueError("events required")
    factors = []
    for i, (pre_flow, flow) in enumerate(events):
        ending = amount(pre_flow, "pre_flow")
        if isinstance(flow, bool) or not isinstance(flow, (int, float)) or not math.isfinite(flow):
            raise ValueError("invalid flow")
        if i == len(events)-1 and flow != 0:
            raise ValueError("final event must have zero flow")
        factors.append(ending / opening)
        opening = ending + flow
        if i != len(events)-1 and opening <= 0:
            raise ValueError("nonpositive post-flow opening value")
    return math.prod(factors) - 1.0

def modified_dietz(beginning, ending, flows_with_weights):
    """Flow weights are fractions of the period remaining, 0 <= w <= 1."""
    b = amount(beginning, "beginning", positive=True)
    e = amount(ending, "ending")
    total_flows = 0.0
    weighted_flows = 0.0
    for flow, weight in flows_with_weights:
        if isinstance(flow, bool) or not isinstance(flow, (int, float)) or not math.isfinite(flow):
            raise ValueError("invalid flow")
        if isinstance(weight, bool) or not isinstance(weight, (int, float)) or not math.isfinite(weight) or not 0 <= weight <= 1:
            raise ValueError("weight must be between zero and one")
        total_flows += flow
        weighted_flows += flow * weight
    denominator = b + weighted_flows
    if denominator <= 0:
        raise ValueError("nonpositive weighted capital base")
    return (e - b - total_flows) / denominator

class TWRTests(unittest.TestCase):
    def test_01_one_period(self): self.assertAlmostEqual(subperiod_return(100, 110), .1)
    def test_02_loss(self): self.assertAlmostEqual(subperiod_return(160, 144), -.1)
    def test_03_link(self): self.assertAlmostEqual(link_returns([.1,-.1]), -.01)
    def test_04_exact_contribution(self): self.assertAlmostEqual(exact_twr(100, [(110,50),(144,0)]), -.01)
    def test_05_exact_withdrawal(self): self.assertAlmostEqual(exact_twr(100, [(110,-20),(99,0)]), .21)
    def test_06_no_flows(self): self.assertAlmostEqual(exact_twr(100, [(121,0)]), .21)
    def test_07_zero_return(self): self.assertAlmostEqual(exact_twr(100, [(100,50),(150,0)]), 0)
    def test_08_total_loss(self): self.assertEqual(link_returns([.1,-1]), -1)
    def test_09_dietz_no_flows(self): self.assertAlmostEqual(modified_dietz(100,110,[]), .1)
    def test_10_dietz_midpoint(self): self.assertAlmostEqual(modified_dietz(100,165,[(50,.5)]), .12)
    def test_11_dietz_zero(self): self.assertAlmostEqual(modified_dietz(100,150,[(50,.5)]), 0)
    def test_12_invalid(self):
        cases = [lambda: exact_twr(0,[(100,0)]),
                 lambda: exact_twr(100,[(100,-100),(0,0)]),
                 lambda: exact_twr(100,[(110,5)]),
                 lambda: link_returns([]),
                 lambda: subperiod_return(0,100),
                 lambda: modified_dietz(100,150,[(50,1.2)]),
                 lambda: modified_dietz(100,100,[(-200,1)])]
        for fn in cases:
            with self.assertRaises(ValueError): fn()

if __name__ == "__main__":
    events=[(110,50),(144,0)]
    print("Exact TWR:", f"{exact_twr(100,events):.2%}")
    print("Modified Dietz illustration:", f"{modified_dietz(100,165,[(50,.5)]):.2%}")
    unittest.main(verbosity=2)
```

## 13. Exercises with worked answers

1. **Simple subperiod:** $100→$110 before a flow. **Answer:** +10%.
2. **Second subperiod:** $160→$144. **Answer:** −10%.
3. **Linked TWR:** +10%, then −10%. **Answer:** −1%.
4. **Naive account growth:** $100→$144 with a $50 contribution. **Answer:** +44% account-value change, not TWR.
5. **Post-flow base:** $110 plus $50 contribution. **Answer:** $160.
6. **Withdrawal base:** $110 less $20 withdrawal. **Answer:** $90.
7. **Post-withdrawal return:** $90→$99. **Answer:** +10%.
8. **Withdrawal example TWR:** +10% and +10%. **Answer:** +21%.
9. **Account ending balance:** Withdrawal example ends at $99. **Answer:** $99, despite +21% TWR.
10. **Three periods:** +3%, −2%, +4%. **Answer:** 1.03×0.98×1.04−1=4.9776%.
11. **Modified Dietz numerator:** B=100, E=165, F=50. **Answer:** 15.
12. **Modified Dietz denominator:** Midpoint F=50. **Answer:** 100+25=125.
13. **Modified Dietz return:** Same data. **Answer:** 12%.
14. **Zero-return contribution:** $100→$100, deposit $50, then $150→$150. **Answer:** TWR=0%.
15. **Internal transfer:** Move cash from portfolio bank balance to portfolio equity holdings. **Answer:** Not an external flow.
16. **Dividend classification:** Receive dividend into portfolio cash. **Answer:** Investment income, not an investor deposit.
17. **Fee basis:** Why label gross or net TWR? **Answer:** Different fee treatment changes reported performance.
18. **Valuation timing:** Why value immediately before a flow? **Answer:** To isolate investment gain/loss from the external capital movement.

## 14. Applied mini-project — Auditable TWR engine

Construct a portfolio performance ledger with these events, in chronological order:

| Event | Pre-flow portfolio value | External flow after valuation |
|---|---:|---:|
| Opening | $1,000 | — |
| Event 1 | $1,080 | +$200 |
| Event 2 | $1,216 | −$100 |
| Final | $1,227.60 | $0 |

**Tasks:**

1. Calculate the post-flow capital base after each event.
2. Compute all three exact subperiod returns.
3. Link the gross factors to obtain cumulative TWR.
4. Compare TWR with the naive ending/opening balance change.
5. Build a return index rebased to 100.
6. Add validation for missing valuations, non-finite flows, nonpositive post-flow capital, and inconsistent event order.
7. Produce an audit-ready CSV containing each event's opening value, pre-flow value, flow, post-flow value, and return.

**Worked checks:** First subperiod = 1,080/1,000−1=**+8%**. After a $200 deposit, the next opening value is $1,280; second subperiod = 1,216/1,280−1=**−5%**. After a $100 withdrawal, the third opening value is $1,116; third subperiod = 1,227.60/1,116−1=**+10%**. Linked TWR = **1.08×0.95×1.10−1=12.86%**.

The naive account-value change is **22.76%**, which is not the TWR because net external contributions total $100.

**Acceptance criteria:** Subperiod returns reconcile with pre-flow and post-flow valuations; linked TWR is 12.86%; all 12 reference tests pass; and external cash flows never count as investment income.

## 15. Production and SRE considerations

- Store flow timestamps with explicit time zones and cutoff conventions.
- Identify external versus internal cash movements with an auditable classification.
- Detect duplicate and late-arriving transactions.
- Preserve corporate-action, dividend, and fee accounting.
- Use a documented policy for missing or stale valuations.
- Separate exact TWR from Modified Dietz approximations in reporting.
- Reconcile subperiod factor products against published performance indices.
- Document treatment of material intraday cash flows and unusual events.
- Validate extreme returns and zero-capital boundaries.
- Maintain versioned calculation methodology and repeatable QA evidence.
