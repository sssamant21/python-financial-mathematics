## Learning objectives

Understand why investment return should be evaluated alongside risk; calculate and interpret Sharpe, Sortino, Calmar, information ratios, and beta; distinguish total, downside, drawdown, and benchmark-relative risk; recognize methodological assumptions and failure cases; implement auditable Python calculations.

## 1. Why risk adjustment matters

A strategy with a 12% return is not necessarily preferable to one with a 10% return. The first may have experienced substantially greater volatility, deeper drawdowns, or much more benchmark-relative risk.

**Risk-adjusted performance** relates earned return to a defined measure of risk. The resulting statistic can be useful for comparison, but it cannot compress all financial risk into a single number.

Always specify:

- The return methodology: price-only versus total return, gross versus net of fees, and time-weighted versus money-weighted.
- Observation period and sampling frequency.
- The risk measure and its calculation convention.
- Benchmark and risk-free-rate assumptions.
- Annualization methodology and relevant limitations.

## 2. Sharpe ratio — excess return per unit of volatility

The **Sharpe ratio** relates mean excess return to the standard deviation of excess returns.

For equally spaced period returns R_t and a matched periodic risk-free rate r_f,t:

**Excess return e_t = R_t − r_f,t**.

**Sharpe_period = mean(e_t) / sample_std(e_t)**.

For a constant periodic risk-free rate, subtracting that constant changes the mean but not the standard deviation.

A commonly used annualization under suitable assumptions is:

**Sharpe_annual ≈ Sharpe_period × sqrt(k)**,

where k is the number of periods per year. This scaling assumes an appropriate stationary, sufficiently uncorrelated return process; autocorrelation, changing volatility, and nonnormal returns can invalidate it.

### Worked example A — Sharpe ratio

Consider period returns +10% and −10%, with risk-free return 0% per period.

Mean excess return = 0%.

Sample volatility = sqrt(0.02) ≈ 14.1421%.

**Sharpe = 0 / 0.141421 = 0**.

If the periodic risk-free rate is 1%, mean excess return is −1%, and the sample volatility remains 14.1421%:

**Sharpe ≈ −0.07071**.

A zero-volatility excess-return series makes the usual ratio undefined; do not silently report infinity as a reliable performance measure.

## 3. Risk-free rate alignment

The risk-free return must correspond to the **same period length, currency, and return convention** as the investment return.

For an annual-effective risk-free rate of 5% and a 12-month convention, a consistent monthly-effective equivalent is:

**r_f,monthly = 1.05^(1/12)−1 ≈ 0.4074%**.

Simply dividing 5% by 12 is an approximation and is not identical to converting an annual-effective rate. If risk-free rates change through time, use period-matched observations.

## 4. Sortino ratio — downside risk relative to a target

The **Sortino ratio** focuses on downside variation below a target or minimum acceptable return (MAR).

One common downside deviation definition is:

**DD = sqrt[(1/n)Σ min(0,R_t−MAR)²]**.

Then:

**Sortino_period = [mean(R_t)−MAR] / DD**.

The downside-deviation denominator convention must be disclosed. Some sources use different observation counts or annualization treatments.

### Worked example B — Sortino ratio

Returns: +10%, −10%; MAR=0%.

Mean return = 0%.

Downside deviation = sqrt[(0²+0.10²)/2] = sqrt(0.005) ≈ 7.0711%.

**Sortino = 0**.

If no observations fall below the target, downside deviation is zero and the ratio is undefined under the basic formula. A reporting system should flag this case rather than inventing a comparable finite number.

## 5. Calmar ratio — return relative to maximum drawdown

A common Calmar ratio convention divides an **annualized return** by the **absolute magnitude of maximum drawdown** over a stated lookback horizon:

**Calmar = Annualized return / |MDD|**.

If annualized return is 12% and maximum drawdown is −20%:

**Calmar = 0.12 / 0.20 = 0.60**.

The annualization basis and drawdown measurement horizon must be stated. Different sources use different historical windows, so Calmar ratios from dissimilar windows are not automatically comparable.

If maximum drawdown is zero, the ratio is undefined under this formula.

## 6. Information ratio — active return relative to tracking error

For portfolio return R_p,t and benchmark return R_b,t:

**Active return a_t = R_p,t − R_b,t**.

**Tracking error = sample_std(a_t)**.

**Information ratio = mean(a_t) / tracking error**.

For k observations per year, a common approximate annualization is:

**IR_annual ≈ IR_period × sqrt(k)**,

subject to return autocorrelation and other scaling assumptions.

### Worked example C — Active returns

Suppose active returns are +2% and −2%.

Mean active return = 0%.

Sample tracking error = sqrt[(0.02²+0.02²)/(2−1)] ≈ 2.8284%.

**Information ratio = 0**.

A benchmark must be economically appropriate and measured on the same dates, currency, and fee basis as the portfolio.

## 7. Beta — sensitivity to benchmark returns

Beta measures linear exposure to a benchmark's return variation:

**β = Cov(R_p,R_b) / Var(R_b)**.

When both covariance and variance use consistent sample or population denominators, the factors cancel.

### Worked example D — Beta

Benchmark returns: +10%, −10%.

Asset returns: +20%, −20%.

The asset moves twice as much as the benchmark in these observations, giving:

**β = 2**.

Beta is not a full measure of risk. It is sensitive to the chosen benchmark, measurement window, nonsynchronous prices, and changing market regimes. Beta is undefined when benchmark return variance is zero.

## 8. Alpha and benchmark-relative performance

A simple excess return over a benchmark is:

**Active return = R_p − R_b**.

A model-based alpha, such as a CAPM-style intercept, is different. Under a simplified single-period CAPM expression:

**α = R_p − [r_f + β(R_b−r_f)]**.

Interpretation depends on the model, measurement frequency, estimation procedure, and whether returns are expected or realized. Do not label every positive active return as statistically significant alpha.

## 9. Comparing measures

| Measure | Return numerator | Risk denominator | Main limitation |
|---|---|---|---|
| Sharpe | Mean excess return | Standard deviation of excess return | Penalizes upside and downside equally |
| Sortino | Mean return above target | Downside deviation | Sensitive to target and denominator convention |
| Calmar | Annualized return | Absolute maximum drawdown | Path- and window-dependent |
| Information ratio | Mean active return | Tracking error | Benchmark-dependent |
| Beta | Covariance with benchmark | Benchmark variance | Measures systematic sensitivity, not total risk |

No one metric dominates all use cases. A robust report combines multiple measures with absolute returns, drawdowns, and data-quality context.

## 10. Statistical and practical limitations

Risk-adjusted metrics are historical estimates and may be unstable in small samples. Common failure modes include:

- Nonstationary returns and changing market regimes.
- Serial correlation and volatility clustering.
- Heavy tails and asymmetric return distributions.
- Stale valuations and smoothed illiquid-asset returns.
- Benchmark selection bias and survivorship bias.
- Different fee, tax, and dividend conventions.
- Inconsistent annualization and risk-free-rate periods.
- Ratios with nearly zero denominators.

A high ratio can arise from underestimated volatility or a short favorable sample rather than a genuinely robust investment process.

## 11. Production methodology controls

For reproducible reporting:

1. Specify return type, currency, and fee basis.
2. Align portfolio, benchmark, and risk-free-rate timestamps.
3. Select sample or population variance explicitly.
4. Store annualization factors and day-count conventions.
5. Reject zero denominators with an explicit status.
6. Report lookback dates and number of observations.
7. Reconcile wealth-based drawdowns against the source return series.
8. Preserve calculation code version and source-data lineage.

The standard-library lab implements Sharpe, Sortino, Calmar, information ratio, beta, and maximum drawdown, including **12 reference unit tests**. The example annualization assumes the stated scaling convention; independent runtime verification remains pending.

```python
import math
import unittest

def validate_returns(values, minimum=2):
    if len(values) < minimum:
        raise ValueError("insufficient observations")
    if any(isinstance(v, bool) or not isinstance(v, (int, float)) or not math.isfinite(v) for v in values):
        raise ValueError("finite numeric returns required")
    return [float(v) for v in values]

def mean(values):
    xs = validate_returns(values)
    return math.fsum(xs) / len(xs)

def sample_std(values):
    xs = validate_returns(values)
    avg = mean(xs)
    return math.sqrt(math.fsum((v - avg)**2 for v in xs) / (len(xs)-1))

def sharpe_ratio(returns, risk_free_period=0.0, periods_per_year=1):
    xs = validate_returns(returns)
    if not math.isfinite(risk_free_period) or periods_per_year <= 0:
        raise ValueError("invalid risk-free rate or scale")
    excess = [v-risk_free_period for v in xs]
    vol = sample_std(excess)
    if vol == 0:
        raise ValueError("Sharpe undefined for zero excess-return volatility")
    return mean(excess) / vol * math.sqrt(periods_per_year)

def downside_deviation(returns, target=0.0):
    xs = validate_returns(returns)
    if not math.isfinite(target):
        raise ValueError("invalid target")
    return math.sqrt(math.fsum(min(0.0, v-target)**2 for v in xs) / len(xs))

def sortino_ratio(returns, target=0.0, periods_per_year=1):
    xs = validate_returns(returns)
    dd = downside_deviation(xs, target)
    if dd == 0 or periods_per_year <= 0:
        raise ValueError("Sortino undefined for zero downside deviation")
    return (mean(xs)-target) / dd * math.sqrt(periods_per_year)

def max_drawdown(returns):
    xs = validate_returns(returns)
    wealth = peak = 1.0
    worst = 0.0
    for r in xs:
        if r < -1:
            raise ValueError("simple return below -100%")
        wealth *= 1+r
        peak = max(peak, wealth)
        worst = min(worst, wealth/peak-1)
    return worst

def calmar_ratio(annualized_return, maximum_drawdown):
    if any(isinstance(v,bool) or not isinstance(v,(int,float)) or not math.isfinite(v)
           for v in (annualized_return,maximum_drawdown)):
        raise ValueError("finite inputs required")
    if maximum_drawdown >= 0 or maximum_drawdown < -1:
        raise ValueError("negative nonzero maximum drawdown required")
    return annualized_return / abs(maximum_drawdown)

def information_ratio(active_returns, periods_per_year=1):
    xs = validate_returns(active_returns)
    tracking_error = sample_std(xs)
    if tracking_error == 0 or periods_per_year <= 0:
        raise ValueError("information ratio undefined")
    return mean(xs)/tracking_error*math.sqrt(periods_per_year)

def beta(asset_returns, benchmark_returns):
    a, b = validate_returns(asset_returns), validate_returns(benchmark_returns)
    if len(a) != len(b):
        raise ValueError("aligned return series required")
    ma, mb = mean(a), mean(b)
    numerator = math.fsum((x-ma)*(y-mb) for x,y in zip(a,b))
    denominator = math.fsum((y-mb)**2 for y in b)
    if denominator == 0:
        raise ValueError("zero benchmark variance")
    return numerator/denominator

class RiskAdjustedTests(unittest.TestCase):
    def test_01_mean(self): self.assertAlmostEqual(mean([.1,-.1]),0)
    def test_02_sample_std(self): self.assertAlmostEqual(sample_std([.1,-.1]),math.sqrt(.02))
    def test_03_sharpe(self): self.assertAlmostEqual(sharpe_ratio([.1,-.1]),0)
    def test_04_sharpe_rf(self): self.assertAlmostEqual(sharpe_ratio([.1,-.1],.01),-.01/math.sqrt(.02))
    def test_05_sortino(self): self.assertAlmostEqual(sortino_ratio([.1,-.1]),0)
    def test_06_downside(self): self.assertAlmostEqual(downside_deviation([.1,-.1]),math.sqrt(.005))
    def test_07_max_drawdown(self): self.assertAlmostEqual(max_drawdown([.2,-.25]),-.25)
    def test_08_calmar(self): self.assertAlmostEqual(calmar_ratio(.12,-.2),.6)
    def test_09_information(self): self.assertAlmostEqual(information_ratio([.1,-.1]),0)
    def test_10_beta(self): self.assertAlmostEqual(beta([.2,-.2],[.1,-.1]),2)
    def test_11_annual_sharpe(self): self.assertAlmostEqual(sharpe_ratio([.1,-.1],periods_per_year=4),0)
    def test_12_invalid(self):
        for fn in (lambda:sharpe_ratio([.1,.1]),
                   lambda:sortino_ratio([.1,.2]),
                   lambda:calmar_ratio(.1,0),
                   lambda:beta([.1,.2],[.1,.1]),
                   lambda:information_ratio([.1,.1]),
                   lambda:mean([float("nan"),.1])):
            with self.assertRaises(ValueError): fn()

if __name__ == "__main__":
    returns=[.04,-.02,.03,-.01,.05]
    print("Sharpe (zero periodic risk-free rate):",round(sharpe_ratio(returns),4))
    print("Sortino (zero target):",round(sortino_ratio(returns),4))
    print("Maximum drawdown:",f"{max_drawdown(returns):.2%}")
    unittest.main(verbosity=2)
```

## 13. Exercises with worked solutions

1. **Mean return:** +10%, −10%. **Answer:** 0%.
2. **Sample volatility:** +10%, −10%. **Answer:** sqrt(0.02)≈14.1421%.
3. **Sharpe with zero risk-free rate:** Same series. **Answer:** 0.
4. **Sharpe with 1% periodic risk-free rate:** Same series. **Answer:** −0.01/sqrt(0.02)≈−0.07071.
5. **Downside deviation:** +10%, −10%, MAR=0. **Answer:** sqrt(0.005)≈7.0711%.
6. **Sortino:** Same series and MAR. **Answer:** 0.
7. **Calmar:** Annualized return 12%, MDD −20%. **Answer:** 0.60.
8. **Information ratio:** Active returns +2%, −2%. **Answer:** 0.
9. **Tracking error:** Same active returns. **Answer:** sqrt(0.0008)≈2.8284%.
10. **Beta:** Benchmark +10%, −10%; asset +20%, −20%. **Answer:** 2.
11. **Annual Sharpe scaling:** Periodic Sharpe=0.5, k=12. **Answer:** 0.5×sqrt(12)≈1.7321 under the scaling assumptions.
12. **Annual risk-free conversion:** Annual-effective 5%, monthly-equivalent. **Answer:** 1.05^(1/12)−1≈0.4074%.
13. **Zero volatility:** All excess returns identical. **Answer:** Sharpe is undefined under the standard formula.
14. **No downside observations:** Every return exceeds MAR. **Answer:** Sortino is undefined under the standard formula.
15. **Zero drawdown:** MDD=0. **Answer:** Calmar denominator is zero; report undefined.
16. **Zero benchmark variance:** All benchmark returns identical. **Answer:** Beta is undefined.
17. **Benchmark mismatch:** Portfolio in USD, benchmark in EUR with no currency conversion. **Answer:** Comparison is not aligned and must be corrected.
18. **Metric selection:** Assess benchmark-relative consistency. **Answer:** Information ratio, supported by active-return and tracking-error details.

## 14. Applied mini-project — Risk-adjusted strategy scorecard

Compare two hypothetical monthly total-return strategies:

| Month | Strategy A | Strategy B | Benchmark |
|---|---:|---:|---:|
| 1 | +3% | +2% | +2% |
| 2 | −2% | −1% | −1% |
| 3 | +4% | +3% | +2% |
| 4 | −1% | −2% | −1% |
| 5 | +2% | +1% | +1% |
| 6 | +1% | +2% | +1% |

Assume a constant monthly risk-free return of **0.2%**, MAR=0%, and a **12-month annualization convention**.

**Tasks:**

1. Calculate arithmetic mean monthly return for each strategy.
2. Calculate monthly sample volatility and annualized volatility.
3. Calculate Sharpe and Sortino ratios using consistent periodic inputs.
4. Calculate maximum drawdown from each strategy's compounded wealth index.
5. Calculate information ratio against the benchmark.
6. Calculate beta relative to the benchmark.
7. Identify undefined or numerically unstable cases.
8. Produce an audit table with all inputs, calculation conventions, and metric outputs.

**Worked checkpoints:** Strategy A's six returns sum to **+7%**, giving an arithmetic mean of **7%/6≈1.1667% per month**. Strategy B's six returns sum to **+5%**, giving **5%/6≈0.8333% per month**. Strategy A's mean monthly excess return over the 0.2% risk-free assumption is **≈0.9667%**.

**Acceptance criteria:** Portfolio and benchmark dates align; monthly risk-free return is subtracted consistently; Sharpe and information ratios use sample standard deviations; drawdowns are computed from compounded wealth; zero-denominator cases are explicit; all 12 reference unit tests pass.

## 15. SRE and data-quality considerations

- Monitor missing and stale price or benchmark observations.
- Track return methodology and data-source versions.
- Detect currency, frequency, and date-alignment mismatches.
- Flag extreme metrics driven by near-zero denominators.
- Require minimum sample lengths before publishing metrics.
- Preserve reproducible input snapshots and calculation results.
- Validate risk-free-rate conversion and annualization assumptions.
- Use peer review for changes to metric definitions.
- Avoid treating a single risk-adjusted metric as a complete risk assessment.

Risk-adjusted measures connect investment return to distinct forms of risk: total volatility, downside variability, peak-to-trough decline, and benchmark-relative performance. Their value depends on clearly stated conventions and careful interpretation.
