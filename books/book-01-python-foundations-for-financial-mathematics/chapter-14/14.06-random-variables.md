## Learning objectives

Define random variables as numerical functions of outcomes; distinguish discrete and continuous variables; construct payoff and return distributions; calculate expectation, variance, and event probabilities; apply transformations; and implement a reproducible Python simulation with validation and reference tests.

## 1. From outcomes to financial numbers

A sample space describes what can happen. A **random variable** assigns a number to each outcome.

Formally, a real-valued random variable is a measurable function:

**X: Ω → ℝ.**

In a finite sample space, measurability is automatic when all subsets are events. For more general spaces, measurability ensures that events such as {X≤x} have well-defined probabilities.

Financial examples include the future stock price, one-period return, bond payoff, credit loss, insurance claim amount, and number of trades executed.

A random variable is **not** necessarily a variable whose value changes at every instant; it is a numerical quantity whose realized value depends on an uncertain outcome.

## 2. Worked example — Three-state investment payoff

Consider a hypothetical investment with the following one-period net dollar payoffs:

| State | Probability | X(state) |
|---|---:|---:|
| Bear | 25% | −$20 |
| Base | 50% | +$5 |
| Bull | 25% | +$30 |

The sample space is Ω={bear,base,bull}. The random variable X maps each state to a payoff.

The probability distribution of X is:

**P(X=−20)=.25, P(X=5)=.50, P(X=30)=.25.**

The probabilities sum to one.

## 3. Discrete versus continuous random variables

A **discrete** random variable has a finite or countably infinite set of possible values. Examples include number of defaults, number of claims, and a simplified three-state investment payoff.

A **continuous** random variable is often modeled using a probability density, such as an idealized continuously distributed return. For a continuous distribution, the probability of each exact point is zero. An interval has positive probability when it contains positive mass.

Actual market prices may be quoted in ticks and recorded with finite precision. Choosing a continuous model is a modeling approximation, not a claim that trading systems have infinite precision.

## 4. Probability mass function

For a discrete random variable X, its probability mass function is:

**p_X(x)=P(X=x).**

Every mass is nonnegative, and the sum over all possible values is one.

Different underlying outcomes can map to the same numerical value. Their probabilities must then be **aggregated**.

### Worked example A — Same payoff from different states

Suppose states A, B, C have probabilities .2, .3, .5. A and B both pay $0, while C pays $10.

Then:

**P(X=0)=.2+.3=.5** and **P(X=10)=.5**.

The payoff distribution has two values even though the sample space has three states.

## 5. Cumulative distribution function

For any real-valued random variable:

**F_X(x)=P(X≤x).**

For the three-state payoff example:

- F_X(x)=0 when x<−20.
- F_X(x)=.25 when −20≤x<5.
- F_X(x)=.75 when 5≤x<30.
- F_X(x)=1 when x≥30.

The CDF is nondecreasing and right-continuous. It is useful for computing threshold probabilities such as the chance that a portfolio loses more than a specified amount.

## 6. Expected value

For a discrete random variable:

**E[X]=Σ_x xP(X=x).**

For the three-state investment:

**E[X]=(.25)(−20)+(.50)(5)+(.25)(30)=$5.**

The expected payoff is a probability-weighted average, not a guaranteed outcome.

## 7. Variance and standard deviation

The variance measures dispersion around the expectation:

**Var(X)=E[(X−E[X])²].**

For the example:

**Var(X)=.25(−20−5)²+.50(5−5)²+.25(30−5)²=312.5 dollars².**

**SD(X)=√312.5≈$17.6777.**

Standard deviation has the same units as the random variable. Variance has squared units.

## 8. Transformations of random variables

A new random variable can be created by applying a function to an existing random variable:

**Y=g(X).**

For a linear transformation Y=aX+b:

**E[Y]=aE[X]+b** and **Var(Y)=a²Var(X)**.

### Worked example B — Leveraged payoff

If Y=2X+1 and E[X]=5, then:

**E[Y]=2(5)+1=11.**

If Var(X)=312.5:

**Var(Y)=4(312.5)=1250.**

A nonlinear transformation generally requires computing its distribution or expectation directly; E[g(X)] need not equal g(E[X]).

## 9. Financial return as a random variable

For an asset with initial price P₀>0 and uncertain future price P₁, the one-period simple return is:

**R=(P₁−P₀)/P₀**, ignoring distributions and costs.

If P₀=$100 and future prices are $90 and $120, the possible returns are −10% and +20%.

If dividends or other cash distributions occur, the return definition must include them when appropriate.

## 10. Credit-loss random variable

Define the default indicator D:

**D=1** if default occurs, and **D=0** otherwise.

If P(default)=p, then:

**E[D]=p** and **Var(D)=p(1−p)**.

For a fixed exposure of $10,000 and loss given default of 40%, define the simplified loss:

**L=4000D.**

If p=.02:

**E[L]=4000(.02)=$80.**

Real credit models may require stochastic exposure, recovery, discounting, and dependence.

## 11. Indicator variables and event probabilities

For an event A, the indicator random variable is:

**I_A(ω)=1 if ω∈A; otherwise 0.**

An important identity is:

**E[I_A]=P(A).**

Indicators connect event-based probability calculations with numerical expectations and are useful for simulation and risk metrics.

## 12. Simulation versus analytical distribution

For a known finite distribution, exact formulas are generally preferable for simple expectations and probabilities. Monte Carlo simulation samples outcomes repeatedly and estimates statistics empirically.

A simulation mean is:

**X̄=(1/n)Σᵢ Xᵢ.**

With independent, identically distributed observations and a finite expectation, the law of large numbers explains why this average approaches the expected value as the sample size increases. A finite run will not generally match the theoretical expectation exactly.

A fixed pseudorandom seed helps reproduce results, but it does not validate the assumed probabilities.

The standard-library lab maps outcomes to numeric payoffs, aggregates duplicate values, computes expectation and variance, evaluates threshold-event probabilities, and samples scenarios reproducibly. Use Python 3.8 or later. The first command runs **12 reference unit tests**; the second compiles without running. Every declared state must have exactly one finite numeric payoff. Payoff labels keep their input precision when grouped. Weights within 1e−12 of unit mass are normalized; moments are evaluated before conversion to floats, with decimal text used for float inputs. Simulation uses float sampling weights and illustrates ordinary scenario probabilities.

```python
from fractions import Fraction
from math import isfinite, sqrt
from random import Random
import unittest

def validate(weights):
    if not weights:
        raise ValueError("empty probability model")
    exact = {}
    for state, p in weights.items():
        if isinstance(p, bool) or not isinstance(p, (int, float)) or not 0 <= p <= 1:
            raise ValueError("invalid probability")
        exact[state] = Fraction(str(p))
    total = sum(exact.values())
    if abs(total - 1) > Fraction(1, 10**12):
        raise ValueError("probabilities must sum to one within 1e-12")
    return {state: p / total for state, p in exact.items()}

def _payoff(value):
    if isinstance(value, bool) or not isinstance(value, (int, float)):
        raise ValueError("random variable values must be finite numbers")
    if isinstance(value, float) and not isfinite(value):
        raise ValueError("random variable values must be finite numbers")
    return Fraction(value) if isinstance(value, int) else Fraction(str(value))

def _report(value):
    try:
        result = float(value)
    except OverflowError as exc:
        raise ValueError("result exceeds float range") from exc
    if not isfinite(result) or (result == 0 and value != 0):
        raise ValueError("result outside reportable float range")
    return result

def _distribution(w, mapping):
    if set(mapping) != set(w):
        raise ValueError("mapping must cover exactly the declared outcomes")
    result = {}
    for state, p in w.items():
        value = mapping[state]
        _payoff(value)
        result[value] = result.get(value, 0) + p
    return result

def distribution(weights, mapping):
    return {x: _report(p) for x, p in _distribution(validate(weights), mapping).items()}

def _mean(d):
    return sum(_payoff(x) * p for x, p in d.items())

def expected(weights, mapping):
    return _report(_mean(_distribution(validate(weights), mapping)))

def variance(weights, mapping):
    d = _distribution(validate(weights), mapping)
    mean = _mean(d)
    return _report(sum(p * (_payoff(x) - mean)**2 for x, p in d.items() if p))

def event_probability(weights, mapping, predicate):
    d = _distribution(validate(weights), mapping)
    return _report(sum(p for x, p in d.items() if predicate(x)))

def simulate(weights, mapping, n=10000, seed=42):
    w = validate(weights)
    _distribution(w, mapping)
    if type(n) is not int or n <= 0:
        raise ValueError("n must be positive integer")
    if type(seed) is not int:
        raise ValueError("seed must be integer")
    rng = Random(seed)
    states = rng.choices(list(w), weights=[float(p) for p in w.values()], k=n)
    return [mapping[s] for s in states]

class RandomVariableTests(unittest.TestCase):
    def setUp(self):
        self.w={"bear":.25,"base":.5,"bull":.25}
        self.x={"bear":-20,"base":5,"bull":30}
    def test_01_distribution(self): self.assertEqual(distribution(self.w,self.x),{-20.0:.25,5.0:.5,30.0:.25})
    def test_02_expectation(self): self.assertAlmostEqual(expected(self.w,self.x),5)
    def test_03_variance(self): self.assertAlmostEqual(variance(self.w,self.x),312.5)
    def test_04_sd(self): self.assertAlmostEqual(sqrt(variance(self.w,self.x)),sqrt(312.5))
    def test_05_loss_event(self): self.assertAlmostEqual(event_probability(self.w,self.x,lambda x:x<0),.25)
    def test_06_positive_event(self): self.assertAlmostEqual(event_probability(self.w,self.x,lambda x:x>0),.75)
    def test_07_constant(self): self.assertAlmostEqual(variance(self.w,{s:7 for s in self.w}),0)
    def test_08_transform(self): self.assertAlmostEqual(expected(self.w,{s:2*v+1 for s,v in self.x.items()}),11)
    def test_09_aggregation(self):
        self.assertEqual(distribution({"a":.2,"b":.3,"c":.5},{"a":0,"b":0,"c":1}),{0.0:.5,1.0:.5})
    def test_10_reproducibility(self): self.assertEqual(simulate(self.w,self.x,20,7),simulate(self.w,self.x,20,7))
    def test_11_simulation_length(self): self.assertEqual(len(simulate(self.w,self.x,123)),123)
    def test_12_invalid(self):
        for fn in (lambda:expected(self.w,{"bear":-20}),
                   lambda:variance({"a":.8,"b":.4},{"a":0,"b":1}),
                   lambda:simulate(self.w,self.x,0),
                   lambda:distribution(self.w,{"bear":0,"base":1,"bull":float("nan")})):
            with self.assertRaises(ValueError): fn()

if __name__=="__main__":
    suite=unittest.defaultTestLoader.loadTestsFromTestCase(RandomVariableTests)
    result=unittest.TextTestRunner(verbosity=2).run(suite)
    if not result.wasSuccessful(): raise SystemExit(1)
```

## 14. Twenty-four worked exercises

1. **Random variable definition:** Ω={bear,base,bull}; X={−20,5,30}. **Solution:** X is a function assigning one numerical payoff to each state.

2. **Probability mass:** P(bear)=.25. **Solution:** P(X=−20)=.25.

3. **Expected payoff:** Probabilities .25,.5,.25 and payoffs −20,5,30. **Solution:** E[X]=5.

4. **Variance:** Same distribution. **Solution:** Var(X)=312.5 dollars².

5. **Standard deviation:** Var(X)=312.5. **Solution:** SD(X)=√312.5≈17.6777 dollars.

6. **Loss event:** Only bear has negative payoff. **Solution:** P(X<0)=.25.

7. **Positive payoff:** Base and bull pay positive amounts. **Solution:** P(X>0)=.75.

8. **Linear transformation:** Y=2X+1 and E[X]=5. **Solution:** E[Y]=11.

9. **Variance scaling:** Y=2X+1; Var(X)=312.5. **Solution:** Var(Y)=4×312.5=1250.

10. **Constant payoff:** X=7 always. **Solution:** E[X]=7; Var(X)=0.

11. **Two states same payoff:** Two outcomes with probabilities .2 and .3 both pay 0. **Solution:** P(X=0)=.5.

12. **Bernoulli default indicator:** D=1 for default, 0 otherwise; P(default)=.02. **Solution:** E[D]=.02.

13. **Credit loss:** L=4000D with default probability .02. **Solution:** E[L]=$80.

14. **Return mapping:** Asset price begins at $100, ends at $90 or $120. **Solution:** Simple returns −10% or +20%.

15. **Price and return:** P₀=100, R=.05. **Solution:** P₁=100(1+.05)=105.

16. **CDF:** P(X=−20)=.25, P(X=5)=.5, P(X=30)=.25. **Solution:** F_X(5)=P(X≤5)=.75.

17. **Strict inequality:** Same X. **Solution:** P(X<5)=.25.

18. **Threshold:** Same X. **Solution:** P(X≥5)=.75.

19. **Continuous versus discrete:** A price is modeled continuously. **Solution:** For an atomless continuous model, P(X=x)=0 at every exact x.

20. **Outcome versus variable:** Ω includes economic scenarios. **Solution:** X converts each scenario into a numerical financial quantity.

21. **Expected loss:** Losses 0 with probability .9 and 100 with probability .1. **Solution:** E[L]=10.

22. **Indicator event:** I_A=1 when event A occurs. **Solution:** E[I_A]=P(A).

23. **Simulation:** A fixed-seed run produces 1000 observations. **Solution:** The empirical mean approximates, but need not equal, E[X].

24. **Model risk:** A random variable is based on subjective scenario weights. **Solution:** Its calculated distribution inherits the uncertainty of those assumptions.

## 16. Common mistakes and operational controls

| Issue | Consequence | Recommended control |
|---|---|---|
| Confusing outcome with payoff | Incorrect event mapping | Define Ω and X separately |
| Ignoring duplicate payoff values | Incorrect probability mass | Aggregate probability by value |
| Mixing dollars and percentages | Invalid variance and threshold comparisons | Track units explicitly |
| Treating expected payoff as guaranteed | Misleading financial conclusion | Report distribution and downside probability |
| Treating a continuous model as exact reality | False precision | Document discretization and modeling assumptions |
| Missing state mappings | Incomplete distribution | Require mapping coverage |
| Invalid scenario probabilities | Mathematically inconsistent model | Validate bounds and sum |
| Assuming a seed proves correctness | Model risk remains untested | Separate reproducibility from calibration |
