## Project mission

Build an auditable, reproducible **Financial Probability Simulator** using only Python's standard library. This capstone integrates sample spaces, events, discrete random variables, expected value, variance, standard deviation, sampling, default-count distributions, Monte Carlo uncertainty, and reproducible scenario analysis from Sections 14.1–14.15.

This is a teaching and acceptance-lab project, not a production credit or investment risk engine.

## 1. Learning outcomes

By the end of the project, a learner should be able to:

1. Specify a probability model and verify its mathematical consistency.
2. Compute exact expected values and dispersion.
3. Generate reproducible Monte Carlo scenarios with local PRNG state.
4. Estimate losses, empirical quantiles, and simulation standard errors.
5. Compare baseline and stressed scenarios with paired draws.
6. Simulate independent Bernoulli defaults and compare to binomial expectations.
7. Use a simple nonparametric bootstrap to estimate mean uncertainty.
8. Record configuration provenance and reject invalid inputs.
9. Explain statistical assumptions, limitations, and acceptance evidence.
10. Run and review 12 reference unit tests.

## 2. Business use case

A fictional investment committee is evaluating a one-period strategy with three possible net dollar payoffs:

| Scenario | Probability | Net payoff |
|---|---:|---:|
| Bear | .25 | −$20 |
| Base | .50 | +$5 |
| Bull | .25 | +$30 |

The committee wants an exact theoretical baseline and a reproducible Monte Carlo report. A separate illustrative credit desk wants to model defaults across 10 independent, identical loans with probability of default .1.

These are deliberately simplified educational scenarios. Do not treat the inputs as calibrated market or credit forecasts.

### Key design decisions

Use a local `random.Random(seed)` instance for each reproducible experiment. Do not rely on shared global random state. Reject nonfinite outcomes, negative probabilities, probabilities that fail to sum to one, invalid seeds, and insufficient sample sizes.

Use `math.fsum` for finite summation, `statistics.stdev` for sample dispersion, and an explicitly documented empirical quantile convention.

## 4. Exact analytical baseline

The expected payoff is:

**μ=E[X]=.25(−20)+.50(5)+.25(30)=5 dollars.**

The second moment is:

**E[X²]=.25(400)+.50(25)+.25(900)=337.5 dollars².**

Variance:

**Var(X)=337.5−5²=312.5 dollars².**

Standard deviation:

**σ=√312.5≈17.67766953 dollars.**

Only the bear scenario has a negative payoff, so:

**P(X<0)=.25.**

The expected magnitude of the negative payoff, counted as zero in non-loss states, is:

**E[max(−X,0)]=.25(20)=5 dollars.**

This is *not* the conditional expected loss given that a loss occurs; the latter is $20.

## 5. Monte Carlo design

For each run:

1. Fix the model and record the seed.
2. Draw n independent scenarios with replacement using the configured weights.
3. Calculate sample mean and sample standard deviation.
4. Estimate standard error as **s/√n**.
5. Compute empirical 5th and 95th percentiles.
6. Estimate the proportion of negative outcomes.
7. Compare empirical values to exact analytical benchmarks.

Under iid finite-variance sampling, the theoretical standard error of the simulated mean is:

**SE=√312.5/√n.**

At n=10,000 this is approximately **$0.176777**. At n=40,000 it is approximately **$0.088388**.

Increasing the number of draws reduces Monte Carlo noise but does not correct incorrect scenario probabilities.

## 6. Stress testing with common random numbers

Define the stressed payoff as **Y=X+2** for every simulated outcome.

Then:

**E[Y]=7 dollars**, **Var(Y)=312.5 dollars²**.

When comparing stressed and baseline payoffs using the same underlying draws, every paired difference is exactly $2, apart from floating-point rounding. This removes sampling noise from the estimated difference for this specific deterministic transformation.

A real stress test may change probabilities, correlations, tails, or the model structure; a simple additive shock does not capture those effects.

## 7. Independent-loan default model

Let D_i be an independent Bernoulli indicator with p=.1 for each of 10 identical loans.

**N=ΣD_i~Binomial(10,.1).**

Expected defaults:

**E[N]=10(.1)=1.**

Variance:

**Var(N)=10(.1)(.9)=.9.**

No defaults:

**P(N=0)=.9¹⁰≈.34867844.**

At least one default:

**P(N≥1)=1−.9¹⁰≈.65132156.**

This binomial model assumes independent, identically distributed default indicators. Common macroeconomic shocks and borrower heterogeneity can invalidate that assumption.

## 8. Bootstrap uncertainty

The project includes a nonparametric bootstrap of the simulated payoff mean. Each bootstrap repetition samples n observations **with replacement** from the observed Monte Carlo sample.

The standard deviation of the resulting bootstrap means estimates mean-estimator variability under the bootstrap's assumptions.

This adds a second layer of simulation. The bootstrap does not validate the original financial scenario model and should not be mistaken for a remedy for model risk.

The script is self-contained and requires no third-party dependencies. It contains **12 reference unit tests**. Independent runtime execution remains pending.

```python
import hashlib
import json
import math
import random
import statistics
import unittest

PAYOFFS = (-20.0, 5.0, 30.0)
WEIGHTS = (0.25, 0.50, 0.25)

def validate_distribution(outcomes, probabilities):
    xs, ps = list(outcomes), list(probabilities)
    if not xs or len(xs) != len(ps):
        raise ValueError("nonempty matching outcomes/probabilities required")
    if any(type(x) not in (int, float) or not math.isfinite(x) for x in xs):
        raise ValueError("nonfinite payoff")
    if any(type(p) not in (int, float) or not math.isfinite(p) or p < 0 or p > 1 for p in ps):
        raise ValueError("invalid probability")
    if abs(math.fsum(ps) - 1.0) > 1e-12:
        raise ValueError("probabilities must sum to one")
    return xs, ps

def exact_moments(outcomes, probabilities):
    xs, ps = validate_distribution(outcomes, probabilities)
    mu = math.fsum(x*p for x,p in zip(xs,ps))
    var = math.fsum(p*(x-mu)**2 for x,p in zip(xs,ps))
    return mu, var, math.sqrt(var)

def empirical_quantile(values, probability):
    xs = sorted(values)
    if not xs or any(type(x) not in (int,float) or not math.isfinite(x) for x in xs):
        raise ValueError("finite nonempty sample required")
    if type(probability) not in (int,float) or not math.isfinite(probability) or not 0 <= probability <= 1:
        raise ValueError("invalid quantile")
    index = (len(xs)-1)*probability
    low, high = math.floor(index), math.ceil(index)
    return xs[low] + (index-low)*(xs[high]-xs[low])

def simulate(outcomes, probabilities, count, seed):
    xs, ps = validate_distribution(outcomes, probabilities)
    if type(count) is not int or count < 2 or type(seed) is not int:
        raise ValueError("count >= 2 and integer seed required")
    rng = random.Random(seed)
    return rng.choices(xs, weights=ps, k=count)

def summarize(draws):
    xs = list(draws)
    if len(xs) < 2 or any(type(x) not in (int,float) or not math.isfinite(x) for x in xs):
        raise ValueError("at least two finite draws required")
    mu = math.fsum(xs)/len(xs)
    sd = statistics.stdev(xs)
    return {"mean":mu, "sample_sd":sd, "se":sd/math.sqrt(len(xs)),
            "p05":empirical_quantile(xs,.05), "p95":empirical_quantile(xs,.95),
            "loss_probability":math.fsum(x < 0 for x in xs)/len(xs)}

def bootstrap_mean_se(draws, repetitions, seed):
    xs = list(draws)
    summarize(xs)
    if type(repetitions) is not int or repetitions < 2 or type(seed) is not int:
        raise ValueError("invalid bootstrap parameters")
    rng = random.Random(seed)
    means = [math.fsum(rng.choices(xs,k=len(xs)))/len(xs) for _ in range(repetitions)]
    return statistics.stdev(means)

def paired_stress(draws, additive_shock):
    xs = list(draws)
    summarize(xs)
    if type(additive_shock) not in (int,float) or not math.isfinite(additive_shock):
        raise ValueError("invalid shock")
    return [x+additive_shock for x in xs]

def default_count_simulation(loans, pd, trials, seed):
    if type(loans) is not int or loans < 1 or type(trials) is not int or trials < 2 or type(seed) is not int:
        raise ValueError("invalid counts or seed")
    if type(pd) not in (int,float) or not math.isfinite(pd) or not 0 <= pd <= 1:
        raise ValueError("invalid PD")
    rng = random.Random(seed)
    return [sum(rng.random() < pd for _ in range(loans)) for _ in range(trials)]

def manifest(seed, trials, outcomes, probabilities):
    validate_distribution(outcomes, probabilities)
    if type(seed) is not int or type(trials) is not int or trials < 2:
        raise ValueError("invalid run parameters")
    config = {"seed":seed,"trials":trials,"outcomes":list(outcomes),
              "probabilities":list(probabilities),"prng":"random.Random"}
    raw = json.dumps(config,sort_keys=True,separators=(",",":"))
    return {"configuration":config,"sha256":hashlib.sha256(raw.encode()).hexdigest()}

class SimulatorTests(unittest.TestCase):
    def test_01_mean(self): self.assertAlmostEqual(exact_moments(PAYOFFS,WEIGHTS)[0],5)
    def test_02_variance(self): self.assertAlmostEqual(exact_moments(PAYOFFS,WEIGHTS)[1],312.5)
    def test_03_sd(self): self.assertAlmostEqual(exact_moments(PAYOFFS,WEIGHTS)[2],math.sqrt(312.5))
    def test_04_replay(self): self.assertEqual(simulate(PAYOFFS,WEIGHTS,100,42),simulate(PAYOFFS,WEIGHTS,100,42))
    def test_05_count(self): self.assertEqual(len(simulate(PAYOFFS,WEIGHTS,100,42)),100)
    def test_06_quantile(self): self.assertEqual(empirical_quantile([1,2,3,4],.5),2.5)
    def test_07_loss_rate(self): self.assertAlmostEqual(summarize([-1,1,-1,1])["loss_probability"],.5)
    def test_08_se(self): self.assertAlmostEqual(summarize([1,2,3])["se"],1/math.sqrt(3))
    def test_09_bootstrap(self): self.assertEqual(bootstrap_mean_se([4,4,4],10,2),0)
    def test_10_stress(self):
        x=[-20,5,30]
        self.assertEqual(paired_stress(x,2),[-18,7,32])
    def test_11_defaults(self):
        self.assertEqual(default_count_simulation(10,0,20,42),[0]*20)
        self.assertEqual(default_count_simulation(10,1,20,42),[10]*20)
    def test_12_invalid(self):
        for fn in (lambda:exact_moments([1,2],[.4,.7]),
                   lambda:simulate(PAYOFFS,WEIGHTS,1,42),
                   lambda:empirical_quantile([1,2],1.2),
                   lambda:default_count_simulation(10,-.1,20,42),
                   lambda:manifest(42,1,PAYOFFS,WEIGHTS)):
            with self.assertRaises(ValueError): fn()

if __name__ == "__main__":
    suite = unittest.defaultTestLoader.loadTestsFromTestCase(SimulatorTests)
    result = unittest.TextTestRunner(verbosity=2).run(suite)
    if not result.wasSuccessful():
        raise SystemExit(1)
```

## 13. Twenty-four worked exercises

1. **Probability check:** Weights .25,.50,.25. **Solution:** Sum=1.

2. **Scenario expectation:** Payoffs −20,5,30. **Solution:** Expected payoff=$5.

3. **Second moment:** Same scenario distribution. **Solution:** E[X²]=337.5.

4. **Variance:** Same distribution. **Solution:** 312.5 dollars².

5. **Standard deviation:** Same distribution. **Solution:** √312.5≈$17.6777.

6. **Loss probability:** Only payoff −20 is negative. **Solution:** 25%.

7. **Expected shortfall contribution:** −20 loss with probability .25. **Solution:** Expected loss-only amount=$5.

8. **No-loss probability:** Other two scenarios. **Solution:** 75%.

9. **Stress mean:** Add $2 to every payoff. **Solution:** Mean=$7.

10. **Stress variance:** Add $2 to every payoff. **Solution:** Unchanged at 312.5.

11. **Scale mean:** Double each payoff. **Solution:** Mean=$10.

12. **Scale variance:** Double each payoff. **Solution:** 1250.

13. **Bernoulli PD:** Default probability .1. **Solution:** Mean=.1; variance=.09.

14. **Binomial defaults:** n=10,p=.1. **Solution:** Expected defaults=1.

15. **Binomial variance:** n=10,p=.1. **Solution:** Variance=.9.

16. **Zero defaults:** n=10,p=.1. **Solution:** P(X=0)=.9¹⁰≈.348678.

17. **At least one default:** n=10,p=.1. **Solution:** P(X≥1)≈.651322.

18. **Poisson comparison:** λ=1. **Solution:** P(X=0)=e⁻¹≈.367879.

19. **MC error:** σ=√312.5,n=10000. **Solution:** SE≈.176777.

20. **Quadruple trials:** n=10000→40000. **Solution:** SE approximately halves.

21. **Empirical median:** [1,2,3,4]. **Solution:** 2.5 under linear interpolation.

22. **Sample standard error:** [1,2,3]. **Solution:** 1/√3.

23. **Paired stress:** Every payoff shifted +2. **Solution:** Paired difference exactly +2.

24. **Model risk:** Defaults become correlated. **Solution:** Independent-binomial model no longer adequate.

## 17. Troubleshooting and operational runbook

| Symptom | Likely cause | Corrective action |
|---|---|---|
| Probabilities fail validation | Inputs do not sum to one | Correct and document probabilities |
| Mean differs from theoretical value | Finite Monte Carlo sample | Compare deviation with estimated SE |
| Results differ across identical runs | Seed, code, or draw order changed | Compare run manifests |
| Stress difference unexpectedly noisy | Unpaired scenario draws | Reuse baseline draws |
| Bootstrap SE unstable | Too few repetitions or extreme values | Increase repetitions; inspect tails |
| Defaults vary more than binomial model | Dependence or heterogeneous PDs | Revisit model assumptions |
| Simulation runs out of memory | Retaining too many draws | Use streaming statistics and bounded batches |
| Report lacks auditability | Missing provenance | Retain manifest, commit, test logs |
