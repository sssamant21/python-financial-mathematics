## 1. Why conditional probability matters

Financial risks are rarely identical across economic conditions. A borrower may be more likely to default during a recession; a liquidity shortage may become more likely after a funding shock; and a risk alert can be more informative when the base rate of the event is understood.

Conditional probability measures how the probability of an event changes when another event is known to have occurred. It is a mathematical relationship, not proof of causation.

For events A and B with **P(B)>0**:

**P(A|B)=P(A∩B)/P(B).**

Read this as “probability of A given B.”

## 2. The conditioning population

Consider 1,000 hypothetical borrower-period observations:

| Market regime | Survives | Defaults | Total |
|---|---:|---:|---:|
| Normal | 720 | 80 | 800 |
| Stress | 150 | 50 | 200 |
| Total | 870 | 130 | 1,000 |

The table is an illustrative joint distribution, not observed empirical data.

The unconditional probability of default is **130/1000=13%**.

Conditioning on stress changes the denominator to the 200 stressed observations:

**P(default|stress)=50/200=25%.**

Conditioning on normal conditions gives:

**P(default|normal)=80/800=10%.**

The conditioning event determines the reference population.

## 3. Reversing the condition is not valid

From the same table:

**P(stress|default)=50/130≈38.46%.**

This differs from P(default|stress)=25%.

A common analytical mistake is to read “25% of stressed borrowers default” as “25% of defaulters were stressed.” The two questions use different denominators.

## 4. Joint probability and the multiplication rule

Rearrange the conditional probability formula:

**P(A∩B)=P(A|B)P(B).**

For default and stress:

**P(default∩stress)=0.25×0.20=0.05=5%.**

The same intersection can be computed in reverse:

**P(stress∩default)=P(stress|default)P(default).**

**≈(5/13)×0.13=0.05.**

This identity does not require independence.

## 5. Conditional complements

Within the same conditioning event B:

**P(Aᶜ|B)=1−P(A|B)**, provided P(B)>0.

If P(default|stress)=25%, then:

**P(survival|stress)=75%.**

This complement assumes that default and survival are exhaustive, mutually exclusive states for the stated time horizon.

## 6. The law of total probability

Suppose B₁,...,Bₙ partition the sample space. Then:

**P(A)=Σ P(A|Bᵢ)P(Bᵢ).**

For the two market regimes:

**P(default)=P(default|stress)P(stress)+P(default|normal)P(normal).**

**=0.25(0.20)+0.10(0.80)=0.05+0.08=13%.**

This is an important reconciliation check for scenario-weighted credit risk models.

## 7. Bayes' theorem

For P(A)>0:

**P(B|A)=P(A|B)P(B)/P(A).**

In the credit example:

**P(stress|default)=0.25(0.20)/0.13≈38.46%.**

Bayes' theorem is particularly valuable when analysts have a prior probability, a signal or observation, and the probability of that signal under competing outcomes.

## 8. Financial risk signals and the base-rate problem

Suppose only **1%** of borrowers default in the modeled period. A hypothetical alert has:

- **90% sensitivity:** P(flag|default)=0.90.
- **10% false positive rate:** P(flag|survival)=0.10.

The probability that a flagged borrower actually defaults is:

**P(default|flag)=[0.90×0.01]/[0.90×0.01+0.10×0.99].**

**=0.009/0.108≈8.33%.**

Even a reasonably sensitive alert may have a low positive predictive value when the underlying event is rare. A model must not confuse sensitivity with posterior default probability.

## 9. Independence under conditioning

A and B are independent if:

**P(A∩B)=P(A)P(B).**

When P(B)>0, this is equivalent to **P(A|B)=P(A)**.

In our credit example:

**P(default|stress)=25%**, whereas **P(default)=13%**.

Therefore stress and default are not independent under the hypothetical distribution.

Conditional independence is a different property: two events may be independent after conditioning on a third event even when they are not independent unconditionally.

## 10. Edge cases and modeling boundaries

**Zero-probability evidence:** The elementary ratio P(A∩B)/P(B) is undefined if P(B)=0. More advanced continuous probability theory uses conditional distributions and regular conditional probabilities, but those concepts should not be approximated by dividing by zero.

**Model calibration:** A mathematically consistent posterior can still be inaccurate if the prior or likelihood estimates are poorly calibrated.

**Temporal alignment:** Default within 30 days given market stress this week is not the same event as default within one year given an annual stress regime.

**Dependence:** Shared exposures, macroeconomic conditions, and selection bias can change observed conditional relationships.

```python
from math import fsum, isfinite
import unittest

def validated(weights):
    if not weights:
        raise ValueError("empty distribution")
    for p in weights.values():
        if isinstance(p, bool) or not isinstance(p, (int, float)) or not isfinite(p) or not 0 <= p <= 1:
            raise ValueError("invalid probability")
    if abs(fsum(weights.values()) - 1) > 1e-12:
        raise ValueError("probabilities must sum to one")
    return dict(weights)

def prob(weights, outcomes):
    w = validated(weights)
    a = set(outcomes)
    if not a.issubset(w):
        raise ValueError("event outside sample space")
    return fsum(w[x] for x in a)

def conditional(weights, event, given):
    denominator = prob(weights, given)
    if denominator == 0:
        raise ValueError("conditioning event has probability zero")
    return prob(weights, set(event) & set(given)) / denominator

def bayes(prior, sensitivity, false_positive):
    for x in (prior, sensitivity, false_positive):
        if isinstance(x, bool) or not isinstance(x, (int, float)) or not isfinite(x) or not 0 <= x <= 1:
            raise ValueError("invalid probability input")
    evidence = sensitivity * prior + false_positive * (1 - prior)
    if evidence == 0:
        raise ValueError("zero-probability evidence")
    return sensitivity * prior / evidence

def total_probability(regimes):
    if not regimes:
        raise ValueError("empty regimes")
    total_weight = fsum(p for p, _ in regimes)
    if abs(total_weight - 1) > 1e-12:
        raise ValueError("regime weights must sum to one")
    for p, conditional_p in regimes:
        if any(isinstance(x, bool) or not isinstance(x, (int,float)) or not isfinite(x) or not 0 <= x <= 1 for x in (p, conditional_p)):
            raise ValueError("invalid regime probability")
    return fsum(p * conditional_p for p, conditional_p in regimes)

class ConditionalProbabilityTests(unittest.TestCase):
    def setUp(self):
        self.w = {"normal_survive": .72, "normal_default": .08,
                  "stress_survive": .15, "stress_default": .05}
        self.stress = {"stress_survive", "stress_default"}
        self.normal = {"normal_survive", "normal_default"}
        self.default = {"normal_default", "stress_default"}
    def test_01_stress(self):
        self.assertAlmostEqual(prob(self.w, self.stress), .2)
    def test_02_default(self):
        self.assertAlmostEqual(prob(self.w, self.default), .13)
    def test_03_default_given_stress(self):
        self.assertAlmostEqual(conditional(self.w,self.default,self.stress), .25)
    def test_04_default_given_normal(self):
        self.assertAlmostEqual(conditional(self.w,self.default,self.normal), .1)
    def test_05_stress_given_default(self):
        self.assertAlmostEqual(conditional(self.w,self.stress,self.default), .05/.13)
    def test_06_total_probability(self):
        self.assertAlmostEqual(total_probability([(.2,.25),(.8,.1)]),.13)
    def test_07_bayes(self):
        self.assertAlmostEqual(bayes(.13,.25,.15/.87),(.13*.25)/(.13*.25+.87*(.15/.87)))
    def test_08_certain_given_self(self):
        self.assertAlmostEqual(conditional(self.w,self.stress,self.stress),1)
    def test_09_disjoint(self):
        self.assertAlmostEqual(conditional(self.w,self.normal,self.stress),0)
    def test_10_zero_condition(self):
        with self.assertRaises(ValueError): conditional(self.w,self.default,set())
    def test_11_invalid_prior(self):
        with self.assertRaises(ValueError): bayes(1.1,.8,.1)
    def test_12_invalid_weights(self):
        for fn in (lambda:prob({"a":.6,"b":.6},{"a"}),
                   lambda:total_probability([(.5,.2),(.4,.3)]),
                   lambda:bayes(0,0,0)):
            with self.assertRaises(ValueError): fn()

if __name__ == "__main__":
    suite = unittest.defaultTestLoader.loadTestsFromTestCase(ConditionalProbabilityTests)
    result = unittest.TextTestRunner(verbosity=2).run(suite)
    if not result.wasSuccessful():
        raise SystemExit(1)
```

## 12. Twenty-four worked exercises

1. **Definition:** P(A∩B)=.06; P(B)=.20. **Solution:** P(A|B)=.30.

2. **Reverse conditioning:** P(A∩B)=.06; P(A)=.15. **Solution:** P(B|A)=.40.

3. **Credit stress:** P(default∩stress)=.05; P(stress)=.20. **Solution:** P(default|stress)=25%.

4. **Normal regime:** P(default∩normal)=.08; P(normal)=.80. **Solution:** P(default|normal)=10%.

5. **Marginal default:** P(default∩stress)=.05 and P(default∩normal)=.08. **Solution:** P(default)=13%.

6. **Bayes reversal:** P(stress∩default)=.05; P(default)=.13. **Solution:** P(stress|default)=5/13≈38.46%.

7. **Complement conditional:** P(default|stress)=.25. **Solution:** P(survival|stress)=.75.

8. **Joint probability:** P(stress)=.2; P(default|stress)=.25. **Solution:** P(both)=.05.

9. **Total probability:** P(stress)=.2; conditional default rates .25 in stress, .10 in normal. **Solution:** P(default)=.2(.25)+.8(.10)=.13.

10. **Base-rate screening:** P(default)=.01; true positive rate .9; false positive rate .1. **Solution:** P(default|flag)=.009/(.009+.099)=1/12≈8.33%.

11. **No false positives:** P(default)=.01; sensitivity=.9; false positive=0. **Solution:** P(default|flag)=1 if the flag can occur.

12. **Zero evidence:** P(flag)=0. **Solution:** P(default|flag) is undefined via the elementary ratio.

13. **Independent events:** P(A)=.3; P(B)=.4; A and B independent. **Solution:** P(A|B)=.3.

14. **Dependent events:** P(A)=.3; P(B)=.4; P(A∩B)=.2. **Solution:** P(A|B)=.5; not independent.

15. **Mutually exclusive events:** A and B disjoint with P(B)>0. **Solution:** P(A|B)=0.

16. **Conditional sure event:** P(B)>0. **Solution:** P(B|B)=1.

17. **Two regimes:** Stress probability=.1; default rates .4 and .02. **Solution:** P(default)=.1(.4)+.9(.02)=.058.

18. **Bayes for stress:** Using preceding regime model. **Solution:** P(stress|default)=.04/.058≈68.97%.

19. **Diagnostic likelihood:** P(flag|default)=.8. **Solution:** This is sensitivity, not P(default|flag).

20. **False positive rate:** P(flag|survival)=.05. **Solution:** Specificity=95%.

21. **Credit score:** A high-risk score is more common among defaulters. **Solution:** Do not infer positive predictive value without the default base rate.

22. **Time horizon:** Default probabilities for 30 days and 365 days. **Solution:** They are not directly interchangeable.

23. **Regime weighting:** Scenario probabilities .6 and .4; conditional loss .1 and .3. **Solution:** P(loss)=.6(.1)+.4(.3)=.18.

24. **Evidence audit:** Risk model changes the prior default rate. **Solution:** Recompute posterior probabilities even if sensitivity and false positive rates are unchanged.

Use the four-outcome joint distribution:

| Normal, survives | 72% |
| Normal, defaults | 8% |
| Stress, survives | 15% |
| Stress, defaults | 5% |

### Requirements

1. Validate all four probabilities and their total.
2. Compute unconditional default and stress probabilities.
3. Compute default probability conditional on stress and normal conditions.
4. Compute stress probability conditional on default.
5. Reconstruct unconditional default probability using total probability.
6. Calculate the joint stress-and-default probability using both multiplication-rule directions.
7. Test whether stress and default are independent.
8. Add a zero-probability conditioning-event test.

## 14. Troubleshooting and operational runbook

| Symptom | Likely issue | Action |
|---|---|---|
| Conditional rate exceeds 100% | Incorrect numerator/denominator | Validate event intersection and conditioning set |
| P(A|B) confused with P(B|A) | Reversed condition | Recompute with Bayes' theorem |
| Posterior differs from expected | Base rate omitted | Include prior and false-positive rate |
| Division by zero | Conditioning event impossible in model | Report undefined |
| Total-probability mismatch | Missing or overlapping regimes | Verify partition and weights |
| Risk rate shifts after data refresh | Prior, likelihood, or population changed | Version data and reconcile |
| False confidence in alert | Poor calibration or selection bias | Evaluate out-of-sample calibration |

For production analytics, store the source table, observation window, event definitions, sample sizes, model version, and test evidence. Escalate unexplained changes in conditional risk estimates before downstream reporting.
