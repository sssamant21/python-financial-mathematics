## Learning objectives

Construct and validate probability mass functions; compute cumulative and tail probabilities; calculate moments; distinguish Bernoulli, binomial, and count models; implement exact and simulated financial calculations; and recognize model assumptions and limitations.

## 1. What makes a random variable discrete?

A discrete random variable X takes values in a finite or countably infinite set. Financial examples include the number of loan defaults, daily insurance claims, trades executed, or a scenario-based investment payoff.

Its **probability mass function** (PMF) is:

**p_X(x)=P(X=x).**

A valid PMF satisfies **p_X(x)≥0** for every possible value and **Σ_x p_X(x)=1**.

A probability assigned to a particular value is a *mass*, not a density.

## 2. A financial payoff PMF

Consider an investment with three possible net dollar payoffs:

| Payoff x | Probability p_X(x) |
|---:|---:|
| −$20 | 0.25 |
| +$5 | 0.50 |
| +$30 | 0.25 |

The masses are nonnegative and total 1.

The expected payoff is:

**E[X]=Σ_x xp_X(x)=.25(−20)+.50(5)+.25(30)=$5.**

This expected value is a probability-weighted average, not a guaranteed payoff.

## 3. Cumulative distribution function

The cumulative distribution function (CDF) is:

**F_X(t)=P(X≤t)=Σ_{x≤t}p_X(x).**

For the payoff model:

| Threshold t | F_X(t) |
|---|---:|
| t<−20 | 0 |
| −20≤t<5 | 0.25 |
| 5≤t<30 | 0.75 |
| t≥30 | 1 |

Discrete CDFs are nondecreasing, right-continuous step functions.

A strict upper-tail probability is:

**P(X>t)=1−F_X(t).**

For t=5, P(X>5)=.25. For P(X≥5), include the mass at 5, giving .75.

## 4. Expectation and variance

For a discrete X:

**E[X]=Σ_x xp_X(x).**

**Var(X)=Σ_x (x−E[X])²p_X(x).**

The three-state payoff model has:

**Var(X)=.25(−25)²+.50(0)²+.25(25)²=312.5 dollars².**

**SD(X)=√312.5≈$17.6777.**

The variance uses squared payoff units; the standard deviation uses the original units.

## 5. Bernoulli random variables

A Bernoulli variable D equals 1 when an event occurs and 0 otherwise:

**P(D=1)=p, P(D=0)=1−p.**

Then:

**E[D]=p** and **Var(D)=p(1−p)**.

### Worked example A — Default indicator

If a loan has a one-year default probability of 2%, D is Bernoulli(.02).

**E[D]=.02**, **Var(D)=.02(.98)=.0196**.

If the simplified loss on default is $4,000, then L=4000D and **E[L]=$80**.

## 6. Binomial random variables

If X counts successes in n **independent, identically distributed** Bernoulli trials, each with success probability p, then:

**X~Binomial(n,p).**

Its PMF is:

**P(X=k)=C(n,k)p^k(1−p)^(n−k), k=0,...,n.**

Its moments are:

**E[X]=np** and **Var(X)=np(1−p)**.

### Worked example B — Count of defaults

Suppose ten loans have independent, identical one-year default probabilities of 10%.

Then X~Binomial(10,.1).

**E[X]=10(.1)=1 default.**

**Var(X)=10(.1)(.9)=.9 defaults².**

**P(X=0)=(.9)^10≈34.87%.**

This is a teaching model; real loan defaults can be correlated and heterogeneous.

## 7. At-least-one-event calculations

For n independent identical Bernoulli trials:

**P(X≥1)=1−P(X=0)=1−(1−p)^n.**

For five independent trials with p=.2:

**P(X≥1)=1−(.8)^5=1−.32768=.67232=67.232%.**

The complement method is often simpler and less error-prone than adding every positive count probability.

## 8. Other discrete models

The **geometric distribution** can model the number of independent Bernoulli trials until the first success, under a fixed success probability.

The **Poisson distribution** models counts under a particular rate-based assumption:

**P(X=k)=e^(−λ)λ^k/k!, k=0,1,...**

with **E[X]=Var(X)=λ**.

A Poisson model can be useful for illustrative claim or arrival counts, but overdispersion, clustering, seasonality, and changing rates may invalidate it. These distributions receive more systematic treatment later in Chapter 14.

## 9. Joint outcomes and aggregation

A random variable is a function of underlying states. Distinct states can produce the same numeric payoff.

If states A and B have probabilities .2 and .3 and both produce payoff zero, then:

**P(X=0)=.2+.3=.5.**

Do not treat each underlying state as a separate PMF value if the random variable maps them to the same numerical outcome.

## 10. Exact probability versus Monte Carlo

For small discrete distributions, calculate probabilities and moments exactly. Monte Carlo simulation is useful for larger models or complex payoff transformations.

A reproducible simulation records the PMF, seed, sample size, software version, and summary statistics. More trials reduce sampling noise but do not correct an inaccurate PMF.

The Python standard-library implementation validates PMFs, calculates expectation, variance, CDF and tail probabilities, constructs binomial distributions, and samples outcomes with a fixed seed. Use Python 3.8 or later. The first command runs **12 reference unit tests**; the second compiles without running. Weights within 1e−12 of one are normalized. The binomial constructor returns exact fractions; the analysis functions accept these directly and report floats. Float inputs are interpreted through their decimal text for moments. Full-support construction is intended for teaching, and simulation uses float weights, so it does not resolve arbitrarily small tails.

```python
from fractions import Fraction
from math import comb, isfinite, sqrt
from random import Random
import unittest

def _number(x):
    if isinstance(x, bool) or not isinstance(x, (int, float, Fraction)):
        raise ValueError("finite numeric value required")
    if isinstance(x, float) and not isfinite(x):
        raise ValueError("finite numeric value required")
    return Fraction(str(x)) if isinstance(x, float) else Fraction(x)

def _probability(x):
    value = _number(x)
    if not 0 <= value <= 1:
        raise ValueError("probability outside [0,1]")
    return value

def _report(value):
    try:
        result = float(value)
    except OverflowError as exc:
        raise ValueError("result exceeds float range") from exc
    if not isfinite(result) or (result == 0 and value != 0):
        raise ValueError("result outside reportable float range")
    return result

def validate_pmf(pmf):
    if not pmf:
        raise ValueError("PMF must not be empty")
    for x in pmf:
        _number(x)
    d = {x: _probability(p) for x, p in pmf.items()}
    mass = sum(d.values())
    if abs(mass - 1) > Fraction(1, 10**12):
        raise ValueError("probabilities must sum to one within 1e-12")
    return {x: p / mass for x, p in d.items()}

def _mean(d):
    return sum(_number(x) * p for x, p in d.items())

def expectation(pmf):
    return _report(_mean(validate_pmf(pmf)))

def variance(pmf):
    d = validate_pmf(pmf)
    mu = _mean(d)
    return _report(sum(p * (_number(x) - mu)**2 for x, p in d.items() if p))

def cdf(pmf, threshold):
    d = validate_pmf(pmf)
    _number(threshold)
    return _report(sum(p for x, p in d.items() if x <= threshold))

def tail_probability(pmf, threshold):
    d = validate_pmf(pmf)
    _number(threshold)
    return _report(sum(p for x, p in d.items() if x > threshold))

def binomial_pmf(n, p):
    if type(n) is not int or n < 0:
        raise ValueError("n must be nonnegative integer")
    p = _probability(p)
    return {k: comb(n,k) * p**k * (1-p)**(n-k) for k in range(n+1)}

def sample(pmf, count=10000, seed=42):
    d = validate_pmf(pmf)
    if type(count) is not int or count <= 0:
        raise ValueError("count must be positive integer")
    if type(seed) is not int:
        raise ValueError("seed must be integer")
    rng = Random(seed)
    return rng.choices(list(d), weights=[float(p) for p in d.values()], k=count)

class DiscreteRandomVariableTests(unittest.TestCase):
    def setUp(self):
        self.d={-20:.25,5:.5,30:.25}
    def test_01_expectation(self): self.assertAlmostEqual(expectation(self.d),5)
    def test_02_variance(self): self.assertAlmostEqual(variance(self.d),312.5)
    def test_03_sd(self): self.assertAlmostEqual(sqrt(variance(self.d)),sqrt(312.5))
    def test_04_cdf(self): self.assertAlmostEqual(cdf(self.d,5),.75)
    def test_05_lower_cdf(self): self.assertAlmostEqual(cdf(self.d,-21),0)
    def test_06_upper_cdf(self): self.assertAlmostEqual(cdf(self.d,30),1)
    def test_07_tail(self): self.assertAlmostEqual(tail_probability(self.d,5),.25)
    def test_08_bernoulli(self): self.assertAlmostEqual(expectation(binomial_pmf(1,.02)),.02)
    def test_09_binomial_mean(self): self.assertAlmostEqual(expectation(binomial_pmf(10,.1)),1)
    def test_10_binomial_variance(self): self.assertAlmostEqual(variance(binomial_pmf(10,.1)),.9)
    def test_11_seed(self): self.assertEqual(sample(self.d,20,7),sample(self.d,20,7))
    def test_12_invalid(self):
        for f in (lambda:expectation({0:.8,1:.3}),
                  lambda:binomial_pmf(-1,.1),
                  lambda:binomial_pmf(2,1.1),
                  lambda:sample(self.d,0),
                  lambda:cdf(self.d,float("nan"))):
            with self.assertRaises(ValueError): f()

if __name__=="__main__":
    suite=unittest.defaultTestLoader.loadTestsFromTestCase(DiscreteRandomVariableTests)
    result=unittest.TextTestRunner(verbosity=2).run(suite)
    if not result.wasSuccessful(): raise SystemExit(1)
```

## 13. Applied mini-project — Loan default count simulator

A portfolio contains **10 hypothetical independent loans**, each with a one-year default probability of **10%**. Build an auditable default-count analysis.

### Requirements

1. Construct the binomial PMF for k=0,...,10.
2. Verify that the masses sum to one.
3. Calculate E[X] and Var(X).
4. Calculate P(X=0), P(X≥1), and P(X≥2).
5. Simulate 20,000 portfolio years with a fixed seed.
6. Compare simulated mean defaults with the exact value.
7. Re-run with a different seed and discuss sampling variation.
8. Reject invalid n, p, and sample counts.
9. Document the independence and identical-probability assumptions.
10. Propose a dependence stress test that would invalidate the simple binomial model.

### Worked checkpoints

**E[X]=1** and **Var(X)=.9**.

**P(X=0)=.9^10≈.34867844.**

**P(X≥1)=1−.9^10≈.65132156.**

**P(X=1)=10(.1)(.9)^9≈.38742049.**

**P(X≥2)=1−P(X=0)−P(X=1)≈.26390107.**

For the reference runtime, 20,000 draws give mean counts **1.00525** (seed 42) and **0.99995** (seed 43). The theoretical standard error of the sample mean is √(.9/20000) ≈ 0.00671 defaults per year.

For an extreme dependence stress, let all loans default together with probability .1 and otherwise all survive. The marginals remain .1 and the mean remains 1, but the count variance is 9 and P(X=10) rises from 10⁻¹⁰ to .1.

### Acceptance gate

- PMF mass totals one within tolerance.
- Exact moments and event probabilities match the checkpoints.
- The 12 reference unit tests pass when independently executed.
- Simulation is reproducible under a fixed seed.
- Model assumptions, scenario horizon, and data lineage are documented.
- Results are not presented as empirical forecasts without calibration.

## 14. Troubleshooting and production controls

| Symptom | Likely cause | Correction |
|---|---|---|
| PMF totals above or below one | Missing or duplicated outcomes | Validate support and normalization |
| Wrong threshold probability | Confusion between <, ≤, >, ≥ | Check inclusion of boundary mass |
| Incorrect variance | Used mean of squares without subtracting mean² | Apply full variance formula |
| Binomial model underestimates joint defaults | Defaults are dependent | Model common factors or stress dependence |
| Simulated mean changes across runs | Seed not fixed | Record seed and software version |
| Zero-probability outcomes appear in reporting | Invalid sampling or mapping | Validate weights and event mapping |
| Results do not match observed default counts | Model drift or misspecification | Backtest and recalibrate |
