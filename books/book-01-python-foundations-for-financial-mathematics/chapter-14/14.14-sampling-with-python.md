## Learning objectives

Distinguish populations and samples; sample financial scenarios with and without replacement; calculate sample statistics, standard errors, empirical quantiles, bootstrap estimates, and approximate confidence intervals; and implement reproducible Python sampling experiments.

## 1. Financial motivation

Analysts often observe only a finite sample of returns, defaults, claims, or settlement times. Sampling connects probability models to observed or simulated outcomes, but estimates contain sampling error and can be distorted by bias, dependence, stale data, and regime shifts.

A large sample reduces Monte Carlo noise under appropriate conditions; it does not correct an incorrect model.

## 2. Populations, samples, and estimators

The sample mean of n observations is **x̄=(1/n)Σxᵢ**.

The conventional unbiased sample variance estimator under iid sampling with finite variance is **s²=[1/(n−1)]Σ(xᵢ−x̄)²**, n≥2.

For [1,2,3], the sample mean is 2, sample variance is 1, and sample standard deviation is 1. Treating the three values as an entire population gives population variance 2/3.

## 3. Sampling with and without replacement

With replacement, an observation can be drawn repeatedly. Python's **random.choices** samples with replacement and supports relative weights.

Without replacement, each selected record is removed from the pool for that draw. Python's **random.sample** provides this behavior.

A reproducible illustration:

```python
import random
rng = random.Random(42)
states = ["bear", "base", "bull"]
with_replacement = rng.choices(states, weights=[1, 2, 1], k=10)
without_replacement = rng.sample(states, k=2)
```

Relative weights [1,2,1] imply probabilities [.25,.5,.25]. The independence of repeated draws depends on the specified sampling mechanism.

## 4. Scenario-weighted sampling

Consider three investment payoffs: −$20, +$5, +$30 with probabilities .25, .50, .25.

The theoretical mean is **E[X]=.25(−20)+.50(5)+.25(30)=$5**.

Repeated independent draws approximate this distribution. A simulated sample mean need not equal $5 exactly, even with many observations.

## 5. Law of large numbers

Under suitable assumptions, sample averages converge toward the expected value as sample size increases. This convergence is not necessarily monotonic and does not remove data bias, model misspecification, or financial regime risk.

## 6. Standard errors

For iid observations with finite variance σ², the standard deviation of the sample mean is **σ/√n**. Estimate it with **SE(x̄)=s/√n**.

For s=.2 and n=400, **SE=.2/20=.01**.

Quadrupling sample size approximately halves the standard error under the same iid variance assumptions. Autocorrelation and clustered observations require dependence-aware methods.

## 7. Approximate confidence intervals

An approximate large-sample 95% normal confidence interval is:

**x̄±1.96×SE(x̄)**.

For mean=.05, s=.2, n=400:

**.05±1.96(.01)=[.0304,.0696]**.

A frequentist 95% interval procedure has approximately 95% coverage over repeated valid samples. It is not a 95% posterior probability statement about the fixed parameter. Small normal samples with unknown variance commonly use Student t intervals instead.

## 8. Empirical quantiles

Empirical quantiles summarize the observed distribution. Different packages use different interpolation conventions. This lab uses linear interpolation at sorted index **(n−1)p**.

For [1,2,3,4], the interpolated median is 2.5. Tail quantiles generally require larger samples and explicit uncertainty estimates.

## 9. Bootstrap resampling

The nonparametric bootstrap draws n observations with replacement from an original sample of size n, repeatedly recalculating a statistic.

For data [2,4,6], one possible resample [2,2,6] has mean 10/3.

A single resample is not a confidence interval. Hundreds or thousands of resamples can characterize estimator variability under appropriate assumptions.

Ordinary iid bootstrap methods may be invalid for autocorrelated financial returns. Consider block bootstrap or other dependence-aware techniques when needed.

## 10. Stratified and systematic sampling

Stratified sampling partitions a population into meaningful groups, such as borrower grades, and samples within groups. Aggregate with appropriate population weights.

Systematic sampling selects observations at regular intervals after a random start; periodicity in the data may bias results.

When evaluating predictive models, avoid random splits that leak future financial observations into training data. Preserve chronological evaluation where required.

## 11. Historical versus Monte Carlo sampling

Historical sampling draws from observed data; Monte Carlo sampling draws from an assumed distribution. A precise Monte Carlo estimate is precise *for the assumed model*, not necessarily accurate for future real-world outcomes.

Document simulation error and model uncertainty separately.

## 12. Reproducibility and controls

Use a local seeded **random.Random** instance for reproducible educational simulations. It is not cryptographically secure and must not be used for passwords, tokens, or other secrets.

Record the seed, code version, sample size, runtime, assumptions, and data lineage.

The standard-library implementation provides weighted draws, sample means and SDs, standard errors, bootstrap resampling, empirical quantiles, and approximate mean intervals. It includes **12 reference unit tests**. Independent runtime and editorial QA remain pending.

```python
import math
import random
import statistics
import unittest

def weights_ok(weights):
    w=list(weights)
    if not w or any(isinstance(p,bool) or not isinstance(p,(int,float)) or not math.isfinite(p) or p<0 for p in w) or math.fsum(w)<=0:
        raise ValueError("invalid weights")
    return w

def draw(outcomes,weights,n,seed=42):
    xs=list(outcomes)
    w=weights_ok(weights)
    if len(xs)!=len(w) or any(isinstance(x,bool) or not isinstance(x,(int,float)) or not math.isfinite(x) for x in xs):
        raise ValueError("invalid outcomes")
    if isinstance(n,bool) or not isinstance(n,int) or n<1 or isinstance(seed,bool) or not isinstance(seed,int):
        raise ValueError("invalid n or seed")
    return random.Random(seed).choices(xs,weights=w,k=n)

def avg(values):
    xs=list(values)
    if not xs or any(isinstance(x,bool) or not isinstance(x,(int,float)) or not math.isfinite(x) for x in xs):
        raise ValueError("invalid sample")
    return math.fsum(xs)/len(xs)

def sd(values):
    xs=list(values)
    avg(xs)
    if len(xs)<2: raise ValueError("n must be at least 2")
    return statistics.stdev(xs)

def se(values):
    xs=list(values)
    return sd(xs)/math.sqrt(len(xs))

def quantile(values,p):
    xs=sorted(values)
    avg(xs)
    if isinstance(p,bool) or not isinstance(p,(int,float)) or not math.isfinite(p) or not 0<=p<=1:
        raise ValueError("invalid quantile")
    pos=(len(xs)-1)*p
    i,j=math.floor(pos),math.ceil(pos)
    return xs[i]+(pos-i)*(xs[j]-xs[i])

def bootstrap(values,reps,seed=42):
    xs=list(values)
    avg(xs)
    if isinstance(reps,bool) or not isinstance(reps,int) or reps<1 or isinstance(seed,bool) or not isinstance(seed,int):
        raise ValueError("invalid bootstrap arguments")
    rng=random.Random(seed)
    return [avg(rng.choices(xs,k=len(xs))) for _ in range(reps)]

def mean_interval(values,z=1.96):
    xs=list(values)
    if len(xs)<2 or isinstance(z,bool) or not isinstance(z,(int,float)) or not math.isfinite(z) or z<=0:
        raise ValueError("invalid interval arguments")
    margin=z*se(xs)
    return avg(xs)-margin,avg(xs)+margin

class Tests(unittest.TestCase):
    def test_01_mean(self): self.assertEqual(avg([1,2,3]),2)
    def test_02_sd(self): self.assertEqual(sd([1,2,3]),1)
    def test_03_se(self): self.assertAlmostEqual(se([1,2,3]),1/math.sqrt(3))
    def test_04_median(self): self.assertEqual(quantile([1,2,3,4],.5),2.5)
    def test_05_min(self): self.assertEqual(quantile([1,2,3],0),1)
    def test_06_max(self): self.assertEqual(quantile([1,2,3],1),3)
    def test_07_seed(self): self.assertEqual(draw([-1,1],[1,3],100,7),draw([-1,1],[1,3],100,7))
    def test_08_length(self): self.assertEqual(len(draw([0,1],[1,1],50)),50)
    def test_09_bootstrap_seed(self): self.assertEqual(bootstrap([1,2,3],20,7),bootstrap([1,2,3],20,7))
    def test_10_constant(self): self.assertEqual(bootstrap([4,4,4],10),[4]*10)
    def test_11_interval(self):
        a,b=mean_interval([1,2,3])
        self.assertAlmostEqual((a+b)/2,2)
    def test_12_invalid(self):
        for fn in (lambda:draw([1,2],[0,0],10),lambda:draw([1],[1],0),
                   lambda:sd([1]),lambda:bootstrap([1,2],0),
                   lambda:quantile([1,2],1.2)):
            with self.assertRaises(ValueError): fn()

if __name__=="__main__":
    result=unittest.TextTestRunner(verbosity=2).run(unittest.defaultTestLoader.loadTestsFromTestCase(Tests))
    if not result.wasSuccessful(): raise SystemExit(1)
```

## 16. Troubleshooting

| Symptom | Likely cause | Action |
|---|---|---|
| Sample mean differs from expected value | Finite-sample noise | Report SE and sample size |
| Duplicate observations appear | Sampling with replacement | Use random.sample when uniqueness is required |
| Interval is too narrow | Dependence or underestimated variance | Review assumptions |
| Bootstrap results unstable | Few repetitions or rare tail events | Increase repetitions and inspect tail coverage |
| Backtest too accurate | Data leakage or selection bias | Enforce chronological splits |
| Simulation differs between runs | Uncontrolled random state | Use local seeded generator |
| Bias persists at large n | Incorrect model or biased source | Revisit assumptions and data |
