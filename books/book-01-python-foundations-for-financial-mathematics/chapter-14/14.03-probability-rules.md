## 1. Why probability rules matter

Financial risk questions often combine events: a market decline, a borrower default, a liquidity shock, or an insurance claim. Reliable analysis requires rules for combining and comparing probabilities without double-counting outcomes.

A probability model starts with a sample space Ω and events A and B that are subsets of Ω.

## 2. Three probability axioms

The foundational rules are:

1. **Nonnegativity:** P(A) ≥ 0 for every event A.
2. **Normalization:** P(Ω) = 1.
3. **Countable additivity:** For pairwise disjoint events A₁,A₂,..., the probability of their union equals the sum of their probabilities.

In a finite discrete model, assigning nonnegative probabilities to every elementary outcome that sum to one satisfies these axioms.

From these axioms follow P(∅)=0, P(A)≤1, and other useful identities.

## 3. Complement rule

The complement Aᶜ contains outcomes not in A:

**P(Aᶜ) = 1 − P(A).**

### Worked example A — No default

If the probability that a borrower defaults within one year is 4%, the probability of **no default over that same horizon** is:

**1−0.04=0.96=96%.**

The horizon and default definition must match.

## 4. Addition rule for disjoint events

If A and B are mutually exclusive:

**P(A∪B) = P(A)+P(B).**

### Worked example B — Exclusive market states

Suppose P(up)=50%, P(flat)=20%, and P(down)=30%. These states are mutually exclusive.

**P(up or flat)=0.50+0.20=70%.**

Do not apply simple addition to overlapping events.

## 5. General addition rule and inclusion–exclusion

For any two events:

**P(A∪B)=P(A)+P(B)−P(A∩B).**

The intersection term corrects for outcomes counted in both A and B.

### Worked example C — Market and credit stress

Assume P(market stress)=20%, P(default)=13%, and P(both)=5%.

**P(stress or default)=0.20+0.13−0.05=0.28=28%.**

For three events, inclusion–exclusion extends to:

**P(A∪B∪C)=P(A)+P(B)+P(C)−P(A∩B)−P(A∩C)−P(B∩C)+P(A∩B∩C).**

## 6. Monotonicity and useful bounds

If A is a subset of B, then:

**P(A)≤P(B).**

For any A and B:

**max(0,P(A)+P(B)−1) ≤ P(A∩B) ≤ min(P(A),P(B)).**

These are useful consistency checks when scenario estimates come from different sources.

For example, if P(A)=0.8 and P(B)=0.7, their intersection must be at least 0.5. Reporting a 0.1 joint probability would violate basic probability rules.

## 7. Conditional probability

When P(B)>0:

**P(A|B)=P(A∩B)/P(B).**

This measures the probability of A **within the subset of outcomes where B occurs**.

### Worked example D — Default during stress

With P(default and stress)=5% and P(stress)=20%:

**P(default|stress)=0.05/0.20=25%.**

The unconditional probability of default remains 13% in this model.

If P(B)=0, the elementary conditional probability ratio is undefined.

## 8. Multiplication rule

Rearranging conditional probability gives:

**P(A∩B)=P(A|B)P(B).**

Equivalently:

**P(A∩B)=P(B|A)P(A).**

This works without assuming independence.

### Worked example E — Joint event

If a recession has probability 20% and the conditional probability of default during recession is 25%:

**P(recession and default)=0.20×0.25=5%.**

## 9. Independence versus mutual exclusivity

A and B are independent when:

**P(A∩B)=P(A)P(B).**

If market stress and default were independent with probabilities 20% and 13%, their joint probability would be:

**0.20×0.13=2.6%.**

But the scenario model gives 5%, so the events are **dependent**.

Mutually exclusive events with positive probabilities cannot be independent. Their intersection is zero, whereas the product of their probabilities is positive.

## 10. Law of total probability

Suppose B₁,...,Bₙ form a partition of Ω and all conditioning probabilities are defined. Then:

**P(A)=Σ P(A|Bᵢ)P(Bᵢ).**

### Worked example F — Credit risk by market regime

Let P(stress)=20%, P(normal)=80%, P(default|stress)=25%, and P(default|normal)=10%.

**P(default)=0.25(0.20)+0.10(0.80)=0.05+0.08=0.13=13%.**

This reconciles conditional default assumptions to the overall default probability.

## 11. Bayes' rule

For P(A)>0:

**P(B|A)=P(A|B)P(B)/P(A).**

### Worked example G — Probability of stress given default

Using the same scenario:

**P(stress|default)=0.25×0.20/0.13≈38.46%.**

Notice the distinction:

- P(default|stress)=25%.
- P(stress|default)≈38.46%.

These are not interchangeable.

## 12. A complete joint financial model

Consider four mutually exclusive market/borrower outcomes:

| Joint outcome | Probability |
|---|---:|
| Normal, no default | 72% |
| Normal, default | 8% |
| Stress, no default | 15% |
| Stress, default | 5% |

The probabilities sum to 100%.

From this table:

- P(stress)=20%.
- P(default)=13%.
- P(stress and default)=5%.
- P(stress or default)=28%.
- P(default|stress)=25%.
- P(default|normal)=10%.
- P(stress|default)=5/13≈38.46%.

Every calculation can be checked against the same underlying joint distribution.

```python
from math import fsum, isfinite
import unittest

def validate(weights):
    if not weights:
        raise ValueError("empty distribution")
    for p in weights.values():
        if isinstance(p, bool) or not isinstance(p, (int,float)) or not isfinite(p) or not 0 <= p <= 1:
            raise ValueError("probabilities must be finite and between 0 and 1")
    if abs(fsum(weights.values())-1) > 1e-12:
        raise ValueError("probabilities must sum to 1")
    return dict(weights)

def probability(weights, event):
    weights=validate(weights)
    event=set(event)
    if not event.issubset(weights):
        raise ValueError("event outside sample space")
    return fsum(weights[outcome] for outcome in event)

def complement(weights, event):
    weights=validate(weights)
    return probability(weights, set(weights)-set(event))

def union_probability(weights, a, b):
    return probability(weights, set(a)|set(b))

def intersection_probability(weights, a, b):
    return probability(weights, set(a)&set(b))

def conditional_probability(weights, a, given):
    denominator=probability(weights,given)
    if denominator == 0:
        raise ValueError("conditioning event has zero probability")
    return intersection_probability(weights,a,given)/denominator

def independent(weights,a,b,tolerance=1e-12):
    pa=probability(weights,a)
    pb=probability(weights,b)
    pab=intersection_probability(weights,a,b)
    return abs(pab-pa*pb)<=tolerance

class ProbabilityRulesTests(unittest.TestCase):
    def setUp(self):
        self.weights={"normal_ok":.72,"normal_default":.08,
                      "stress_ok":.15,"stress_default":.05}
        self.stress={"stress_ok","stress_default"}
        self.default={"normal_default","stress_default"}
    def test_01_total(self): self.assertAlmostEqual(probability(self.weights,self.weights),1)
    def test_02_empty(self): self.assertEqual(probability(self.weights,[]),0)
    def test_03_complement(self): self.assertAlmostEqual(complement(self.weights,self.stress),.8)
    def test_04_stress(self): self.assertAlmostEqual(probability(self.weights,self.stress),.2)
    def test_05_default(self): self.assertAlmostEqual(probability(self.weights,self.default),.13)
    def test_06_intersection(self): self.assertAlmostEqual(intersection_probability(self.weights,self.stress,self.default),.05)
    def test_07_union(self): self.assertAlmostEqual(union_probability(self.weights,self.stress,self.default),.28)
    def test_08_conditional(self): self.assertAlmostEqual(conditional_probability(self.weights,self.default,self.stress),.25)
    def test_09_dependent(self): self.assertFalse(independent(self.weights,self.stress,self.default))
    def test_10_disjoint_addition(self):
        a={"normal_ok"}
        b={"stress_ok"}
        self.assertAlmostEqual(union_probability(self.weights,a,b),.87)
    def test_11_invalid_weights(self):
        with self.assertRaises(ValueError): probability({"a":.7,"b":.4},{"a"})
    def test_12_invalid_events(self):
        for fn in (lambda:probability(self.weights,{"missing"}),
                   lambda:conditional_probability(self.weights,self.default,set()),
                   lambda:probability({"a":float("nan")},{"a"})):
            with self.assertRaises(ValueError): fn()

if __name__ == "__main__":
    suite=unittest.defaultTestLoader.loadTestsFromTestCase(ProbabilityRulesTests)
    unittest.TextTestRunner(verbosity=2).run(suite)
```

## 14. Twenty-four worked exercises

1. **Probability bound:** An event has probability 1.2. **Answer:** Invalid; probabilities must be in [0,1].

2. **Certain event:** P(Ω)=? **Answer:** 1.

3. **Impossible event:** P(∅)=? **Answer:** 0.

4. **Complement:** P(default)=.04. **Answer:** P(no default)=.96.

5. **Disjoint addition:** P(A)=.2 and P(B)=.3; A,B disjoint. **Answer:** P(A∪B)=.5.

6. **Overlapping union:** P(A)=.4,P(B)=.3,P(A∩B)=.1. **Answer:** P(A∪B)=.6.

7. **Intersection recovery:** P(A∪B)=.7,P(A)=.5,P(B)=.4. **Answer:** P(A∩B)=.2.

8. **Subset monotonicity:** A⊆B. **Answer:** P(A)≤P(B).

9. **At least one event:** P(neither A nor B)=.45. **Answer:** P(A∪B)=.55.

10. **Exactly one:** P(A)=.4,P(B)=.3,P(A∩B)=.1. **Answer:** P(exactly one)=.4+.3−2(.1)=.5.

11. **Both events:** P(A)=.6,P(B)=.5, independent. **Answer:** P(A∩B)=.3.

12. **Independent union:** P(A)=.6,P(B)=.5, independent. **Answer:** P(A∪B)=.6+.5−.3=.8.

13. **Conditional default:** P(default∩stress)=.05, P(stress)=.20. **Answer:** P(default|stress)=.25.

14. **Conditional stress:** P(default∩stress)=.05, P(default)=.13. **Answer:** P(stress|default)=.05/.13≈38.46%.

15. **Dependence check:** P(A)=.2,P(B)=.13,P(A∩B)=.05. **Answer:** Dependent because .05≠.026.

16. **Total probability:** P(stress)=.2, P(default|stress)=.25, P(default|normal)=.1. **Answer:** P(default)=.2(.25)+.8(.1)=.13.

17. **Bayes inversion:** P(default)=.13,P(stress|default)=.05/.13. **Answer:** P(default∩stress)=.05.

18. **Two independent survivals:** P(default A)=.02, P(default B)=.03. **Answer:** P(neither defaults)=.98×.97=.9506.

19. **At least one default:** Same independent loans. **Answer:** 1−.9506=.0494=4.94%.

20. **Three-state distribution:** Weights .5,.2,.3. **Answer:** Valid; sum 1.

21. **Invalid distribution:** Weights .5,.2,.4. **Answer:** Invalid; sum 1.1.

22. **No conditional probability:** P(B)=0. **Answer:** P(A|B) is undefined by elementary ratio formula.

23. **Mutually exclusive vs independent:** P(A)>0,P(B)>0 and A∩B=∅. **Answer:** Not independent because P(A)P(B)>0.

24. **Risk report audit:** Market stress and default overlap. **Answer:** Use inclusion–exclusion; do not sum marginal probabilities without subtracting overlap.

## 16. Common mistakes and troubleshooting

| Mistake | Why it fails | Correction |
|---|---|---|
| Add overlapping event probabilities | Double-counts the intersection | Use inclusion–exclusion |
| Multiply marginal probabilities automatically | Assumes independence without evidence | Use conditional probability |
| Reverse a conditional probability | P(A|B) generally differs from P(B|A) | Apply Bayes' rule |
| Ignore the event horizon | Monthly and annual probabilities differ | State a consistent horizon |
| Condition on a zero-probability event | Denominator is zero | Report undefined under elementary formula |
| Mix model scenarios and observed frequencies | Misrepresents uncertainty | Label estimates and assumptions |
| Accept invalid weights | Violates probability axioms | Validate finite nonnegative weights totaling one |

## 17. Production and SRE considerations

Probability engines should validate input distributions, maintain event definitions as versioned configuration, enforce stable numerical tolerances, capture data lineage, and provide clear error handling. Changes in scenario weights can alter downstream expected-loss estimates; review and document such changes before publishing revised risk metrics.

For real-world risk decisions, test sensitivity to model assumptions, dependence, rare events, and regime changes. Mathematically consistent probabilities are necessary but not sufficient for a well-calibrated financial model.
