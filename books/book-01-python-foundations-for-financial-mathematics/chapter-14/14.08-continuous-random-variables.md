## 1. From discrete states to a continuum

A discrete random variable assigns probability mass to individual values. A **continuous random variable with a probability density function** instead assigns probabilities to intervals by integrating a density.

Financial examples include an idealized asset return, interest rate, or time until a transaction arrives. Market data have finite recording precision, so continuity is a mathematical approximation.

For a variable X with density f_X:

**P(a<X≤b)=∫ₐᵇ f_X(x)dx.**

A valid density satisfies **f_X(x)≥0** and **∫₋∞^∞ f_X(x)dx=1**.

A density is **not** itself a probability. It may exceed one where concentrated over a narrow interval.

## 2. Point probabilities

For a random variable with a density:

**P(X=x)=0** for every fixed real x.

This does not mean the outcome cannot occur. It means probability is assigned to ranges rather than isolated points.

Not every real-valued random variable has a density: mixed distributions can include point masses, and some continuous distributions are singular. The formulas in this section assume a density where stated.

## 3. Cumulative distribution function

For any real-valued random variable:

**F_X(t)=P(X≤t).**

If X has density f_X:

**F_X(t)=∫₋∞ᵗ f_X(x)dx.**

The CDF is nondecreasing, right-continuous, approaches zero toward −∞, and approaches one toward +∞.

For a variable with a density:

**P(a<X≤b)=F_X(b)−F_X(a).**

Endpoint inclusion does not affect interval probabilities in this setting.

## 4. Survival and tail probabilities

The survival function is:

**S_X(t)=P(X>t)=1−F_X(t).**

A financial operations team might use this to estimate the probability that a settlement delay exceeds a service-level threshold. A risk team may use an analogous tail calculation to estimate the probability of a return below a loss threshold.

The event and sign convention matter: **P(R<−0.10)** is a downside tail, whereas **P(R>0.10)** is an upside tail.

## 5. Worked model — Exponential waiting time

Let X be a nonnegative waiting time with exponential distribution of rate λ>0:

**f_X(x)=λe^(−λx)** for x≥0, and zero otherwise.

Its CDF is:

**F_X(x)=1−e^(−λx)** for x≥0.

Its survival function is:

**S_X(x)=e^(−λx)** for x≥0.

For λ=.5 per hour:

**P(X≤1)=1−e^(−.5)≈39.35%.**

**P(X>2)=e^(−1)≈36.79%.**

**P(1<X≤2)=e^(−.5)−e^(−1)≈23.87%.**

The exponential model assumes a constant hazard rate and has a memoryless property. Real financial operations may show time-of-day variation, queues, outages, or clustering that violate these assumptions.

## 6. Expected value and variance

For a continuous random variable with density and existing integrals:

**E[X]=∫₋∞^∞ xf_X(x)dx.**

**Var(X)=∫₋∞^∞ (x−E[X])²f_X(x)dx.**

For an exponential variable:

**E[X]=1/λ**, **Var(X)=1/λ²**, and **SD(X)=1/λ**.

At λ=.5 per hour, mean waiting time is **2 hours**, variance is **4 hours²**, and standard deviation is **2 hours**.

## 7. Quantiles and percentiles

A p-quantile is commonly defined as:

**q_p=inf{x:F_X(x)≥p}.**

For the exponential distribution with 0≤p<1:

**q_p=−ln(1−p)/λ.**

At λ=.5:

- Median q_.5=ln(2)/.5≈1.3863 hours.
- 90th percentile q_.9=−ln(.1)/.5≈4.6052 hours.

A percentile threshold is not an average. The 90th percentile means that 90% of modeled observations are at or below the threshold.

## 8. Uniform distribution

For X uniformly distributed on [a,b], a<b:

**f_X(x)=1/(b−a)** for a≤x≤b.

**E[X]=(a+b)/2** and **Var(X)=(b−a)²/12**.

If X is uniform on [0,10], then:

**P(2≤X≤5)=(5−2)/10=30%.**

Uniform distributions can be useful as transparent baseline assumptions but are rarely adequate as realistic return models.

## 9. Normal and lognormal previews

A normal distribution has support over the entire real line, making it a common introductory model for changes or returns. A lognormal distribution is supported on positive values and is often used for stylized asset-price models.

Neither distribution is universally correct for financial data. Heavy tails, skewness, jumps, volatility clustering, and regime changes can cause large departures from textbook assumptions.

Chapter 14.12 and 14.13 develop common distributions and the normal distribution in more depth.

## 10. Transformations and units

If Y=aX+b with a>0, then:

**F_Y(y)=F_X((y−b)/a).**

For a<0, the inequality reverses and the transformation requires corresponding care.

For waiting times, converting hours to minutes gives Y=60X. The mean changes from 2 hours to 120 minutes; the variance changes from 4 hours² to **14,400 minutes²**.

A density also changes units under scaling. Never compare a density value with a probability without accounting for its measurement unit.

## 11. Numerical stability and reproducibility

Computing **1−e^(−z)** for very small positive z can lose floating-point precision. Python's **math.expm1** helps calculate e^u−1 accurately near zero.

For an exponential quantile near p=0, **math.log1p(−p)** is more stable than log(1−p).

Monte Carlo sampling approximates a theoretical distribution. Record the seed, number of samples, model parameters, and Python version. A fixed seed improves reproducibility but does not validate the distributional assumption.

```python
from math import exp, isfinite, log, sqrt
from random import Random
import unittest

def positive_rate(rate):
    if isinstance(rate,bool) or not isinstance(rate,(int,float)) or not isfinite(rate) or rate<=0:
        raise ValueError("rate must be finite and positive")
    return rate

def exponential_pdf(x,rate):
    positive_rate(rate)
    if not isfinite(x): raise ValueError("x must be finite")
    return rate*exp(-rate*x) if x>=0 else 0.0

def exponential_cdf(x,rate):
    positive_rate(rate)
    if not isfinite(x): raise ValueError("x must be finite")
    return -__import__("math").expm1(-rate*x) if x>=0 else 0.0

def exponential_survival(x,rate):
    positive_rate(rate)
    if not isfinite(x): raise ValueError("x must be finite")
    return exp(-rate*x) if x>=0 else 1.0

def interval_probability(a,b,rate):
    if not isfinite(a) or not isfinite(b) or a>b:
        raise ValueError("invalid interval")
    return exponential_cdf(b,rate)-exponential_cdf(a,rate)

def exponential_quantile(p,rate):
    positive_rate(rate)
    if isinstance(p,bool) or not isinstance(p,(int,float)) or not isfinite(p) or not 0<=p<1:
        raise ValueError("p must lie in [0,1)")
    return -__import__("math").log1p(-p)/rate

def sample_exponential(rate,n=1000,seed=42):
    positive_rate(rate)
    if isinstance(n,bool) or not isinstance(n,int) or n<=0:
        raise ValueError("n must be positive integer")
    if isinstance(seed,bool) or not isinstance(seed,int):
        raise ValueError("seed must be integer")
    rng=Random(seed)
    return [rng.expovariate(rate) for _ in range(n)]

class ContinuousTests(unittest.TestCase):
    def test_01_density_origin(self): self.assertAlmostEqual(exponential_pdf(0,.5),.5)
    def test_02_negative_density(self): self.assertEqual(exponential_pdf(-1,.5),0)
    def test_03_cdf_origin(self): self.assertEqual(exponential_cdf(0,.5),0)
    def test_04_cdf_negative(self): self.assertEqual(exponential_cdf(-1,.5),0)
    def test_05_cdf_one(self): self.assertAlmostEqual(exponential_cdf(1,.5),1-exp(-.5))
    def test_06_survival(self): self.assertAlmostEqual(exponential_survival(2,.5),exp(-1))
    def test_07_interval(self): self.assertAlmostEqual(interval_probability(1,2,.5),exp(-.5)-exp(-1))
    def test_08_quantile(self): self.assertAlmostEqual(exponential_cdf(exponential_quantile(.9,.5),.5),.9)
    def test_09_median(self): self.assertAlmostEqual(exponential_quantile(.5,.5),log(2)/.5)
    def test_10_seed(self): self.assertEqual(sample_exponential(.5,10,9),sample_exponential(.5,10,9))
    def test_11_sample_nonnegative(self): self.assertTrue(all(x>=0 for x in sample_exponential(.5,100)))
    def test_12_invalid(self):
        for fn in (lambda:exponential_pdf(1,0),
                   lambda:exponential_cdf(float("nan"),.5),
                   lambda:interval_probability(2,1,.5),
                   lambda:exponential_quantile(1,.5),
                   lambda:sample_exponential(.5,0)):
            with self.assertRaises(ValueError): fn()

if __name__=="__main__":
    result=unittest.TextTestRunner(verbosity=2).run(
        unittest.defaultTestLoader.loadTestsFromTestCase(ContinuousTests))
    if not result.wasSuccessful(): raise SystemExit(1)
```

## 14. Applied mini-project — Settlement waiting-time risk monitor

A payment operations team uses an illustrative exponential model with **λ=.5 per hour** for settlement waiting time X.

### Requirements

1. Document the model's constant-hazard assumption.
2. Calculate the density at 0 and 1 hour.
3. Calculate P(X≤1), P(X>2), and P(1<X≤2).
4. Calculate mean, variance, and standard deviation.
5. Calculate the median and 90th percentile.
6. Simulate 20,000 waiting times using a fixed seed.
7. Compare the empirical mean and 90th percentile with the theoretical values.
8. Test invalid rates, intervals, quantiles, and sample sizes.
9. Document operational scenarios that violate a constant-rate assumption.
10. Produce an auditable report with units and model version.

Model outputs must be labeled as hypothetical until calibrated against actual settlement observations.

## 15. Common mistakes and operational controls

| Mistake | Why it matters | Correction |
|---|---|---|
| Treating density as probability | A density has units and can exceed one | Integrate over an interval |
| Using P(X=x)>0 for a density model | Confuses mass and density | Use interval probabilities |
| Confusing upper and lower tails | Misstates risk | Write the event inequality first |
| Ignoring time units | Changes rate and quantile interpretation | Record hours, days, or minutes |
| Assuming exponential arrivals everywhere | Ignores nonstationarity and clustering | Backtest hazard assumptions |
| Reporting exact simulation agreement | Sampling is random | Use tolerances and uncertainty intervals |
| Using unstable subtraction | Loses precision for small probabilities | Use expm1/log1p |
| Applying a model beyond its support | Produces impossible scenarios | Validate domain assumptions |
