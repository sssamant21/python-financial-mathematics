## 2. Core probability review

For events A and B:

**P(Aᶜ)=1−P(A)**.

**P(A∪B)=P(A)+P(B)−P(A∩B)**.

When P(B)>0:

**P(A|B)=P(A∩B)/P(B)**.

Events A and B are independent when:

**P(A∩B)=P(A)P(B)**.

Bayes' theorem:

**P(A|B)=P(B|A)P(A)/P(B)**, provided P(B)>0.

### Worked credit-screening example

Suppose default prevalence is 2%, a screening signal detects 90% of defaults, and its false-positive rate among non-defaults is 5%.

Then:

**P(D|positive)=[.9(.02)]/[.9(.02)+.05(.98)]≈.268657**.

The positive predictive probability is about 26.87%, not 90%. This illustrates the importance of base rates.

## 3. Random variables and moments

For a discrete random variable with outcomes xᵢ and probabilities pᵢ:

**E[X]=Σxᵢpᵢ**.

**Var(X)=E[X²]−E[X]²**.

For jointly distributed X and Y:

**Cov(X,Y)=E[(X−E[X])(Y−E[Y])]**.

When variances are positive:

**Corr(X,Y)=Cov(X,Y)/(σ_Xσ_Y)**.

Zero correlation does not generally imply independence. Independence implies zero covariance when the relevant moments exist.

For portfolio weights w₁,w₂:

**Var(w₁X+w₂Y)=w₁²Var(X)+w₂²Var(Y)+2w₁w₂Cov(X,Y)**.

## 4. Distribution review

| Distribution | Support | Mean | Variance | Financial example |
|---|---|---|---|---|
| Bernoulli(p) | 0,1 | p | p(1−p) | Single default |
| Binomial(n,p) | 0,...,n | np | np(1−p) | Independent defaults |
| Geometric(p), trials to success | 1,2,... | 1/p | (1−p)/p² | Trials until event |
| Poisson(λ) | 0,1,... | λ | λ | Claims per period |
| Uniform(a,b) | [a,b] | (a+b)/2 | (b−a)²/12 | Simplified bounded scenario |
| Exponential(λ) | [0,∞) | 1/λ | 1/λ² | Waiting time |
| Normal(μ,σ²) | Real line | μ | σ² | Stylized returns |

Parameter and support assumptions must be stated. For example, the independent-binomial model is generally unsuitable for highly correlated defaults without further modeling.

## 5. Sampling and simulation review

The sample mean is **x̄=Σxᵢ/n**.

For n≥2, sample variance is **s²=Σ(xᵢ−x̄)²/(n−1)**.

For iid finite-variance observations, the estimated standard error of the mean is **s/√n**.

A nonparametric bootstrap repeatedly draws n observations with replacement from a sample of size n. Its results depend on assumptions about the data-generating process.

Fixed PRNG seeds support reproducibility; they do not validate a model or guarantee statistical independence between parallel streams.

## 7. Applied problem A — Credit default counts

A fictional lender holds 10 loans. For the introductory model, each loan defaults independently with probability .1 during a one-year horizon.

### Tasks

1. Define the Bernoulli indicator for each loan.
2. Show that the count of defaults is binomial under the assumptions.
3. Calculate mean and variance.
4. Calculate P(no defaults) and P(at least one default).
5. Simulate 20,000 portfolio years with a recorded seed.
6. Compare simulated counts against exact binomial probabilities.
7. Explain why macroeconomic dependence may invalidate the model.

### Reference answers

**N~Binomial(10,.1)**.

**E[N]=1**.

**Var(N)=.9**.

**P(N=0)=.9^10≈.34867844**.

**P(N≥1)=1−.9^10≈.65132156**.

Using a supplemental loop over ten Bernoulli trials per portfolio year, seed 42 gave 6,960 zero-default years and 7,766 one-default years out of 20,000 (34.80% and 38.83%), with mean 1.0017. This loop is an exercise extension, not implemented by the local lab.

A Poisson approximation with λ=1 has **P(N=0)=e^(−1)≈.36787944**, which is not identical to the binomial result.

## 8. Applied problem B — Financial scenario analysis

Consider a strategy with three hypothetical net dollar payoffs:

| Scenario | Probability | Payoff |
|---|---:|---:|

| Bull | .25 | +$30 |

### Tasks

2. Calculate exact mean, variance, and SD.
3. Calculate the probability of a negative payoff.
4. Generate 1,000 and 20,000 draws with a fixed seed.
5. Compare sample means and standard errors.
6. Estimate empirical 5th and 95th percentiles.
7. Bootstrap the mean with at least 500 resamples.
8. Apply a paired +$2 additive stress.
9. Distinguish simulation uncertainty from model risk.
10. Record a reproducibility manifest.

### Reference answers

**E[X]=$5**.

**E[X²]=337.5 dollars²**.

**Var(X)=312.5 dollars²**.

**SD(X)=√312.5≈$17.67767**.

**P(X<0)=.25**.

**E[X+2]=$7**.

**Var(X+2)=312.5 dollars²**.

Use seed 42 for the two scenario runs. Their means are **$5.475** (1,000 draws) and **$5.07625** (20,000 draws); estimated SEs are **$0.55629** and **$0.12522**. Both samples have 5th and 95th percentiles −$20 and $30. For the bootstrap use the 1,000-draw sample, 500 resamples of size 1,000, and seed 43. For stress, draw the payoffs (−18, 7, 32) using the baseline weights and seed, retaining the paired +$2 difference. Record these settings and the source hash alongside the results.

## 9. Applied problem C — Normal return threshold

Assume a stylized one-period return **R~N(.01,.02²)** and initial portfolio exposure **V=$100,000**.

### Tasks

1. Calculate P(R≤0).
2. Calculate the 5th return percentile.
3. Define loss L=−VR.
4. Calculate the unfloored 95% loss VaR.
5. Explain the implications of heavy tails, skewness, jumps, and changing volatility.

### Reference answers

**P(R≤0)=Φ(−.5)≈.308538**.

**q_.05(R)=.01+.02(−1.6448536)≈−.0228971**, or −2.28971%.

**VaR_.95=100,000[.02(1.6448536)−.01]≈$2,289.71**.

This is a model-implied quantile, not a validated forecast. Normal VaR does not quantify the size of losses beyond the quantile.

The standard-library code checks binomial and Poisson probability masses, normal probabilities, exact discrete moments, quantiles, reproducible scenario draws, and bootstrap behavior. It includes **12 reference unit tests**. Use Python 3.8 or later. The first command runs the tests; the second compiles without executing. Probability totals within 1e−12 of one are normalized, and exact intermediate fractions preserve moment and quantile precision before float output. Sampling remains float based; extreme tails and production-scale performance require separate validation.

```python
from fractions import Fraction
import math
import random
import statistics
import unittest

def _number(x):
    if type(x) not in (int, float):
        raise ValueError("finite numeric value required")
    if isinstance(x, float) and not math.isfinite(x):
        raise ValueError("finite numeric value required")
    return Fraction(str(x)) if isinstance(x, float) else Fraction(x)

def _report(x):
    try:
        result = float(x)
    except OverflowError as exc:
        raise ValueError("result outside float range") from exc
    if not math.isfinite(result) or (result == 0 and x != 0):
        raise ValueError("result outside reportable float range")
    return result

def validate_probability(p):
    p = _number(p)
    if not 0 <= p <= 1:
        raise ValueError("invalid probability")
    return p

def binomial_pmf(k, n, p):
    p = validate_probability(p)
    if type(n) is not int or n < 0 or type(k) is not int or k < 0:
        raise ValueError("invalid count")
    return float(math.comb(n,k)*p**k*(1-p)**(n-k)) if k <= n else 0.0

def poisson_pmf(k, rate):
    r = _number(rate)
    if type(k) is not int or k < 0 or r <= 0:
        raise ValueError("invalid Poisson inputs")
    try:
        r = _report(r)
        log_mass = -r + k*math.log(r) - math.lgamma(k+1)
    except OverflowError as exc:
        raise ValueError("Poisson parameters outside numerical range") from exc
    if not math.isfinite(log_mass) or log_mass > 0:
        raise ValueError("Poisson mass outside numerical range")
    return math.exp(log_mass)

def normal_cdf(x, mu=0.0, sigma=1.0):
    x,mu,sigma = map(_number,(x,mu,sigma))
    if sigma <= 0:
        raise ValueError("invalid normal inputs")
    z = (x-mu)/sigma
    if z <= -40:
        return 0.0
    if z >= 40:
        return 1.0
    return .5*math.erfc(-float(z)/math.sqrt(2))

def _distribution(values, probabilities):
    xs, ps = list(values), list(probabilities)
    if not xs or len(xs) != len(ps):
        raise ValueError("nonempty matching outcomes and probabilities required")
    for x in xs:
        _number(x)
    weights = [validate_probability(p) for p in ps]
    total = sum(weights)
    if abs(total-1) > Fraction(1,10**12):
        raise ValueError("probabilities must sum to one within 1e-12")
    return xs, [p/total for p in weights]

def exact_moments(values, probabilities):
    xs, ps = _distribution(values,probabilities)
    xs = [_number(x) for x in xs]
    mu = sum(x*p for x,p in zip(xs,ps))
    var = sum(p*(x-mu)**2 for x,p in zip(xs,ps))
    return _report(mu), _report(var)

def empirical_quantile(values, p):
    xs = sorted(values)
    p = validate_probability(p)
    if not xs:
        raise ValueError("empty sample")
    for x in xs:
        _number(x)
    pos = (len(xs)-1)*p
    low, high = math.floor(pos), math.ceil(pos)
    alpha = pos-low
    return _report((1-alpha)*_number(xs[low])+alpha*_number(xs[high]))

def sample_scenarios(values, probabilities, n, seed):
    xs, ps = _distribution(values,probabilities)
    if type(n) is not int or n < 2 or type(seed) is not int:
        raise ValueError("invalid sample count or seed")
    return random.Random(seed).choices(xs,weights=[float(p) for p in ps],k=n)

def summarize(values):
    xs = list(values)
    if len(xs) < 2:
        raise ValueError("at least two observations required")
    for x in xs:
        _number(x)
    try:
        mu = _report(statistics.mean(xs))
        sd = _report(statistics.stdev(xs))
    except OverflowError as exc:
        raise ValueError("summary outside float range") from exc
    return mu, sd, sd/math.sqrt(len(xs))

def bootstrap_means(values, repetitions, seed):
    xs = list(values)
    summarize(xs)
    if type(repetitions) is not int or repetitions < 2 or type(seed) is not int:
        raise ValueError("invalid bootstrap parameters")
    rng = random.Random(seed)
    return [_report(statistics.mean(rng.choices(xs,k=len(xs)))) for _ in range(repetitions)]

class ChapterTests(unittest.TestCase):
    def test_01_binomial_zero(self): self.assertAlmostEqual(binomial_pmf(0,10,.1),.9**10)
    def test_02_binomial_one(self): self.assertAlmostEqual(binomial_pmf(1,10,.1),10*.1*.9**9)
    def test_03_binomial_normalization(self): self.assertAlmostEqual(math.fsum(binomial_pmf(k,10,.1) for k in range(11)),1)
    def test_04_poisson(self): self.assertAlmostEqual(poisson_pmf(0,2),math.exp(-2))
    def test_05_normal_center(self): self.assertAlmostEqual(normal_cdf(0),.5)
    def test_06_normal_one(self): self.assertAlmostEqual(normal_cdf(1),.8413447460685429)
    def test_07_mean(self): self.assertEqual(exact_moments([-20,5,30],[.25,.5,.25])[0],5)
    def test_08_variance(self): self.assertEqual(exact_moments([-20,5,30],[.25,.5,.25])[1],312.5)
    def test_09_median(self): self.assertEqual(empirical_quantile([1,2,3,4],.5),2.5)
    def test_10_replay(self): self.assertEqual(sample_scenarios([0,1],[.5,.5],100,42),sample_scenarios([0,1],[.5,.5],100,42))
    def test_11_bootstrap(self): self.assertEqual(bootstrap_means([4,4,4],10,42),[4]*10)
    def test_12_invalid(self):
        for f in (lambda:binomial_pmf(1,10,-.1),
                  lambda:poisson_pmf(0,0),
                  lambda:normal_cdf(0,sigma=0),
                  lambda:exact_moments([1,2],[.2,.2]),
                  lambda:sample_scenarios([0,1],[.5,.5],1,42)):
            with self.assertRaises(ValueError): f()

if __name__=="__main__":
    suite=unittest.defaultTestLoader.loadTestsFromTestCase(ChapterTests)
    result=unittest.TextTestRunner(verbosity=2).run(suite)
    if not result.wasSuccessful():
        raise SystemExit(1)
```

## 12. Troubleshooting and model governance

| Symptom | Likely issue | Required response |
|---|---|---|
| Probabilities do not sum to one | Input or data-quality error | Reject and correct model inputs |
| Default-count variance exceeds binomial estimate | Correlated or heterogeneous defaults | Revisit model structure |
| Monte Carlo results differ | Seed, code, or draw-order drift | Compare manifests |
| Simulated mean differs from exact mean | Sampling noise | Evaluate against estimated SE |
| Normal VaR understates losses | Heavy tails or regime shifts | Backtest and stress test |
| Bootstrap intervals too narrow | Dependence or inappropriate resampling | Use suitable dependence-aware methods |
| Financial results are not auditable | Missing data or run provenance | Retain evidence and reviewer signoff |
