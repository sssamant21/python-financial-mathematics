## 1. Why distribution choice matters

A probability distribution maps possible outcomes to probabilities. Different financial problems have different supports, event mechanisms, and tail behaviors.

A loan-default indicator is binary, a count of defaults is integer-valued, a settlement waiting time is nonnegative, and an idealized continuously compounded return may be modeled on the entire real line.

A convenient distribution is not automatically a calibrated or realistic one. Model choice requires checking assumptions, historical evidence, dependence, and stress behavior.

## 2. Comparison of common distributions

| Distribution | Support | Parameters | Mean | Variance | Example |
|---|---|---|---|---|---|
| Bernoulli | 0,1 | p | p | p(1−p) | One loan default |
| Binomial | 0,...,n | n,p | np | np(1−p) | Defaults in n iid loans |
| Geometric (trial count) | 1,2,... | p | 1/p | (1−p)/p² | Trials until first event |
| Poisson | 0,1,... | λ | λ | λ | Claims count |
| Discrete uniform | n equally likely states | n | Depends on labels | Depends on labels | Simplified scenario selector |
| Continuous uniform | [a,b] | a,b | (a+b)/2 | (b−a)²/12 | Bounded baseline |
| Exponential | [0,∞) | λ | 1/λ | 1/λ² | Waiting time |
| Normal | (−∞,∞) | μ,σ | μ | σ² | Stylized returns |
| Lognormal | (0,∞) | μ,σ for log X | e^(μ+σ²/2) | (e^σ²−1)e^(2μ+σ²) | Stylized prices |

For geometric distributions, parameterization matters: this section counts **trials including the success**, rather than failures before success.

## 3. Bernoulli distribution

A Bernoulli variable D equals 1 when an event occurs and 0 otherwise:

**P(D=1)=p**, **P(D=0)=1−p**.

**E[D]=p** and **Var(D)=p(1−p)**.

### Worked example A — Single default

For p=.02:

**P(D=1)=.02**, **P(D=0)=.98**, **Var(D)=.02(.98)=.0196**.

If loss on default is a fixed $4,000, expected loss is $80.

## 4. Binomial distribution

If X counts successes in n independent, identically distributed Bernoulli trials:

**P(X=k)=C(n,k)p^k(1−p)^(n−k)** for k=0,...,n.

**E[X]=np**, **Var(X)=np(1−p)**.

### Worked example B — Ten loans

For n=10, p=.1:

**P(X=0)=.9^10≈.34867844**.

**P(X=1)=10(.1)(.9)^9≈.38742049**.

**P(X≥1)=1−.9^10≈.65132156**.

Real portfolios often contain heterogeneous probabilities and correlated defaults. A binomial model may be useful pedagogically but inadequate operationally.

## 5. Geometric distribution

Let T count independent Bernoulli trials until the first success, with constant success probability p>0:

**P(T=k)=(1−p)^(k−1)p**, k=1,2,...

**E[T]=1/p**, **Var(T)=(1−p)/p²**.

If p=.2, the expected number of trials until first success is 5.

A changing event probability or dependence between trials violates the simple geometric model.

## 6. Poisson distribution

For a nonnegative integer count X and rate parameter λ>0:

**P(X=k)=e^(−λ)λ^k/k!**.

**E[X]=λ**, **Var(X)=λ**.

### Worked example C — Claims

Suppose a simplified model expects two claims per day, λ=2.

**P(X=0)=e^(−2)≈.135335**.

**P(X=1)=2e^(−2)≈.270671**.

Overdispersion, common shocks, seasonality, or clustering may make a Poisson model unsuitable.

## 7. Uniform distributions

### Discrete uniform

If n distinct outcomes are equally likely, each has probability **1/n**.

For equally likely integer values 1,...,n:

**E[X]=(n+1)/2** and **Var(X)=(n²−1)/12**.

### Continuous uniform

For X uniform on [a,b] with a<b:

**f_X(x)=1/(b−a)** inside the interval, zero outside.

**P(c≤X≤d)=(d−c)/(b−a)** for a≤c≤d≤b.

For X uniform on [0,10]:

**P(2≤X≤5)=3/10=.3**.

Uniform assumptions are transparent but often unrealistic for financial returns.

## 8. Exponential distribution

For waiting time T≥0 with rate λ>0:

**f_T(t)=λe^(−λt)**.

**F_T(t)=1−e^(−λt)** and **P(T>t)=e^(−λt)** for t≥0.

**E[T]=1/λ** and **Var(T)=1/λ²**.

For λ=.5 per hour:

**E[T]=2 hours** and **P(T>2)=e^(−1)≈.367879**.

The constant hazard assumption should be checked against real operational patterns.

## 9. Normal distribution preview

For X~Normal(μ,σ²), σ>0:

**f_X(x)=[1/(σ√(2π))] exp(−(x−μ)²/(2σ²))**.

**E[X]=μ** and **Var(X)=σ²**.

The standardized variable is:

**Z=(X−μ)/σ**.

A standard normal has mean zero and standard deviation one, with:

**P(Z≤0)=.5**.

Normal distributions are symmetric and have relatively light tails compared with many observed financial-return series. Section 14.13 explores normal probability calculations in detail.

## 10. Lognormal distribution preview

X is lognormal when **ln X** follows a normal distribution.

This ensures X>0 and introduces right skew.

A stylized asset price may be modeled lognormally over a fixed horizon under specified assumptions, but actual asset prices may experience jumps, volatility changes, and other deviations.

Do not assume an ordinary simple return is lognormal merely because the associated price is modeled as lognormal.

## 11. Selecting an appropriate distribution

Use these questions before choosing a model:

1. Is the variable binary, a count, a bounded continuous quantity, or an unbounded continuous quantity?
2. Are events independent, identically distributed, or correlated?
3. Is the event rate stable through time?
4. Does the observed variance match the proposed distribution's variance?
5. Are tails, skewness, and zero-inflation adequately represented?
6. Are the units and observation horizon consistent?
7. Does the model remain credible under stress scenarios?

## 12. Numerical methods and reproducibility

Use exact formulas when tractable and simulation when necessary. For rare-event probabilities, floating-point underflow or cancellation can affect direct calculations.

Record the parameterization, input data, seed, sample size, and software version. Reproducibility does not establish calibration or forecast accuracy.

```python
from math import comb, exp, factorial, fsum, isfinite, log, sqrt
from random import Random
import unittest

def probability(p):
    if isinstance(p,bool) or not isinstance(p,(int,float)) or not isfinite(p) or not 0<=p<=1:
        raise ValueError("probability must lie in [0,1]")
    return p

def integer(n,minimum=0):
    if isinstance(n,bool) or not isinstance(n,int) or n<minimum:
        raise ValueError("invalid integer count")
    return n

def positive(x):
    if isinstance(x,bool) or not isinstance(x,(int,float)) or not isfinite(x) or x<=0:
        raise ValueError("positive finite parameter required")
    return x

def bernoulli_pmf(k,p):
    integer(k)
    probability(p)
    return (1-p) if k==0 else (p if k==1 else 0.0)

def binomial_pmf(k,n,p):
    integer(k)
    integer(n)
    probability(p)
    return comb(n,k)*p**k*(1-p)**(n-k) if k<=n else 0.0

def poisson_pmf(k,rate):
    integer(k)
    positive(rate)
    return exp(-rate+k*log(rate)-__import__("math").lgamma(k+1))

def uniform_cdf(x,a,b):
    if any(isinstance(z,bool) or not isinstance(z,(int,float)) or not isfinite(z) for z in (x,a,b)) or a>=b:
        raise ValueError("invalid uniform inputs")
    return max(0.0,min(1.0,(x-a)/(b-a)))

def exponential_cdf(x,rate):
    positive(rate)
    if isinstance(x,bool) or not isinstance(x,(int,float)) or not isfinite(x):
        raise ValueError("invalid observation")
    return 0.0 if x<0 else -__import__("math").expm1(-rate*x)

def normal_cdf(x,mu=0.0,sigma=1.0):
    from math import erf
    positive(sigma)
    if any(isinstance(z,bool) or not isinstance(z,(int,float)) or not isfinite(z) for z in (x,mu)):
        raise ValueError("invalid normal inputs")
    return .5*(1+erf((x-mu)/(sigma*sqrt(2))))

def simulate_defaults(n,p,trials=10000,seed=42):
    integer(n)
    probability(p)
    integer(trials,1)
    integer(seed,0)
    rng=Random(seed)
    return [sum(rng.random()<p for _ in range(n)) for _ in range(trials)]

class DistributionTests(unittest.TestCase):
    def test_01_bernoulli(self): self.assertAlmostEqual(bernoulli_pmf(1,.02),.02)
    def test_02_bernoulli_zero(self): self.assertAlmostEqual(bernoulli_pmf(0,.02),.98)
    def test_03_binomial_zero(self): self.assertAlmostEqual(binomial_pmf(0,10,.1),.9**10)
    def test_04_binomial_one(self): self.assertAlmostEqual(binomial_pmf(1,10,.1),10*.1*.9**9)
    def test_05_binomial_normalization(self): self.assertAlmostEqual(fsum(binomial_pmf(k,10,.1) for k in range(11)),1)
    def test_06_poisson_zero(self): self.assertAlmostEqual(poisson_pmf(0,2),exp(-2))
    def test_07_poisson_one(self): self.assertAlmostEqual(poisson_pmf(1,2),2*exp(-2))
    def test_08_uniform(self): self.assertAlmostEqual(uniform_cdf(5,0,10),.5)
    def test_09_exponential(self): self.assertAlmostEqual(exponential_cdf(1,.5),1-exp(-.5))
    def test_10_normal(self): self.assertAlmostEqual(normal_cdf(0),.5)
    def test_11_seed(self): self.assertEqual(simulate_defaults(4,.1,20,7),simulate_defaults(4,.1,20,7))
    def test_12_invalid(self):
        for fn in (lambda:bernoulli_pmf(1,1.2),
                   lambda:binomial_pmf(0,-1,.1),
                   lambda:poisson_pmf(0,0),
                   lambda:uniform_cdf(1,2,2),
                   lambda:normal_cdf(0,0,0),
                   lambda:simulate_defaults(1,.1,0)):
            with self.assertRaises(ValueError): fn()

if __name__=="__main__":
    result=unittest.TextTestRunner(verbosity=2).run(
        unittest.defaultTestLoader.loadTestsFromTestCase(DistributionTests))
    if not result.wasSuccessful(): raise SystemExit(1)
```

## 16. Troubleshooting and operational controls

| Symptom | Likely cause | Action |
|---|---|---|
| Count probabilities exceed one in total | Formula or normalization error | Reconcile PMF |
| Poisson understates variability | Overdispersion or dependence | Consider alternative count models |
| Binomial default estimates fail in stress | Correlated borrowers | Model common risk factors |
| Negative simulated waiting time | Invalid sampler or units | Validate support |
| Normal model produces impossible values | Wrong support assumption | Use suitable bounded/positive model |
| Tail events occur more often than predicted | Thin-tail model | Stress test and recalibrate |
| Results change across runs | Seed not recorded | Set and document reproducibility inputs |
