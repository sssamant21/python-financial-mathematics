## Learning objectives

Define normal densities and CDFs, standardize z-scores, calculate intervals and tails, interpret percentiles, calculate simplified loss Value at Risk, and implement reproducible Python tests.

## 1. Financial motivation and assumptions

The normal distribution provides a convenient benchmark for stylized returns, measurement errors, and aggregated fluctuations. Actual financial returns may be skewed, heavy-tailed, autocorrelated, or subject to jumps and volatility clustering. Model fit must be checked; a normal assumption is not a factual claim about markets.

## 2. Normal probability density

Write **X~N(μ,σ²)** for mean μ and standard deviation σ>0. Its density is:

**f_X(x)=exp[−(x−μ)²/(2σ²)]/(σ√(2π)).**

Its mean is μ, variance is σ², and support is all real numbers. Since it is continuous, **P(X=x)=0** for each fixed x. The density value is not a point probability.

## 3. Standardization and z-scores

For X~N(μ,σ²), **Z=(X−μ)/σ~N(0,1)**. A z-score counts standard deviations above or below the mean.

**Example:** X~N(10,2²), x=12 gives z=1 and **P(X≤12)=Φ(1)≈.841345**, where Φ is the standard-normal CDF.

## 4. Cumulative and survival functions

**F_X(x)=Φ((x−μ)/σ)**.

**P(X>x)=1−F_X(x)**. Numerically, evaluate the survival function directly for extreme right tails to avoid cancellation when F is close to one.

For Z~N(0,1): **P(Z>1)=P(Z<−1)≈.158655**.

## 5. Interval probabilities

**P(a<X≤b)=F_X(b)−F_X(a)**.

For standard normal Z:

| Interval | Probability |
|---|---:|
| −1<Z<1 | ≈.682689 |
| −2<Z<2 | ≈.95450 |
| −3<Z<3 | ≈.99730 |

The familiar 68–95–99.7 rule is a property of the normal distribution, not of arbitrary asset returns.

## 6. Symmetry

The normal density is symmetric around μ. For standard normal Z, **Φ(−z)=1−Φ(z)**. This simplifies probability calculations but is a potentially unrealistic assumption for asymmetric financial risks.

## 7. Normal quantiles

For 0<p<1, the p-quantile is **q_p=μ+σΦ⁻¹(p)**.

| Percentile | Standard-normal quantile |
|---|---:|
| 1% | −2.32635 |
| 5% | −1.64485 |
| 50% | 0 |
| 95% | +1.64485 |
| 99% | +2.32635 |

A quantile is a modeled threshold, not a guaranteed observed outcome.

## 8. Financial return threshold example

Assume a hypothetical one-day return **R~N(.001,.02²)**.

For a −3% return, **z=(−.03−.001)/.02=−1.55**. Hence **P(R≤−.03)=Φ(−1.55)≈.0606**, or approximately 6.06% under this model. This is not an empirically calibrated forecast.

## 9. Simplified normal loss Value at Risk

Define portfolio loss **L=−VR** for fixed exposure V>0 and one-period return R~N(μ_R,σ_R²). Positive L represents a loss.

Then **L~N(−Vμ_R,V²σ_R²)** and the *unfloored* loss quantile at confidence α is:

**VaR_α=V[σ_RΦ⁻¹(α)−μ_R].**

For V=$100,000, μ_R=.01, σ_R=.02 and α=.95:

**VaR_.95≈100,000[.02(1.6448536)−.01]=$2,289.71.**

The model-implied probability of loss exceeding this threshold is 5%. VaR does not quantify the severity of losses beyond the threshold; some reporting conventions also floor VaR at zero.

## 10. Transformations and aggregation

For X~N(μ,σ²), **aX+b~N(aμ+b,a²σ²)** when a≠0.

If X and Y are independent normal variables, their sum is normal with mean **μ_X+μ_Y** and variance **σ_X²+σ_Y²**.

For jointly normal correlated variables, the sum remains normal and its variance includes **2Cov(X,Y)**. Normal marginal distributions alone do not guarantee a normally distributed sum.

## 11. Central limit theorem caveats

Under suitable assumptions, standardized averages of many observations may approach a normal distribution. This does not imply individual returns are normal or that dependence, infinite variance, or small samples can be ignored.

## 12. Numerical stability and governance

Python's **math.erfc** supports stable CDF and survival calculations. The reference quantile solver uses bisection on μ±12σ for ordinary probabilities; it is not a production-grade extreme-tail solver. For production risk engines, use validated numerical libraries, tail backtests, and model governance.

```python
from math import erfc, exp, isfinite, pi, sqrt
from random import Random
import unittest

def check(mu,sigma):
    if any(isinstance(v,bool) or not isinstance(v,(int,float)) or not isfinite(v) for v in (mu,sigma)) or sigma<=0:
        raise ValueError("invalid normal parameters")

def pdf(x,mu=0,sigma=1):
    check(mu,sigma)
    if not isfinite(x): raise ValueError("invalid x")
    z=(x-mu)/sigma
    return exp(-z*z/2)/(sigma*sqrt(2*pi))

def cdf(x,mu=0,sigma=1):
    check(mu,sigma)
    if not isfinite(x): raise ValueError("invalid x")
    return .5*erfc(-(x-mu)/(sigma*sqrt(2)))

def survival(x,mu=0,sigma=1):
    check(mu,sigma)
    if not isfinite(x): raise ValueError("invalid x")
    return .5*erfc((x-mu)/(sigma*sqrt(2)))

def interval(a,b,mu=0,sigma=1):
    if not isfinite(a) or not isfinite(b) or a>b: raise ValueError("invalid interval")
    return cdf(b,mu,sigma)-cdf(a,mu,sigma)

def quantile(p,mu=0,sigma=1):
    check(mu,sigma)
    if isinstance(p,bool) or not isinstance(p,(int,float)) or not isfinite(p) or not 0<p<1:
        raise ValueError("invalid probability")
    lo,hi=mu-12*sigma,mu+12*sigma
    for _ in range(100):
        mid=(lo+hi)/2
        if cdf(mid,mu,sigma)<p: lo=mid
        else: hi=mid
    return (lo+hi)/2

def loss_var(mu,sigma,confidence,exposure):
    check(mu,sigma)
    if isinstance(exposure,bool) or not isinstance(exposure,(int,float)) or not isfinite(exposure) or exposure<0:
        raise ValueError("invalid exposure")
    return exposure*(sigma*quantile(confidence)-mu)

def simulate(n,mu=0,sigma=1,seed=42):
    check(mu,sigma)
    if isinstance(n,bool) or not isinstance(n,int) or n<=0 or isinstance(seed,bool) or not isinstance(seed,int):
        raise ValueError("invalid simulation inputs")
    rng=Random(seed)
    return [rng.gauss(mu,sigma) for _ in range(n)]

class Tests(unittest.TestCase):
    def test_01_pdf(self): self.assertAlmostEqual(pdf(0),1/sqrt(2*pi))
    def test_02_cdf(self): self.assertAlmostEqual(cdf(0),.5)
    def test_03_survival(self): self.assertAlmostEqual(survival(0),.5)
    def test_04_one(self): self.assertAlmostEqual(cdf(1),.8413447460685429)
    def test_05_left(self): self.assertAlmostEqual(cdf(-1),.15865525393145707)
    def test_06_right(self): self.assertAlmostEqual(survival(1),.15865525393145707)
    def test_07_interval(self): self.assertAlmostEqual(interval(-1,1),.6826894921370859)
    def test_08_median(self): self.assertAlmostEqual(quantile(.5),0)
    def test_09_percentile(self): self.assertAlmostEqual(quantile(.95),1.6448536269514722,places=6)
    def test_10_var(self): self.assertAlmostEqual(loss_var(.01,.02,.95,100000),2289.707253902944,places=5)
    def test_11_seed(self): self.assertEqual(simulate(10,seed=7),simulate(10,seed=7))
    def test_12_invalid(self):
        for fn in (lambda:pdf(0,0,0),lambda:cdf(float("nan")),
                   lambda:interval(2,1),lambda:quantile(1),
                   lambda:loss_var(0,.2,.95,-1),lambda:simulate(0)):
            with self.assertRaises(ValueError): fn()

if __name__=="__main__":
    r=unittest.TextTestRunner(verbosity=2).run(unittest.defaultTestLoader.loadTestsFromTestCase(Tests))
    if not r.wasSuccessful(): raise SystemExit(1)
```

7. **Within two SD:** −2<Z<2. **Solution:** P≈.95450.

8. **Within three SD:** −3<Z<3. **Solution:** P≈.99730.

11. **Nonstandard tail:** X~N(10,2²). **Solution:** P(X>12)≈.158655.

12. **Nonstandard interval:** X~N(10,2²). **Solution:** P(8<X<12)≈.682689.

13. **Median:** X~N(10,2²). **Solution:** 10.

14. **Mean and variance:** X~N(10,2²). **Solution:** mean=10, variance=4.

15. **95th percentile:** Standard normal. **Solution:** 1.644854.

16. **5th percentile:** Standard normal. **Solution:** −1.644854.

17. **Symmetry:** Normal mean μ. **Solution:** P(X<μ−a)=P(X>μ+a).

18. **Affine transform:** X~N(10,2²), Y=3X+1. **Solution:** Y~N(31,6²).

19. **Independent sum:** X~N(0,1),Y~N(0,4) independent. **Solution:** X+Y~N(0,5).

20. **Loss quantile:** R~N(.01,.02²), V=$100,000. **Solution:** 95% loss VaR≈$2,289.71.

21. **Negative VaR:** Positive mean much greater than volatility. **Solution:** Unfloored loss quantile may be negative.

22. **Point probability:** X continuous normal. **Solution:** P(X=μ)=0.

23. **Heavy tails:** Daily returns exhibit jumps. **Solution:** Normal VaR can underestimate extreme losses.

24. **Changing volatility:** Returns show clustering. **Solution:** Constant-σ normal assumption needs review.

## 16. Troubleshooting and production controls

| Symptom | Cause | Action |
|---|---|---|
| Wrong z-score | Divided by variance instead of SD | Divide by σ |
| Negative SD | Invalid parameter | Reject σ≤0 |
| Right tail rounds to zero | CDF subtraction cancellation | Use survival function |
| VaR sign appears reversed | Confused return and loss | Define L=−VR |
| More extreme losses than predicted | Heavy tails or volatility shifts | Stress test and recalibrate |
| Different simulation results | Seed or sample count changed | Record both |
| Correlated returns aggregated incorrectly | Ignored covariance | Include covariance terms |
