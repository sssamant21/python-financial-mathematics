## Learning objectives

Design a visualization boundary that consumes reviewed data, show units and timing without changing financial meaning, build a small price-series plot, manage optional plotting dependencies and figure ownership, and distinguish automated plot checks from visual and financial review.

## 1. Purpose and scope

A visualization helps a reader inspect a financial result; it does not validate the underlying model or data. The plotting layer should make the instrument, price definition, currency, timestamps and limitations visible. It should consume data that has already passed the relevant source, point-in-time and financial checks. A chart can look plausible while displaying stale, revised, misaligned or incorrect data.

This section adds an educational line chart for a **single synthetic price series**. It does not load market data, establish data provenance, calculate returns, adjust corporate actions, perform FX conversion, choose an investment or produce a production dashboard. Section 21.13's pair validator checks a narrow record contract; the plotting function below accepts plain sequences and does not automatically invoke it. Callers must perform the appropriate validation before plotting.

## 2. Chart contract and design

| Concern | Teaching decision |
|---|---|
| Timeline | At least two strictly increasing timezone-aware timestamps, displayed using UTC tick labels. |
| Values | Equal-length finite positive built-in floats, interpreted as one consistent price series. |
| Labels | Nonblank trimmed instrument and price-basis labels; three uppercase ASCII letters as a currency label. |
| Financial meaning | No conversion, adjustment, resampling, filling, smoothing or interpolation of input values is performed. The line visually connects observations. |
| Presentation | Title identifies instrument and price basis; axes identify UTC time and price currency. Points are marked and a grid is shown. |
| Ownership | Return a Matplotlib figure and axes to the caller; the caller decides whether to show, save and close them. |
| Limit | At most 10,000 observations; this is an educational resource limit, not a performance guarantee. |

A line segment is a visual connection, not proof of observed prices between timestamps. A continuous axis may hide missing observations; apply a separately specified calendar and gap policy before plotting. Do not relabel a raw price as adjusted, claim total return from price alone, or mix currencies. The currency format check does not establish ISO membership. The function does not establish whether timestamps were available at a decision time or whether records share a valid source and price basis.

Charts may omit zero from a price axis to show variation, but should make the scale clear; a truncated axis can visually exaggerate a change. Label units, time zone, return convention and transformations. Use accessible colors and markers, avoid implying precision beyond the data, and inspect the actual output. Consider an accompanying data table and source/as-of details for decisions.

## 4. Reference implementation

In the Section 21.3 teaching project, apply the capstone package updates through Section 21.13. Create `src/financial_toolkit/visualization.py`:

```python
"""Educational single-series price visualization."""
from datetime import datetime, timezone
import math

MAX_PLOT_POINTS = 10_000


def _valid_label(value: object) -> bool:
    return type(value) is str and bool(value) and value == value.strip()


def plot_price_series(times: list[datetime] | tuple[datetime, ...],
                      prices: list[float] | tuple[float, ...],
                      instrument: str, currency: str, price_basis: str):
    """Return (figure, axes) for a labeled, already-reviewed price series.

    Require 2–10000 increasing aware datetimes and equal-length positive finite
    built-in float prices. Labels must satisfy the documented contract.
    This does not validate source, availability, currency membership, price
    basis or financial suitability. It does not show, save or close a figure.
    Missing Matplotlib raises ImportError; invalid inputs raise ValueError.
    """
    if type(times) not in (list, tuple) or type(prices) not in (list, tuple):
        raise ValueError("times and prices must be lists or tuples")
    if not 2 <= len(times) <= MAX_PLOT_POINTS or len(times) != len(prices):
        raise ValueError("series must have equal length from 2 to 10000")
    if any(type(t) is not datetime or t.tzinfo is None or t.utcoffset() is None
           for t in times):
        raise ValueError("timestamps must be timezone-aware datetimes")
    # Normalize to UTC for ordering and plotting; do not mutate caller inputs.
    utc_times = [t.astimezone(timezone.utc) for t in times]
    if any(a >= b for a, b in zip(utc_times, utc_times[1:])):
        raise ValueError("timestamps must be strictly increasing instants")
    if any(type(p) is not float or not math.isfinite(p) or p <= 0.0
           for p in prices):
        raise ValueError("prices must be positive finite floats")
    if not _valid_label(instrument) or not _valid_label(price_basis):
        raise ValueError("instrument and price basis must be nonblank trimmed labels")
    if (type(currency) is not str or len(currency) != 3
            or any(ch < "A" or ch > "Z" for ch in currency)):
        raise ValueError("currency must be three uppercase ASCII letters")

    import matplotlib.dates as mdates
    import matplotlib.pyplot as plt

    fig, ax = plt.subplots()
    ax.plot(utc_times, prices, marker="o", label=instrument)
    ax.set_title(f"{instrument} — {price_basis} price")
    ax.set_xlabel("Observation time (UTC)")
    ax.set_ylabel(f"Price ({currency})")
    ax.xaxis.set_major_formatter(mdates.DateFormatter("%Y-%m-%d %H:%M", tz=timezone.utc))
    ax.grid(True, alpha=0.3)
    fig.autofmt_xdate()
    fig.tight_layout()
    return fig, ax
```

UTC conversion occurs only after the caller provides aware datetimes; it does not resolve incorrectly assigned or ambiguous local times. The function checks strictly increasing instants after conversion, rejecting duplicates even if different offsets describe the same instant. It keeps the caller's sequences unchanged. The code is embedded in this manuscript; no separate installed package or chart file is created by publication.

## 5. Example use and lifecycle

```python
from datetime import datetime, timezone
import matplotlib.pyplot as plt
from financial_toolkit import plot_price_series

utc = timezone.utc
times = [datetime(2025, 1, 2, 16, tzinfo=utc),
         datetime(2025, 1, 3, 16, tzinfo=utc)]
prices = [100.0, 110.0]  # synthetic price observations
fig, ax = plot_price_series(times, prices, "EXAMPLE", "USD", "Unadjusted")
try:
    fig.savefig("synthetic_price.png", dpi=150)
finally:
    plt.close(fig)
```

The output filename is illustrative and is relative to the process's working directory. The user chooses and protects the destination. The `finally` block closes the figure even if saving fails. In an interactive workflow, a caller may instead display the figure and close it when finished. This example does not claim a file has been generated or visually reviewed during publication.

## 6. Twelve Python reference tests

Save as `tests/test_visualization.py` in the teaching project. These reference definitions have **not** been run for publication. Install an approved Matplotlib in the test environment first. `MPLBACKEND=Agg` must be set before the test process starts; the tests create and close figures without opening a window. They inspect chart structure, not visual appearance or data truth.

```python
from datetime import datetime, timedelta, timezone
import unittest
import matplotlib.dates as mdates
import matplotlib.pyplot as plt
from financial_toolkit import plot_price_series

UTC = timezone.utc
T1 = datetime(2025, 1, 2, 16, tzinfo=UTC)
T2 = datetime(2025, 1, 3, 16, tzinfo=UTC)


class VisualizationTests(unittest.TestCase):
    def make_plot(self, times=None, prices=None, instrument="EXAMPLE",
                  currency="USD", basis="Unadjusted"):
        if times is None:
            times = [T1, T2]
        if prices is None:
            prices = [100.0, 110.0]
        fig, ax = plot_price_series(times, prices, instrument, currency, basis)
        self.addCleanup(plt.close, fig)
        return fig, ax

    def test_labels(self):
        _, ax = self.make_plot()
        self.assertEqual(ax.get_title(), "EXAMPLE — Unadjusted price")
        self.assertEqual(ax.get_xlabel(), "Observation time (UTC)")
        self.assertEqual(ax.get_ylabel(), "Price (USD)")
    def test_values_and_marker(self):
        _, ax = self.make_plot()
        line = ax.lines[0]
        self.assertEqual(list(line.get_ydata()), [100.0, 110.0])
        self.assertEqual(line.get_marker(), "o")
    def test_timestamps(self):
        _, ax = self.make_plot()
        actual = mdates.date2num(ax.lines[0].get_xdata())
        expected = mdates.date2num([T1, T2])
        for a, b in zip(actual, expected):
            self.assertAlmostEqual(a, b, places=10)
    def test_different_offsets_order_by_instant(self):
        offset = timezone(timedelta(hours=2))
        _, ax = self.make_plot(times=[T1.astimezone(offset), T2])
        self.assertEqual(len(ax.lines[0].get_ydata()), 2)
    def test_input_not_mutated(self):
        times, prices = [T1, T2], [100.0, 110.0]
        self.make_plot(times, prices)
        self.assertEqual(times, [T1, T2])
        self.assertEqual(prices, [100.0, 110.0])
    def test_bad_lengths(self):
        with self.assertRaises(ValueError):
            plot_price_series([T1], [100.0], "X", "USD", "Raw")
    def test_mismatched_lengths(self):
        with self.assertRaises(ValueError):
            plot_price_series([T1, T2], [100.0], "X", "USD", "Raw")
    def test_naive_time(self):
        with self.assertRaises(ValueError):
            plot_price_series([datetime(2025, 1, 2), T2], [1.0, 2.0], "X", "USD", "Raw")
    def test_duplicate_instant(self):
        same = T1.astimezone(timezone(timedelta(hours=2)))
        with self.assertRaises(ValueError):
            plot_price_series([T1, same], [1.0, 2.0], "X", "USD", "Raw")
    def test_invalid_prices(self):
        for bad in (0.0, -1.0, 1, True, float("nan")):
            with self.subTest(bad=bad):
                with self.assertRaises(ValueError):
                    plot_price_series([T1, T2], [1.0, bad], "X", "USD", "Raw")
    def test_invalid_labels(self):
        for instrument, currency, basis in ((" ", "USD", "Raw"),
                                             ("X", "usd", "Raw"),
                                             ("X", "USD", "")):
            with self.subTest(instrument=instrument, currency=currency, basis=basis):
                with self.assertRaises(ValueError):
                    plot_price_series([T1, T2], [1.0, 2.0], instrument, currency, basis)
    def test_too_many_points(self):
        times = [T1 + timedelta(seconds=i) for i in range(10001)]
        with self.assertRaises(ValueError):
            plot_price_series(times, [1.0] * len(times), "X", "USD", "Raw")


if __name__ == "__main__":
    unittest.main(verbosity=2)
```

## 9. Troubleshooting

| Symptom | Possible cause | Next step |
|---|---|---|
| `ImportError` when plotting | Matplotlib is absent in the selected environment | Install an approved version and record the dependency |
| `ValueError` | Invalid labels, times, prices or lengths | Check the documented contract and sanitized input |
| A GUI window appears during automation | Backend was not configured before Python started | Set an appropriate headless backend before running tests |
| Labels overlap or are unreadable | Figure size, formatting or data density | Inspect the saved figure and revise presentation for its intended size |
| Chart looks valid but data is wrong | Source, timing or price basis was not properly reviewed | Reconcile provenance and financial semantics separately |
