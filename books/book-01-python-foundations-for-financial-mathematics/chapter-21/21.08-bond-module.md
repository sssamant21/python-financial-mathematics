## Learning objectives

Construct periodic coupon-bond cash flows, discount them using a stated per-period yield, distinguish coupon rate from yield and price, apply known-value and financial-property checks, and identify the scope and numerical limits of the capstone implementation.

## 1. Scope and conventions

This educational module prices an idealized fixed-coupon bond **on a coupon date immediately after any payment due that day**. It assumes a positive face amount, a constant coupon amount paid at each period end, redemption of face at maturity, and one constant effective yield per period. The coupon rate supplied to the function is a decimal **per coupon period**; coupon amount equals face multiplied by that periodic rate. A zero coupon is allowed. No cash flow is received at time zero.

All amounts are in the same currency and units. The returned value is the total present value for the supplied face amount, not automatically a price per 100 face. The module does not use actual dates, calendars, day counts, accrued interest, clean/dirty price adjustments, fees, taxes, default or recovery, liquidity, inflation, callable features, reinvestment, FX or a term structure. It does not solve for yield, duration or convexity. These exclusions matter for real instruments. The code is an educational draft, not a production pricing system.

## 2. Coupon cash flows and valuation

For face $`F>0`$, periodic coupon rate $`c\ge0`$, effective periodic yield $`y>-1`$, and integer number of remaining periods $`n\ge1`$, the coupon is $`C=Fc`$. The simplified price on the specified coupon date is

```math
P=\sum_{t=1}^{n}\frac{C}{(1+y)^t}+\frac{F}{(1+y)^n}.
```

For face 100, periodic coupon rate 5%, periodic yield 5%, and two remaining periods, the flows are `[0, 5, 105]` and the price is 100 in exact arithmetic. With the same face and yield but zero coupon, the price is $`100/1.05^2\approx90.70294785`$. For a one-period bond with coupon 5 and yield 10%, price is $`105/1.1\approx95.45454545`$.

The coupon rate, yield and payment frequency must use consistent periods. A bond with a 6% **annual coupon rate** paid semiannually has a 3% coupon per half-year under the conventional simple allocation of the annual coupon. A 6% **effective annual yield** corresponds instead to $`(1.06)^{1/2}-1`$, approximately 2.9563% effective per half-year. Other quoting conventions exist; this function does not convert rates. For positive future cash flows, price falls as the yield increases, holding all other inputs and the timeline fixed. That relationship alone does not establish a market value or investment suitability.

## 3. Interface and numerical contract

| Item | Teaching policy |
|---|---|
| Face | Positive, finite built-in `float`. |
| Coupon rate | Finite built-in `float` between 0 and 1 inclusive, per coupon period. |
| Yield | Finite built-in `float` strictly greater than −1, effective per coupon period. |
| Periods | Built-in `int` from 1 to 1,000 inclusive; Boolean is rejected. |
| Result | Unrounded finite `float` in face units for the supplied face amount. |
| Failure | Invalid input or nonfinite cash flow, discounted intermediate or total raises `ValueError`. |

The 1,000-period limit matches Section 21.6's maximum 1,001-element schedule including time zero; it is an educational resource bound, not a promise of accuracy or performance. The cash-flow module calls Section 21.5's repeated-period discounting function for each entry, leading to quadratic work as the schedule grows. Float rounding, cancellation and underflow remain possible; a finite result need not be accurate enough for a particular use. Extreme input values can overflow or produce nonfinite intermediate values, which are rejected.

There is no automatic currency or decimal rounding policy. A price formatted to two places is merely displayed that way. Validate financial conventions and ranges independently before adopting any result.

## 4. Reference implementation

In the Section 21.3 teaching project, first apply the Section 21.5 time-value, 21.6 cash-flow and 21.7 loan updates. Create `src/financial_toolkit/bonds.py`:

```python
"""Educational periodic fixed-coupon bond valuation."""
import math
from .cashflows import net_present_value

MAX_BOND_PERIODS = 1_000


def fixed_coupon_bond_price(face: float, coupon_rate: float,
                            yield_rate: float, periods: int) -> float:
    """Return unrounded present value for a simplified fixed-coupon bond.

    The valuation is on a coupon date after the current coupon is paid.
    Coupon rate and effective yield are per period; all future coupons and
    redemption occur at period ends. No accrued interest or dates are modeled.
    Invalid inputs or nonfinite intermediate values raise ValueError.
    Floating-point rounding and underflow remain possible.
    """
    if type(face) is not float or not math.isfinite(face) or face <= 0.0:
        raise ValueError("face must be a positive finite float")
    if (type(coupon_rate) is not float or not math.isfinite(coupon_rate)
            or not 0.0 <= coupon_rate <= 1.0):
        raise ValueError("coupon rate must be a finite float between 0 and 1")
    if (type(yield_rate) is not float or not math.isfinite(yield_rate)
            or yield_rate <= -1.0):
        raise ValueError("yield must be a finite float greater than -1")
    if type(periods) is not int or not 1 <= periods <= MAX_BOND_PERIODS:
        raise ValueError("periods must be an integer from 1 to 1000")

    coupon = face * coupon_rate
    redemption = face + coupon
    if not math.isfinite(coupon) or not math.isfinite(redemption):
        raise ValueError("nonfinite bond cash flow")
    flows = [0.0] + [coupon] * (periods - 1) + [redemption]
    return net_present_value(flows, yield_rate)
```

The maturity flow contains both the final coupon and the principal; it must not be counted twice. The schedule has `periods + 1` entries including time zero. Negative yields greater than −1 are accepted by this mathematical contract, though an accepted input is not necessarily appropriate for a particular bond. The function rejects integer and Boolean inputs rather than silently converting them. This code is supplied within the manuscript; it does not itself create a separately installed package.

## 5. Worked example and integration

```python
from financial_toolkit import fixed_coupon_bond_price, net_present_value

price = fixed_coupon_bond_price(100.0, 0.05, 0.05, 2)
check = net_present_value([0.0, 5.0, 105.0], 0.05)
print(f"Bond value: {price:.6f} amount units")
print(f"Cash-flow value: {check:.6f} amount units")
```

Both calculations should be approximately 100 for the specified conventions. This integration check confirms agreement of the interfaces but is **not independent**, because the bond function calls the same cash-flow function. Derive the par and zero-coupon benchmarks separately, and use tolerances in amount units. Test and review extreme yields, underflow, overflow, schedule limits and the actual application domain before release.

A bond priced at par here has its per-period coupon rate equal to the effective yield under this simplified model. A positive coupon bond is generally below par when its yield exceeds its coupon rate and above par when its yield is lower, with the other assumptions fixed. This is a mathematical relationship for these modeled cash flows, not a guarantee of a traded price.

## 6. Twelve Python reference tests

Save as `tests/test_bonds.py` in the teaching project after applying the preceding capstone module updates. These test definitions have **not** been executed for publication. Tolerances are illustrative in face-amount units.

```python
import math
import unittest
from financial_toolkit import fixed_coupon_bond_price, net_present_value


class BondTests(unittest.TestCase):
    def test_par_bond(self):
        self.assertTrue(math.isclose(fixed_coupon_bond_price(100.0, 0.05, 0.05, 2),
                                     100.0, rel_tol=0.0, abs_tol=1e-10))
    def test_zero_coupon(self):
        self.assertTrue(math.isclose(fixed_coupon_bond_price(100.0, 0.0, 0.05, 2),
                                     90.70294784580499, rel_tol=0.0, abs_tol=1e-10))
    def test_one_period(self):
        self.assertTrue(math.isclose(fixed_coupon_bond_price(100.0, 0.05, 0.10, 1),
                                     105.0 / 1.1, rel_tol=0.0, abs_tol=1e-10))
    def test_zero_yield(self):
        self.assertEqual(fixed_coupon_bond_price(100.0, 0.05, 0.0, 2), 110.0)
    def test_negative_yield(self):
        self.assertTrue(math.isclose(fixed_coupon_bond_price(95.0, 0.0, -0.05, 1),
                                     100.0, rel_tol=0.0, abs_tol=1e-10))
    def test_yield_monotonicity(self):
        self.assertGreater(fixed_coupon_bond_price(100.0, 0.05, 0.03, 2),
                           fixed_coupon_bond_price(100.0, 0.05, 0.07, 2))
    def test_face_scaling(self):
        self.assertTrue(math.isclose(fixed_coupon_bond_price(200.0, 0.05, 0.06, 2),
                                     2 * fixed_coupon_bond_price(100.0, 0.05, 0.06, 2),
                                     rel_tol=1e-12, abs_tol=1e-10))
    def test_cashflow_integration(self):
        self.assertEqual(fixed_coupon_bond_price(100.0, 0.05, 0.05, 2),
                         net_present_value([0.0, 5.0, 105.0], 0.05))
    def test_invalid_face(self):
        for face in (0.0, -1.0, 100, float("nan")):
            with self.subTest(face=face):
                with self.assertRaises(ValueError):
                    fixed_coupon_bond_price(face, 0.05, 0.05, 2)
    def test_invalid_coupon_and_yield(self):
        for coupon, yld in ((-0.01, 0.05), (1.01, 0.05), (True, 0.05),
                            (0.05, -1.0), (0.05, float("inf"))):
            with self.subTest(coupon=coupon, yld=yld):
                with self.assertRaises(ValueError):
                    fixed_coupon_bond_price(100.0, coupon, yld, 2)
    def test_invalid_periods(self):
        for periods in (0, 1001, True, 2.0):
            with self.subTest(periods=periods):
                with self.assertRaises(ValueError):
                    fixed_coupon_bond_price(100.0, 0.05, 0.05, periods)
    def test_cashflow_overflow(self):
        with self.assertRaises(ValueError):
            fixed_coupon_bond_price(1e308, 1.0, 0.05, 1)


if __name__ == "__main__":
    unittest.main(verbosity=2)
```

## 8. Forty worked exercises

1. **Face:** What is the redemption amount in this model? **Answer:** The supplied face amount at maturity.
2. **Coupon:** Face 100 and per-period coupon rate 5% give what coupon? **Answer:** 5 per period.
3. **Timeline:** What flows arise for a two-period bond with those inputs? **Answer:** `[0.0, 5.0, 105.0]`.
4. **Time zero:** Is a current coupon included? **Answer:** No; valuation is immediately after the current coupon is paid.
5. **Par:** Price with face 100, coupon 5% and yield 5% for two periods? **Answer:** 100 in exact arithmetic.
6. **Zero coupon:** Price of face 100 at 5% for two periods? **Answer:** Approximately 90.70294785.
7. **One period:** Price of face 100, coupon 5%, yield 10%? **Answer:** Approximately 95.45454545.
8. **Zero yield:** Price of face 100 with two coupons of 5? **Answer:** 110.
9. **Negative yield:** PV of 95 due in one period at −5%? **Answer:** 100 in exact arithmetic.
10. **Yield boundary:** Why reject −1? **Answer:** The discount denominator is zero.
11. **Rate units:** How is 5% represented? **Answer:** As `0.05`.
12. **Coupon frequency:** How is a 6% annual coupon usually allocated across two equal semiannual coupons? **Answer:** 3% of face each half-year under that convention.
13. **Yield conversion:** What is the half-year effective rate equivalent to 6% effective annually? **Answer:** $`(1.06)^{1/2}-1`$, about 2.9563%.
14. **Yield versus coupon:** Are they necessarily the same? **Answer:** No; coupon determines payments while yield determines discounting.
15. **Yield increase:** What happens to the modeled price when yield rises? **Answer:** It falls for these positive future flows, all else equal.
16. **Above par:** What is the relationship when coupon exceeds yield in this simplified setting? **Answer:** Price exceeds face.
17. **Below par:** What is the relationship when yield exceeds coupon? **Answer:** Price is below face.
18. **Scaling:** What happens when face doubles with rates and term fixed? **Answer:** Price doubles in exact arithmetic.
19. **Price units:** Is the result automatically quoted per 100 face? **Answer:** No; it values the supplied face amount.
20. **Maturity:** Does the final flow include the last coupon? **Answer:** Yes, together with face.
21. **Accrued:** Does this module compute accrued interest? **Answer:** No.
22. **Dates:** Does it use a day-count convention? **Answer:** No.
23. **Credit:** Does it model default or recovery? **Answer:** No.
24. **Callability:** Does it model early redemption? **Answer:** No.
25. **Term structure:** Does it use different rates for each period? **Answer:** No; one constant yield is used.
26. **Yield solver:** Does it calculate yield from a price? **Answer:** No.
27. **Duration:** Does it calculate duration? **Answer:** No.
28. **Face domain:** Is zero face accepted? **Answer:** No; face must be positive.
29. **Coupon domain:** Is a negative coupon rate accepted? **Answer:** No, under this teaching contract.
30. **Integer face:** Is `100` accepted? **Answer:** No; use a built-in float such as `100.0`.
31. **Boolean periods:** Is `True` accepted? **Answer:** No.
32. **Maximum:** What is the maximum number of periods? **Answer:** 1,000.
33. **Schedule size:** How many elements does a 1,000-period bond require? **Answer:** 1,001 including time zero.
34. **Overflow:** What if face plus final coupon is nonfinite? **Answer:** The function raises `ValueError`.
35. **Underflow:** Does a finite price guarantee all contributions were preserved? **Answer:** No.
36. **Performance:** Why is the reference method quadratic in the number of periods? **Answer:** The underlying module repeatedly discounts each successive cash flow period by period.
37. **Rounding:** Does the function round to cents? **Answer:** No; display formatting is separate.
