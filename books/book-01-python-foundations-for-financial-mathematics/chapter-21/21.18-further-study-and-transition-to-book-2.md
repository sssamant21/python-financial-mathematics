## 2. Why continue to mathematical foundations?

Python expresses a model and performs calculations, but understanding its assumptions requires mathematical reasoning. Algebra clarifies constraints and rearrangements; functions describe relationships; limits and derivatives explain local change; integration handles accumulation; linear algebra organizes portfolios and systems; optimization describes constrained choices; numerical methods explain approximations and their limits. Mathematical validity, implementation correctness and suitability for a financial decision are related but distinct questions.

For a certain one-period payment \(C\) and effective per-period rate \(r>-1\), Book 1 used

\[
PV=\frac{C}{1+r}.
\]

Book 2 can extend the reasoning: identify the domain, interpret the function, derive sensitivity with respect to the rate, and examine assumptions. For fixed \(C>0\), \(dPV/dr=-C/(1+r)^2<0\). This supports the conclusion that PV decreases as the rate rises **within this model**, holding the payment and period fixed. It does not establish that the payment is truly certain or the chosen discount rate is appropriate.

## 5. Review the integrated case

Section 21.17's synthetic case calculates price returns of 10% and −5% from two pairs of prices. With beginning weights 0.6 and 0.4, the exact one-period weighted price return is 4%. Its unweighted cross-sectional mean of the two asset returns is 2.5%; that is neither the portfolio return nor a time-series volatility estimate. A separate toy simulation has an analytical mean of 100, but a finite random sample need not have that mean.

To validate the case, independently derive the expected values, confirm time and sign conventions, inspect source and availability assumptions, test data and module boundaries, assess numerical error and review the suitability of each model. A reproducible seeded result is useful evidence of behavior in a specified environment; it is not proof of financial accuracy or future performance. Visualizations require separate data review and actual visual inspection.

## 6. Twelve Python reference checks

Save as `book1_transition_checks.py` in an isolated directory. This self-contained educational script checks mathematical examples; it does **not** import or verify the capstone package, create an evidence record, or establish a model approval. The definitions have not been executed for publication.

```python
import math
import unittest
from decimal import Decimal, ROUND_HALF_EVEN


class TransitionChecks(unittest.TestCase):
    def test_present_value(self):
        self.assertTrue(math.isclose(110.0 / 1.1, 100.0,
                                     rel_tol=0.0, abs_tol=1e-10))
    def test_future_value(self):
        self.assertTrue(math.isclose(100.0 * 1.1**2, 121.0,
                                     rel_tol=0.0, abs_tol=1e-10))
    def test_npv(self):
        self.assertTrue(math.isclose(-100.0 + 110.0 / 1.1, 0.0,
                                     rel_tol=0.0, abs_tol=1e-10))
    def test_price_return(self):
        self.assertTrue(math.isclose(110.0 / 100.0 - 1.0, 0.1,
                                     rel_tol=0.0, abs_tol=1e-12))
    def test_linked_return(self):
        self.assertTrue(math.isclose(1.1 * 0.9 - 1.0, -0.01,
                                     rel_tol=0.0, abs_tol=1e-12))
    def test_portfolio_return(self):
        self.assertTrue(math.isclose(0.6 * 0.1 + 0.4 * (-0.05), 0.04,
                                     rel_tol=0.0, abs_tol=1e-12))
    def test_cross_section_mean(self):
        self.assertTrue(math.isclose((0.1 - 0.05) / 2.0, 0.025,
                                     rel_tol=0.0, abs_tol=1e-12))
    def test_sample_variance(self):
        mean = 0.025
        variance = ((0.1 - mean)**2 + (-0.05 - mean)**2) / 1
        self.assertTrue(math.isclose(variance, 0.01125,
                                     rel_tol=0.0, abs_tol=1e-12))
    def test_bond_par(self):
        value = 5.0 / 1.05 + 105.0 / (1.05**2)
        self.assertTrue(math.isclose(value, 100.0, rel_tol=0.0, abs_tol=1e-10))
    def test_simulation_model_expectation(self):
        self.assertEqual(0.5 * 110.0 + 0.5 * 90.0, 100.0)
    def test_decimal_rounding_example(self):
        self.assertEqual(Decimal("0.015").quantize(Decimal("0.01"),
                                                  rounding=ROUND_HALF_EVEN),
                         Decimal("0.02"))
    def test_pv_rate_sensitivity_sign(self):
        derivative = -110.0 / (1.1**2)
        self.assertLess(derivative, 0.0)


if __name__ == "__main__":
    unittest.main(verbosity=2)
```
