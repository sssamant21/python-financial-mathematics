## Learning objectives

Define convex sets, convex functions, strict and strong convexity; apply Jensen's inequality and Hessian criteria; distinguish convexity from merely having a local minimum; and interpret convexity in financial calibration and portfolio variance.

## 1. Convex sets

A set \(C\subseteq\mathbb R^n\) is **convex** if, for every \(x,y\in C\) and \(0\le\lambda\le1\),

\[
\boxed{\lambda x+(1-\lambda)y\in C}.
\]

Thus every line segment joining two points in the set stays inside it. Examples include \(\mathbb R^n\), intervals, affine subspaces, half-spaces, Euclidean balls, and intersections of convex sets. The set \(\{x\in\mathbb R:x^2\ge1\}\) is not convex because \(-1\) and \(1\) belong to it but their midpoint does not.

A long-only portfolio simplex

\[
\{w\in\mathbb R^n:w_i\ge0,\ \sum_iw_i=1\}
\]

is convex. It is a **constrained** feasible region, even though convexity remains useful in analyzing its optimization problem.

## 2. Convex functions

A function \(f:C\to\mathbb R\), defined on a convex set \(C\), is convex if

\[
\boxed{f(\lambda x+(1-\lambda)y)\le
\lambda f(x)+(1-\lambda)f(y)}
\]

for all \(x,y\in C\) and \(\lambda\in[0,1]\). Its graph lies at or below the straight chord connecting two graph points.

A **strictly convex** function has a strict inequality whenever \(x\ne y\) and \(0<\lambda<1\). A **concave** function is one whose negative is convex. A strictly convex function has at most one global minimizer on a convex domain, provided a minimizer exists.

## 3. First-order characterization

If \(f\) is differentiable and convex on an open convex domain,

\[
\boxed{f(y)\ge f(x)+\nabla f(x)^\mathsf T(y-x)}.
\]

Every tangent hyperplane underestimates the function globally. Consequently, any stationary point \(\nabla f(x^*)=0\) is a global minimizer.

For a differentiable concave function, the inequality reverses; a stationary point is a global maximizer.

## 4. Hessian criterion

If \(f\) is twice continuously differentiable on an open convex domain, then \(f\) is convex **if and only if** its Hessian is positive semidefinite everywhere on that domain:

\[
\boxed{d^\mathsf TH_f(x)d\ge0\quad\text{for all }x,d}.
\]

A positive definite Hessian everywhere implies strict convexity. The converse is false: \(f(x)=x^4\) is strictly convex on \(\mathbb R\), but \(f''(0)=0\).

A twice differentiable function is **\(m\)-strongly convex** when

\[
H_f(x)\succeq mI,\qquad m>0,
\]

throughout its convex domain. This gives a uniform positive curvature lower bound and, when a minimizer exists, uniqueness and useful error bounds.

## 5. Convexity versus second-order point classification

Section 16.3 examined the Hessian **at a stationary point** to classify local behavior. Convexity is a **global property over a domain**. A positive definite Hessian at one point does not establish global convexity. For example,

\[
f(x)=x^2-x^4
\]

has \(f''(0)=2>0\), so zero is a strict local minimum, but \(f''(x)=2-12x^2\) becomes negative for sufficiently large \(|x|\); the function is not convex on \(\mathbb R\).

## 6. Financial calibration: weighted least squares

For a linear model \(A\theta\), observations \(b\), and a symmetric positive semidefinite weighting matrix \(W\),

\[
L(\theta)=\tfrac12(A\theta-b)^\mathsf TW(A\theta-b)
\]

has gradient and Hessian

\[
\nabla L=A^\mathsf TW(A\theta-b),\qquad
\boxed{H_L=A^\mathsf TWA\succeq0}.
\]

Therefore \(L\) is convex. It is strictly convex if \(A^\mathsf TWA\) is positive definite, for example if \(W\) is positive definite and \(A\) has full column rank. Nonlinear pricing residuals generally do **not** inherit this guarantee.

## 7. Portfolio variance

Let \(\Sigma\) be a symmetric positive semidefinite covariance matrix. Portfolio variance is

\[
\boxed{q(w)=w^\mathsf T\Sigma w}.
\]

Its derivatives are

\[
\nabla q(w)=2\Sigma w,\qquad H_q=2\Sigma\succeq0.
\]

Hence variance is convex in portfolio weights. If \(\Sigma\) is positive definite, the variance objective is strictly convex. The unconstrained global minimizer of \(q(w)\) is \(w=0\) when \(\Sigma\) is positive definite, which is typically **not a feasible invested portfolio**; budget and allocation restrictions belong in a constrained optimization formulation.

Use the reference covariance matrix

\[
\Sigma=\begin{bmatrix}0.04&0.01\\0.01&0.09\end{bmatrix}.
\]

Its leading principal minor is \(0.04>0\) and determinant \(0.0035>0\), so it is positive definite. At \(w=(0.6,0.4)\), variance is \(0.0336\).

## 8. Jensen's inequality and finance interpretation

For a convex \(f\) and a random variable \(X\) with suitable integrability,

\[
\boxed{f(\mathbb E[X])\le\mathbb E[f(X)]}.
\]

For \(f(x)=x^2\), this becomes \((\mathbb E[X])^2\le\mathbb E[X^2]\), equivalent to nonnegative variance. Jensen's inequality is useful in understanding convex payoff exposure and risk, but it does not by itself establish the price of a derivative; pricing also requires a valid model and measure.

## 9. Operations and numerical cautions

Convexity does not imply an optimizer is automatically found by a particular algorithm or that a solution exists on an unbounded domain. For example, \(e^x\) is strictly convex on \(\mathbb R\) but has no attained global minimum. Poor conditioning, scaling, stopping tolerances, and inaccurate gradients can still affect numerical results for convex objectives.

## 11. Twenty worked exercises

**1.** Define a convex set.  
*Answer:* It contains every convex combination of any two of its points.

**2.** Is the interval \([0,1]\) convex?  
*Answer:* Yes.

**3.** Is \((-\infty,-1]\cup[1,\infty)\) convex?  
*Answer:* No.

**4.** Is an affine subspace convex?  
*Answer:* Yes.

**5.** Is the long-only fully invested portfolio simplex convex?  
*Answer:* Yes.

**6.** State the convex-function inequality.  
*Answer:* \(f(\lambda x+(1-\lambda)y)\le\lambda f(x)+(1-\lambda)f(y)\).

**7.** Is \(x^2\) convex?  
*Answer:* Yes, strictly and strongly convex on \(\mathbb R\).

**8.** Is \(-x^2\) convex?  
*Answer:* No; it is strictly concave.

**9.** Is \(x^4\) strictly convex?  
*Answer:* Yes, on \(\mathbb R\).

**10.** Is \(x^4\) strongly convex on all of \(\mathbb R\)?  
*Answer:* No; its second derivative vanishes at zero.

**11.** State the differentiable supporting-hyperplane inequality.  
*Answer:* \(f(y)\ge f(x)+\nabla f(x)^\mathsf T(y-x)\).

**12.** State the Hessian test for convexity.  
*Answer:* \(H_f(x)\succeq0\) everywhere on an open convex domain.

**13.** Does a positive definite Hessian at one point prove global convexity?  
*Answer:* No.

**14.** What is the Hessian of \(\tfrac12\|A\theta-b\|^2\)?  
*Answer:* \(A^\mathsf TA\).

**15.** What makes weighted linear least squares convex?  
*Answer:* Its Hessian \(A^\mathsf TWA\) is positive semidefinite for \(W\succeq0\).

**16.** Find the gradient of \(w^\mathsf T\Sigma w\) for symmetric \(\Sigma\).  
*Answer:* \(2\Sigma w\).

**17.** Find its Hessian.  
*Answer:* \(2\Sigma\).

**18.** Evaluate variance at \(w=(0.6,0.4)\) for the reference matrix.  
*Answer:* \(0.0336\).

**19.** State Jensen's inequality.  
*Answer:* \(f(\mathbb E[X])\le\mathbb E[f(X)]\) for convex \(f\) under suitable assumptions.

**20.** What comes next?  
*Answer:* 16.5 — Gradient Descent.
