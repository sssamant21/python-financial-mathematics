## Learning objectives

Classify stationary points with second derivatives and Hessians; distinguish positive/negative definiteness, semidefiniteness, and indefiniteness; apply the two-variable determinant test; explain inconclusive cases; and interpret curvature in financial calibration and risk objectives.

## 1. Why first-order conditions are not enough

For a differentiable objective \(f\), an interior local optimum must satisfy \(\nabla f(x^*)=0\). But a stationary point can be a minimum, maximum, saddle, or neither. If \(f\) is twice continuously differentiable near \(x^*\), its local behavior is described by

\[
f(x^*+h)=f(x^*)+\tfrac12h^\mathsf TH_f(x^*)h+o(\|h\|^2),
\]

because the first-order term vanishes at stationarity. The quadratic form \(h^\mathsf TH_fh\) measures local curvature along the displacement \(h\).

## 2. One-dimensional second-derivative test

For a twice continuously differentiable scalar function with \(f'(x^*)=0\):

- If \(f''(x^*)>0\), the point is a **strict local minimum**.
- If \(f''(x^*)<0\), the point is a **strict local maximum**.
- If \(f''(x^*)=0\), the test is **inconclusive**.

For example, \(f(x)=x^2\) has a strict minimum at zero, \(g(x)=-x^2\) has a strict maximum, and \(h(x)=x^3\) is stationary at zero but not an extremum. Both \(x^4\) and \(-x^4\) have zero second derivative at zero, yet have a strict minimum and maximum respectively.

## 3. Hessian definiteness

For a symmetric Hessian \(H\):

| Curvature | Condition for every nonzero \(d\) | Stationary-point conclusion |
|---|---|---|
| Positive definite | \(d^\mathsf THd>0\) | Strict local minimum |
| Negative definite | \(d^\mathsf THd<0\) | Strict local maximum |
| Indefinite | Both positive and negative directional curvature occur | Saddle point |
| Positive semidefinite | \(d^\mathsf THd\ge0\) | Necessary for a local minimum; not sufficient |
| Negative semidefinite | \(d^\mathsf THd\le0\) | Necessary for a local maximum; not sufficient |

If the Hessian is singular or merely semidefinite, higher-order terms and direct function comparisons may be required. A strict local minimum can have a singular Hessian, as with \(x^4\).

## 4. Two-variable determinant test

For a twice continuously differentiable function \(f(x,y)\) at a stationary point, let

\[
H=\begin{bmatrix}A&B\\B&C\end{bmatrix},
\qquad D=AC-B^2.
\]

Then

\[
\boxed{
\begin{array}{ll}
D>0,\ A>0 &\Rightarrow \text{strict local minimum},\\
D>0,\ A<0 &\Rightarrow \text{strict local maximum},\\
D<0 &\Rightarrow \text{saddle point},\\
D=0 &\Rightarrow \text{inconclusive}.
\end{array}}
\]

The determinant is not a substitute for verifying the stationary condition. If \(D>0\), \(A\) and \(C\) necessarily have the same sign.

## 5. Worked examples

**Strict minimum.** For \(f(x,y)=2(x-1)^2+3(y+2)^2\), the stationary point is \((1,-2)\) and

\[
H=\begin{bmatrix}4&0\\0&6\end{bmatrix},\quad D=24>0.
\]

Since \(A=4>0\), the point is a strict local minimum and, by direct nonnegativity, a global minimum.

**Strict maximum.** For \(g(x,y)=-2(x-1)^2-3(y+2)^2\), the same point has \(H=\operatorname{diag}(-4,-6)\), \(D=24>0\), and \(A=-4<0\): a strict local and global maximum.

**Saddle.** For \(s(x,y)=x^2-y^2\), the origin is stationary and \(H=\operatorname{diag}(2,-2)\), so \(D=-4<0\).

**Inconclusive Hessian.** For \(u(x,y)=x^4+y^4\), the origin is a strict global minimum even though \(H(0,0)=0\). For \(v(x,y)=x^4-y^4\), the same zero Hessian occurs, but the origin is a saddle. Higher-order behavior decides.

## 6. Eigenvalue interpretation

A real symmetric Hessian has real eigenvalues and orthogonal eigenvectors. Positive definiteness is equivalent to all eigenvalues being positive; negative definiteness means all are negative; an indefinite Hessian has eigenvalues of both signs. A zero eigenvalue makes the strict definiteness test inconclusive, although nonzero eigenvalues can still reveal positive or negative curvature.

For a \(2\times2\) symmetric matrix, the eigenvalues are

\[
\lambda_\pm=\frac{A+C\pm\sqrt{(A-C)^2+4B^2}}{2}.
\]

Numerical classifications near zero eigenvalues require tolerances tied to the matrix scale; roundoff can change the apparent sign.

## 7. Financial calibration example

Reuse the synthetic calibration loss

\[
L(r)=[1000(1+2r)-1100]^2=(2000r-100)^2.
\]

The stationary rate is \(r^*=0.05\), and

\[
L''(r)=8{,}000{,}000>0.
\]

Thus \(r^*\) is a strict local minimum. Because the loss is a nonnegative quadratic that reaches zero, it is also the unique global minimum. The curvature value is large partly because the objective uses squared currency residuals and a decimal-rate coordinate; raw Hessian magnitudes cannot be compared meaningfully across differently scaled objectives without normalization.

For a weighted linear least-squares model

\[
L(\theta)=\tfrac12(A\theta-b)^\mathsf TW(A\theta-b),
\]

with a symmetric positive semidefinite weight matrix \(W\),

\[
\nabla L=A^\mathsf TW(A\theta-b),\qquad
H_L=A^\mathsf TWA.
\]

The Hessian is positive semidefinite. It is positive definite when \(W\) is positive definite and \(A\) has full column rank. Rank deficiency can produce nonunique minimizers. Nonlinear residual models can have additional curvature terms and need not be convex.

## 8. Local versus global guarantees

A positive definite Hessian at one stationary point establishes a **strict local** minimum, not global optimality for an arbitrary nonlinear objective. Global optimality requires additional structure, such as convexity over the entire relevant convex domain. Conversely, an indefinite Hessian at a stationary point establishes a saddle regardless of distant behavior.

## 9. Numerical cautions

Finite-difference Hessians can be unstable because second derivatives involve subtracting nearly equal values. Prefer analytic or automatic differentiation when available, verify Hessian symmetry, use scale-aware steps, and compare numerical curvature against independently derived examples. An optimization solver's convergence flag is not a mathematical proof of optimality.

## 11. Twenty worked exercises

**1.** State the scalar second-order sufficient condition for a strict local minimum.  
*Answer:* \(f'(x^*)=0\) and \(f''(x^*)>0\).

**2.** State the scalar sufficient condition for a strict local maximum.  
*Answer:* \(f'(x^*)=0\) and \(f''(x^*)<0\).

**3.** What if \(f''(x^*)=0\)?  
*Answer:* The test is inconclusive.

**4.** Classify \(x^2\) at zero.  
*Answer:* Strict global minimum.

**5.** Classify \(-x^2\) at zero.  
*Answer:* Strict global maximum.

**6.** Classify \(x^3\) at zero.  
*Answer:* Stationary non-extremum.

**7.** Classify \(x^4\) at zero.  
*Answer:* Strict global minimum despite zero second derivative.

**8.** Define a positive definite Hessian.  
*Answer:* \(d^\mathsf THd>0\) for every nonzero \(d\).

**9.** Define an indefinite Hessian.  
*Answer:* It has directions of both positive and negative quadratic curvature.

**10.** Write the two-variable Hessian determinant.  
*Answer:* \(D=AC-B^2\).

**11.** What does \(D<0\) imply at a stationary point?  
*Answer:* Saddle.

**12.** What do \(D>0,A>0\) imply?  
*Answer:* Strict local minimum.

**13.** What do \(D>0,A<0\) imply?  
*Answer:* Strict local maximum.

**14.** What does \(D=0\) imply?  
*Answer:* Inconclusive second-order test.

**15.** Find the Hessian of \(2(x-1)^2+3(y+2)^2\).  
*Answer:* \(\operatorname{diag}(4,6)\).

**16.** Find its determinant.  
*Answer:* \(24\).

**17.** Find the Hessian of \(x^2-y^2\).  
*Answer:* \(\operatorname{diag}(2,-2)\).

**18.** Find its determinant.  
*Answer:* \(-4\).

**19.** Find \(L''(r)\) for the reference financial calibration.  
*Answer:* \(8{,}000{,}000\).
