An inverse function answers a question in the opposite direction: instead of computing an output from an input, it recovers the input from an output. In finance, this is useful for recovering the quantity needed to produce a specified profit, or finding the discount rate implied by a known future cash flow and present value. Inverse calculations require special care because **not every function has an inverse over its original domain**.

## 3.4.1 Learning objectives

After completing this section, you should be able to define an inverse function; identify injectivity and the appropriate output range; derive inverses algebraically; verify them by composing in both directions; distinguish algebraic candidates from feasible financial inputs; handle constant functions and discrete quantities; and implement domain-aware inverse calculations in Python.

## 3.4.2 What is an inverse function?

Suppose $f:D\to R$ is a function, where $R=f(D)$ is its **actual range**. An inverse $f^{-1}:R\to D$ exists if and only if $f$ is **one-to-one** (injective): distinct inputs never produce the same output.

For every $x\in D$ and $y\in R$,

$$f^{-1}(f(x))=x,\qquad f(f^{-1}(y))=y.$$

These two identities are stronger than merely finding an expression that appears to solve an equation. They confirm that the domains and ranges line up.

The notation $f^{-1}$ means inverse function, **not** reciprocal $1/f(x)$.

If the codomain is larger than the range, the inverse is defined on the range unless a different mapping is explicitly constructed. For example, $f(x)=2x+1$ on $D=[0,\infty)$ has range $[1,\infty)$, so its inverse $(y-1)/2$ accepts $y\ge1$, not every real $y$.

## 3.4.3 Inverting a linear function

Let $f(x)=ax+b$. Set $y=ax+b$ and solve for $x$:

$$y-b=ax\quad\Longrightarrow\quad x=\frac{y-b}{a},\qquad a\ne0.$$

Thus

$$\boxed{f^{-1}(y)=\frac{y-b}{a}}.$$

For $f(x)=2x+3$, the inverse is $(y-3)/2$. Check both directions:

$$f^{-1}(f(x))=\frac{(2x+3)-3}{2}=x,$$

$$f(f^{-1}(y))=2\frac{y-3}{2}+3=y.$$

If $a=0$, $f(x)=b$ is constant. On a domain containing more than one point, it is not injective and has **no inverse function**. Solving $f(x)=b$ produces many possible inputs, not a unique inverse.

## 3.4.4 A nonlinear function that needs domain restriction

Consider $s(x)=x^2$ on the real numbers. It is not one-to-one because $s(2)=s(-2)=4$. Therefore it has no inverse function on all of $\mathbb R$.

Restrict the domain to $[0,\infty)$:

$$s:[0,\infty)\to[0,\infty),\qquad s(x)=x^2.$$

Now it is injective, and

$$s^{-1}(y)=\sqrt{y},\qquad y\ge0.$$

If instead the domain is $(-\infty,0]$, the inverse is $-\sqrt{y}$. **The inverse depends on the domain restriction**, not just the original formula.

The reference implementation includes an exact-rational restricted-square example. Because $\sqrt{2}$ is irrational, a rational-only implementation must not falsely return an exact rational answer. It explicitly classifies inputs whose square root cannot be represented as a rational number.

## 3.4.5 Financial inverse: quantity from profit

Let price $p$, variable cost $v$, and fixed cost $F$ be fixed. The profit function is

$$\Pi(q)=(p-v)q-F.$$

Write $m=p-v$. If $m\ne0$, the algebraic inverse is

$$\boxed{q=\frac{\Pi+F}{m}}.$$

But the financial domain may require $q\in\mathbb Z_{\ge0}$. The inverse then accepts only profits in the **discrete range**

$$\{-F+mq:q=0,1,2,\ldots\}.$$

A candidate can be a valid real number and still fail to be an attainable whole-item quantity.

### Worked example

Let $p=20$, $v=10$, and $F=100$. Then

$$\Pi(q)=10q-100.$$

For target profit 80,

$$q=\frac{80+100}{10}=18.$$

Substitute back: $\Pi(18)=10(18)-100=80$. Both the domain and original equation are satisfied.

For target profit 85,

$$q=\frac{85+100}{10}=18.5.$$

The algebraic inverse exists over a continuous quantity domain, but there is **no exact whole-item solution**. The output 85 is not in the discrete range of the original whole-item profit function. Do not round 18.5 and still call it an inverse.

If $p=v$, profit is constant at $-F$. There is no inverse on a domain with multiple quantities: target $-F$ corresponds to all quantities, while any other target corresponds to none.

## 3.4.6 Financial inverse: recover the implied discount rate

Consider a positive future cash flow $C$ discounted for one period at rate $r$:

$$V(r)=\frac{C}{1+r}.$$

Assume $C>0$ and $r>-1$, so the discount factor is positive. Then $V>0$. To recover the rate from a positive present value $V$, rearrange:

$$V(1+r)=C\quad\Longrightarrow\quad
\boxed{r=\frac{C}{V}-1}.$$

For $C=110$ and $V=100$,

$$r=\frac{110}{100}-1=\frac{1}{10}=10\%.$$

Check: $110/(1+1/10)=100$.

The inverse's domain is $V>0$, and its range is $r>-1$. If the economic policy additionally requires $r\ge0$, then $0<V\le C$. A negative implied rate greater than $-1$ is mathematically valid under the broader model, but may be disallowed by a narrower policy.

**Important:** This is an *implied rate within a simplified one-period deterministic model*, not an estimate of a market yield without further cash-flow and pricing assumptions.

## 3.4.7 Graphical interpretation

The graphs of a function and its inverse are reflections across the line $y=x$ **when both axes use the same numeric coordinate scale**. A point $(a,b)$ on $f$ becomes $(b,a)$ on $f^{-1}$.

For a financial inverse, the axes also swap **units**. Profit as a function of quantity has horizontal units of items and vertical units of currency. Quantity as a function of profit has horizontal units of currency and vertical units of items. This unit swap matters more than the apparent visual symmetry in a plot.

The horizontal-line test is a graphical injectivity test: if a horizontal line intersects a graph more than once, the function is not one-to-one on that domain.

## 3.4.9 Common mistakes

- Confusing $f^{-1}(x)$ with $1/f(x)$.
- Assuming every function is invertible.
- Ignoring the original function's domain.
- Using the codomain instead of the actual range as the inverse domain.
- Treating an algebraic inverse quantity as a valid whole-item solution.
- Dividing by a zero contribution margin.
- Taking only the positive square root without first restricting the domain.
- Reporting an approximate answer as exact.
- Calling an implied discount rate an observed market rate.

## 3.4.10 Exercises

**1.** Find the inverse of $f(x)=5x-7$ and verify both composition identities.

**2.** Does $f(x)=x^2-1$ have an inverse over all real numbers? Restrict its domain to $x\ge0$ and find the inverse and its domain.

**3.** A profit model is $\Pi(q)=8q-120$ with $q\in\mathbb Z_{\ge0}$. Recover the quantity for profit 40 and determine whether profit 44 is attainable.

**4.** Find the implied rate if a one-period future payment of 240 currency units has present value 200. Check your result.

**5.** Let $f(x)=4$ for every $x\ge0$. Explain why the equation $f(x)=4$ has many solutions but the function has no inverse.

**6.** If a positive future cash flow is $C=100$, determine which present values are permitted when the discount rate is restricted to $r\ge0$.

**7.** Solve $x^2=9$ over (a) all real inputs and (b) the restricted domain $x\ge0$. Explain the distinction between solving an equation and evaluating an inverse function.

### Worked answers

1. $f^{-1}(y)=(y+7)/5$; substituting in either direction simplifies to the original input.
2. No, since $x$ and $-x$ produce the same output. With $x\ge0$, $f^{-1}(y)=\sqrt{y+1}$ for $y\ge-1$.
3. For 40, $q=(40+120)/8=20$. For 44, $q=164/8=20.5$, not an integer, so 44 is not in the discrete range.
4. $r=240/200-1=1/5=20\%$. Check $240/(1+1/5)=200$.
5. Many inputs map to the same output 4; injectivity fails.
6. $V=100/(1+r)$ with $r\ge0$, so $0<V\le100$.
7. Over reals, $x=\pm3$. With $x\ge0$, $x=3$. The inverse square function is defined only after a one-to-one domain restriction.
