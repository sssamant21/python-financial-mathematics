Financial models describe relationships between inputs and outputs. Before drawing a graph or calculating a sensitivity, we must decide **which inputs are permitted**, **what the output means**, and **which outputs can actually occur**. These choices are mathematical and economic—not merely programming details.

## 3.1.1 Learning objectives

- Distinguish a function's **range** from its codomain.
- Identify natural mathematical restrictions and additional financial policy restrictions.
- Describe discrete versus continuous domains.
- Compute and characterize the range of simple financial functions.
- Validate inputs and outputs with a standard-library Python implementation.
- Explain why a numerical sample is not a proof of a full range.

## 3.1.2 What makes a relationship a function?

A function $f:D\to C$ assigns **exactly one** element of codomain $C$ to every input in domain $D$. The rule can be expressed by an equation, table, algorithm, or piecewise definition.

The *domain* $D$ is the set of permitted inputs. The *codomain* $C$ is the declared target set. The *range* (or image) is the set of outputs actually attained:

$$f(D)=\{f(x):x\in D\}\subseteq C.$$

For example, let $f(x)=x^2$ with $D=\mathbb R$ and $C=\mathbb R$. Its range is $[0,\infty)$, which is smaller than the codomain. Changing the domain to $[0,2]$ changes the range to $[0,4]$ without changing the formula.

A relation that maps one input to two different outputs is not a function unless the model supplies an additional selection rule. Conversely, two different inputs *may* have the same output: a function need not be one-to-one.

## 3.1.3 Mathematical domain versus financial domain

Consider the profit function for a single product:

$$\Pi(q)=(p-v)q-F,$$

where $p$ is unit selling price, $v$ is variable cost per unit, $F$ is fixed cost for the period, and $q$ is quantity sold. For fixed parameters, the formula is algebraically defined for every real $q$. But a financial interpretation may require

$$q\in\mathbb Z_{\ge0}.$$

If only 100 items can be sold, the operational domain becomes

$$D=\{0,1,\ldots,100\}.$$

These are **three different domains** for the same algebraic expression. The function's attainable outputs change accordingly. An implementation should not silently treat an algebraic domain as an economically valid one.

The output of profit is measured in currency units; the input quantity is measured in items. The parameter $p-v$ has units currency per item. Dimensional consistency is a useful independent check.

## 3.1.4 Range of a linear profit function

Write $m=p-v$. For whole-item quantities $q\in\mathbb Z_{\ge0}$,

$$\Pi(D)=\{-F+mq:q=0,1,2,\ldots\}.$$

This is a discrete set, not automatically a continuous interval.

- If $m>0$, the range starts at $-F$ and increases in increments of $m$ without an upper bound.
- If $m=0$, the range is the singleton $\{-F\}$.
- If $m<0$, the range starts at $-F$ and decreases in increments of $|m|$ without a lower bound.

For $p=20$, $v=8$, and $F=60$, profit is $\Pi(q)=12q-60$. With whole units and capacity four, the domain is $\{0,1,2,3,4\}$ and the range is

$$\{-60,-48,-36,-24,-12\}.$$

It is **not** the interval $[-60,-12]$: values such as $-50$ are not attainable when items are indivisible.

If $q$ is allowed to be any real value in $[0,4]$, the range *does* become the entire interval $[-60,-12]$. Domain assumptions matter.

## 3.1.5 Rational functions and excluded inputs

Consider a one-period discounted value model

$$V(r)=\frac{C}{1+r},$$

where $C$ is a specified future cash flow and $r$ is the period's dimensionless rate. The algebraic real domain excludes $r=-1$, because the denominator would be zero.

For a financial interpretation that requires a strictly positive gross discount factor, use

$$D=\{r\in\mathbb R:r>-1\}.$$

If $C>0$, the range on this domain is $(0,\infty)$. To see this, $1+r>0$ makes $V>0$; for any $y>0$, choosing $r=C/y-1$ yields $V(r)=y$ and satisfies $r>-1$.

If $C=0$, the range is $\{0\}$. If $C<0$, the range is $(-\infty,0)$. These statements depend on the selected domain; permitting negative denominators would change the attainable signs.

At $C=110$ and $r=0.10$, the value is $110/1.10=100$ currency units. The model does not assert that the rate is market-observable or that the cash flow is certain.

## 3.1.6 Multiple inputs and parameter fixing

A financial function can take several inputs:

$$\Pi(q,p,v,F)=(p-v)q-F.$$

Here the domain is a set of valid tuples, such as

$$D=\{(q,p,v,F):q\in\mathbb Z_{\ge0},\ p,v,F\in\mathbb R_{\ge0}\}.$$

When studying $\Pi$ as a function of $q$ alone, the other three quantities must be fixed. Changing $p$ between two evaluations means changing a parameter, not merely moving to another quantity on the same one-input function.

A function specification should therefore name its inputs, fixed parameters, units, restrictions, output units, and exceptional cases. This makes later graphing, composition, and inverse calculations less error-prone.

## 3.1.8 Common mistakes

- Confusing the **codomain** with the actual range.
- Treating discrete attainable outputs as a continuous interval.
- Forgetting that division by zero removes inputs from the domain.
- Assuming all algebraically permitted inputs are financially meaningful.
- Claiming that a few sampled values prove the full range.
- Changing parameters between evaluations without identifying the change.
- Ignoring output units when interpreting a function.

## 3.1.9 Exercises

**1.** Let $f(x)=x^2$ on $D=[-2,3]$. Determine the range and explain why it is not $[4,9]$.

**2.** Let $\Pi(q)=5q-20$ on $D=\{0,1,2,3,4,5\}$. List the entire range. Is the output $-7$ attainable?

**3.** Let $V(r)=100/(1+r)$ with $r>-1$. Determine the range and find the input that produces output $50$.

**4.** Explain why $g(x)=1/(x-4)$ cannot accept $x=4$. State its algebraic real domain and range.

**5.** If $\Pi(q)=-3q-10$ and $q\in\mathbb Z_{\ge0}$, describe the range and its maximum value.

**6.** Define a valid domain for a model of the number of completed transactions per day. Explain why a continuous interval would be an inaccurate default.

### Answers

1. The range is $[0,9]$. The interval includes $x=0$, giving minimum zero, and $x=3$, giving maximum nine.
2. The range is $\{-20,-15,-10,-5,0,5\}$. The output $-7$ is not attained.
3. Range $(0,\infty)$; $100/(1+r)=50$ gives $r=1$.
4. The denominator vanishes at $x=4$. Domain $\mathbb R\setminus\{4\}$; range $\mathbb R\setminus\{0\}$.
5. Range $\{-10,-13,-16,\ldots\}$, with maximum $-10$ at $q=0$.
6. A natural domain is $\mathbb Z_{\ge0}$, possibly bounded by daily capacity. A count cannot take a fractional value.
