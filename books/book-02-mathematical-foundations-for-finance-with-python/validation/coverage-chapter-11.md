## Project contract and acceptance details

The 11.9 eight-step workflow has positive evidence for label alignment, marked values, NAV normalization, unexplained difference, four exposure measures, two scenarios and three policy breaches. Independent NAV is an input assumption, not a fact the program can certify. The report correctly calls the 40000 difference unexplained; it must not be treated as verified cash.

Input records are frozen dataclasses with tuple conversion. Attempted mutation, original source data preservation across all operations, mismatched currency units, negative NAV, nonfinite price/return values, invalid Policy fields and empty scenarios do not each have assertions in the project script. A bool rejection tests the shared numeric validator, not every caller path. The report contains assumptions, but policy output omits configured cap values and tolerances; it reports feasibility and breach names only.

The manuscript's timestamps, periods, corporate-action consistency and independently verified NAV are upstream data-governance requirements. Vector records in 11.7–11.10 have no timestamp/period or general axis field. Matrix row/column labels in 11.8 encode orientation by convention; there is no explicit date-versus-asset axis type that could reject a semantically transposed square matrix when labels still happen to match. These distinctions should remain explicit; shape and unit checks cannot verify unseen metadata.

11.7 does implement a budget test, while 11.9 intentionally does not impose one on risky weights summing to 0.6. This is an intentional scope difference, not a missing capstone requirement. Signed sector and individual long-cap examples in 11.7's conceptual policy table are not all implemented by its optional absolute/gross policy helper.

The final rubric's 85/100 threshold has not been graded. The mandatory nonfinite-input requirement is not demonstrated by a direct NaN/Inf assertion in 11.10: it tests bool rejection instead. Other section suites test NaN in selected contexts; that does not establish every final-assessment path.
