## Learning objectives

Understand limits as statements about behavior near an input, distinguish a limit from a function value, evaluate elementary limits algebraically, investigate numerical limits from both sides, and recognize numerical evidence as distinct from proof.

## 1. What is a limit?

The notation

\[
\lim_{x\to a} f(x)=L
\]

means that values of \(f(x)\) can be made arbitrarily close to \(L\) by choosing \(x\) sufficiently close to \(a\), with \(x\ne a\). It does **not** assert that \(f(a)\) exists or equals \(L\).

For example, let

\[
f(x)=\frac{x^2-4}{x-2},\qquad x\ne2.
\]

Factoring gives \(f(x)=x+2\) whenever \(x\ne2\). Consequently,

\[
\boxed{\lim_{x\to2}f(x)=4},
\]

although the original expression is undefined at \(x=2\). This is a removable hole in the graph.

## 2. Approaching from either direction

A **left-hand limit** considers \(x<a\); a **right-hand limit** considers \(x>a\). A finite two-sided limit exists precisely when both one-sided limits exist and agree.

For \(f(x)=x+2\) away from \(x=2\):

| \(x\) | \(f(x)\) |
|---:|---:|
| 1.9 | 3.9 |
| 1.99 | 3.99 |
| 1.999 | 3.999 |
| 2.001 | 4.001 |
| 2.01 | 4.01 |
| 2.1 | 4.1 |

These values suggest the limit is 4; algebra establishes it exactly.

## 3. Function value versus limit

Consider

\[
h(x)=
\begin{cases}
x+2,&x\ne2,\\
100,&x=2.
\end{cases}
\]

Then \(h(2)=100\) while \(\lim_{x\to2}h(x)=4\). Changing the function at a single isolated input does not change its limit there, provided nearby behavior is unchanged.

By contrast, for \(j(x)=0\) when \(x<0\) and \(j(x)=1\) when \(x\ge0\), the left-hand limit at zero is 0 and the right-hand limit is 1. The two-sided limit does not exist.

## 4. Formal definition

The statement \(\lim_{x\to a}f(x)=L\) means:

For every \(\varepsilon>0\), there exists \(\delta>0\) such that

\[
0<|x-a|<\delta\quad\Longrightarrow\quad |f(x)-L|<\varepsilon.
\]

The condition \(0<|x-a|\) excludes the input \(a\) itself. For \(f(x)=x+2\), \(a=2\), and \(L=4\), we have \(|f(x)-4|=|x-2|\). Choosing \(\delta=\varepsilon\) proves the limit.

## 5. Limit laws and their assumptions

If \(\lim_{x\to a}f(x)=A\) and \(\lim_{x\to a}g(x)=B\), then

\[
\lim(f+g)=A+B,\quad \lim(cf)=cA,\quad \lim(fg)=AB.
\]

For a quotient, \(\lim(f/g)=A/B\) only when \(B\ne0\). These laws require the component limits to exist and do not authorize division by zero.

Polynomials are continuous, so their limits can be found by substitution. Rational functions are continuous wherever their denominators are nonzero.

## 6. Financial example: a stable zero-rate limit

The finite-annuity future-value factor is

\[
A_n(r)=\frac{(1+r)^n-1}{r},\qquad r\ne0.
\]

For an integer \(n\ge1\), the binomial expansion shows

\[
(1+r)^n=1+nr+O(r^2),
\]

and hence

\[
\boxed{\lim_{r\to0}A_n(r)=n}.
\]

The quotient is undefined at \(r=0\), but the original finite payment sum has the value \(n\). The limit tells us how to extend the formula continuously at zero. This does **not** imply that an infinite perpetuity has a finite value at zero interest.

## 7. Numerical investigation and its limits

A table of nearby function values can reveal a likely limit. It cannot establish a limit for every arbitrarily close input. Floating-point arithmetic also limits how close a computer can represent distinct numbers near \(a\).

In Python, subtracting nearly equal values can destroy accuracy. For the annuity factor, use \`math.expm1(n * math.log1p(r)) / r\` for small nonzero \(r\), and return \(n\) at exactly zero. For the rational example, evaluate the simplified expression away from the excluded point.

## 9. Exercises

**1.** Explain why \(f(a)\) need not equal \(\lim_{x\to a}f(x)\).

**2.** Find \(\lim_{x\to3}(2x+1)\).

**3.** Evaluate \(\lim_{x\to2}(x^2-4)/(x-2)\).

**4.** Can a two-sided limit exist when finite one-sided limits differ?

**5.** Give a function with \(f(1)=10\) but \(\lim_{x\to1}f(x)=2\).

**6.** Prove \(\lim_{x\to2}(x+2)=4\) using \(\varepsilon\) and \(\delta\).

**7.** Evaluate \(\lim_{r\to0}((1+r)^5-1)/r\).

**8.** Explain why numerical sampling alone is not a proof of a limit.

### Worked solutions

1. A limit describes values at inputs near \(a\), excluding \(a\) itself.
2. 7.
3. 4, because the quotient simplifies to \(x+2\) for \(x\ne2\).
4. No; the two one-sided limits must agree.
5. Set \(f(x)=x+1\) for \(x\ne1\), and \(f(1)=10\).
6. Since \(|(x+2)-4|=|x-2|\), take \(\delta=\varepsilon\).
7. 5, by the binomial expansion.
8. Finitely many samples cannot rule out unusual behavior between sampled inputs, and floating-point rounding can distort the results.
