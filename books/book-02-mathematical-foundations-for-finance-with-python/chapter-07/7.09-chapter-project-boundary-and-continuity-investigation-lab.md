## Project mission

Build a small, auditable boundary-analysis toolkit for financial functions. Your toolkit must distinguish a mathematical limit from a function value, test one-sided behavior, identify discontinuities, evaluate stable zero-rate extensions, and locate roots only when the Intermediate Value Theorem's hypotheses are satisfied.

This capstone integrates Sections 7.1–7.8. It is designed for a local Python environment without third-party dependencies.

## Learning outcomes

By completing this project you should be able to:

1. Formulate mathematical assumptions before running numerical experiments.
2. Classify removable, jump, and infinite discontinuities.
3. Investigate one-sided limits while recognizing the limitations of finite sampling.
4. Implement and test continuous extensions of financial formulas at zero interest.
5. Apply a bracketed root solver to a continuous financial residual.
6. Record test evidence, failure conditions, and reproducibility details.

## Case A — A removable singularity

Consider

\[
f(x)=\frac{x^2-9}{x-3},\qquad x\ne3.
\]

For \(x\ne3\),

\[
f(x)=x+3,
\]

so the two-sided limit at 3 equals 6. The original function is undefined at 3. Define the continuous extension \(F(3)=6\), and \(F(x)=f(x)\) otherwise.

**Tasks:** Implement both the original and extended functions. Verify the original rejects \(x=3\), and that the extension agrees with \(x+3\) for representative points on both sides.

## Case B — A jump in a transaction fee

Define a fee model

\[
J(A)=\begin{cases}
5,&0\le A<1000,\\
10,&A\ge1000.
\end{cases}
\]

At the threshold \(A=1000\), the left-hand limit is 5 and the right-hand limit is 10. The function value is 10, so the model has a jump discontinuity.

**Tasks:** Test amounts immediately below, exactly at, and above 1000. Do not use an arbitrary closeness tolerance to decide which fee bracket applies: the contract specifies an exact threshold.

## Case C — An infinite discontinuity

Let

\[
V(x)=\frac{1}{x-2}.
\]

The left-hand values diverge to \(-\infty\) and the right-hand values to \(+\infty\) as \(x\to2\). The function is undefined at 2.

**Tasks:** Generate symmetric samples approaching 2. Confirm signs and increasing magnitudes for the selected offsets. Explain why finite samples alone cannot prove divergence.

## Case D — A zero-rate financial boundary

The future-value annuity accumulation factor for \(n\) equal end-of-period payments is

\[
S_n(r)=\frac{(1+r)^n-1}{r},\qquad r\ne0,\quad r>-1.
\]

For a positive integer \(n\),

\[
S_n(r)=\sum_{k=0}^{n-1}(1+r)^k.
\]

This identity implies

\[
\lim_{r\to0}S_n(r)=n.
\]

Define \(S_n(0)=n\). Implement the factor using \`math.expm1(n*math.log1p(r))/r\` for nonzero rates, with the exact zero-rate branch. Compare with the independent finite-sum formula.

**Tasks:** Check negative rates greater than -1, tiny positive rates, exact zero, and ordinary positive rates. State that this is a *finite* annuity, not a perpetuity.

## Case E — A root with a mathematical guarantee

For a two-period security paying 50 at year 1 and 1050 at year 2, priced at 1000, define

\[
R(y)=\frac{50}{1+y}+\frac{1050}{(1+y)^2}-1000,\qquad y>-1.
\]

The residual is continuous and strictly decreasing on its domain. Since \(R(0)>0\) and \(R(0.1)<0\), the IVT guarantees a unique yield in \((0,0.1)\). The exact solution is \(y=0.05\).

**Tasks:** Implement bisection with explicit sign-bracket validation, a width-based tolerance, maximum iterations, and an auditable result containing the root estimate, bracket, iteration count, and residual. Verify that a bracket without a sign change is rejected.

## Failure investigations

**A false discontinuity from rounding:** The raw expression \((x^2-9)/(x-3)\) can lose precision near 3. Compare against its algebraically simplified form.

**A missed jump:** Sampling only integer amounts may hide the immediate neighborhood of the fee threshold. Test values just below and above 1000.

**A false root from a sign change:** A discontinuous step function can have opposite endpoint signs without any root. The continuity assumption must be established separately.

**A wrong annuity at zero:** Direct substitution into the quotient yields division by zero. Use the continuous extension derived from the finite sum.

**A misleadingly small residual:** A small function residual is not automatically a tight root error bound. Retain the final bisection bracket.

## Exercises and project review

1. Explain the difference between \(f(3)\) and \(\lim_{x\to3}f(x)\) in Case A.
2. Determine the two one-sided limits of the fee model at 1000.
3. Explain why \(V(x)\) has a vertical asymptote at 2.
4. Derive the zero-rate annuity extension using the finite sum.
5. Explain why \`log1p\` and \`expm1\` improve numerical stability.
6. Identify the assumptions needed for the bond-yield IVT argument.
7. Explain why the yield is unique in Case E.
8. Describe what a successful reference-check run proves and what it does not prove.

### Answers

1. The original \(f(3)\) is undefined, while the limit is 6.
2. Left limit 5; right limit 10.
3. One-sided values are unbounded with opposite signs.
4. Each of the \(n\) terms tends to 1, so the sum tends to \(n\).
5. They reduce cancellation near zero.
6. The residual must be continuous on the bracket, and the endpoint signs must differ.
7. Positive discounted payments strictly decrease as yield increases.
8. It demonstrates that the listed tests passed in that runtime; it does not establish correctness for all inputs or substitute for mathematical review.
