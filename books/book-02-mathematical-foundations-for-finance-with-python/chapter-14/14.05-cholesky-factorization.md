## Learning objectives

Derive the Cholesky factorization for symmetric positive-definite (SPD) matrices, compute a \(2\times2\) lower-triangular factor, solve linear systems using forward and backward substitution, validate the reconstruction, and interpret its use in financial covariance and risk models.

## 1. The factorization

For a real symmetric positive-definite matrix \(A\), there is a unique lower-triangular matrix \(L\) with **strictly positive diagonal entries** such that

\[
\boxed{A=LL^\mathsf T}.
\]

The SPD requirement matters. A singular positive-semidefinite matrix may have a square-root factorization, but the standard positive-pivot Cholesky algorithm cannot complete because at least one pivot is zero. Indefinite matrices can produce negative pivots and must be rejected by this algorithm.

## 2. Derivation for a symmetric 2×2 matrix

Let

\[
A=\begin{bmatrix}a&b\\b&d\end{bmatrix},
\qquad
L=\begin{bmatrix}\ell_{11}&0\\\ell_{21}&\ell_{22}\end{bmatrix}.
\]

Multiplication gives

\[
LL^\mathsf T=
\begin{bmatrix}
\ell_{11}^2&\ell_{11}\ell_{21}\\
\ell_{11}\ell_{21}&\ell_{21}^2+\ell_{22}^2
\end{bmatrix}.
\]

Equating entries and choosing positive diagonal entries yields

\[
\boxed{
\ell_{11}=\sqrt a,\qquad
\ell_{21}=\frac b{\sqrt a},\qquad
\ell_{22}=\sqrt{d-\frac{b^2}{a}}
}.
\]

The necessary and sufficient SPD conditions for a symmetric \(2\times2\) matrix are \(a>0\) and \(ad-b^2>0\). These make both square roots strictly positive.

## 3. Worked two-factor example

Take the hypothetical risk matrix

\[
A=\begin{bmatrix}4&2\\2&3\end{bmatrix}.
\]

The leading principal minor is \(4>0\), and \(\det A=12-4=8>0\), so \(A\) is SPD.

\[
\ell_{11}=2,\quad
\ell_{21}=1,\quad
\ell_{22}=\sqrt{3-1}=\sqrt2.
\]

Thus

\[
\boxed{L=\begin{bmatrix}2&0\\1&\sqrt2\end{bmatrix}}.
\]

Reconstruction gives

\[
LL^\mathsf T=
\begin{bmatrix}4&2\\2&1+2\end{bmatrix}
=A.
\]

## 4. Solving a linear system

For \(Ax=b\), use \(LL^\mathsf Tx=b\) without explicitly computing \(A^{-1}\).

**Forward substitution:** solve \(Ly=b\).

**Backward substitution:** solve \(L^\mathsf Tx=y\).

For \(b=(6,5)^\mathsf T\), forward substitution gives

\[
2y_1=6\Rightarrow y_1=3,\qquad
y_1+\sqrt2\,y_2=5\Rightarrow y_2=\sqrt2.
\]

Backward substitution gives

\[
\sqrt2\,x_2=\sqrt2\Rightarrow x_2=1,\qquad
2x_1+x_2=3\Rightarrow x_1=1.
\]

Therefore \(\boxed{x=(1,1)}\), and direct verification yields \(Ax=(6,5)\).

## 5. Determinant and quadratic forms

Because \(\det(A)=\det(L)^2\),

\[
\boxed{\det(A)=\left(\prod_iL_{ii}\right)^2}.
\]

For the example, \(\det(A)=(2\sqrt2)^2=8\).

For any vector \(x\),

\[
x^\mathsf TAx=x^\mathsf TLL^\mathsf Tx
=\|L^\mathsf Tx\|_2^2.
\]

Since \(L\) is nonsingular, the expression is strictly positive for every nonzero \(x\). This gives a direct geometric explanation of positive definiteness.

## 6. Financial application: covariance transformations

If \(\Sigma\) is a valid SPD covariance matrix and \(z\) is a zero-mean random vector with identity covariance, then

\[
r=Lz,\qquad \Sigma=LL^\mathsf T
\]

implies

\[
\operatorname{Cov}(r)=L\operatorname{Cov}(z)L^\mathsf T
=LL^\mathsf T=\Sigma.
\]

This is a covariance transformation, not a claim that transformed returns are normally distributed. If \(z\) is additionally standard multivariate normal, \(r\) is multivariate normal with covariance \(\Sigma\).

The factor depends on factor ordering. Cholesky columns should not be interpreted as uniquely identified economic shocks without a documented ordering and modeling assumption.

## 7. Numerical and operational safeguards

- Check matrix shape, finite entries, and symmetry.
- Reject zero or negative pivots rather than silently adding a diagonal adjustment.
- Record a scale-aware reconstruction residual \(\|A-LL^\mathsf T\|_F\).
- Verify a solved system independently using \(\|Ax-b\|_2\).
- Avoid explicit matrix inversion to solve linear systems.
- If covariance estimates are singular or indefinite, investigate the model and data before applying a documented repair policy.
- Use established numerical libraries (such as NumPy or SciPy) for general production-sized matrices; this chapter's standard-library implementation is educational and limited to \(2\times2\).

## 9. Twenty worked exercises

**1.** State the Cholesky factorization.  
*Answer:* \(A=LL^\mathsf T\) for SPD \(A\), with lower-triangular \(L\) and positive diagonal.

**2.** Is \(L\) upper or lower triangular?  
*Answer:* Lower triangular.

**3.** What is the reference matrix?  
*Answer:* \(\begin{bmatrix}4&2\\2&3\end{bmatrix}\).

**4.** Compute its determinant.  
*Answer:* \(8\).

**5.** Verify the first Sylvester condition.  
*Answer:* \(a=4>0\).

**6.** Compute \(\ell_{11}\).  
*Answer:* \(2\).

**7.** Compute \(\ell_{21}\).  
*Answer:* \(1\).

**8.** Compute \(\ell_{22}\).  
*Answer:* \(\sqrt2\).

**9.** Write the reference \(L\).  
*Answer:* \(\begin{bmatrix}2&0\\1&\sqrt2\end{bmatrix}\).

**10.** Reconstruct the top-left entry.  
*Answer:* \(2^2=4\).

**11.** Reconstruct the off-diagonal entry.  
*Answer:* \(2(1)=2\).

**12.** Reconstruct the bottom-right entry.  
*Answer:* \(1^2+(\sqrt2)^2=3\).

**13.** State the forward substitution equation.  
*Answer:* \(Ly=b\).

**14.** State the backward substitution equation.  
*Answer:* \(L^\mathsf Tx=y\).

**15.** Solve \(Ax=(6,5)\).  
*Answer:* \(x=(1,1)\).

**16.** Verify the solution.  
*Answer:* \(A(1,1)=(6,5)\).

**17.** Express \(\det A\) using \(L\).  
*Answer:* \((\prod_iL_{ii})^2\).

**18.** Express \(x^\mathsf TAx\) using \(L\).  
*Answer:* \(\|L^\mathsf Tx\|_2^2\).

**19.** Does a singular PSD matrix support standard positive-pivot Cholesky?  
*Answer:* No.

**20.** What is the next topic?  
*Answer:* 14.6 — Singular Value Decomposition.
