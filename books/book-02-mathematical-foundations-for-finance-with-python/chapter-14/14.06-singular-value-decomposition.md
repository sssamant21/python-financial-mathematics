## Learning objectives

Define singular value decomposition (SVD), distinguish it from eigendecomposition, derive singular values using \(A^\mathsf TA\), identify left and right singular directions, reconstruct rectangular matrices, assess rank and conditioning, and explain how SVD supports stable financial exposure replication.

## 1. The singular value decomposition

For any real \(m\times n\) matrix \(A\), an SVD exists:

\[
\boxed{A=U\Sigma V^\mathsf T}.
\]

In a **full SVD**, \(U\in\mathbb R^{m\times m}\) and \(V\in\mathbb R^{n\times n}\) are orthogonal, and \(\Sigma\in\mathbb R^{m\times n}\) is diagonal-shaped with nonnegative entries. A **reduced SVD** uses \(r=\min(m,n)\) columns: \(U_r\in\mathbb R^{m\times r}\), \(\Sigma_r\in\mathbb R^{r\times r}\), and \(V_r\in\mathbb R^{n\times r}\). Both represent \(A\) exactly.

The singular values \(\sigma_1\ge\sigma_2\ge\cdots\ge0\) are the nonnegative square roots of the eigenvalues of \(A^\mathsf TA\). The columns of \(V\) are right singular vectors (input directions); those of \(U\) are left singular vectors (output directions).

Unlike eigendecomposition, SVD applies to rectangular and rank-deficient matrices.

## 2. Why \(A^\mathsf TA\) matters

From \(A=U\Sigma V^\mathsf T\),

\[
A^\mathsf TA=V(\Sigma^\mathsf T\Sigma)V^\mathsf T.
\]

Therefore,

\[
A^\mathsf TAv_i=\sigma_i^2v_i,\qquad
Av_i=\sigma_i u_i\quad(\sigma_i>0).
\]

The nonzero singular values describe how strongly the linear map stretches particular orthogonal input directions. A zero singular value indicates a direction with no mapped output and, for an \(m\times n\) matrix, contributes to the null space.

**Numerical caution:** Although the identities use \(A^\mathsf TA\), production SVD algorithms generally do not form this product to solve least squares because its condition number is squared. The educational lab uses an analytic \(2\times2\) example only.

## 3. Worked rectangular exposure example

Let the hypothetical factor-by-instrument exposure matrix be

\[
A=\begin{bmatrix}3&0\\0&2\\0&0\end{bmatrix}
\quad(3\text{ factors}\times2\text{ instruments}).
\]

Then

\[
A^\mathsf TA=\begin{bmatrix}9&0\\0&4\end{bmatrix}.
\]

The singular values are \(3\) and \(2\). A reduced SVD is

\[
U_r=\begin{bmatrix}1&0\\0&1\\0&0\end{bmatrix},
\quad
\Sigma_r=\begin{bmatrix}3&0\\0&2\end{bmatrix},
\quad
V_r=I_2.
\]

Reconstruction gives \(U_r\Sigma_rV_r^\mathsf T=A\). The condition number on the nonzero singular subspace is \(\kappa_2(A)=3/2\). Both instrument directions are identifiable from the modeled factors.

## 4. Rank deficiency and an unhedgeable direction

Change the matrix to

\[
B=\begin{bmatrix}3&0\\0&0\\0&0\end{bmatrix}.
\]

Its singular values are \(3\) and \(0\), so \(\operatorname{rank}(B)=1\). The second instrument direction has no modeled exposure; its position cannot be determined from factor matching alone. In an unconstrained least-squares problem, infinitely many allocations may achieve the same modeled exposure.

The Moore–Penrose pseudoinverse uses reciprocals of **nonzero** singular values. It selects the minimum-Euclidean-norm least-squares solution, subject to the chosen units and scaling.

## 5. SVD and least squares

For \(A=U\Sigma V^\mathsf T\), the minimum-norm least-squares solution is

\[
\boxed{x^*=A^+b=V\Sigma^+U^\mathsf Tb},
\]

where \(\Sigma^+\) reciprocates retained nonzero singular values and transposes the rectangular shape. A numerical rank tolerance decides which small singular values are treated as zero. This decision can materially change the estimated positions.

For the full-rank reference \(A\) and target \(b=(6,4,5)\), the minimum-norm solution is \(x=(2,2)\). The achieved exposure is \((6,4,0)\), and the residual \(b-Ax=(0,0,5)\) represents an unreplicated third factor. The half-squared-residual objective is \(25/2=12.5\). A mathematically optimal allocation does not imply acceptance under business risk limits.

## 6. Conditioning and sensitivity

For a full-column-rank matrix, the spectral condition number is

\[
\kappa_2(A)=\frac{\sigma_{\max}}{\sigma_{\min}}.
\]

Large \(\kappa_2\) indicates that small perturbations in input exposures or target measurements can cause large position changes. When the smallest singular value is zero, the matrix is rank deficient and the full-column-rank condition number is infinite.

For financial exposure matrices, inspect singular values alongside factor units, scaling, model assumptions, and independent position limits. The singular-value threshold is an engineering and governance choice, not an economic truth.

## 7. Geometry and interpretation

The SVD maps the unit sphere in instrument-position space to an ellipsoid in factor-exposure space. Right singular vectors determine input directions; singular values give stretch magnitudes; left singular vectors determine output directions. This interpretation remains useful even when the number of instruments differs from the number of modeled factors.

Singular-vector signs are arbitrary, and singular vectors within a repeated singular-value subspace are not uniquely identified. Avoid assigning stable economic labels to such directions without additional assumptions.

*Answer:* No.
