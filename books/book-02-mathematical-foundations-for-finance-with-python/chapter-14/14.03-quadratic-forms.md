## Learning objectives

Define quadratic forms; expand diagonal and cross terms; explain why only the symmetric part of a matrix contributes; derive the gradient and Hessian; interpret quadratic exposure models; evaluate quadratic forms in an eigenbasis; and distinguish a numerical risk proxy from a validated covariance-based portfolio risk measure.

## 1. Definition

For \(x\in\mathbb R^n\) and \(A\in\mathbb R^{n\times n}\), the scalar

\[
\boxed{q(x)=x^\mathsf TAx}
\]

is a **quadratic form**. In two dimensions,

\[
A=\begin{bmatrix}a&b\\c&d\end{bmatrix},
\qquad x=\begin{bmatrix}x_1\\x_2\end{bmatrix}
\]

gives

\[
q(x)=ax_1^2+(b+c)x_1x_2+dx_2^2.
\]

If \(A\) is symmetric, \(b=c\), so the interaction term is \(2bx_1x_2\). This factor of two matters in financial sensitivity calculations.

## 2. Only the symmetric part matters

Write

\[
S=\tfrac12(A+A^\mathsf T),\qquad
K=\tfrac12(A-A^\mathsf T).
\]

Here \(S\) is symmetric and \(K\) is skew-symmetric. For any real \(x\), \(x^\mathsf TKx=0\), hence

\[
\boxed{x^\mathsf TAx=x^\mathsf TSx}.
\]

Thus every real quadratic form can be represented by a symmetric matrix. A financial implementation should either require symmetry or explicitly disclose symmetrization rather than silently discarding inconsistent entries.

## 3. Worked two-factor example

Let

\[
A=\begin{bmatrix}2&1\\1&2\end{bmatrix},
\qquad x=\begin{bmatrix}2\\1\end{bmatrix}.
\]

Then

\[
q(x)=2x_1^2+2x_1x_2+2x_2^2
=2(4)+2(2)+2(1)=\boxed{14}.
\]

The matrix-vector product is \(Ax=(5,4)^\mathsf T\), and \(x^\mathsf TAx=2(5)+1(4)=14\). The cross term contributes \(4\), which would be omitted by an incorrect diagonal-only calculation.

## 4. Gradient and Hessian

For constant \(A\),

\[
\nabla(x^\mathsf TAx)=(A+A^\mathsf T)x.
\]

For symmetric \(A\),

\[
\boxed{\nabla q(x)=2Ax,\qquad \nabla^2q(x)=2A}.
\]

A common financial objective uses \(f(x)=\tfrac12x^\mathsf TAx\), so its gradient is \(Ax\) and Hessian is \(A\). Keep the \(1/2\) convention consistent in code and documentation.

For the reference \(x=(2,1)\), \(\nabla q=(10,8)\) and \(\nabla^2q=\begin{bmatrix}4&2\\2&4\end{bmatrix}\).

## 5. Spectral interpretation

If symmetric \(A=Q\Lambda Q^\mathsf T\) and \(y=Q^\mathsf Tx\), then

\[
\boxed{q(x)=\sum_{i=1}^n\lambda_i y_i^2}.
\]

For the reference matrix, \(\lambda_1=3\), \(\lambda_2=1\), and unit eigenvectors \(v_1=(1,1)/\sqrt2\), \(v_2=(1,-1)/\sqrt2\). At \(x=(2,1)\),

\[
y_1=3/\sqrt2,\qquad y_2=1/\sqrt2,
\]

so

\[
q=3(9/2)+1(1/2)=\boxed{14}.
\]

This representation makes the directional curvature explicit. It also motivates the next section's distinction between positive definite, positive semidefinite, indefinite, and negative definite matrices.

## 6. Portfolio risk connection

For a return vector with a properly estimated covariance matrix \(\Sigma\) and portfolio weight vector \(w\), portfolio return variance is

\[
\operatorname{Var}(w^\mathsf TR)=w^\mathsf T\Sigma w.
\]

This identity assumes compatible return definitions, a covariance matrix for the same assets and horizon, and consistent weight conventions. A generic symmetric exposure matrix is **not automatically a covariance matrix**. The quadratic form may be a proxy for sensitivity, a local curvature approximation, or an optimization penalty; label it accordingly.

The sign of \(x^\mathsf TAx\) depends on the matrix. A covariance matrix is positive semidefinite, so its quadratic form is nonnegative. A generic symmetric matrix can produce negative values for some directions.

## 7. Homogeneity and scale

For any scalar \(c\),

\[
q(cx)=c^2q(x).
\]

Doubling positions quadruples the quadratic value under an unchanged matrix. This is a mathematical scaling rule, not a claim that all real-world financial risks scale quadratically at arbitrary position sizes. Liquidity, transaction costs, market impact, and model breakdown can violate the assumptions.

## 10. Twenty worked exercises

**1.** Define a quadratic form.  
*Answer:* \(q(x)=x^\mathsf TAx\).

**2.** Expand a symmetric \(2\times2\) form.  
*Answer:* \(ax_1^2+2bx_1x_2+dx_2^2\).

**3.** What is the reference matrix?  
*Answer:* \(\begin{bmatrix}2&1\\1&2\end{bmatrix}\).

**4.** What is the reference vector?  
*Answer:* \((2,1)\).

**5.** Compute the first diagonal term.  
*Answer:* \(2(2^2)=8\).

**6.** Compute the cross term.  
*Answer:* \(2(1)(2)(1)=4\).

**7.** Compute the second diagonal term.  
*Answer:* \(2(1^2)=2\).

**8.** Compute the total quadratic value.  
*Answer:* \(14\).

**9.** Compute \(Ax\).  
*Answer:* \((5,4)\).

**10.** Compute \(x^\mathsf T(Ax)\).  
*Answer:* \(14\).

**11.** State the general quadratic gradient.  
*Answer:* \((A+A^\mathsf T)x\).

**12.** State the symmetric quadratic gradient.  
*Answer:* \(2Ax\).

**13.** Compute the reference gradient.  
*Answer:* \((10,8)\).

**14.** State the symmetric Hessian.  
*Answer:* \(2A\).

**15.** State the spectral representation.  
*Answer:* \(\sum_i\lambda_i y_i^2\).

**16.** Compute the reference spectral coordinates.  
*Answer:* \((3/\sqrt2,1/\sqrt2)\).

**17.** Compute the spectral quadratic value.  
*Answer:* \(3(9/2)+1(1/2)=14\).

**18.** What is \(q(2x)\) for the reference?  
*Answer:* \(56\).

**19.** Does every symmetric matrix define a valid covariance matrix?  
*Answer:* No; covariance matrices must also be positive semidefinite.

*Answer:* 14.4 — Positive Definite and Semidefinite Matrices.
