## 2.2.1 Learning Objectives

After this section, you should be able to solve a one-variable linear equation through equivalent steps, classify unique, inconsistent, and identity cases, and rearrange a financial formula for a selected unknown. You should also be able to state the conditions required before dividing, distinguish a real solution from an admissible financial solution, and check a candidate in the original equation.

Section 2.1 rewrote expressions without changing their values on stated domains. Here an equality becomes a condition: which values of an unknown make it true? Solving the equation and interpreting the result are separate responsibilities.

Our running example reuses the hypothetical one-period value model with fixed and proportional fees. We solve for principal and for the required period rate while keeping the model's assumptions visible.

## 2.2.2 Recognize Linearity in the Chosen Unknown

A one-variable linear equation can be written

\[
ax+b=cx+d,
\]

with fixed coefficients. Bringing terms together gives \((a-c)x=d-b\). When the collected coefficient is nonzero, the unknown appears to the first power and has a unique real solution.

The phrase “linear in the chosen unknown” matters. The formula \(I=Prt\) is linear in \(r\) when \(P\) and \(t\) are fixed. If both \(P\) and \(r\) are unknown, their product is not a one-variable linear problem. Likewise, \(A=P(1+r)^2\) is linear in principal for fixed rate, but quadratic in rate for fixed nonzero principal.

Some expressions contain an unknown on both sides and are still linear after collection. Others look complicated but simplify to an identity or contradiction. Classify the collected equation before dividing or assuming an answer exists.

This section does not solve a system with several unknowns, a rational equation with an unknown denominator, or an equation requiring logarithms. Those problems need additional methods developed later in the curriculum.

## 2.2.3 Preserve the Solution Set at Every Step

Adding or subtracting the same expression on both sides preserves equality. Multiplying or dividing both sides by the same known nonzero number is reversible and preserves the solution set.

For example,

\[
\begin{aligned}
4(x-3)+5&=2x+9\\
4x-12+5&=2x+9\\
4x-7&=2x+9\\
2x&=16\\
x&=8.
\end{aligned}
\]

Expansion preserves the expression; subtracting \(2x\) and adding 7 preserves the equation; division by 2 is permitted because it is nonzero. Substitution gives 25 on each original side.

Avoid relying on “move it across and change the sign” as an unexplained rule. The sign changes because the same term is subtracted or added on both sides. Writing the actual operation makes it easier to audit more complicated formulas.

Multiplication by zero is not reversible. It turns any equality into \(0=0\), losing the original restriction. Division by an expression that might be zero also needs a case split. These issues are particularly important when the divisor contains parameters rather than a visible constant such as 2.

## 2.2.4 Classify the Collected Coefficient

Write the equation as \(ax+b=T\), so \(ax=T-b\). There are three cases:

| Condition | Equation type | Real solution set |
|---|---|---|
| \(a\ne0\) | Unique solution | \(\{(T-b)/a\}\) |
| \(a=0\), \(T=b\) | Identity | All real numbers |
| \(a=0\), \(T\ne b\) | Inconsistent | Empty set |

For \(0x+7=7\), every real input satisfies the equation. For \(0x+7=8\), none does. Neither case should be represented by arbitrarily returning zero as the solution.

For an equation with variables on both sides, the coefficient in this table is the **collected** coefficient. For example, \(3x+2=3x+5\) has collected coefficient zero even though the original expressions each contain a nonzero coefficient of \(x\).

A financial domain is applied after this algebraic classification. An identity over the reals may have all positive principals as its financial solutions. A unique real root might be negative and therefore excluded. Classification prevents a mathematical special case from being confused with an invalid input or a particular allowed value.

## 2.2.5 Rearrange a Formula for a Specific Variable

Use the one-period model

\[
A=P(1+r)-F-kP=P(1+r-k)-F.
\]

Here principal \(P\), fixed fee \(F\), and ending value \(A\) share one currency and scale. The gross period rate \(r\) and fee fraction \(k\) are decimals. The proportional fee is based on initial principal, and there are no additional flows or rounding steps.

To solve for principal at a specified target value, add the fixed fee and factor:

\[
A+F=P(1+r-k).
\]

If \(1+r-k\ne0\), division gives

\[
P=\frac{A+F}{1+r-k}.
\]

This is a conditional formula. Its denominator restriction belongs alongside it. It is incomplete to publish only the quotient and let a division exception stand in for the missing mathematical cases.

Treat the other parameters as fixed while solving for principal. Changing which symbol is unknown changes which coefficient can vanish and which domain must be checked.

## 2.2.6 Solve for Principal and Check the Original Model

Take target ending value \(A=1045\), gross rate \(r=0.06\), fixed fee \(F=5\), and fee fraction \(k=0.01\). Then

\[
P=\frac{1045+5}{1+0.06-0.01}
=\frac{1050}{1.05}=1000.
\]

Check the original uncollected equation:

\[
1000(1.06)-5-0.01(1000)=1045.
\]

The unique real principal is positive, so it satisfies the declared principal domain. This establishes that it meets the target under the specified model, not that an actual product will realize the quoted gross return.

A useful check is a signed residual,

\[
\varepsilon(P):=P(1+r)-F-kP-A.
\]

For \(P=1000\), it is exactly zero. For \(P=999\), it is \(-1.05\). A zero residual verifies equality for the supplied candidate and parameters. It does not by itself verify that the candidate lies in the financial domain or that the input conventions match an external source.

## 2.2.7 Handle a Vanishing or Negative Coefficient

Let \(c=1+r-k\). With \(r>-1\), \(F,k\geq0\), and target \(A\geq0\), consider the principal equation \(cP=A+F\).

If \(c=0\), the original model has ending value \(-F\) regardless of principal. When \(A=F=0\), every positive principal is admissible. If \(A+F>0\), there is no solution. For example, \(r=0,k=1,F=3,A=0\) requires \(-3=0\), which is impossible.

If \(c<0\) and \(A+F>0\), the unique real root is negative. Its residual can still be zero, but it is inadmissible under \(P>0\). If \(A=F=0\) and \(c\ne0\), the unique real root is zero, which is also excluded by that strict domain.

If \(c>0\) and \(A+F>0\), the root is positive. These branches show why checking only for a nonzero denominator is insufficient for a financial answer.

The lab permits all nonnegative fee fractions, including unusually large ones, to make these algebraic branches visible. These synthetic cases illustrate the specification; they are not descriptions of customary fees.

## 2.2.8 Solve for the Required Period Rate

For fixed positive principal, rearrange the same model for \(r\):

\[
\begin{aligned}
A+F&=P(1+r-k),\\
\frac{A+F}{P}&=1+r-k,\\
r&=\frac{A+F}{P}-1+k.
\end{aligned}
\]

Division is justified because \(P>0\). At principal 1000, target 1045, fixed fee 5, and fee fraction 0.01, this gives \(r=0.06\).

The model also requires \(r>-1\). For target zero, fixed fee zero, fee fraction zero, and positive principal, the algebraic candidate is \(r=-1\). It satisfies the ending-value equation but is excluded by this declared rate domain. Returning its exact value with `admissible=False` preserves the distinction.

A required rate is an algebraic input needed to meet the target under the model. It is not a forecast, a guaranteed available rate, or evidence that a feasible market opportunity exists. The interface uses an effective decimal period rate; annualization or quotation conversion is a separate task.

## 2.2.9 Rearrange Other Quantities Without Changing Meaning

The same equation gives

\[
F=P(1+r-k)-A,
\qquad
k=1+r-\frac{A+F}{P}\quad(P>0).
\]

After computing them, apply \(F\geq0\) or \(k\geq0\) as appropriate. A negative fixed-fee candidate may solve the equation over the reals but describes a rebate rather than a nonnegative fee under this model.

For simple interest \(I=Prt\), solving for rate gives \(r=I/(Pt)\) only when \(Pt\ne0\). If \(P>0\) and \(t=0\), then \(I=0\) for every rate allowed by the model. A nonzero target interest at zero time is inconsistent. Increasing or guessing a rate cannot resolve that contradiction.

A target in a different currency or time unit is not repaired by algebraic rearrangement. Units and conventions remain attached to every version of the formula. A rearranged expression answers the original question only if the quantities retain their original meanings.

## 2.2.10 Exact Classification and Numerical Caution

This lab classifies rational coefficients exactly. If \(c=0\), the zero-coefficient branch is used; otherwise division proceeds. There is no arbitrary threshold that silently treats a small nonzero coefficient as zero.

For example, \(c=10^{-6}\) and \(A+F=1\) imply principal \(10^6\). Replacing \(c\) by zero would change a unique-solution equation into an inconsistent one. With approximate measured inputs, a small coefficient can make the inferred principal sensitive to input changes. That requires a separate accuracy and conditioning analysis, not an undocumented algebraic shortcut.

The use of exact fractions here does not remove uncertainty from an externally supplied rate or fee. It makes the arithmetic and branch classification exact for the supplied numbers. The code rejects floats and Boolean values so that this narrow representation contract is explicit.

Check the original formula as well as the rearranged one, and report classification, candidate, domain admissibility, and residual separately. These fields answer different questions and should not be compressed into one ambiguous numeric return value.

## 2.2.11 Worked Python Lab — Classify, Rearrange, and Verify

Save as [code/section_2_02.py](code/section_2_02.py). The generic solver handles \(ax+b=T\) over the reals. Financial wrappers then apply their declared domains. `solution=None` in an all or none classification is not a zero solution; inspect `kind`.

```python
"""Exact linear classification and one-period financial rearrangements."""
from fractions import Fraction


def rational(value):
    if type(value) not in (int, str, Fraction):
        raise TypeError("use an integer, rational string, or Fraction")
    return Fraction(value)


def solve_linear(*, coefficient, constant, target):
    a, b, t = map(rational, (coefficient, constant, target))
    if a == 0:
        return {"kind": "all" if b == t else "none", "solution": None}
    return {"kind": "unique", "solution": (t - b) / a}


def principal_for_target(*, target_value, period_rate, fixed_fee, fee_rate):
    target, r, fixed, k = map(rational,
                             (target_value, period_rate, fixed_fee, fee_rate))
    if target < 0 or r <= -1 or fixed < 0 or k < 0:
        raise ValueError("require target >= 0, r > -1, F >= 0, k >= 0")
    result = solve_linear(coefficient=1 + r - k, constant=-fixed, target=target)
    p = result["solution"]
    admissible = result["kind"] == "all" or (p is not None and p > 0)
    residual = None if p is None else p * (1 + r) - fixed - k * p - target
    return {**result, "admissible": admissible, "residual": residual,
            "solution_domain": "positive real principal"}


def rate_for_target(*, principal, target_value, fixed_fee, fee_rate):
    p, target, fixed, k = map(rational,
                             (principal, target_value, fixed_fee, fee_rate))
    if p <= 0 or target < 0 or fixed < 0 or k < 0:
        raise ValueError("require P > 0 and target, F, k >= 0")
    rate = (target + fixed) / p - 1 + k
    residual = p * (1 + rate) - fixed - k * p - target
    return {"kind": "unique", "solution": rate,
            "admissible": rate > -1, "residual": residual,
            "solution_domain": "real period rate greater than -1"}


def main():
    principal = principal_for_target(target_value=1045, period_rate="0.06",
                                     fixed_fee=5, fee_rate="0.01")
    print(f"Principal: {principal['solution']}, "
          f"admissible={principal['admissible']}, residual={principal['residual']}")
    rate = rate_for_target(principal=1000, target_value=1045,
                           fixed_fee=5, fee_rate="0.01")
    print(f"Period rate: {rate['solution']}, "
          f"admissible={rate['admissible']}, residual={rate['residual']}")
    all_case = principal_for_target(target_value=0, period_rate=0,
                                    fixed_fee=0, fee_rate=1)
    none_case = principal_for_target(target_value=0, period_rate=0,
                                     fixed_fee=3, fee_rate=1)
    negative = principal_for_target(target_value=100, period_rate=0,
                                    fixed_fee=0, fee_rate=2)
    print(f"Zero coefficient, zero target: {all_case['kind']}")
    print(f"Zero coefficient, fixed fee 3: {none_case['kind']}")
    print(f"Negative real root: {negative['solution']}, "
          f"admissible={negative['admissible']}, residual={negative['residual']}")


if __name__ == "__main__":
    main()
```

Expected output:

```text
Principal: 1000, admissible=True, residual=0
Period rate: 3/50, admissible=True, residual=0
Zero coefficient, zero target: all
Zero coefficient, fixed fee 3: none
Negative real root: -100, admissible=False, residual=0
```

## 2.2.12 Practice Problems

1. Solve \(4(x-3)+5=2x+9\), naming the reversible operations. Verify the result in the original equation.
2. Classify \(0x+7=7\), \(0x+7=8\), and \(-3x+6=0\). For a separate domain \(x>0\), describe the admissible solutions.
3. Under the fee model, solve for principal when target value is 828, period rate 5%, fixed fee 4, and fee fraction 1%. Check the final value through the original formula.
4. With principal 800, target value 828, fixed fee 4, and fee fraction 1%, solve for the period rate. Then rearrange for the fixed fee using that rate and confirm its value.
5. With \(r=0,k=1,F=0,A=0\), describe the principal solutions. Change \(F\) to 3 and classify again. Separately, use \(r=0,k=2,F=0,A=100\) to find the real root and assess the positive-principal restriction.
6. For simple interest \(I=Prt\), assume \(P>0,t\geq0,r\geq0\). Find the annual simple rate when \(P=2000,I=30,t=1/4\) year. At \(t=0\), classify the possibilities for target interest zero and target interest 30 without dividing by zero.

## 2.2.13 Worked Answers

1. Expand and collect to obtain \(4x-7=2x+9\); subtract \(2x\) and add 7 to obtain \(2x=16\); divide by nonzero 2 to obtain \(x=8\). Original sides both equal 25.
2. The first is an identity; every positive real value is admissible under the added domain. The second has no real solution and therefore no admissible one. The third has unique solution \(x=2\), which is positive and satisfies the original equation.
3. \(P=(828+4)/(1+0.05-0.01)=832/1.04=800\). Original value is \(800(1.05)-4-0.01(800)=828\). The positive root is admissible.
4. \(r=(828+4)/800-1+0.01=0.05\). Rearranging for fixed fee gives \(F=800(1+0.05-0.01)-828=4\), a nonnegative fee.
5. The first case has coefficient zero and equation \(0=0\), so every positive principal works. With fixed fee 3 it becomes \(-3=0\), giving none. In the separate negative-coefficient case, \(-P=100\), so the unique real root is −100. Its residual is zero, but it is inadmissible under \(P>0\).
6. Since \(Pt=500\ne0\), rate is \(30/500=0.06\), or 6% simple per year. At zero time the model gives zero interest for every allowed nonnegative rate; target zero is satisfied by all those rates, while target 30 is inconsistent. Neither zero-time case permits the quotient \(I/(Pt)\).

## 2.2.14 Common Mistakes, Summary, and Sources

Common mistakes include changing only one side of an equality, dividing before checking a parameter-dependent coefficient, returning zero for an identity or inconsistency, and accepting a root solely because its residual is zero. Another is forgetting which variables are held fixed when calling an equation linear.

Collect the unknown's coefficient, classify its zero case, perform reversible operations, and substitute the candidate into the original equation. Then apply the financial domain and interpret the result with its units and conventions. Keep a solved-for rate or principal separate from any claim that the corresponding real-world opportunity exists.
