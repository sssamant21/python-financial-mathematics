This chapter project combines algebraic rearrangement, rational equations, inequalities, simultaneous requirements, domain restrictions, and independent substitution checks in a small deterministic financial model. The project is intentionally **not** a business forecast or investment recommendation. Its inputs are synthetic, and it uses only the Python standard library.

## 2.9.1 Project objective

Build an analyzer that answers three different questions about a single-product business model:

1. At what quantity is a specified profit achieved **exactly**?
2. What is the **minimum feasible whole-unit quantity** needed to achieve *at least* a target profit?
3. What unit selling price would produce a specified profit at a fixed quantity?

These questions are related but not interchangeable. Equality may have no integer solution even when an inequality has a feasible minimum integer quantity.

### Acceptance requirements

The analyzer must use exact rational arithmetic; reject floats, booleans, and negative prices or costs; distinguish unique, absent, and infinitely many algebraic solutions; enforce nonnegative quantities and prices; validate solutions by substituting them into the original equation; and report exact equality separately from inequality thresholds.

## 2.9.2 State the model and units

Let:

| Symbol | Meaning | Units |
|---|---|---|
| $p$ | Selling price per item | currency/item |
| $v$ | Variable cost per item | currency/item |
| $F$ | Fixed cost over the modeled period | currency |
| $q$ | Items sold | items |
| $T$ | Target profit over the period | currency |

Assume a single period, constant unit price and variable cost, no volume discounts, no taxes, no inventory changes, and no uncertainty. Then

$$\Pi(q)=pq-vq-F=(p-v)q-F.$$

Define **contribution margin per unit** $m=p-v$, with units currency/item. The model is therefore

$$\Pi(q)=mq-F.$$

For a financially meaningful base model, require $p,v,F\ge0$ and $q\ge0$. When units must be indivisible, additionally require $q\in\mathbb Z$. The contribution margin $m$ may be negative even though prices and costs are nonnegative.

## 2.9.3 Rearrange for exact target profit

Set profit equal to a target $T$:

$$mq-F=T\iff mq=F+T.$$

If $m\ne0$, the unique algebraic candidate is

$$\boxed{q=\frac{F+T}{m}}.$$

Check $q\ge0$ before reporting a financially feasible quantity. If whole units are required, also check whether the rational quantity is an integer. Do **not** silently round a solution to an equality problem: rounding generally changes the profit.

If $m=0$, the equation reduces to $-F=T$. When $T=-F$, *every* nonnegative quantity satisfies the equality; otherwise no quantity satisfies it. Dividing by zero is not a valid shortcut.

### Worked example

Let $p=25$, $v=15$, and $F=1200$ currency units. Then $m=10$ currency units/item and

$$\Pi(q)=10q-1200.$$

Break-even means $T=0$:

$$q=\frac{1200}{10}=120\text{ items}.$$

Independent substitution: $25(120)-15(120)-1200=3000-1800-1200=0$.

For $T=255$, exact equality gives $q=145.5$ items. That is valid over the nonnegative real numbers, but not when items must be whole. The exact whole-unit equality problem has **no solution**.

## 2.9.4 Minimum quantity for a profit threshold

Now require

$$\Pi(q)\ge T\iff mq\ge F+T.$$

The sign of $m$ determines the inequality:

- If $m>0$, then $q\ge(F+T)/m$. Include $q\ge0$ and take the ceiling only if whole units are required.
- If $m=0$, profit is always $-F$. Quantity zero is the minimum feasible quantity if $-F\ge T$; otherwise there is no feasible quantity.
- If $m<0$, profit decreases as quantity increases. Quantity zero gives the greatest feasible profit. If $-F\ge T$, the minimum is zero; otherwise the target is unattainable under $q\ge0$.

For the worked model, target profit $T=255$ requires

$$q\ge\frac{1200+255}{10}=145.5.$$

With whole items, the minimum is $q=146$. Check both sides of the threshold: $\Pi(145)=250<255$ and $\Pi(146)=260\ge255$. **The minimum threshold solution is not an exact-equality solution.**

## 2.9.5 Rearrange for price

For fixed $q>0$, solve

$$T=(p-v)q-F$$

for the unit selling price:

$$\boxed{p=v+\frac{F+T}{q}}.$$

For $q=150$, $v=15$, $F=1200$, and $T=300$,

$$p=15+\frac{1500}{150}=25.$$

Check: $(25-15)(150)-1200=300$. A negative computed price would violate the nonnegative-price policy and must be flagged separately.

At $q=0$, profit equals $-F$ regardless of price. If $T=-F$, any nonnegative price satisfies the target; otherwise none does. Again, the zero-denominator case is classified rather than ignored.

## 2.9.6 Implementation design

The [Python implementation](code/section_2_09.py) exposes five operations:

| Function | Contract |
|---|---|
| `model` | Validate inputs and compute exact contribution margin |
| `profit` | Evaluate the original profit equation |
| `solve_quantity` | Solve exact target equality and classify degeneracy |
| `minimum_quantity` | Solve target inequality and optionally enforce whole units |
| `solve_price` | Rearrange for price with zero-quantity and domain checks |

Inputs accept integers, rational strings (such as `"7/2"` or `"0.05"`), and `Fraction` instances. Booleans and floats are rejected to avoid accidental binary approximation. Results use explicit `kind` labels, and unique equality solutions carry a zero residual.

The integer ceiling is computed with integer arithmetic rather than floating-point conversion. No external data or packages are needed.

Run from `chapter-02/code`:

```bash
python section_2_09.py
python check_section_2_09.py
```

The [reference checks](code/check_section_2_09.py) cover exact break-even, target-profit thresholds, fractional equality quantities, inverse price solving, zero margins, negative margins, zero quantities, invalid inputs, and original-equation invariants. A passing test suite is necessary evidence, not proof of universal correctness.

## 2.9.7 Validation matrix

| Scenario | Expected result |
|---|---|
| $p=25,v=15,F=1200,T=0$ | Unique break-even: 120 items |
| Same inputs, $T=255$, real quantity | Exact equality: 145.5 items |
| Same inputs, $T=255$, whole units | No exact integer equality |
| Same inputs, $T=255$, minimum whole units | 146 items |
| $p=v$, $F=0$, $T=0$ | Every nonnegative quantity satisfies equality |
| $p=v$, $F=100$, $T=0$ | No quantity satisfies equality |
| $p<v$, $F>0$, $T=0$ | No nonnegative break-even quantity |
| $q=0$, $T=-F$ | Any nonnegative selling price works |
| $q=0$, $T\ne-F$ | No selling price works |

For each unique result, verify the original profit equation. For each inequality threshold, verify feasibility at the returned quantity and, when positive and integral, infeasibility at one unit below.

## 2.9.8 Extended exercises

1. A product sells for 40 currency units, costs 28 per item, and has fixed cost 960. Find exact break-even and check it.
2. For the same model, find the minimum whole-unit quantity giving at least 125 profit. Check the quantity immediately below.
3. Rearrange the profit equation to solve for fixed cost $F$ in terms of $p,v,q,T$. State a domain restriction for a nonnegative fixed cost.
4. Suppose contribution margin is zero and fixed cost is 50. Classify exact target profits $T=-50$ and $T=0$.
5. Explain why rounding $q=145.5$ to $146$ is appropriate for a minimum-profit inequality but not for exact target-profit equality.
6. Propose two metamorphic tests: one involving scaling all currency values by the same positive factor, and one involving direct substitution into the original profit formula.

### Reference answers

1. Margin $12$; $q=960/12=80$ items. Check: $12(80)-960=0$.
2. Require $12q-960\ge125$, so $q\ge1085/12=90+5/12$; minimum whole units is $91$. Profit at $90$ is $120<125$, while profit at $91$ is $132\ge125$.
3. $F=(p-v)q-T$. Require $(p-v)q-T\ge0$ if fixed cost cannot be negative.
4. $T=-50$ holds for every nonnegative quantity; $T=0$ holds for none.
5. At 146 items profit is 260, not 255. The inequality is met, but equality is not.
6. Scaling $p,v,F,T$ by $k>0$ preserves quantity solutions and multiplies profits by $k$; any returned exact solution must have zero original-model residual.

## 2.9.9 Limitations and production boundaries

This is a mathematical teaching tool, not a production finance system. It does not model taxes, capacity, tiered prices, stochastic demand, multiple products, nonlinear costs, time value of money, or accounting conventions. A production implementation would require explicit currency and rounding policies, input provenance, error handling, auditability, and domain-specific review.
