## Learning objectives

Define scalar-valued multivariable functions, distinguish inputs from outputs, identify domains and units, evaluate financial models with several inputs, interpret level sets and cross-sections, and recognize the importance of controlled comparisons and validation.

## 1. From one input to several

A single-variable function maps one number to another: \(f(x)\). A function of several variables maps an input vector to an output:

\[
f:D\subseteq\mathbb R^n\to\mathbb R,\qquad
(x_1,\ldots,x_n)\mapsto f(x_1,\ldots,x_n).
\]

For example, the future value of a principal \(P\), continuously compounded at rate \(r\) for time \(t\), is

\[
\boxed{V(P,r,t)=Pe^{rt}}.
\]

This is a three-input scalar-valued function. Its financial domain may be \(P\ge0\), \(t\ge0\), and \(r\in\mathbb R\), with \(r\) measured in inverse years and \(t\) in years. These domain choices are model assumptions; an application may impose tighter business rules.

## 2. Domain, range, and units

The **domain** contains admissible input combinations. The **range** contains outputs achieved on that domain. For \(V(P,r,t)\) with \(P\ge0\), \(t\ge0\), and finite real \(r\), the range is nonnegative. If \(P>0\), the output is strictly positive for finite \(r,t\).

A numerical program must also restrict values to those representable by floating-point arithmetic. Mathematically valid inputs can still overflow or underflow during evaluation.

Units are essential: \(rt\) must be dimensionless. Using a rate quoted as 5% per year means \(r=0.05\), not \(5\). Months must be converted to years before combining them with an annual rate.

## 3. Worked example: account value

Let \(P=1000\), \(r=0.05\), and \(t=2\) years. Then

\[
V(1000,0.05,2)=1000e^{0.1}\approx\boxed{1105.170186}.
\]

Change only \(r\) to \(0.06\), holding \(P,t\) fixed:

\[
V(1000,0.06,2)=1000e^{0.12}\approx1127.496852.
\]

The finite change in value is approximately \(22.326666\). This is a **scenario difference**, not yet a partial derivative. Section 15.2 introduces local rate sensitivity.

## 4. Cross-sections and controlled comparisons

A cross-section fixes all but one input. For example,

\[
g(r)=V(1000,r,2)=1000e^{2r}
\]

is a single-variable slice of the original multivariable function. Cross-sections make it easier to inspect one assumption at a time, but real financial inputs may move jointly.

A scenario table can compare rate and horizon simultaneously:

| Annual rate | 1 year | 2 years |
|---|---:|---:|
| 0% | 1000.00 | 1000.00 |
| 5% | 1051.27 | 1105.17 |
| 10% | 1105.17 | 1221.40 |

Each entry uses the same \(P=1000\) and consistent units.

## 5. Level sets

A **level set** for output \(c\) is

\[
\{(P,r,t)\in D:V(P,r,t)=c\}.
\]

For fixed \(P>0\), a target value \(c>0\) satisfies

\[
rt=\ln(c/P).
\]

When \(t>0\),

\[
\boxed{r=\frac{\ln(c/P)}{t}}.
\]

Many rate–time pairs can generate the same value. If \(t=0\), the value is \(P\) regardless of rate; division by \(t\) would be invalid. Level sets describe mathematical equivalence, not necessarily equivalent economic risks.

## 6. A second financial example: discounted cash flow

For a single future cash flow \(F\), continuously discounted,

\[
\boxed{PV(F,r,t)=Fe^{-rt}}.
\]

With \(F=1000\), \(r=0.05\), and \(t=2\), present value is \(1000e^{-0.1}\approx904.837418\). The same domain and unit discipline applies. The model omits credit, liquidity, and cash-flow uncertainty unless explicitly added.

## 7. Vector-valued functions

Some financial models produce multiple outputs:

\[
G(P,r,t)=\begin{bmatrix}Pe^{rt}\\Pe^{-rt}\end{bmatrix}.
\]

This maps \(\mathbb R^3\) inputs to \(\mathbb R^2\) outputs on the chosen domain. Scalar functions and vector functions have different derivative structures; later sections introduce gradients and Jacobians.

## 8. Numerical safeguards

- Validate the number and type of inputs; reject booleans masquerading as numbers.
- Reject nonfinite inputs and outputs.
- State rate conventions and time units explicitly.
- Do not infer causality from a scenario difference.
- Avoid comparing outputs from different valuation conventions without reconciliation.
- Use tolerances when comparing floating-point results; document reference values.
- Do not treat an educational deterministic valuation as an approved financial forecast.

## 10. Twenty worked exercises

**1.** Define a scalar-valued multivariable function.  
*Answer:* \(f:D\subseteq\mathbb R^n\to\mathbb R\).

**2.** How many inputs does \(V(P,r,t)\) have?  
*Answer:* Three.

**3.** What is the output of \(V\)?  
*Answer:* Future account value in currency units.

**4.** State the continuously compounded value function.  
*Answer:* \(V=Pe^{rt}\).

**5.** What must be dimensionless in the exponent?  
*Answer:* \(rt\).

**6.** Express 5% as a decimal.  
*Answer:* \(0.05\).

**7.** Convert 18 months to years.  
*Answer:* \(1.5\) years.

**8.** Evaluate \(V(1000,0,2)\).  
*Answer:* 1000.

**9.** Evaluate \(V(0,0.05,2)\).  
*Answer:* 0.

**10.** Evaluate \(V(1000,0.05,2)\).  
*Answer:* Approximately 1105.170186.

**11.** Evaluate \(V(1000,0.06,2)\).  
*Answer:* Approximately 1127.496852.

**12.** Compute the scenario difference between Exercises 11 and 10.  
*Answer:* Approximately 22.326666.

**13.** What is a cross-section?  
*Answer:* A function obtained by fixing some inputs.

**14.** Give the rate cross-section for \(P=1000,t=2\).  
*Answer:* \(g(r)=1000e^{2r}\).

**15.** Define a level set.  
*Answer:* All admissible inputs producing a specified output.

**16.** Solve \(Pe^{rt}=c\) for \(r\), assuming \(P,c,t>0\).  
*Answer:* \(r=\ln(c/P)/t\).

**17.** Why is the inverse formula invalid at \(t=0\)?  
*Answer:* It divides by zero; rate cannot be identified from value at zero time.

**18.** Write the discounted cash-flow function.  
*Answer:* \(PV(F,r,t)=Fe^{-rt}\).

**19.** Evaluate \(PV(1000,0.05,2)\).  
*Answer:* Approximately 904.837418.

**20.** What comes next?  
*Answer:* 15.2 — Partial Derivatives.

## 11. Applied assessment

Construct a 3×2 grid of \(V(1000,r,t)\) for rates \(0,0.05,0.10\) and horizons \(1,2\). Explain which inputs vary, verify that \(V(P,0,t)=P\), calculate \(PV(1000,0.05,2)\), and recover the annual rate that produces \(1000e^{0.1}\) after two years.

**Acceptance:** grid values match the stated model within documented floating-point tolerances; recovered rate \(0.05\); invalid inputs rejected; model units and assumptions stated.
