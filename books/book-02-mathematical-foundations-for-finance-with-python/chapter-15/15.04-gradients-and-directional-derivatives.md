## Learning objectives

Construct gradients, compute directional derivatives along normalized vectors, distinguish gradients from finite changes, interpret gradient geometry, and apply sensitivity calculations to portfolio variance and continuously compounded valuation.

## 1. The gradient

For differentiable \(f:\mathbb R^n\to\mathbb R\), the **gradient** is the vector of partial derivatives:

\[
\boxed{\nabla f(x)=\begin{bmatrix}
\partial f/\partial x_1\\ \vdots\\ \partial f/\partial x_n
\end{bmatrix}}.
\]

For a small input displacement \(\Delta x\), the first-order approximation is

\[
f(x+\Delta x)-f(x)\approx\nabla f(x)^\mathsf T\Delta x.
\]

The gradient is evaluated at a specified base point. Its components have output units per unit of the corresponding input; components involving different units should not be compared directly as if they had identical dimensions.

## 2. Directional derivatives

For a **unit** direction vector \(u\), the directional derivative is

\[
\boxed{D_uf(x)=\lim_{h\to0}\frac{f(x+hu)-f(x)}h
=\nabla f(x)^\mathsf Tu}.
\]

If \(d\ne0\) is not normalized, use \(u=d/\|d\|_2\) for change per unit distance in the selected coordinate system. The derivative along a parametrized path \(x(s)=x+sd\) is instead \(df(x(s))/ds|_{s=0}=\nabla f(x)^\mathsf Td\). These are different conventions.

For fixed Euclidean units, the maximum directional derivative is \(\|\nabla f\|_2\), attained in the positive gradient direction when the gradient is nonzero; the minimum is its negative. In financial problems, coordinate scaling and feasible constraints often make this purely geometric statement insufficient for an investment decision.

## 3. Polynomial example

Let

\[
f(x,y)=x^2+2xy+3y^2.
\]

Then

\[
\nabla f(x,y)=\begin{bmatrix}2x+2y\\2x+6y\end{bmatrix}.
\]

At \((1,2)\), \(\nabla f=(6,14)^\mathsf T\). For the unit direction \(u=(3/5,4/5)^\mathsf T\),

\[
D_uf(1,2)=6(3/5)+14(4/5)=\boxed{14.8}.
\]

For \(d=(3,4)\), the derivative with respect to the path parameter \(s\) is \(6(3)+14(4)=74\), exactly five times the unit-direction derivative.

## 4. Portfolio variance as a quadratic function

Let a symmetric covariance matrix be

\[
C=\begin{bmatrix}0.04&0.01\\0.01&0.09\end{bmatrix},
\quad w=\begin{bmatrix}0.6\\0.4\end{bmatrix}.
\]

Portfolio variance is

\[
q(w)=w^\mathsf TCw.
\]

For symmetric \(C\),

\[
\boxed{\nabla q(w)=2Cw}.
\]

Here \(Cw=(0.028,0.042)^\mathsf T\), so

\[
\boxed{\nabla q(w)=(0.056,0.084)^\mathsf T}.
\]

Choose the **weight-preserving** unit direction

\[
u=\frac{1}{\sqrt2}(1,-1)^\mathsf T.
\]

Since its components sum to zero, a sufficiently small displacement along \(u\) preserves the total weight of one. The directional derivative is

\[
D_uq(w)=\frac{0.056-0.084}{\sqrt2}
=\boxed{-0.014\sqrt2\approx-0.019799}.
\]

This is local variance change per unit Euclidean weight displacement, **not** volatility change or a guaranteed risk reduction for arbitrary trade sizes. Long-only bounds also constrain how far the weights may move.

## 5. Exact change versus first-order estimate

For a quadratic form,

\[
q(w+hd)-q(w)
=2h\,d^\mathsf TCw+h^2d^\mathsf TCd.
\]

The first term is the directional linear approximation; the second is the exact curvature correction. For the unit direction \(u=(1,-1)/\sqrt2\),

\[
u^\mathsf TCu=\frac{0.04-2(0.01)+0.09}{2}=0.055.
\]

Thus

\[
\boxed{q(w+hu)-q(w)=-0.014\sqrt2\,h+0.055h^2}.
\]

For \(h=0.01\), the linear estimate is approximately \(-0.000197990\), while the exact change adds \(0.0000055\).

## 6. Valuation gradient

For \(V(P,r,t)=Pe^{rt}\),

\[
\boxed{\nabla V=
\begin{bmatrix}
e^{rt}\\Pte^{rt}\\Pre^{rt}
\end{bmatrix}}.
\]

At \((P,r,t)=(1000,0.05,2)\), the components are approximately

\[
(1.105170,\ 2210.340372,\ 55.258509).
\]

These components have **different units**, so Euclidean normalization of the raw three-component gradient is generally not economically meaningful. To evaluate a scenario \((dP,dr,dt)\), use the path derivative

\[
\frac{dV}{ds}=V_P\frac{dP}{ds}+V_r\frac{dr}{ds}+V_t\frac{dt}{ds}.
\]

For the path slopes \((100,0.01,0.5)\), the derivative is

\[
100e^{0.1}+20e^{0.1}+25e^{0.1}
=\boxed{145e^{0.1}\approx160.249677}.
\]

This agrees with Section 15.3.

## 7. Gradient orthogonality and level sets

For a differentiable level curve \(f(x,y)=c\), any tangent vector \(v\) at a regular point satisfies

\[
\nabla f(x,y)^\mathsf Tv=0.
\]

The gradient is normal to the level curve when \(\nabla f\ne0\). For financial valuation, a level set can represent combinations of inputs that produce the same modeled value, but this does not imply equal risk, liquidity, or implementation cost.

## 8. Validation and operational caveats

- Check symmetry and input dimensions before using \(\nabla(w^\mathsf TCw)=2Cw\).
- Distinguish variance sensitivities from volatility sensitivities.
- State whether the direction is unit length or a path-parameter velocity.
- Use domain-preserving perturbations for finite differences.
- Compare analytical derivatives with centered differences using suitable steps and tolerances.
- Document constraints, units, coordinate scaling, and the fact that covariance estimates may be uncertain.

## 10. Twenty worked exercises

**1.** Define a gradient.  
*Answer:* The vector of first partial derivatives.

**2.** What is the gradient of \(f=x^2+y^2\)?  
*Answer:* \((2x,2y)\).

**3.** What is the gradient of \(f=x^2+2xy+3y^2\)?  
*Answer:* \((2x+2y,2x+6y)\).

**4.** Evaluate that gradient at \((1,2)\).  
*Answer:* \((6,14)\).

**5.** Normalize \(d=(3,4)\).  
*Answer:* \(u=(3/5,4/5)\).

**6.** Find \(D_uf(1,2)\) for that \(u\).  
*Answer:* \(14.8\).

**7.** Find the derivative along \(x(s)=(1,2)+s(3,4)\) at zero.  
*Answer:* \(74\).

**8.** Why do the answers to Exercises 6 and 7 differ?  
*Answer:* One uses a unit direction; the other uses the unnormalized path velocity.

**9.** State the gradient of \(q(w)=w^\mathsf TCw\) for symmetric \(C\).  
*Answer:* \(2Cw\).

**10.** Compute \(Cw\) for the reference portfolio.  
*Answer:* \((0.028,0.042)\).

**11.** Compute \(\nabla q(w)\).  
*Answer:* \((0.056,0.084)\).

**12.** Normalize \((1,-1)\).

**16.** State the exact quadratic change along \(u\).

**17.** Find \(V_P\) for \(V=Pe^{rt}\).

### Covariance normalization contract

The teaching helpers accept off-diagonal entries under their existing `math.isclose` policy, then replace both with the float-rounded exact midpoint of the represented entries. Variance, gradient and Hessian use that same symmetric matrix. Section 15.6 delegates covariance validation to Section 15.4. The determinant screen requires a finite positive result and a positive first diagonal; singular PSD matrices remain outside this restricted API even though the mathematical identities apply more broadly. Extreme determinant range/underflow is not a general positive-definiteness certificate. [Consistency regression and limits](../validation/chapter-15-covariance-consistency-followup.md).


### Determinant-screen exclusions

A rejection by the finite floating-point determinant screen does not prove that a matrix is mathematically non-positive-definite. Selected exactly positive-definite inputs are excluded when determinant products overflow, underflow or round to a cancelling value. The teaching API preserves that restricted acceptance policy; use an appropriate scaled factorization or higher-precision classification when these cases matter. [Exact-reference exclusion benchmarks](../validation/chapter-15-covariance-screen-followup.md).
