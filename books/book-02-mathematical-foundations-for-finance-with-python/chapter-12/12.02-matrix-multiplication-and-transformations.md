## Learning objectives

Explain the row-by-column definition of matrix multiplication, determine compatible shapes, demonstrate noncommutativity and associativity, compose transformations, and apply labeled matrix products to financial factor exposures.

## 1. Matrix multiplication

For \(A\in\mathbb R^{m\times n}\) and \(B\in\mathbb R^{n\times p}\), the product \(C=AB\in\mathbb R^{m\times p}\) is defined by

\[
\boxed{c_{ij}=\sum_{k=1}^{n}a_{ik}b_{kj}}.
\]

The **inner dimensions** must agree. The output retains the left matrix's row axis and the right matrix's column axis. Multiplication is generally **not commutative**: \(AB\ne BA\), and one product can exist while the other does not.

For

\[
A=\begin{bmatrix}1&2\\3&4\end{bmatrix},
\quad
B=\begin{bmatrix}2&0\\1&3\end{bmatrix},
\]

\[
AB=\begin{bmatrix}4&6\\10&12\end{bmatrix},
\qquad
BA=\begin{bmatrix}2&4\\10&22\end{bmatrix}.
\]

Both products are defined, but they differ.

## 2. Transformations and composition

A matrix represents a linear transformation once its input and output coordinate systems are defined. For \(x\in\mathbb R^n\), \(Ax\in\mathbb R^m\) maps \(n\) input coordinates into \(m\) output coordinates.

When dimensions agree, \(A(Bx)=(AB)x\). Thus **\(AB\) applies \(B\) first, then \(A\)** to a column vector. This order matters in risk-factor transformations, currency conversions, and portfolio aggregation.

## 3. Financial exposure chain

Let the asset-by-factor sensitivity matrix be

\[
S=\begin{bmatrix}
2&1\\
-1&3\\
0&4
\end{bmatrix},
\]

with asset rows ALPHA/BETA/GAMMA and factor columns RATE/CREDIT. Let portfolio weights be \(w=(0.5,0.3,0.2)\). Then

\[
w^\mathsf T S=(0.7,2.2).
\]

Now define a factor-by-scenario mapping

\[
T=\begin{bmatrix}1&2\\3&-1\end{bmatrix},
\]

with factor rows RATE/CREDIT and scenario columns BASE/STRESS. The portfolio's scenario coordinates are

\[
(w^\mathsf T S)T=(0.7+6.6,\ 1.4-2.2)=\boxed{(7.3,-0.8)}.
\]

Equivalently, compute the asset-by-scenario matrix \(ST\) first, then aggregate using \(w^\mathsf T(ST)\). Both paths agree by associativity.

**Interpretation caution:** These are illustrative standardized coordinates, **not** dollar P&L or scenario returns. In real applications, each transformation must carry economically compatible units and an explicit calibration.

## 4. Why labels matter more than shape alone

Suppose the factor rows of \(T\) arrive in CREDIT/RATE order rather than RATE/CREDIT. Positional multiplication would silently assign the wrong coefficients. A reliable implementation must match the left matrix's factor column labels to the right matrix's factor row labels before multiplication.

A dimensionally compatible but semantically incompatible matrix product is still invalid. Also reject duplicate labels, missing or extra factors, ragged rows, nonfinite entries, and unsupported unit contracts.

## 5. Matrix multiplication versus elementwise multiplication

Matrix multiplication combines inner dimensions through sums of products. Elementwise multiplication combines corresponding entries and typically requires matching shapes or explicit broadcasting. For square matrices, \(A@B\) and \(A*B\) in NumPy are fundamentally different.

\`\`\`python
import numpy as np
A = np.array([[1, 2], [3, 4]])
B = np.array([[2, 0], [1, 3]])
assert np.array_equal(A @ B, [[4, 6], [10, 12]])
assert np.array_equal(A * B, [[2, 0], [3, 12]])
\`\`\`

## 7. Exercises with worked answers

**1.** Multiply \(A=\begin{bmatrix}1&2\\3&4\end{bmatrix}\) and \(B=\begin{bmatrix}2&0\\1&3\end{bmatrix}\).  
*Answer:* \(\begin{bmatrix}4&6\\10&12\end{bmatrix}\).

**2.** Calculate \(BA\).  
*Answer:* \(\begin{bmatrix}2&4\\10&22\end{bmatrix}\).

**3.** Are \(AB\) and \(BA\) equal?  
*Answer:* No.

**4.** What is the shape of a \((3,2)\) times \((2,4)\) product?  
*Answer:* \((3,4)\).

**5.** Can a \((3,2)\) matrix multiply a \((3,4)\) matrix?  
*Answer:* No; 2 differs from 3.

**6.** Can a \((4,3)\) matrix multiply a \((3,1)\) matrix?  
*Answer:* Yes; output shape \((4,1)\).

**7.** What does \(ABx\) apply first?  
*Answer:* \(B\), then \(A\).

**8.** Is matrix multiplication associative when all products exist?  
*Answer:* Yes, \(A(BC)=(AB)C\).

**9.** Is matrix multiplication commutative?  
*Answer:* Not generally.

**10.** Find \(w^\mathsf TS\) for the reference portfolio.  
*Answer:* \((0.7,2.2)\).

**11.** Find the BASE scenario coordinate.  
*Answer:* \(7.3\).

**12.** Find the STRESS scenario coordinate.  
*Answer:* \(-0.8\).

**13.** Why should factor axes be aligned by label?  
*Answer:* Shape equality cannot detect reordered factor identities.

**14.** Why is a standardized exposure not automatically dollar P&L?  
*Answer:* Economic interpretation depends on factor calibration, units, and the mapping to actual cash flows.
