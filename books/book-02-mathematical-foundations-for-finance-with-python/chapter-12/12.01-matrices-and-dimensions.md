## Learning objectives

Define matrices, rows, columns, shape, and indexing; distinguish vectors from matrices; validate financial axis labels and units; and implement safe portfolio-by-factor exposure aggregation.

## 1. Matrix notation

A matrix \(A\in\mathbb R^{m\times n}\) is a rectangular array with \(m\) rows and \(n\) columns:

\[
A=\begin{bmatrix}a_{11}&\cdots&a_{1n}\\ \vdots&\ddots&\vdots\\a_{m1}&\cdots&a_{mn}\end{bmatrix}.
\]

The entry \(a_{ij}\) is in row \(i\), column \(j\) (mathematical indexing begins at 1; Python indexing begins at 0). Its **shape** is \((m,n)\). A row vector is \(1\times n\), a column vector is \(n\times1\), and a scalar is not automatically a \(1\times1\) matrix in NumPy. The shape \((n,)\) represents a one-dimensional array without a declared row/column orientation.

## 2. Financial exposure matrix

Consider a position-by-factor sensitivity matrix, with rows ALPHA, BETA, GAMMA and columns RATE, CREDIT:

\[
S=\begin{bmatrix}
2&1\\
-1&3\\
0&4
\end{bmatrix},\qquad \operatorname{shape}(S)=(3,2).
\]

The coefficients here are **dimensionless standardized sensitivity units** for a teaching example. Production risk factors may have incompatible units (DV01, spread duration, delta); these must be normalized or treated using a documented factor-specific convention.

For holdings weights \(w=(0.5,0.3,0.2)\), aggregate factor exposures are

\[
w^\mathsf T S
=\bigl(0.5(2)+0.3(-1)+0.2(0),\
0.5(1)+0.3(3)+0.2(4)\bigr)
=\boxed{(0.7,2.2)}.
\]

The output has two factor coordinates. A matrix is not merely a nested list: row and column meanings are part of the data contract.

## 3. Shape rules

Two matrices can be added only when their dimensions agree. The matrix-vector product \(S^\mathsf T w\) is defined because \(S^\mathsf T\) has shape \((2,3)\) and \(w\) has three entries, producing a two-component factor vector.

In contrast, \(Sw\) is undefined for \(S\in\mathbb R^{3\times2}\) and \(w\in\mathbb R^3\): inner dimensions \(2\) and \(3\) disagree. **Shape compatibility is necessary, not sufficient**: label order, axis meaning, units, and timestamps must also match.

## 4. Python and NumPy shapes

\`\`\`python
import numpy as np
S = np.array([[2.0, 1.0], [-1.0, 3.0], [0.0, 4.0]])
w = np.array([0.5, 0.3, 0.2])
assert S.shape == (3, 2)
assert w.shape == (3,)
assert np.allclose(w @ S, [0.7, 2.2])
\`\`\`

The companion lab uses only the Python standard library so that the essential contracts remain transparent. It aligns weights by asset labels before aggregation, validates unique row/column labels, rejects ragged matrices and nonfinite values, and reports factor outputs by label.

## 5. Common failure modes

| Failure | Why it matters | Required behavior |
|---|---|---|
| Ragged rows | No consistent rectangular shape | Reject |
| Duplicate asset label | Ambiguous join | Reject |
| Missing factor label | Incomplete factor coverage | Reject |
| Shuffled weights | Positional aggregation is wrong | Align by label |
| Transposed matrix | Axes swapped | Check declared axis semantics |
| Mixed units | Meaningless sum | Reject or normalize upstream |
| NaN/Infinity | Invalid numerical result | Reject |

## 6. Worked exercises

**1.** What is the shape of \(\begin{bmatrix}1&2&3\\4&5&6\end{bmatrix}\)?  
*Solution:* \((2,3)\).

**2.** Identify \(a_{23}\) in Exercise 1.  
*Solution:* 6.

**3.** How many elements are in a \(4\times5\) matrix?  
*Solution:* 20.

**4.** What is the shape of \(S^\mathsf T\) when \(S\) is \(3\times2\)?  
*Solution:* \((2,3)\).

**5.** Can \(3\times2\) and \(3\times2\) matrices be added?  
*Solution:* Yes.

**6.** Can \(3\times2\) and \(2\times3\) matrices be added?  
*Solution:* No.

**7.** Can \(S^\mathsf T\) multiply a three-component vector?  
*Solution:* Yes; the result has two components.

**8.** Can \(S\) multiply a three-component column vector?  
*Solution:* No; the inner dimensions disagree.

**9.** Find the RATE exposure of the example portfolio.  
*Solution:* 0.7 standardized units.

**10.** Find the CREDIT exposure.  
*Solution:* 2.2 standardized units.

**11.** Why does a shuffled weight vector require alignment?  
*Solution:* Equal shape does not guarantee matching asset identities.

**12.** Why reject duplicate labels?  
*Solution:* They make asset-to-row mapping ambiguous.

**13.** What is a ragged matrix?  
*Solution:* A nested sequence whose rows have different lengths.

**14.** Does a numerical \((3,2)\) shape identify which axis is assets?  
*Solution:* No; axis metadata is required.
