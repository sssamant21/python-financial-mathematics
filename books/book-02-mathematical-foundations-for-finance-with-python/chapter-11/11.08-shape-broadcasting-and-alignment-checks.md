## Learning objectives

Distinguish scalar, vector, and matrix shapes; understand NumPy broadcasting; recognize valid and invalid financial alignment; implement fail-closed label, unit, and shape contracts; and test numerical pipelines against silent mismatches.

## 1. Shape is part of the contract

A scalar has shape \`()\`, a one-dimensional vector of three assets has shape \`(3,)\`, and a matrix of four dates by three assets has shape \`(4,3)\`. A shape describes array structure, **not** the identity or meaning of an axis.

For example, prices \((100,50,25)\) USD/share and holdings \((2,4,10)\) shares yield market value \(650\) USD. If holdings arrive in GAMMA/ALPHA/BETA order as \((10,2,4)\), positional multiplication yields \(1200\) USD, even though both vectors have shape \`(3,)\`. Correctly realigning by asset produces \(650\) USD.

## 2. NumPy broadcasting

NumPy compares array shapes from the trailing dimensions. Two dimensions are compatible if they are equal or either is 1. Missing leading dimensions are treated as 1.

Examples:

| Left shape | Right shape | Result |
|---|---|---|
| \`(3,)\` | \`(3,)\` | \`(3,)\` |
| \`(4,3)\` | \`(3,)\` | \`(4,3)\` |
| \`(4,1)\` | \`(1,3)\` | \`(4,3)\` |
| \`(4,3)\` | \`(4,)\` | Error: trailing dimensions 3 and 4 disagree |
| \`(3,1)\` | \`(3,)\` | \`(3,3)\`, potentially unintended |

Broadcasting is a computational rule, **not** proof of financial correctness. The dangerous \`(3,1) * (3,)\` case can silently produce a 3×3 outer product instead of three matched position values.

## 3. Axis meaning and matrix orientation

Let \(\mathbf R\) be a return matrix with shape \((T,N)\), where rows represent dates and columns represent assets. For portfolio weights \(\mathbf w\) with shape \((N,)\), the portfolio return series is

\[
\mathbf r_p=\mathbf R\mathbf w
\]

with shape \((T,)\). This assumes all columns are aligned to weight labels and returns use compatible periods and conventions.

For \(T=2,N=3\),

\[
\mathbf R=\begin{bmatrix}0.01&-0.02&0.03\\0.02&0.01&-0.01\end{bmatrix},
\quad
\mathbf w=\begin{bmatrix}0.5\\0.3\\0.2\end{bmatrix}.
\]

Then \(\mathbf r_p=(0.005,0.011)\). A transposed matrix may produce a dimension error—or, if square, silently calculate the wrong thing.

## 4. Label, unit, and timestamp alignment

A reliable pipeline verifies:

1. **Unique labels:** reject duplicates, blanks, and missing/extra assets.
2. **Axis semantics:** distinguish asset, date, factor, and scenario dimensions.
3. **Unit contracts:** USD/share × shares yields USD; dimensionless weights × simple returns yields simple return.
4. **Temporal consistency:** match valuation timestamps and return periods.
5. **Finite values:** reject NaN, positive/negative infinity, and booleans treated as numbers.
6. **Explicit broadcasting:** permit only documented expansions, such as applying one weight vector to all dates.

Labels are identifiers, not a sort order. Reindex deliberately rather than relying on positional order or accidental dictionary iteration.

## 5. Worked portfolio example

Price labels: ALPHA/BETA/GAMMA, values \((100,50,25)\) USD/share.

Holdings labels: GAMMA/ALPHA/BETA, values \((10,2,4)\) shares.

An unsafe positional dot product gives \(100(10)+50(2)+25(4)=1200\) USD. After aligning holdings to ALPHA/BETA/GAMMA, values become \((2,4,10)\) shares and the correct market value is \(100(2)+50(4)+25(10)=650\) USD.

**Difference: 550 USD**, caused entirely by misalignment, not market movement.

## 6. Safe vectorized return example

Suppose the return matrix columns arrive in GAMMA/ALPHA/BETA order, while weights are labeled ALPHA/BETA/GAMMA. Reorder matrix columns explicitly before multiplication. For weights \((0.5,0.3,0.2)\), the two sample rows above produce portfolio returns \(0.005\) and \(0.011\). A check should verify both the matrix shape and the exact asset-label set before running the calculation.

## 8. Exercises with worked answers

**1.** What is the shape of a scalar? *Answer:* \`()\`.

**2.** What is the shape of a three-asset vector? *Answer:* \`(3,)\`.

**3.** What is the shape of four dates by three assets? *Answer:* \`(4,3)\`.

**4.** Broadcast \`(4,3)\` with \`(3,)\`. *Answer:* \`(4,3)\`.

**5.** Broadcast \`(4,1)\` with \`(1,3)\`. *Answer:* \`(4,3)\`.

**6.** Can \`(4,3)\` and \`(4,)\` broadcast? *Answer:* No.

**7.** What shape results from \`(3,1)\` and \`(3,)\`? *Answer:* \`(3,3)\`.

**8.** Does equal shape imply equal asset ordering? *Answer:* No.

**9.** Compute the correctly aligned example portfolio value. *Answer:* 650 USD.

**10.** Compute its unsafe positional value. *Answer:* 1200 USD.

**11.** Compute the error caused by misalignment. *Answer:* 550 USD.

**12.** Multiply return row \((0.01,-0.02,0.03)\) by weights \((0.5,0.3,0.2)\). *Answer:* 0.005.

**13.** Multiply return row \((0.02,0.01,-0.01)\) by those weights. *Answer:* 0.011.

**14.** Why should a square return matrix still carry axis metadata? *Answer:* Shape alone cannot distinguish dates from assets.

## 9. Applied assessment

Accept a price vector, a shuffled holdings vector, and a date-by-asset return matrix with shuffled columns. Validate labels, shape, units, and finite values; realign by asset; compute market value and portfolio returns; and reject missing or duplicate labels. Demonstrate that broadcasting compatibility alone is not a sufficient financial validation.

**Acceptance:** reference value 650 USD; returns 0.005 and 0.011; wrong-axis and wrong-label rejection; explicit broadcasting rules; reproducible source and checks.
