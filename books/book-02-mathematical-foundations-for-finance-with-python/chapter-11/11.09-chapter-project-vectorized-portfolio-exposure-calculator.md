## Project mission

Build an auditable portfolio exposure calculator that accepts labeled prices, signed holdings, an independently supplied NAV, and labeled asset-return scenarios. The calculator must reject silent misalignment, report signed and gross exposures, compute scenario P&L and portfolio return contributions, and evaluate a documented risk-policy gate.

This project integrates Sections 11.1–11.8: labeled vectors, addition and scaling, inner products, norms, orthogonality, projections, portfolio weights, and broadcasting/alignment checks.

## 1. Input contract

All prices are USD/share, holdings are signed shares, NAV is USD, and scenario returns are dimensionless **simple returns**. Asset labels must be unique and exactly matched across feeds. A scenario is an asset-labeled return vector for a defined period. Do not mix valuation timestamps, currencies, return horizons, or inconsistent corporate-action adjustments.

For this project, cash is represented explicitly as a zero-return USD position when needed. The NAV denominator is supplied independently rather than inferred from the signed sum of risky positions. The difference between NAV and marked risky positions is reported as an **unexplained reconciliation amount**; it is not automatically assumed to be cash.

## 2. Reference portfolio

| Asset | Price (USD/share) | Signed shares | Position value (USD) |
|---|---:|---:|---:|
| ALPHA | 100 | 500 | 50,000 |
| BETA | 50 | -200 | -10,000 |
| GAMMA | 25 | 800 | 20,000 |

Given NAV \(=100000\) USD, the signed position values are

\[
\mathbf v=(50000,-10000,20000)\text{ USD}.
\]

The weights relative to NAV are

\[
\mathbf w=(0.5,-0.1,0.2).
\]

The portfolio's risky-position **net exposure** is \(0.6\), **gross exposure** is \(0.8\), **long exposure** is \(0.7\), and **short exposure magnitude** is \(0.1\). The risky positions sum to 60000 USD, so the NAV reconciliation difference is 40000 USD. A real accounting system must identify the components of that difference before treating it as cash.

## 3. Scenario valuation

For scenario asset returns \(\mathbf r\), first-order marked-position P&L under a simple-return, static-holdings approximation is

\[
\boxed{\Delta V=\mathbf v^\mathsf T\mathbf r}.
\]

For scenario A, returns \((0.02,-0.01,0.04)\), the P&L is

\[
50000(0.02)+(-10000)(-0.01)+20000(0.04)
=1000+100+800=\boxed{1900\text{ USD}}.
\]

The NAV-normalized return contribution is \(1900/100000=\boxed{1.9\%}\). It is not necessarily the realized total portfolio return because the reconciliation amount, financing, fees, cash flows, and nonmodeled holdings may contribute.

For scenario B, returns \((-0.03,0.02,-0.01)\), the P&L is \(-1500-200-200=\boxed{-1900\text{ USD}}\), or \(-1.9\%\) of NAV.

## 4. Constraint gate

This project's sample policy requires: positive NAV; gross exposure at most \(1.0\); absolute individual asset weight at most \(0.6\); and an explicitly configured maximum absolute NAV reconciliation difference of 40000 USD. A budget equality \(\sum w_i=1\) is **not** imposed on the risky positions because their signed sum is \(0.6\), and the unexplained NAV difference is tracked separately.

The calculator reports each failed rule rather than silently adjusting holdings. A passing gate is only a check against the specified sample policy, not evidence of investment suitability, liquidity, legal compliance, or production certification.

## 5. Workflow architecture

1. Validate and freeze labels, prices, holdings, NAV, and scenario inputs.
2. Align holdings and every return scenario to the price asset order.
3. Compute position values and NAV-relative weights.
4. Reconcile signed risky-position value to supplied NAV.
5. Calculate long, short, net, and gross exposure.
6. Compute scenario P&L and NAV-normalized return contributions.
7. Evaluate individual-name, gross, and reconciliation constraints.
8. Export a deterministic JSON report with explicit assumptions and draft validation status.

## 7. Failure scenarios and recovery

| Failure | Detection | Safe response |
|---|---|---|
| Shuffled holdings | Same label set, different order | Realign by label |
| Missing instrument | Asset-label mismatch | Reject calculation |
| Duplicate asset | Duplicate-label validation | Reject calculation |
| Mixed currencies | Unit contract mismatch | Reject; convert upstream with documented FX |
| Zero or negative NAV | NAV validation | Reject |
| NaN or infinity | Finite-number validation | Reject |
| Gross limit exceeded | Policy breach report | Flag; do not silently rebalance |
| NAV reconciliation gap exceeded | Reconciliation policy | Flag; investigate accounting components |
| Scenario missing an asset | Label mismatch | Reject scenario |
| Unmatched timestamps | Input governance check | Stop; request consistent snapshots |
