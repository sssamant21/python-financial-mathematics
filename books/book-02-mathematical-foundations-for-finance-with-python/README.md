# Book 2 — Mathematical Foundations for Finance with Python

## Purpose

Build the algebra, calculus, linear algebra, optimization, and numerical reasoning needed to derive, implement, and validate deterministic financial models. Book 01 supplies programming foundations; Book 02 develops the mathematics behind them.
